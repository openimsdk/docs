---
title: '申请加入群组'
description: '申请加入或直接加入 Flutter 群组。'
sourcePath: '/sdk/flutter/group/join-group'
---

```dart
await OpenIM.iMManager.groupManager.joinGroup(
  groupID: groupID,
  reason: '申请加入项目讨论组',
  joinSource: 3,
);
```

固定版 `joinSource` 使用 `2` 邀请、`3` 搜索、`4` 二维码。需要审核时，Future 成功只表示申请已提交；实际加入以 `onJoinedGroupAdded` 或重新查询为准。
