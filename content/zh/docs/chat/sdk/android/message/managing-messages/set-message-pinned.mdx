---
title: '置顶或取消置顶消息'
description: '设置会话消息的置顶状态，并处理置顶消息变化事件。'
sourcePath: '/sdk/android/message/managing-messages/set-message-pinned'
---

最后一个参数为 `true` 时置顶消息，为 `false` 时取消置顶：

```java
messageManager.setConversationPinnedMsg(
    callback,
    conversationID,
    clientMsgID,
    true
);
```

成功回调表示设置请求完成，不代表置顶变化事件已经到达。

置顶消息发生变化时，`OnAdvanceMsgListener.onChangedPinnedMsg` 返回对应的 `conversationID` 和当前置顶消息列表：

```java
@Override
public void onChangedPinnedMsg(ChangedPinnedMsg event) {
    handlePinnedMessagesChanged(event.getConversationID(), event.getMsgs());
}
```

`MessageManager` 只能设置一个 `OnAdvanceMsgListener`；如果应用还需要处理其他消息事件，请在同一个 listener 中实现相应回调。设置方法见[事件概览](/sdk/android/events/overview-events)。需要主动获取当前置顶消息时，使用[查询会话置顶消息](/sdk/android/message/managing-messages/get-pinned-messages)。
