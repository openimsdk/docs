Pass the original `MessageItem` after it has been sent successfully:

```ts
const { data: message } = await openimsdk.createForwardMessage(sourceMessage);
```

A message that is still sending or has failed cannot be forwarded. When the Promise resolves, it returns a pending object with a new `clientMsgID` and does not modify the original message. Send the new object to the target one-to-one or group conversation afterward.
