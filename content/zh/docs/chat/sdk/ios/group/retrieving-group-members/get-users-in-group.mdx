从一组候选用户中快速排查哪些用户属于指定的群组：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupID` | `NSString *` | 目标群组 ID。 |
| `userIDs` | `NSArray<NSString *> *` | 待检查的候选用户 ID 列表。 |

```objc
[[OIMManager manager] getUsersInGroup:@"group_1001"
                              userIDs:@[@"user_001", @"user_002", @"user_003"]
                            onSuccess:^(NSArray<NSString *> *userIDs) {
                                [self replaceUsersInGroup:userIDs];
                            }
                            onFailure:^(NSInteger code, NSString *message) {
                                NSLog(@"getUsersInGroup failed: %ld %@", (long)code, message);
                            }];
```

状态以 `groupID:userID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回仍在该群内的用户 ID 数组 `NSArray<NSString *> *`。

该方法适用于快速过滤群内成员 ID，避免拉取和反序列化完整的群成员资料对象。查询仅返回调用时刻的数据快照，不触发成员 delegate 回调。群成员详细信息与事件处理参见[群成员查询概览](/sdk/ios/group/retrieving-group-members/overview-retrieving-group-members)。
