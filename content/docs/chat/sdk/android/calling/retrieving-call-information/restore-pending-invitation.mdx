`getSignalingInvitationInfoStartApp()` takes no application parameters. It returns the invitation snapshot that should be handled when the application starts or resumes.

```java
OpenIMClient.getInstance().signalingManager.getSignalingInvitationInfoStartApp(
    new OnBase<SignalingInfo>() {
        @Override
        public void onSuccess(SignalingInfo info) {
            if (info != null
                && info.getInvitation() != null
                && info.getInvitation().getRoomID() != null
                && !info.getInvitation().getRoomID().isEmpty()) {
                restoreIncomingCall(info);
            }
        }

        @Override
        public void onError(int code, String error) {
            clearExpiredIncomingCall();
        }
    }
);
```

Success only means that the current snapshot was retrieved; it does not replace the call listener. Restore the incoming-call interface only when both `invitation` and `roomID` are valid. Continue handling cancellation, timeout, acceptance, and hang-up through [Handle call events](/sdk/android/calling/managing-calls/handle-call-events).
