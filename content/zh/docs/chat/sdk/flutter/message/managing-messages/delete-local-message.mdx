---
title: '删除本地消息'
description: '使用 Flutter SDK 仅删除当前设备上的一条消息。'
sourcePath: '/sdk/flutter/message/managing-messages/delete-local-message'
---

```dart
await OpenIM.iMManager.messageManager.deleteMessageFromLocalStorage(
  conversationID: conversationID,
  clientMsgID: clientMsgID,
);
```

Future 成功只表示本地消息已删除。服务端仍保留记录，重建本地数据后可能再次同步；该操作不通知其他设备或会话成员，也不是撤回。
