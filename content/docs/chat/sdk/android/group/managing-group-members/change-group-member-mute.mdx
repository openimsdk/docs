`seconds` is the mute duration in seconds. Pass `0` to unmute the member. Member-level mute state is independent from the group's mute-all setting.

```java
OpenIMClient.getInstance().groupManager.changeGroupMemberMute(new OnBase<String>() {
    @Override public void onSuccess(String data) { markMemberMuteSubmitted(groupID, userID); }
    @Override public void onError(int code, String error) { showMemberMuteError(error); }
}, groupID, userID, 3600L);
```

Read `muteEndTime` from `onGroupMemberInfoChanged` to update the member state. Do not keep deriving the final mute state from local time and the submitted duration.
