---
title: '转让群主'
description: '将群主身份转让给另一名有效群成员。'
sourcePath: '/sdk/uniapp/group/managing-group-members/transfer-group-owner'
---

只有当前群主可以调用 `transferGroupOwner()`。目标用户必须是该群组中的有效成员。

```uts
import { transferGroupOwner } from '@/uni_modules/unix-openim-sdk'

await transferGroupOwner({
  groupID: groupID,
  newOwnerUserID: targetUserID,
})
```

`groupID` 是目标群组 ID，`newOwnerUserID` 是新群主的用户 ID。

Promise 成功表示 SDK 已完成转让请求。原群主和新群主的角色都可能发生变化，因此应逐条处理后续 `onGroupMemberInfoChanged()` 事件，并使用 `groupID:userID` 更新成员记录。需要重新确认管理角色时，可以调用[分页查询群成员](/sdk/uniapp/group/retrieving-group-members/get-group-member-list)，将 `filter` 设为 `OpenIMGroupMemberFilterAdminAndOwner` 查询群主和管理员。

群主需要退出群组时，必须先完成转让，再调用[退出群组](/sdk/uniapp/group/quit-group)。如果群组不再需要，也可以选择解散群组，但解散会影响所有成员。
