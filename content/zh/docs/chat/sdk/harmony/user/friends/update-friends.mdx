---
title: '更新好友资料'
description: '更新一个好友的备注、置顶状态或关系扩展字段。'

---

`updateFriend()` 每次更新一个好友。只传本次需要修改的字段；`ex` 是完整字符串，不会自动合并 JSON。

```ts
import sdk, { UpdateFriendReq } from '@openimsdk/imsdk';

const request: UpdateFriendReq = {
  userID: friendUserID,
  remark: remark.trim(),
  pinned: true,
};
await sdk.updateFriend(request);
```

Promise 成功不表示好友资料事件已经到达。收到 `EventOnFriendInfoChanged` 后，按 `friendUserID` 更新缓存；完整监听见[分页获取好友列表](/sdk/harmony/user/friends/get-friend-list-page)。
