更新当前登录账号的基础展示资料。只需传入本次需要修改的字段。

```ts
await OpenIMSDK.setSelfInfo({
  nickname: nickname.trim(),
  faceURL,
  ex: mergedExtra,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `nickname` | `string` | 否 | 新昵称。 |
| `faceURL` | `string` | 否 | 新头像地址。 |
| `ex` | `string` | 否 | 业务自定义的扩展用户信息。 |

除以上字段外，至少传入一个实际要更新的资料字段。`ex` 是字符串类型，可按业务需要传递 JSON 字符串或其他格式的自定义扩展信息。

## 返回结果

调用完成后，当前用户资料更新已生效。

更新当前用户资料后会触发 `OnSelfInfoUpdated` 事件，事件载荷携带更新后的当前用户信息。客户端应以 `userID` 为合并标识更新当前用户的资料缓存。

## 监听当前用户资料变化

用户个人信息更新时，触发 `OnSelfInfoUpdated` 事件，以下为设置监听的示例：

```ts
const handleSelfInfoUpdated = (selfUserInfo: SelfUserInfo) => {
  // 根据 selfUserInfo.userID 更新本地用户信息
};

// 设置监听
OpenIMSDK.on(OpenIMEvent.OnSelfInfoUpdated, handleSelfInfoUpdated);

// 取消监听
OpenIMSDK.off(OpenIMEvent.OnSelfInfoUpdated, handleSelfInfoUpdated);
```

退出登录、切换账号或销毁用户状态层时，取消该监听。
