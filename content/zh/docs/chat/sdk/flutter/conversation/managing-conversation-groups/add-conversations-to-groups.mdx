将一个或多个会话添加到指定的会话分组中。该操作仅建立分组关联，不会创建新会话，也不会改变消息发送目标。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationGroupIDs` | `List<String>` | 是 | 目标会话分组 ID 列表。 |
| `conversationIDs` | `List<String>` | 是 | 待加入分组的会话 ID 列表。 |

```dart
await OpenIM.iMManager.conversationGroupManager.addConversationsToGroups(
  conversationGroupIDs: [conversationGroupID],
  conversationIDs: [conversationID],
);
```

## 返回结果

Future 成功表示关联设置请求已处理完成。客户端以 `conversationGroupID` 与 `conversationID` 为合并标识更新本地分组内的会话成员列表。

多端同步或事件到达时通过 `onConversationGroupMemberAdded` 通知，完整事件监听请参考[会话分组概览](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups)。
