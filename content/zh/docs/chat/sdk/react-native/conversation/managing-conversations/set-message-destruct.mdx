配置会话的服务端消息自动定期删除策略。

```ts
await OpenIMSDK.setConversation({
  conversationID,
  isMsgDestruct: true,
  msgDestructTime: 3600,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 要设置的会话 ID。 |
| `isMsgDestruct` | `boolean` | 否 | 是否开启服务端消息定期删除。 |
| `msgDestructTime` | `number` | 否 | 消息删除周期，单位为秒。 |

启用策略时同时传入 `isMsgDestruct: true` 与 `msgDestructTime`；传入 `isMsgDestruct: false` 可关闭该策略。注意该功能与单聊阅后即焚不同，阅后即焚由 `isPrivateChat` 与 `burnDuration` 控制。

服务端消息定期删除仅影响云端保存的历史消息。已同步到客户端本地数据库的消息不会被主动清理；但在清理本地数据或更换新设备时，已被云端删除的消息将无法再次拉取。

## 返回结果

调用完成后，服务端消息定期删除策略已更新。

更新成功后会触发 `OnConversationChanged` 事件；客户端应使用 `conversationID` 定位目标会话，并合并最新的 `isMsgDestruct` 与 `msgDestructTime` 属性。完整监听方式见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。
