`data`、`extension` 和 `description` 由业务定义，接收端应按自己的协议解析。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `data` | `String` | 是 | 自定义消息主体，通常传经过校验的 JSON 字符串。 |
| `extension` | `String` | 是 | 业务扩展信息；没有内容时传空字符串。 |
| `description` | `String` | 是 | 通知栏、会话摘要等位置使用的简短描述。 |

```java
Message message = OpenIMClient.getInstance().messageManager.createCustomMessage(
    dataJson, extensionJson, description);
```

返回的 `Message` 只是在本地创建的待发送对象。发送端与接收端应按约定的协议版本和字段定义处理自定义数据，并为未知版本提供降级展示。创建完成后使用[发送消息](/sdk/android/message/sending-messages/send-message)。
