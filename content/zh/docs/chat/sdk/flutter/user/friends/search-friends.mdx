```dart
final results = await OpenIM.iMManager.friendshipManager.searchFriends(
  keywordList: [keyword.trim()],
  isSearchUserID: true,
  isSearchNickname: true,
  isSearchRemark: true,
);
```

`keywordList` 当前只传一个非空关键词，其余布尔值决定匹配用户 ID、昵称和好友备注。Future 返回 `List<SearchFriendsInfo>`；搜索结果只属于当前搜索界面，不应覆盖好友列表快照，也不会触发好友 listener。
