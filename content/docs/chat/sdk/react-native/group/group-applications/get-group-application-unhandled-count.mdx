Query the number of group applications awaiting review by the current user since a specified timestamp:

```ts
const count = await OpenIMSDK.getGroupApplicationUnhandledCount({
  time: 0,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `time` | `number` | Yes | Start timestamp in Unix milliseconds. Pass `0` to count all unhandled group applications. |

## Return value

Resolves to a `number` representing the unhandled group application count. This query reads a count snapshot and does not alter conversation unread counters or emit events.
