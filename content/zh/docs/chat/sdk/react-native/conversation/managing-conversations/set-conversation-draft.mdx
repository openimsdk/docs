为指定会话保存草稿内容。当用户离开聊天页面、切换会话或将应用切到后台时，可调用此方法持久化当前的未发送编辑内容。

```ts
await OpenIMSDK.setConversationDraft({
  conversationID,
  draftText: editorValue,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 要保存草稿的会话 ID。 |
| `draftText` | `string` | 是 | 草稿内容。传入空字符串可清除草稿。 |

输入过程中建议由业务侧维护编辑器临时状态，在离开页面或切换会话时再提交保存。

## 返回结果

调用完成后，草稿内容已持久化保存。

草稿保存后会触发 `OnConversationChanged` 事件；客户端应使用 `conversationID` 定位目标会话，并合并最新的 `draftText` 和 `draftTextTime` 字段。完整监听方式见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。切换账号或退出登录时，建议同步清理应用内存中的编辑器状态。
