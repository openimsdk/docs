分页查询当前登录用户作为群主或管理员有权审批的入群申请记录：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupIDs` | `List<String>?` | 否 | 指定群组 ID 列表进行筛选；不传表示查询全部管理的群组申请。 |
| `handleResults` | `List<int>?` | 否 | 按处理状态筛选：`0` 待处理，`1` 已通过，`-1` 已拒绝。 |
| `offset` | `int` | 是 | 分页偏移量，首屏从 `0` 开始。 |
| `count` | `int` | 是 | 每页拉取数量。 |

```dart
final applications = await OpenIM.iMManager.groupManager
    .getGroupApplicationListAsRecipient(
  GetGroupApplicationListAsRecipientReq(
    groupIDs: [groupID],
    handleResults: [0],
    offset: 0,
    count: 20,
  ),
);
```

## 返回结果

Future 成功返回符合筛选条件的 `List<GroupApplicationInfo>` 入群申请记录列表。

查询操作建立静态快照，不会触发事件通知。新申请到达或多端处理变更请参考[入群申请概览](/sdk/flutter/group/group-applications/overview-group-applications)。
