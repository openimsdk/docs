---
title: '清理全部本地消息'
description: '清理当前账号在当前设备上的全部消息。'
sourcePath: '/sdk/harmony/message/managing-messages/clear-all-local-messages'
---

```ts
import sdk from '@openimsdk/imsdk';

await sdk.deleteAllMessageFromLocal();
resetAllMessageState();
```

这是不可撤销的账号级本地操作。Promise 成功后，应同步清空当前账号的内存消息、搜索结果、分页游标和相关缓存。操作不会通知其他设备或会话成员；服务端仍可能保留历史，重新同步后消息可能重新出现。
