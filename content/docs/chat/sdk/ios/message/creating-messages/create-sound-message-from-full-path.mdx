```objc
OIMMessageInfo *message =
    [OIMMessageInfo createSoundMessageFromFullPath:audioURL.path
                                          duration:durationSeconds];
```

The path must be readable, and `duration` is measured in seconds. Send the returned object through the regular sending API so the SDK can upload and send it.
