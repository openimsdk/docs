---
title: '检查本地群组数据是否完整同步'
description: '检查当前账号的本地群组资料是否已完成全量同步。'
sourcePath: '/sdk/harmony/group/data-synchronization/check-group-data-sync'
---

该方法用于诊断或决定是否等待同步完成，不返回群组列表，也不会主动触发一次新的同步。

```ts
import sdk, { CheckLocalGroupFullSyncResp } from '@openimsdk/imsdk';

const response: CheckLocalGroupFullSyncResp = await sdk.checkLocalGroupFullSync();
if (!response.IsFullSync) {
  showGroupSyncingState();
}
```

固定响应字段为首字母大写的 `IsFullSync`。`true` 表示查询时本地群组数据已完成全量同步；`false` 表示仍可能缺少数据。同步状态后续仍可能变化，应结合 SDK 同步事件，而不是持续高频轮询。
