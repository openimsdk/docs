WASM SDK 通过 `SdkEvent` 推送连接、同步、用户、好友、会话、群组、消息和通话相关事件。`getSDK()` 返回的实例统一提供 `on()` 和 `off()`；不需要为不同领域创建独立的事件处理器对象。

## 注册与移除事件

处理函数必须保持稳定引用。需要清理时，把注册时使用的同一事件枚举值和函数引用传给 `off()`。每个事件的完整代码集中在下表链接的对应页面；本页不使用其他功能的事件重复演示通用写法。

事件回调通常包含 `data`、`errCode` 和 `errMsg`。应用应校验 `errCode`，使用 `data` 中的业务 ID 找到并更新对应记录，同时忽略重复事件；错误日志中应记录事件名和必要的业务标识。

## 监听初始化同步

登录后 SDK 会同步 OpenIMServer 数据。以下事件适合驱动全局同步状态和进度展示：

| 事件 | 含义 |
| --- | --- |
| `OnSyncServerStart` | 开始同步 OpenIMServer 数据。`data` 为 `boolean`：`true` 表示本地库因卸载重装、清除站点数据等原因重建后的同步；`false` 表示普通登录后同步。 |
| `OnSyncServerProgress` | 同步进度发生变化；`data` 为进度数值。 |
| `OnSyncServerFinish` | 本轮同步完成，可以刷新依赖完整数据的界面。 |
| `OnSyncServerFailed` | 本轮同步失败，应记录错误并等待重试或连接恢复。 |

```ts
import { SdkEvent } from '@openim/wasm-client-sdk';

function handleSyncStart({ data: reinstalled }) {
  setSyncState({ status: 'syncing', progress: 0, reinstalled });
}

function handleSyncProgress({ data }) {
  setSyncState({ status: 'syncing', progress: data });
}

function handleSyncFinish() {
  setSyncState({ status: 'ready', progress: 100 });
}

function handleSyncFailed({ errCode, errMsg }) {
  setSyncState({ status: 'failed' });
  console.error('WASM SDK 数据同步失败', { errCode, errMsg });
}

openimsdk.on(SdkEvent.OnSyncServerStart, handleSyncStart);
openimsdk.on(SdkEvent.OnSyncServerProgress, handleSyncProgress);
openimsdk.on(SdkEvent.OnSyncServerFinish, handleSyncFinish);
openimsdk.on(SdkEvent.OnSyncServerFailed, handleSyncFailed);

function removeSyncListeners() {
  openimsdk.off(SdkEvent.OnSyncServerStart, handleSyncStart);
  openimsdk.off(SdkEvent.OnSyncServerProgress, handleSyncProgress);
  openimsdk.off(SdkEvent.OnSyncServerFinish, handleSyncFinish);
  openimsdk.off(SdkEvent.OnSyncServerFailed, handleSyncFailed);
}
```

`OnSyncServerStart` 用于进入同步状态；其 `data` 表示本次同步是否发生在卸载重装或等价的本地数据库重建之后。`true` 时本地通常没有可用缓存，适合展示更完整的同步引导或全量加载提示；`false` 时通常只同步上次登录后发生的变化。`OnSyncServerProgress` 的 `data` 是当前进度数值。完成和失败事件在 WASM 声明中不携带该布尔值，只用于将本轮同步状态置为完成或失败。这些事件描述 SDK 的整体同步过程，不是某个查询 API 的 Promise 回调，也不对应某一条用户、会话或消息记录；状态应按当前 SDK 实例和登录用户隔离。

本页集中提供四个同步事件的完整监听示例。退出登录、切换账号或销毁 SDK 作用域时调用 `removeSyncListeners()`。

同步完成后，数据仍可能继续变化。应重新获取当前界面所需的数据，并继续通过各功能页面说明的事件更新界面。
