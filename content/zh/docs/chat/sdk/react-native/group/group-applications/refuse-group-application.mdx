群主或管理员拒绝指定用户的入群申请。

```ts
await OpenIMSDK.refuseGroupApplication({
  groupID: application.groupID,
  fromUserID: application.userID,
  handleMsg: '暂不接受该申请',
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 申请对应的群组 ID。 |
| `fromUserID` | `string` | 是 | 申请人的用户 ID，对应申请记录的 `userID`。 |
| `handleMsg` | `string` | 是 | 拒绝原因；没有说明时传空字符串。 |

## 返回结果

调用完成后，入群申请审批已处理完成。

拒绝后，申请状态变化会通过 `OnGroupApplicationRejected` 事件通知。客户端应在入群申请列表中更新审批状态，并以 `groupID` 关联所属群组。完整事件监听说明见[获取收到的入群申请](/sdk/react-native/group/group-applications/get-group-application-list-as-recipient)。
