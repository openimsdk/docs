---
title: '使用 URL 创建文件消息'
description: '使用 iOS SDK 从已上传 URL 创建文件消息。'
sourcePath: '/sdk/ios/message/creating-messages/create-file-message-by-url'
---

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createFileMessageByURL:uploadedURL
                                  fileName:@"report.pdf"
                                      size:uploadedSize];
```

URL、文件名和字节大小必须来自真实上传结果。返回对象发送时使用 `sendMessageNotOss:...`。
