`setAppBadge()` 用于向 SDK 上报应用当前展示的消息总未读数。

```uts
import { setAppBadge } from '@/uni_modules/unix-openim-sdk'

await setAppBadge(totalUnreadCount)
```

`totalUnreadCount` 应为非负整数。通常在消息总未读数变化、登录同步完成或清空未读消息后更新；不要把单个会话的未读数作为应用总角标。

Promise 成功只表示 SDK 已接受本次角标值，不会改变会话的本地未读数。若应用需要在系统桌面图标上展示角标，还应根据目标平台和应用的通知方案更新系统界面。消息总未读数的查询和持续维护见[获取消息总未读数](/sdk/uniapp/conversation/managing-conversations/get-total-unread-count)。
