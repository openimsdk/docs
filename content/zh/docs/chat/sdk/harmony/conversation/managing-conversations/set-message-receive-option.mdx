---
title: '设置会话消息接收方式'
description: '设置单个会话的消息接收与通知方式。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/set-message-receive-option'
---

| 枚举值                                   | 含义                 |
| ---------------------------------------- | -------------------- |
| `ConvRecvMsgOpt.ReceiveMessage`          | 正常接收并允许通知。 |
| `ConvRecvMsgOpt.NotReceiveMessage`       | 不接收该会话消息。   |
| `ConvRecvMsgOpt.ReceiveNotNotifyMessage` | 接收消息但不通知。   |

```ts
import sdk, { ConvRecvMsgOpt, SetConversationReq } from '@openimsdk/imsdk';

const request: SetConversationReq = {
  conversationID: conversationID,
  recvMsgOpt: ConvRecvMsgOpt.ReceiveNotNotifyMessage,
};
await sdk.setConversation(request);
```

会话级设置与账号级默认策略相互独立。Promise 成功、会话事件到达和重新查询是三个阶段。
