群主解散指定的群组。

```ts
await OpenIMSDK.dismissGroup(groupID);
```

## 参数说明

`groupID` 为要解散的群组 ID。解散群组会影响群内所有成员，只有群主具备解散权限，服务端会对调用者身份进行校验。

## 返回结果

调用完成后，群组已被解散。

群组解散后，群内所有成员客户端均会触发 `OnGroupDismissed` 事件，事件载荷为已解散的群组信息。客户端应以 `groupID` 为合并标识从已加入的群组列表中移除该群，并清理本地相关群会话与成员缓存。完整事件监听说明见[群组概览](/sdk/react-native/group/overview-group)。
