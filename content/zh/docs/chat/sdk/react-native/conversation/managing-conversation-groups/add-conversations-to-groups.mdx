将一个或多个会话批量添加到一个或多个会话分组中。

```ts
await OpenIMSDK.addConversationsToGroups({
  conversationIDs: [conversationID],
  conversationGroupIDs: [conversationGroupID],
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationIDs` | `string[]` | 是 | 要添加的会话 ID 列表。 |
| `conversationGroupIDs` | `string[]` | 是 | 目标会话分组 ID 列表。 |

## 返回结果

调用完成后，分组与会话的关联请求已处理完成。

分组关联变化会通过 `OnConversationGroupMemberAdded` 事件通知；客户端在合并状态时，应分别以 `conversationGroupID` 定位目标会话分组、以 `conversationID` 维护该分组内的会话列表。完整监听方式见[会话分组概览](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups)。
