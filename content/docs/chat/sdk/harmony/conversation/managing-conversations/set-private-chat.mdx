Enable or disable burn-after-reading private mode for a conversation. This operates independently of [Set periodic server message destruction](/sdk/harmony/conversation/managing-conversations/set-message-destruct):

## Code example

```ts
import sdk, { SetConversationReq } from '@openimsdk/imsdk';

const request: SetConversationReq = {
  conversationID: conversationID,
  isPrivateChat: true,
};
await sdk.setConversation(request);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `string` | Yes | Target conversation identifier. |
| `isPrivateChat` | `boolean` | Yes | Set to `true` to enable burn-after-reading; set to `false` to disable. |

## Return value

Returns a Promise that resolves to `void` when the setting is saved.

## State changes after the call

Pass `true` to enable burn-after-reading and `false` to disable it. To set the lifespan of read messages, configure [Set burn duration](/sdk/harmony/conversation/managing-conversations/set-burn-duration). After the Promise resolves, the SDK emits `EventOnConversationChanged`. Match the item by `conversationID` and update its `isPrivateChat` property in UI state, as described in [Retrieve conversation list](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list).
