---
title: '将用户加入黑名单'
description: '将指定用户加入当前账号的黑名单。'
sourcePath: '/sdk/harmony/user/blacklist/add-black'
---

```ts
import sdk, { AddBlackReq } from '@openimsdk/imsdk';

const request: AddBlackReq = {
  userID: targetUserID,
  ex: '',
};
await sdk.addBlack(request);
```

Promise 成功后等待黑名单事件到达，客户端按 `blockUserID`（即目标 `userID`）新增或更新记录，完整事件监听请参考 [获取黑名单](/sdk/harmony/user/blacklist/get-black-list)。加入黑名单不会删除历史会话；产品侧是否隐藏聊天入口应另行处理。
