同一个会话可以关联多个会话分组。使用 `getConversationGroupIDsByConversationID()` 反向查询一个会话当前所属的全部分组。

```ts
const { data: conversationGroupIDs } =
  await openimsdk.getConversationGroupIDsByConversationID(conversationID);
```

参数 `conversationID` 是 OpenIM 会话 ID，不是聊天群组 ID。

## 返回结果

Promise 成功后，`data` 是 `string[]`，每个元素都是一个 `conversationGroupID`。该方法不返回完整分组对象；需要分组资料时，再调用 `getConversationGroups()` 获取当前分组列表，具体用法见[查询会话分组列表](/sdk/wasm/conversation/managing-conversation-groups/get-conversation-groups)。

该查询不会触发分组事件。如何接收并处理会话与分组关系的后续变化，见[会话分组概览](/sdk/wasm/conversation/managing-conversation-groups/overview-conversation-groups)。
