---

在进入聊天会话窗口或网络连接重连后，若需即时查询指定成员当前是否正在输入，可调用 `getInputStates()`：

```ts
const { data: platformIDs } = await openimsdk.getInputStates({
  conversationID,
  userID: memberUserID,
});

setTyping(memberUserID, platformIDs.length > 0);
```

接口成功后返回当前仍处于输入状态的平台 ID 数组（`platformIDs`），该查询为只读操作，不会触发事件推送。在常规聊天场景中，无需轮询该接口，推荐通过 [上报输入状态](/sdk/wasm/message/composing-messages/update-typing-status) 中介绍的事件监听机制实时获知对端输入状态。
