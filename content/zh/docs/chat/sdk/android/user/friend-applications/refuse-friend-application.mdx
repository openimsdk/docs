拒绝指定用户发来的添加好友申请，并可附带拒绝理由。

```java
OpenIMClient.getInstance().friendshipManager.refuseFriendApplication(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 拒绝好友申请成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    applicantUserID,
    "暂不添加"
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `applicantUserID` | `String` | 是 | 申请发起方的用户 ID。 |
| `handleMsg` | `String` | 否 | 拒绝时的附言说明。 |

## 返回结果

成功回调表示服务端已记录拒绝处理结果。

操作完成后，SDK 会通过 `OnFriendshipListener` 派发事件：
- `onFriendApplicationRejected(FriendApplicationInfo application)`：通知申请记录状态已更新为“已拒绝”，客户端应以 `userID` 为主键更新本地申请列表中对应项的状态。

完整监听配置请参考[获取收到的好友申请](/sdk/android/user/friend-applications/get-recv-friend-application-list)。
