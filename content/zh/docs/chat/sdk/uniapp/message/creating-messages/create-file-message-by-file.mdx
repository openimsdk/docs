`createFileMessageFromFullPath()` 根据本地文件创建消息。`filePath` 是 App 原生侧能够读取的 POSIX 绝对路径或 `unifile://` URI，`fileName` 是接收端展示和保存时使用的文件名。

```uts
import {
  createFileMessageFromFullPath,
} from '@/uni_modules/unix-openim-sdk'

const message = await createFileMessageFromFullPath({
  filePath: `${uni.env.USER_DATA_PATH}/project-plan.pdf`,
  fileName: '项目计划.pdf',
})
if (message == null) return
```

文件名应保留合适的扩展名，但不能替代对真实文件类型的校验。选择器返回的临时路径可能被系统清理；需要延后发送时，先将文件保存到 `uni.env.USER_DATA_PATH`，再传入保存后的路径。

Promise 成功后返回 `OpenIMMessageItem | null`。非空结果只创建待发送对象；后续使用[发送消息](/sdk/uniapp/message/sending-messages/send-message)，由 SDK 上传文件并发送。
