当业务层已自行将图片资源上传至对象存储并持有远端 URL 时，可调用通过 URL 创建图片消息方法生成图片消息对象，避免由 SDK 重复上传。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createImageMessageByURL:@""
                              sourcePicture:source
                                 bigPicture:big
                            snapshotPicture:snapshot];
```

## 参数说明

- `sourcePath`：本地图片原始路径。仅使用远端资源时传入空字符串 `@""`。
- `sourcePicture`：原图信息对象（`OIMPictureInfo`），包含原图的 URL、尺寸及文件大小。
- `bigPicture`：大图/高清图信息对象（`OIMPictureInfo`）。
- `snapshotPicture`：缩略图信息对象（`OIMPictureInfo`）。

## 返回结果

- 返回包含远端 URL 的图片消息对象（`OIMMessageInfo *`）。传入的三个图片信息对象的 URL、大小和宽高必须来自真实的上传结果。
- 由于媒体资源已由业务自行上传，后续应调用[发送不经 OSS 的消息](/sdk/ios/message/sending-messages/send-message-not-oss)直接投递消息。若需由 SDK 托管上传本地图片文件，见[使用本地路径创建图片消息](/sdk/ios/message/creating-messages/create-image-message-from-full-path)。
