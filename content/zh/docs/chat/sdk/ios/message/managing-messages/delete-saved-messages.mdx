---
title: '批量删除消息'
description: '使用 iOS SDK 批量删除同一会话中的消息。'
sourcePath: '/sdk/ios/message/managing-messages/delete-saved-messages'
---

```objc
[[OIMManager manager] deleteMessages:conversationID
    clientMsgID:selectedClientMsgIDs
    isSync:YES
    onSuccess:nil
    onFailure:nil];
```

消息 ID 必须属于同一会话。`isSync` 控制是否请求同步到当前账号其他客户端，不代表其他会话成员已经删除。

`onMsgDeleted:` 是本页归属事件。按消息路由和 `clientMsgID` 幂等移除；事件可能来自其他客户端。listener 的稳定注册与移除见[接收消息](/sdk/ios/message/receiving-messages/receive-messages)。
