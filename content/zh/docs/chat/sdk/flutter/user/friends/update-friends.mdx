```dart
await OpenIM.iMManager.friendshipManager.updateFriends(
  UpdateFriendsReq(
    friendUserIDs: [friendUserID],
    remark: remark.trim(),
  ),
);
```

一次调用会把同一字段值应用到全部目标好友。`ex` 是完整字符串；不同好友需要不同值时分别调用。Future 成功与 `onFriendInfoChanged` 分别处理。
