传入消息列表、标题和摘要列表。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `messages` | `List<Message>` | 是 | 要合并展示的消息，按期望顺序传入。 |
| `title` | `String` | 是 | 合并消息卡片的标题。 |
| `summaries` | `List<String>` | 是 | 会话列表或卡片使用的摘要，顺序应与消息内容一致。 |

```java
Message message = OpenIMClient.getInstance().messageManager.createMergerMessage(
    messages, title, summaries);
```

返回的 `Message` 只是在本地创建的待发送对象。`messages` 决定合并卡片包含的原始消息，`summaries` 决定摘要展示内容；创建完成后使用[发送消息](/sdk/android/message/sending-messages/send-message)。
