使用 `deleteConversationGroup()` 删除指定会话分组及其会话关联。该操作不会删除分组中的会话或消息。

```dart
await OpenIM.iMManager.conversationGroupManager.deleteConversationGroup(
  conversationGroupID: conversationGroupID,
);
```

`conversationGroupID` 表示会话分组 ID，不是 OpenIM 聊天群组 ID。

## 返回结果

当前 Flutter 声明返回未具体化的 `Future`。成功表示删除请求已完成；可以先按 `conversationGroupID` 移除本地分组，再通过 `onConversationGroupDeleted` 更新状态，或重新查询确认当前结果。

完整 listener 见[会话分组概览](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups)。
