Retrieve full conversation details for a known collection of conversation IDs:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationIDList` | `List<String>` | Yes | List of target conversation IDs to query. |

## Code example

```dart
final conversations = await OpenIM.iMManager.conversationManager
    .getMultipleConversation(conversationIDList: conversationIDs);

final byID = {
  for (final item in conversations) item.conversationID: item,
};
```

## Return value

A successful `Future` returns a list of matching `ConversationInfo` objects (`List<ConversationInfo>`). If certain IDs do not exist locally, they will be omitted from the result list; do not assume a 1:1 positional correspondence between the input arguments and output items.

This query returns an immediate data snapshot and does not emit event notifications. For subsequent real-time updates, see [Retrieve conversation list](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list).
