Retrieve member profiles for designated users within a specific group:

```ts
const members = await OpenIMSDK.getSpecifiedGroupMembersInfo({
  groupID: 'group-001',
  userIDList: ['user-001', 'user-002'],
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group ID. |
| `userIDList` | `string[]` | Yes | Array of member user IDs to retrieve. |

## Return value

A resolved Promise returns `GroupMemberItem[]` matching the requested user IDs. The order of elements in the returned array is not guaranteed to match the input ID sequence; use the composite key `groupID:userID` to correlate and merge member data into your local state. For field definitions, see [Group overview](/sdk/react-native/group/overview-group).
