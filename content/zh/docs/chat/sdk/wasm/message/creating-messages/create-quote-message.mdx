---
title: '创建回复消息'
description: '创建一条包含原消息引用的回复消息。'
sourcePath: '/sdk/wasm/message/creating-messages/create-quote-message'
---

回复消息包含新的文本内容以及被回复消息的完整引用。应从当前消息列表中取得原 `MessageItem`，并在创建前确认它仍属于当前会话。

```ts
const { data: message } = await openimsdk.createQuoteMessage({
  text: '同意这个方案',
  message: JSON.stringify(originalMessage),
});
```

`text` 是新消息正文，`message` 是序列化后的原 `MessageItem`。不要手工拼接原消息字段；发送前还应按照产品规则检查空文本和内容长度。

Promise 成功后，`data` 是新的待发送 `MessageItem`，被引用消息不会被修改。下一步使用[发送消息](/sdk/wasm/message/sending-messages/send-message)投递该对象；接收端应为已删除或无法展示的原消息提供降级提示。
