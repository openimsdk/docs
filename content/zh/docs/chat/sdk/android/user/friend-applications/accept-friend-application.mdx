同意指定用户发来的添加好友申请，建立双方的好友关系。

```java
OpenIMClient.getInstance().friendshipManager.acceptFriendApplication(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 接受好友申请成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    applicantUserID,
    "已通过"
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `applicantUserID` | `String` | 是 | 申请发起方的用户 ID。 |
| `handleMsg` | `String` | 否 | 审批通过时的附言说明。 |

## 返回结果

成功回调表示服务端已记录接受操作并建立双向好友关系。

操作完成后，SDK 会通过 `OnFriendshipListener` 派发事件：
- `onFriendApplicationAccepted(FriendApplicationInfo application)`：通知申请记录状态已更新为“已同意”，客户端应以 `userID` 为主键更新申请项状态。
- `onFriendAdded(FriendInfo friend)`：通知新增好友关系，客户端应以 `userID` 为主键将新好友加入本地通讯录列表。

完整监听配置请参考[分页获取好友列表](/sdk/android/user/friends/get-friend-list-page)。
