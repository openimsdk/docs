当前登录用户主动退出指定群组：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupID` | `NSString *` | 目标群组 ID。普通成员与管理员可直接退出；群主退出前需先调用[转让群主](/sdk/ios/group/managing-group-members/transfer-group-owner)。 |

```objc
[[OIMManager manager] quitGroup:groupID
    onSuccess:^(NSString * _Nullable data) {
        [self closeGroupPage];
    }
    onFailure:^(NSInteger code, NSString *message) {
        [self showErrorCode:code message:message];
    }];
```

状态以 `groupID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 表示服务端已处理退群请求。群移除事件随后将通过群组监听下发至各端并按 `groupID` 从本地群列表中清理，完整事件处理见[群组概览](/sdk/ios/group/overview-group)。
