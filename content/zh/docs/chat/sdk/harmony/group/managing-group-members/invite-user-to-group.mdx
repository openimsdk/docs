---
title: '邀请用户加入群组'
description: '邀请一个或多个用户加入指定群组。'
sourcePath: '/sdk/harmony/group/managing-group-members/invite-user-to-group'
---

客户端可以根据当前成员角色控制入口，但最终权限仍由 OpenIMServer 校验。

```ts
import sdk, { InviteUserToGroupReq } from '@openimsdk/imsdk';

const request: InviteUserToGroupReq = {
  groupID: groupID,
  userIDs: ['user_002', 'user_003'],
  reason: '邀请加入项目讨论组',
};
await sdk.inviteUserToGroup(request);
```

调用前应对 `userIDs` 去重。Promise 成功不代表所有用户已经出现在成员列表；根据群组策略，邀请可能需要后续处理。只有成员真正加入并收到成员新增事件后，才将其加入列表。
