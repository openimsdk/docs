```objc
[[OIMManager manager] deleteMessages:conversationID
    clientMsgID:selectedClientMsgIDs
    isSync:YES
    onSuccess:nil
    onFailure:nil];
```

All message IDs must belong to the same conversation. `isSync` controls whether the deletion should synchronize to the current account's other clients; it does not mean that other conversation participants deleted their copies.

This page owns `onMsgDeleted:`. Remove messages idempotently by their routing information and `clientMsgID`; an event may originate from another client. For stable listener registration and removal, see [Receive messages](/sdk/ios/message/receiving-messages/receive-messages).
