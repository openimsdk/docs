The `GroupLookMemberInfo` enum governs whether group members can inspect other members' profiles through the group roster. Do not treat this enum as a raw boolean value:

## Code example

```ts
import sdk, { GroupLookMemberInfo, SetGroupInfoReq } from '@openimsdk/imsdk';

const request: SetGroupInfoReq = {
  groupID: groupID,
  lookMemberInfo: GroupLookMemberInfo.AllowGroupLookMemberInfo,
};
await sdk.setGroupInfo(request);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group identifier. |
| `lookMemberInfo` | `GroupLookMemberInfo` | Yes | Member profile access policy enum value. |

| Option | Value | Description |
| --- | --- | --- |
| `GroupLookMemberInfo.AllowGroupLookMemberInfo` | `0` | Members may view other members' profiles. |
| `GroupLookMemberInfo.ProhibitGroupLookMemberInfo` | `1` | Members are prohibited from viewing other members' profiles. |

## Return value

Returns a Promise that resolves to `void` when the setting is saved.

## State changes after the call

Member profile visibility operates independently of friend request permissions. Resolving the Promise confirms the change on the server. The SDK emits `EventOnGroupInfoChanged`; match the group by `groupID` and update `lookMemberInfo` in the client UI model, as detailed in [Group overview](/sdk/harmony/group/overview-group).
