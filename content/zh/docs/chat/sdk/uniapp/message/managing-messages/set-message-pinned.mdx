`setConversationPinnedMsg()` 与 `onChangedPinnedMsg` 属于<span className="enterprise-field-badge">商业版</span>。

```uts
import {
  off,
  onChangedPinnedMsg,
  setConversationPinnedMsg,
} from '@/uni_modules/unix-openim-sdk'

const pinnedSubscription = onChangedPinnedMsg((payload) => {
  refreshPinnedMessagesAfterValidJson(payload)
})
await setConversationPinnedMsg(pinParams)
off(pinnedSubscription)
```

参数使用 `OpenIMSetConversationPinnedMsgParams`。事件是 raw 字符串，校验后重新查询置顶列表；不要把未验证 payload 强转为消息对象。
