description: '使用 getGroupsInfo 批量查询指定群组的最新资料。'
sourcePath: '/sdk/android/group/retrieving-groups/get-specified-groups-info'
---

`getGroupsInfo()` 的 `groupIDs` 参数为要查询的群组 ID 列表，返回结果为 `GroupInfo` 列表。

```java
OpenIMClient.getInstance().groupManager.getGroupsInfo(new OnBase<List<GroupInfo>>() {
    @Override public void onSuccess(List<GroupInfo> groups) { showGroups(groups); }
    @Override public void onError(int code, String error) { showGroupQueryError(error); }
}, groupIDs);
```
