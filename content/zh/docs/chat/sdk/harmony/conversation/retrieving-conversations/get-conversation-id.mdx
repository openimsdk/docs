只需要会话标识而不需要完整对象时使用本方法。

```ts
import sdk, {
  GetConversationIDBySessionTypeReq,
  GetConversationIDBySessionTypeResp,
  SessionType,
} from '@openimsdk/imsdk';

const request: GetConversationIDBySessionTypeReq = {
  sourceID: targetUserID,
  sessionType: SessionType.Single,
};
const response: GetConversationIDBySessionTypeResp =
  await sdk.getConversationIDBySessionType(request);
useConversationID(response.conversationID);
```

群聊时将 `sourceID` 改为群组 ID，并使用 `SessionType.WriteGroup`。`conversationID` 由 SDK 内部统一计算生成，请勿在客户端自行拼接字符串；如需获取包含未读数和最新消息的完整会话对象，请参考[查询指定会话](/sdk/harmony/conversation/retrieving-conversations/get-conversation-by-target)。
