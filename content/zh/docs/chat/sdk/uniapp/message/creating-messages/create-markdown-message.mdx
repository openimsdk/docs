---
title: '创建 Markdown 消息'
description: '创建一条包含 Markdown 文本的待发送消息。'
sourcePath: '/sdk/uniapp/message/creating-messages/create-markdown-message'
---

`createMarkdownMessage()` 接收包含 `content` 的对象。`content` 是完整 Markdown 源文本，不是已经渲染的 HTML。

```uts
import { createMarkdownMessage } from '@/uni_modules/unix-openim-sdk'

const message = await createMarkdownMessage({
  content: '**发布完成**\n\n请查看最新版本说明。',
})
if (message == null) return
```

接收端应使用受控的 Markdown 渲染器，并对链接、图片和可能产生 HTML 的语法做安全限制。无法识别 Markdown 的客户端应至少能够展示纯文本内容。

Promise 成功只返回待发送的 `OpenIMMessageItem | null`，不会渲染或发送消息。
