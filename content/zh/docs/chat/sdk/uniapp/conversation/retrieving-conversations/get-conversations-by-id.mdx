---

在已知一组 `conversationID` 时，可批量查询对应会话的当前数据。该操作直接接收会话 ID 字符串数组。

```uts
import { getMultipleConversation } from '@/uni_modules/unix-openim-sdk'

const result = await getMultipleConversation(conversationIDs)
const conversations = result?.conversations ?? []

conversations.forEach((conversation) => {
  conversationByID.set(conversation.conversationID, conversation)
})
```

Promise 成功后返回 `OpenIMConversationListResult | null`，会话数组位于 `conversations`。客户端应按各会话的 `conversationID` 建立和合并本地状态；某个 ID 没有对应结果时按缺失记录处理，不要依赖响应数组与请求数组的位置顺序一一对应。字段含义见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。该查询只返回调用时数据，不会触发会话事件。
