调用清理全部本地消息接口将仅清空当前登录账号在当前设备本地存储中的所有历史消息，不影响服务端的漫游记录。

```objc
[[OIMManager manager] deleteAllMsgFromLocalWithOnSuccess:^(NSString * _Nullable data) {
    // 本地清理成功，重置消息视图
    [self resetAllMessageSnapshots];
} onFailure:^(NSInteger code, NSString * _Nullable msg) {
    // 处理清理失败
}];
```

## 返回结果

- `onSuccess`：清理成功回调。表示当前设备上的全部本地消息已被清除。服务端仍保留漫游记录，若后续重新从服务端拉取历史消息，相关消息仍可恢复。
- `onFailure`：清理失败回调，返回错误码 `code` 和错误信息 `msg`。
- 该操作属于纯本地操作，不会向其他端派发消息删除事件。若需彻底删除服务端与本地的所有历史记录，见[清理全部消息](/sdk/ios/message/managing-messages/clear-all-messages)。
