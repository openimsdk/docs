Disassociate one or more conversations from one or more conversation groups. This operation removes group membership only; it does not delete conversations or messages:

```ts
await OpenIMSDK.removeConversationsFromGroups({
  conversationIDs: [conversationID],
  conversationGroupIDs: [conversationGroupID],
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationIDs` | `string[]` | Yes | List of conversation IDs to remove. |
| `conversationGroupIDs` | `string[]` | Yes | List of target conversation group IDs. |

## Return value

A resolved Promise confirms that the conversations were detached from the designated groups.

Removal triggers the `OnConversationGroupMemberDeleted` event. Reconcile local state by locating the group using `conversationGroupID` and removing the member conversation matching `conversationID`. For event registration, see [Conversation groups overview](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups).
