主动查询指定会话中当前处于置顶状态的消息列表。常用于刚进入聊天页面时快速回显顶部常驻消息栏。

```java
String conversationID = "g_group_123";

OpenIMClient.getInstance().messageManager.getConversationPinnedMsgs(
    new OnBase<List<Message>>() {
        @Override
        public void onSuccess(List<Message> messages) {
            // messages 包含当前会话所有的置顶消息
        }

        @Override
        public void onError(int code, String error) {
            // 处理查询失败
        }
    },
    conversationID
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<List<Message>>` | 是 | 异步请求回调。 |
| `conversationID` | `String` | 是 | 待查询的目标会话 ID。 |

## 返回结果

成功回调返回当前会话的置顶消息列表 `List<Message>`。

客户端应以 `clientMsgID` 为标识渲染置顶栏条目。置顶与取消置顶操作请参阅[置顶或取消置顶消息](/sdk/android/message/managing-messages/set-message-pinned)。
