从本地缓存中直接读取当前登录账号的完整资料快照，包含昵称、头像、扩展字段以及账号全局设置。该方法直接读取本地存储，不发起网络请求。

```java
OpenIMClient.getInstance().userInfoManager.getSelfLocalUserInfo(
    new OnBase<LocalUser>() {
        @Override
        public void onSuccess(LocalUser user) {
            // 使用 user 更新当前用户资料
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    }
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<LocalUser>` | 是 | 异步请求回调。 |

## 返回结果

成功回调返回当前登录账号的 `LocalUser` 对象：

| 字段 | 说明 |
| --- | --- |
| `userID` | 当前登录用户的全局唯一 ID。 |
| `nickname` | 当前账号的昵称。 |
| `faceURL` | 当前账号的头像 URL 地址。 |
| `ex` | 自定义业务扩展字段。 |
| `attachedInfo` <span className="enterprise-field-badge">商业版</span> | 附加信息，格式由业务自行约定。 |
| `globalRecvMsgOpt` | 全局消息免打扰模式：`0` 正常接收，`1` 完全不接收，`2` 接收但不提醒。 |
| `addFriendPermission` <span className="enterprise-field-badge">商业版</span> | 好友添加权限设置，具体取值含义请参考[设置好友添加权限](/sdk/android/user/user-profile/set-friend-add-permission)。 |

若当前用户在其他设备或通过服务端更新了资料，SDK 会通过 `OnUserListener.onSelfInfoUpdated` 事件推送最新数据，客户端应以 `userID` 为主键更新本地缓存。资料修改与完整监听配置请参考[更新当前用户资料](/sdk/android/user/user-profile/set-self-info)。
