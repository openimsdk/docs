有权限的群主或管理员可以调用 `kickGroupMember()`。不能使用该方法移除群主；如需更换群主，应先转让群主身份。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 目标群组 ID。 |
| `reason` | `string` | 是 | 移除说明；没有说明时传空字符串。 |
| `userIDList` | `string[]` | 是 | 待移除的成员用户 ID；调用前应去重。 |

```uts
import { kickGroupMember } from '@/uni_modules/unix-openim-sdk'

await kickGroupMember({
  groupID: groupID,
  reason: '已离开项目',
  userIDList: [targetUserID],
})
```

Promise 成功表示 SDK 已完成移除请求。收到 `onGroupMemberDeleted()` 后，再按 `groupID:userID` 移除对应成员；完整监听见[分页查询群成员](/sdk/uniapp/group/retrieving-group-members/get-group-member-list)。
