description: '使用 Flutter SDK 控制群成员能否通过群组发送好友申请。'
sourcePath: '/sdk/flutter/group/set-group-member-friend-permission'
---

```dart
await OpenIM.iMManager.groupManager.setGroupInfo(
  GroupInfo(
    groupID: groupID,
    applyMemberFriend: AllowType.notAllow,
  ),
);
```

`AllowType.allow` 的值为 `0`，表示允许；`AllowType.notAllow` 的值为 `1`，表示不允许。该字段不负责隐藏群成员资料。

Future 成功表示请求完成；最终状态通过 `onGroupInfoChanged` 或重新查询校准。
