已知 `roomID` 但需要重新获取或刷新入会凭据时，可按房间 ID 重新获取入会凭据：

```java
OpenIMClient.getInstance().signalingManager.signalingGetTokenByRoomID(
    new OnBase<SignalingCertificate>() {
        @Override
        public void onSuccess(SignalingCertificate credentials) {
            // credentials 提供 roomID、token 和 liveURL，用于接入媒体房间。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    roomID
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<SignalingCertificate>` | 是 | 异步请求回调。 |
| `roomID` | `String` | 是 | 目标通话房间 ID。 |

## 返回结果

成功回调返回 `SignalingCertificate` 凭据对象，包含：
- `roomID`：通话房间全局标识。
- `token`：进入实时音视频房间的鉴权 Token。
- `liveURL`：媒体引擎连接地址。
- `busyLineUserIDList`：忙线用户列表。

取得有效凭据后即可连接媒体引擎进入房间。若因网络重连或长时间等待导致 Token 失效，可重新调用此接口刷新凭据。
