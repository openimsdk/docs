从本地视频文件及其第一帧封面图路径构建待发送的视频消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `videoPath` | `String` | 是 | 设备本地可访问的视频文件路径。 |
| `videoType` | `String` | 是 | 视频文件的 MIME 类型（例如 `video/mp4`）。 |
| `duration` | `int` | 是 | 视频播放时长（秒）。 |
| `snapshotPath` | `String` | 是 | 视频第一帧封面截图的本地文件路径。 |

```dart
final message = await OpenIM.iMManager.messageManager.createVideoMessage(
  videoPath: videoPath,
  videoType: 'video/mp4',
  duration: durationSeconds,
  snapshotPath: snapshotPath,
);
```

传入的视频文件与封面图路径必须在当前平台具备有效读取权限，时长单位为秒。

## 返回结果

Future 成功返回待发送的视频消息对象（`Message`），其详细属性保存在 `videoElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送或文件上传，也不会触发新消息事件通知。构建完成后，需将返回的 `Message` 实例传给[发送消息](/sdk/flutter/message/sending-messages/send-message)，由 SDK 执行媒体上传与消息投递。若使用全绝对路径创建，请参考[使用本地路径创建视频消息](/sdk/flutter/message/creating-messages/create-video-message-from-full-path)；若视频及封面已上传至对象存储，请参考[使用 URL 创建视频消息](/sdk/flutter/message/creating-messages/create-video-message-by-url)。
