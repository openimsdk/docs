群主或管理员一键清除指定成员在当前群聊中的所有历史发言。常用于违规广告账号封禁及群内不当言论集中清理等管理场景。

```java
String conversationID = "g_group_123";
String targetUserID = "user_spammer";

OpenIMClient.getInstance().messageManager.deleteUserAllMessagesInConv(
    conversationID,
    targetUserID,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 清理请求已成功提交
        }

        @Override
        public void onError(int code, String error) {
            // 处理失败（如权限不足）
        }
    }
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 目标群聊会话 ID。仅支持群聊会话。 |
| `targetUserID` | `String` | 是 | 待清理消息的目标成员用户 ID。 |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |

## 返回结果

成功回调中的 `data` 返回确认信息。

## 监听清理事件

清理操作成功后，群内所有在线成员端将通过 `OnAdvanceMsgListener.onDeleteUserAllMsgsInConv` 收到批量删除事件通知：

```java
@Override
public void onDeleteUserAllMsgsInConv(DeleteUserAllMsgsListenerMsg event) {
    // 根据 event.getConversationID() 与 event.getUserID()
    // 从当前会话列表中批量移除该用户发送的所有历史消息
}
```

客户端在收到该事件后，应结合会话 ID 与用户 ID 进行过滤，批量清理 UI 列表中的对应气泡；完整监听注册见[接收消息](/sdk/android/message/receiving-messages/receive-messages)。
