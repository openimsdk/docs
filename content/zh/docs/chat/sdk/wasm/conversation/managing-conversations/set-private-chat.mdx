---
title: '开启或关闭阅后即焚'
description: '设置指定会话是否启用阅后即焚模式。'
sourcePath: '/sdk/wasm/conversation/managing-conversations/set-private-chat'
---

通过设置 `isPrivateChat` 为 `true` 或 `false`，可以开启或关闭当前会话的阅后即焚模式：

```ts
await openimsdk.setConversation({
  conversationID,
  isPrivateChat: true,
});
```

传入 `false` 即可关闭该模式。消息在阅读后的销毁倒计时时长可通过 `burnDuration` 属性单独配置，具体请参考[设置阅后即焚时长](/sdk/wasm/conversation/managing-conversations/set-burn-duration)。

接口调用成功后，SDK 会触发 `SdkEvent.OnConversationChanged` 事件。业务层可根据 `conversationID` 更新对应会话的 `isPrivateChat` 状态。完整的事件监听配置请参考[获取会话列表](/sdk/wasm/conversation/retrieving-conversations/retrieve-conversation-list)。
