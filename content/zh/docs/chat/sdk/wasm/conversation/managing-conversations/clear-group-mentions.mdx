---
title: '重置群聊 @ 状态'
description: '在用户处理群聊中的 @ 消息后重置会话的群聊 @ 状态。'
sourcePath: '/sdk/wasm/conversation/managing-conversations/clear-group-mentions'
---

在用户查看或处理群聊中的 @ 提醒后，可将当前会话的 `groupAtType` 重置为普通状态，以清除会话列表中的 @ 强提醒角标：

```ts
import { GroupMentionType } from '@openim/wasm-client-sdk';

await openimsdk.setConversation({
  conversationID,
  groupAtType: GroupMentionType.Normal,
});
```

`groupAtType` 是 SDK 根据新收到的群聊消息自动维护的提醒状态（如有人 @我、@所有人等）。该接口主要用于用户查阅后将其重置回 `Normal`（普通）状态。重置群聊 @ 状态与标记消息已读属于独立操作，两者互不影响。

调用成功后，SDK 会触发 `SdkEvent.OnConversationChanged` 事件通知会话状态变更。前端可根据 `conversationID` 找到目标会话并更新提醒状态。完整的会话事件监听示例请参考[获取会话列表](/sdk/wasm/conversation/retrieving-conversations/retrieve-conversation-list)。
