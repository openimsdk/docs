统计指定时间之后待审核的入群申请数量，常用于更新界面红点或角标：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `time` | `NSInteger` | 统计起始时间戳。传入 `0` 表示统计所有待处理的入群申请。 |

```objc
GetGroupApplicationUnhandledCountReq *req =
    [[GetGroupApplicationUnhandledCountReq alloc] initWithTime:0];

[[OIMManager manager] getGroupApplicationUnhandledCount:req
                                              onSuccess:^(NSInteger count) {
                                                  [self updateApplicationBadge:count];
                                              }
                                              onFailure:^(NSInteger code, NSString *message) {
                                                  NSLog(@"getGroupApplicationUnhandledCount failed: %ld %@", (long)code, message);
                                              }];
```

## 返回结果

成功回调 `onSuccess` 返回未处理的入群申请总数量 `NSInteger`。

该查询接口不修改任何申请记录的状态，亦不触发群事件回调。若需查看具体的申请列表或处理申请，请参考[获取收到的入群申请](/sdk/ios/group/group-applications/get-group-application-list-as-recipient)与[入群申请概览](/sdk/ios/group/group-applications/overview-group-applications)。
