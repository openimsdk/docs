---
title: '获取已加入群组'
description: '查询当前用户已加入的全部群组。'
sourcePath: '/sdk/uniapp/group/retrieving-groups/get-joined-group-list'
---

当前用户加入的群组数量较少时，可以使用无参数的 `getJoinedGroupList()` 一次读取完整列表。

```uts
import { getJoinedGroupList } from '@/uni_modules/unix-openim-sdk'

const result = await getJoinedGroupList()
const groups = result != null ? result.groups : []
```

Promise 成功后返回 `OpenIMGroupListResult | null`；非空结果的 `groups` 是当前用户已加入的 `OpenIMGroupItem[]`，不是应用内的公开群目录。群资料主要字段见[群组概览](/sdk/uniapp/group/overview-group)。

群组数量较多时应使用[分页获取已加入群组](/sdk/uniapp/group/retrieving-groups/get-joined-group-list-page)，避免一次加载全部记录。查询不会触发事件，后续加入、退出和资料变化仍需通过群组事件更新。
