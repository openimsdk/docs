`burnDuration` <span className="enterprise-field-badge">商业版</span> 表示阅后即焚时长，通过 `setConversation()` 更新。

```uts
import { setConversation } from '@/uni_modules/unix-openim-sdk'

await setConversation({ conversationID, burnDuration: 30 })
```

时长单位和允许范围以商业版服务端协议为准。不要在客户端自行倒计时后直接删除服务端消息；界面应结合消息状态和服务端事件呈现。

关闭能力时使用产品约定的关闭值，并重新查询会话确认。
