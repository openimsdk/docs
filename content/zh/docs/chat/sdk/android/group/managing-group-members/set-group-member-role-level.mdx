---
title: '设置管理员'
description: '使用 SetGroupMemberInfo.roleLevel 设置成员的群内角色。'
sourcePath: '/sdk/android/group/managing-group-members/set-group-member-role-level'
---

`roleLevel` 使用 `GroupRole` 常量：`OWNER`、`ADMIN` 和 `MEMBER`。转让群主请使用[转让群主](/sdk/android/group/managing-group-members/transfer-group-owner)。

```java
SetGroupMemberInfo update = new SetGroupMemberInfo();
update.setGroupID(groupID);
update.setUserID(userID);
update.setRoleLevel(GroupRole.ADMIN);

OpenIMClient.getInstance().groupManager.setGroupMemberInfo(update, new OnBase<String>() {
    @Override public void onSuccess(String data) { /* 请求已完成。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
});
```

角色修改成功后，通过 `onGroupMemberInfoChanged` 接收成员资料变化通知。
