根据用户 ID 列表批量查询指定用户在目标群组中的群成员资料：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `userIDList` | `List<String>` | 是 | 需要查询的用户 ID 列表。 |

```dart
final members = await OpenIM.iMManager.groupManager.getGroupMembersInfo(
  groupID: groupID,
  userIDList: userIDList,
);
```

## 返回结果

Future 成功返回匹配到的群成员资料列表（`List<GroupMembersInfo>`）。

若某些用户未出现在返回列表中，仅表示其当前不是目标群的有效成员，不能据此推断该用户账号不存在。

查询操作建立静态快照，不改变群成员状态，也不会触发事件通知。本地缓存与后续增量事件合并应使用复合标识 `groupID:userID`，详细规则请参考[群成员查询概览](/sdk/flutter/group/retrieving-group-members/overview-retrieving-group-members)。
