Set only the fields that must change on `UserInfoReq`.

```java
UserInfoReq request = new UserInfoReq();
request.setNickname(displayName.trim());
request.setFaceURL(avatarURL);
request.setEx(extra);

OpenIMClient.getInstance().userInfoManager.setSelfInfo(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // Profile update succeeded.
        }

        @Override
        public void onError(int code, String error) {
            // Handle the error.
        }
    },
    request
);
```

This operation updates only the nickname, avatar, and user extension data. Add-friend permission is a separate account setting; see [Set friend request permissions](/sdk/android/user/user-profile/set-friend-add-permission).

A successful callback means the update request completed. `onSelfInfoUpdated(UserInfo info)` reports changes to the current user's profile.

## Updatable fields

| Field                 | Description                  |
| --------------------- | ---------------------------- |
| `nickname`            | New nickname.                |
| `faceURL`             | New avatar URL.              |
| `ex`                  | User extension string.        |

Send only fields that should change. Account-level message reception is also a separate operation; see [Set global message reception](/sdk/android/user/user-profile/set-global-message-reception).

Receive `onSelfInfoUpdated` through `OnUserListener` when the current user's profile changes:

```java
@Override
public void onSelfInfoUpdated(UserInfo info) {
    // Handle the current user's profile change.
}
```
