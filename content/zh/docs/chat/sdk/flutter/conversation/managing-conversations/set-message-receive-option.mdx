设置指定会话的消息接收与免打扰选项：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 目标会话 ID。 |
| `req` | `ConversationReq` | 是 | 会话修改请求对象，`recvMsgOpt` 指定新的接收选项。 |

```dart
await OpenIM.iMManager.conversationManager.setConversation(
  conversationID,
  ConversationReq(recvMsgOpt: ReceiveMessageOpt.notNotify),
);
```

`ReceiveMessageOpt` 枚举取值说明：

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `ReceiveMessageOpt.receive` | `0` | 正常接收消息，并允许通知提醒。 |
| `ReceiveMessageOpt.notReceive` | `1` | 不接收该会话消息，也不通知。 |
| `ReceiveMessageOpt.notNotify` | `2` | 正常接收该会话消息，但不进行通知提醒（免打扰模式）。 |

## 返回结果

Future 成功表示免打扰选项已保存。若需要设置账号维度的全局消息免打扰，请参考[设置全局消息接收方式](/sdk/flutter/user/retrieving-and-updating-user-information/set-global-message-reception)。

多端同步或事件到达时通过会话变更事件通知。客户端以 `conversationID` 为合并标识更新对应会话的 `recvMsgOpt` 属性，完整事件监听请参考[获取会话列表](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list)。
