Use `speechToText()` to transcribe a local audio file that the SDK can read. Pass a local path, not a remote URL, Base64 data, or an uploaded file name.

```ts
const { text } = await OpenIMSDK.speechToText(filename);
```

`filename` is the local audio-file path. The call returns `{ text }`, where `text` is the transcription. See [Check speech recognition support](/sdk/react-native/message/composing-messages/check-speech-to-text) when capability information is needed; to save the result in a local voice message, see [Save a local transcript](/sdk/react-native/message/composing-messages/save-local-transcript).
