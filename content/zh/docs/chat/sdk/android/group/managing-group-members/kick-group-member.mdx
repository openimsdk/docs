---
title: '移除群成员'
description: '使用 kickGroupMember 将指定成员移出群组。'
sourcePath: '/sdk/android/group/managing-group-members/kick-group-member'
---

`kickGroupMember()` 接收成员 ID 列表和移除说明。产品层应先防止当前用户误移除自身，并遵守群主、管理员权限边界。

```java
OpenIMClient.getInstance().groupManager.kickGroupMember(new OnBase<String>() {
    @Override public void onSuccess(String data) { markRemovalSubmitted(groupID); }
    @Override public void onError(int code, String error) { showRemovalError(error); }
}, groupID, memberUserIDs, "已不再参与该项目");
```

收到 `onGroupMemberDeleted` 后再从成员缓存中移除目标成员。
