独立上传本地文件至存储服务器，用于用户头像、群头像或业务附件管理：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `id` | `String` | 是 | 关联上传任务与监听回调的稳定业务唯一标识。 |
| `filePath` | `String` | 是 | 当前客户端可读取的本地文件绝对路径。 |
| `fileName` | `String` | 是 | 原始文件名（包含扩展名）。 |
| `contentType` | `String?` | 否 | 文件的 MIME 类型（如 `image/png`）。 |
| `cause` | `String?` | 否 | 业务侧定义的上传原因说明（如 `user-avatar`）。 |

```dart
await OpenIM.iMManager.uploadFile(
  id: 'upload_task_001',
  filePath: filePath,
  fileName: fileName,
  contentType: contentType,
  cause: 'user-avatar',
);
```

## 返回结果

Future 成功返回 `void`，表示文件上传任务已成功提交并启动。

上传进度和最终的文件 URL 通过全局监听器回调分发。在完成回调中获取到的远程文件访问地址，可进一步用于更新个人资料头像或业务资源。该方法本身不会自动修改任何用户资料，也不会创建或发送聊天消息。

关于上传监听器的全局注册与回调参数处理，请参考[监听文件上传进度](/sdk/flutter/file-uploads/set-upload-file-listener)。
