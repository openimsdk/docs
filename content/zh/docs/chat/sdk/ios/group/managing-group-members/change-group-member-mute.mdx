title: '设置群成员禁言'
description: '设置或解除 iOS 群成员禁言。'

---

群主或管理员可以对指定群成员设置指定时长的禁言，或解除其禁言状态：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupID` | `NSString *` | 目标群组 ID。 |
| `userID` | `NSString *` | 目标群成员的用户 ID。 |
| `mutedSeconds` | `NSInteger` | 禁言时长（单位：秒）。设置为 `0` 表示解除禁言。 |

```objc
[[OIMManager manager] changeGroupMemberMute:@"group_1001"
                                     userID:@"user_003"
                               mutedSeconds:3600
                                  onSuccess:^(NSString * _Nullable data) {
                                      NSLog(@"changeGroupMemberMute success");
                                  }
                                  onFailure:^(NSInteger code, NSString *message) {
                                      NSLog(@"changeGroupMemberMute failed: %ld %@", (long)code, message);
                                  }];
```

状态以 `groupID:userID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回操作结果。

服务端完成禁言设置后，群内会通过 `onGroupMemberInfoChanged:` 事件分发成员资料变更（监听注册参见[群组概览](/sdk/ios/group/overview-group)），对应成员模型的 `muteEndTime` 字段将更新为解除禁言的时间戳。客户端应以 `groupID:userID` 为合并标识更新该成员状态。若需对全群成员禁言，请参考[设置群组全员禁言](/sdk/ios/group/change-group-mute)；群成员查询与完整接口参见[群成员查询概览](/sdk/ios/group/retrieving-group-members/overview-retrieving-group-members)。
