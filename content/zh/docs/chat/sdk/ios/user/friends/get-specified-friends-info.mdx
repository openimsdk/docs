已知好友 `userID` 时，按需批量查询对应的好友详细关系资料：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `userIDs` | `NSArray<NSString *> *` | 待查询的用户 ID 列表。 |
| `filterBlack` | `BOOL` | 是否自动过滤已被拉入黑名单的用户。 |

```objc
[[OIMManager manager] getSpecifiedFriendsInfo:@[@"user_a", @"user_b"]
                                  filterBlack:YES
                                    onSuccess:^(NSArray<OIMFriendInfo *> *friends) {
                                        [friendStore mergeFriends:friends];
                                    }
                                    onFailure:^(NSInteger code, NSString *message) {
                                        NSLog(@"getSpecifiedFriendsInfo failed: %ld %@", (long)code, message);
                                    }];
```

状态以 `userID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回匹配的好友资料数组 `NSArray<OIMFriendInfo *> *`。返回空数组表示所传入的目标用户不是好友或已被黑名单过滤。

该查询仅返回当前时刻的数据快照，不触发好友事件。若只需快速核验好友关系是否存在，建议使用[检查好友关系](/sdk/ios/user/friends/check-friend)。
