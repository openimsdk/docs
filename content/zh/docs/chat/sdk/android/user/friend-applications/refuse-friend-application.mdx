---
title: '拒绝好友申请'
description: '使用 refuseFriendApplication() 拒绝好友申请。'
sourcePath: '/sdk/android/user/friend-applications/refuse-friend-application'
---

```java
OpenIMClient.getInstance().friendshipManager.refuseFriendApplication(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markApplicationRejected(applicantUserID);
        }

        @Override
        public void onError(int code, String error) {
            recordApplicationRejectFailure(code, error);
        }
    },
    applicantUserID,
    "暂不添加"
);
```

`applicantUserID` 是申请方用户 ID，最后一个参数是处理附言。成功 callback 表示拒绝请求完成；申请状态通过统一好友申请 listener 合并，并最终以 `handleResult == 2` 表示已拒绝。
