Delete recording records for selected meeting or real-time room IDs.

## HTTP request
```bash
POST {API_ADDRESS}/rtc-meeting/delete_meeting_records
```

## Request body
| Parameter | Required | Type | Description |
| --- | --- | --- | --- |
| roomIDs | Yes | string[] | Meeting or real-time room IDs. |

## Response
`errCode: 0` means the requested recording records were deleted.

## Permissions and limits
- Available only in OpenIM Enterprise.
- This is destructive. Validate recording ownership and retention policy before calling it.
