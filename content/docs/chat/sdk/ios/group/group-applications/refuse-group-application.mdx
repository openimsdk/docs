Invoke `refuseGroupApplication:fromUserId:handleMsg:onSuccess:onFailure:` to reject a specified group application (restricted to group owners and administrators):

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `NSString *` | Yes | Target group ID. |
| `fromUserId` | `NSString *` | Yes | User ID of the applicant. |
| `handleMsg` | `NSString *` | No | Rejection explanation or remark. |

## Code example

```objc
[[OIMManager manager] refuseGroupApplication:@"group_1001"
                                  fromUserId:@"user_003"
                                   handleMsg:@"Application requirements not met"
                                   onSuccess:^(NSString * _Nullable data) {
                                       NSLog(@"refuseGroupApplication success");
                                   }
                                   onFailure:^(NSInteger code, NSString *message) {
                                       NSLog(@"refuseGroupApplication failed: %ld %@", (long)code, message);
                                   }];
```

## Return value

The `onSuccess` callback returns confirmation when the server accepts the rejection.

## State changes after the call

1. **Application status update**: The rejection event broadcasts across connected clients via the `onGroupApplicationRejected:` listener callback. The client matches records by `groupID:userID` and updates the entry status to rejected.
2. **Re-query calibration**: For listener integration and list updates, refer to [Group applications overview](/sdk/ios/group/group-applications/overview-group-applications).
