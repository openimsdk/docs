基于相对于 SDK 初始化数据目录的相对文件路径创建视频消息对象。需同时提供视频文件及其封面缩略图路径，在调用[发送消息](/sdk/android/message/sending-messages/send-message)时，SDK 会自动上传视频和封面图片。

```java
String videoPath = "videos/sample.mp4";
String mimeType = "video/mp4";
long durationSeconds = 15L;
String snapshotPath = "snapshots/sample_thumb.jpg";

Message message = OpenIMClient.getInstance().messageManager.createVideoMessage(
    videoPath,
    mimeType,
    durationSeconds,
    snapshotPath
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `videoPath` | `String` | 是 | 视频文件相对于 SDK 初始化数据目录的相对路径。 |
| `mimeType` | `String` | 是 | 视频 MIME 类型（例如 `video/mp4` 或文件扩展名 `mp4`）。 |
| `duration` | `long` | 是 | 视频播放时长（单位：秒）。 |
| `snapshotPath` | `String` | 是 | 视频封面缩略图相对于 SDK 初始化数据目录的相对路径。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.VIDEO`。

本接口仅在本地创建待发送对象，不会自动发起网络上传。构建完成后，请调用[发送消息](/sdk/android/message/sending-messages/send-message)投递至单聊或群聊。若使用本地绝对路径创建，请参阅[使用本地路径创建视频消息](/sdk/android/message/creating-messages/create-video-message-by-file)。
