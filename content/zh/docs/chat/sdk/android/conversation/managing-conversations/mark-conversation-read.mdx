---
title: '标记会话已读'
description: '使用 messageManager.markConversationMessageAsRead() 将指定会话的消息标记为已读。'

---

用户打开会话并阅读完当前可见消息后，调用 `messageManager.markConversationMessageAsRead()` 标记会话已读。不要在仅预览通知或后台收到消息时提前标记。

```java
OpenIMClient.getInstance().messageManager.markConversationMessageAsRead(
    conversationID,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markConversationReadSubmitted(conversationID);
        }

        @Override
        public void onError(int code, String error) {
            recordMarkReadFailure(code, error);
        }
    }
);
```

成功回调表示标记请求已完成。需要更新会话列表时，可重新查询会话或通过 `onConversationChanged` 接收变化。

对于单聊，可以通过 `OnAdvanceMsgListener.onRecvC2CReadReceipt` 监听对端发来的已读回执。消息监听器的设置方式见[接收消息](/sdk/android/message/receiving-messages/receive-messages)，消息回调和已读回执字段见[消息概览](/sdk/android/message/overview-message)。
