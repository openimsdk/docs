---
title: '更新好友资料'
description: '更新一个好友的备注、置顶状态或关系扩展字段。'

---

更新好友资料时每次操作一个好友。只传入本次需要修改的字段；`ex` 是完整的扩展字符串，底层不会自动合并已有 JSON 内容。

```ts
import sdk, { UpdateFriendReq } from '@openimsdk/imsdk';

const request: UpdateFriendReq = {
  userID: friendUserID,
  remark: remark.trim(),
  pinned: true,
};
await sdk.updateFriend(request);
```

Promise 成功不表示好友资料变更事件已经到达。客户端按 `friendUserID`（即 `userID`）合并好友资料，完整监听见[分页获取好友列表](/sdk/harmony/user/friends/get-friend-list-page)。
