---
title: '删除入群申请'
description: '批量删除指定的入群申请记录。'
sourcePath: '/sdk/harmony/group/group-applications/delete-group-requests'
---

该操作按“群组 + 申请人”删除申请记录，适合清理已经处理或不再需要展示的记录。

```ts
import sdk, { DeleteGroupRequestsReq } from '@openimsdk/imsdk';

const request: DeleteGroupRequestsReq = {
  groupRequests: [{ groupID: application.groupID, fromUserID: application.userID }],
};
await sdk.deleteGroupRequests(request);
```

删除申请记录不等于拒绝申请。需要给出审核结果时，应先接受或拒绝；删除后再处理可能已找不到对应记录。Promise 成功后，删除事件可能随后到达，列表应按 `groupID:userID` 移除记录。
