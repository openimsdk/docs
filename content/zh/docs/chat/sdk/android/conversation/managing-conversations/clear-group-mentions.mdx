title: '重置群聊 @ 状态'
description: '清除指定群聊会话的群聊 @ 提醒标记。'

当群聊中有成员 @ 当前用户或 @ 全体成员时，会话的 `groupAtType` 会标记对应的提醒状态。在用户进入群聊阅读相关提醒消息后，可重置该会话的 @ 状态，取消会话列表中的红点或高亮提示。

```java
OpenIMClient.getInstance().conversationManager.resetConversationGroupAtType(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    conversationID
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `conversationID` | `String` | 是 | 目标群聊会话的唯一标识。 |

## 返回结果

成功回调表示服务端已记录重置操作，会话的 `groupAtType` 状态将恢复为普通状态。

重置完成后，SDK 会触发 `OnConversationListener.onConversationChanged` 事件；客户端收到通知后应根据 `conversationID` 找到对应会话，移除“[@有人@我]”或“[@全体成员]”的高亮标记并刷新界面，完整监听配置请参考[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
