按用户 ID 批量查询应用内用户的公开基础资料，适合在搜索添加好友、展示候选人或陌生人资料卡等场景下使用。

## 查询公开资料

传入待查询的用户 ID 列表，即可批量获取对应用户的公开资料。调用前建议去除空值和重复 ID，并合理控制单次请求数量。

```java
List<String> userIDs = Arrays.asList("user_a", "user_b");

OpenIMClient.getInstance().userInfoManager.getUsersInfo(
    new OnBase<List<PublicUserInfo>>() {
        @Override
        public void onSuccess(List<PublicUserInfo> users) {
            // 使用 users 显示用户资料
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    userIDs
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<List<PublicUserInfo>>` | 是 | 异步请求回调。 |
| `userIDs` | `List<String>` | 是 | 待查询的目标用户 ID 列表，建议调用前去重并过滤空值。 |

## 返回结果

成功回调返回包含命中用户公开资料的 `List<PublicUserInfo>`：

| 字段 | 说明 |
| --- | --- |
| `userID` | 用户的全局唯一 ID。 |
| `nickname` | 用户的公开昵称。 |
| `faceURL` | 用户的公开头像 URL 地址。 |
| `ex` | 用户的公开自定义扩展字符串。 |
| `createTime` | 用户账号的注册时间。 |

此处返回的公开资料应以 `userID` 为主键进行本地缓存与去重。若需修改当前登录用户自身的资料与扩展信息，请参考[更新当前用户资料](/sdk/android/user/user-profile/set-self-info)。

## 搜索添加好友

当业务已经获得候选用户的 `userID` 时，可以先查询并展示公开资料，用户确认后再通过[发送好友申请](/sdk/android/user/friend-applications/add-friend)向目标用户发起申请。

该接口仅根据 `userID` 精确查询公开资料；昵称、手机号等其他维度的模糊搜索需由业务服务端接口支持。

## 按场景选择展示数据

同一个 `userID` 在不同场景中使用不同的资料类型：

| 场景 | 使用的类型 |
| --- | --- |
| 用户搜索、陌生人资料卡 | `PublicUserInfo` |
| 好友列表、联系人页和好友备注 | `FriendInfo` |
| 群成员列表、群内昵称和群角色 | `GroupMembersInfo` |

好友资料使用[查询指定好友资料](/sdk/android/user/friends/get-friends-info)，群成员资料使用[分页查询群成员](/sdk/android/group/retrieving-group-members/get-group-member-list)。
