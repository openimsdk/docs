```uts
import { getFriendApplicationListAsApplicant } from '@/uni_modules/unix-openim-sdk'

const result = await getFriendApplicationListAsApplicant({ offset: 0, count: 50 })
renderSentApplications(result?.applications ?? [])
```

Parameters are optional. Results can move while pages load, so deduplicate with participant IDs and time fields rather than array indexes. Reload after App restoration, login, or missed events.
