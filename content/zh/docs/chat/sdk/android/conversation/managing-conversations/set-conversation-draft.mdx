---
title: '设置会话草稿'
description: '保存或清空当前会话的本地未发送草稿内容。'

---

用户离开聊天页、切换会话或输入框内容变动时，可以保存未发送的文本草稿。在文本输入过程中建议对频繁输入做防抖处理，在用户退出页面时立即提交一次最新草稿内容。

```java
OpenIMClient.getInstance().conversationManager.setConversationDraft(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    conversationID,
    editorValue
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `conversationID` | `String` | 是 | 目标会话的唯一标识。 |
| `draftText` | `String` | 是 | 草稿文本内容；清空草稿时传入空字符串 `""`。 |

## 返回结果

成功回调表示草稿已成功保存至本地会话数据中。草稿仅在当前设备端保存，不会同步至其他端。

草稿保存或清空后，SDK 会触发 `OnConversationListener.onConversationChanged` 事件；客户端应以 `conversationID` 唯一定位目标会话，并更新 `draftText` 与 `draftTextTime`，完整监听配置请参考[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
