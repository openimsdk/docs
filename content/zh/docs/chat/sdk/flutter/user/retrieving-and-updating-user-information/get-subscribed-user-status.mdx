```dart
final states =
    await OpenIM.iMManager.userManager.getSubscribeUsersStatus();
mergePresence(states);
```

该方法不接收用户数组，也不改变订阅集合。可在重连或重新进入页面时调用，并按 `userID` 合并结果；查询不触发 callback。当前 SDK 不公开记录临时 `getUserStatus()`。
