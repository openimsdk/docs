Report the total unread message count currently displayed by the application to the OpenIM SDK to synchronize badge state with remote push notification services:

```ts
await OpenIMSDK.setAppBadge(totalUnreadCount);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `totalUnreadCount` | `number` | Yes | Total unread message count currently displayed by the application. Must be a non-negative integer. |

## Return value

A resolved Promise confirms that the SDK accepted and updated the badge count.

- This method only synchronizes the total unread count with the SDK and remote push notification services; it does not directly alter the unread status of individual conversations.
- To display a numeric badge on the mobile home screen icon (iOS launcher badge or Android application icon), combine this API with native React Native badge packages (such as `@react-native-community/push-notification-ios` or vendor push SDKs) to update system launcher badges.
- For querying and tracking real-time unread counts, see [Get total unread count](/sdk/react-native/conversation/managing-conversations/get-total-unread-count).
