```objc
OIMMessageInfo *message =
    [OIMMessageInfo createVideoMessageByURL:videoURL
                                  videoType:@"video/mp4"
                                   duration:durationSeconds
                                       size:videoSize
                                   snapshot:snapshotURL];
```

The video URL, media type, duration in seconds, size in bytes, and snapshot URL must come from actual upload results. Send the returned object with `sendMessageNotOss:...`.
