构建包含内置表情或第三方表情包内容的表情消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `index` | `int` | 是 | 表情索引编号（由业务表情包协议定义）。 |
| `data` | `String` | 是 | 表情附加数据，例如表情网络 URL、动态图资源路径或自定义 JSON 标识。 |

```dart
final message = await OpenIM.iMManager.messageManager
    .createFaceMessage(index: 3, data: emojiURL);
```

表情编号与数据格式由客户端业务层约定，建议在接收端为未下载或未知的表情资源提供兜底降级展示。

## 返回结果

Future 成功返回待发送的表情消息对象（`Message`），其内容保存在 `faceElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送，也不会触发新消息事件通知。构建完成后，需将返回的 `Message` 实例传给[发送消息](/sdk/flutter/message/sending-messages/send-message)投递至单聊或群聊会话。
