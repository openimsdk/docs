title: '查询指定好友资料'
description: '使用 getFriendsInfo() 查询指定用户的好友关系资料。'
sourcePath: '/sdk/android/user/friends/get-friends-info'
---

```java
OpenIMClient.getInstance().friendshipManager.getFriendsInfo(
    new OnBase<List<UserInfo>>() {
        @Override
        public void onSuccess(List<UserInfo> friends) {
            for (UserInfo friend : friends) {
                friendStore.put(friend.getUserID(), friend);
            }
        }

        @Override
        public void onError(int code, String error) {
            recordFriendInfoFailure(code, error);
        }
    },
    Arrays.asList("user_a", "user_b"),
    true
);
```

第二个参数是目标用户 ID 列表，`filterBlack` 决定是否过滤黑名单用户。成功 callback 返回 `List<UserInfo>`；通过 `getFriendInfo()` 读取好友备注和关系字段，并按 `userID` 合并。调用前应去除空值和重复 ID。

当目标用户不是好友，或目标用户因 `filterBlack == true` 被过滤时，返回结果中可能没有对应记录。需要同时展示账号公开资料时，应再调用[获取指定用户资料](/sdk/android/user/user-profile/get-users-info)，并按 `userID` 合并两类数据。

该查询不会触发好友 listener。只需要判断好友关系时使用 [`checkFriend()`](/sdk/android/user/friends/check-friend)。
