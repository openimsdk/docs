构建包含表情编号与自定义元数据的表情贴纸消息。适用于应用内置的大表情、动态表情或贴纸包发送。

```java
int index = 101; // 表情索引编号
String dataJson = "{\"packID\":\"pack_classic\",\"url\":\"https://example.com/face/101.gif\"}";

Message message = OpenIMClient.getInstance().messageManager.createFaceMessage(index, dataJson);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `index` | `int` | 是 | 表情编号，由业务端定义的表情库索引。 |
| `data` | `String` | 是 | 表情资源自定义信息（例如动态图 URL、表情包名称等 JSON 字符串）。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.FACE`。

本接口仅在本地生成消息模型，构建完成后调用[发送消息](/sdk/android/message/sending-messages/send-message)发送。
