`transferGroupOwner()` accepts two parameters: `groupID`, the ID of the group whose ownership is being transferred, and `newOwnerUserID`, the ID of the new owner. The target user must already be a member of the group.

```java
OpenIMClient.getInstance().groupManager.transferGroupOwner(new OnBase<String>() {
    @Override public void onSuccess(String data) { markOwnershipTransferSubmitted(groupID); }
    @Override public void onError(int code, String error) { showTransferError(error); }
}, groupID, newOwnerUserID);
```

After the transfer succeeds, you can call [Get group owners and admins](/sdk/android/group/retrieving-group-members/get-group-member-owner-and-admin) again to retrieve the latest profiles.
