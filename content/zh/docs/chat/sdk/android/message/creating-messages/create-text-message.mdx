---
title: '创建文本消息'
description: '使用 createTextMessage 创建文本 Message。'
sourcePath: '/sdk/android/message/creating-messages/create-text-message'
---

`createTextMessage()` 接收非空文本并创建待发送的 `Message`，不会自动发送消息。应用应在调用前完成长度限制和内容策略校验。

```java
Message message = OpenIMClient.getInstance().messageManager.createTextMessage(text);
```

返回的 `Message` 可先加入本地发送队列，再通过[发送消息](/sdk/android/message/sending-messages/send-message)投递；是否发送成功以发送回调为准。
