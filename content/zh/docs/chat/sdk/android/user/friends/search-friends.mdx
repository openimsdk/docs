在当前登录用户的好友数据库中执行本地模糊搜索，支持按用户 ID、昵称和备注名匹配好友。

```java
OpenIMClient.getInstance().friendshipManager.searchFriends(
    new OnBase<List<FriendInfo>>() {
        @Override
        public void onSuccess(List<FriendInfo> results) {
            // 使用 results 显示搜索结果
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    Collections.singletonList(keyword.trim()),
    true,
    true,
    true
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<List<FriendInfo>>` | 是 | 异步请求回调。 |
| `keywordList` | `List<String>` | 是 | 搜索关键词列表，通常传入单个非空搜索词。 |
| `isSearchUserID` | `boolean` | 是 | 是否匹配好友的用户 ID。 |
| `isSearchNickname` | `boolean` | 是 | 是否匹配好友的昵称。 |
| `isSearchRemark` | `boolean` | 是 | 是否匹配设置的好友备注名。 |

注意三个搜索开关至少需要将其中一项设为 `true`。

## 返回结果

成功回调返回匹配到的 `List<FriendInfo>` 列表。客户端应以 `userID` 为主键对搜索结果进行去重与展示；若未命中任何好友，返回空列表。
