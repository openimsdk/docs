---
title: '翻译文本'
description: '将一段文本翻译为指定目标语言。'
sourcePath: '/sdk/harmony/message/translating-messages/translate-text'
---

该商业版能力只翻译传入文本，不创建或修改聊天消息。

```ts
import sdk, { TranslateTextReq, TranslateTextResp } from '@openimsdk/imsdk';

const request: TranslateTextReq = {
  text: 'Hello, OpenIM',
  sourceLanguage: 'en',
  targetLanguage: 'zh-CN',
};
const response: TranslateTextResp = await sdk.translateText(request);
showTranslation(response.translatedText, response.detectedLanguage);
```

语言代码必须使用当前翻译服务支持的格式。`detectedLanguage` 是服务识别到的源语言，可能与请求值不同；翻译结果应作为辅助内容展示，不要用它覆盖原文。
