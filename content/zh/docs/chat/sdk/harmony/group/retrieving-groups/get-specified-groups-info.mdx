该查询适合在已经持有群组 ID 时读取最新资料，不是公开群目录，也不负责按名称发现陌生群组。

```ts
import sdk, { GetSpecifiedGroupsInfoReq, GetSpecifiedGroupsInfoResp } from '@openimsdk/imsdk';

const request: GetSpecifiedGroupsInfoReq = {
  groupIDs: ['group_001', 'group_002'],
};
const response: GetSpecifiedGroupsInfoResp = await sdk.getSpecifiedGroupsInfo(request);
const groups = response.groups;
```

查询单个群组时仍需传入数组。返回数组不保证与输入 ID 按位置一一对应，应使用 `groupID` 建立对应关系。查询只返回调用时的资料，不会触发群组事件；页面保持打开时继续处理群资料变化事件。
