Queries member profiles for specified users within a particular group.

## Code example

```ts
import sdk, {
  GetSpecifiedGroupMembersInfoReq,
  GetSpecifiedGroupMembersInfoResp,
} from '@openimsdk/imsdk';

const request: GetSpecifiedGroupMembersInfoReq = {
  groupID: groupID,
  userIDs: ['user_001', 'user_002'],
};
const response: GetSpecifiedGroupMembersInfoResp = await sdk.getSpecifiedGroupMembersInfo(request);
const members = response.members;
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group identifier. |
| `userIDs` | `string[]` | Yes | Array of user IDs to query. |

## Return value

Returns a Promise resolving to `GetSpecifiedGroupMembersInfoResp`:

| Property | Type | Description |
| --- | --- | --- |
| `members` | `GroupMemberItem[]` | List of member profiles matching the requested user IDs. |

## State changes after the call

The returned array order is not guaranteed to match the input ID sequence. Because nicknames, roles, and mute states differ across groups for the same user, clients should index and cache member data using `groupID:userID`. This query does not trigger events; to listen for member changes, see [Retrieve group member list](/sdk/harmony/group/retrieving-group-members/get-group-member-list).
