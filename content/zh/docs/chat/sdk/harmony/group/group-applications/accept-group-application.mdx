---
title: '接受入群申请'
description: '同意指定用户加入群组。'
sourcePath: '/sdk/harmony/group/group-applications/accept-group-application'
---

群主或管理员通过统一处理接口同意一条待处理申请。

```ts
import sdk, { ApprovalStatus, HandleGroupApplicationReq } from '@openimsdk/imsdk';

const request: HandleGroupApplicationReq = {
  groupID: application.groupID,
  fromUserID: application.userID,
  handledMsg: '同意加入',
  status: ApprovalStatus.Approved,
};
await sdk.handleGroupApplication(request);
```

Promise 成功表示处理请求已经完成。不要据此在本地构造最终成员资料；收到申请接受事件后更新申请记录，成员真正加入时再处理群成员事件。
