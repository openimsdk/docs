`ex` 用于保存应用自定义的会话级数据。它是完整字符串，SDK 不会自动合并 JSON；多个业务模块共用时，应划分稳定命名空间，并在写入前保留其他模块的数据。

```uts
import { setConversation } from '@/uni_modules/unix-openim-sdk'

await setConversation({
  conversationID,
  ex: JSON.stringify({ category: 'work' }),
})
```

示例展示一次完整写入。实际项目如果已经保存其他扩展数据，应先按业务约定解析旧值、合并所需字段，再序列化整个新值。

Promise 成功表示本次设置请求已成功返回，不表示会话事件已经到达。收到 `onConversationChanged()` 后，按 `conversationID` 更新对应会话；需要校准状态时重新查询会话。完整监听见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。
