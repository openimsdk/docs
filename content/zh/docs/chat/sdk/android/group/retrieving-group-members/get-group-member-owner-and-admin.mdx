获取指定群组中的群主与所有管理员成员资料列表。常用于群管理页面呈现、管理权限核验以及群内审批流程控制。

```java
String groupID = "group_123";

OpenIMClient.getInstance().groupManager.getGroupMemberOwnerAndAdmin(
    new OnBase<List<GroupMembersInfo>>() {
        @Override
        public void onSuccess(List<GroupMembersInfo> members) {
            // members 包含群主及所有管理员资料
        }

        @Override
        public void onError(int code, String error) {
            // 处理查询失败
        }
    },
    groupID
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<List<GroupMembersInfo>>` | 是 | 异步请求回调。 |
| `groupID` | `String` | 是 | 目标群组全局唯一 ID。 |

## 返回结果

成功回调返回管理成员列表 `List<GroupMembersInfo>`。

列表中的成员可通过角色级别（`roleLevel`）区分管理角色：`100`（`GroupRole.OWNER`）为群主，`60`（`GroupRole.ADMIN`）为管理员。客户端应以 `groupID:userID` 为标识维护群核心管理人员列表。设置或撤销管理员请参阅[设置管理员](/sdk/android/group/managing-group-members/set-group-member-role-level)。
