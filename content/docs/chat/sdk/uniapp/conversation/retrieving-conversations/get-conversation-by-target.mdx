`getOneConversation()` resolves a conversation from session type and target ID.

```uts
import { getOneConversation } from '@/uni_modules/unix-openim-sdk'

const result = await getOneConversation({ sessionType, sourceID })
const conversation = result?.conversation ?? null
```

Use a user ID for direct chat or group ID for group chat. A nullable result means no current local conversation; it does not create one.
