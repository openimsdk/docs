分页拉取当前登录用户主动向他人发起的好友申请记录列表：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `offset` | `int` | 否 | 分页拉取的偏移量，首屏从 `0` 开始。 |
| `count` | `int` | 否 | 每页拉取的好友申请记录数量。 |

```dart
final items = await OpenIM.iMManager.friendshipManager
    .getFriendApplicationListAsApplicant(
  req: GetFriendApplicationListAsApplicantReq(offset: 0, count: 20),
);
```

## 返回结果

Future 成功返回当前页的好友申请记录列表（`List<FriendApplicationInfo>`）。

查询操作建立静态数据快照，不会触发事件通知。申请记录可基于 `fromUserID:toUserID` 唯一去重与合并。发起新好友申请请参考[发送好友申请](/sdk/flutter/user/friend-applications/add-friend)。
