调用 `deleteConversationGroup()` 删除会话分组及其会话关联。

```ts
await OpenIMSDK.deleteConversationGroup(conversationGroupID);
```

参数 `conversationGroupID` 为会话分组 ID。

## 返回结果

调用完成后，分组删除请求已完成。该操作不会删除会话或消息。分组变化会通过 `OnConversationGroupDeleted` 事件通知，完整监听方式见[会话分组概览](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups)。
