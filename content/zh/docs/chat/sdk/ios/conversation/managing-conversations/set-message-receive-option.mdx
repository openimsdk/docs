---
title: '设置会话消息接收选项'
description: '使用 iOS SDK 设置会话的消息接收选项。'
sourcePath: '/sdk/ios/conversation/managing-conversations/set-message-receive-option'
---

```objc
[[OIMManager manager] setConversationRecvMessageOpt:conversationID
                                             status:OIMReceiveMessageOptNotNotify
                                          onSuccess:nil
                                          onFailure:nil];
```

`OIMReceiveMessageOptReceive` 表示在线接收且离线推送，`OIMReceiveMessageOptNotReceive` 表示不接收也不推送，`OIMReceiveMessageOptNotNotify` 表示在线接收但离线不推送。成功后通过 `onConversationChanged:` 合并最新状态。
