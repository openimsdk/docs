进入会话、连接恢复或需要校准状态时，查询指定用户当前正在输入的平台 ID 列表。

```java
OpenIMClient.getInstance().conversationManager.getInputState(
    new OnBase<List<Integer>>() {
        @Override
        public void onSuccess(List<Integer> platformIDs) {
            boolean typing = platformIDs != null && !platformIDs.isEmpty();
            updateTypingState(conversationID, userID, typing);
        }

        @Override
        public void onError(int code, String error) {
            recordTypingStatusQueryFailure(code, error);
        }
    },
    conversationID,
    userID
);
```

成功 callback 返回平台 ID 数组快照；空列表表示查询时没有平台处于输入状态。查询本身不会触发输入状态事件。群聊中不要频繁轮询全部成员，只在进入页面、连接恢复或补偿状态时查询重点成员；在线增量由[上报输入状态](/sdk/android/message/composing-messages/update-typing-status)归属的 listener 维护。
