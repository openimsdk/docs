---
title: '删除会话'
description: '删除当前账号的指定会话记录，但保留会话消息。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/delete-conversation'
---

`deleteConversation()` 只删除当前账号的会话记录，不删除该会话下的消息。

```uts
import { deleteConversation } from '@/uni_modules/unix-openim-sdk'

await deleteConversation(conversationID)
```

Promise 成功后可以从当前列表移除对应 `conversationID`。该操作不删除好友关系，也不退出或解散群组；聊天目标仍然存在时，新消息或后续同步可能重新生成会话。需要确认当前列表时，应重新查询并以最新结果为准。
