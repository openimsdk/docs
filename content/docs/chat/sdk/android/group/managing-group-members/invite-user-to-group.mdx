Pass the group ID, the list of invited user IDs, and an invitation message. The server determines whether the users join immediately according to the group settings and the current user's permissions.

```java
OpenIMClient.getInstance().groupManager.inviteUserToGroup(new OnBase<String>() {
    @Override public void onSuccess(String data) { markInviteSubmitted(groupID); }
    @Override public void onError(int code, String error) { showInviteError(error); }
}, groupID, inviteeUserIDs, "Join the project discussion");
```

Merge users into the member list only after `onGroupMemberAdded` confirms that they joined. A successful submission alone does not mean that they are already members.
