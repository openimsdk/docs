title: '创建表情消息'
description: '使用 WASM SDK 创建表情消息。'

---

表情消息适用于发送应用内置的表情包内容（如系统自带 Emoji、动态贴图或自定义大图表情）。SDK 仅负责传输表情标识及扩展元数据，不负责表情图片资源的实际下载，客户端各端需基于统一的表情包规范进行解析展示。

```ts
const { data: message } = await openimsdk.createFaceMessage({
  index: 12,
  data: JSON.stringify({ pack: 'default' }),
});
```

`index` 为双方约定的表情序号或索引值，`data` 为自定义扩展字符串，通常用于记录表情包包名（pack）、版本号或特定贴图 ID。当接收端遇到本地尚未下载或无法识别的表情时，建议展示默认占位图或降级提示。

接口调用成功后，返回的 `data` 为待发送的 `MessageItem` 对象。后续需调用 [发送消息](/sdk/wasm/message/sending-messages/send-message) 将其发送至指定会话。
