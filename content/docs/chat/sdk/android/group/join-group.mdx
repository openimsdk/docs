Use `joinGroup()` to submit a request to join a group. Set `joinSource` to the source of the request, such as an invitation, search result, or QR code. Use the five-parameter overload when attaching extra data.

```java
OpenIMClient.getInstance().groupManager.joinGroup(new OnBase<String>() {
    @Override public void onSuccess(String data) { markJoinSubmitted(groupID); }
    @Override public void onError(int code, String error) { showJoinError(error); }
}, groupID, "I would like to join the project discussion", 3, "{\"from\":\"search\"}");
```

The verification mode determines whether the user joins immediately. Update local state later through `onJoinedGroupAdded` or the relevant group application event.
