```objc
[[OIMManager manager] insertSingleMessageToLocalStorage:message
    recvID:targetUserID
    sendID:currentUserID
    onSuccess:^(OIMMessageInfo *stored) {
        if (stored != nil) [self upsertMessage:stored];
    }
    onFailure:nil];
```

The success result may be `nil`; merge it by `clientMsgID` only when present. This method modifies the current device only. It does not trigger the new-message delegate or notify another user or device.
