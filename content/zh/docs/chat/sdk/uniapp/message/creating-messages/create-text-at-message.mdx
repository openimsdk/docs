`createTextAtMessage()` 创建群聊 @ 消息，参数包含正文、被 @ 用户和可选引用信息。

```uts
import { createTextAtMessage } from '@/uni_modules/unix-openim-sdk'

const message = await createTextAtMessage({
  text: '@Alice 请确认',
  atUserIDList: ['user_a'],
  atUsersInfo: [{ atUserID: 'user_a', groupNickname: 'Alice' }],
  quoteMessage: null,
})
```

字段以 `OpenIMCreateTextAtMessageParams` 为准，用户列表和显示信息保持一致。商业版 `getAtAllTag()` <span className="enterprise-field-badge">商业版</span> 可查询当前服务端使用的“@所有人”标签；HarmonyOS 支持该本地/企业入口。

创建后仍需调用发送 API并填写目标群 ID。
