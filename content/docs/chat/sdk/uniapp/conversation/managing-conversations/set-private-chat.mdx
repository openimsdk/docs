`isPrivateChat` is a <span className="enterprise-field-badge">Commercial</span> field accepted by the public `setConversation()` operation.

```uts
import { setConversation } from '@/uni_modules/unix-openim-sdk'

await setConversation({ conversationID, isPrivateChat: true })
```

Pass only this field. The host must still implement the corresponding product UI/security behavior; confirm the final flag from conversation updates.
