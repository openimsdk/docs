---
title: '设置全局消息接收方式'
description: '设置当前账号在全部会话中的默认消息接收与通知方式。'
sourcePath: '/sdk/wasm/user/profile/set-global-message-reception'
---

`globalRecvMsgOpt` 是账号级默认策略。它控制当前账号是否接收消息以及是否允许通知，不属于昵称、头像等普通用户资料。

```ts
import { MessageReceiveOption } from '@openim/wasm-client-sdk';

await openimsdk.setSelfInfo({
  globalRecvMsgOpt: MessageReceiveOption.ReceiveWithoutNotification,
});
```

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `MessageReceiveOption.Receive` | `0` | 正常接收消息，并允许离线推送或通知。 |
| `MessageReceiveOption.ReceiveWithoutNotification` | `2` | 接收消息，但不触发离线推送或通知。 |

全局消息接收方式使用 `Receive` 和 `ReceiveWithoutNotification`：`Receive` 表示关闭免打扰，`ReceiveWithoutNotification` 表示开启全天免打扰。

单个会话的 `recvMsgOpt` 是更细粒度的会话设置，见[设置会话消息接收方式](/sdk/wasm/conversation/managing-conversations/set-message-receive-option)。同时存在账号级与会话级设置时，客户端应展示服务端返回的最终会话状态，不要仅根据本地开关推断。

Promise 成功表示设置请求完成，不等同于 `OnSelfInfoUpdated` 已经到达。事件监听与 `getSelfUserInfo()` 校准方式见[更新当前用户资料](/sdk/wasm/user/profile/set-self-info)。
