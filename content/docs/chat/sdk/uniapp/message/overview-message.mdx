Use `clientMsgID` as the stable client identifier and merge send results, realtime events, and history by `(conversationID,clientMsgID)`. Creation only builds an `OpenIMMessageItem`; `sendMessage()` performs delivery.

```uts
import { off, onSendMessageProgress, onUploadFileProgress, onUploadLogsProgress } from '@/uni_modules/unix-openim-sdk'

const send = onSendMessageProgress((event) => updateMessageProgress(event.clientMsgID, event.progress))
const file = onUploadFileProgress((event) => updateCurrentUpload(event.progress))
const logs = onUploadLogsProgress((event) => updateLogUpload(event.progress))
off(send); off(file); off(logs)
```

Progress can repeat or skip values; only final API completion defines success. Convert `unifile://` to a readable native path before local-file creation.
