Call `getSpecifiedGroupsInfo()` to retrieve information for specific groups by group ID.

```ts
const groups = await OpenIMSDK.getSpecifiedGroupsInfo([
  'group-001',
  'group-002',
]);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- |
| `groupIDs` | `string[]` | Yes | IDs of the groups to retrieve. |

## Return value

When the call completes, it returns matching `GroupItem[]` entries. See [Group overview](/sdk/react-native/group/overview-group) for field descriptions.
