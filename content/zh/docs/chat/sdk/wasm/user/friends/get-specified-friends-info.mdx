---
title: '查询指定好友资料'
description: '按用户 ID 查询指定好友关系资料。'
sourcePath: '/sdk/wasm/user/friends/get-specified-friends-info'
---

```ts
const { data: friends } = await openimsdk.getSpecifiedFriendsInfo({
  friendUserIDList: userIDs,
  filterBlack: true,
});
```

Promise 成功返回匹配的 `FriendUserItem[]`。返回数组不保证与输入 ID 按位置一一对应，应按 `userID` 合并；完整字段见[分页获取好友列表](/sdk/wasm/user/friends/get-friend-list-page)。

陌生人公开资料应使用 `getUsersInfo()`。
