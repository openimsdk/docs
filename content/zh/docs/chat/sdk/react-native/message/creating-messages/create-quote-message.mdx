创建引用原消息的回复消息。

```ts
const message = await OpenIMSDK.createQuoteMessage({
  text: '同意这个方案。',
  message: originalMessage,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `text` | `string` | 是 | 回复的文本内容。 |
| `message` | `MessageItem` | 是 | 被回复的原消息完整对象。 |

## 返回结果

调用完成后返回新建的待发送 `MessageItem` 消息对象，其中 `quoteElem` 保存引用信息。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送消息](/sdk/react-native/message/sending-messages/send-message)将消息投递到单聊或群聊会话中。接收端展示回复消息时，应注意兼容原消息已撤回或已删除的情况。若需同时携带富文本实体，请参考[创建富文本回复消息](/sdk/react-native/message/creating-messages/create-advanced-quote-message)。
