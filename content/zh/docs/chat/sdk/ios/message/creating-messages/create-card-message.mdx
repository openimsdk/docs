调用创建名片消息方法可构建向对端推荐个人联系人信息的用户名片消息对象。

```objc
OIMCardElem *card = [OIMCardElem new];
card.userID = @"user_b";
card.nickname = @"Alex";
card.faceURL = @"https://example.com/avatar.png";
card.ex = @"";

OIMMessageInfo *message = [OIMMessageInfo createCardMessage:card];
```

## 参数说明

- `cardElem`：名片元素对象（`OIMCardElem`），包含以下属性：
  - `userID`：被推荐人的用户 ID。
  - `nickname`：名片展示的昵称。
  - `faceURL`：名片展示的头像地址。
  - `ex`：业务自定义扩展数据。

## 返回结果

- 返回初始化的名片消息对象（`OIMMessageInfo *`），其内容类型为名片。
- 名片中的昵称与头像在创建时固化为当前快照，后续被推荐用户的个人资料变更不会自动同步修改历史名片中的内容。创建后需调用[发送消息](/sdk/ios/message/sending-messages/send-message)进行投递。
