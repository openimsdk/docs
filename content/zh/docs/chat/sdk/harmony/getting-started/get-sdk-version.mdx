在完成[工程与平台接入](/sdk/harmony/getting-started/environment-specific-implementation)并引入 HAR 包后，可调用查询 SDK 版本接口获取当前实际加载的 OpenIMClientSDK 底层版本，适合在诊断页、启动日志或兼容性检查中确认运行基线。

```ts
import sdk, { VersionResp } from '@openimsdk/imsdk';

const response: VersionResp = await sdk.version();
console.info(`OpenIMClientSDK version: ${response.version}`);
```

## 返回结果

Promise 成功后，`version` 字段是 SDK 版本字符串。该值用于排查制品是否符合预期，不应代替应用自己的版本号或作为服务端授权凭据。

如果多个模块都需要版本信息，应在应用级服务中查询一次并复用结果，避免在页面渲染期间反复调用。确认版本与依赖就绪后，可继续前往[认证与管理登录会话](/sdk/harmony/getting-started/authenticate-and-manage-session)。
