Handle whitespace, maximum length, and content policy checks in the application layer before calling this method.

## Code example

```ts
import sdk, { CreateTextMessageReq, CreateTextMessageResp } from '@openimsdk/imsdk';

const text = input.trim();
if (text.length > 0) {
  const request: CreateTextMessageReq = { text: text };
  const response: CreateTextMessageResp = await sdk.createTextMessage(request);
  const message = response.message;
}
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `text` | `string` | Yes | Message text content. |

## Return value

Returns a Promise resolving to `CreateTextMessageResp`:

| Property | Type | Description |
| --- | --- | --- |
| `message` | `IMMessage` | Locally instantiated text message object. |

## State changes after the call

Promise resolution returns only the local `IMMessage` object ready for transmission; it does not write to OpenIMServer or trigger message events. Pass the returned object to [Send message](/sdk/harmony/message/sending-messages/send-message) as the next step.
