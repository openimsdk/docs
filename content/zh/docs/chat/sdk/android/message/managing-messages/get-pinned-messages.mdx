---

查询结果是指定会话当前的置顶消息快照。

```java
messageManager.getConversationPinnedMsgs(new OnBase<List<Message>>() {
    @Override public void onSuccess(List<Message> messages) { showPinned(messages); }
    @Override public void onError(int code, String error) { showPinnedError(error); }
}, conversationID);
```
