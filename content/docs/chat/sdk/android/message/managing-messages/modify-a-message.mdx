Use `modifyMessage` to change an existing message in a conversation. Normally, start with the original message, change the supported content, and preserve its other fields.

```java
messageManager.modifyMessage(callback, modifyRequest);
```

The success callback means that the modification request completed.

After a message is modified, other clients receive the complete modified `Message` through `OnAdvanceMsgListener.onMessageModified`:

```java
@Override
public void onMessageModified(Message message) {
    handleModifiedMessage(message);
}
```

`MessageManager` can retain only one `OnAdvanceMsgListener`. If the application handles other message events, implement their callbacks in the same listener. See [Events](/sdk/android/events/overview-events) for setup.
