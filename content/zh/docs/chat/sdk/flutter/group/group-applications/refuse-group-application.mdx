---
title: '拒绝入群申请'
description: '拒绝 Flutter 入群申请。'
sourcePath: '/sdk/flutter/group/group-applications/refuse-group-application'
---

传入有效的 `groupID`、申请人 `userID` 和可选 `handleMsg`。Future 成功与 `onGroupApplicationRejected` 到达分别处理。

```dart
await OpenIM.iMManager.groupManager.refuseGroupApplication(
  groupID: groupID,
  userID: applicantUserID,
  handleMsg: '暂不开放加入',
);
```
