---
title: '删除好友'
description: '删除当前用户与指定用户的好友关系。'
sourcePath: '/sdk/uniapp/user/friends/delete-friend'
---

`deleteFriend()` 直接接收要删除的好友用户 ID。

```uts
import { deleteFriend } from '@/uni_modules/unix-openim-sdk'

await deleteFriend(friendUserID)
```

Promise 成功表示本次删除好友请求已成功返回，不表示好友事件已经到达。收到 `onFriendDeleted()` 后，按事件数据中的 `userID` 从好友列表和相关缓存中移除记录；完整监听见[分页获取好友列表](/sdk/uniapp/user/friends/get-friend-list-page)。如果事件可能遗漏，应重新查询好友列表并以最新结果为准。
