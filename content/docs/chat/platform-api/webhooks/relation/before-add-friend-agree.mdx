Validate a friend-request acceptance.

## HTTP request
```http
POST {WEBHOOK_ADDRESS}/callbackBeforeAddFriendAgreeCommand
```

## Request body
| Property | Type | Description |
| --- | --- | --- |
| callbackCommand | string | `callbackBeforeAddFriendAgreeCommand`. |
| fromUserID | string | User performing the action |
| blackUserID | string | Counterparty user ID |
| HandleResult | int | Request handling result |
| HandleMsg | string | Handling message |

## Response
Return the common before-event response from [Webhooks overview](/platform-api/webhooks/overview). Use `nextCode: 1` to reject the operation.

## Processing rules
- Configuration key: `beforeAddFriendAgree`.
- OpenIM waits synchronously; timeout behavior follows `failedContinue`.
- The protocol retains the historical field names `blackUserID`, `HandleResult`, and `HandleMsg`; parse them exactly as shown.
