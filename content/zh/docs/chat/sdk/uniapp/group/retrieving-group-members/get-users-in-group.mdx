在仅需要判断一组用户是否在群内，而无需获取其完整群成员资料时，执行快速状态查询。

```uts
import { getUsersInGroup } from '@/uni_modules/unix-openim-sdk'

const presentUserIDs = await getUsersInGroup({
  groupID: groupID,
  userIDList: candidateUserIDs,
})

const confirmedUserIDs = presentUserIDs != null ? presentUserIDs : []
```

`groupID` 是目标群组 ID，`userIDList` 是待检查的用户 ID 数组。Promise 成功后返回 `string[] | null`；非空数组只包含输入用户中仍属于该群组的用户 ID，不返回完整成员资料。

该查询只反映调用时的快照状态，不会触发群成员事件。需要持续维护成员列表时，应参考[分页查询群成员](/sdk/uniapp/group/retrieving-group-members/get-group-member-list)拉取成员数据并监听增量事件。
