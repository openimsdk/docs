Invoke `createAtAllFlag:` on `OIMMessageInfo` to construct an `OIMAtInfo` model representing all group members when assembling custom @ mention structures:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `displayText` | `NSString *` | Yes | The placeholder text to display in the UI (such as `@All`). |

## Code example

```objc
OIMAtInfo *atAll = [OIMMessageInfo createAtAllFlag:@"@All"];
```

## Return value

Returns an initialized `OIMAtInfo` instance configured to designate all group members. This marker does not represent a real user account and serves strictly as an all-member indicator in @ messages.

## State changes after the call

1. **Local memory instantiation**: This method builds an in-memory `OIMAtInfo` instance without making network calls.
2. **Usage**: Supply this instance in the `atUsersInfo` parameter when assembling compound mention messages via [Create an @ message](/sdk/ios/message/creating-messages/create-text-at-message).
