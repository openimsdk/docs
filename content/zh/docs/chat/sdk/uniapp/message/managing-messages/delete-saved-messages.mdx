`deleteMessages()` <span className="enterprise-field-badge">商业版</span> 批量删除明确指定的消息。本页归属公共 `onMsgDeleted` 事件。

```uts
import {
  deleteMessages,
  off,
  onMsgDeleted,
} from '@/uni_modules/unix-openim-sdk'

const deletedSubscription = onMsgDeleted((message) => {
  removeMessageByID(message.clientMsgID)
})

await deleteMessages(deleteParams)
off(deletedSubscription)
```

`deleteParams` 使用锁定的 `OpenIMDeleteMessagesParams`，不要只传本地数组。事件和请求结果幂等合并；是否影响其他设备由商业服务语义决定。
