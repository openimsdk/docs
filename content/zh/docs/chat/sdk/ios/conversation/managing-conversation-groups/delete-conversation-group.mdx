删除指定的会话分组及其分组成员关联。该操作仅移除分组维度，不会删除分组内的任何会话或历史消息：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `conversationGroupID` | `NSString *` | 待删除的目标会话分组 ID。 |

```objc
#import <OpenIMSDK/CallbackProxy.h>
@import OpenIMCore;

CallbackProxy *callback = [[CallbackProxy alloc]
    initWithOnSuccess:^(NSString * _Nullable data) {
        [self removeConversationGroupByID:@"group_work_101"];
    }
    onFailure:^(NSInteger code, NSString * _Nullable message) {
        NSLog(@"DeleteConversationGroup failed: %ld %@", (long)code, message);
    }];

Open_im_sdkDeleteConversationGroup(callback, @"group_work_101");
```

状态以 `conversationGroupID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 表示会话分组已被成功删除。

客户端应以 `conversationGroupID` 为合并标识在本地移除对应会话分组。其他登录端会通过 `onConversationGroupDeleted:` 事件同步删除通知，事件监听与生命周期请参见[会话分组概览](/sdk/ios/conversation/managing-conversation-groups/overview-conversation-groups)。
