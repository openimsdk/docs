---
title: '拒绝通话'
description: '拒绝当前尚未接听的通话邀请。'
sourcePath: '/sdk/harmony/calling/managing-calls/reject-call'
---

```ts
import sdk, { Platform, SignalingRejectReq } from '@openimsdk/imsdk';

const request: SignalingRejectReq = {
  invitation: invitation,
  offlinePush: offlinePush,
  participant: participant,
  opUserPlatformID: Platform.HarmonyOS,
  userID: invitation.inviterUserID,
};
await sdk.signalingReject(request);
```

传入完整邀请和当前拒绝者的参与者资料。Promise 成功后可以关闭来电界面并释放尚未使用的本地媒体资源，但不能据此判断发起方已经收到拒绝事件。
