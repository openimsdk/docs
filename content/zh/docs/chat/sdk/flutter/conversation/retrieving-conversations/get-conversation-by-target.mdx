从通讯录、用户资料或群资料进入聊天页时，使用 `getOneConversation()`。单聊传对方用户 ID，群聊传群组 ID；即使还没有消息，也不要自行构造 `ConversationInfo`。

```dart
final conversation =
    await OpenIM.iMManager.conversationManager.getOneConversation(
  sourceID: targetUserID,
  sessionType: ConversationType.single,
);

openChatPage(conversation: conversation);
```

群聊使用 `ConversationType.superGroup`。Future 成功返回 `ConversationInfo`，查询本身不触发会话回调；后续变化由[获取会话列表](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list)统一合并。
