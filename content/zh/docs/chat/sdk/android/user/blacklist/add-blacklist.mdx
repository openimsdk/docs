---
title: '拉黑用户'
description: '使用 addBlacklist() 将用户加入当前账号黑名单。'
sourcePath: '/sdk/android/user/blacklist/add-blacklist'
---

```java
OpenIMClient.getInstance().friendshipManager.addBlacklist(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 拉黑用户成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    targetUserID,
    "{\"source\":\"profile-menu\"}"
);
```

第二个参数是目标 `userID`，第三个参数是可选扩展字符串。无需扩展信息时可使用不带 `ex` 的重载。成功 callback 表示拉黑请求完成，不表示事件已经到达。

黑名单是单向关系：被拉黑用户不能向当前用户发送消息，但当前用户是否允许继续向对方发送消息由业务层决定。`ex` 是用于保存黑名单扩展信息的字符串，也可以存储 JSON 字符串。

拉黑状态变化时，可通过 `OnFriendshipListener` 接收 `onBlacklistAdded`：

```java
@Override
public void onBlacklistAdded(BlacklistInfo user) {
    // 处理新增的黑名单记录
}
```
