---

`messageManager.clearConversationAndDeleteAllMsg()` 清空指定会话的消息并保留会话入口。

```java
OpenIMClient.getInstance().messageManager.clearConversationAndDeleteAllMsg(
    conversationID,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成，消息已清空。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    }
);
```

成功回调后，会话入口仍然保留，但当前账号下的消息会被清除。需要更新会话列表时，可重新查询会话或通过 `onConversationChanged` 接收变化。
