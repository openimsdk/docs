`setAppBadge()` 用于向 SDK 上报应用当前展示的未读角标数量。它不会直接操作 HarmonyOS 桌面图标，宿主应用仍需按产品和系统能力更新界面角标。

```ts
import sdk, { SetAppBadgeReq } from '@openimsdk/imsdk';

const request: SetAppBadgeReq = {
  appUnreadCount: totalUnreadCount,
};
await sdk.setAppBadge(request);
```

`appUnreadCount` 应为非负整数。通常在总未读数变化、登录同步完成和清空未读后更新；不要把单个会话未读数当成全局角标。

Promise 成功只表示 SDK 已接受本次角标值，不代表系统桌面角标已经显示，也不会改变会话本地未读数。
