在应用启动或从后台恢复时获取未处理的通话邀请。常用于离线推送拉起应用后恢复呼叫界面。

```java
OpenIMClient.getInstance().signalingManager.getSignalingInvitationInfoStartApp(
    new OnBase<SignalingInfo>() {
        @Override
        public void onSuccess(SignalingInfo info) {
            // 使用前校验 info 中 invitation 和 roomID 是否有效。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明查询失败原因。
        }
    }
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<SignalingInfo>` | 是 | 异步请求回调。 |

## 返回结果

成功回调返回应用启动或冷启动拉起时缓存的未决通话邀请 `SignalingInfo`。

该方法不会自动接听通话。使用前需校验 `info` 中的 `invitation` 和 `roomID` 是否有效；若存在有效邀请，应用可展示来电弹窗并交由用户[接受通话](/sdk/android/calling/managing-calls/accept-call)或[拒绝通话](/sdk/android/calling/managing-calls/reject-call)。后续邀请取消或超时状态变更请参考[处理通话事件](/sdk/android/calling/managing-calls/handle-call-events)。
