---

进入会话、连接恢复或需要校准时，查询指定成员仍处于输入状态的平台列表：

```ts
const { data: platformIDs } = await openimsdk.getInputStates({
  conversationID,
  userID: memberUserID,
});

setTyping(memberUserID, platformIDs.length > 0);
```

Promise 返回平台 ID 数组快照，查询本身不触发输入状态事件。群聊中不要轮询全部成员，应由[上报输入状态](/sdk/wasm/message/composing-messages/update-typing-status)归属的事件维护输入用户集合。
