---
title: '解散群组'
description: '由群主解散指定群组。'
sourcePath: '/sdk/harmony/group/dismiss-group'
---

只有群主可以解散群组。解散会影响群内所有成员，不同于删除、隐藏或清空当前账号的会话。

```ts
import sdk, { DismissGroupReq } from '@openimsdk/imsdk';

const request: DismissGroupReq = { groupID: groupID };
await sdk.dismissGroup(request);
```

Promise 成功表示解散请求已经完成；相关客户端收到解散事件后，应按 `groupID` 将群组标记为已解散，并关闭继续管理成员或发送消息的入口。群组事件处理器不应直接删除会话或历史消息。
