---
title: '将用户移出黑名单'
description: '将指定用户移出当前账号的黑名单。'
sourcePath: '/sdk/uniapp/user/blacklist/remove-black'
---

`removeBlack()` 直接接收需要移出黑名单的用户 ID。该操作只改变当前账号维护的黑名单关系，不会自动恢复好友关系或其他业务状态。

```uts
import { removeBlack } from '@/uni_modules/unix-openim-sdk'

await removeBlack(toUserID)
```

Promise 成功表示本次移出黑名单请求已成功返回，不表示黑名单事件已经到达。收到 `onBlackDeleted()` 后，按事件数据中的 `userID` 从黑名单列表和相关缓存中移除记录；完整监听见[获取黑名单](/sdk/uniapp/user/blacklist/get-black-list)。需要立即确认或事件可能遗漏时，应重新查询黑名单并以最新结果为准。
