Hide a specified conversation entry from the currently signed-in user's conversation list. This action does not delete friendships, leave groups, or affect the counterparty's conversation list:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `String` | Yes | Target conversation ID. |

## Code example

```dart
await OpenIM.iMManager.conversationManager.hideConversation(
  conversationID: conversationID,
);
```

## Return value

A successful `Future` indicates that the hide request has been processed. The client should immediately remove the conversation item from the local list. If a new message is received or a full sync runs later, the conversation may reappear in the list.

## State changes after the call

Multi-device synchronization and incoming events notify clients via conversation change callbacks. The client updates its local list using `conversationID` as the merge key. For complete listener integration, see [Retrieve conversation list](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list).
