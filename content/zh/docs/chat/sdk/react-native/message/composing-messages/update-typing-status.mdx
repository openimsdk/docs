向单聊对方上报自定义的输入状态提示文本。

```ts
await OpenIMSDK.typingStatusUpdate({
  recvID: receiverUserID,
  msgTip: '正在输入…',
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `recvID` | `string` | 是 | 接收输入提示的单聊目标用户 ID。 |
| `msgTip` | `string` | 是 | 要上报的输入提示文本。 |

## 返回结果

调用完成后，输入状态提示已发送给目标用户。

需要根据输入框焦点状态自动同步输入中状态时，请参考[更新输入状态](/sdk/react-native/message/composing-messages/change-input-states)。
