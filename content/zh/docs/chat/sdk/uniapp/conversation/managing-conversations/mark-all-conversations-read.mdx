---
title: '将全部会话标为已读'
description: '清零当前账号所有本地未读会话的未读数。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/mark-all-conversations-read'
---

当用户明确执行“全部已读”时，调用 `markAllConversationMessageAsRead()` 处理当前 SDK 本地记录中的未读会话。

```uts
import { markAllConversationMessageAsRead } from '@/uni_modules/unix-openim-sdk'

await markAllConversationMessageAsRead()
```

Promise 成功表示 SDK 已完成本次找到的全部未读会话处理，不表示相关会话事件已经全部到达，也不保证其他客户端的界面已同步完成。

界面应通过 `onConversationChanged()` 按 `conversationID` 更新各会话，并通过 `onTotalUnreadMessageCountChanged()` 更新账号总未读数。完整监听分别见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)和[获取消息总未读数](/sdk/uniapp/conversation/managing-conversations/get-total-unread-count)。事件可能遗漏时，重新查询这两项数据并刷新界面。
