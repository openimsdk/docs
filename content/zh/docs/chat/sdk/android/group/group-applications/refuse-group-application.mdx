---
title: '拒绝入群申请'
description: '使用 refuseGroupApplication 拒绝指定用户的入群申请。'
sourcePath: '/sdk/android/group/group-applications/refuse-group-application'
---

拒绝操作同样使用申请所属 `groupID`、申请人 `userID` 和处理说明。

```java
OpenIMClient.getInstance().groupManager.refuseGroupApplication(new OnBase<String>() {
    @Override public void onSuccess(String data) { /* 请求已完成。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
}, groupID, applicantUserID, "当前群组人数已满");
```

拒绝成功后，通过 `onGroupApplicationRejected` 接收通知，也可以重新调用查询 API 获取最新申请列表。
