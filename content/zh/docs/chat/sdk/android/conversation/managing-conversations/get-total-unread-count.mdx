获取当前登录账号在所有会话中的未读消息总数，常用于应用初始化、登录完成或从后台切回前台时校准底部导航栏的消息角标。

```java
OpenIMClient.getInstance().conversationManager.getTotalUnreadMsgCount(
    new OnBase<String>() {
        @Override
        public void onSuccess(String value) {
            int totalUnread = Integer.parseInt(value);
            // totalUnread 是当前账号的未读消息总数。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    }
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |

## 返回结果

成功回调返回包含未读总数的 `String` 字符串，解析为整数后即可用于展示全局未读角标。

当有新消息到达、会话被标记已读或未读数因其他端同步发生变动时，SDK 会通过 `OnConversationListener.onTotalUnreadMessageCountChanged` 事件主动推送最新未读总数。完整监听注册请参考[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
