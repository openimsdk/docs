Before an unanswered call is accepted, the initiator can cancel the invitation:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `info` | `SignalingInfo` | Yes | The complete signaling object saved when initiating the call invitation. |

## Code example

```dart
await OpenIM.iMManager.signalingManager
    .signalingCancel(info: activeInfo);
```

## Return value

A successful `Future` indicates that the cancellation signaling request has been received by the server.

## State changes after the call

The client should terminate its outgoing call waiting UI and release local media resources using `roomID`. The invitee dismisses the incoming call notification upon receiving the cancellation event (see [Handle call events](/sdk/flutter/calling/managing-calls/handle-call-events) for listener details). If the call has already been answered and established, invoke [Hang up a call](/sdk/flutter/calling/managing-calls/hang-up-call) instead.
