Get a recurrence definition, generation progress, next schedule time, and status.

## HTTP request
```bash
POST {API_ADDRESS}/rtc-meeting/get_repeat_meeting
```

## Request body
| Parameter | Required | Type | Description |
| --- | --- | --- | --- |
| repeatMeetingID | Yes | string | Recurring meeting ID. |

## Response
`data.repeatMeeting` contains [`RepeatMeetingData`](/platform-api/meeting/overview#repeatmeetingdata).

## Permissions and limits
- Available only in OpenIM Enterprise.
- Validate that the caller may view the series.
