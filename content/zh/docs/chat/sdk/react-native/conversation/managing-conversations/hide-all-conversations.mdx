隐藏当前登录账号的全部会话列表项。该操作仅在当前设备上批量隐藏会话，不删除任何历史聊天消息。

```ts
await OpenIMSDK.hideAllConversations();
```

## 返回结果

调用完成后，隐藏全部会话请求已处理完成。

调用成功后，客户端可清空当前展示的会话列表，并通过[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)和[获取消息总未读数](/sdk/react-native/conversation/managing-conversations/get-total-unread-count)刷新界面数据。后续新消息到达或产生新交互时，相关会话会通过 `OnNewConversation` 或 `OnConversationChanged` 事件重新出现，客户端按 `conversationID` 进行列表合并与展示。
