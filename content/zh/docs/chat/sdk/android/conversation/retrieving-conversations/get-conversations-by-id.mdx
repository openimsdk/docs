使用 `getMultipleConversation()` 根据 `conversationIDs` 查询多个会话。`conversationIDs` 是待查询的会话 ID 列表。

```java
OpenIMClient.getInstance().conversationManager.getMultipleConversation(
    new OnBase<List<ConversationInfo>>() {
        @Override
        public void onSuccess(List<ConversationInfo> conversations) {
            // conversations 是按 conversationIDs 查询到的会话快照。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    conversationIDs
);
```

成功回调返回 `List<ConversationInfo>`。
