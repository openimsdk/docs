基于本地设备存储中的绝对路径（例如从系统文件选择器选取的文件路径）创建文件消息对象。在调用[发送消息](/sdk/android/message/sending-messages/send-message)时，SDK 会读取本地文件并执行上传。

```java
String absolutePath = "/storage/emulated/0/Download/specs.docx";
String fileName = "产品需求规格说明书.docx";

Message message = OpenIMClient.getInstance().messageManager.createFileMessageFromFullPath(
    absolutePath,
    fileName
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `filePath` | `String` | 是 | 本地文件的绝对文件路径。必须保证当前应用具备读取权限。 |
| `fileName` | `String` | 是 | 展示给接收端的文件名称（包含文件扩展名）。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.FILE`。

构建完成后，调用[发送消息](/sdk/android/message/sending-messages/send-message)向目标会话投递。
