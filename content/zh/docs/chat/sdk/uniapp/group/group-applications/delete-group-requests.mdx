---
title: '删除入群申请'
description: '批量删除指定的入群申请记录。'
sourcePath: '/sdk/uniapp/group/group-applications/delete-group-requests'
---

删除入群申请接口按“群组 + 申请人”批量删除入群申请记录。该操作适合清理已经处理完毕或不再需要展示的历史记录。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupRequests` | `OpenIMSimpleGroupRequest[]` | 是 | 要删除的申请列表。 |
| `groupRequests[].groupID` | `string` | 是 | 申请加入的群组 ID。 |
| `groupRequests[].fromUserID` | `string` | 是 | 申请人的用户 ID，对应申请记录中的 `userID`。 |

```uts
import { deleteGroupRequests } from '@/uni_modules/unix-openim-sdk'

await deleteGroupRequests({
  groupRequests: [
    {
      groupID: application.groupID,
      fromUserID: application.userID,
    },
  ],
})
```

删除申请记录不等于拒绝申请。需要给出明确审核结果时，应先调用[接受入群申请](/sdk/uniapp/group/group-applications/accept-group-application)或[拒绝入群申请](/sdk/uniapp/group/group-applications/refuse-group-application)；记录删除后将无法再次进行审批操作。

Promise 成功表示删除请求已经完成。收到入群申请被删除事件后，客户端应按 `groupID:userID` 从申请列表中移除对应记录。完整事件监听请参考[获取收到的入群申请](/sdk/uniapp/group/group-applications/get-group-application-list-as-recipient)。
