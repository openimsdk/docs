---
title: '设置会话草稿'
description: '保存或清空指定会话的输入草稿。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/set-conversation-draft'
---

用户离开聊天页、切换会话或输入框内容变化时，可以使用 `setConversationDraft()` 保存草稿。输入过程中建议先维护编辑器状态并对保存调用做防抖；离开页面前再提交一次最新内容，避免每次按键都写入 SDK。

```uts
import { setConversationDraft } from '@/uni_modules/unix-openim-sdk'

await setConversationDraft({
  conversationID,
  draftText: editorValue,
})
```

清空草稿时把 `draftText` 设为空字符串。

Promise 成功表示草稿已经保存，不表示会话变化事件已经到达。收到 `onConversationChanged()` 后，按 `conversationID` 更新 `draftText` 和 `draftTextTime`；完整监听见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。退出登录或切换账号时还应清理编辑器内存状态，避免把一个账号的草稿带到另一个账号。
