```objc
[[OIMManager manager] getJoinedGroupListPageWithOffset:0 count:50
    onSuccess:^(NSArray<OIMGroupInfo *> *groups) { [self replaceFirstPage:groups]; }
    onFailure:^(NSInteger code, NSString *message) { [self showErrorCode:code message:message]; }];
```

`offset` starts at `0`. Increment it by the number of requested items when loading more. If group addition or deletion events arrive during pagination, rebuild the snapshot from the first page.
