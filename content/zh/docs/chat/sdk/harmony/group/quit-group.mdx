---
title: '退出群组'
description: '退出当前账号已加入的群组。'
sourcePath: '/sdk/harmony/group/quit-group'
---

普通成员和管理员可以退出群组。群主不能直接退出，应先将群主身份转让给其他成员。

```ts
import sdk, { QuitGroupReq } from '@openimsdk/imsdk';

const request: QuitGroupReq = { groupID: groupID };
await sdk.quitGroup(request);
```

Promise 成功表示退出请求已经完成；随后可在退出事件中按 `groupID` 移除已加入群组记录。退出群组不等同于删除或隐藏本地会话，不能根据会话是否存在判断成员关系。
