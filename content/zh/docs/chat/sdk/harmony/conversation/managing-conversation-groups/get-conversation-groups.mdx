会话分组属于商业版能力。查询条件可限定普通分组、筛选分组或全部分组。

```ts
import sdk, {
  ConversationGroupQueryType,
  GetConversationGroupsReq,
  GetConversationGroupsResp,
} from '@openimsdk/imsdk';

const request: GetConversationGroupsReq = {
  conversationGroupType: ConversationGroupQueryType.ConversationGroupQueryAll,
};
const response: GetConversationGroupsResp = await sdk.getConversationGroups(request);
const groups = response.conversationGroups;
```

Promise 成功后返回 `IMConversationGroup[]`。渲染和缓存时以 `conversationGroupID` 作为稳定标识；查询本身不会触发分组事件。事件到达或连接恢复后，可以重新调用本方法校准列表。
