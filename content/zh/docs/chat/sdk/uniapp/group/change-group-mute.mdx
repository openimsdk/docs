---
title: '设置群组全员禁言'
description: '开启或关闭指定群组的整体禁言状态。'
sourcePath: '/sdk/uniapp/group/change-group-mute'
---

`changeGroupMute()` 控制群组整体禁言，群主和管理员可以按 OpenIMServer 权限执行该操作。

```uts
import { changeGroupMute } from '@/uni_modules/unix-openim-sdk'

await changeGroupMute({
  groupID,
  isMute: true,
})
```

`isMute` 为 `true` 时开启全员禁言，为 `false` 时关闭。群主和管理员通常仍可发送消息，因此全员禁言不表示每一位成员都无法发言。

该方法的参数只有 `groupID` 和 `isMute`，不支持通过 `muteBypassUserIDs` 设置全员禁言例外名单。

Promise 成功表示本次设置请求已成功返回，不表示群资料事件已经到达。收到 `onGroupInfoChanged()` 后，按 `groupID` 更新对应群资料；需要校准状态时重新查询指定群组。完整监听见[群组概览](/sdk/uniapp/group/overview-group)。
