---
title: '设置会话消息接收方式'
description: '使用 setConversationRecvMessageOpt() 设置单个会话的消息接收与通知方式。'
sourcePath: '/sdk/android/conversation/managing-conversations/set-message-receive-option'
---

```java
OpenIMClient.getInstance().conversationManager.setConversationRecvMessageOpt(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    conversationID,
    2
);
```

| 数值 | 含义                         |
| ---- | ---------------------------- |
| `0`  | 正常接收消息并允许通知。     |
| `1`  | 不接收该会话消息，也不通知。 |
| `2`  | 接收该会话消息，但不通知。   |

账号级默认策略见[设置全局消息接收方式](/sdk/android/user/user-profile/set-global-message-reception)。会话列表中的接收方式变化可通过 `onConversationChanged` 接收，监听器设置方式见[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
