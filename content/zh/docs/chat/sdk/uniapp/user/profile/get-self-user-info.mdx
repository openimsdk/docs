`getSelfUserInfo()` 查询当前登录账号的用户资料，不接收业务参数。

```uts
import { getSelfUserInfo } from '@/uni_modules/unix-openim-sdk'

const currentUser = await getSelfUserInfo()
if (currentUser != null) {
  setCurrentUser(currentUser)
}
```

## 返回结果

Promise 成功后返回 `OpenIMUserInfo | null`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `userID` | `string` | 当前登录用户的 OpenIMSDK 用户 ID。 |
| `nickname` | `string` | 账号级昵称。 |
| `faceURL` | `string` | 账号级头像地址。 |
| `ex` | `string` | 由业务约定的账号级扩展字符串。 |
| `createTime` | `number` 或 `null` | 用户记录创建时间；存在值时为 Unix 毫秒时间戳。 |
| `attachedInfo` | `string` 或 `null` | SDK 附加信息，只按已确认的业务约定解析。 |
| `globalRecvMsgOpt` | `OpenIMMessageReceiveOption` 或 `null` | 当前账号的全局消息接收方式，取值含义见[设置全局消息接收方式](/sdk/uniapp/user/profile/set-global-message-reception)。 |
| `addFriendPermission` <span className="enterprise-field-badge">商业版</span> | `OpenIMAddFriendPermission` 或 `null` | 当前账号的加好友处理策略，取值含义见[设置加好友权限](/sdk/uniapp/user/profile/set-friend-add-permission)。 |

判断消息接收方式和加好友策略时，使用 SDK 导出的对应常量进行比较，不要在界面逻辑中散落裸数字。

该查询只返回调用时的数据，不会触发资料事件。当前用户资料发生变化时，SDK 通过 `onSelfInfoUpdated()` 通知；完整监听和清理代码见[更新当前用户资料](/sdk/uniapp/user/profile/set-self-info)。切换账号时，应清理上一账号的资料缓存后再加载新账号。
