description: '使用 getGroupMemberList 按角色和分页条件读取群成员。'

---

`filter` 传 `0` 查询全部成员，`1` 普通成员，`2` 群主，`3` 管理员。`offset` 与 `count` 控制分页。

```java
OpenIMClient.getInstance().groupManager.getGroupMemberList(
    new OnBase<List<GroupMembersInfo>>() {
        @Override public void onSuccess(List<GroupMembersInfo> members) { /* members 是当前页成员。 */ }
        @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
    }, groupID, 0, offset, 50);
```
