已知通话房间 ID 时，可以查询该房间的音视频接入凭据。

```ts
const roomCredentials =
  await OpenIMSDK.signalingGetTokenByRoomID(roomID);
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `roomID` | `string` | 是 | 目标通话房间 ID。 |

## 返回结果

调用完成后返回 `RtcInviteResults`，包含 `roomID`、`token`、`liveURL` 和可选的 `busyLineUserIDList`。将返回的房间凭据交给实时音视频媒体引擎加入通话房间。详细字段说明见[发起单聊通话](/sdk/react-native/calling/managing-calls/start-single-call)。
