```java
messageManager.sendGroupMessageReadReceipt(
    conversationID,
    visibleClientMsgIDs,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 已读回执已上报
        }

        @Override
        public void onError(int code, String error) {
            // 处理失败
        }
    }
);
```

同一批消息必须属于目标群会话。成功回调只表示服务端接受上报，不代表其他客户端界面已经更新。会话未读数仍由 `markConversationMessageAsRead` 独立维护。

其他客户端通过 `OnAdvanceMsgListener.onRecvGroupMessageReadReceipt` 接收群聊成员级已读变化。本页是该事件的完整监听归属页；根据 `conversationID` 以及回执中的消息 ID 合并消息已读数、未读数和成员信息。

```java
@Override
public void onRecvGroupMessageReadReceipt(GroupMessageReceipt receipt) {
    mergeGroupReadReceipt(receipt);
}
```

上报回调、群回执事件和[查询群消息已读成员](/sdk/android/message/managing-read-status/get-group-message-readers)取得的成员快照是三个独立阶段。
