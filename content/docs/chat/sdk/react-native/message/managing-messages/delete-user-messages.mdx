Delete all historical messages posted by a specific user within a group conversation:

This administrative action is typically initiated by group owners or managers to moderate chat logs and remove spam or abusive content.

```ts
await OpenIMSDK.deleteUserAllMessagesInConv({
  conversationID,
  userID,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `string` | Yes | Target group conversation ID. |
| `userID` | `string` | Yes | Target user ID whose messages will be deleted. |

## Return value

A resolved Promise confirms that the deletion request was validated and executed on the server. Permissions are enforced according to group roles; invoking this method without administrative privileges returns an error.

## Listen for user message deletions

When a user's messages are removed from a group, the SDK emits the `OnDeleteUserAllMsgsInConv` event. The callback payload provides the target `conversationID` and `userID`. Locate the active conversation and filter out all messages sent by `userID`.

```ts
interface DeleteUserAllMsgsData {
  conversationID: string;
  userID: string;
}

const handleUserMessagesDeleted = (data: DeleteUserAllMsgsData) => {
  // Locate the target conversation by data.conversationID and filter out messages from data.userID
};

// Register listener
OpenIMSDK.on(
  OpenIMEvent.OnDeleteUserAllMsgsInConv,
  handleUserMessagesDeleted,
);

// Unregister listener on cleanup
OpenIMSDK.off(
  OpenIMEvent.OnDeleteUserAllMsgsInConv,
  handleUserMessagesDeleted,
);
```

Always unregister listeners using identical function references when unmounting components or signing out.
