Leave a group that the authenticated account is currently a member of:

```ts
await OpenIMSDK.quitGroup(groupID);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group ID to leave. |

Group owners cannot directly quit a group; the owner must first [Transfer group ownership](/sdk/react-native/group/managing-group-members/transfer-group-owner) before leaving.

## Return value

A resolved Promise confirms that the current user has left the group on the server.

Leaving the group triggers `OnJoinedGroupDeleted` on the departing client and `OnGroupMemberDeleted` for remaining members. Use `groupID` to remove the group from the local joined groups list and clear group conversation state. For full event listeners, see [Group overview](/sdk/react-native/group/overview-group).
