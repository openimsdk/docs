通话建立后或通话进行中，可以调用接口挂断并退出通话房间。

```ts
await OpenIMSDK.signalingHungUp({
  opUserID: currentUserID,
  invitation,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `opUserID` | `string` | 是 | 当前挂断通话的操作用户 ID。 |
| `invitation` | `RtcInvite` | 是 | 本次通话的完整通话邀请对象，其中的 `roomID` 应与当前通话房间一致。 |

## 返回结果

调用完成后，挂断请求已处理完成。

其他参与者会通过 `OnHangUp` 事件收到挂断通知；客户端应使用 `roomID` 标识通话房间并清理本地音视频通话状态。完整事件监听说明见[处理通话事件](/sdk/react-native/calling/managing-calls/handle-call-events)。
