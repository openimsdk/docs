---
title: '挂断通话'
description: '结束已经建立的音频或视频通话。'
sourcePath: '/sdk/harmony/calling/managing-calls/hang-up-call'
---

```ts
import sdk, { SignalingHungUpReq } from '@openimsdk/imsdk';

const request: SignalingHungUpReq = {
  invitation: invitation,
  offlinePush: offlinePush,
  userID: peerUserID,
};
await sdk.signalingHungUp(request);
```

完整邀请中的 `roomID` 必须与当前媒体房间一致。Promise 成功表示挂断信令已发送完成，客户端可根据 `roomID` 结束本地通话，停止音视频采集、离开媒体房间并释放硬件资源；对端收到挂断事件后完成退出，完整事件监听请参考[处理通话事件](/sdk/harmony/calling/managing-calls/handle-call-events)。取消、拒绝、超时和挂断建议共用幂等的本地清理流程。
