`getSignalingInvitationInfoStartApp()` 用于在应用启动或恢复时获取未处理的通话邀请。

```java
OpenIMClient.getInstance().signalingManager.getSignalingInvitationInfoStartApp(
    new OnBase<SignalingInfo>() {
        @Override
        public void onSuccess(SignalingInfo info) {
            if (info != null
                && info.getInvitation() != null
                && info.getInvitation().getRoomID() != null
                && !info.getInvitation().getRoomID().isEmpty()) {
                restoreIncomingCall(info);
            }
        }

        @Override
        public void onError(int code, String error) {
            clearExpiredIncomingCall();
        }
    }
);
```

成功回调返回的是调用时的邀请快照，不会接通通话，仍需自行处理取消、超时、接受通话邀请。
