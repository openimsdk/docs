The OpenIM iOS SDK identifies users using unique `userID` strings. When developing profile cards, contact lists, friend management workflows, or blocklists, differentiate between public user identities, mutual friend relationships, and blacklist states.

Group member rosters, group-specific nicknames, role levels, and member permissions belong to the group domain. For group member management, refer to [Retrieve group members](/sdk/ios/group/retrieving-group-members/overview-retrieving-group-members).

## User data models

The OpenIM iOS SDK models user information through dedicated data objects depending on the business scenario:

| Model | Applicable scenario | Recommended documentation |
| --- | --- | --- |
| `OIMUserInfo` | The logged-in user's profile, settings views, personal avatar, nickname, and global message reception preferences. | [View your profile](/sdk/ios/user/retrieving-and-updating-user-information/get-self-profile), [Update your profile](/sdk/ios/user/retrieving-and-updating-user-information/update-self-profile) |
| `OIMPublicUserInfo` | Looking up application users, finding friend candidates, and displaying stranger profile cards. | [Retrieve public profiles by user ID](/sdk/ios/user/retrieving-users/retrieve-users) |
| `OIMFriendInfo` | The current user's friend list, custom friend remarks, and relationship extension metadata. | [Retrieve the friend list by page](/sdk/ios/user/friends/get-friend-list-page), [Retrieve specified friends](/sdk/ios/user/friends/get-specified-friends-info) |
| `OIMBlackInfo` | Users added to the current user's blacklist. | [Retrieve the blocklist](/sdk/ios/user/moderating-a-user/retrieve-a-list-of-blocked-users), [Block a user](/sdk/ios/user/moderating-a-user/block-user), [Unblock a user](/sdk/ios/user/moderating-a-user/unblock-user) |
| `OIMUserStatusInfo` | Real-time presence status and active platform indicators for target users. | [Subscribe to user status](/sdk/ios/user/retrieving-and-updating-user-information/subscribe-user-status) |

A single `userID` can exist across public directory entries, friend relationships, blocklists, and group rosters. Prioritize `OIMFriendInfo` when displaying contacts, `OIMPublicUserInfo` for general directory entries, and `OIMGroupMemberInfo` within group contexts. Conversation titles and message header labels derive from `OIMConversationInfo.showName`.

## State synchronization

User domain events are observed and merged using `userID` as the unique entity merge identifier:

- **Self profile changes**: [Update your profile](/sdk/ios/user/retrieving-and-updating-user-information/update-self-profile).
- **Friend application updates**: [Retrieve received friend requests](/sdk/ios/user/friend-applications/get-friend-application-list-as-recipient).
- **Friend relationships and profile changes**: [Retrieve the friend list by page](/sdk/ios/user/friends/get-friend-list-page).
- **Blacklist updates**: [Block a user](/sdk/ios/user/moderating-a-user/block-user).
- **Online status changes**: [Subscribe to user status](/sdk/ios/user/retrieving-and-updating-user-information/subscribe-user-status).

Fetch initial data snapshots via query APIs, then register domain delegates to merge real-time incremental updates into local caches and views.
