构建包含结构化富文本实体（如超链接、自定义标签等）的消息对象。通过 `RichMessage` 列表标记正文中特定偏移量（`offset`）与长度（`length`）的文本片段，使接收端可以高亮渲染或绑定点击交互。

```java
RichMessage link = new RichMessage();
link.setType("link");
link.setOffset(0);
link.setLength(6);
link.setUrl("https://docs.openim.io");
link.setInfo("{\"title\":\"OpenIM documentation\"}");

Message message = OpenIMClient.getInstance().messageManager.createAdvancedTextMessage(
    "OpenIM 文档链接",
    Collections.singletonList(link)
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `text` | `String` | 是 | 完整的富文本消息正文。 |
| `richMessages` | `List<RichMessage>` | 是 | 富文本实体定义列表。每个实体包含 `type`（类型）、`offset`（字符偏移量）、`length`（实体跨度长度）、`url`（跳转链接）以及 `info`（自定义元数据）。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.ADVANCED_TEXT`。

本方法只在本地构造消息对象，不会自动发送。构建完成后，请调用[发送消息](/sdk/android/message/sending-messages/send-message)进行投递。
