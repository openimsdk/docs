Call `changeGroupMute()` to enable or disable group-wide muting.

```ts
await OpenIMSDK.changeGroupMute({
  groupID,
  isMute: true,
  muteBypassUserIDs: [serviceAccountUserID],
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- |
| `groupID` | `string` | Yes | ID of the target group. |
| `isMute` | `boolean` | Yes | Use `true` to enable group-wide muting or `false` to disable it. |
| `muteBypassUserIDs` <span className="enterprise-field-badge">Enterprise</span> | `string[]` | No | User IDs that can still send messages while the group is muted. |

Do not add every member to `muteBypassUserIDs`. The server controls whether the group owner and administrators can send messages.

## Return value

When the call completes, the group-wide mute setting is updated. Group profile changes trigger `OnGroupInfoChanged`; see [Group overview](/sdk/react-native/group/overview-group) for event handling.
