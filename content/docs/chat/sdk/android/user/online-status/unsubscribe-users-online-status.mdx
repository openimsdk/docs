Cancel online-status subscriptions when users leave the visible range, the screen closes, or the account changes. Remove empty and duplicate IDs before making the call.

```java
List<String> userIDs = Arrays.asList("user_a", "user_b");

OpenIMClient.getInstance().userInfoManager.unsubscribeOnlineUsersStatus(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            for (String userID : userIDs) {
                presenceByUserID.remove(userID);
            }
        }

        @Override
        public void onError(int code, String error) {
            recordStatusUnsubscribeFailure(code, error);
        }
    },
    userIDs
);
```

A successful callback means that the unsubscribe request completed. Only then remove the IDs from the application's subscription set and presence cache. Retain the previous state after an error so the operation can be retried. This operation does not change user profiles or friend relationships.

Call [Subscribe to user online status](/sdk/android/user/online-status/subscribe-users-online-status) when those users need to be tracked again.
