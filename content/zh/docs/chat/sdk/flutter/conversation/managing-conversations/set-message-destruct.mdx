开启或关闭会话消息在服务端自动定期销毁的策略，并配置销毁时长。该能力用于控制服务端消息存储周期，与客户端阅读即焚功能相互独立：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 目标会话 ID。 |
| `req` | `ConversationReq` | 是 | 会话修改请求对象。`isMsgDestruct` 控制是否开启定期销毁，`msgDestructTime` 指定销毁周期（单位为秒，例如 `3600` 秒即 1 小时）。 |

```dart
await OpenIM.iMManager.conversationManager.setConversation(
  conversationID,
  ConversationReq(
    isMsgDestruct: true,
    msgDestructTime: 3600,
  ),
);
```

## 返回结果

Future 成功表示定期销毁策略已设置完成。关闭此能力时将 `isMsgDestruct` 设为 `false` 即可。

多端同步或事件到达时通过会话变更事件通知。客户端以 `conversationID` 为合并标识更新对应会话的定期销毁配置，完整事件监听请参考[获取会话列表](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list)。
