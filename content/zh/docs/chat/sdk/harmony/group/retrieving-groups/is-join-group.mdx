---
title: '检查是否已加入群组'
description: '检查指定用户是否已加入目标群组。'
sourcePath: '/sdk/harmony/group/retrieving-groups/is-join-group'
---

HarmonyOS 接口同时接收群组 ID 和用户 ID，因此既可查询当前账号，也可在有权限的场景检查其他用户。

```ts
import sdk, { IsJoinGroupReq, IsJoinGroupResp } from '@openimsdk/imsdk';

const request: IsJoinGroupReq = {
  groupID: groupID,
  userID: currentUserID,
};
const response: IsJoinGroupResp = await sdk.isJoinGroup(request);
if (response.joined) {
  showGroupMemberActions();
}
```

该方法只查询调用时的成员关系，不会触发群组事件。需要持续维护当前账号状态时，同时处理加入、退出和解散事件，并在重连或关键操作后重新查询。
