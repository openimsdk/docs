同意对端用户发来的好友申请，正式建立好友关系：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `userID` | `String` | 是 | 提出好友申请的对方用户 ID。 |
| `handleMsg` | `String` | 否 | 同意申请时的备注附言。 |

```dart
await OpenIM.iMManager.friendshipManager.acceptFriendApplication(
  userID: applicantUserID,
  handleMsg: '已通过',
);
```

## 返回结果

Future 成功表示服务端已完成同意好友申请的处理，双方已建立好友关系。

操作成功后，申请状态按申请方 `userID` 更新为已通过，本地好友列表应通过 `userID` 合并新好友。后续各端会收到好友申请变更通知及好友添加通知。申请记录维护请参考[获取收到的好友申请](/sdk/flutter/user/friend-applications/get-friend-application-list-as-recipient)，好友列表管理请参考[分页获取好友列表](/sdk/flutter/user/friends/get-friend-list-page)。
