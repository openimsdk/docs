---
title: '取消订阅用户状态'
description: '使用 unsubscribeOnlineUsersStatus 取消指定用户的在线状态订阅。'
sourcePath: '/sdk/android/user/online-status/unsubscribe-users-online-status'
---

用户离开可见范围、页面结束或切换账号时，取消不再需要的在线状态订阅。调用前应去除空值和重复 ID。

```java
List<String> userIDs = Arrays.asList("user_a", "user_b");

OpenIMClient.getInstance().userInfoManager.unsubscribeOnlineUsersStatus(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 取消订阅成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    userIDs
);
```

成功 callback 表示取消订阅请求已完成。

需要再次跟踪用户状态时，重新调用[订阅用户在线状态](/sdk/android/user/online-status/subscribe-users-online-status)。
