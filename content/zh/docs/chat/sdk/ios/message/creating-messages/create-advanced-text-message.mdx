调用创建富文本消息方法可构建包含高亮实体（如超链接、高亮标签等）的高级文本消息对象。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createAdvancedTextMessage:text
                            messageEntityList:entities];
```

## 参数说明

- `text`：完整的富文本消息正文（`NSString *`）。
- `messageEntityList`：富文本实体对象列表（`NSArray<OIMMessageEntity *> *`）。每个实体对象包含 `type`、`offset`、`length` 和扩展 URL 等字段。

## 返回结果

- 返回初始化的富文本消息对象（`OIMMessageInfo *`），其内容类型为高级文本。
- 构造实体时，`offset` 与 `length` 必须与正文中的字符范围精确匹配。创建后需调用[发送消息](/sdk/ios/message/sending-messages/send-message)进行投递。
