```dart
await OpenIM.iMManager.conversationManager.setConversation(
  conversationID,
  ConversationReq(isPinned: true),
);
```

Pass `true` to pin the conversation and `false` to unpin it. This state affects only the current user's conversation list.

A successful `Future` does not mean that `onConversationChanged` has already arrived. Merge the latest conversation by `conversationID`; see [Retrieve the conversation list](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list) for the complete listener.
