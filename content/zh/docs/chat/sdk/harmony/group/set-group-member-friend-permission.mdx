---
title: '设置群内添加好友权限'
description: '控制成员能否通过群组向其他成员发送好友申请。'
sourcePath: '/sdk/harmony/group/set-group-member-friend-permission'
---

该设置只控制通过群成员关系发起好友申请，不等同于隐藏成员资料，也不会删除已有好友关系。

```ts
import sdk, { GroupApplyMemberFriend, SetGroupInfoReq } from '@openimsdk/imsdk';

const request: SetGroupInfoReq = {
  groupID: groupID,
  applyMemberFriend: GroupApplyMemberFriend.AllowGroupApplyMemberFriend,
};
await sdk.setGroupInfo(request);
```

如需禁止，传 `ProhibitGroupApplyMemberFriend`。Promise 成功后，通过群资料事件或重新查询更新界面。
