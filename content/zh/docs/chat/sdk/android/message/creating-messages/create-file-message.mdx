基于相对于 SDK 初始化数据目录的相对文件路径创建普通文件消息对象。在调用[发送消息](/sdk/android/message/sending-messages/send-message)时，SDK 会自动上传文件并计算进度。

```java
String filePath = "documents/annual_report.pdf";
String fileName = "年度汇报.pdf";

Message message = OpenIMClient.getInstance().messageManager.createFileMessage(
    filePath,
    fileName
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `filePath` | `String` | 是 | 文件相对于 SDK 初始化数据目录的相对文件路径。 |
| `fileName` | `String` | 是 | 文件的原始显示名称（如 `年度汇报.pdf`），用于接收端展示与保存。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.FILE`。

构建完成后，请调用[发送消息](/sdk/android/message/sending-messages/send-message)投递至单聊或群聊。若使用本地绝对路径创建，请参阅[使用本地路径创建文件消息](/sdk/android/message/creating-messages/create-file-message-by-file)。
