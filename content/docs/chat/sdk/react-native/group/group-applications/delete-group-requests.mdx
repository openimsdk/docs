Batch purge group join application records from the local history list. This operation cleans up record entries only; it does not approve or reject applications:

```ts
await OpenIMSDK.deleteGroupRequests([
  {
    fromUserID: application.userID,
    groupID: application.groupID,
  },
]);
```

## Parameters

Accepts an array of group request identifiers:

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `fromUserID` | `string` | Yes | Applicant user ID (corresponds to `application.userID`). |
| `groupID` | `string` | Yes | Target group ID of the application. |

Deleting records does not change the approval status of a pending request. To process applications, see [Accept a group application](/sdk/react-native/group/group-applications/accept-group-application) and [Refuse a group application](/sdk/react-native/group/group-applications/refuse-group-application).

## Return value

A resolved Promise confirms that the group request records were deleted on the server.

Deletion triggers the `OnGroupApplicationDeleted` event. Remove items from your local application list using the composite key `groupID:fromUserID`. For event details, see [Get received group applications](/sdk/react-native/group/group-applications/get-group-application-list-as-recipient).
