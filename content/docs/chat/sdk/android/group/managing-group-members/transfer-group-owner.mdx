The target user must already be a group member. Require explicit confirmation before transferring ownership, then retrieve the owner and administrator profiles again after completion.

```java
OpenIMClient.getInstance().groupManager.transferGroupOwner(new OnBase<String>() {
    @Override public void onSuccess(String data) { markOwnershipTransferSubmitted(groupID); }
    @Override public void onError(int code, String error) { showTransferError(error); }
}, groupID, newOwnerUserID);
```

`onGroupMemberInfoChanged` and group profile changes can arrive asynchronously. Do not assume that local roles have already been updated inside the success callback.
