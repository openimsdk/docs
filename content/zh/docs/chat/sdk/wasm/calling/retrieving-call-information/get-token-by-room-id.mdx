title: '获取通话房间 Token'
description: '使用 WASM SDK 按房间 ID 重新获取入会凭据。'
sourcePath: '/sdk/wasm/calling/retrieving-call-information/get-token-by-room-id'
---

已经知道 `roomID`、但需要重新获取入会凭据时，调用 `signalingGetTokenByRoomID()`：

```ts
const { data: roomCredentials } =
  await openimsdk.signalingGetTokenByRoomID(roomID);

await mediaEngine.join({
  roomID,
  token: roomCredentials.token,
  liveURL: roomCredentials.liveURL,
});
```

Promise 成功后，`data` 是 `SignalingTokenResult`，包含 `token` 和 `liveURL`，不重复返回 `roomID`。只有取得有效 Token 后，才能使用本次查询参数中的 `roomID` 连接媒体引擎。

没有取得有效 Token 时，不应继续进入媒体房间；需要时可重新调用本接口获取。
