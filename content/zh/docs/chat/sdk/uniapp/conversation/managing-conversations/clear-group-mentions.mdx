---
title: '重置群聊 @ 状态'
description: '在用户处理群聊中的 @ 消息后重置会话提醒状态。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/clear-group-mentions'
---

用户处理完群聊中的 @ 消息后，可以使用 `OpenIMGroupMentionTypeNormal` 把该会话的 `groupAtType` 重置为普通状态。

```uts
import {
  OpenIMGroupMentionTypeNormal,
  setConversation,
} from '@/uni_modules/unix-openim-sdk'

await setConversation({
  conversationID,
  groupAtType: OpenIMGroupMentionTypeNormal,
})
```

`groupAtType` 是 SDK 根据群消息维护的提醒状态。本操作只负责重置为普通状态，不应用来伪造“@我”或“@所有人”等未发生的状态。重置群聊 @ 状态与标记消息已读是两个不同操作。

Promise 成功表示设置请求已经完成；收到 `onConversationChanged()` 后，再按 `conversationID` 更新界面中的会话状态。完整监听见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。
