由群主解散指定群组：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupID` | `NSString *` | 待解散的目标群组 ID。只有群主有权解散群组。 |

```objc
[[OIMManager manager] dismissGroup:groupID
    onSuccess:^(NSString * _Nullable data) {
        [self showDismissed];
    }
    onFailure:^(NSInteger code, NSString *message) {
        [self showErrorCode:code message:message];
    }];
```

状态以 `groupID` 为合并标识。解散群组会彻底销毁群实体，不同于仅清理本地记录的删除或隐藏会话操作。

## 返回结果

成功回调 `onSuccess` 表示服务端已处理群解散操作。群内成员及各端将收到群组解散事件通知并更新群列表与聊天会话状态，完整事件处理见[群组概览](/sdk/ios/group/overview-group)。
