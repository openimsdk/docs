当业务层已自行将录制的音频文件上传至自有服务器或对象存储时，可调用通过 URL 创建音频消息方法直接生成语音消息对象，避免 SDK 再次执行上传。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createSoundMessageByURL:uploadedURL
                                   duration:durationSeconds
                                       size:uploadedSize];
```

## 参数说明

- `soundURL`：已上传的远端音频文件可访问 URL（`NSString *`）。
- `duration`：音频播放时长（单位：秒）。
- `size`：音频文件的实际字节大小。

## 返回结果

- 返回包含远端 URL 的语音消息对象（`OIMMessageInfo *`）。所传的 URL、时长和文件大小必须来自真实上传数据。
- 由于媒体资源已由业务自行上传，后续需调用[发送不经 OSS 的消息](/sdk/ios/message/sending-messages/send-message-not-oss)直接完成消息发送。若需由 SDK 托管上传本地音频，见[使用本地路径创建音频消息](/sdk/ios/message/creating-messages/create-sound-message-from-full-path)。
