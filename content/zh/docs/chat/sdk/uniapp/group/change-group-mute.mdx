---
title: '设置群组全员禁言'
description: '开启或关闭指定群组的整体禁言状态。'
sourcePath: '/sdk/uniapp/group/change-group-mute'
---

设置群组整体禁言状态。群主和管理员可根据服务端配置的权限执行全员禁言或解除全员禁言。

```uts
import { changeGroupMute } from '@/uni_modules/unix-openim-sdk'

await changeGroupMute({
  groupID,
  isMute: true,
})
```

`isMute` 为 `true` 时开启全员禁言，为 `false` 时关闭。群主和管理员通常仍可发送消息，因此全员禁言不表示每一位成员都无法发言。

该方法的参数只有 `groupID` 和 `isMute`，不支持通过 `muteBypassUserIDs` 设置全员禁言例外名单。

Promise 成功表示设置请求已完成。客户端可先将本地对应群组的禁言状态更新为目标值，收到群资料变更事件后，按 `groupID` 确认最新状态；需要校准状态时可使用[查询指定群组资料](/sdk/uniapp/group/retrieving-groups/get-specified-groups-info)重新拉取。完整群组事件监听见[群组概览](/sdk/uniapp/group/overview-group)。
