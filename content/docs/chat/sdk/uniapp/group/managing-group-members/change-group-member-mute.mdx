Invoke `changeGroupMemberMute()` to mute or unmute a specific group member.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group identifier. |
| `userID` | `string` | Yes | Target member user ID. |
| `mutedSeconds` | `number` | Yes | Mute duration in seconds; pass `0` to lift the mute. |

The group owner can mute administrators and regular members; administrators can mute only regular members. Final permissions are authoritatively enforced by OpenIMServer.

## Code example

```uts
import { changeGroupMemberMute } from '@/uni_modules/unix-openim-sdk'

await changeGroupMemberMute({
  groupID: groupID,
  userID: targetUserID,
  mutedSeconds: 3600,
})
```

## Return value

The Promise resolves with `void` once OpenIMServer updates the member mute duration.

## State changes after the call

A resolved Promise confirms that the request completed on the server. The member's final mute state is determined by the `muteEndTime` Unix timestamp in their member profile rather than local seconds calculations. Connected clients receive `onGroupMemberInfoChanged`, at which point the UI updates the member's mute expiration matching `groupID:userID`. For complete member event handling, see [Get group member list](/sdk/uniapp/group/retrieving-group-members/get-group-member-list).
