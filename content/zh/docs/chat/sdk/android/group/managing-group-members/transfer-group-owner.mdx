---
title: '转让群主'
description: '使用 transferGroupOwner 将群主身份转让给指定群成员。'
sourcePath: '/sdk/android/group/managing-group-members/transfer-group-owner'
---

`transferGroupOwner()` 接收 `groupID` 和 `newOwnerUserID` 两个参数：`groupID` 为要转让群主的群组 ID，`newOwnerUserID` 为新群主的用户 ID，该用户必须是该群的成员。

```java
OpenIMClient.getInstance().groupManager.transferGroupOwner(new OnBase<String>() {
    @Override public void onSuccess(String data) { /* 请求已完成。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
}, groupID, newOwnerUserID);
```

转让成功后，可以重新调用[获取群主和管理员](/sdk/android/group/retrieving-group-members/get-group-member-owner-and-admin)获取最新资料。
