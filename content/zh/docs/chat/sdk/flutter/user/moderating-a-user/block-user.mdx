```dart
await OpenIM.iMManager.friendshipManager.addBlacklist(
  userID: targetUserID,
  ex: '{"source":"profile-menu"}',
);
```

黑名单是单向关系：对方不能向当前用户发送消息，但当前用户仍可能向对方发送。`ex` 是完整字符串。Future 成功不等于事件已到达。

`onBlackAdded` 是本页归属事件，应纳入唯一 `OnFriendshipListener`，按 `userID` 写入或覆盖记录。
