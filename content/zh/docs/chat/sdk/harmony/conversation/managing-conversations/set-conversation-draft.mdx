---
title: '设置会话草稿'
description: '保存或清空指定会话的输入草稿。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/set-conversation-draft'
---

输入过程中先维护编辑器状态并对保存做防抖，离开页面前再提交最新内容。

```ts
import sdk, { SetConversationDraftReq } from '@openimsdk/imsdk';

const request: SetConversationDraftReq = {
  conversationID: conversationID,
  draftText: editorValue,
};
await sdk.setConversationDraft(request);
```

传入空字符串可清空会话草稿。接口调用成功后，SDK 会触发会话变更事件；客户端收到通知后根据 `conversationID` 更新对应会话的 `draftText` 与 `draftTextTime`，完整监听配置请参考[获取会话列表](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list)。切换账号时应同步清理编辑器内存中的输入状态。
