---
title: '检查语音识别能力'
description: '使用 Flutter SDK 检查当前部署是否支持语音识别。'
sourcePath: '/sdk/flutter/message/composing-messages/check-speech-to-text'
---

```dart
try {
  await OpenIM.iMManager.messageManager.speechToTextCapabilities();
  setTranscriptionAvailable(true);
} catch (error) {
  setTranscriptionAvailable(false);
}
```

该方法返回 `Future<void>`。成功只表示可以继续展示转写入口，不会返回格式、采样率、时长或大小字段。精确限制应来自与部署一致的业务配置，不能虚构能力对象。
