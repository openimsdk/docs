After the user has handled the @ mentions in a group chat, reset that conversation's `groupAtType`:

```objc
[[OIMManager manager] resetConversationGroupAtType:conversationID
                                         onSuccess:nil
                                         onFailure:nil];
```

Group-mention state and message read state are separate. A successful callback, arrival of `onConversationChanged:`, and a reconciliation query are three distinct stages. Query the conversation again when the state must be confirmed immediately.
