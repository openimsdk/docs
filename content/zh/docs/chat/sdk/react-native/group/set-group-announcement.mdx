发布或更新群公告内容。

```ts
await OpenIMSDK.setGroupInfo({
  groupID,
  notification: announcement,
});
```

## 参数说明

`groupID` 为目标群组 ID，`notification` 为公告文本内容。传入空字符串可以清空群公告；群公告与群简介 `introduction` 为两个独立字段。

## 返回结果

调用完成后，群公告修改已生效。

群资料变化会通过 `OnGroupInfoChanged` 事件通知群内成员。客户端应以 `groupID` 为合并标识更新对应群组的 `notification` 字段。完整事件监听说明见[群组概览](/sdk/react-native/group/overview-group)。
