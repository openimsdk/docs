---
title: '查询群消息已读成员'
description: '分页查询群消息的已读或未读成员。'
sourcePath: '/sdk/harmony/message/managing-read-status/get-group-message-readers'
---

使用 `conversationID` 和 `clientMsgID` 定位目标群消息。

```ts
import sdk, { GetGroupMessageReaderListReq, GetGroupMessageReaderListResp } from '@openimsdk/imsdk';

const request: GetGroupMessageReaderListReq = {
  conversationID: conversationID,
  clientMsgID: message.clientMsgID,
  filter: 0,
  offset: 0,
  count: 50,
};
const response: GetGroupMessageReaderListResp = await sdk.getGroupMessageReaderList(request);
const readers = response.readers;
```

`filter: 0` 查询已读成员，`1` 查询未读成员。客户端按 `groupID:userID` 去重；接口使用偏移量分页，返回数量小于 `count` 时可视为到达末尾。查询只返回调用时的成员快照，不触发回执事件；上报群消息已读请参考 [上报群消息已读](/sdk/harmony/message/managing-read-status/send-group-read-receipts)。
