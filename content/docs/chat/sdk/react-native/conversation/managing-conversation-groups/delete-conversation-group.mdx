Delete a conversation group and dissolve its conversation associations. This operation only deletes the group category; it does not delete conversations or message histories:

```ts
await OpenIMSDK.deleteConversationGroup(conversationGroupID);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationGroupID` | `string` | Yes | Target conversation group ID to delete. |

## Return value

A resolved Promise confirms that the conversation group was deleted from the server.

Deletion triggers the `OnConversationGroupDeleted` event. Remove the conversation group entry matching `conversationGroupID` from local UI lists. For full event listeners, see [Conversation groups overview](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups).
