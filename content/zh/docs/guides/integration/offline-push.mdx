在移动端环境中，用户离线、应用被终止或进入后台后，操作系统可能挂起应用进程，使 **OpenIMClientSDK 长连接**无法继续接收消息。为了让用户及时收到通知，需要接入第三方离线推送服务：

- 中国境内环境推荐使用[个推（GeTui）](https://www.getui.com/)。
- 中国境外环境推荐使用 [Firebase Cloud Messaging（FCM）](https://firebase.google.com/)。

## 服务端与客户端配置

完整的 OpenIMSDK 离线推送链路同时涉及 OpenIMServer 和 OpenIMClientSDK 配置。

### 服务端配置

以下 YAML 示例展示如何选择个推或 FCM，并配置相应凭证：

```yaml
# 使用 GeTui 进行离线推送，也可以选择 fcm 或 jpns。
# 请从对应服务商获取配置值。
enable:
  getui:
    pushUrl: https://restapi.getui.com/v2/$appId
    masterSecret:
    appKey:
    intent:
    channelID:
    channelName:
  fcm:
    # filePath 优先；为空时使用 authURL。
    filePath:
    authURL: # 必须以 https 或 http 开头
```
