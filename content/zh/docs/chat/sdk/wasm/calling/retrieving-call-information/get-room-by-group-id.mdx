`signalingGetRoomByGroupID()` 的参数是群组 ID，不是自定义 `roomID`：

```ts
const { data: room } = await openimsdk.signalingGetRoomByGroupID(groupID);

if (room.roomID) {
  renderParticipants(room.participant ?? []);
}
```

## 返回结果

Promise 成功后，`data` 是当前的 `SignalingRoomInfo`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `roomID` | `string` | 当前群通话的房间 ID。 |
| `invitation` | `SignalingInvitation`（可选） | 当前房间对应的完整邀请数据。 |
| `participant` | `SignalingParticipantInfo[]`（可选） | 当前房间的参与者资料。 |

每个 `SignalingParticipantInfo` 都包含 `userInfo: PublicUserItem`，并可能包含当前群组上下文中的 `groupMemberInfo: GroupMemberItem` 和 `groupInfo: GroupItem`。账号资料、群内昵称与群资料属于不同数据源，不要相互覆盖。

Promise 成功但 `data` 中没有可用的 `roomID` 时，表示当前没有可恢复的群通话，不要继续使用旧凭据。Promise 被拒绝时，应根据 `errCode` 区分参数、鉴权、网络或服务端错误；除非当前部署明确约定了“房间不存在”的错误码，否则不要把任意错误都解释为“没有进行中的通话”。

若业务为群通话使用自定义房间 ID，仍需用 `groupID` 调用本方法，再使用返回或已保存的 `roomID` 更新对应通话状态。
