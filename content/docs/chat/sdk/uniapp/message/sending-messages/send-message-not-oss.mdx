```uts
import { sendMessageNotOss } from '@/uni_modules/unix-openim-sdk'

const sent = await sendMessageNotOss({ message, recvID, groupID })
```

Use this only when the message already contains complete remotely accessible media metadata. A local-path message sent through this route may be inaccessible to recipients; use normal `sendMessage()` for local uploads.
