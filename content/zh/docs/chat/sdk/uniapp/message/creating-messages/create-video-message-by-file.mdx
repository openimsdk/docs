`createVideoMessageFromFullPath()` 根据本地视频文件及其封面图创建消息。SDK 字段名使用 `snapshot`，本文统一称为“视频封面图”。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `videoPath` | `string` | 是 | App 原生侧能够读取的视频路径。 |
| `videoType` | `string` | 是 | 视频 MIME 类型，例如 `video/mp4`。 |
| `duration` | `number` | 是 | 视频时长，单位为秒。 |
| `snapshotPath` | `string` | 是 | App 原生侧能够读取的视频封面图路径。 |

```uts
import {
  createVideoMessageFromFullPath,
} from '@/uni_modules/unix-openim-sdk'

const message = await createVideoMessageFromFullPath({
  videoPath: `${uni.env.USER_DATA_PATH}/demo.mp4`,
  videoType: 'video/mp4',
  duration: 18,
  snapshotPath: `${uni.env.USER_DATA_PATH}/demo-cover.jpg`,
})
if (message == null) return
```

视频和封面图路径应使用 POSIX 绝对路径或 `unifile://` URI。若媒体选择或视频处理接口返回临时文件，延后发送前应将两份文件保存到应用数据目录。视频时长使用秒，封面图应与实际视频内容匹配。

Promise 成功后返回 `OpenIMMessageItem | null`。非空结果只创建待发送对象；后续使用[发送消息](/sdk/uniapp/message/sending-messages/send-message)，由 SDK 上传视频、封面图并发送。
