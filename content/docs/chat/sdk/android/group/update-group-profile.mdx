Use `setGroupInfo()` to update a group profile. The request object should contain at least the `groupID` and the fields being changed. Do not use an incomplete local cache to overwrite fields that are not part of the current edit.

```java
GroupInfo update = new GroupInfo();
update.setGroupID(groupID);
update.setGroupName("Mobile project team");
update.setIntroduction("Android and iOS collaboration group");

OpenIMClient.getInstance().groupManager.setGroupInfo(update, new OnBase<String>() {
    @Override public void onSuccess(String data) { markGroupUpdateSubmitted(groupID); }
    @Override public void onError(int code, String error) { showGroupUpdateError(error); }
});
```

Merge the latest profile from `onGroupInfoChanged`. Group announcements and extra data use the same API and are covered on their respective pages.
