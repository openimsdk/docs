---
title: '获取当前用户资料'
description: '使用 getSelfLocalUserInfo() 获取当前登录用户的本地资料。'
sourcePath: '/sdk/android/user/user-profile/get-self-local-user-info'
---

```java
OpenIMClient.getInstance().userInfoManager.getSelfLocalUserInfo(
    new OnBase<LocalUser>() {
        @Override
        public void onSuccess(LocalUser user) {
            // 使用 user 更新当前用户资料
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    }
);
```

完成初始化并登录后调用该方法获取当前账号的本地资料。成功 callback 返回 `LocalUser`，包含 `userID`、`nickname`、`faceURL`、`ex`、`attachedInfo`、`globalRecvMsgOpt` 和 `addFriendPermission` 等字段。

## 返回结果

| 字段                  | 说明                                                           |
| --------------------- | -------------------------------------------------------------- |
| `userID`              | 当前登录用户 ID。                                              |
| `nickname`            | 当前账号昵称。                                                 |
| `faceURL`             | 当前账号头像地址。                                             |
| `ex`                  | 当前账号扩展字符串。                                           |
| `attachedInfo` <span className="enterprise-field-badge">商业版</span> | 附加信息，格式由业务约定。                                     |
| `globalRecvMsgOpt`    | 全局消息接收方式：`0` 正常接收，`1` 不接收，`2` 接收但不提示。 |
| `addFriendPermission` <span className="enterprise-field-badge">商业版</span> | 添加好友权限值，具体含义见[设置好友添加权限](/sdk/android/user/user-profile/set-friend-add-permission)。 |
