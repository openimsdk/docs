---
title: '隐藏会话'
description: '从当前账号的会话列表隐藏指定会话入口。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/hide-a-conversation'
---

```ts
import sdk, { HideConversationReq } from '@openimsdk/imsdk';

const request: HideConversationReq = {
  conversationID: conversationID,
};
await sdk.hideConversation(request);
```

隐藏不会删除好友关系、群组或消息。新消息或重新同步后，会话仍可能再次出现。Promise 成功后可从当前列表移除，再用查询和事件校准。
