Construct an image message object from a file path relative to the SDK initialization data directory. When sending via [Send a message](/sdk/android/message/sending-messages/send-message), the SDK automatically compresses the image and uploads the file.

## Code example

```java
String imagePath = "images/pic_001.jpg"; // Path relative to SDK data directory

Message message = OpenIMClient.getInstance().messageManager.createImageMessage(imagePath);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `imagePath` | `String` | Yes | File path of the image relative to the SDK initialization data directory. |

## Return value

Returns the created `Message` object with `contentType` set to `MessageType.PICTURE`.

## State changes after the call

1. **Local initialization**: Initializes the local `Message` structure without initiating network uploads.
2. **Transmission**: Call [Send a message](/sdk/android/message/sending-messages/send-message) to upload and send the image. For absolute local file paths, see [Create an image message from a local path](/sdk/android/message/creating-messages/create-image-message-by-file).
