---
title: '申请加入群组'
description: '提交入群申请，或在群组无需审核时直接加入。'
sourcePath: '/sdk/uniapp/group/join-group'
---

向指定群组发起加入请求。是否需要管理员审核由群组的 `needVerification` 配置决定，`joinSource` 记录用户发起申请的来源途径。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 目标群组 ID。 |
| `reqMsg` | `string` | 是 | 申请说明；没有说明时传空字符串。 |
| `joinSource` | `OpenIMGroupJoinSource` | 是 | 入群途径，取值见下表。 |
| `ex` | `string` | 否 | 业务扩展字符串。 |

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `OpenIMGroupJoinSourceAdmin` | `1` | 由管理员添加；通常用于管理流程，不作为普通用户自助入口。 |
| `OpenIMGroupJoinSourceInvitation` | `2` | 通过邀请加入。 |
| `OpenIMGroupJoinSourceSearch` | `3` | 通过搜索加入。 |
| `OpenIMGroupJoinSourceQRCode` | `4` | 通过二维码加入。 |

```uts
import {
  OpenIMGroupJoinSourceSearch,
  joinGroup,
} from '@/uni_modules/unix-openim-sdk'

await joinGroup({
  groupID: groupID,
  reqMsg: '申请加入项目讨论组',
  joinSource: OpenIMGroupJoinSourceSearch,
})
```

Promise 成功表示入群请求已发送至服务端。若该群开启了入群验证，调用成功不代表当前用户已成为群成员，须等待管理员审核；审核通过并收到群组加入事件后，按 `groupID` 更新已加入群组列表。完整群组事件监听见[群组概览](/sdk/uniapp/group/overview-group)。

无需审核时也建议以加入事件或重新查询的结果确认最终成员状态，不要仅根据按钮操作修改本地权限。
