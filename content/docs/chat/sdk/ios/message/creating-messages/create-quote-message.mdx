Invoke `createQuoteMessage:message:` on `OIMMessageInfo` to construct a reply message object quoting an existing original message:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `text` | `NSString *` | Yes | Body text of the new reply message. |
| `message` | `OIMMessageInfo *` | Yes | Original message object being quoted, typically obtained from the active conversation list. |

## Code example

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createQuoteMessage:@"Agreed with this approach"
                               message:originalMessage];
```

## Return value

Returns an initialized `OIMMessageInfo` model with its content type set to quoted reply.

## State changes after the call

1. **Local memory instantiation**: This method builds a new in-memory message object and does not mutate the original quoted message.
2. **Subsequent dispatch**: Call [Send a message](/sdk/ios/message/sending-messages/send-message) to deliver the quoted reply.
