批量检查当前用户与指定用户的好友关系。

```ts
const checks = await OpenIMSDK.checkFriend(['user_a', 'user_b']);
```

## 参数说明

传入要检查的目标用户 ID 数组 `string[]`。

## 返回结果

调用完成后返回 `FriendshipInfo[]` 数组，每个元素包含被检查用户的好友状态：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `userID` | `string` | 被检查用户的 ID。 |
| `result` | `number` | 好友关系状态：`1` 表示是好友，`0` 表示非好友。 |

需要判断黑名单关系时，请参考[获取黑名单](/sdk/react-native/user/blacklist/get-black-list)。
