---
title: '创建位置消息'
description: '使用 iOS SDK 创建位置消息。'
sourcePath: '/sdk/ios/message/creating-messages/create-location-message'
---

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createLocationMessage:@"上海市浦东新区"
                                  latitude:31.2304
                                 longitude:121.4737];
```

参数依次是位置描述、纬度和经度。业务应先取得用户授权并按隐私规则控制精度。该 selector 只创建待发送对象。
