将设备上 SDK 可读取的本地音频文件识别为文字。传入本地文件路径，不要传递远端 URL、Base64 数据或上传后的文件名。

```ts
const { text } = await OpenIMSDK.speechToText(filename);
```

## 参数说明

`filename` 是设备本地音频文件的完整路径。

## 返回结果

调用完成后返回包含 `{ text }` 的对象，其中 `text` 为识别出的文本内容。调用前建议先[检查语音识别能力](/sdk/react-native/message/composing-messages/check-speech-to-text)；需要将结果写入当前设备的消息对象中时，请参考[保存本地转写结果](/sdk/react-native/message/composing-messages/save-local-transcript)。
