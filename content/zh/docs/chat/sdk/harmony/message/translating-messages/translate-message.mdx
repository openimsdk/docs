---
title: '翻译消息'
description: '翻译一条已同步消息，并返回带翻译内容的消息对象。'
sourcePath: '/sdk/harmony/message/translating-messages/translate-message'
---

通过会话 ID 和客户端消息 ID 定位消息。

```ts
import sdk, { TranslateMessageReq, TranslateMessageResp } from '@openimsdk/imsdk';

const request: TranslateMessageReq = {
  conversationID: conversationID,
  clientMsgID: message.clientMsgID,
  sourceLanguageCode: 'en',
  targetLanguageCode: 'zh-CN',
};
const response: TranslateMessageResp = await sdk.translateMessage(request);
replaceMessage(response.message.clientMsgID, response.message);
```

源消息必须已经同步到本地。Promise 成功后返回更新后的 `IMMessage`；按 `conversationID:clientMsgID` 替换本地展示项，并保留原文。该调用不代表其他客户端已经获得相同翻译结果。
