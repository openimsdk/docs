---
title: '上报群消息已读'
description: '使用 Android SDK 上报群消息已读回执。'
sourcePath: '/sdk/android/message/managing-read-status/send-group-read-receipts'
---

```java
messageManager.sendGroupMessageReadReceipt(
    conversationID,
    visibleClientMsgIDs,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 已读回执已上报
        }

        @Override
        public void onError(int code, String error) {
            // 处理失败
        }
    }
);
```

同一批消息必须属于目标群会话。成功回调只表示服务端接受上报，不代表其他客户端界面已经更新。会话未读数仍由 `markConversationMessageAsRead` 独立维护。

其他客户端通过 `OnAdvanceMsgListener.onRecvGroupMessageReadReceipt` 接收群消息已读回执：

```java
@Override
public void onRecvGroupMessageReadReceipt(GroupMessageReceipt receipt) {
    handleGroupMessageReadReceipt(receipt);
}
```

需要查询某条群消息的已读或未读成员时，使用[查询群消息已读成员](/sdk/android/message/managing-read-status/get-group-message-readers)。
