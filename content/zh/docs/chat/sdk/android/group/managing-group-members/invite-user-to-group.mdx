邀请一个或多个用户加入指定群组。群组在[设置入群验证方式](/sdk/android/group/set-group-join-verification)中的配置将决定邀请结果：若群组开启了全体验证，受邀用户可能需等待管理员审批；若免验证或允许直接邀请，受邀用户将直接加入群聊。

```java
String groupID = "group_123";
List<String> inviteeUserIDs = Arrays.asList("user_a", "user_b");
String reqMsg = "邀请加入技术讨论群";

OpenIMClient.getInstance().groupManager.inviteUserToGroup(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 邀请请求已处理
        }

        @Override
        public void onError(int code, String error) {
            // 处理邀请失败
        }
    },
    groupID,
    inviteeUserIDs,
    reqMsg
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `groupID` | `String` | 是 | 目标群组全局唯一 ID。 |
| `inviteeUserIDs` | `List<String>` | 是 | 待邀请的用户 ID 列表。传入前建议剔除空值与重复项。 |
| `reqMsg` | `String` | 否 | 邀请附言说明，可传空字符串。 |

## 返回结果

成功回调中的 `data` 返回确认信息。

用户成功加入群聊后，群内各端会触发 `onGroupMemberAdded` 事件，返回新增成员的 `GroupMembersInfo`。客户端应以 `groupID:userID` 为标识增量更新群成员列表；完整监听见[群组概览](/sdk/android/group/overview-group)。
