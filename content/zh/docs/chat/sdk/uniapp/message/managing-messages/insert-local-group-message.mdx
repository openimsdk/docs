title: '插入本地群聊消息'
description: '把业务生成的消息插入群聊本地历史。'
sourcePath: '/sdk/uniapp/message/managing-messages/insert-local-group-message'
---

`insertGroupMessageToLocalStorage()` 只写本机群聊历史。

```uts
import { insertGroupMessageToLocalStorage } from '@/uni_modules/unix-openim-sdk'

await insertGroupMessageToLocalStorage(insertParams)
```

参数使用 `OpenIMInsertGroupMessageParams`，包含群、发送方和消息。它不广播给群成员；需要真实投递使用发送 API。
