Batch reorder conversation groups for the current account:

```ts
await OpenIMSDK.setConversationGroupOrder([
  { conversationGroupID: firstGroupID, order: 100 },
  { conversationGroupID: secondGroupID, order: 200 },
]);
```

## Parameters

Accepts an array of order specification objects:

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationGroupID` | `string` | Yes | Target conversation group ID to reorder. |
| `order` | `number` | Yes | New numeric ordering priority value. |

## Return value

A resolved Promise confirms that the new sort order was saved on the server.

Ordering updates trigger the `OnConversationGroupChanged` event. In local state reconciliation, update the `order` property of each group identified by `conversationGroupID` and re-sort the conversation group list view. For event details, see [Conversation groups overview](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups).
