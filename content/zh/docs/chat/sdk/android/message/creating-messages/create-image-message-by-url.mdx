使用已上传至业务自有云存储或第三方 CDN 的图片 URL 创建图片消息对象。SDK 不会再次对图片执行上传，适用于业务自行管理文件存储的场景。

```java
String sourceURL = "https://example.com/images/origin.jpg";

PictureInfo sourcePicture = new PictureInfo();
sourcePicture.setUrl(sourceURL);
sourcePicture.setWidth(1080);
sourcePicture.setHeight(1920);

PictureInfo bigPicture = sourcePicture;

PictureInfo snapshotPicture = new PictureInfo();
snapshotPicture.setUrl("https://example.com/images/thumb.jpg");
snapshotPicture.setWidth(200);
snapshotPicture.setHeight(355);

Message message = OpenIMClient.getInstance().messageManager.createImageMessageByURL(
    sourceURL,
    sourcePicture,
    bigPicture,
    snapshotPicture
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `sourceURL` | `String` | 是 | 已上传原图的远端可访问 URL。 |
| `sourcePicture` | `PictureInfo` | 是 | 原图信息对象，包含 URL、宽、高以及文件大小等。 |
| `bigPicture` | `PictureInfo` | 是 | 大图信息对象。若未单独生成大图，可直接传入原图信息。 |
| `snapshotPicture` | `PictureInfo` | 是 | 缩略图信息对象，用于聊天列表中快速预览。 |

## 返回结果

返回创建完成的待发送 `Message` 对象，其 `contentType` 为 `MessageType.PICTURE`。

由于图片资源已由外部上传，发送该消息时应调用[发送不经 OSS 的消息](/sdk/android/message/sending-messages/send-message-not-oss)直接投递，避免重复上传。
