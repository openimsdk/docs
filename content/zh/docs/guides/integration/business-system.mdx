## 与现有业务系统集成

即时通讯（IM）已经成为许多应用不可或缺的基础能力。如果你已经拥有业务系统，并希望通过 OpenIMSDK 增加聊天功能，可以按本页说明连接业务账号、业务后端、OpenIMServer 和 OpenIMClientSDK。

![OpenIMSDK 与业务系统关系图](/assets/guides/introduction/assets/relation.png)

在上图中：

- **Your APP Server** 表示现有业务后端，开发语言不限。用户资料和密码校验等业务数据仍由该服务维护。
- **Your APP Client** 表示现有业务客户端，可以使用主流开发框架。

## 业务后端通过 REST API 对接 OpenIMServer

1. **注册新用户：**业务用户注册成功后，调用[创建用户](/platform-api/user/creating-users/create-a-user)接口，在 OpenIMServer 中创建对应用户。
2. **更新用户资料：**用户修改头像、昵称或扩展字段后，调用[更新用户](/platform-api/user/managing-users/update-a-user)接口同步资料。
3. **获取登录 Token：**业务后端完成身份校验后，调用[获取用户 Token](/platform-api/auth/tokens/get-user-token)接口，并将 Token 返回给客户端。
4. **导入存量用户：**正式上线前，通过创建用户接口将现有用户数据导入 OpenIMServer。

## 业务客户端集成 OpenIMClientSDK

1. **完成登录：**客户端从业务后端取得 IM Token 后，调用 OpenIMClientSDK 登录接口。
2. **接入即时通讯能力：**将 OpenIMClientSDK 集成到应用中，按需启用会话、消息、群组和关系链能力。
3. **维护业务资料：**用户资料仍以业务后端为事实源；资料变更后，由业务后端同步到 OpenIMServer。
