从 `onReceiveNewInvitation` 取得原始 `SignalingInfo` 后，使用 `signalingAccept()` 接受邀请：

```java
OpenIMClient.getInstance().signalingManager.signalingAccept(
    new OnBase<SignalingCertificate>() {
        @Override
        public void onSuccess(SignalingCertificate credentials) {
            joinMediaRoom(
                credentials.getRoomID(),
                credentials.getToken(),
                credentials.getLiveURL()
            );
        }

        @Override
        public void onError(int code, String error) {
            showAcceptError(code, error);
        }
    },
    receivedInfo
);
```

`receivedInfo` 必须保留收到的原始 `roomID`、邀请人、被邀请人和会话类型，不能重新构造为只包含 `roomID` 的对象。

成功回调返回 `SignalingCertificate`。取得有效的 `token` 和 `roomID` 后再连接媒体房间；远端状态由[处理通话事件](/sdk/android/calling/managing-calls/handle-call-events)继续合并。
