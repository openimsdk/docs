根据已上传音频的 URL 资源信息创建音频消息。

```ts
const message = await OpenIMSDK.createSoundMessageByURL({
  uuid: 'audio-001',
  soundPath: '',
  sourceUrl: 'https://www.example.com/sound.mp3',
  dataSize: 54000,
  duration: 18,
  soundType: 'audio/mpeg',
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `uuid` | `string` | 是 | 音频唯一资源标识。 |
| `soundPath` | `string` | 是 | 本地音频路径；仅有远端资源时传空字符串。 |
| `sourceUrl` | `string` | 是 | 已上传音频的远端网络地址。 |
| `dataSize` | `number` | 是 | 音频数据大小，单位为字节。 |
| `duration` | `number` | 是 | 音频时长，单位为秒。 |
| `soundType` | `string` | 否 | 音频文件类型（MIME 类型）。 |

## 返回结果

调用完成后返回已创建的 `MessageItem` 消息对象，其中 `soundElem` 保存远端音频信息。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送已上传的媒体消息](/sdk/react-native/message/sending-messages/send-message-not-oss)直接投递该消息，无需重复上传音频文件。
