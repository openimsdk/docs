```objc
[[OIMManager manager] setConversationPrivateChat:conversationID
                                        isPrivate:YES
                                        onSuccess:nil
                                        onFailure:nil];
```

Pass `YES` to enable burn after reading or `NO` to disable it. Set the burn-after-reading duration with the separate method; do not treat the success or event stages of the two requests as one operation. Burn after reading is distinct from periodic deletion of server-side messages.
