会话分组属于商业版能力。`conversationGroupID` 指定目标分组；除 ID 外，只传本次需要修改的字段，并至少提供一个更新字段。

## 参数说明

| 参数                  | 类型      | 是否必填 | 说明                  |
| --------------------- | --------- | -------- | --------------------- |
| `conversationGroupID` | `string`  | 是       | 要更新的会话分组 ID。 |
| `name`                | `string`  | 否       | 新的分组名称。        |
| `ex`                  | `string`  | 否       | 新的完整扩展字符串。  |
| `hidden`              | `boolean` | 否       | 是否隐藏该分组。      |

```ts
import sdk, { UpdateConversationGroupReq, UpdateConversationGroupResp } from '@openimsdk/imsdk';

const request: UpdateConversationGroupReq = {
  conversationGroupID: conversationGroupID,
  name: '重点工作',
  hidden: false,
};
const response: UpdateConversationGroupResp = await sdk.updateConversationGroup(request);
const updatedGroup = response.conversationGroup;
```

Promise 成功后返回更新后的 `IMConversationGroup`。可以先按 `conversationGroupID` 更新本地记录；事件随后到达或连接恢复时，再重新查询分组确认最新状态。
