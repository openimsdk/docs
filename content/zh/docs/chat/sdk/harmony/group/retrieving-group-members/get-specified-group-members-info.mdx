---
title: '查询指定群成员资料'
description: '按用户 ID 查询其在目标群组中的成员资料。'
sourcePath: '/sdk/harmony/group/retrieving-group-members/get-specified-group-members-info'
---

```ts
import sdk, {
  GetSpecifiedGroupMembersInfoReq,
  GetSpecifiedGroupMembersInfoResp,
} from '@openimsdk/imsdk';

const request: GetSpecifiedGroupMembersInfoReq = {
  groupID: groupID,
  userIDs: ['user_001', 'user_002'],
};
const response: GetSpecifiedGroupMembersInfoResp = await sdk.getSpecifiedGroupMembersInfo(request);
const members = response.members;
```

结果数组不保证与输入 ID 按位置一一对应。同一用户在不同群组中的昵称、角色和禁言状态可能不同，应使用 `groupID:userID` 对应和缓存成员资料。查询不会触发成员事件。
