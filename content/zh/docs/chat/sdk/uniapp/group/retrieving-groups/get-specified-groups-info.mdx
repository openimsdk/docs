`getSpecifiedGroupsInfo()` 批量查询群资料。

```uts
import { getSpecifiedGroupsInfo } from '@/uni_modules/unix-openim-sdk'

const result = await getSpecifiedGroupsInfo(['group_a', 'group_b'])
const groups = result?.groups ?? []
```

结果不保证与输入顺序一致，按 `groupID` 映射。未返回群可能不存在、已解散或当前无权访问。大量 ID 分批查询。
