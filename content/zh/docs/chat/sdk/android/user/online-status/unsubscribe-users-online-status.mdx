---
title: '取消订阅用户状态'
description: '取消指定用户的在线状态订阅，停止接收其状态变更通知。'
sourcePath: '/sdk/android/user/online-status/unsubscribe-users-online-status'
---

当用户离开可见范围、页面销毁或切换账号时，取消不再需要的在线状态订阅，避免接收多余的状态变更推送。

```java
List<String> userIDs = Arrays.asList("user_a", "user_b");

OpenIMClient.getInstance().userInfoManager.unsubscribeOnlineUsersStatus(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    userIDs
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `userIDs` | `List<String>` | 是 | 需要取消订阅的目标用户 ID 列表。传入前建议剔除空字符串与重复项。 |

## 返回结果

成功回调中的 `data` 返回确认信息，表示服务端已停止向当前客户端推送对应用户的状态变更。

本地如果维护了在线状态缓存，应根据业务需要决定是否清理对应 `userID` 的状态记录。如需重新接收其状态推送，请再次调用[订阅用户在线状态](/sdk/android/user/online-status/subscribe-users-online-status)。
