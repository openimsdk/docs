创建应用内约定的自定义表情消息。

```ts
const message = await OpenIMSDK.createFaceMessage({
  index: 12,
  data: JSON.stringify({
    url: 'https://www.example.com/emoji.png',
  }),
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `index` | `number` | 是 | 双方约定的表情序号或索引。 |
| `data` | `string` | 是 | 由发送端和接收端共同约定的自定义字符串，用于传递表情资源地址或渲染信息。 |

## 返回结果

调用完成后返回已创建的 `MessageItem` 消息对象，其中 `faceElem` 保存表情数据。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送消息](/sdk/react-native/message/sending-messages/send-message)将消息投递到单聊或群聊会话中。
