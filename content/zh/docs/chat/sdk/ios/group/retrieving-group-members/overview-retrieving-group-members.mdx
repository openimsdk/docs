群成员缓存使用 `groupID:userID` 作为键。本菜单提供分页、指定成员、成员关系、管理角色和搜索方法。

```objc
- (void)startMemberEvents { [[OIMManager callbacker] addGroupListener:self]; }
- (void)stopMemberEvents { [[OIMManager callbacker] removeGroupListener:self]; }
- (void)onGroupMemberAdded:(OIMGroupMemberInfo *)item { [self upsertMember:item]; }
- (void)onGroupMemberDeleted:(OIMGroupMemberInfo *)item { [self removeMember:item]; }
- (void)onGroupMemberInfoChanged:(OIMGroupMemberInfo *)item { [self upsertMember:item]; }
```

分页期间发生增删时，从第一页重新建立快照。
