Retrieve all groups joined by the current logged-in user in a single request. This method takes no parameters and is ideal for initial cache loading or scenarios with a moderate number of groups.

## Code example

```dart
final groups = await OpenIM.iMManager.groupManager.getJoinedGroupList();
```

## Return value

Returns a `Future` resolving to a `List<GroupInfo>` containing all groups joined by the current user.

This method retrieves the subset of groups the user belongs to, not a public group discovery directory. For accounts that belong to a large number of groups or when incremental loading is preferred, use [Retrieve joined groups by page](/sdk/flutter/group/retrieving-groups/get-joined-group-list-page).

## State changes after the call

This query retrieves a point-in-time snapshot and does not trigger event callbacks. For incremental group synchronization and state merging keyed by `groupID`, see [Group overview](/sdk/flutter/group/overview-group).
