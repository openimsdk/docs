`getConversationIDBySessionType()` 根据聊天目标 `sourceId` 和会话类型 `sessionType` 获取 `conversationID`。

```java
String conversationID = OpenIMClient.getInstance().conversationManager
    .getConversationIDBySessionType(
        sourceId,
        ConversationType.SINGLE_CHAT
    );
```

`sourceId` 在单聊中是对方 `userID`，在群聊中是 `groupID`。群聊根据群类型使用 `ConversationType.GROUP_CHAT` 或 `ConversationType.SUPER_GROUP_CHAT`。

返回值是 `String` 类型的 `conversationID`。需要会话资料时调用[查询指定会话](/sdk/android/conversation/retrieving-conversations/get-conversation-by-target)。
