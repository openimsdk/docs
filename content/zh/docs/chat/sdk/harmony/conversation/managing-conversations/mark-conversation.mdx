---
title: '标记或取消标记会话'
description: '设置当前用户对指定会话的标记状态。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/mark-conversation'
---

标记会话属于商业版能力。标记后会话进入会话分组中的内置“标记一组”，无需再调用分组成员 API。

```ts
import sdk, { SetConversationReq } from '@openimsdk/imsdk';

const request: SetConversationReq = {
  conversationID: conversationID,
  isMarked: true,
};
await sdk.setConversation(request);
```

传 `false` 取消标记。标记与置顶相互独立。收到会话变化事件后按 `conversationID` 更新 `isMarked`。
