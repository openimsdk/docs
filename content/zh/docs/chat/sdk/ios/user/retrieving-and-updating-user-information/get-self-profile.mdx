调用获取当前用户资料接口拉取当前登录账号的完整资料快照：

```objc
[[OIMManager manager] getSelfInfoWithOnSuccess:^(OIMUserInfo *user) {
    [profileStore replaceCurrentUser:user];
} onFailure:^(NSInteger code, NSString *message) {
    NSLog(@"getSelfInfo failed: %ld %@", (long)code, message);
}];
```

## 返回结果

成功回调 `onSuccess` 返回当前登录用户的 `OIMUserInfo` 对象，常用属性包括：

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `userID` | `NSString *` | 当前登录用户的用户 ID。 |
| `nickname` | `NSString *` | 用户昵称。 |
| `faceURL` | `NSString *` | 用户头像地址。 |
| `ex` | `NSString *` | 业务扩展字段。 |
| `globalRecvMsgOpt` | `OIMReceiveMessageOpt` | 全局消息接收选项。 |

该查询只拉取当前时刻的数据快照，不触发资料变化 Delegate；若需要修改个人资料，请参阅[更新当前用户资料](/sdk/ios/user/retrieving-and-updating-user-information/update-self-profile)。
