Use `messageManager.clearConversationAndDeleteAllMsg()` for a product action such as “clear chat history”.

```java
OpenIMClient.getInstance().messageManager.clearConversationAndDeleteAllMsg(
    conversationID,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            messageStore.clearConversation(conversationID);
        }

        @Override
        public void onError(int code, String error) {
            recordConversationClearFailure(code, error);
        }
    }
);
```

The conversation entry remains while the current account's messages and summary state are cleared. Clear the visible message list immediately, then reconcile the latest message, summary, and unread state from `onConversationChanged` or a fresh query.
