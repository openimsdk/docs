`OpenIMConversationItem` can expose commercial `isMsgDestruct` and `msgDestructTime`, but the frozen setter cannot write them. Treat them as read-only <span className="enterprise-field-badge">Commercial</span> state. Use an explicitly supported business API to change policy and then reload; client countdown UI is not authoritative deletion.
