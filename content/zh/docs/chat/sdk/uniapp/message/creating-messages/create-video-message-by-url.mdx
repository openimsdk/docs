`createVideoMessageByURL()` 适用于视频和封面图已经由业务上传服务取得远端 URL 的场景。SDK 字段名使用 `snapshot`，本文统一称为“视频封面图”。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `videoPath` | `string` | 否 | 原始视频本地路径；只有远端资源时可以传空字符串。 |
| `videoUUID` | `string` | 否 | 视频资源唯一标识，优先使用上传结果返回的值。 |
| `videoUrl` | `string` | 否 | 已上传视频的可访问地址；创建 URL 型视频消息时应提供。 |
| `videoType` | `string` | 否 | 视频 MIME 类型。 |
| `videoSize` | `number` | 否 | 视频文件大小，单位为字节。 |
| `duration` | `number` | 否 | 视频时长，单位为秒。 |
| `snapshotPath` | `string` | 否 | 原始封面图本地路径；只有远端资源时可以传空字符串。 |
| `snapshotUUID` | `string` | 否 | 封面图资源唯一标识。 |
| `snapshotSize` | `number` | 否 | 封面图大小，单位为字节。 |
| `snapshotUrl` | `string` | 否 | 已上传封面图的可访问地址；创建 URL 型视频消息时应提供。 |
| `snapshotWidth` | `number` | 否 | 封面图宽度，单位为像素。 |
| `snapshotHeight` | `number` | 否 | 封面图高度，单位为像素。 |
| `snapshotType` | `string` | 否 | 封面图 MIME 类型。 |

```uts
import { createVideoMessageByURL } from '@/uni_modules/unix-openim-sdk'

const message = await createVideoMessageByURL({
  videoPath: '',
  videoUUID: uploadedVideo.uuid,
  videoUrl: uploadedVideo.url,
  videoType: 'video/mp4',
  videoSize: uploadedVideo.size,
  duration: 18,
  snapshotPath: '',
  snapshotUUID: uploadedCover.uuid,
  snapshotSize: uploadedCover.size,
  snapshotUrl: uploadedCover.url,
  snapshotWidth: 1280,
  snapshotHeight: 720,
  snapshotType: 'image/jpeg',
})
if (message == null) return
```

接口类型允许字段为空，但能够正常播放和展示的视频消息需要有效的 `videoUrl`、`snapshotUrl`，以及与上传资源一致的大小、类型、尺寸和时长。封面图 MIME 类型的字段名是 `snapshotType`。

Promise 成功只创建待发送对象。后续使用[发送已上传的媒体消息](/sdk/uniapp/message/sending-messages/send-message-not-oss)，避免再次上传视频和封面图。
