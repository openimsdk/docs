---
title: '拒绝通话'
description: '使用 WASM SDK 拒绝通话邀请。'
sourcePath: '/sdk/wasm/calling/managing-calls/reject-call'
---

用户拒绝来电时，将事件中收到的完整邀请数据交给 `signalingReject()`：

```ts
await openimsdk.signalingReject({
  opUserID: currentUserID,
  invitation,
});
```

`opUserID` 是当前执行拒绝操作的用户 ID；`invitation` 应直接使用来电事件中的完整 `SignalingInvitation`，不要只保留 `roomID` 或邀请人等部分字段。

Promise 成功只表示 OpenIMServer 已完成拒绝请求。发起端随后通过 `OnInviteeRejected` 更新界面，完整处理见[通话事件](/sdk/wasm/calling/managing-calls/handle-call-events)。
