---
title: '置顶或取消置顶会话'
description: '设置指定会话在当前用户会话列表中的置顶状态。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/pin-conversation'
---

```ts
import sdk, { SetConversationReq } from '@openimsdk/imsdk';

const request: SetConversationReq = {
  conversationID: conversationID,
  isPinned: true,
};
await sdk.setConversation(request);
```

传 `false` 取消置顶。该状态只影响当前账号的会话排序。Promise 成功后等待会话变化事件，或重新查询会话确认。
