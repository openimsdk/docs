---
title: '检查是否已加入群组'
description: '检查当前用户是否已经加入指定 iOS 群组。'
sourcePath: '/sdk/ios/group/retrieving-groups/is-join-group'
---

```objc
[[OIMManager manager] isJoinedGroup:groupID
    onSuccess:^(BOOL joined) { [self updateJoinedState:joined]; }
    onFailure:^(NSInteger code, NSString *message) { [self showErrorCode:code message:message]; }];
```

成功 callback 的 `joined` 是当前成员关系快照。查询不会触发 delegate；持续变化见[群组概览](/sdk/ios/group/overview-group)。
