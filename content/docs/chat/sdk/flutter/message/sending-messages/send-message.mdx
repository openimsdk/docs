```dart
final sent = await OpenIM.iMManager.messageManager.sendMessage(
  message: message,
  userID: receiverUserID,
  offlinePushInfo: offlinePushInfo,
);
```

For a one-to-one message, set only `userID`; for a group message, set only `groupID`. A message sent with `isOnlineOnly` is not stored in ordinary history. The Future returns the server-confirmed `Message`. Confirm that its `clientMsgID` is non-empty before replacing the local pending item.
