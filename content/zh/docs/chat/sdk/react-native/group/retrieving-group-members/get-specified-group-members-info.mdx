调用 `getSpecifiedGroupMembersInfo()` 查询指定用户在一个群组中的成员资料。

```ts
const members = await OpenIMSDK.getSpecifiedGroupMembersInfo({
  groupID: 'group-001',
  userIDList: ['user-001', 'user-002'],
});
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 目标群组 ID。 |
| `userIDList` | `string[]` | 是 | 要查询的成员用户 ID 数组。 |

## 返回结果

调用完成后返回匹配的 `GroupMemberItem[]`，字段说明见[群组概览](/sdk/react-native/group/overview-group)。
