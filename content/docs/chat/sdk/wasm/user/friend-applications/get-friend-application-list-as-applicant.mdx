Call `getFriendApplicationListAsApplicant()` with `offset` and `count` to page through applications sent by the current user.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `offset` | `number` | Yes | Pagination offset. Pass `0` for the first page. |
| `count` | `number` | Yes | Number of applications to request. |

```ts
const { data: applications } =
  await openimsdk.getFriendApplicationListAsApplicant({
    offset: 0,
    count: 20,
  });
```

After the Promise succeeds, `data` contains the current page of sent `FriendApplicationItem[]`. See [Get received friend applications](/sdk/wasm/user/friend-applications/get-friend-application-list-as-recipient) for field descriptions. The query does not trigger an application event.

When a state change arrives during pagination, use `fromUserID:toUserID` to find the matching application. See [Get received friend applications](/sdk/wasm/user/friend-applications/get-friend-application-list-as-recipient) for the complete listeners.
