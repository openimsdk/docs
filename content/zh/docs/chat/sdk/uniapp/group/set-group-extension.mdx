---
title: '设置群组扩展字段'
description: '设置指定群组的业务扩展字符串。'
sourcePath: '/sdk/uniapp/group/set-group-extension'
---

`ex` 是完整字符串，SDK 不会自动合并其中的 JSON 字段。多个业务模块共用时，应划分稳定命名空间，并在写入前保留其他模块的数据。

```uts
import { setGroupInfo } from '@/uni_modules/unix-openim-sdk'

await setGroupInfo({
  groupID,
  ex: JSON.stringify({ projectID: 'project-42' }),
})
```

示例展示一次完整写入。实际项目已有扩展数据时，应按业务约定解析旧值、合并本次字段，再序列化整个新值。

Promise 成功表示设置请求已完成。客户端可先将本地对应群组的 `ex` 扩展字段更新为目标值，收到群资料变更事件后，按 `groupID` 确认最新状态。完整群组事件监听见[群组概览](/sdk/uniapp/group/overview-group)。
