调用创建转发消息方法可基于一条已存在的历史消息副本生成新的待转发消息对象。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createForwardMessage:sourceMessage];
```

## 参数说明

- `message`：待转发的原始历史消息对象（`OIMMessageInfo *`），通常从已有消息列表中获取。

## 返回结果

- 返回全新的待发送消息对象（`OIMMessageInfo *`）。SDK 会为其生成独立的 `clientMsgID`，不会篡改或影响原始消息的内容和状态。
- 创建转发消息后，需调用[发送消息](/sdk/ios/message/sending-messages/send-message)接口将消息投递至目标单聊或群聊会话中。
