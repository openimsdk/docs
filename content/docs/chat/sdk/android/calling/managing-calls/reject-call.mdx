When the user declines an incoming call, pass the unmodified `SignalingInfo` object received in the invitation event to `signalingReject()`:

## Code example

```java
OpenIMClient.getInstance().signalingManager.signalingReject(
    new OnBase<String>() {
        @Override
        public void onSuccess(String result) {
            // Rejection request completed.
        }

        @Override
        public void onError(int code, String error) {
            // code and error describe the failure.
        }
    },
    signalingInfo
);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | Yes | Callback delivering the asynchronous operation result. |
| `signalingInfo` | `SignalingInfo` | Yes | Complete signaling payload received in the invitation event, preserving the original `roomID`, inviter, and invitees. |

## Return value

The successful callback indicates that the server recorded the call rejection. Dismiss the incoming call ringing screen and cancel notification alerts on the callee client.

## State changes after the call

The caller and other room members receive notification events indicating that the invitation was rejected. Update member statuses in active calling screens using `roomID:userID`. For complete listener registration details, see [Handle call events](/sdk/android/calling/managing-calls/handle-call-events).
