使用业务侧已上传至对象存储的视频与封面截图 URL 及元数据，构建待发送的视频消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `videoElem` | `VideoElem` | 是 | 已上传视频与封面的元数据模型，应包含真实的视频 URL、封面 URL、UUID、字节大小、播放时长与画面尺寸。 |

```dart
final message = await OpenIM.iMManager.messageManager
    .createVideoMessageByURL(videoElem: videoElem);
```

`VideoElem` 中填写的视频和封面图属性必须来自真实的上传结果，以保证接收端能准确显示缩略图并正常播放。

## 返回结果

Future 成功返回待发送的视频消息对象（`Message`），其内容保存在 `videoElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送，也不会触发新消息事件通知。由于视频资源已由业务侧提前上传，构建完成后必须将返回的 `Message` 实例传给[发送不经 OSS 的消息](/sdk/flutter/message/sending-messages/send-message-not-oss)进行投递，避免重复上传。若需由 SDK 上传本地视频，请参考[创建视频消息](/sdk/flutter/message/creating-messages/create-video-message)。
