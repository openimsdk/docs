发布或更新指定群组的公告内容。通过在 `GroupInfo` 中指定 `groupID` 和新的 `notification` 字符串完成更新。更新成功后，服务端会自动记录公告的发布人以及更新时间。

```java
GroupInfo update = new GroupInfo();
update.setGroupID("group_123");
update.setNotification("今晚 20:00 进行版本发布确认。");

OpenIMClient.getInstance().groupManager.setGroupInfo(
    update,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 群公告发布成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理发布失败
        }
    }
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupInfo` | `GroupInfo` | 是 | 群资料对象，必须设置目标 `groupID` 以及新的公告内容 `notification`。 |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |

## 返回结果

成功回调中的 `data` 返回确认信息。

公告更新成功后，群内成员随后会触发 `onGroupInfoChanged` 事件接收更新后的 `GroupInfo`（包含最新的 `notification`、更新时间戳 `notificationUpdateTime` 及更新人 `notificationUserID`）。客户端应以 `groupID` 为标识合并群资料并更新公告展示；完整监听见[群组概览](/sdk/android/group/overview-group)。
