---
title: '识别音频文字'
description: '使用 WASM SDK 将音频识别为文字。'
sourcePath: '/sdk/wasm/message/composing-messages/transcribe-audio'
---

调用 `speechToText()` 可将音频数据转换为文字。在 Web 浏览器环境中，需将音频文件先转码为 Base64 格式字符串再传入调用：

```ts
const { data: result } = await openimsdk.speechToText({
  filename: audioFile.name,
  data: audioBase64,
});
setTranscript(result.text);
```

接口调用成功后返回 `{ text: string }` 识别结果对象。该操作仅执行转写，不会自动修改原始语音消息，亦不会触发消息变更事件。在调用前可先参考[检查语音识别能力](/sdk/wasm/message/composing-messages/check-speech-to-text)校验音频格式与大小；若需将文字结果保存到本地消息，请参考[保存本地转写结果](/sdk/wasm/message/composing-messages/save-local-transcript)。
