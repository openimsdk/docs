Android SDK 仅提供分页版本。`offset` 从 `0` 开始，后续页按已经成功合并的条目数推进；返回为空时停止加载。

```java
OpenIMClient.getInstance().groupManager.getJoinedGroupListPage(new OnBase<List<GroupInfo>>() {
    @Override public void onSuccess(List<GroupInfo> groups) { appendJoinedGroups(groups); }
    @Override public void onError(int code, String error) { showPageError(error); }
}, offset, 20);
```

使用 `onJoinedGroupAdded` 与 `onJoinedGroupDeleted` 合并增量，不要仅依赖已加载分页作为完整群列表。
