```uts
import { setConversation } from '@/uni_modules/unix-openim-sdk'

await setConversation({ conversationID, isPinned: true })
```

Pass only the field being changed; use `false` to unpin. Apply the final `onConversationChanged` snapshot before re-sorting instead of assuming Promise completion defines the final order.
