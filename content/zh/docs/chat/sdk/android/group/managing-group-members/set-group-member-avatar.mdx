更新成员在指定群聊中展示的专属头像。该设置仅作用于当前群聊内部展示，不会影响用户的全局个人资料头像。

```java
SetGroupMemberInfo update = new SetGroupMemberInfo();
update.setGroupID("group_123");
update.setUserID("user_a");
update.setFaceURL("https://example.com/member_avatar.png");

OpenIMClient.getInstance().groupManager.setGroupMemberInfo(
    update,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 群成员头像更新成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理更新失败
        }
    }
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupMemberInfo` | `SetGroupMemberInfo` | 是 | 群成员资料修改对象，必须设置 `groupID`、成员 `userID` 以及新的群内头像地址 `faceURL`。 |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |

## 返回结果

成功回调中的 `data` 返回确认信息。

头像更新成功后，群内成员端随后将收到 `onGroupMemberInfoChanged` 事件通知，返回更新后的 `GroupMembersInfo`。客户端应以 `groupID:userID` 为标识更新群成员头像缓存并刷新界面；完整监听见[群组概览](/sdk/android/group/overview-group)。
