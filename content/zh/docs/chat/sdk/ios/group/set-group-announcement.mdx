---
title: '发布或更新群公告'
description: '使用 iOS SDK 局部更新群组公告。'
sourcePath: '/sdk/ios/group/set-group-announcement'
---

```objc
NSDictionary *changes = @{
    @"groupID": groupID,
    @"notification": announcement
};

[[OIMManager manager] setGroupInfoDictionary:changes
    onSuccess:nil
    onFailure:nil];
```

`notification` 是群公告，与群简介 `introduction` 不同。传入空字符串可清空公告；修改权限最终由 OpenIMServer 校验。

成功 callback、`onGroupInfoChanged:` 到达和重新查询是三个阶段，完整 delegate 见[群组概览](/sdk/ios/group/overview-group)。
