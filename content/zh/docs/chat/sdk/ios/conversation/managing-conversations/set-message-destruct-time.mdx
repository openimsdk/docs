---
title: '设置服务端消息删除周期'
description: '使用 iOS SDK 设置会话服务端消息的定期删除周期。'
sourcePath: '/sdk/ios/conversation/managing-conversations/set-message-destruct-time'
---

```objc
[[OIMManager manager] setConversationMsgDestructTime:conversationID
                                     msgDestructTime:destructTime
                                         onSuccess:nil
                                         onFailure:nil];
```

`msgDestructTime` 是服务端消息的定期删除周期，具体计时语义还应结合服务端策略确认。启用或关闭由独立开关方法完成。成功后从 `OIMConversationInfo.msgDestructTime` 读取最新快照。
