The user domain covers the current profile, public profiles, presence, friendships, friend requests, and blacklist entries. Use stable `userID` values as keys; nicknames and avatars can change.

`OpenIMUserInfo` includes public `userID`, `nickname`, `faceURL`, `ex`, and optional `createTime`. `attachedInfo` and `globalRecvMsgOpt` are <span className="enterprise-field-badge">Commercial</span> extensions and must remain optional. Friend data uses `OpenIMFriendUserItem`, blacklist data uses `OpenIMBlackUserItem`, and requests use `OpenIMFriendApplicationItem`.

Register events before loading a snapshot, then merge both sources idempotently by `userID`. Reload snapshots after reconnection, login, or process restoration; events alone are not a complete database.

- [Subscribe to presence](/sdk/uniapp/user/online-status/subscribe-users-status)

Your application backend remains authoritative for identity and authorization. Chat profiles must not replace account authentication.
