---
title: '发送好友申请'
description: '向指定用户发送好友申请。'
sourcePath: '/sdk/harmony/user/friend-applications/add-friend'
---

发送前避免向自己或已有好友关系的账号重复申请。`reqMsg` 是验证信息，`ex` 是双方业务已约定的扩展字符串。

```ts
import sdk, { AddFriendReq } from '@openimsdk/imsdk';

const request: AddFriendReq = {
  userID: targetUserID,
  reqMsg: verificationMessage,
  ex: '',
};
await sdk.addFriend(request);
```

Promise 成功表示服务端接受申请，不表示对方已经同意，也不能据此直接加入好友列表。发出的申请可参考 [获取发出的好友申请](/sdk/harmony/user/friend-applications/get-friend-application-list-as-applicant)；申请事件监听请参考 [获取收到的好友申请](/sdk/harmony/user/friend-applications/get-friend-application-list-as-recipient)。
