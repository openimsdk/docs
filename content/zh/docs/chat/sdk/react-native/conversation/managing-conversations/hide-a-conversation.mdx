隐藏当前登录账号会话列表中的单个会话。该操作仅在当前设备上隐藏会话项，不删除聊天历史；当该会话收到新消息或产生新交互时，会话将重新出现在列表中。

```ts
await OpenIMSDK.hideConversation(conversationID);
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 要隐藏的会话 ID。 |

## 返回结果

调用完成后，隐藏会话请求已处理完成。

调用成功后，客户端可先从当前会话列表中移除该 `conversationID` 对应的项。后续状态变化或收到新消息时会通过 `OnConversationChanged` 事件通知，客户端应按 `conversationID` 更新或重新展示会话。完整监听方式见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。
