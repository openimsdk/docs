`updateFriends()` 会把同一组修改应用到 `friendUserIDs` 中的所有好友。不同好友需要设置不同内容时，应分别调用。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `friendUserIDs` | `string[]` | 是 | 要更新的好友用户 ID 列表。 |
| `remark` | `string` | 否 | 新的好友备注。 |
| `isPinned` | `boolean` | 否 | 是否在联系人列表中置顶好友。 |
| `ex` | `string` | 否 | 新的好友关系扩展字符串，会完整覆盖旧值。 |

除 `friendUserIDs` 外，至少传入一个确实需要修改的字段。

```uts
import { updateFriends } from '@/uni_modules/unix-openim-sdk'

await updateFriends({
  friendUserIDs: [friendUserID],
  remark: remark.trim(),
  isPinned: true,
})
```

Promise 成功表示本次更新请求已成功返回，不表示好友资料变化事件已经到达。收到 `onFriendInfoChanged()` 后，按事件数据中的 `userID` 更新对应好友；需要校准状态时重新查询好友资料。完整监听见[分页获取好友列表](/sdk/uniapp/user/friends/get-friend-list-page)。`ex` 是完整字符串，SDK 不会自动合并其中的 JSON 字段。
