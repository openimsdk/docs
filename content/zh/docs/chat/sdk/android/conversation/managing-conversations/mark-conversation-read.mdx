当用户进入聊天界面并浏览消息后，可将该会话的所有未读消息标记为已读，清除当前会话的未读计数。请在界面展示完成后调用，避免在仅收到后台通知或悬浮窗预览时提前标记。

```java
OpenIMClient.getInstance().messageManager.markConversationMessageAsRead(
    conversationID,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    }
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 目标会话的唯一标识。 |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |

## 返回结果

成功回调表示已读上报已被服务端成功记录。本地会话的未读数将置零，总未读数同步减少。

接口调用成功后，SDK 会触发 `OnConversationListener.onConversationChanged` 事件更新对应会话；客户端应以 `conversationID` 唯一定位目标会话并刷新未读角标，监听配置请参考[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。

在单聊场景中，对端会收到单聊已读回执事件 `OnAdvanceMsgListener.onRecvC2CReadReceipt`，详细说明请参考[接收消息](/sdk/android/message/receiving-messages/receive-messages)与[消息概览](/sdk/android/message/overview-message)。
