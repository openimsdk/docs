开启或关闭单聊会话的阅后即焚模式。阅后即焚的消息销毁倒计时时长可通过[设置阅后即焚时长](/sdk/react-native/conversation/managing-conversations/set-burn-duration)单独配置。

```ts
await OpenIMSDK.setConversationPrivateChat({
  conversationID,
  isPrivate: true,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 要设置的会话 ID。 |
| `isPrivate` | `boolean` | 是 | `true` 开启阅后即焚，`false` 关闭。 |

## 返回结果

调用完成后，会话的阅后即焚状态已更新。

更新成功后会触发 `OnConversationChanged` 事件；客户端应使用 `conversationID` 定位目标会话，并合并最新的 `isPrivateChat` 状态。完整监听方式见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。
