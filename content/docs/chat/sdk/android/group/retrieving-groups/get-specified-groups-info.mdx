When you already have a set of `groupID` values, use `getGroupsInfo()` to retrieve their profiles. The result is a list of `GroupInfo` objects. Do not assume that its order exactly matches the request list.

```java
OpenIMClient.getInstance().groupManager.getGroupsInfo(new OnBase<List<GroupInfo>>() {
    @Override public void onSuccess(List<GroupInfo> groups) { mergeGroups(groups); }
    @Override public void onError(int code, String error) { showGroupQueryError(error); }
}, groupIDs);
```

Remove empty and duplicate IDs before making the request. Treat groups that do not exist or cannot be accessed as missing results.
