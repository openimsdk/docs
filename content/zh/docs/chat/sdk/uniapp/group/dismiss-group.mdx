---
title: '解散群组'
description: '由群主解散指定群组。'
sourcePath: '/sdk/uniapp/group/dismiss-group'
---

由群主主动解散指定群组。解散操作会作用于全群所有成员，不同于当前账号单方面的退出群组、删除或隐藏会话。

```uts
import { dismissGroup } from '@/uni_modules/unix-openim-sdk'

await dismissGroup(groupID)
```

`groupID` 是要解散的群组 ID。Promise 成功表示服务端已接受解散请求。相关客户端收到群组解散事件后，应按 `groupID` 将群组标记为已解散状态，并禁用继续发送消息或管理成员的入口。完整群组事件监听见[群组概览](/sdk/uniapp/group/overview-group)。

会话是否保留属于会话领域。群组事件处理器不应直接删除会话或历史消息。
