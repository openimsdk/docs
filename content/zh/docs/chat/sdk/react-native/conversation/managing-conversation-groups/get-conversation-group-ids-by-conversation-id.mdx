一个会话可以属于多个会话分组。传入会话 ID 可以获取该会话已归属的全部会话分组。需要查询所有分组或按类型筛选时，可参考[查询会话分组列表](/sdk/react-native/conversation/managing-conversation-groups/get-conversation-groups)。

```ts
const groups = await OpenIMSDK.getConversationGroupByConversationID(conversationID);
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 目标会话 ID，可由单聊或群聊目标生成。 |

## 返回结果

调用完成后返回 `ConversationGroup[]`，每个元素都是一个完整的会话分组对象，包含 `conversationGroupID`、`name` 和 `order` 等属性。查询只返回调用时的快照，不会触发事件；后续分组变化见[会话分组概览](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups)。
