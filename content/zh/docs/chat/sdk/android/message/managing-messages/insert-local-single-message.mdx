将一条构造好的消息直接写入当前设备的单聊本地数据库中。该操作不会触发网络请求向服务端发送消息，也不会同步到其他端或对方设备，常用于插入本地安全提示、系统辅助说明或本地数据迁移。若需真实发送消息，请调用[发送消息](/sdk/android/message/sending-messages/send-message)。

```java
String receiverUserID = "user_b";
String senderUserID = "user_a";

OpenIMClient.getInstance().messageManager.insertSingleMessageToLocalStorage(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 本地写入成功，刷新单聊界面
        }

        @Override
        public void onError(int code, String error) {
            // 写入失败处理
        }
    },
    message,
    receiverUserID,
    senderUserID
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `message` | `Message` | 是 | 待插入的完整消息对象（通常由各 `create*Message` 接口创建）。 |
| `receiver` | `String` | 是 | 单聊接收方的用户 ID。 |
| `sender` | `String` | 是 | 单聊发送方的用户 ID。两字段决定消息方向，不可颠倒。 |

## 返回结果

成功回调中的 `data` 返回确认信息。

写入成功后，客户端应以 `clientMsgID` 为标识将该消息追加至单聊列表进行本地渲染。该操作不触发新消息事件。
