Toggle group-wide muting to silence regular members in a group:

```ts
await OpenIMSDK.changeGroupMute({
  groupID,
  isMute: true,
  muteBypassUserIDs: [serviceAccountUserID],
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group ID to mute or unmute. |
| `isMute` | `boolean` | Yes | Set `true` to enable group-wide muting, or `false` to disable. |
| `muteBypassUserIDs` <span className="enterprise-field-badge">Commercial</span> | `string[]` | No | List of member user IDs permitted to speak even when muting is active. |

Do not pass all group members into `muteBypassUserIDs`. Group owners and administrators bypass muting automatically based on server permissions.

## Return value

A resolved Promise confirms that the group mute setting was applied on the server.

The update triggers the `OnGroupInfoChanged` event. Use `groupID` to update the group's mute status and bypass list in your local state store. For full event listeners, see [Group overview](/sdk/react-native/group/overview-group).
