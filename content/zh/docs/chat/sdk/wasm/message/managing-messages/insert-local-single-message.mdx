## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `message` | `MessageItem` | 是 | 要写入本地数据库的完整消息对象。 |
| `recvID` | `string` | 是 | 单聊接收方的用户 ID。 |
| `sendID` | `string` | 是 | 消息发送方的用户 ID。 |

```ts
const { data: message } = await openimsdk.createTextMessage('本地提示');
await openimsdk.insertSingleMessageToLocalStorage({
  message,
  recvID: targetUserID,
  sendID: currentUserID,
});
```

Promise 成功只表示当前设备本地数据库已写入，不发送消息，也不触发新消息事件。`createTextMessage()` 只是准备参数，其正文归属[创建文本消息](/sdk/wasm/message/creating-messages/create-text-message)页面。
