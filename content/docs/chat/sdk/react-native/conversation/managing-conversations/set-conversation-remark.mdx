Assign a custom alias remark for a conversation visible only to the current account:

```ts
await OpenIMSDK.setConversation({
  conversationID,
  remark: 'Project Discussions',
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `string` | Yes | Target conversation ID to update. |
| `remark` | `string` | No | Custom conversation remark. Pass an empty string `""` to clear the existing remark. |

When rendering conversation titles in the list view, prioritize `remark` over `showName` if present. Setting a conversation remark affects only the conversation display for this account; it does not change the global nickname of a user or group.

## Return value

A resolved Promise confirms that the conversation remark was saved to the server.

The update triggers the `OnConversationChanged` event. Use `conversationID` to identify the conversation entry and update its `remark` field. For event listener details, see [Retrieve conversation list](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list).
