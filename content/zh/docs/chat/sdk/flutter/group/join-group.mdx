---
title: '申请加入群组'
description: '申请加入或直接加入 Flutter 群组。'
sourcePath: '/sdk/flutter/group/join-group'
---

```dart
await OpenIM.iMManager.groupManager.joinGroup(
  groupID: groupID,
  reason: '申请加入项目讨论组',
  joinSource: 3,
);
```

`joinSource` 表示入群来源：`2` 为邀请，`3` 为搜索，`4` 为二维码。群组需要审核时，Future 成功只表示申请已提交；实际加入结果以 `onJoinedGroupAdded` 事件或重新查询的群组信息为准。
