创建普通分组时需要提供名称、顺序值和分组类型；如需同时加入一个已有会话，再传入 `conversationID`。

## 参数说明

| 参数                    | 类型                    | 是否必填 | 说明                                 |
| ----------------------- | ----------------------- | -------- | ------------------------------------ |
| `name`                  | `string`                | 是       | 分组名称。                           |
| `order`                 | `number`                | 是       | 分组顺序值，排序方向由产品统一约定。 |
| `conversationGroupType` | `ConversationGroupType` | 是       | 普通分组或筛选分组。                 |
| `conversationID`        | `string`                | 否       | 创建后立即加入分组的会话 ID。        |
| `ex`                    | `string`                | 否       | 应用约定的分组扩展字符串。           |

```ts
import sdk, {
  ConversationGroupType,
  CreateConversationGroupReq,
  CreateConversationGroupResp,
} from '@openimsdk/imsdk';

const request: CreateConversationGroupReq = {
  name: '工作',
  order: 100,
  conversationGroupType: ConversationGroupType.ConversationGroupTypeNormal,
  conversationID: conversationID,
};
const response: CreateConversationGroupResp = await sdk.createConversationGroup(request);
const group = response.conversationGroup;
```

Promise 成功后返回新建的 `IMConversationGroup`。客户端可使用 `conversationGroupID` 作为合并标识更新本地分组列表；完整的事件监听机制请参考[会话分组概览](/sdk/harmony/conversation/managing-conversation-groups/overview-conversation-groups)，连接恢复后也可重新查询确认最新状态。
