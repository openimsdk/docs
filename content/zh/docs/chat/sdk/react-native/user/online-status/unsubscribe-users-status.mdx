取消订阅指定用户的在线状态。

```ts
await OpenIMSDK.unsubscribeUsersStatus(userIDs);
```

## 参数说明

传入要取消订阅的目标用户 ID 数组 `string[]`。

## 返回结果

调用完成后，指定的在线状态订阅已取消。页面翻页、搜索结果重置、退出登录或不再需要展示这些用户时，应及时取消对应订阅。取消订阅后将不再收到这些用户的在线状态变更事件。
