Group member data is encapsulated in `GroupMembersInfo` objects. Because a user's in-group nickname, role level, and mute duration vary across different groups, manage local caches and merge incremental updates using the composite key `groupID:userID`.

## Query operations

- [Get group member list with pagination](/sdk/flutter/group/retrieving-group-members/get-group-member-list)
- [Get group members info](/sdk/flutter/group/retrieving-group-members/get-group-members-info)
- [Get users in group](/sdk/flutter/group/retrieving-group-members/get-users-in-group)
- [Search group members](/sdk/flutter/group/retrieving-group-members/search-group-members)
- [Get group owner and admin](/sdk/flutter/group/retrieving-group-members/get-group-owner-and-admin)

Query methods fetch snapshots of member rosters at invocation time and do not emit listener events. If membership shifts significantly during pagination, reset the offset and reload the first page.

## Member events

Group member changes are received centrally via `OnGroupListener`:
- `onGroupMemberAdded`: New members joined the group.
- `onGroupMemberDeleted`: Members left or were removed from the group.
- `onGroupMemberInfoChanged`: Member attributes (role, nickname, mute state) changed.

Merge updates idempotently using `groupID:userID`. Because events may be triggered by other users or background tasks, do not treat them as direct responses to a specific local method call.

For consolidated listener configuration, see [Events overview](/sdk/flutter/events/overview-events).
