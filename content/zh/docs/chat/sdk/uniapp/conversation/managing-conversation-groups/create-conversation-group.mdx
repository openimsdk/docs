`createConversationGroup()` <span className="enterprise-field-badge">商业版</span> 创建分组，并可把一个会话作为初始成员。

```uts
import { createConversationGroup } from '@/uni_modules/unix-openim-sdk'

const result = await createConversationGroup({
  name: '重要会话',
  order: 100,
  conversationGroupType: 0,
  conversationID: conversationID,
  ex: '',
})

const group = result?.conversationGroup
```

分组类型使用插件导出的合同值。`conversationID` 可省略；`ex` 是整段业务扩展。返回分组可能为 `null`，最终列表以分组事件或重新查询为准。
