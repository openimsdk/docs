---
title: '创建回复消息'
description: '创建一条包含原消息引用的回复消息。'
sourcePath: '/sdk/wasm/message/creating-messages/create-quote-message'
---

回复消息包含一条新的回复文本以及被回复原消息的完整上下文引用。调用时需传入当前会话中已经存在的原 `MessageItem` 对象：

```ts
const { data: message } = await openimsdk.createQuoteMessage({
  text: '同意这个方案',
  message: JSON.stringify(originalMessage),
});
```

`text` 为新输入的回复正文，`message` 为被引用原消息序列化后的 JSON 字符串。请直接序列化完整的原始消息对象，避免手动拼凑属性。

接口调用成功后，返回的 `data` 为新的待发送 `MessageItem` 对象，原始被引用的消息保持不变。随后需调用 [发送消息](/sdk/wasm/message/sending-messages/send-message) 发送该消息；接收端展示时，若原消息已被物理删除，建议展示如“引用的消息已删除”等降级提示。
