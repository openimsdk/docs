引用已有消息并附带纯文本回复内容，构建待发送的引用消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `text` | `String` | 是 | 回复内容的正文文本。 |
| `quoteMsg` | `Message` | 是 | 被引用的原始完整消息对象。 |

```dart
final message = await OpenIM.iMManager.messageManager.createQuoteMessage(
  text: '同意这个方案',
  quoteMsg: originalMessage,
);
```

引用的原始消息应当直接来自本地消息列表、历史查询结果或接收事件，避免手动伪造字段。

## 返回结果

Future 成功返回待发送的引用消息对象（`Message`），其内容保存在 `quoteElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送，不会修改被引用的原始消息，也不会触发新消息事件通知。构建完成后，需将返回的 `Message` 实例传给[发送消息](/sdk/flutter/message/sending-messages/send-message)投递至单聊或群聊会话。
