title: '发送不经 OSS 的消息'
description: '使用 sendMessageNotOss 发送已经由业务上传资源的媒体消息。'

`sendMessageNotOss()` 用于发送已经包含有效远端媒体 URL 的消息，避免 SDK 再次上传文件。只应与 `create*MessageByURL()` 创建的媒体消息配合使用；本地路径或本地文件消息仍使用[发送消息](/sdk/android/message/sending-messages/send-message)。

单聊只填写 `recvUid`，群聊只填写 `recvGid`。`offlinePushInfo` 控制接收方离线时的推送内容。

```java
OpenIMClient.getInstance().messageManager.sendMessageNotOss(
    new OnMsgSendCallback() {
        @Override
        public void onSuccess(Message sentMessage) {
            // 按 clientMsgID 替换本地待发送消息。
        }

        @Override
        public void onError(int code, String error) {
            // 标记发送失败并允许重试。
        }
    },
    message,
    peerUserID,
    null,
    offlinePushInfo
);
```

成功回调返回发送后的 `Message`，表示当前发送请求已经完成，不代表接收方事件已经到达。接收方处理方式见[接收消息](/sdk/android/message/receiving-messages/receive-messages)。
