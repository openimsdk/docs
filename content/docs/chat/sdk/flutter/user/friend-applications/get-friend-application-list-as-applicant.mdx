Retrieve outgoing friend applications initiated by the currently logged-in user using pagination:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `offset` | `int` | No | Pagination offset index. Start at `0` for the first page. |
| `count` | `int` | No | Number of application records to fetch per page. |

## Code example

```dart
final items = await OpenIM.iMManager.friendshipManager
    .getFriendApplicationListAsApplicant(
  req: GetFriendApplicationListAsApplicantReq(offset: 0, count: 20),
);
```

## Return value

A successful `Future` returns a list of friend application records for the requested page (`List<FriendApplicationInfo>`).

Query operations return an immediate data snapshot and do not emit listener events. Deduplicate and merge application records using the composite identifier `fromUserID:toUserID`. To submit new requests, see [Add a friend](/sdk/flutter/user/friend-applications/add-friend).
