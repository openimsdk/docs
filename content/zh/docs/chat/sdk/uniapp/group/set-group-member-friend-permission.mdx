title: '设置群内添加好友权限'
description: '控制成员能否通过群组向其他成员发送好友申请。'
sourcePath: '/sdk/uniapp/group/set-group-member-friend-permission'
---

`applyMemberFriend` 使用 `0 | 1` 表示权限，没有导出具名常量。

| 数值 | 含义 |
| --- | --- |
| `0` | 允许通过群成员关系发起好友申请。 |
| `1` | 不允许通过群成员关系发起好友申请。 |

```uts
import { setGroupInfo } from '@/uni_modules/unix-openim-sdk'

const disallowMemberFriendRequest: 0 | 1 = 1

await setGroupInfo({
  groupID,
  applyMemberFriend: disallowMemberFriendRequest,
})
```

该字段只控制通过群成员关系发起好友申请，不等同于隐藏成员资料，也不会删除已有好友关系。Promise 成功后，收到 `onGroupInfoChanged()` 时再更新群资料；完整监听见[群组概览](/sdk/uniapp/group/overview-group)。
