为指定会话设置业务自定义扩展字符串。`ex` 字段为纯文本字符串，更新时采用全量覆盖机制；若存放 JSON 等结构化数据，更新前应先读取原值并在业务层合并后再保存：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 目标会话 ID。 |
| `req` | `ConversationReq` | 是 | 会话修改请求对象，`ex` 传入序列化后的扩展字符串。 |

```dart
await OpenIM.iMManager.conversationManager.setConversation(
  conversationID,
  ConversationReq(ex: mergedExtensionJSON),
);
```

## 返回结果

Future 成功表示扩展字段已更新。

多端同步或事件到达时通过会话变更事件通知。客户端以 `conversationID` 为合并标识更新对应会话的 `ex` 扩展字段，完整事件监听请参考[获取会话列表](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list)。
