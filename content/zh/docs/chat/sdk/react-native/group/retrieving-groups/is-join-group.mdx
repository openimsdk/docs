检查当前登录账号是否已加入指定的群组。

```ts
const isJoined = await OpenIMSDK.isJoinGroup('group-001');
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 要检查的群组 ID。 |

## 返回结果

调用完成后返回 `boolean`：`true` 表示当前账号已是该群成员，`false` 表示尚未加入或已退出。该查询只返回当前本地状态快照；群成员关系的动态变更请参考[群组概览](/sdk/react-native/group/overview-group)中的群组事件监听。
