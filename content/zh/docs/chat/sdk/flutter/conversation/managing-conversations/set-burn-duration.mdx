配置阅后即焚模式下消息在阅读后的自动销毁倒计时时长：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 目标会话 ID。 |
| `req` | `ConversationReq` | 是 | 会话修改请求对象，`burnDuration` 单位为秒（例如 `30` 秒）。 |

```dart
await OpenIM.iMManager.conversationManager.setConversation(
  conversationID,
  ConversationReq(burnDuration: 30),
);
```

## 返回结果

Future 成功表示阅后即焚时长已更新。开启或关闭阅后即焚功能本身需配合 `isPrivateChat` 字段，请参考[开启或关闭阅后即焚](/sdk/flutter/conversation/managing-conversations/set-private-chat)；请勿将此参数与服务端的定期消息销毁配置混淆。

多端同步或事件到达时通过会话变更事件通知。客户端以 `conversationID` 为合并标识更新本地会话的 `burnDuration` 属性，完整事件监听请参考[获取会话列表](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list)。
