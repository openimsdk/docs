---
title: '开启或关闭阅后即焚'
description: '设置指定会话是否启用阅后即焚模式。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/set-private-chat'
---

阅后即焚属于商业版能力。`isPrivateChat` 控制指定会话是否启用该模式；它与服务端消息的周期删除策略不是同一项能力。

```uts
import { setConversation } from '@/uni_modules/unix-openim-sdk'

await setConversation({
  conversationID,
  isPrivateChat: true,
})
```

传入 `false` 可关闭阅后即焚。消息保留时长通过 `burnDuration` 单独设置，见[设置阅后即焚时长](/sdk/uniapp/conversation/managing-conversations/set-burn-duration)。

Promise 成功表示设置请求已完成。客户端可先将本地会话的阅后即焚状态更新为目标值，收到会话变更事件后，按 `conversationID` 确认最新状态。完整会话事件监听见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。
