title: '更新群昵称'
description: '使用 SetGroupMemberInfo.nickname 更新成员在指定群中的显示昵称。'

---

成员资料修改统一使用 `setGroupMemberInfo()`。请求中填写 `groupID`、`userID` 和 `nickname`。

```java
SetGroupMemberInfo update = new SetGroupMemberInfo();
update.setGroupID(groupID);
update.setUserID(userID);
update.setNickname("小林");

OpenIMClient.getInstance().groupManager.setGroupMemberInfo(update, new OnBase<String>() {
    @Override public void onSuccess(String data) { markNicknameSubmitted(groupID, userID); }
    @Override public void onError(int code, String error) { showMemberUpdateError(error); }
});
```

以 `onGroupMemberInfoChanged` 返回的 `GroupMembersInfo.nickname` 更新显示。
