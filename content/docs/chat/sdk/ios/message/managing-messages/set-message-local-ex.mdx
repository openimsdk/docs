```objc
[[OIMManager manager] setMessageLocalEx:conversationID
                            clientMsgID:message.clientMsgID
                                localEx:@"{\"downloaded\":true}"
                              onSuccess:nil
                              onFailure:nil];
```

`localEx` is replaced as a complete string in the current device's local database only. It is not synchronized to other devices and does not trigger the new-message delegate. To preserve existing fields, parse and merge them in the application before updating.
