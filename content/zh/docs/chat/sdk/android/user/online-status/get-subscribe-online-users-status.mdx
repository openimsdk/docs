---
title: '查询已订阅用户状态'
description: '使用 getSubscribeOnlineUsersStatus() 获取已订阅用户的在线状态快照。'
sourcePath: '/sdk/android/user/online-status/get-subscribe-online-users-status'
---

```java
OpenIMClient.getInstance().userInfoManager.getSubscribeOnlineUsersStatus(
    new OnBase<List<UsersOnlineStatus>>() {
        @Override
        public void onSuccess(List<UsersOnlineStatus> states) {
            mergeOnlineStates(states);
        }

        @Override
        public void onError(int code, String error) {
            recordStatusQueryFailure(code, error);
        }
    }
);
```

该方法不接收用户 ID，也不改变订阅集合。成功 callback 返回当前已订阅用户的 `List<UsersOnlineStatus>` 状态快照，适合在重连或重新进入页面时按 `userID` 校准状态。

查询本身不会触发 `onUserStatusChanged`。状态快照只应覆盖在线状态存储，不要覆盖用户昵称、头像等资料字段；需要资料时分别调用用户资料 API。
