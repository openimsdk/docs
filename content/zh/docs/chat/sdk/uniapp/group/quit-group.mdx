---
title: '退出群组'
description: '退出当前用户已加入的群组。'
sourcePath: '/sdk/uniapp/group/quit-group'
---

普通成员和管理员可以调用 `quitGroup()` 退出群组。群主不能直接退出，应先将群主身份转让给其他成员。

```uts
import { quitGroup } from '@/uni_modules/unix-openim-sdk'

await quitGroup(groupID)
```

`groupID` 是要退出的群组 ID。Promise 成功表示 SDK 已完成退出请求；随后可在 `onJoinedGroupDeleted()` 中按 `groupID` 移除已加入群组记录。完整监听见[群组概览](/sdk/uniapp/group/overview-group)。

退出群组不会等同于删除或隐藏本地会话。历史会话可能继续保留，因此不能根据会话是否存在判断当前用户是否仍属于该群。
