根据指定关键字与匹配维度在本地好友列表中执行模糊检索：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `keywordList` | `List<String>` | 是 | 搜索关键字列表。当前建议传入包含单个非空关键字的列表。 |
| `isSearchUserID` | `bool` | 否 | 是否匹配好友的用户 ID。 |
| `isSearchNickname` | `bool` | 否 | 是否匹配好友的昵称。 |
| `isSearchRemark` | `bool` | 否 | 是否匹配为好友设置的备注名。 |

```dart
final results = await OpenIM.iMManager.friendshipManager.searchFriends(
  keywordList: ['alice'],
  isSearchUserID: true,
  isSearchNickname: true,
  isSearchRemark: true,
);
```

## 返回结果

Future 成功返回匹配的好友搜索结果列表（`List<SearchFriendsInfo>`）。

每个 `SearchFriendsInfo` 包含好友的基本信息及关联匹配字段。搜索结果仅用于驱动当前搜索 UI 呈现，不应直接替换全局联系人列表的持久状态；若需基于搜索结果更新好友关系或发起会话，客户端应以目标好友实体的 `userID` 作为关联主键。

该查询为本地检索操作，不会触发好友 listener。拉取常规联系人列表请参考[分页获取好友列表](/sdk/flutter/user/friends/get-friend-list-page)。
