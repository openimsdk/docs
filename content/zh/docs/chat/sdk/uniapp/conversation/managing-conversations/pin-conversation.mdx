---
title: '置顶或取消置顶会话'
description: '设置指定会话在当前用户会话列表中的置顶状态。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/pin-conversation'
---

`isPinned` 只改变当前用户会话列表中的排序状态，不影响其他群成员或单聊对方。

```uts
import { setConversation } from '@/uni_modules/unix-openim-sdk'

await setConversation({
  conversationID,
  isPinned: true,
})
```

传入 `true` 置顶，传入 `false` 取消置顶。Promise 成功表示设置请求已完成，客户端可先将本地会话置顶状态更新为目标值。收到会话变更事件后，按 `conversationID` 确认最新状态；需要校准状态时可重新拉取该会话。完整会话事件监听见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。
