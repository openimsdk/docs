```ts
await openimsdk.deleteAllMsgFromLocalAndSvr();
resetAllMessageSnapshots();
```

Require confirmation before executing this operation. When the Promise resolves, messages stored locally and on the server for the current account have been cleared. It does not delete copies held by other conversation members or prove that other devices have refreshed their state. Reconcile subsequent conversation summaries through conversation events or a new query.
