Specify the lifespan in seconds that messages remain accessible after being read under burn-after-reading mode:

## Code example

```ts
import sdk, { SetConversationReq } from '@openimsdk/imsdk';

const request: SetConversationReq = {
  conversationID: conversationID,
  burnDuration: 30,
};
await sdk.setConversation(request);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `string` | Yes | Target conversation identifier. |
| `burnDuration` | `number` | Yes | Countdown duration in seconds after which viewed messages are destroyed. |

## Return value

Returns a Promise that resolves to `void` when the duration is updated.

## State changes after the call

Activating burn-after-reading mode also requires enabling `isPrivateChat` via [Enable or disable burn-after-reading](/sdk/harmony/conversation/managing-conversations/set-private-chat). Do not confuse burn duration with server-side periodic retention configured in [Set periodic server message destruction](/sdk/harmony/conversation/managing-conversations/set-message-destruct). After the Promise resolves, the SDK emits `EventOnConversationChanged`. Match the item by `conversationID` and update its `burnDuration` attribute in the local store, as shown in [Retrieve conversation list](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list).
