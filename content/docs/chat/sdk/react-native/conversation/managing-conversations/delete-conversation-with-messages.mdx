Call `deleteConversationAndDeleteAllMsg()` to delete the conversation record and the current account's messages in it.

```ts
await OpenIMSDK.deleteConversationAndDeleteAllMsg(conversationID);
```

## Parameters

`conversationID` is the ID of the conversation to delete.

## Return result

After the call completes, remove the conversation and its messages from the current screen. If `OnConversationChanged` is received later, update the list by `conversationID`. See [Retrieve the conversation list](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list) for listener details.
