创建包含原消息引用和文本实体的富文本回复消息。

```ts
const message = await OpenIMSDK.createAdvancedQuoteMessage({
  text: '我已查看相关链接。',
  message: originalMessage,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `text` | `string` | 是 | 回复的原始文本内容。 |
| `message` | `MessageItem` | 是 | 被引用的原消息对象。 |
| `messageEntityList` | `MessageEntity[]` | 否 | 文本中的高亮或链接等自定义实体列表。 |

`MessageEntity` 使用 `type`、`offset`、`length` 描述实体，并可按需要传入 `url` 或 `info`。

## 返回结果

调用完成后返回已创建的 `MessageItem` 消息对象。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送消息](/sdk/react-native/message/sending-messages/send-message)将消息投递到单聊或群聊会话中。
