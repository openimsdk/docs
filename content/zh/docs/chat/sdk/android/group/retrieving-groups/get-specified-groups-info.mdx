批量获取指定群组的最新资料。传入群组 ID 列表，常用于会话标题栏展示、群信息卡片呈现以及群资料设置界面的信息回显。

```java
List<String> groupIDs = Arrays.asList("group_123", "group_456");

OpenIMClient.getInstance().groupManager.getGroupsInfo(
    new OnBase<List<GroupInfo>>() {
        @Override
        public void onSuccess(List<GroupInfo> groups) {
            // groups 为查询到的群组资料列表
        }

        @Override
        public void onError(int code, String error) {
            // 处理查询失败
        }
    },
    groupIDs
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<List<GroupInfo>>` | 是 | 异步请求回调。 |
| `groupIDs` | `List<String>` | 是 | 待查询的目标群组 ID 列表。 |

## 返回结果

成功回调返回群组资料列表 `List<GroupInfo>`。包含群名称 `groupName`、群头像 `faceURL`、群公告 `notification`、成员数 `memberCount`、群主 ID `ownerUserID` 以及扩展信息 `ex`。

客户端应以 `groupID` 为标识合并群组资料缓存。若群资料发生变更，SDK 会通过 `onGroupInfoChanged` 事件实时推送更新；完整监听见[群组概览](/sdk/android/group/overview-group)。
