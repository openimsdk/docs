在发起的通话邀请尚未接通前，发起方可调用取消接口撤回邀请：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `signalingInfo` | `OIMSignalingInfo *` | 发起通话时保存的完整信令信息对象。 |

```objc
[[OIMManager manager] signalingCancel:signalingInfo
                            onSuccess:^{ [self releaseCallResources]; }
                            onFailure:^(NSInteger code, NSString * _Nullable message) {
    [self showCallError:code message:message ?: @"取消邀请失败"];
}];
```

调用时需传入发起通话时保存的完整 `OIMSignalingInfo`。通话状态以 `roomID` 为合并标识，参与者状态同时结合用户 ID。

## 返回结果

成功回调 `onSuccess` 表示服务端已处理取消信令。被邀请端将收到邀请被取消事件并自动关闭来电页面，完整事件处理见[处理通话事件](/sdk/ios/calling/managing-calls/handle-call-events)。发起端在收到成功回调后应及时停止呼叫等待并释放相关媒体资源。
