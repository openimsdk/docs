title: '创建文本消息'
description: '根据文本内容创建一条待发送消息。'
sourcePath: '/sdk/uniapp/message/creating-messages/create-text-message'
---

`createTextMessage()` 接收文本字符串。调用前应在业务层处理空白、长度和内容规则。

```uts
import { createTextMessage } from '@/uni_modules/unix-openim-sdk'

const text = input.trim()
if (text.length == 0) return

const message = await createTextMessage(text)
if (message == null) return
```

Promise 成功后返回 `OpenIMMessageItem | null`。非空结果只是待发送对象，不会写入 OpenIMServer，也不会触发新消息事件。

下一步将该对象交给[发送消息](/sdk/uniapp/message/sending-messages/send-message)。发送完成后，使用返回消息的 `clientMsgID` 更新本地待发送项。
