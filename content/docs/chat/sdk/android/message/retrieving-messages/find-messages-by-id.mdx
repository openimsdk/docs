Create a list of `SearchParams` for the messages you need.

```java
messageManager.findMessageList(new OnBase<SearchResult>() {
    @Override public void onSuccess(SearchResult result) { /* result contains the matches. */ }
    @Override public void onError(int code, String error) { /* code and error describe the failure. */ }
}, searchParams);
```
