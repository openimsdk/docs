---
title: '拒绝好友申请'
description: '拒绝指定用户发来的好友申请。'
sourcePath: '/sdk/uniapp/user/friend-applications/refuse-friend-application'
---

处理收到的申请时，`toUserID` 填写申请人的用户 ID。`handleMsg` 可以记录拒绝说明；没有内容时传空字符串。

```uts
import { refuseFriendApplication } from '@/uni_modules/unix-openim-sdk'

await refuseFriendApplication({
  toUserID: applicantUserID,
  handleMsg: '',
})
```

Promise 成功表示本次拒绝请求已成功返回，不表示申请事件已经到达。收到 `onFriendApplicationRejected()` 后，按 `fromUserID:toUserID` 更新对应申请；需要校准状态时重新查询申请列表。拒绝申请不会创建好友关系，也不等同于删除申请记录；完整监听见[获取收到的好友申请](/sdk/uniapp/user/friend-applications/get-friend-application-list-as-recipient)。
