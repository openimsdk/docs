`getGroupMembersInfo()` accepts one `groupID` and a list of target user IDs. It returns the users' `GroupMembersInfo` profiles within that group.

```java
OpenIMClient.getInstance().groupManager.getGroupMembersInfo(
    new OnBase<List<GroupMembersInfo>>() {
        @Override public void onSuccess(List<GroupMembersInfo> members) { /* members contains the requested profiles. */ }
        @Override public void onError(int code, String error) { /* code and error describe the failure. */ }
    }, groupID, userIDs);
```
