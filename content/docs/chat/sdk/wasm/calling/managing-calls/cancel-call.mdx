Before an invitation is answered, the caller can cancel it with `signalingCancel()`:

```ts
await openimsdk.signalingCancel({
  opUserID: currentUserID,
  invitation,
});
```

Pass the current user's ID and the complete `SignalingInvitation` for this call. Reuse the invitation data saved when the call was started; do not construct an incomplete object containing only `roomID`.

Resolving the Promise indicates that the cancellation signaling request has completed. The application should also end its local ringing or waiting state and release any unallocated media resources. Remote clients receive updates via `SdkEvent.OnInvitationCancelled`; see [Handle call events](/sdk/wasm/calling/managing-calls/handle-call-events) for complete event listener and cleanup configurations.
