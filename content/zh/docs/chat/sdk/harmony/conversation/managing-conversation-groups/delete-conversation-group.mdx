---
title: '删除会话分组'
description: '删除指定会话分组及其会话关联。'
sourcePath: '/sdk/harmony/conversation/managing-conversation-groups/delete-conversation-group'
---

删除分组会一并移除它与会话的关联，但不会删除其中的会话或消息。

```ts
import sdk, { DeleteConversationGroupReq } from '@openimsdk/imsdk';

const request: DeleteConversationGroupReq = {
  conversationGroupID: conversationGroupID,
};
await sdk.deleteConversationGroup(request);
```

`conversationGroupID` 是会话分组 ID，不是聊天群组 ID。Promise 成功表示删除请求已经完成；客户端可先根据 `conversationGroupID` 从本地列表中移除对应分组记录，收到事件后完成状态同步，完整监听代码请参考[会话分组概览](/sdk/harmony/conversation/managing-conversation-groups/overview-conversation-groups)。
