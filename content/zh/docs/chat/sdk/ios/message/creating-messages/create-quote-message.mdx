调用创建回复消息方法可构建引用原消息并附带新回复文本的消息对象。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createQuoteMessage:@"同意这个方案"
                               message:originalMessage];
```

## 参数说明

- `text`：用户输入的回复正文文本（`NSString *`）。
- `message`：被引用的原始消息对象（`OIMMessageInfo *`），通常从会话当前列表中获取。

## 返回结果

- 返回初始化的引用回复消息对象（`OIMMessageInfo *`），其内容类型为引用消息。
- 该方法仅生成新的待发送消息对象，不会直接修改原消息。创建后需调用[发送消息](/sdk/ios/message/sending-messages/send-message)进行投递。
