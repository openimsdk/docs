title: '查询会话所属分组'
description: '查询指定会话当前关联的全部会话分组。'

同一个会话可以关联多个分组。该方法返回完整的分组对象，而不是只返回分组 ID。

```ts
import sdk, {
  GetConversationGroupByConversationIDReq,
  GetConversationGroupByConversationIDResp,
} from '@openimsdk/imsdk';

const request: GetConversationGroupByConversationIDReq = {
  conversationID: conversationID,
};
const response: GetConversationGroupByConversationIDResp =
  await sdk.getConversationGroupByConversationID(request);
const groups = response.conversationGroups;
```

`conversationID` 是 OpenIM 会话 ID，不是聊天群组 ID。需要分组 ID 时读取每项的 `conversationGroupID`。该查询不会触发事件；关联发生变化后，按[会话分组概览](/sdk/harmony/conversation/managing-conversation-groups/overview-conversation-groups)中的方式合并事件或重新查询。
