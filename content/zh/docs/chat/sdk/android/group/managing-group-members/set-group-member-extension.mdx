设置群成员的自定义业务扩展数据。在 `SetGroupMemberInfo` 中指定 `ex` 字段（如 JSON 字符串），用于保存成员在群内的业务自定义属性（例如群内职务、积分或自定义标签）。服务端会对传入的字符串进行全量覆盖保存。

```java
SetGroupMemberInfo update = new SetGroupMemberInfo();
update.setGroupID("group_123");
update.setUserID("user_a");
update.setEx("{\"duty\":\"reviewer\",\"tag\":\"expert\"}");

OpenIMClient.getInstance().groupManager.setGroupMemberInfo(
    update,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 群成员扩展字段更新成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理更新失败
        }
    }
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupMemberInfo` | `SetGroupMemberInfo` | 是 | 群成员资料修改对象，必须设置 `groupID`、成员 `userID` 以及新的扩展属性字符串 `ex`。 |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |

## 返回结果

成功回调中的 `data` 返回确认信息。

扩展字段更新成功后，群内成员端随后将收到 `onGroupMemberInfoChanged` 事件通知，返回更新后的 `GroupMembersInfo`。客户端应以 `groupID:userID` 为标识替换成员资料中的 `ex` 缓存；完整监听见[群组概览](/sdk/android/group/overview-group)。
