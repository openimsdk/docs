传入 `GetGroupApplicationListAsRecipientReq`，设置 `groupIDs`、`handleResults`、`offset` 和 `count`。Future 成功返回当前用户有权处理的 `List<GroupApplicationInfo>`。

```dart
final applications = await OpenIM.iMManager.groupManager
    .getGroupApplicationListAsRecipient(
  GetGroupApplicationListAsRecipientReq(
    groupIDs: [groupID],
    handleResults: [0],
    offset: 0,
    count: 20,
  ),
);
```
