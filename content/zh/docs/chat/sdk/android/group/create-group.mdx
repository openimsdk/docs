title: '创建群组'
description: '使用 createGroup 创建群资料并指定初始成员、管理员和群主。'

---

使用 `createGroup()` 创建群组。`GroupInfo` 填写群资料；初始普通成员、管理员和群主分别通过独立参数传入。成功回调返回创建后的完整 `GroupInfo`，应保存服务端确定的 `groupID`。

```java
GroupInfo info = new GroupInfo();
info.setGroupName("项目讨论");
info.setIntroduction("仅限项目成员");

OpenIMClient.getInstance().groupManager.createGroup(
    memberUserIDs, adminUserIDs, info, ownerUserID,
    new OnBase<GroupInfo>() {
        @Override public void onSuccess(GroupInfo group) { openGroup(group.getGroupID()); }
        @Override public void onError(int code, String error) { showCreateError(error); }
    }
);
```

群主和管理员必须由业务侧按权限选择。不要在客户端根据本地用户列表推导群主身份。
