```objc
[[OIMManager manager] setConversationRecvMessageOpt:conversationID
                                             status:OIMReceiveMessageOptNotNotify
                                          onSuccess:nil
                                          onFailure:nil];
```

`OIMReceiveMessageOptReceive` receives messages while online and allows offline push. `OIMReceiveMessageOptNotReceive` disables both message reception and offline push. `OIMReceiveMessageOptNotNotify` receives messages while online but disables offline push. After success, merge the latest state through `onConversationChanged:`.
