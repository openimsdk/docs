Remove a user from the active blocklist:

## Code example

```ts
import sdk, { DeleteBlackReq } from '@openimsdk/imsdk';

const request: DeleteBlackReq = {
  userID: targetUserID,
};
await sdk.deleteBlack(request);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `userID` | `string` | Yes | Target user identifier to unblock. |

## Return value

Returns a Promise that resolves to `void` upon unblocking on the server.

## State changes after the call

Unblocking a user does not automatically restore a friendship if it was previously severed. Once the Promise resolves, update your local blocklist store by removing the record matched on `blockUserID` (matching target `userID`) when `EventOnBlackDeleted` arrives, or re-query via [Retrieve blocklist](/sdk/harmony/user/blacklist/get-black-list).
