`GroupNeedVerification` 定义三种入群策略：

```ts
import sdk, { GroupNeedVerification, SetGroupInfoReq } from '@openimsdk/imsdk';

const request: SetGroupInfoReq = {
  groupID: groupID,
  needVerification: GroupNeedVerification.AllNeedVerification,
};
await sdk.setGroupInfo(request);
```

## 参数说明

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `GroupNeedVerification.ApplyNeedVerificationInviteDirectly` | `0` | 用户申请需要审核；成员邀请可直接入群。 |
| `GroupNeedVerification.AllNeedVerification` | `1` | 申请和普通成员邀请都需要审核；群主或管理员邀请除外。 |
| `GroupNeedVerification.DirectAccess` | `2` | 申请或邀请均可直接入群。 |

客户端应根据策略展示申请提示，但最终是否允许加入仍由 OpenIMServer 判断。Promise 成功后，SDK 会触发群资料变更事件；客户端收到通知后根据 `groupID` 更新验证策略，完整监听代码请参考[群组概览](/sdk/harmony/group/overview-group)。
