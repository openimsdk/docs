用户拒绝来电时，将收到的原始 `SignalingInfo` 交给 `signalingReject()`：

```java
OpenIMClient.getInstance().signalingManager.signalingReject(
    new OnBase<String>() {
        @Override
        public void onSuccess(String result) {
            closeIncomingCallUI();
        }

        @Override
        public void onError(int code, String error) {
            showRejectError(code, error);
        }
    },
    signalingInfo
);
```

成功回调只表示拒绝信令请求完成。发起端随后通过 `onInviteeRejected` 更新界面；完整处理见[处理通话事件](/sdk/android/calling/managing-calls/handle-call-events)。
