---
title: '设置阅后即焚时长'
description: '使用 setConversationBurnDuration() 设置阅后即焚模式的消息保留时长。'
sourcePath: '/sdk/android/conversation/managing-conversations/set-burn-duration'
---

```java
OpenIMClient.getInstance().conversationManager.setConversationBurnDuration(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    conversationID,
    30
);
```

`burnDuration` 的单位为秒。启用或关闭阅后即焚需要设置 `isPrivateChat`，见[开启或关闭阅后即焚](/sdk/android/conversation/managing-conversations/set-private-chat)。不要把它与服务端消息定期删除周期 `msgDestructTime` 混用。

会话列表中的时长变化可通过 `onConversationChanged` 接收，监听器设置方式见[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
