一次性获取当前登录用户已加入的全部群组列表。该方法无需传入参数，适合群组数量较少或初始化本地群组缓存的场景：

```dart
final groups = await OpenIM.iMManager.groupManager.getJoinedGroupList();
```

## 返回结果

Future 成功返回当前用户已加入的群组列表（`List<GroupInfo>`）。

该接口返回当前用户已加入的群组集合，并非系统公开的群组发现目录。若加入的群组数量较多或需要增量分批加载，推荐使用[分页获取已加入群组](/sdk/flutter/group/retrieving-groups/get-joined-group-list-page)。

查询操作建立静态数据快照，不会触发事件通知。群组增量同步与基于 `groupID` 的状态合并规则请参考[群组概览](/sdk/flutter/group/overview-group)。
