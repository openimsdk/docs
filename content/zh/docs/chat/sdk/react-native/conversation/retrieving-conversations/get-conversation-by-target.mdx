根据聊天目标 ID 和会话类型获取单个会话的信息。

```ts
const conversation = await OpenIMSDK.getOneConversation({
  sourceID: targetUserID,
  sessionType: SessionType.Single,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `sourceID` | `string` | 是 | 单聊传对方用户 ID，群聊传群组 ID。 |
| `sessionType` | `SessionType` | 是 | 会话类型。单聊使用 `SessionType.Single`，群聊使用 `SessionType.Group`。 |

## 返回结果

调用完成后返回对应的 `ConversationItem` 会话对象。查询只建立当前会话快照，不会触发会话事件；后续会话状态变更见[会话概览](/sdk/react-native/conversation/overview-conversation)，各字段详细说明见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。
