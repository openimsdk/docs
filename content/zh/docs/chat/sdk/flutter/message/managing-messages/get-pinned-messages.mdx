拉取指定会话中当前处于置顶状态的消息列表快照：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 目标会话 ID。 |

```dart
final messages = await OpenIM.iMManager.messageManager
    .getConversationPinnedMsg(conversationID: conversationID);
replacePinnedMessages(conversationID, messages);
```

## 返回结果

Future 成功返回当前会话的置顶消息列表（`List<Message>`）。

该接口不包含置顶操作者或置顶时间戳等元数据字段。查询操作建立静态快照，不会触发事件通知；本地状态应按 `conversationID` 整体替换并按非空 `clientMsgID` 去重。后续置顶或取消置顶的完整变更与事件处理请参考[置顶或取消置顶消息](/sdk/flutter/message/managing-messages/set-message-pinned)。
