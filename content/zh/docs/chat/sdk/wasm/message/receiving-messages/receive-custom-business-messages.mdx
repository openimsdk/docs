title: '接收自定义业务消息'
description: '监听 WASM SDK 的服务端自定义业务通知。'

---

`SdkEvent.OnRecvCustomBusinessMessage` 用于接收由业务服务端下发的自定义业务指令或全局系统通知。需要注意：该事件的数据载荷并非标准 `MessageItem` 聊天对象；普通单聊或群聊中的自定义消息（`customElem`）仍通过标准新消息事件接收。

```ts
import { SdkEvent } from '@openim/wasm-client-sdk';

function handleCustomBusinessMessage({ data }) {
  const payload = parseAndValidateBusinessPayload(data);
  applyBusinessPayload(payload);
}

openimsdk.on(
  SdkEvent.OnRecvCustomBusinessMessage,
  handleCustomBusinessMessage,
);

function removeCustomBusinessMessageListener() {
  openimsdk.off(
    SdkEvent.OnRecvCustomBusinessMessage,
    handleCustomBusinessMessage,
  );
}
```

监听函数需保持稳定引用以确保后续能正确移除。自定义业务通知的载荷数据结构由业务服务端与客户端统一约定，建议在 payload 中包含唯一业务 ID 或时间戳，便于前端进行消息去重与幂等处理。
