`createSoundMessageFromFullPath()` 根据本地音频文件创建消息。传入音频路径和时长即可，文件大小等信息由 SDK 在后续流程中处理。

`soundPath` 应是 App 原生侧能够读取的 POSIX 绝对路径或 `unifile://` URI；`duration` 是音频时长，单位为秒。

```uts
import {
  createSoundMessageFromFullPath,
} from '@/uni_modules/unix-openim-sdk'

const message = await createSoundMessageFromFullPath({
  soundPath: `${uni.env.USER_DATA_PATH}/voice.m4a`,
  duration: 12,
})
if (message == null) return
```

录音接口返回的临时路径可能被系统清理，也不一定能被原生 SDK 直接读取。需要延后发送时，先将文件保存到 `uni.env.USER_DATA_PATH`，再传入保存后的路径。不要把毫秒数直接作为 `duration`。

Promise 成功后返回 `OpenIMMessageItem | null`。非空结果只表示待发送对象已经创建；后续使用[发送消息](/sdk/uniapp/message/sending-messages/send-message)，由 SDK 上传音频并发送。
