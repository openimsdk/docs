在全局上传管理状态层中集中配置独立文件上传监听器：

## 参数说明

`OnUploadFileListener` 提供以下进度与完成回调：

| 回调方法 | 字段说明 |
| --- | --- |
| `onUploadProgress` | `(String id, int fileSize, int streamSize, int storageSize)`：任务业务 ID、文件总字节数、已读取字节数以及已写入存储字节数。 |
| `onComplete` | `(String id, int size, String url, int type)`：任务业务 ID、最终文件字节大小、远程访问 URL 以及存储类型。 |

```dart
OpenIM.iMManager.setUploadFileListener(
  OnUploadFileListener(
    onUploadProgress: (id, fileSize, streamSize, storageSize) {
      updateFileProgress(id, streamSize, fileSize);
    },
    onComplete: (id, size, url, type) {
      completeFileUpload(id, size, url, type);
    },
  ),
);
```

Flutter SDK 内部仅维护单个 `OnUploadFileListener` 实例，后注册的监听器会覆盖先前的实例。请在应用状态层全局注册一次，避免在各个视图组件中重复注册造成回调覆盖。

各回调以业务 `id` 作为唯一的任务关联主键，请勿使用文件名或列表顺序关联任务状态。切换账号或销毁上传模块时，应停止向旧界面的状态分发并清理任务映射。

文件上传的具体触发调用请参考[上传文件](/sdk/flutter/file-uploads/upload-file)。
