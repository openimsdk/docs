A group owner or administrator calls this method to approve a pending join request:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID. |
| `userID` | `String` | Yes | User ID of the applicant. |
| `handleMsg` | `String?` | No | Optional approval remark message. |

## Code example

```dart
await OpenIM.iMManager.groupManager.acceptGroupApplication(
  groupID: groupID,
  userID: applicantUserID,
  handleMsg: 'Welcome to the team',
);
```

## Return value

A successful `Future` indicates that the join application was approved and the user has officially become a member of the group.

## State changes after the call

Multi-device synchronization and arriving changes trigger `onGroupApplicationAccepted`, while new member additions trigger `onGroupMemberAdded`. The client updates application status and member rosters using `groupID:userID` as the key. For complete listener integration, see [Group applications overview](/sdk/flutter/group/group-applications/overview-group-applications).
