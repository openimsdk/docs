---
title: '设置会话备注'
description: '为当前用户的指定会话设置备注。'

---

设置会话备注属于商业版能力。`remark` 是当前用户维护的会话级备注，不会修改单聊对方的昵称、好友备注或群名称。

```uts
import { setConversation } from '@/uni_modules/unix-openim-sdk'

await setConversation({
  conversationID,
  remark: '项目讨论',
})
```

传入空字符串可清空备注。展示会话名称时，应根据产品规则在 `remark` 与会话原始 `showName` 之间选择，不能把会话备注回写到用户资料、好友关系或群资料中。

Promise 成功只表示设置请求已经完成，不表示会话变化事件已经到达。收到 `onConversationChanged()` 后，按 `conversationID` 更新对应会话的 `remark`；需要校准状态时重新查询会话。完整监听见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。
