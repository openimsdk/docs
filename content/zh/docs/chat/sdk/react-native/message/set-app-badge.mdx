`setAppBadge()` 用于向 SDK 上报应用当前展示的消息总未读数。

```ts
await OpenIMSDK.setAppBadge(totalUnreadCount);
```

`totalUnreadCount` 应为非负整数。通常在消息总未读数变化、登录同步完成或清空未读消息后更新；不要把单个会话的未读数作为应用总角标。

Promise 成功只表示 SDK 已接受本次角标值，不会改变会话的本地未读数。若应用需要在系统桌面图标上展示角标，还应通过 React Native 对应的系统通知能力更新原生界面。消息总未读数的查询和持续维护见[获取消息总未读数](/sdk/react-native/conversation/managing-conversations/get-total-unread-count)。
