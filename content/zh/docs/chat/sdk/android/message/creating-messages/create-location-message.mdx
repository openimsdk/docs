构建包含地理经纬度坐标与详细地址描述的位置消息。适用于在聊天中分享当前定位或指定地点卡片。

```java
double latitude = 39.9042;
double longitude = 116.4074;
String description = "北京市东城区天安门广场";

Message message = OpenIMClient.getInstance().messageManager.createLocationMessage(
    latitude,
    longitude,
    description
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `latitude` | `double` | 是 | 纬度值，有效范围为 `-90.0` 至 `90.0`。 |
| `longitude` | `double` | 是 | 经度值，有效范围为 `-180.0` 至 `180.0`。 |
| `description` | `String` | 是 | 展示给接收方的位置名称或详细地址摘要。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.LOCATION`。

本接口仅在本地创建待发送对象，不会自动发起定位权限申请。构建完成后，请调用[发送消息](/sdk/android/message/sending-messages/send-message)投递至目标会话。
