Invoke `transferGroupOwner()` to transfer group ownership to another active member. Only the current group owner has permission to perform this action.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group identifier. |
| `newOwnerUserID` | `string` | Yes | User ID of the member assuming ownership. |

## Code example

```uts
import { transferGroupOwner } from '@/uni_modules/unix-openim-sdk'

await transferGroupOwner({
  groupID: groupID,
  newOwnerUserID: targetUserID,
})
```

## Return value

The Promise resolves with `void` once OpenIMServer transfers group ownership.

## State changes after the call

A resolved Promise confirms that the ownership transfer completed on OpenIMServer. The roles of both the former owner and the new owner change simultaneously. When `onGroupMemberInfoChanged` fires, update the role records of both members using their respective `groupID:userID` keys. To re-calibrate leadership roles, call [Get group member list](/sdk/uniapp/group/retrieving-group-members/get-group-member-list) with `filter: OpenIMGroupMemberFilterAdminAndOwner`.

When a group owner wishes to leave a group, they must transfer ownership first before calling [Quit a group](/sdk/uniapp/group/quit-group).
