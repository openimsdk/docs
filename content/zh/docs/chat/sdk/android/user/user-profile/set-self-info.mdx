更新当前登录用户的个人基本资料，包括昵称、头像 URL 和业务扩展字段。调用时仅需设置实际需要变更的字段。

```java
UserInfoReq request = new UserInfoReq();
request.setNickname(displayName.trim());
request.setFaceURL(avatarURL);
request.setEx(extra);

OpenIMClient.getInstance().userInfoManager.setSelfInfo(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 更新当前用户资料成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    request
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `request` | `UserInfoReq` | 是 | 待更新的用户资料请求体。 |

### 资料字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `nickname` | `String` | 期望更新的新昵称。 |
| `faceURL` | `String` | 期望更新的新头像 URL 地址。 |
| `ex` | `String` | 自定义业务扩展字符串，格式由业务自行约定。 |

好友添加权限与全局免打扰均为独立的账号设置项，分别请参考[设置好友添加权限](/sdk/android/user/user-profile/set-friend-add-permission)与[设置全局消息接收方式](/sdk/android/user/user-profile/set-global-message-reception)。

## 返回结果

成功回调表示服务端已成功持久化资料更新。资料变更会同步至当前用户的其他登录设备。

资料更新后，SDK 会通过 `OnUserListener` 派发事件；客户端应以 `userID` 为主键更新本地缓存并刷新界面展示：

```java
@Override
public void onSelfInfoUpdated(UserInfo info) {
    // 收到当前用户资料更新，合并本地缓存并刷新 UI
}
```
