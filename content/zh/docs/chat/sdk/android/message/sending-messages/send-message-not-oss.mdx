---
title: '发送不经 OSS 的消息'
description: '使用 sendMessageNotOss 发送已经由业务上传资源的媒体消息。'
sourcePath: '/sdk/android/message/sending-messages/send-message-not-oss'
---

消息中的媒体 URL 已准备好时使用该方法，避免 SDK 再次进入内置上传流程。

```java
messageManager.sendMessageNotOss(callback, message, peerUserID, null, offlinePushInfo);
```
