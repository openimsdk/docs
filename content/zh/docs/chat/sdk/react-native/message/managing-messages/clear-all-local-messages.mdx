清空当前登录账号在当前设备上的全部本地消息记录。

```ts
await OpenIMSDK.deleteAllMsgFromLocal();
```

## 返回结果

调用完成后，当前设备本地数据库中的所有消息记录已被清理，服务端仍保留历史消息。

这是不可逆的账号级本地操作，执行前应向用户明确说明影响范围并要求二次确认。此调用仅清空当前设备上的本地缓存，不会影响其他端，也不会触发多端消息删除事件。客户端应重置本地各会话的消息列表与视图缓存。
