按群组 ID 查询当前正在进行的音视频通话房间：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |

```dart
final room = await OpenIM.iMManager.signalingManager
    .signalingGetRoomByGroupID(groupID: groupID);

if (room.roomID?.isNotEmpty == true) {
  renderParticipants(room.participant ?? const []);
}
```

## 返回结果

Future 成功返回 `RoomCallingInfo` 对象，包含房间基本信息、邀请详情与参与者列表。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `roomID` | `String?` | 进行中的通话房间 ID；为空表示该群组当前没有进行中的通话。 |
| `invitation` | `InvitationInfo?` | 当前通话的邀请详情。 |
| `participant` | `List<ParticipantInfo>?` | 当前房间内的参与者列表。 |
| `token` | `String?` | 房间入会凭据。 |

若返回的 `roomID` 非空，可结合[获取通话房间 Token](/sdk/flutter/calling/retrieving-call-information/get-token-by-room-id)获取媒体凭证加入通话。若无进行中的群通话，应把空房间视为无可恢复通话，不要继续使用旧凭据。
