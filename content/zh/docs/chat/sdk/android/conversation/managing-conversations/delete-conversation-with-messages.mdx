`deleteConversationAndDeleteAllMsg()` 删除指定会话及其全部消息。

```java
OpenIMClient.getInstance().conversationManager.deleteConversationAndDeleteAllMsg(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成，会话及其消息已删除。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    conversationID
);
```

成功回调后清理当前消息列表和会话行。该操作不删除好友关系，也不退出或解散群组；聊天目标仍存在时，会话可能由新消息或同步重新生成。

需要更新会话列表时，可重新查询会话或通过 `onConversationChanged` 接收变化，监听器设置方式见[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
