title: '重置群聊 @ 状态'
description: '使用 resetConversationGroupAtType() 将指定会话的群聊 @ 状态重置为普通状态。'

群聊消息中有人 @ 当前用户或 @ 全体成员时，`groupAtType` 用于标记会话列表中的提醒状态。当前用户阅读相关消息后，调用 `resetConversationGroupAtType()` 清除该会话 `groupAtType` 的 @ 提醒状态，并更新会话列表 UI。

```java
OpenIMClient.getInstance().conversationManager.resetConversationGroupAtType(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markGroupMentionStateReset(conversationID);
        }

        @Override
        public void onError(int code, String error) {
            recordGroupMentionResetFailure(code, error);
        }
    },
    conversationID
);
```

会话列表中的状态变化可通过 `onConversationChanged` 接收，监听器设置方式见[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
