Use `deleteMessageFromLocalStorage()` to delete one message from a conversation on the current device.

```ts
await OpenIMSDK.deleteMessageFromLocalStorage({
  conversationID,
  clientMsgID,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `string` | Yes | Conversation containing the message. |
| `clientMsgID` | `string` | Yes | ID of the message to delete. |

After the call completes, the target message is deleted on the current device.
