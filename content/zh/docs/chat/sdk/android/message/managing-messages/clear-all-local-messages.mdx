清空当前登录账号保存在本设备本地数据库中的全部历史消息。此操作不发起网络请求，不影响远端云端存储，也不会影响其他多端设备与聊天对象的消息记录。执行前建议在 UI 上向用户确认操作影响范围。

```java
OpenIMClient.getInstance().messageManager.deleteAllMsgFromLocal(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 本地清理完成，清空本地界面中的消息展示
        }

        @Override
        public void onError(int code, String error) {
            // 处理清理失败
        }
    }
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |

## 返回结果

成功回调中的 `data` 返回确认信息。

成功回调表示本地消息数据已全部清空。该操作为设备独享行为，不会向其他客户端广播事件。若后续通过拉取漫游历史，仍可能再次从服务端读取到消息。若需同时从云端彻底删除，请参阅[清理全部消息](/sdk/android/message/managing-messages/clear-all-messages)。
