```ts
const { data: ownerAndAdmins } =
  await openimsdk.getGroupMemberOwnerAndAdmin(groupID);
```

`groupID` is the ID of the target group.

When the Promise resolves, `data` is a `GroupMemberItem[]` containing the group owner and administrators. For field descriptions, see [List group members](/sdk/wasm/group/retrieving-group-members/get-group-member-list). If you only need members with management roles, this API avoids traversing the complete member list. Use each item's `roleLevel` to distinguish the owner from administrators.

Subsequent role changes are delivered through `OnGroupMemberInfoChanged`. Use `groupID:userID` to update the matching member. For the complete listener implementation, see [List group members](/sdk/wasm/group/retrieving-group-members/get-group-member-list).
