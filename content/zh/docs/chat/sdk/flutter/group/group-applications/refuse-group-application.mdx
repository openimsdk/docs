群主或管理员调用此方法审核拒绝指定用户的入群申请：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `userID` | `String` | 是 | 申请人用户 ID。 |
| `handleMsg` | `String?` | 否 | 拒绝理由或处理附言。 |

```dart
await OpenIM.iMManager.groupManager.refuseGroupApplication(
  groupID: groupID,
  userID: applicantUserID,
  handleMsg: '暂不开放加入',
);
```

## 返回结果

Future 成功表示拒绝请求已由服务端处理完成。

多端同步或事件到达时通过 `onGroupApplicationRejected` 回调通知。客户端以 `groupID:userID` 为合并标识更新申请状态，完整事件监听请参考[入群申请概览](/sdk/flutter/group/group-applications/overview-group-applications)。
