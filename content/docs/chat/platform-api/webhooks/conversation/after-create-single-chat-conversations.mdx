Synchronize complete properties after one-to-one conversations are created. This callback is available in OpenIM Enterprise.

## HTTP request
```http
POST {WEBHOOK_ADDRESS}/callbackAfterCreateSingleChatConversationsCommand
```

## Request body
The payload contains `callbackCommand: callbackAfterCreateSingleChatConversationsCommand` and the complete property set described on [Before creating one-to-one conversations](/platform-api/webhooks/conversation/before-create-single-chat-conversations).

## Response
Return HTTP success promptly. Conversation creation is already complete and cannot be changed by this response.

## Processing rules
- Configuration key: `afterCreateSingleChatConversations`.
- Process idempotently using `owner_user_id:conversation_id`.
