The caller can cancel an outgoing call invitation before any invitee connects:

```ts
await OpenIMSDK.signalingCancel({
  opUserID: currentUserID,
  invitation,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `opUserID` | `string` | Yes | User ID of the participant canceling the invitation. |
| `invitation` | `RtcInvite` | Yes | Complete call invitation object preserved from when the call was initiated. |

## Return value

A resolved Promise confirms that the cancellation request was received and processed by the server.

Invited members receive cancellation notifications through the `OnInvitationCancelled` event. Identify the active call session using `roomID` to reset the calling UI. For complete event registration, see [Handle call events](/sdk/react-native/calling/managing-calls/handle-call-events).
