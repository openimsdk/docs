使用 `createForwardMessage()` 根据已有消息创建一条转发消息。

```ts
const message = await OpenIMSDK.createForwardMessage(sourceMessage);
```

参数 `sourceMessage` 为完整的 `MessageItem`。调用后返回新的待发送 `MessageItem`，可发送到单聊或群聊。
