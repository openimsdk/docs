---
title: '检查好友关系'
description: '使用 checkFriend() 检查指定用户是否为当前用户的好友。'
sourcePath: '/sdk/android/user/friends/check-friend'
---

```java
OpenIMClient.getInstance().friendshipManager.checkFriend(
    new OnBase<List<FriendshipInfo>>() {
        @Override
        public void onSuccess(List<FriendshipInfo> relations) {
            // 使用 relations 更新好友关系显示
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    Arrays.asList("user_a", "user_b")
);
```

成功 callback 返回 `List<FriendshipInfo>`。每项的 `userID` 是目标用户 ID，调用 `friendshipInfo.getResult()` 获取关系结果；返回 `1` 表示该用户是当前用户的好友且不在黑名单中。

需要昵称、头像或好友备注时，使用[查询指定好友资料](/sdk/android/user/friends/get-friends-info)。
