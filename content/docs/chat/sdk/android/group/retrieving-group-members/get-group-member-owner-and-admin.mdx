Use `getGroupMemberOwnerAndAdmin()` when you need to display or check members with management roles.

```java
OpenIMClient.getInstance().groupManager.getGroupMemberOwnerAndAdmin(
    new OnBase<List<GroupMembersInfo>>() {
        @Override public void onSuccess(List<GroupMembersInfo> members) { showModerators(members); }
        @Override public void onError(int code, String error) { showMemberQueryError(error); }
    }, groupID);
```

The owner, administrator, and regular-member `roleLevel` constants are defined in `GroupRole`.
