Query the count of unhandled friend applications created or updated after a given timestamp, typically used to display badge counts or red dot indicators on contacts tabs:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `time` | `int` | Yes | Epoch timestamp in seconds. Usually set to the timestamp when the user last viewed the application list; pass `0` to count all unhandled requests. |

## Code example

```dart
final count = await OpenIM.iMManager.friendshipManager
    .getFriendApplicationUnhandledCount(
  GetFriendApplicationUnhandledCountReq(time: lastViewedAt),
);
```

## Return value

A successful `Future` returns the unhandled friend application count as an `int`.

This query returns an immediate numerical snapshot; it does not alter application states or trigger events. To inspect or resolve requests, see [Get friend application list as recipient](/sdk/flutter/user/friend-applications/get-friend-application-list-as-recipient).
