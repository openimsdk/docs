---
title: '创建 Markdown 消息'
description: '创建一条包含 Markdown 源文本的待发送消息。'
sourcePath: '/sdk/harmony/message/creating-messages/create-markdown-message'
---

```ts
import sdk, { CreateMarkdownMessageReq, CreateMarkdownMessageResp } from '@openimsdk/imsdk';

const request: CreateMarkdownMessageReq = {
  content: '**发布完成**\n\n请查看最新版本说明。',
};
const response: CreateMarkdownMessageResp = await sdk.createMarkdownMessage(request);
const message = response.message;
```

`content` 是 Markdown 源文本，不是已经渲染的 HTML。接收端应使用受控渲染器，并限制链接、图片和可能产生 HTML 的语法；无法识别该类型时至少展示纯文本。
