---
title: '隐藏会话'
description: '使用 hideConversation() 从当前账号的会话列表隐藏入口。'
sourcePath: '/sdk/android/conversation/managing-conversations/hide-a-conversation'
---

`hideConversation()` 只隐藏当前登录用户的会话入口，不会删除单聊关系、退出群组或影响其他用户。

```java
OpenIMClient.getInstance().conversationManager.hideConversation(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成，会话已隐藏。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    conversationID
);
```

该方法适合临时从聊天列表移除入口。收到新消息或重新同步后，隐藏的会话可能再次出现。

成功回调表示隐藏请求已完成，调用端可以从当前列表移除该 `conversationID`。会话列表后续发生变化时，可通过 `onConversationChanged` 接收更新，监听器设置方式见[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
