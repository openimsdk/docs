For a product action described as “Delete this chat,” call:

```dart
await OpenIM.iMManager.conversationManager
    .deleteConversationAndDeleteAllMsg(conversationID: conversationID);
```

After the `Future` succeeds, immediately clear the current message list and conversation row. This operation does not delete a friendship or leave or dismiss a group. If the chat target still exists, a new message or synchronization may recreate the conversation. Reconcile subsequent state through `onConversationChanged` or another query.
