更新群成员在当前群内展示的独立头像：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `userID` | `String` | 是 | 目标群成员的用户 ID。 |
| `faceURL` | `String` | 是 | 成员在群内展示的新头像 URL。 |

```dart
await OpenIM.iMManager.groupManager.setGroupMemberInfo(
  groupMembersInfo: SetGroupMemberInfo(
    groupID: groupID,
    userID: targetUserID,
    faceURL: avatarURL,
  ),
);
```

群内头像仅在当前群聊中生效，与全局用户账号头像相互独立。如需修改用户的全局账号头像，请参考[更新当前用户资料](/sdk/flutter/user/retrieving-and-updating-user-information/update-self-profile)。

## 返回结果

Future 成功表示服务端已保存该成员在群内的头像设置。

设置生效后，群内相关客户端会收到成员资料变更事件通知；客户端应使用复合标识 `groupID:userID` 更新本地群成员头像。完整的事件监听与增量合并逻辑请参考[群成员查询概览](/sdk/flutter/group/retrieving-group-members/overview-retrieving-group-members)。
