基于本地设备录音生成的绝对文件路径创建语音/音频消息对象。在调用[发送消息](/sdk/android/message/sending-messages/send-message)时，SDK 会自动上传文件并计算进度。

```java
String absolutePath = "/storage/emulated/0/Recordings/voice_sample.m4a";
long durationSeconds = 8L; // 录音时长 8 秒

Message message = OpenIMClient.getInstance().messageManager.createSoundMessageFromFullPath(
    absolutePath,
    durationSeconds
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `soundPath` | `String` | 是 | 本地录音文件的绝对文件路径。必须保证当前应用具备读取权限。 |
| `duration` | `long` | 是 | 音频播放时长（单位：秒）。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.VOICE`。

本接口仅在本地初始化消息对象，构建完成后请调用[发送消息](/sdk/android/message/sending-messages/send-message)发送。
