title: '接受通话'
description: '接受当前通话邀请并取得房间凭据。'

---

取得完整的 `OpenIMSignalingInvitationInfo` 后，接受当前通话邀请并获取入会凭据：

```uts
import { signalingAccept } from '@/uni_modules/unix-openim-sdk'

const result = await signalingAccept({ invitation })

if (result?.roomID != null && result?.token != null) {
  await mediaEngineJoin(result.roomID!, result.token!, result.liveURL)
}
```

`invitation` 是唯一参数，应使用收到或查询到的完整邀请，不要只保留 `roomID` 后重新构造不完整对象。如何从应用启动或前台恢复时取得完整邀请，见[恢复待处理的通话邀请](/sdk/uniapp/calling/retrieving-call-information/restore-pending-invitation)。

Promise 成功后返回 `OpenIMSignalingAcceptResult | null`，包含 `invitation`、`roomID`、`token` 和 `liveURL` 等字段。客户端通话状态以 `roomID` 为合并标识；取得有效房间 ID 与 Token 后再连接媒体引擎。Promise 成功不代表媒体房间已经连接，也不代表其他端已更新状态，完整事件监听见[处理通话事件](/sdk/uniapp/calling/managing-calls/handle-call-events)。
