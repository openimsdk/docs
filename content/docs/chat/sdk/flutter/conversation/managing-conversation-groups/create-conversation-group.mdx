Create a conversation group for the currently signed-in user to organize related conversations by business categories:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupName` | `String` | Yes | Name of the conversation group. |
| `order` | `int?` | No | Sorting sequence value. Ordering conventions are defined by the application layer. |
| `ex` | `String?` | No | Custom business extension string. |
| `conversationID` | `String?` | No | First conversation ID to associate immediately upon group creation. |
| `conversationGroupType` | `ConversationGroupType?` | No | Group type; defaults to `ConversationGroupType.custom`. |

## Code example

```dart
final group = await OpenIM.iMManager.conversationGroupManager
    .createConversationGroup(
  req: CreateConversationGroupReq(
    groupName: 'Work',
    order: 100,
    conversationID: conversationID,
    conversationGroupType: ConversationGroupType.custom,
  ),
);
```

## Return value

A successful `Future` returns the newly created `ConversationGroupInfo` object. The client uses `conversationGroupID` as the merge key to update the local group list.

## State changes after the call

Multi-device synchronization and arriving changes trigger `onConversationGroupAdded` notifications. For complete listener integration, see [Conversation groups overview](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups).
