description: '使用 resetConversationGroupAtType() 将 Android 指定会话的群聊 @ 状态重置为普通状态。'

用户处理完群聊中的 @ 消息后，调用 `resetConversationGroupAtType()` 将 `groupAtType` 重置为普通状态。

```java
OpenIMClient.getInstance().conversationManager.resetConversationGroupAtType(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markGroupMentionStateReset(conversationID);
        }

        @Override
        public void onError(int code, String error) {
            recordGroupMentionResetFailure(code, error);
        }
    },
    conversationID
);
```

本操作只负责重置为普通状态，不应用于主动写入 `atMe`、`atAll` 等状态。群聊 @ 状态与消息已读状态不同。

成功 callback 后通过 `onConversationChanged` 按 `conversationID` 合并该会话；完整 listener 见[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
