title: '获取入群申请角标数'
description: '查询入群申请入口的当前角标数量。'

---

该方法查询当前账号的入群申请入口角标，适合在应用启动、重新登录或申请页返回后恢复角标显示。它没有业务参数。

```ts
const { data: badgeCount } =
  await openimsdk.getGroupApplicationBadgeCount();
```

Promise 成功后，`data` 是申请入口的当前角标数。查询不会清除角标，也不会修改任何申请。这个值由角标状态维护，不等同于按时间范围查询的未处理申请数量。

角标后续变化通过 `OnGroupApplicationBadgeCountChanged` 同步，完整监听见[获取收到的入群申请](/sdk/wasm/group/group-applications/get-group-application-list-as-recipient)。
