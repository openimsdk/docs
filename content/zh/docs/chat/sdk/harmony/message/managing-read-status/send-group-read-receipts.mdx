群消息成员级已读属于商业版能力。同一批消息必须属于目标群聊会话。

```ts
import sdk, {
  EventOnRecvGroupReadReceiptData,
  OpenIMSDKEvent,
  SendGroupMessageReadReceiptReq,
} from '@openimsdk/imsdk';

const request: SendGroupMessageReadReceiptReq = {
  conversationID: conversationID,
  clientMsgIDs: visibleUnreadMessageIDs,
};
await sdk.sendGroupMessageReadReceipt(request);

const handleGroupReadReceipt = (data: EventOnRecvGroupReadReceiptData): void => {
  mergeGroupMessageReadInfo(
    data.groupMessageReceipt.conversationID,
    data.groupMessageReceipt.groupMessageReadInfo,
  );
};
const unsubscribeGroupReadReceipt = sdk.on(
  OpenIMSDKEvent.EventOnRecvGroupReadReceipt,
  handleGroupReadReceipt,
);

export function removeGroupReadReceiptListener(): void {
  unsubscribeGroupReadReceipt();
}
```

不要混入其他会话或尚未展示给用户的消息。Promise 成功、回执事件和成员列表查询是三个独立阶段。会话未读数由会话级已读能力独立维护。销毁状态层时移除监听。
