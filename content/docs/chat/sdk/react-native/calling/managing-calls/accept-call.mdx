Upon receiving an incoming call invitation, invoke `signalingAccept()` to accept the invitation and join the RTC room.

```ts
const roomCredentials = await OpenIMSDK.signalingAccept({
  opUserID: currentUserID,
  invitation,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `opUserID` | `string` | Yes | User ID of the participant accepting the invitation. |
| `invitation` | `RtcInvite` | Yes | Complete call invitation object. Supply the exact object received from the incoming invitation callback rather than constructing it manually. |

## Return value

Resolves to an `RtcInviteResults` object containing the room credentials: `roomID`, `token`, and `liveURL`.

A successful Promise resolution confirms that the signaling request succeeded and room credentials have been issued; it does not indicate that the media pipeline has finished connecting. Other participants receive the `OnInviteeAccepted` event. Maintain local room state using `roomID` as the primary key and track participant status using `userID`. For complete event handling, see [Handle call events](/sdk/react-native/calling/managing-calls/handle-call-events).
