---
title: '退出群组'
description: '使用 Android SDK 让当前登录用户退出指定群组。'
sourcePath: '/sdk/android/group/quit-group'
---

`quitGroup()` 仅作用于当前登录用户，不会解散群组或移除其他成员。

```java
OpenIMClient.getInstance().groupManager.quitGroup(new OnBase<String>() {
    @Override public void onSuccess(String data) { /* 请求已完成。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
}, groupID);
```

成功回调表示退出请求已完成，不表示群组列表事件已经到达。`onJoinedGroupDeleted` 返回已退出群组的 `GroupInfo`；按 `groupID` 从当前用户的群组列表移除。完整 listener 注册见[群组概览](/sdk/android/group/overview-group)。
