会话分组属于商业版能力。`conversationGroupID` 指定目标分组，只传本次需要修改的字段；除 ID 外，至少提供一个更新字段。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationGroupID` | `string` | 是 | 要更新的会话分组 ID。 |
| `name` | `string` | 否 | 新的分组名称。 |
| `ex` | `string` | 否 | 新的完整扩展字符串。 |
| `hidden` | `boolean` | 否 | 是否隐藏该分组。 |

```uts
import { updateConversationGroup } from '@/uni_modules/unix-openim-sdk'

const result = await updateConversationGroup({
  conversationGroupID,
  name: '重点工作',
  hidden: false,
})
const updatedGroup = result?.conversationGroup
```

Promise 成功后返回 `OpenIMUpdateConversationGroupResult | null`，更新后的分组位于 `conversationGroup`。客户端应按 `conversationGroupID` 合并本地分组状态；收到分组变更事件或连接恢复后，可参考[会话分组概览](/sdk/uniapp/conversation/managing-conversation-groups/overview-conversation-groups)重新查询列表校准最新状态。
