消息置顶属于商业版能力。传入目标会话 ID 建立当前置顶列表：

```uts
import { getConversationPinnedMsg } from '@/uni_modules/unix-openim-sdk'

const result = await getConversationPinnedMsg({ conversationID })
const messages = result?.message ?? []

replacePinnedMessages(conversationID, messages)
```

Promise 成功后返回 `OpenIMGetConversationPinnedMsgResult | null`；非空结果的消息数组字段名是 `message`。渲染时按 `clientMsgID` 去重，并结合消息删除、撤回和修改后的最新内容更新列表。

查询只返回调用时的置顶消息，不触发置顶事件。需要持续同步变化时见[置顶或取消置顶消息](/sdk/uniapp/message/managing-messages/set-message-pinned)。
