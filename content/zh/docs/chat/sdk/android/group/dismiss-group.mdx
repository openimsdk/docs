---
title: '解散群组'
description: '使用 Android SDK 解散当前用户拥有的群组。'

---

`dismissGroup()` 解散指定群组，仅群主可执行。

```java
OpenIMClient.getInstance().groupManager.dismissGroup(new OnBase<String>() {
    @Override public void onSuccess(String data) { /* 请求已完成。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
}, groupID);
```

成功回调表示解散请求已完成，不表示所有客户端界面已经更新。`onGroupDismissed` 返回被解散群组的 `GroupInfo`；按 `groupID` 关闭群聊并移除群组状态。完整 listener 注册见[群组概览](/sdk/android/group/overview-group)。
