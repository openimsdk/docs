分页查询当前用户主动发出的入群申请。该接口只提供偏移量分页，不支持按群组 ID 或处理结果筛选。

## 参数说明

参数可以省略；分页时传入可选的 `offset` 和 `count`：

```uts
import {
  getGroupApplicationListAsApplicant,
} from '@/uni_modules/unix-openim-sdk'

const result = await getGroupApplicationListAsApplicant({
  offset: 0,
  count: 20,
})
const applications = result != null ? result.applications : []
```

Promise 成功后返回 `OpenIMGroupApplicationListResult | null`；非空结果的 `applications` 是当前页 `OpenIMGroupApplicationItem[]`。字段含义见[获取收到的入群申请](/sdk/uniapp/group/group-applications/get-group-application-list-as-recipient)。

分页查询期间收到申请状态更新事件时，建议按 `groupID:userID` 局部更新或重置分页重新拉取最新记录。入群申请事件的完整监听与处理逻辑请参考[获取收到的入群申请](/sdk/uniapp/group/group-applications/get-group-application-list-as-recipient)。
