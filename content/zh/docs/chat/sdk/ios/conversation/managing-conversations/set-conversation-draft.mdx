title: '设置会话草稿'
description: '使用 OpenIM iOS SDK 保存或清空会话草稿。'

---

用户离开聊天页、切换会话或输入框内容变化时，可以保存当前会话的草稿文本。输入过程中建议先维护本地状态并使用防抖策略，在退出页面或切换会话时再提交最终文本：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `conversationID` | `NSString *` | 目标会话 ID。 |
| `draftText` | `NSString *` | 草稿内容文本。传入空字符串 `""` 可清空草稿。 |

```objc
[[OIMManager manager] setConversationDraft:@"c2c_user1002"
                                 draftText:@"下午三点开会"
                                 onSuccess:^(NSString * _Nullable data) {
                                     NSLog(@"setConversationDraft success");
                                 }
                                 onFailure:^(NSInteger code, NSString *message) {
                                     NSLog(@"setConversationDraft failed: %ld %@", (long)code, message);
                                 }];
```

清空草稿时传入空字符串：

```objc
[[OIMManager manager] setConversationDraft:@"c2c_user1002"
                                 draftText:@""
                                 onSuccess:^(NSString * _Nullable data) {
                                     NSLog(@"clear draft success");
                                 }
                                 onFailure:^(NSInteger code, NSString *message) {
                                     NSLog(@"clear draft failed: %ld %@", (long)code, message);
                                 }];
```

状态以 `conversationID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回操作结果。

草稿保存完成后，会话属性更新会通过 `onConversationChanged:` 事件广播，客户端按 `conversationID` 合并 `draftText` 与 `draftTextTime` 字段。若需即时校验最终数据，可调用[按 ID 批量获取会话](/sdk/ios/conversation/retrieving-conversations/get-conversations-by-id)重新拉取该会话。完整监听配置参见[获取会话列表](/sdk/ios/conversation/retrieving-conversations/retrieve-conversation-list)。
