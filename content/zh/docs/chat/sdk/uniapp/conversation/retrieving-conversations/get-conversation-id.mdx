description: '根据聊天目标和会话类型获取稳定的会话 ID。'

---

在仅需要确定 `conversationID` 而无需拉取完整会话对象时，可根据聊天目标和会话类型直接获取。单聊传入对方用户 ID，群聊传入群组 ID，请使用 SDK 提供的计算方法，不要在应用层自行拼接会话 ID。

```uts
import {
  OpenIMSessionTypeSingle,
  getConversationIDBySessionType,
} from '@/uni_modules/unix-openim-sdk'

const conversationID = await getConversationIDBySessionType({
  sourceID: targetUserID,
  sessionType: OpenIMSessionTypeSingle,
})
```

参数中的 `sessionType` 与[查询指定会话](/sdk/uniapp/conversation/retrieving-conversations/get-conversation-by-target)一致。Promise 成功后返回代表会话唯一标识的字符串，可用于会话设置、消息历史、已读、隐藏和删除等操作。该查询只计算并返回 ID，不会触发会话事件。
