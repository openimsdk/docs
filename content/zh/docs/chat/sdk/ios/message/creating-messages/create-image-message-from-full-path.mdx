通过本地沙盒中的图片文件绝对路径，可调用创建图片消息方法生成待发送的图片消息对象。SDK 会在后续发送流程中自动提取尺寸并上传至对象存储服务。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createImageMessageFromFullPath:imageURL.path];
```

## 参数说明

- `imagePath`：当前应用沙盒内可访问的本地图片文件绝对路径（`NSString *`）。

## 返回结果

- 返回初始化的图片消息对象（`OIMMessageInfo *`），其内容类型为图片。
- 该方法仅在内存中创建消息对象，不会直接保存或发送。后续需调用[发送消息](/sdk/ios/message/sending-messages/send-message)接口完成媒体上传与网络投递。若图片已由业务层自行上传至存储服务，见[使用 URL 创建图片消息](/sdk/ios/message/creating-messages/create-image-message-by-url)。
