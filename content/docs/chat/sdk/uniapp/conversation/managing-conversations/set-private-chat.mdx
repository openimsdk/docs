Private chat mode (burn after reading) is a Commercial Edition capability. The `isPrivateChat` property toggles this behavior for a specified conversation; it is independent from periodic server-side message destruction policies.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `string` | Yes | Identifier of the target conversation. |
| `isPrivateChat` | `boolean` | Yes | Set to `true` to enable private chat mode, or `false` to disable it. |

## Code example

```uts
import { setConversation } from '@/uni_modules/unix-openim-sdk'

await setConversation({
  conversationID,
  isPrivateChat: true,
})
```

Pass `false` to disable private chat mode. To configure how long messages survive after being viewed, set `burnDuration` as documented in [Set burn duration](/sdk/uniapp/conversation/managing-conversations/set-burn-duration).

## Return value

The Promise resolves with `void` upon successful completion.

## State changes after the call

Promise resolution indicates that the private chat setting was saved locally and dispatched to the server. You can immediately update the local conversation object's `isPrivateChat` property. The SDK then delivers `onConversationChanged`, where you can verify the persisted state using `conversationID` as the primary key. For the centralized conversation list listener, see [Retrieve conversation list](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list).
