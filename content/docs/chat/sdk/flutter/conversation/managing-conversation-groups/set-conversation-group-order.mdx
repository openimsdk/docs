Batch configure display ordering sequences across multiple conversation groups:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `orders` | `List<ConversationGroupOrder>` | Yes | List of group ordering objects. Each item contains `groupID` (target `conversationGroupID`, not a chat group ID) and its new numeric `order` value. |

## Code example

```dart
await OpenIM.iMManager.conversationGroupManager.setConversationGroupOrder(
  orders: [
    ConversationGroupOrder(groupID: firstGroupID, order: 100),
    ConversationGroupOrder(groupID: secondGroupID, order: 200),
  ],
);
```

## Return value

A successful `Future` indicates that the ordering configuration request has been processed. The client updates group sort indexes locally using `conversationGroupID` as the key.

## State changes after the call

Multi-device synchronization and arriving changes trigger `onConversationGroupChanged` notifications. For complete listener integration, see [Conversation groups overview](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups).
