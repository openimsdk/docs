`deleteFriendRequests()` 接收一个包含 `friendRequests` 数组的对象。数组中的每项由申请人和接收人的用户 ID 唯一确定。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `friendRequests` | `OpenIMSimpleFriendRequest[]` | 是 | 要删除的好友申请列表。 |
| `friendRequests[].fromUserID` | `string` | 是 | 申请人的用户 ID。 |
| `friendRequests[].toUserID` | `string` | 是 | 申请接收人的用户 ID。 |

```uts
import { deleteFriendRequests } from '@/uni_modules/unix-openim-sdk'

await deleteFriendRequests({
  friendRequests: [{
    fromUserID,
    toUserID,
  }],
})
```

删除记录不等于拒绝申请，也不会删除已经建立的好友关系。Promise 成功表示本次删除请求已成功返回，不表示删除事件已经到达。收到 `onFriendApplicationDeleted()` 后，按 `fromUserID:toUserID` 从申请列表移除记录；需要校准状态时重新查询申请列表。完整监听见[获取收到的好友申请](/sdk/uniapp/user/friend-applications/get-friend-application-list-as-recipient)。
