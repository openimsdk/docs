Call `removeBlack()` to remove a specified user from the current account's blocklist.

```ts
await OpenIMSDK.removeBlack(blackUserID);
```

`blackUserID` is the user ID to unblock. After the user is removed, `OnBlackDeleted` is emitted. See [Get the blocklist](/sdk/react-native/user/blacklist/get-black-list) for the listener example.
