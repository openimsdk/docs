This method directly retrieves the owner and administrators for a group, making it ideal for rendering admin panels or management team views without paginating through all members.

## Code example

```ts
import sdk, {
  GetGroupMemberOwnerAndAdminReq,
  GetGroupMemberOwnerAndAdminResp,
} from '@openimsdk/imsdk';

const request: GetGroupMemberOwnerAndAdminReq = { groupID: groupID };
const response: GetGroupMemberOwnerAndAdminResp = await sdk.getGroupMemberOwnerAndAdmin(request);
const managers = response.members;
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group identifier. |

## Return value

Returns a Promise resolving to `GetGroupMemberOwnerAndAdminResp`:

| Property | Type | Description |
| --- | --- | --- |
| `members` | `GroupMemberItem[]` | List of group members with owner or administrator roles. |

## State changes after the call

Use the `roleLevel` property of each returned item to distinguish between group owner and administrator roles, merging records into local state using `groupID:userID`. This call is a read-only snapshot that does not trigger events. If the management page remains open, listen for member changes as documented in [Retrieve group member list](/sdk/harmony/group/retrieving-group-members/get-group-member-list).
