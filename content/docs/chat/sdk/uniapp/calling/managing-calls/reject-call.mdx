When a user declines an incoming call, pass the complete `OpenIMSignalingInvitationInfo` object to `signalingReject()`.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `invitation` | `OpenIMSignalingInvitationInfo` | Yes | The complete invitation object received via signaling events or recovered from queries. |

Do not attempt to construct a simplified invitation using only `roomID` or the caller ID.

## Code example

```uts
import { signalingReject } from '@/uni_modules/unix-openim-sdk'

await signalingReject({ invitation })
```

## Return value

The Promise resolves with `void` upon successful submission of the rejection signal.

## State changes after the call

A resolved Promise confirms that the rejection request was accepted by OpenIMServer. The callee client should immediately tear down the incoming call UI, remove the pending invitation state indexed by `roomID`, and release any reserved audio/video hardware resources. Promise resolution does not guarantee that the caller has already processed the event; for caller-side signaling synchronization, see [Handle call events](/sdk/uniapp/calling/managing-calls/handle-call-events).
