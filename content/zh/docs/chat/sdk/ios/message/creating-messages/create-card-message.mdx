---
title: '创建名片消息'
description: '使用 iOS SDK 创建用户卡片消息。'
sourcePath: '/sdk/ios/message/creating-messages/create-card-message'
---

```objc
OIMCardElem *card = [OIMCardElem new];
card.userID = @"user_b";
card.nickname = @"Alex";
card.faceURL = @"https://example.com/avatar.png";
card.ex = @"";
OIMMessageInfo *message = [OIMMessageInfo createCardMessage:card];
```

卡片中的昵称、头像等资料会固定为创建消息时的内容，不会随用户资料自动更新。返回对象仍需显式发送。
