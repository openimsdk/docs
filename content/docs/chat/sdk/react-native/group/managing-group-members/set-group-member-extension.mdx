Configure custom extension metadata for a designated group member:

```ts
await OpenIMSDK.setGroupMemberInfo({
  groupID: 'group-001',
  userID: 'user-002',
  ex: JSON.stringify({
    title: 'maintainer',
  }),
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group ID. |
| `userID` | `string` | Yes | User ID of the member whose custom extension data is being updated. |
| `ex` | `string` | Yes | Custom extension string, typically a serialized JSON payload or custom business identifier. |

## Return value

A resolved Promise confirms that the member extension field was successfully updated on the server.

Member profile updates emit the `OnGroupMemberInfoChanged` event carrying the updated details. Reconcile the local member cache using the composite key `groupID:userID`. For complete event listeners, see [Get group member list by page](/sdk/react-native/group/retrieving-group-members/get-group-member-list).
