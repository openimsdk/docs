检查当前服务端部署与环境是否支持语音识别（转写）能力。该方法无需传入参数，适合在展示语音转文字入口前进行可用性探测：

```dart
try {
  await OpenIM.iMManager.messageManager.speechToTextCapabilities();
  setTranscriptionAvailable(true);
} catch (error) {
  setTranscriptionAvailable(false);
}
```

## 返回结果

Future 成功返回 `void`，表示当前服务端已开启语音识别支持。

若服务端未启用或不支持语音转写，调用将抛出异常。该方法不返回具体的音频采样率、时长限制等参数配置；实际执行语音转写请参考[识别音频文字](/sdk/flutter/message/composing-messages/transcribe-audio)。
