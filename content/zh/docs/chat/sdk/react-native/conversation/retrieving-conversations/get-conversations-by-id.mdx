持有一组会话 ID 时，可以批量查询这些会话的最新详细资料。

```ts
const conversations = await OpenIMSDK.getMultipleConversation(conversationIDList);
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationIDList` | `string[]` | 是 | 要查询的会话 ID 数组。 |

## 返回结果

调用完成后返回 `ConversationItem[]`。返回的数组长度可能少于传入的会话 ID 数量，未返回的项表示本地暂未找到对应会话。客户端应以 `conversationID` 为标识将返回的会话数据合并到本地列表中。单个会话字段说明见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。
