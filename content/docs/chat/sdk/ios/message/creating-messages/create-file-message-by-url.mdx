```objc
OIMMessageInfo *message =
    [OIMMessageInfo createFileMessageByURL:uploadedURL
                                  fileName:@"report.pdf"
                                      size:uploadedSize];
```

The URL, file name, and size in bytes must come from an actual upload result. Send the returned object with `sendMessageNotOss:...`.
