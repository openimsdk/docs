获取当前账号在所有会话中的未读消息总数。该接口由 SDK 统计全量会话，避免在客户端将当前可见分页列表中的 `unreadCount` 简单相加造成统计偏差：

```dart
final value = await OpenIM.iMManager.conversationManager
    .getTotalUnreadMsgCount();
final totalUnread = int.tryParse(value.toString()) ?? 0;
updateApplicationBadge(totalUnread);
```

## 返回结果

Future 成功返回当前账号全量未读消息数统计值。客户端通常用此数值更新应用主导航栏或角标。

查询操作本身不会触发事件回调。后续未读数变化由 `OnConversationListener` 中的 `onTotalUnreadMessageCountChanged` 回调通知，完整 listener 配置请参考[事件概览](/sdk/flutter/events/overview-events)。

若需要把该数值同步至 SDK 的离线推送角标计数，请参考[设置应用角标数量](/sdk/flutter/message/set-app-badge)。
