`createCustomMessage()` 适合订单、任务、邀请或投票等需要同步给会话成员的业务消息。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `data` | `string` | 是 | 完整业务数据字符串，通常为序列化后的 JSON。 |
| `extension` | `string` | 是 | 完整业务扩展字符串。 |
| `descriptionText` | `string` | 是 | 类型说明或不支持该类型时的降级展示文本。 |

```uts
import { createCustomMessage } from '@/uni_modules/unix-openim-sdk'

const message = await createCustomMessage({
  data: JSON.stringify({
    type: 'task',
    taskID: 'task_42',
  }),
  extension: JSON.stringify({ schemaVersion: 1 }),
  descriptionText: '任务卡片',
})
if (message == null) return
```

三个参数都是完整字符串，SDK 不会合并 JSON。接收端应校验消息版本、字段和大小，不要执行来自消息的不可信内容；降级展示文本也不应包含敏感信息。

Promise 成功只返回待发送的 `OpenIMMessageItem | null`。发送消息与接收自定义业务事件是两个独立阶段。
