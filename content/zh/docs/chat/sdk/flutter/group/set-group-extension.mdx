为群组设置业务层自定义扩展字段。`ex` 字段为纯字符串，SDK 采用全量覆盖机制保存；若存储 JSON 等复合结构，应在更新前先读取原扩展数据并在业务层合并后再行提交：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `ex` | `String` | 是 | 新的业务扩展字符串。 |

```dart
await OpenIM.iMManager.groupManager.setGroupInfo(
  GroupInfo(
    groupID: groupID,
    ex: mergedExtensionJSON,
  ),
);
```

## 返回结果

Future 成功表示扩展字段已更新至服务端。

SDK 会通过群资料变更通知广播最新资料。客户端以 `groupID` 为合并标识更新本地群资料中的 `ex` 字段，完整事件监听请参考[群组概览](/sdk/flutter/group/overview-group)；如需主动校准最新状态，可调用[查询指定群组资料](/sdk/flutter/group/retrieving-groups/get-specified-groups-info)。
