Query active call room metadata and connected participants for a specific group using `signalingGetRoomByGroupID()`:

```ts
const room = await OpenIMSDK.signalingGetRoomByGroupID(groupID);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group ID. |

## Return value

Resolves to a `CallingRoomData` object:

| Field | Type | Description |
| --- | --- | --- |
| `roomID` | `string` | Calling room identifier. |
| `invitation` | `RtcInvite` (optional) | Call invitation metadata corresponding to the room. |
| `participant` | `ParticipantInfo[]` (optional) | Active participants currently in the room. |

`participant[].userInfo` provides individual user profiles; group scenarios may also include `groupMemberInfo` and `groupInfo`. This query returns a current snapshot of the room and does not dispatch signaling events. For subsequent live state updates, reconcile incoming events using `roomID` and participant `userID` as detailed in [Handle call events](/sdk/react-native/calling/managing-calls/handle-call-events).
