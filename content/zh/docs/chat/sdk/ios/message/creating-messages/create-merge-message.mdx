---
title: '创建合并消息'
description: '使用 iOS SDK 创建合并转发消息。'
sourcePath: '/sdk/ios/message/creating-messages/create-merge-message'
---

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createMergeMessage:selectedMessages
                                  title:@"聊天记录"
                            summaryList:summaries];
```

三个参数分别是已发送消息数组、卡片标题和顺序对应的摘要。摘要应按消息类型安全生成。返回对象不会修改原消息，也不会自动发送。
