名片资料是创建时写入消息的内容，不会随用户资料后续变化自动更新。

```ts
import sdk, { CreateCardMessageReq, CreateCardMessageResp } from '@openimsdk/imsdk';

const request: CreateCardMessageReq = {
  userID: 'user_42',
  nickname: 'Alex',
  faceURL: 'https://example.com/avatar/user_42.png',
  ex: JSON.stringify({ source: 'team-directory' }),
};
const response: CreateCardMessageResp = await sdk.createCardMessage(request);
const message = response.message;
```

四个字段均为必填。接收端执行添加好友或发起会话前，应重新查询用户资料并检查权限，不要把名片内容当作实时身份凭据。
