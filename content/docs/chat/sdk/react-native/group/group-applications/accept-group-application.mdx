Approve an applicant's pending join request as a group owner or administrator:

```ts
await OpenIMSDK.acceptGroupApplication({
  groupID: application.groupID,
  fromUserID: application.userID,
  handleMsg: 'Approved',
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group ID of the application. |
| `fromUserID` | `string` | Yes | Applicant user ID (corresponds to `application.userID`). |
| `handleMsg` | `string` | Yes | Approval note text. Pass an empty string `""` if not provided. |

## Return value

A resolved Promise confirms that the join application was approved on the server.

Approval triggers `OnGroupApplicationAccepted`, while the applicant joining the group emits `OnGroupMemberAdded`. Maintain the new member record using the composite key `groupID:userID`. For complete event handling, see [Get received group applications](/sdk/react-native/group/group-applications/get-group-application-list-as-recipient).
