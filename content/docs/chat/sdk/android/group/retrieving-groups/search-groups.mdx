`searchGroups()` accepts a keyword list and separate switches for searching group IDs and group names. If both switches are disabled, there is no valid search scope.

```java
OpenIMClient.getInstance().groupManager.searchGroups(new OnBase<List<GroupInfo>>() {
    @Override public void onSuccess(List<GroupInfo> groups) { showSearchResults(groups); }
    @Override public void onError(int code, String error) { showSearchError(error); }
}, Collections.singletonList(keyword), true, true);
```

The current user is not necessarily a member of a group returned by `searchGroups()`. Use [`isJoinGroup()`](/sdk/android/group/retrieving-groups/is-join-group) to determine whether they are a member.
