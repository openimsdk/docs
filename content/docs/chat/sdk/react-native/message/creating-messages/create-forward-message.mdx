Use `createForwardMessage()` to create a forwarded message from an existing message.

```ts
const message = await OpenIMSDK.createForwardMessage(sourceMessage);
```

`sourceMessage` must be a complete `MessageItem`. The call returns a new `MessageItem` ready to send to a direct or group chat.
