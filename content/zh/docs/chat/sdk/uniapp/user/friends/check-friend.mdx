---
title: '检查好友关系'
description: '检查当前用户与一组指定用户是否为好友。'
sourcePath: '/sdk/uniapp/user/friends/check-friend'
---

`checkFriend()` 直接接收用户 ID 数组，适合在资料卡或发起互动前批量确认好友关系。

```uts
import { checkFriend } from '@/uni_modules/unix-openim-sdk'

const response = await checkFriend(['user_a', 'user_b'])
const checks = response?.result ?? []
```

Promise 成功后返回 `OpenIMCheckFriendResult | null`，检查项位于 `result`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `userID` | `string` | 被检查用户的用户 ID。 |
| `result` | `number` | `1` 表示双方是好友，`0` 表示不是好友。 |

该方法只返回调用时的好友关系，不会触发好友事件。好友与黑名单是两种独立关系；需要判断黑名单状态时，应另行[查询黑名单](/sdk/uniapp/user/blacklist/get-black-list)。
