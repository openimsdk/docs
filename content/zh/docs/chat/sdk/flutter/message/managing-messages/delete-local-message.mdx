仅从当前设备的本地数据库中删除指定的单条消息：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 消息所属会话 ID。 |
| `clientMsgID` | `String` | 是 | 待删除消息的客户端消息 ID。 |

```dart
await OpenIM.iMManager.messageManager.deleteMessageFromLocalStorage(
  conversationID: conversationID,
  clientMsgID: clientMsgID,
);
```

## 返回结果

Future 成功表示目标消息已从当前设备本地数据库中成功移除。客户端应根据复合标识 `conversationID:clientMsgID` 从本地状态与 UI 列表中移除该消息。

该操作仅影响当前设备本地，不会删除服务端保存的漫游记录，不会通知其他端设备或会话对端，也不是撤回操作。若需要从本地与服务端同时删除消息并同步至多端，请参考[删除消息](/sdk/flutter/message/managing-messages/delete-saved-message)；若需要撤回已发出的消息并展示撤回提示，请参考[撤回消息](/sdk/flutter/message/managing-messages/revoke-a-message)。
