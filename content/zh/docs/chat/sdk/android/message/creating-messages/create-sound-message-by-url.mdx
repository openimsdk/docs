使用已上传至业务自有云存储或第三方 CDN 的音频远端 URL 创建语音消息对象。SDK 不会再次执行文件上传，适用于业务自行管理文件存储的场景。

```java
SoundElem soundElem = new SoundElem();
soundElem.setSourceUrl("https://example.com/audio/voice_sample.m4a");
soundElem.setDataSize(128000L);
soundElem.setDuration(15L);

Message message = OpenIMClient.getInstance().messageManager.createSoundMessageByURL(soundElem);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `soundElem` | `SoundElem` | 是 | 音频模型对象，至少设置音频下载地址 `sourceUrl`、播放时长 `duration` 以及文件大小 `dataSize`。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.VOICE`。

由于音频资源已预先上传，发送该消息时应调用[发送不经 OSS 的消息](/sdk/android/message/sending-messages/send-message-not-oss)直接投递，避免重复上传。
