```objc
[[OIMManager manager] getSpecifiedGroupMembersInfo:groupID usersID:userIDs
  onSuccess:^(NSArray<OIMGroupMemberInfo *> *members) { [self mergeMembers:members]; }
  onFailure:^(NSInteger code, NSString *message) { [self showErrorCode:code message:message]; }];
```

The success callback returns each target user's profile within the group. Cache it by `groupID:userID`.
