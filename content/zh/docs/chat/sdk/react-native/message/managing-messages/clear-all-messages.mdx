清理当前登录账号在本地及服务端保存的全部消息记录。

```ts
await OpenIMSDK.deleteAllMsgFromLocalAndSvr();
```

## 返回结果

调用完成后，当前账号在本地与服务端的全量消息记录已被清理，其他会话成员已接收的消息不受影响。

这是不可逆的账号级操作，执行前应向用户明确说明影响范围并要求二次确认。清理完成后，当前用户在各个设备上的历史消息均会被同步清空。客户端应清空本地各会话的消息列表与缓存。
