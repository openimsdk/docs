`ex` 是完整字符串，SDK 不会自动合并 JSON。多个业务模块共用该字段时，应在业务层按约定的数据结构合并，保留其他模块的命名空间。

```uts
import { setGroupMemberInfo } from '@/uni_modules/unix-openim-sdk'

await setGroupMemberInfo({
  groupID: groupID,
  userID: targetUserID,
  ex: JSON.stringify({
    title: 'maintainer',
  }),
})
```

示例展示一次完整覆盖。仅在业务确认 `ex` 使用 JSON 格式时采用这种写法；如需保留旧数据，应先把旧值解析为应用明确定义的数据类型，在业务层完成合并后再序列化整个新值。否则应按双方约定处理原始字符串。Promise 成功后，收到 `onGroupMemberInfoChanged()` 时再更新对应成员。
