Query audio format constraints, sampling rate requirements, maximum recording duration, and file size limits supported by the active speech-to-text provider. To execute audio transcription, see [Transcribe audio](/sdk/react-native/message/composing-messages/transcribe-audio).

```ts
const capabilities = await OpenIMSDK.speechToTextCapabilities();
```

## Return value

A resolved Promise returns a `SpeechToTextCapabilities` object:

| Field | Type | Description |
| --- | --- | --- |
| `format` | `string[]` | List of supported audio encoding formats. |
| `sampleRateHz` | `number` | Required audio sampling rate in Hertz (Hz). |
| `maxRecordTimeMs` | `number` | Maximum allowed audio duration in milliseconds. |
| `maxFileSize` | `number` | Maximum allowed audio file size in bytes. |
| `provider` | `string` | Identification tag for the speech recognition service provider. |
