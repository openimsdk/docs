description: '批量设置会话分组的显示顺序。'

---

会话分组属于商业版能力。`setConversationGroupOrder()` 接收一个包含 `conversationGroupOrders` 数组的对象；每项必须同时提供分组 ID 和新的顺序值。

```uts
import { setConversationGroupOrder } from '@/uni_modules/unix-openim-sdk'

await setConversationGroupOrder({
  conversationGroupOrders: [
    { conversationGroupID: firstGroupID, order: 100 },
    { conversationGroupID: secondGroupID, order: 200 },
  ],
})
```

`order` 的排序方向由产品统一约定。Promise 成功表示排序请求已经完成，不返回可直接刷新界面的分组数据；可以先按提交值更新本地顺序，并在事件到达后重新查询分组列表确认最终顺序。
