Use the non-deprecated overload with `GetGroupApplicationListAsRecipientReq`. The request can filter by `offset`, `count`, `groupIDs`, and `handleResults`.

```java
GetGroupApplicationListAsRecipientReq request = new GetGroupApplicationListAsRecipientReq(0, 20);
OpenIMClient.getInstance().groupManager.getRecvGroupApplicationList(
    new OnBase<List<GroupApplicationInfo>>() {
        @Override public void onSuccess(List<GroupApplicationInfo> items) { mergeReceivedApplications(items); }
        @Override public void onError(int code, String error) { showApplicationError(error); }
    }, request);
```

Merge application events by their `groupID` and `userID`. Do not use a list index as an application identifier.
