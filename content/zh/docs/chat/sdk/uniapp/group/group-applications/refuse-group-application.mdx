群主或管理员可以使用 `refuseGroupApplication()` 拒绝一条待处理的入群申请。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 申请对应的群组 ID。 |
| `fromUserID` | `string` | 是 | 申请人的用户 ID，对应申请记录的 `userID`。 |
| `handleMsg` | `string` | 是 | 拒绝说明；没有说明时传空字符串。 |

```uts
import { refuseGroupApplication } from '@/uni_modules/unix-openim-sdk'

await refuseGroupApplication({
  groupID: application.groupID,
  fromUserID: application.userID,
  handleMsg: '暂不接受该申请',
})
```

Promise 成功表示 SDK 已完成本次拒绝请求。收到 `onGroupApplicationRejected()` 后，再使用 `groupID:userID` 更新对应申请；完整监听见[获取收到的入群申请](/sdk/uniapp/group/group-applications/get-group-application-list-as-recipient)。
