## 概述

**OpenIMSDK** 是面向开发者的**应用内即时通讯开源解决方案**。开发者可以在自有应用中集成聊天、群组、好友、通知和音视频通话等能力，无需从零搭建复杂的通信系统。

OpenIMSDK 不同于 WeChat、Slack 等独立聊天应用，它专注于提供**可嵌入的通信能力**。部署方可以自行管理数据、交互逻辑与部署方式，并按业务场景扩展系统。

OpenIMSDK 也是 Twilio、Sendbird 等即时通讯云平台的开源替代方案。它支持私有化部署和信创环境落地，可用于替代依赖第三方 IM 云服务的架构。

## 主要能力

OpenIMSDK 覆盖应用内实时通信的主要模块：

- **统一 API：**提供一致的 API 设计和完整的 SDK 文档，便于在不同平台接入聊天能力。
- **开源范围：**提供可用于自托管和二次开发的源代码，部署方可以根据业务约束进行调整。
- **智能交互扩展：**支持接入 LLM、多智能体等智能交互场景。
- **二次开发：**可以根据业务需要调整聊天逻辑、交互方式和 UI。
- **私有化部署：**可以部署在自有服务器、私有云或信创环境中，由部署方管理数据、网络和合规策略。
- **服务端架构：**OpenIMServer 采用 Go 微服务架构，支持高并发、高可用、集群部署和水平扩展。
- **消息可达性测试：**通过模拟真实用户行为，验证消息发送、接收和推送链路的可靠性。

## 生态组件

- **OpenIMServer：**IM 基础服务端，负责用户之间的实时消息通信，可以部署在自有服务器或私有云环境中。
- **ChatServer：**业务扩展服务端，提供账号注册、管理后台和其他应用层业务能力；如果已有业务系统，可以按需接入。
- **REST API：**允许可信业务后端以管理员权限调用 OpenIMServer，管理用户、群组、消息等资源。
- **Webhook：**当指定事件发生前后，OpenIMServer 通过 HTTP 或 HTTPS 请求通知业务后端，业务后端可以据此干预后续流程或同步数据。
- **OpenIMClientSDK：**覆盖 iOS、Android、Web、Flutter、uni-app、小程序、React Native 和 Electron 等平台，提供聊天、群组、关系链和推送接入能力。

## 部署方式

- **自建私有部署：**在本地、私有云或信创环境中运行 OpenIMServer，并按业务需要部署 ChatServer。当前文档提供 Docker Compose、源码和集群部署方案。

## 适用场景

- 应用内聊天与社交系统
- AI 助手、智能客服与虚拟助理
- 企业协作与视频会议平台
- 电商与客服统一沟通中心
- 医疗与教育实时互动系统
- 政企专用安全通信系统

OpenIMSDK 可以作为自托管的通信基础设施。
