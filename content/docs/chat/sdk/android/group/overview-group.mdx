A group is represented by `GroupInfo`. Its `groupID` is the unique target identifier for profile, member, application, and permission operations. `GroupMembersInfo` represents a member's group-specific nickname, role, mute expiration time, and extra data. One-to-one relationships and conversation unread counts do not belong to the group APIs.

`GroupManager` delivers group profile changes, member changes, application handling, and joined-group changes through one `OnGroupListener`. Set the listener once in a shared state layer and merge events by `groupID` or `userID`.

```java
OpenIMClient.getInstance().groupManager.setOnGroupListener(new OnGroupListener() {
    @Override public void onGroupInfoChanged(GroupInfo group) {
        groupStore.put(group.getGroupID(), group);
    }

    @Override public void onGroupMemberInfoChanged(GroupMembersInfo member) {
        memberStore.put(member.getGroupID() + member.getUserID(), member);
    }
});
```

A successful callback from a group profile or member operation only means that the request completed. Use the corresponding group event or a fresh query as the source of truth.
