从 `onReceiveNewInvitation` 取得原始 `SignalingInfo` 后接受邀请：

```dart
final credentials = await OpenIM.iMManager.signalingManager
    .signalingAccept(info: receivedInfo);
```

必须沿用收到的对象，不能重建只有 `roomID` 的资料。Future 成功返回 `SignalingCertificate`；取得有效的 `token` 和 `roomID` 后再进入媒体房间。
