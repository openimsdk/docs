当图片、视频、音频或文件等多媒体资源已通过业务文件服务或第三方 CDN 上传并取得了访问 URL 时，可调用 `sendMessageNotOss()` 直接发送消息。该接口会跳过 SDK 内置的 OSS 上传流程，直接投递消息协议体。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `recvID` | `string` | 条件必填 | 单聊时填写接收方用户 ID；群聊时传空字符串。 |
| `groupID` | `string` | 条件必填 | 群聊时填写目标群组 ID；单聊时传空字符串。 |
| `message` | `MessageItem` | 是 | 由 URL 型消息创建 API 返回、已经包含远端资源信息的待发送消息。 |
| `offlinePushInfo` | `OfflinePush` | 否 | 离线推送标题、描述和平台配置。 |
| `isOnlineOnly` | `boolean` | 否 | 是否只向在线客户端投递；此类消息不进入本地历史。 |

```ts
const { data: sentMessage } = await openimsdk.sendMessageNotOss({
  recvID: receiverUserID,
  groupID: '',
  message: urlMessage,
});
```

调用前请确保资源 URL、文件大小、多媒体尺寸或时长等参数来自实际的上传结果。

接口调用成功后，返回的 `data` 为服务端确认的最新 `MessageItem` 对象。业务层可根据 `clientMsgID` 匹配本地消息并更新其发送状态。完整字段结构请参考[消息概览](/sdk/wasm/message/overview-message)。

需要注意：该方法不执行文件上传操作；如果消息仍由本地 `File` 对象创建且需要由 SDK 统一上传到 OpenIM OSS，请使用普通 [发送消息](/sdk/wasm/message/sending-messages/send-message) 接口。
