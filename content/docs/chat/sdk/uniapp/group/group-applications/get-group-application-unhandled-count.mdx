Invoke `getGroupApplicationUnhandledCount()` to retrieve the number of pending group join requests awaiting review, typically used to display badges or notification dots on group administration entry points.

## Parameters

The UTS signature requires `offset` and `count` parameters:

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `offset` | `number` | Yes | Pagination offset; pass `0` for initial counts. |
| `count` | `number` | Yes | Page limit for evaluating records. |

## Code example

```uts
import {
  getGroupApplicationUnhandledCount,
} from '@/uni_modules/unix-openim-sdk'

const count = await getGroupApplicationUnhandledCount({
  offset: 0,
  count: 20,
})
setPendingApplicationCount(count != null ? count : 0)
```

## Return value

The Promise resolves with a `number | null` indicating the unhandled count. A `null` return value indicates that no result could be obtained and should not be treated as a confirmed count of zero.

## State changes after the call

This is a read-only query that does not modify records or clear badge indicators. To maintain a real-time badge count, monitor `onGroupApplicationBadgeCountChanged` as detailed in [Get received group applications](/sdk/uniapp/group/group-applications/get-group-application-list-as-recipient).
