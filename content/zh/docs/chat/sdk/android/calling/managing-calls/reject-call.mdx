用户拒绝来电时，将收到的原始 `SignalingInfo` 提交至拒绝通话接口：

```java
OpenIMClient.getInstance().signalingManager.signalingReject(
    new OnBase<String>() {
        @Override
        public void onSuccess(String result) {
            // 拒绝信令请求已完成。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    signalingInfo
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `signalingInfo` | `SignalingInfo` | 是 | 收到邀请时的完整信令对象，必须保留原始 `roomID`、邀请人和被邀请人等字段。 |

## 返回结果

成功回调表示服务端已记录拒接信令。被叫端应同步关闭来电振铃及接听等待界面。

主叫方及房间其他成员将通过事件收到拒接通知，客户端可结合 `roomID` 与 `userID`（即 `roomID:userID`）更新界面中该成员的状态，具体监听配置请参考[处理通话事件](/sdk/android/calling/managing-calls/handle-call-events)。
