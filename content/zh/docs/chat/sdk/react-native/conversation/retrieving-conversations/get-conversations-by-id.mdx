已经持有一组会话 ID 时，调用 `getMultipleConversation()` 批量获取会话信息。

```ts
const conversations = await OpenIMSDK.getMultipleConversation(conversationIDList);
```

## 参数说明

`conversationIDList` 是要查询的会话 ID 数组。

## 返回结果

调用完成后返回 `ConversationItem[]`，返回结果可能少于传入的会话 ID 数量，未返回的会话 ID 表示 SDK 当前未找到对应会话。单个会话的字段说明见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。
