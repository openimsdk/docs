---
title: '删除会话及消息'
description: '删除指定会话记录及当前账号保存的全部会话消息。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/delete-conversation-with-messages'
---

产品语义为“删除此聊天”时使用；调用前应要求用户确认。

```ts
import sdk, { DeleteConversationAndDeleteAllMsgReq } from '@openimsdk/imsdk';

const request: DeleteConversationAndDeleteAllMsgReq = {
  conversationID: conversationID,
};
await sdk.deleteConversationAndDeleteAllMsg(request);
```

该操作删除当前账号的会话入口和本地消息，不删除好友关系、不退出群组，也不影响其他用户。Promise 成功后清理当前页面状态，并重新查询列表校准。
