Query the count of unhandled friend requests received since a given timestamp, ideal for rendering notification badges or contact tab dots:

```ts
const count = await OpenIMSDK.getFriendApplicationUnhandledCount({
  time,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `time` | `number` | Yes | Start timestamp in Unix milliseconds. Pass `0` to count all unhandled friend applications. |

## Return value

Resolves to a `number` representing the count of unhandled friend applications since the specified time. This query reads a snapshot of the counter and does not mutate conversation unread counts or emit events.
