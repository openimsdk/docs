---
title: '将全部会话标为已读'
description: '使用 WASM SDK 清零当前所有未读会话的未读数。'
sourcePath: '/sdk/wasm/conversation/managing-conversations/mark-all-conversations-read'
---

当用户点击“一键已读”或“全部已读”时，可调用 `markAllConversationMessageAsRead()` 将当前账号下所有存在未读消息的会话一次性清零：

```ts
await openimsdk.markAllConversationMessageAsRead();
```

接口调用成功表示 SDK 已向服务端完成全部未读会话的已读标记请求。

随后，SDK 会分别触发 `SdkEvent.OnConversationChanged` 事件更新各受影响会话的未读数，并触发 `SdkEvent.OnTotalUnreadMessageCountChanged` 事件将总未读数同步清零。完整的事件监听配置请参考[获取会话列表](/sdk/wasm/conversation/retrieving-conversations/retrieve-conversation-list)与[获取总未读数](/sdk/wasm/conversation/managing-conversations/get-total-unread-count)。
