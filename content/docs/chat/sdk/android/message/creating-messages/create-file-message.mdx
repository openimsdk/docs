Construct a file message object using a relative path within the SDK initialization data directory. When sending via [Send a message](/sdk/android/message/sending-messages/send-message), the SDK automatically uploads the file and tracks transfer progress.

## Code example

```java
String filePath = "documents/annual_report.pdf";
String fileName = "Annual_Report.pdf";

Message message = OpenIMClient.getInstance().messageManager.createFileMessage(
    filePath,
    fileName
);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `filePath` | `String` | Yes | File path relative to the SDK initialization data directory. |
| `fileName` | `String` | Yes | Display name of the file (such as `Annual_Report.pdf`), used by the receiver for display and saving. |

## Return value

Returns the created `Message` object with `contentType` set to `MessageType.FILE`.

## State changes after the call

1. **Local initialization**: Initializes the local `Message` structure without starting network uploads.
2. **Transmission**: Call [Send a message](/sdk/android/message/sending-messages/send-message) to upload and send the file. For absolute local filesystem paths, see [Create a file message from a local path](/sdk/android/message/creating-messages/create-file-message-by-file).
