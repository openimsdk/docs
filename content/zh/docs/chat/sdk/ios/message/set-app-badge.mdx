调用设置应用角标接口可向 SDK 上报应用当前展示的消息总未读数，便于服务端和推送服务同步角标计数。

```objc
[[OIMManager manager] setAppBadge:totalUnreadCount
                        onSuccess:^(NSString * _Nullable data) {
                            // SDK 已接受本次角标值
                        }
                        onFailure:^(NSInteger code, NSString * _Nullable msg) {
                            // 根据业务需要处理错误
                        }];
```

## 参数说明

- `totalUnreadCount`：应用当前的总未读数（非负整数）。通常在消息总未读数变化、登录同步完成或清空未读消息后更新；请勿传入单个会话的局部未读数。

## 返回结果

- `onSuccess`：SDK 成功接受本次角标值。该调用仅同步角标状态，不会改变本地各会话的未读计数。若需在桌面 App 图标上展示红点角标，还需结合 iOS 系统的通知与角标机制更新桌面 UI。
- `onFailure`：更新角标失败，回调返回错误码 `code` 和错误信息 `msg`。

消息总未读数的查询和持续维护见[获取消息总未读数](/sdk/ios/conversation/managing-conversations/get-total-unread-count)。
