---
title: '挂断通话'
description: '使用 Android SDK 挂断已经建立的通话。'

---

通话建立后，任一参与者都可以挂断当前通话。传入当前通话保存的完整 `SignalingInfo`，其中的 `roomID` 必须与当前媒体房间一致。

```java
OpenIMClient.getInstance().signalingManager.signalingHungUp(
    new OnBase<String>() {
        @Override
        public void onSuccess(String result) {
            // 信令操作已完成。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    signalingInfo
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `signalingInfo` | `SignalingInfo` | 是 | 当前通话的信令对象，其中的 `roomID` 必须与正在进行的通话房间一致。 |

## 返回结果

成功回调表示服务端已完成挂断信令处理。发起挂断的一方应主动关闭通话界面、退出音视频房间并释放麦克风和摄像头等本地硬件资源。

房间内其他参与者将收到挂断或参与者断开事件，客户端可根据 `roomID`（或 `roomID:userID`）关闭界面或更新成员列表，具体事件处理请参考[处理通话事件](/sdk/android/calling/managing-calls/handle-call-events)。
