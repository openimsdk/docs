OpenIM iOS SDK 基于 Objective-C 封装，为 iPhone 和 iPad 应用提供原生即时通讯能力。开发者可通过 `[OIMManager manager]` 获取全局共享管理器，并在整个应用生命周期中复用该实例。

OpenIM iOS SDK 围绕业务 API、Delegate 委托设计与生命周期约定展开，为应用提供即时通讯支持。好友和会话列表推荐使用分页接口。

## 接入流程

1. 安装 `OpenIMSDK`，准备可访问的 OpenIMServer 地址。
2. 从业务后端取得当前用户的 `userID` 和 Token。
3. 配置 `OIMInitConfig` 并完成 SDK 初始化。
4. 在登录前注册业务 delegate，再发起用户登录。
5. 使用用户、好友、会话、群组、消息和音视频通话信令 API 构建业务界面。
6. 退出或切换账号时移除 delegate，并清理当前账号的应用状态。

## 关键数据边界

- 单聊发送时填写 `recvID`，群聊发送时填写 `groupID`。
- `OIMConversationInfo` 保存会话展示信息和未读数；`OIMGroupInfo` 与 `OIMGroupMemberInfo` 保存群组及成员关系。
- 查询回调（Callback）返回调用时刻的数据快照，Delegate 委托则用于监听后续的实时增量事件；写操作回调成功表明当前请求已完成，不代表多端状态已全部同步到位。
