群主或管理员可以调用接受入群申请接口，同意一条待处理的入群申请。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 申请对应的群组 ID。 |
| `fromUserID` | `string` | 是 | 申请人的用户 ID，对应申请记录的 `userID`。 |
| `handleMsg` | `string` | 是 | 处理说明；没有说明时传空字符串。 |

```uts
import { acceptGroupApplication } from '@/uni_modules/unix-openim-sdk'

await acceptGroupApplication({
  groupID: application.groupID,
  fromUserID: application.userID,
  handleMsg: '同意加入',
})
```

Promise 成功表示 SDK 已完成本次同意请求。不要仅根据 Promise 成功在本地构造最终群成员资料；收到入群申请被同意事件后，再按 `groupID:userID` 更新申请记录的处理状态，新成员真正加入时会收到对应的群成员加入事件。完整申请事件监听与处理逻辑请参考[获取收到的入群申请](/sdk/uniapp/group/group-applications/get-group-application-list-as-recipient)。
