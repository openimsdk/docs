使用群组 ID、申请说明和加入途径发起入群申请。

```ts
await OpenIMSDK.joinGroup({
  groupID,
  reqMsg: '申请加入项目讨论组',
  joinSource: GroupJoinSource.Search,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 目标群组 ID。 |
| `reqMsg` | `string` | 是 | 入群申请说明；没有说明时传空字符串。 |
| `joinSource` | `GroupJoinSource` | 是 | 发起入群的途径。 |
| `ex` | `string` | 否 | 业务扩展字符串。 |

`joinSource` 常用值如下：

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `GroupJoinSource.Invitation` | `2` | 通过邀请加入。 |
| `GroupJoinSource.Search` | `3` | 通过搜索加入。 |
| `GroupJoinSource.QrCode` | `4` | 通过二维码加入。 |

`joinSource` 仅记录加入途径，不决定群组是否需要管理员审批。

## 返回结果

调用完成后，入群请求已提交成功。

如果群组设置为允许直接加入，或者管理员审核同意后，当前用户成功加入群组时会收到 `OnJoinedGroupAdded` 事件通知。客户端应以 `groupID` 为合并标识将该群组添加到已加入的群组列表。完整事件监听说明见[群组概览](/sdk/react-native/group/overview-group)。
