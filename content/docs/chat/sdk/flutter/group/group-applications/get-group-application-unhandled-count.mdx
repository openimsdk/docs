Query the count of pending, unhandled group join applications received by the current user as an owner or administrator, commonly used for badges or notification dots:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `time` | `int` | Yes | Epoch timestamp in seconds. Pass `0` to count all unhandled group applications. |

## Code example

```dart
final count = await OpenIM.iMManager.groupManager
    .getGroupApplicationUnhandledCount(
  GetGroupApplicationUnhandledCountReq(time: 0),
);
```

## Return value

A successful `Future` returns the count of unhandled group join applications as an `int`.

This query returns an immediate numerical snapshot; it does not modify application records or emit event notifications. When new applications arrive or decisions sync across sessions, see [Group applications overview](/sdk/flutter/group/group-applications/overview-group-applications).
