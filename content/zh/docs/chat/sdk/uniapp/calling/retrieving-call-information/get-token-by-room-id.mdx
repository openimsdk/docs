---

在已知 `roomID` 但需要重新取得或刷新加入媒体房间的凭据时，获取房间 Token：

```uts
import {
  signalingGetTokenByRoomID,
} from '@/uni_modules/unix-openim-sdk'

const result = await signalingGetTokenByRoomID({ roomID })

if (result?.token != null) {
  await mediaEngineJoin(roomID, result.token!, result.liveURL)
}
```

Promise 成功后返回 `OpenIMSignalingGetTokenByRoomIDResult | null`，其中 `token` 和 `liveURL` 都可能为空。返回结果不重复包含 `roomID`；连接媒体引擎时继续使用本次查询参数中的值。

没有取得有效 `token` 时，不应继续进入媒体房间；应用可在网络恢复后重新查询获取。通话整体状态管理与事件监听见[处理通话事件](/sdk/uniapp/calling/managing-calls/handle-call-events)。
