Call `getJoinedGroupList()` to retrieve every group that the current account has joined.

```ts
const groups = await OpenIMSDK.getJoinedGroupList();
```

## Return value

When the call completes, it returns `GroupItem[]`. For many groups, use [Get joined groups by page](/sdk/react-native/group/retrieving-groups/get-joined-group-list-page) to retrieve them in batches.
