---
title: '删除好友'
description: '删除当前用户与指定用户的好友关系。'
sourcePath: '/sdk/harmony/user/friends/delete-friend'
---

```ts
import sdk, { DeleteFriendReq } from '@openimsdk/imsdk';

const request: DeleteFriendReq = {
  userID: friendUserID,
};
await sdk.deleteFriend(request);
```

Promise 成功只表示删除请求完成。客户端按 `friendUserID`（即目标 `userID`）从好友列表移除，完整事件监听与校准请参考 [分页获取好友列表](/sdk/harmony/user/friends/get-friend-list-page)。删除好友不会自动加入黑名单或删除历史会话；加入黑名单请参考 [将用户加入黑名单](/sdk/harmony/user/blacklist/add-black)。
