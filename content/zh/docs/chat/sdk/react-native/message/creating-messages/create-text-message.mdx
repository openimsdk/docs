创建基础纯文本消息。

```ts
const message = await OpenIMSDK.createTextMessage('你好，欢迎加入讨论。');
```

## 参数说明

传入消息的正文文本内容字符串。

## 返回结果

调用完成后返回已创建的 `MessageItem` 消息对象，其中 `textElem` 保存纯文本内容。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送消息](/sdk/react-native/message/sending-messages/send-message)将消息投递到单聊或群聊会话中。
