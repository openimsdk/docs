按群组 ID 批量查询群资料，适用于在已知群组 ID 时获取其最新群详情。该接口不属于公开群探索目录，也不用于按群名称搜索陌生群组。

```uts
import { getSpecifiedGroupsInfo } from '@/uni_modules/unix-openim-sdk'

const result = await getSpecifiedGroupsInfo(groupIDs)
const groups = result != null ? result.groups : []
```

`groupIDs` 是待查询的群组 ID 数组。查询单个群组时仍需传入数组，并检查 `groups` 中是否存在对应结果。

Promise 成功后返回 `OpenIMGroupListResult | null`；非空结果的 `groups` 是匹配的 `OpenIMGroupItem[]`。返回数组不保证与输入 ID 按位置一一对应，客户端应以 `groupID` 为合并标识建立对应关系。群资料主要字段见[群组概览](/sdk/uniapp/group/overview-group)。

查询只返回调用时的群资料快照，不会触发群组事件。页面处于活跃状态时，应通过[群组概览](/sdk/uniapp/group/overview-group)中说明的群资料事件同步后续变化，并在网络重连或关键操作后重新查询以校准最新资料。
