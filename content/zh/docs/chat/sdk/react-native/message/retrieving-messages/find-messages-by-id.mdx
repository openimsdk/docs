根据会话 ID 与客户端消息 ID 列表精确查找消息。此方法适合从搜索结果、引用回复、系统通知或离线推送跳转到特定消息时调用。

```ts
const result = await OpenIMSDK.findMessageList([
  {
    conversationID,
    clientMsgIDList: [clientMsgID],
  },
]);

const targetMessage = result.findResultItems?.[0]?.messageList?.[0];
```

## 参数说明

接收一个包含查询条件的数组，数组中的每个对象代表一个会话维度的查询：

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 目标消息所属的会话 ID。 |
| `clientMsgIDList` | `string[]` | 是 | 要查找的消息客户端 ID 列表。 |

## 返回结果

调用成功后返回 `SearchMessageResult` 对象，精确查找的结果位于 `findResultItems` 列表中：

- 列表中的每一项包含所属会话的 `conversationID` 以及匹配到的消息列表 `messageList: MessageItem[]`。
- 若本地或服务端未找到对应 ID 的消息，结果项可能为空或其 `messageList` 为空数组。
- 完整的搜索结果数据结构及高级字段请参考[搜索消息](/sdk/react-native/message/searching-messages/search-messages)。
