Set or clear the marked flag on a conversation for the current account. Marked conversations can be highlighted or organized into custom flagged views:

```ts
await OpenIMSDK.setConversation({
  conversationID,
  isMarked: true,
});
```

Pass `false` for `isMarked` to unmark the conversation. To manage conversation grouping, see [Conversation groups overview](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups).

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `string` | Yes | Target conversation ID to update. |
| `isMarked` | `boolean` | No | Set `true` to mark the conversation, or `false` to clear the mark. |

## Return value

A resolved Promise confirms that the marked status of the conversation has been updated.

State changes trigger the `OnConversationChanged` event. Use `conversationID` to locate the target conversation entry in your state store and reconcile its `isMarked` value. For complete event listeners, see [Retrieve conversation list](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list).
