---
title: '将全部会话标为已读'
description: '清零当前账号所有本地未读会话的未读数。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/mark-all-conversations-read'
---

当用户在界面执行“全部已读”操作时，一键清零当前账号在本地记录中的所有未读会话未读数。

```uts
import { markAllConversationMessageAsRead } from '@/uni_modules/unix-openim-sdk'

await markAllConversationMessageAsRead()
```

Promise 成功表示 SDK 已完成本次找到的全部未读会话处理，不表示相关会话事件已经全部到达，也不保证其他客户端的界面已同步完成。

客户端可通过会话变更事件按 `conversationID` 批量更新各会话未读状态，并通过总未读数变更事件同步更新账号未读角标。完整监听分别见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)和[获取消息总未读数](/sdk/uniapp/conversation/managing-conversations/get-total-unread-count)。若需校准，可重新拉取会话列表与总未读数刷新界面。
