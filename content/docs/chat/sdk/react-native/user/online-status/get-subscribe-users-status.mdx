Retrieve the latest online presence states for all users currently subscribed by this account:

```ts
const states = await OpenIMSDK.getSubscribeUsersStatus();
```

## Return value

Resolves to an array of `UserOnlineState[]`. Update local presence indicators keyed by `userID`. If target users have not yet been subscribed, follow [Subscribe to user online status](/sdk/react-native/user/online-status/subscribe-users-status).
