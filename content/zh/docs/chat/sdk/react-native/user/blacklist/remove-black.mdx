将指定用户移出当前账号的黑名单。

```ts
await OpenIMSDK.removeBlack(blackUserID);
```

## 参数说明

`blackUserID` 是要移出黑名单的目标用户 ID。

## 返回结果

调用完成后，目标用户已被移出黑名单。

移出黑名单后会触发 `OnBlackDeleted` 事件通知。客户端应以 `userID` 为合并标识从本地黑名单列表中移除对应记录。完整事件监听说明见[获取黑名单](/sdk/react-native/user/blacklist/get-black-list)。
