OpenIM Android SDK 使用 `userID` 标识用户。实现资料卡、好友添加、联系人或黑名单功能时，需要区分应用用户的公开资料、当前用户维护的好友关系，以及黑名单状态。

群成员列表、群内昵称、群角色和成员管理属于群组能力，应使用群组相关 API；用户 API 只处理用户资料、好友关系、好友申请、黑名单和在线状态。

## 用户类型

Android SDK 会根据使用场景返回不同的用户对象：

| 类型                    | 适用场景                                                             | 主要 API                                                          |
| ----------------------- | -------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `LocalUser`             | 当前登录用户的本地资料、设置页、头像、昵称和账号级接收设置           | `getSelfLocalUserInfo()`、`setSelfInfo()`                         |
| `PublicUserInfo`        | 查询应用用户、查找好友候选人和展示陌生人资料卡                       | `getUsersInfo()`                                                  |
| `UserInfo`              | Android wrapper 返回的组合对象，可承载公开资料、好友资料或黑名单资料 | `getFriendListPage()`、`getFriendsInfo()`、`getBlacklist()`       |
| `FriendInfo`            | 当前用户的好友列表、好友备注和关系扩展字段                           | `searchFriends()`、`getFriendListPage()`                          |
| `FriendApplicationInfo` | 好友申请双方、处理状态和附言                                         | 好友申请查询与 listener                                           |
| `BlacklistInfo`         | 当前用户拉黑的用户及黑名单关系字段                                   | `getBlacklist()`、`addBlacklist()`、`removeBlacklist()`           |
| `UsersOnlineStatus`     | 用户在线状态和在线平台列表                                           | `subscribeUsersOnlineStatus()`、`getSubscribeOnlineUsersStatus()` |

同一个 `userID` 可能同时出现在公开资料、好友资料、黑名单和群成员资料中。展示联系人信息时优先使用 `UserInfo.getFriendInfo()`；只需要账号公开资料时使用 `PublicUserInfo`；黑名单页面使用 `UserInfo.getBlackInfo()`。会话列表和聊天页标题属于会话数据，应使用会话对象中的展示名称。

所有列表和事件都应使用 `userID` 作为稳定标识。好友申请同时包含申请方和接收方，应使用 `fromUserID:toUserID` 标识一条申请。

## 状态更新

用户相关事件由对应能力页负责监听和合并：

- 当前用户资料变化：见[更新当前用户资料](/sdk/android/user/user-profile/set-self-info)。
- 好友申请变化：见[获取收到的好友申请](/sdk/android/user/friend-applications/get-recv-friend-application-list)。
- 好友关系和好友资料变化：见[分页获取好友列表](/sdk/android/user/friends/get-friend-list-page)。
- 黑名单变化：见[拉黑用户](/sdk/android/user/blacklist/add-blacklist)。
- 在线状态变化：见[订阅用户在线状态](/sdk/android/user/online-status/subscribe-users-online-status)。

Android SDK 的 `UserInfoManager` 和 `FriendshipManager` 各保存一个 listener，`setOnUserListener()` 和 `setOnFriendshipListener()` 都采用替换语义。应用应在统一状态层组合各页面所需 callback，并分别设置一次，不能让多个页面重复设置而覆盖其他 callback。
