通过创建会话分组接口，可为当前登录用户创建自定义会话分组。普通分组必须提供名称；若需在创建时一并加入某个会话，可传入该会话的 `conversationID`：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `name` | `NSString *` | 必填，分组名称。 |
| `order` | `NSNumber *` | 可选，分组排序值。 |
| `ex` | `NSString *` | 可选，业务自定义扩展字符串。 |
| `conversationID` | `NSString *` | 可选，创建时一并加入该分组的会话 ID。 |
| `conversationGroupType` | `NSNumber *` | 可选，分组类型（`0` 为普通自定义分组，`1` 为规则筛选分组）。 |

```objc
#import <OpenIMSDK/CallbackProxy.h>
@import OpenIMCore;

NSDictionary *request = @{
    @"name": @"工作",
    @"order": @100,
    @"conversationID": @"c2c_user1002",
    @"conversationGroupType": @0,
};

NSData *requestData = [NSJSONSerialization dataWithJSONObject:request options:0 error:nil];
NSString *requestJSON = [[NSString alloc] initWithData:requestData
                                              encoding:NSUTF8StringEncoding];

CallbackProxy *callback = [[CallbackProxy alloc]
    initWithOnSuccess:^(NSString * _Nullable data) {
        if (data == nil) {
            return;
        }
        [self upsertConversationGroupJSON:data];
    }
    onFailure:^(NSInteger code, NSString * _Nullable message) {
        NSLog(@"CreateConversationGroup failed: %ld %@", (long)code, message);
    }];

Open_im_sdkCreateConversationGroup(callback, requestJSON);
```

状态以 `conversationGroupID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 的 `data` 参数返回包含新建分组信息的 JSON 字符串对象。常用属性包括 `conversationGroupID`、`name`、`order`、`version`、`conversationGroupType`、`hidden`、`unreadCount` 及 `conversationIDs`。客户端应以 `conversationGroupID` 为合并标识更新本地分组存储。

多端同步或后续增量变更会通过 `onConversationGroupAdded:` 事件广播，事件监听与详细说明请参见[会话分组概览](/sdk/ios/conversation/managing-conversation-groups/overview-conversation-groups)。
