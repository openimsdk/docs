调用 `addConversationsToGroups()` 可将一个或多个会话批量添加到一个或多个会话分组中。该操作仅建立会话与分组的归属关联，不会创建新会话，也不会影响消息收发与未读计数。

## 参数说明

| 参数                   | 类型       | 是否必填 | 说明                      |
| ---------------------- | ---------- | -------- | ------------------------- |
| `conversationIDs`      | `string[]` | 是       | 要添加的 OpenIM 会话 ID。 |
| `conversationGroupIDs` | `string[]` | 是       | 目标会话分组 ID。         |

```ts
await openimsdk.addConversationsToGroups({
  conversationIDs: [conversationID],
  conversationGroupIDs: [conversationGroupID],
});
```

## 返回结果

接口调用成功后，表示会话已成功加入指定分组。

随后 SDK 会触发 `SdkEvent.OnConversationGroupMemberAdded` 事件，事件数据包含分组信息、会话 ID 列表及会话详情对象。业务层可据此增量更新分组内的会话列表。完整的事件监听配置请参考[会话分组概览](/sdk/wasm/conversation/managing-conversation-groups/overview-conversation-groups)。
