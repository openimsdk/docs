创建 Markdown 格式的消息。

```ts
const message = await OpenIMSDK.createMarkdownMessage(
  '## 发布完成\n\n- Android\n- iOS',
);
```

## 参数说明

传入完整的 Markdown 格式文本字符串。

## 返回结果

调用完成后返回已创建的 `MessageItem` 消息对象，其中 `markdownTextElem` 保存 Markdown 文本内容。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送消息](/sdk/react-native/message/sending-messages/send-message)将消息投递到单聊或群聊会话中。接收端渲染不可信 Markdown 文本时，建议使用支持过滤不安全标签的安全渲染组件。
