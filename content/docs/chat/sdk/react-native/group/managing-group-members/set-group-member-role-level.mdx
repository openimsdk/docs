Promote a member to administrator or demote them back to regular member:

```ts
await OpenIMSDK.setGroupMemberInfo({
  groupID: 'group-001',
  userID: 'user-002',
  roleLevel: GroupMemberRole.Admin,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group ID. |
| `userID` | `string` | Yes | User ID of the member whose role is being configured. |
| `roleLevel` | `GroupMemberRole` | Yes | Target member role level. |

| Enum value | Value | Description |
| --- | --- | --- |
| `GroupMemberRole.Normal` | `20` | Regular group member. Pass this value to revoke administrator privileges. |
| `GroupMemberRole.Admin` | `60` | Group administrator. |
| `GroupMemberRole.Owner` | `100` | Group owner; used solely for role identification. |

Group ownership cannot be transferred by assigning `GroupMemberRole.Owner`. To transfer ownership, see [Transfer group ownership](/sdk/react-native/group/managing-group-members/transfer-group-owner).

## Return value

A resolved Promise confirms that the member's role level has been updated on the server.

Role changes trigger the `OnGroupMemberInfoChanged` event carrying the updated member profile. Reconcile the member's role status using the composite key `groupID:userID`. For complete event listeners, see [Get group member list by page](/sdk/react-native/group/retrieving-group-members/get-group-member-list).
