---
title: '检查好友关系'
description: '批量检查当前用户与指定用户是否为好友。'
sourcePath: '/sdk/harmony/user/friends/check-friend'
---

```ts
import sdk, { CheckFriendReq, CheckFriendResp } from '@openimsdk/imsdk';

const request: CheckFriendReq = {
  friendUserIDs: ['user_a', 'user_b'],
};
const response: CheckFriendResp = await sdk.checkFriend(request);
```

每个检查项包含 `userID` 与 `result`。`CheckFriendResult.IsFriend` 表示好友，`CheckFriendResult.NotFriend` 表示非好友。该查询不判断黑名单，也不会触发好友事件。
