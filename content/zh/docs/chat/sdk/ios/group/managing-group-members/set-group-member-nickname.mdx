---
title: '修改群内昵称'
description: '更新 iOS 成员的群内昵称。'
sourcePath: '/sdk/ios/group/managing-group-members/set-group-member-nickname'
---

传入 `groupID`、`userID` 和新的 `groupNickname`。成功 callback 表示服务端完成请求；最终资料通过 `onGroupMemberInfoChanged:` 或重新查询校准。

```objc
[[OIMManager manager] setGroupMemberNickname:groupID
  userID:targetUserID
  groupNickname:@"新的群内昵称"
  onSuccess:^(NSString * _Nullable data) { [self showSaved]; }
  onFailure:^(NSInteger code, NSString *message) {
    [self showErrorCode:code message:message];
  }];
```
