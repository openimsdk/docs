`burnDuration` is <span className="enterprise-field-badge">Commercial</span>.

```uts
import { setConversation } from '@/uni_modules/unix-openim-sdk'

await setConversation({ conversationID, burnDuration: 30 })
```

Use the server-defined unit, range, and disabled value. Client countdown UI does not itself delete server messages; reload the conversation to confirm the setting.
