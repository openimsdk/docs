---
title: '置顶或取消置顶消息'
description: '使用 setConversationPinnedMsg 设置会话消息的置顶状态。'
sourcePath: '/sdk/android/message/managing-messages/set-message-pinned'
---

最后一个参数为 `true` 置顶，`false` 取消置顶；变化通过 `onChangedPinnedMsg` 同步。

```java
messageManager.setConversationPinnedMsg(callback, conversationID, clientMsgID, true);
```
