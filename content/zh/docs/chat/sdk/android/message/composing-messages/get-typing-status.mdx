查询指定用户当前正在输入的平台 ID 列表。

```java
OpenIMClient.getInstance().conversationManager.getInputState(
    new OnBase<List<Integer>>() {
        @Override
        public void onSuccess(List<Integer> platformIDs) {
            boolean typing = platformIDs != null && !platformIDs.isEmpty();
            updateTypingState(conversationID, userID, typing);
        }

        @Override
        public void onError(int code, String error) {
            recordTypingStatusQueryFailure(code, error);
        }
    },
    conversationID,
    userID
);
```

成功回调返回平台 ID 列表；空列表表示该用户当前没有平台处于输入状态。输入状态发生变化时，通过[上报输入状态](/sdk/android/message/composing-messages/update-typing-status)页面介绍的回调接收通知。
