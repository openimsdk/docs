description: '使用 setCustomBusinessListener 接收独立于普通聊天消息的业务回调。'

自定义业务回调携带字符串，业务侧应按协议校验来源和 JSON 结构，不要将其直接当作 `Message` 渲染。

```java
messageManager.setCustomBusinessListener(new OnCustomBusinessListener() {
    @Override public void onRecvCustomBusinessMessage(String payload) { handleBusiness(payload); }
});
```

本页是 `onRecvCustomBusinessMessage` 的完整处理归属页。载荷应包含业务协议版本和稳定幂等 ID，并按该 ID 去重；不要依赖回调顺序，也不要使用自定义业务消息授予客户端权限。

`MessageManager` 只保存一个自定义业务 listener，后一次设置会替换前一次。应在应用级事件中心设置一次，并在退出或切换账号时停止向旧账号状态分发。
