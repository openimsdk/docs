`sendGroupMessageReadReceipt()` 与 `onRecvGroupReadReceipt` 属于<span className="enterprise-field-badge">商业版</span>。

```uts
import {
  off,
  onRecvGroupReadReceipt,
  sendGroupMessageReadReceipt,
} from '@/uni_modules/unix-openim-sdk'

const receiptSubscription = onRecvGroupReadReceipt((payload) => refreshReadState(payload))
await sendGroupMessageReadReceipt(receiptParams)
off(receiptSubscription)
```

参数使用 `OpenIMSendGroupMessageReadReceiptParams`。事件为 raw JSON，校验后按消息 ID合并；Promise 成功、事件到达和成员列表查询是不同阶段。
