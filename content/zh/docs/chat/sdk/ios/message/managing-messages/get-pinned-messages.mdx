---
title: '查询会话置顶消息'
description: '使用 iOS SDK 获取会话当前的置顶消息列表。'
sourcePath: '/sdk/ios/message/managing-messages/get-pinned-messages'
---

```objc
[[OIMManager manager] getConversationPinnedMsgWithConversationID:conversationID
    onSuccess:^(NSArray<OIMMessageInfo *> *messages) {
        [self replacePinnedMessages:messages ?: @[] conversationID:conversationID];
    }
    onFailure:nil];
```

成功数组只包含消息，不包含置顶时间和操作者。查询本身不触发事件；按 `clientMsgID` 去重。详细变化由[置顶或取消置顶消息](/sdk/ios/message/managing-messages/set-message-pinned)归属的 delegate 同步。
