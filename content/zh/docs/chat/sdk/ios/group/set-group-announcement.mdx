发布或更新群组公告（通常仅群主和管理员有权限操作）：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupInfoDictionary` | `NSDictionary *` | 包含 `groupID` 和待更新字典键值对的字典对象。 |

| 键名 | 类型 | 说明 |
| --- | --- | --- |
| `groupID` | `NSString *` | 目标群组 ID。 |
| `notification` | `NSString *` | 群公告内容，传空字符串可清空已有公告。注意此处为 `notification` 字段，而非群简介 `introduction`。 |

```objc
NSDictionary *changes = @{
    @"groupID": groupID,
    @"notification": announcement
};

[[OIMManager manager] setGroupInfoDictionary:changes
    onSuccess:^(NSString * _Nullable data) {
        [self showAnnouncementUpdated];
    }
    onFailure:^(NSInteger code, NSString *message) {
        [self showErrorCode:code message:message];
    }];
```

状态以 `groupID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 表示服务端已接收公告更新。群内各端随后会通过群资料变更事件收到更新后的 `OIMGroupInfo`，完整事件处理见[群组概览](/sdk/ios/group/overview-group)。
