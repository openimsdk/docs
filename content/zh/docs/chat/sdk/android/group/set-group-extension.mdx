---
title: '设置群组扩展字段'
description: '通过 GroupInfo.ex 保存应用定义的群组扩展数据。'
sourcePath: '/sdk/android/group/set-group-extension'
---

`GroupInfo.ex` 是完整字符串，SDK 不会合并 JSON。多个业务模块共用该字段时，应由应用读取旧值、合并自己的命名空间后再提交。

```java
GroupInfo update = new GroupInfo();
update.setGroupID(groupID);
update.setEx("{\"projectCode\":\"mobile\",\"archived\":false}");

OpenIMClient.getInstance().groupManager.setGroupInfo(update, new OnBase<String>() {
    @Override public void onSuccess(String data) { markExtensionSubmitted(groupID); }
    @Override public void onError(int code, String error) { showExtensionError(error); }
});
```

不要将访问令牌、密钥或仅适合本机的 UI 状态写入群扩展字段。
