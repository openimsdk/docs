---
title: '取消通话邀请'
description: '由发起方取消尚未接通的通话邀请。'
sourcePath: '/sdk/harmony/calling/managing-calls/cancel-call'
---

```ts
import sdk, { SignalingCancelReq } from '@openimsdk/imsdk';

const request: SignalingCancelReq = {
  invitation: invitation,
  offlinePush: offlinePush,
  participant: participant,
  userID: peerUserID,
};
await sdk.signalingCancel(request);
```

邀请应使用发起时保存的完整对象，`userID` 为需要接收取消信令的被邀请人。Promise 成功后，客户端可根据 `roomID` 结束本地等待状态并释放相关资源；对端收到取消事件后关闭来电提示，完整事件监听请参考[处理通话事件](/sdk/harmony/calling/managing-calls/handle-call-events)。通话已经接通建立后应使用[挂断通话](/sdk/harmony/calling/managing-calls/hang-up-call)。
