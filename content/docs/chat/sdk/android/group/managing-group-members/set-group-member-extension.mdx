The `SetGroupMemberInfo.ex` string stores extra group member information and can contain a JSON string with additional member information.

```java
SetGroupMemberInfo update = new SetGroupMemberInfo();
update.setGroupID(groupID);
update.setUserID(userID);
update.setEx("{\"duty\":\"reviewer\"}");

OpenIMClient.getInstance().groupManager.setGroupMemberInfo(update, new OnBase<String>() {
    @Override public void onSuccess(String data) { /* The request completed. */ }
    @Override public void onError(int code, String error) { /* code and error describe the failure. */ }
});
```

A successful callback means that the extension update request completed; it does not mean that every client has updated its UI. `onGroupMemberInfoChanged` provides the updated `GroupMembersInfo`. Merge it by `groupID:userID` and replace the member's `ex`. See [Group overview](/sdk/android/group/overview-group) for the complete listener setup.
