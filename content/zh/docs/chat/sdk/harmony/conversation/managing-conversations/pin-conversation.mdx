---
title: '置顶或取消置顶会话'
description: '设置指定会话在当前用户会话列表中的置顶状态。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/pin-conversation'
---

```ts
import sdk, { SetConversationReq } from '@openimsdk/imsdk';

const request: SetConversationReq = {
  conversationID: conversationID,
  isPinned: true,
};
await sdk.setConversation(request);
```

传入 `true` 表示置顶，传入 `false` 表示取消置顶。置顶状态仅影响当前登录用户的会话排序，不会影响对端或其他群成员。接口调用成功后，SDK 会触发会话变更事件；客户端收到通知后根据 `conversationID` 更新对应会话的 `isPinned` 属性并重排列表，完整监听配置请参考[获取会话列表](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list)。
