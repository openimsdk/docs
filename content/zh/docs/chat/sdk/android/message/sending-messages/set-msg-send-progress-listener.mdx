通过 `OnMsgSendCallback.onProgress()` 获取当前消息的发送进度。

```java
messageManager.sendMessage(new OnMsgSendCallback() {
    @Override public void onProgress(long progress) { /* progress 是发送进度。 */ }
    @Override public void onSuccess(Message sentMessage) { /* sentMessage 是发送成功的消息。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
}, message, peerUserID, null, offlinePushInfo);
```
