设置单个会话的消息免打扰或消息接收选项。

```ts
await OpenIMSDK.setConversationRecvMessageOpt({
  conversationID,
  opt: MessageReceiveOptType.NotNotify,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 要设置的会话 ID。 |
| `opt` | `MessageReceiveOptType` | 是 | 会话消息接收方式。 |

`MessageReceiveOptType` 常用值如下：

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `MessageReceiveOptType.Normal` | `0` | 正常接收消息并允许提醒。 |
| `MessageReceiveOptType.NotReceive` | `1` | 不接收该会话的消息。 |
| `MessageReceiveOptType.NotNotify` | `2` | 接收消息但不提醒（免打扰）。 |

## 返回结果

调用完成后，会话的消息接收选项已更新。

更新成功后会触发 `OnConversationChanged` 事件；客户端应使用 `conversationID` 定位目标会话，并合并最新的 `recvMsgOpt` 属性以更新界面红点或免打扰图标。账号级默认接收策略请参考用户资料中的[设置全局消息接收方式](/sdk/react-native/user/profile/set-global-message-reception)。完整监听方式见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。
