具备管理权限的群主或管理员可以调用移除群成员接口。该方法不能用于移除群主；如需更换群主，应先调用[转让群主](/sdk/uniapp/group/managing-group-members/transfer-group-owner)。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 目标群组 ID。 |
| `reason` | `string` | 是 | 移除说明；没有说明时传空字符串。 |
| `userIDList` | `string[]` | 是 | 待移除的成员用户 ID；调用前应去重。 |

```uts
import { kickGroupMember } from '@/uni_modules/unix-openim-sdk'

await kickGroupMember({
  groupID: groupID,
  reason: '已离开项目',
  userIDList: [targetUserID],
})
```

Promise 成功表示 SDK 已完成移除请求。收到群成员退出或被踢事件后，再按 `groupID:userID` 从本地列表移除对应成员；完整事件监听与处理逻辑请参考[分页查询群成员](/sdk/uniapp/group/retrieving-group-members/get-group-member-list)。
