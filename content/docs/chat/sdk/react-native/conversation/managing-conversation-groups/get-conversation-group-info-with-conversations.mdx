Retrieve group metadata alongside a paginated list of conversations in that group:

```ts
const result = await OpenIMSDK.getConversationGroupInfoWithConversations({
  conversationGroupID,
  pagination: {
    pageNumber: 1,
    showNumber: 20,
  },
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationGroupID` | `string` | Yes | Target conversation group ID to query. |
| `pagination.pageNumber` | `number` | Yes | Page number starting from `1`. |
| `pagination.showNumber` | `number` | Yes | Number of conversation items per page. |

## Return value

Resolves to an object containing:

| Field | Type | Description |
| --- | --- | --- |
| `group` | `ConversationGroup` | Conversation group details. |
| `conversationTotal` | `number` | Total number of conversations associated with this group. |
| `conversationElems` | `ConversationItem[]` | Conversation items retrieved for the current page. |

When the accumulated conversations reach `conversationTotal`, further pagination can stop. Reconcile groups by `conversationGroupID` and individual conversations by `conversationID`. For conversation properties, see [Retrieve conversation list](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list); for group properties, see [Conversation groups overview](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups).
