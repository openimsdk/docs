`speechToTextCapabilities()` is used only to query supported audio formats, sample rates, recording duration, and file size limits. The interface that actually performs speech recognition is [Transcribe audio](/sdk/react-native/message/composing-messages/transcribe-audio).

```ts
const capabilities = await OpenIMSDK.speechToTextCapabilities();
```

## Return value

The call returns `SpeechToTextCapabilities`:

| Field | Type | Description |
| --- | --- | --- |
| `format` | `string[]` | Supported audio formats. |
| `sampleRateHz` | `number` | Required audio sample rate in hertz. |
| `maxRecordTimeMs` | `number` | Maximum recording duration in milliseconds. |
| `maxFileSize` | `number` | Maximum file size in bytes. |
| `provider` | `string` | Current speech-recognition provider. |
