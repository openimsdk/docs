The OpenIM React Native SDK uses `userID` as the unique user identifier. User APIs allow applications to read and modify current user settings, query public profile cards for arbitrary users, and subscribe to real-time online presence states.

Friendship relationships, friend requests, and blacklists are managed as part of relationship capabilities; see [Relationships overview](/sdk/react-native/user/overview-relationships).

## User data structures

The SDK exposes distinct models tailored to specific user contexts:

| Structure | Context | Applicable guides |
| --- | --- | --- |
| `SelfUserInfo` | Current authenticated user's profile, avatar, nickname, and account-level notification settings | [Get current user profile](/sdk/react-native/user/profile/get-self-user-info), [Update current user profile](/sdk/react-native/user/profile/set-self-info) |
| `PublicUserItem` | Public user profile cards for arbitrary users | [Get user profiles](/sdk/react-native/user/profile/get-users-info) |
| `UserOnlineState` | Presence states and active platform client lists | [Subscribe to user online status](/sdk/react-native/user/online-status/subscribe-users-status), [Get subscribed user status](/sdk/react-native/user/online-status/get-subscribe-users-status), [Unsubscribe from user online status](/sdk/react-native/user/online-status/unsubscribe-users-status) |

`SelfUserInfo` belongs strictly to the local signed-in user, whereas `PublicUserItem` represents searchable public profile cards. Friendship metadata, blacklist statuses, and group membership roles are tracked via dedicated relationship and group models.

## Event listeners

User profile and presence updates trigger realtime push events:

- Current user profile mutations trigger `OnSelfInfoUpdated`, documented in [Update current user profile](/sdk/react-native/user/profile/set-self-info).
- Online presence changes trigger `OnUserStatusChanged`, documented in [Subscribe to user online status](/sdk/react-native/user/online-status/subscribe-users-status).
- Friendship, application, and blacklist events are detailed in [Relationships overview](/sdk/react-native/user/overview-relationships).
