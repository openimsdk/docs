群主或管理员同意指定的加群申请：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupID` | `NSString *` | 目标群组 ID。 |
| `fromUserId` | `NSString *` | 申请人的用户 ID。 |
| `handleMsg` | `NSString *` | 审批处理附言。 |

```objc
[[OIMManager manager] acceptGroupApplication:@"group_1001"
                                  fromUserId:@"user_003"
                                   handleMsg:@"同意加入项目组"
                                   onSuccess:^(NSString * _Nullable data) {
                                       NSLog(@"acceptGroupApplication success");
                                   }
                                   onFailure:^(NSInteger code, NSString *message) {
                                       NSLog(@"acceptGroupApplication failed: %ld %@", (long)code, message);
                                   }];
```

状态以 `groupID:userID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回操作结果。

调用成功表示入群申请已被同意。服务端处理完成后会联动产生以下两个事件：

1. 入群申请状态变更会通过 `onGroupApplicationAccepted:` 事件广播，客户端应以 `groupID:userID` 为合并标识更新申请记录状态为已同意。
2. 申请人成功加入群组后，会通过 `onGroupMemberAdded:` 事件广播，客户端应以 `groupID:userID` 为合并标识将该成员加入群成员列表。

相关事件监听与列表处理请参见[入群申请概览](/sdk/ios/group/group-applications/overview-group-applications)与[群成员查询概览](/sdk/ios/group/retrieving-group-members/overview-retrieving-group-members)。
