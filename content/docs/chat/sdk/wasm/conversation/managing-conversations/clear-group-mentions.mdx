After the user handles mentioned messages in a group chat, reset the conversation's `groupAtType` to its normal state:

```ts
import { GroupMentionType } from '@openim/wasm-client-sdk';

await openimsdk.setConversation({
  conversationID,
  groupAtType: GroupMentionType.Normal,
});
```

`groupAtType` is a reminder state the SDK derives from group messages. This operation only resets it to the normal state. Do not use it to fabricate `MentionedMe`, `MentionedAll`, or another state that did not occur. Resetting group mention state and marking messages as read are separate operations.

After the Promise succeeds, continue to update the matching conversation from `OnConversationChanged`. See [Get the conversation list](/sdk/wasm/conversation/retrieving-conversations/retrieve-conversation-list) for the complete listener.
