按群组 ID 查询进行中的通话房间。查询参数为群组 ID（`groupID`），即使群通话使用了自定义 `roomID`，此处仍需传入 `groupID`。

```java
OpenIMClient.getInstance().signalingManager.signalingGetRoomByGroupID(
    new OnBase<RoomCallingInfo>() {
        @Override
        public void onSuccess(RoomCallingInfo room) {
            // room 包含房间、完整邀请和当前参与者信息。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明查询失败原因。
        }
    },
    groupID
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<RoomCallingInfo>` | 是 | 异步请求回调。 |
| `groupID` | `String` | 是 | 目标群组 ID。即使群通话使用了自定义 `roomID`，此处仍需传入 `groupID`。 |

## 返回结果

成功回调返回当前群组正在进行中的通话快照 `RoomCallingInfo`，包含：
- `roomID`：当前通话房间标识。
- `invitation`：发起呼叫时的原始邀请信息。
- `participant`：当前房间内参与者的资料与状态列表。
- `groupID`：群组 ID。
- `token`：加入媒体房间所需的临时凭据。
- `liveURL`：媒体服务器地址。

若返回数据中 `roomID` 为空，说明当前群组内没有进行中的音视频通话。查询结果为调用时刻的数据快照，后续通话状态变化请结合[处理通话事件](/sdk/android/calling/managing-calls/handle-call-events)进行实时维护。
