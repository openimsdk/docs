Invoke `hideAllConversations()` to clear list visibility, unread counts, latest message summaries, and drafts across all conversations on the current client, removing them from the active paginated conversation list. This method accepts no parameters.

## Code example

```uts
import { hideAllConversations } from '@/uni_modules/unix-openim-sdk'

await hideAllConversations()
```

## Return value

The Promise resolves with `void` upon successful completion.

## State changes after the call

Promise resolution indicates that local conversation visibility flags were reset. This call does not delete local message records or server-side messages, nor does it affect friendships, group memberships, or conversation state on other devices. When new messages arrive for any of these conversations, they will reappear in the active list.

After the call resolves, refresh your UI by re-querying the conversation list and total unread count as described in [Retrieve conversation list](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list) and [Get total unread count](/sdk/uniapp/conversation/managing-conversations/get-total-unread-count).
