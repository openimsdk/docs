为单条消息设置仅在当前设备生效的本地自定义扩展字段（如 UI 折叠状态、本地解析结果等）：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 消息所属会话 ID。 |
| `clientMsgID` | `String` | 是 | 目标消息的客户端消息 ID。 |
| `localEx` | `String` | 是 | 本地专属的自定义扩展字符串，通常使用 JSON 格式。 |

```dart
await OpenIM.iMManager.messageManager.setMessageLocalEx(
  conversationID: conversationID,
  clientMsgID: clientMsgID,
  localEx: jsonEncode({'expanded': true}),
);
```

`localEx` 为整段覆盖写入，SDK 不会自动执行增量合并。写入前应确保 `clientMsgID` 非空有效。

## 返回结果

Future 成功表示本地扩展字段已成功更新至当前设备的本地数据库。客户端应依据复合标识 `conversationID:clientMsgID` 同步更新本地界面的消息状态。

该操作属于纯本地数据更新，不会上传至服务端，不会同步到多端设备或其他会话成员，也不会触发任何消息事件通知。
