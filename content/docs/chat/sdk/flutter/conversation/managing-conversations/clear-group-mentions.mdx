After a user views or acts on @ mention notifications in a group chat, reset `groupAtType` back to normal:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `String` | Yes | Target group conversation ID. |
| `req` | `ConversationReq` | Yes | Conversation modification request. Pass `GroupAtType.atNormal` for `groupAtType`. |

## Code example

```dart
await OpenIM.iMManager.conversationManager.setConversation(
  conversationID,
  ConversationReq(groupAtType: GroupAtType.atNormal),
);
```

## Return value

A successful `Future` indicates that the mention reset request has completed. Group @ mention status drives prominent badge indicators and operates independently from message read receipts.

## State changes after the call

The SDK emits conversation change events notifying connected clients of the update. The client uses `conversationID` as the merge key to update `groupAtType` on the local conversation model. For complete listener integration, see [Retrieve conversation list](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list).
