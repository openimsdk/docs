从本地文件系统的完整绝对路径构建待发送的语音/音频消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `soundPath` | `String` | 是 | 设备文件系统中的完整绝对路径。 |
| `duration` | `int` | 是 | 音频播放时长（秒）。 |

```dart
final message = await OpenIM.iMManager.messageManager
    .createSoundMessageFromFullPath(
  soundPath: absolutePath,
  duration: durationSeconds,
);
```

传入的绝对路径必须在当前平台具备有效读取权限，时长单位为秒。

## 返回结果

Future 成功返回待发送的音频消息对象（`Message`），音频属性保存在 `soundElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送或文件上传，也不会触发新消息事件通知。构建完成后，需将返回的 `Message` 实例传给[发送消息](/sdk/flutter/message/sending-messages/send-message)，由 SDK 执行媒体上传与消息投递。若使用平台通用相对路径，请参考[创建音频消息](/sdk/flutter/message/creating-messages/create-sound-message)；若音频已上传至对象存储，请参考[使用 URL 创建音频消息](/sdk/flutter/message/creating-messages/create-sound-message-by-url)。
