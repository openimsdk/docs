---
title: '退出群组'
description: '使用 quitGroup 让当前登录用户退出指定群组。'
sourcePath: '/sdk/android/group/quit-group'
---

`quitGroup()` 仅作用于当前登录用户，不会解散群组或移除其他成员。

```java
OpenIMClient.getInstance().groupManager.quitGroup(new OnBase<String>() {
    @Override public void onSuccess(String data) { removeJoinedGroup(groupID); }
    @Override public void onError(int code, String error) { showQuitError(error); }
}, groupID);
```

请求成功后仍应处理 `onJoinedGroupDeleted`，并清理该群的成员列表、群会话入口等应用缓存。
