---
title: '创建名片消息'
description: '使用 createCardMessage 创建联系人名片消息。'
sourcePath: '/sdk/android/message/creating-messages/create-card-message'
---

`CardElem` 保存名片用户的 ID、昵称、头像等展示资料。只传递接收方有权查看的字段，不要把好友备注或群内昵称当作账号公开资料。

```java
Message message = OpenIMClient.getInstance().messageManager.createCardMessage(cardElem);
```

返回的 `Message` 只是在本地创建的待发送对象，不会自动发送或重新查询名片用户资料；创建完成后使用[发送消息](/sdk/android/message/sending-messages/send-message)。
