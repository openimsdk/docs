调用创建自定义消息方法可构建承载结构化业务数据的自定义消息对象（例如业务订单卡片、投票信息、转账记录等）。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createCustomMessage:json
                              extension:@"com.example.order"
                            description:@"订单卡片"];
```

## 参数说明

- `data`：序列化后的自定义业务 JSON 字符串（`NSString *`）。
- `extension`：业务扩展与自定义协议标识（`NSString *`），如 `com.example.order`。
- `description`：在旧版客户端或会话列表最后一条消息展示的降级文本（`NSString *`）。

## 返回结果

- 返回初始化的自定义消息对象（`OIMMessageInfo *`），其内容类型为自定义消息。
- 该方法仅在本地构建待发送对象。接收端消费时应校验协议版本与数据模型；支付、审批等权威业务状态必须由业务服务校验。后续发送需调用[发送消息](/sdk/ios/message/sending-messages/send-message)。
