---
title: '设置管理员'
description: '将普通群成员设置为管理员，或取消其管理员身份。'
sourcePath: '/sdk/harmony/group/managing-group-members/set-group-member-role-level'
---

只有具备相应权限的群主可以调整管理员身份。

```ts
import sdk, { GroupMemberRoleLevel, SetGroupMemberInfoReq } from '@openimsdk/imsdk';

const request: SetGroupMemberInfoReq = {
  groupID: groupID,
  userID: targetUserID,
  roleLevel: GroupMemberRoleLevel.GroupAdmin,
};
await sdk.setGroupMemberInfo(request);
```

取消管理员身份时传 `GroupOrdinaryUsers`。不能通过写入 `GroupOwner` 转让群主，应使用[转让群主](/sdk/harmony/group/managing-group-members/transfer-group-owner)。Promise 成功后，通过成员资料变化事件更新角色。
