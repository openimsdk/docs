---
title: '创建回复消息'
description: '引用一条已有消息并创建带回复文本的待发送消息。'
sourcePath: '/sdk/uniapp/message/creating-messages/create-quote-message'
---

`createQuoteMessage()` 创建回复消息。`text` 是本次回复正文，`message` 是被回复消息完整序列化后的字符串。

```uts
import { createQuoteMessage } from '@/uni_modules/unix-openim-sdk'

const message = await createQuoteMessage({
  text: '收到，我今天处理。',
  message: JSON.stringify(originalMessage),
})
if (message == null) return
```

`originalMessage` 应来自当前会话的查询结果或消息事件，不要只拼接展示文本，也不要引用业务层自行构造的不完整对象。发送前应确认原消息仍属于目标会话，并为原消息已删除或无法解析的情况提供降级展示。

Promise 成功只返回新的待发送 `OpenIMMessageItem | null`，不会修改被回复消息。
