构建包含超链接、特定高亮等富文本实体的消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `text` | `String` | 是 | 完整的消息正文文本。 |
| `list` | `List<RichMessageInfo>?` | 否 | 富文本实体配置列表，包含链接地址、字符偏移量与长度等信息。 |

```dart
final message = await OpenIM.iMManager.messageManager
    .createAdvancedTextMessage(text: text, list: entities);
```

每个 `RichMessageInfo` 的偏移量与长度必须基于最终正文计算，URL 及附加信息建议在传入前完成校验。

## 返回结果

Future 成功返回待发送的富文本消息对象（`Message`），其内容存储在 `advancedTextElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送，也不会触发新消息事件通知。构建完成后，需将返回的 `Message` 实例传给[发送消息](/sdk/flutter/message/sending-messages/send-message)投递至单聊或群聊会话。
