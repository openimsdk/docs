`faceURL` specifies the avatar URL in the group member profile and applies solely within the target group.

## Code example

```ts
import sdk, { SetGroupMemberInfoReq } from '@openimsdk/imsdk';

const request: SetGroupMemberInfoReq = {
  groupID: groupID,
  userID: targetUserID,
  faceURL: avatarURL,
};
await sdk.setGroupMemberInfo(request);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group identifier. |
| `userID` | `string` | Yes | Target member user ID. |
| `faceURL` | `string` | Yes | Member avatar image URL. |

## Return value

Returns a Promise that resolves to `void` when the avatar update succeeds on the server.

## State changes after the call

In-group member avatars are distinct from account-level profile avatars. To modify the account profile avatar, use [Update current user profile](/sdk/harmony/user/profile/set-self-info). After the Promise resolves, the SDK triggers a group member info changed event; clients update the member record matching `groupID:userID`. For complete event listeners, see [Retrieve group member list](/sdk/harmony/group/retrieving-group-members/get-group-member-list).
