设置或取消群成员的管理员身份，只有群主具备该操作权限。

## 参数说明

`roleLevel` 字段类型为 `OpenIMGroupMemberRole`，可选枚举值如下：

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `OpenIMGroupMemberRoleNormal` | `20` | 普通成员（用于取消管理员身份）。 |
| `OpenIMGroupMemberRoleAdmin` | `60` | 管理员（用于设置管理员）。 |
| `OpenIMGroupMemberRoleOwner` | `100` | 群主（只用于识别角色，不能用于本操作）。 |

```uts
import {
  OpenIMGroupMemberRoleAdmin,
  setGroupMemberInfo,
} from '@/uni_modules/unix-openim-sdk'

await setGroupMemberInfo({
  groupID: groupID,
  userID: targetUserID,
  roleLevel: OpenIMGroupMemberRoleAdmin,
})
```

不能通过将 `roleLevel` 设为 `OpenIMGroupMemberRoleOwner` 来转让群主，如需更换群主应使用[转让群主](/sdk/uniapp/group/managing-group-members/transfer-group-owner)。Promise 成功表示设置请求已完成。收到群成员信息变更事件后，再按 `groupID:userID` 更新对应成员的角色；完整事件监听请参考[分页查询群成员](/sdk/uniapp/group/retrieving-group-members/get-group-member-list)。
