---
title: '发布或更新群公告'
description: '设置或清空指定群组的公告内容。'
sourcePath: '/sdk/harmony/group/set-group-announcement'
---

`notification` 是群公告，与用于介绍群组的 `introduction` 不同。公告修改权限由 OpenIMServer 校验；客户端可以根据当前成员角色控制入口，但不能只依赖前端判断。

```ts
import sdk, { SetGroupInfoReq } from '@openimsdk/imsdk';

const request: SetGroupInfoReq = {
  groupID: groupID,
  notification: announcement.trim(),
};
await sdk.setGroupInfo(request);
```

传入空字符串可以清空公告。Promise 成功表示服务端更新请求已完成；SDK 会触发群资料变更事件，客户端收到通知后根据 `groupID` 更新群公告，完整监听代码请参考[群组概览](/sdk/harmony/group/overview-group)。
