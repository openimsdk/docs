有权限的群主或管理员可以调用 `kickGroupMember()`。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 要移除成员的群组 ID。 |
| `reason` | `string` | 是 | 移除原因；没有补充说明时传空字符串。 |
| `userIDList` | `string[]` | 是 | 要移除的成员用户 ID 列表。 |

```ts
await openimsdk.kickGroupMember({
  groupID,
  reason: '已离开项目',
  userIDList: [targetUserID],
});
```

不能用该方法移除群主；应先转让群主身份。

Promise 成功表示移除请求已经完成。`OnGroupMemberDeleted` 随后可能到达，应按 `groupID:userID` 移除成员；完整监听见[分页查询群成员](/sdk/wasm/group/retrieving-group-members/get-group-member-list)。
