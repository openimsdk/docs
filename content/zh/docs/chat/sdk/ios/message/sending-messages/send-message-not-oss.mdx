`sendMessageNotOss:...` 用于业务已经上传资源并创建 URL 型媒体消息的场景，避免再次进入 SDK 对象存储上传。

```objc
[[OIMManager manager] sendMessageNotOss:urlMessage
                                 recvID:receiverUserID
                                groupID:nil
                           isOnlineOnly:NO
                        offlinePushInfo:nil
                              onSuccess:^(OIMMessageInfo *sent) {
    if (sent != nil) [messageStore upsert:sent];
}
                             onProgress:nil
                              onFailure:nil];
```

单聊和群聊目标互斥。资源 URL、大小、类型、尺寸和时长必须来自实际上传结果。成功 callback 与远端接收 delegate 分别处理。
