Invoke `refuseGroupApplication()` as a group owner or administrator to decline a pending group join request.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group identifier. |
| `fromUserID` | `string` | Yes | The applicant's user ID (matching `userID` in the application record). |
| `handleMsg` | `string` | Yes | Rejection comment or explanation; pass an empty string if omitted. |

## Code example

```uts
import { refuseGroupApplication } from '@/uni_modules/unix-openim-sdk'

await refuseGroupApplication({
  groupID: application.groupID,
  fromUserID: application.userID,
  handleMsg: 'Application declined at this time',
})
```

## Return value

The Promise resolves with `void` once OpenIMServer processes the rejection.

## State changes after the call

A resolved Promise confirms that the rejection was accepted by OpenIMServer. When `onGroupApplicationRejected` fires, update the review status of the application record matching `groupID:userID`. Rejecting a request does not remove the application log from history. For complete event registration logic, see [Get received group applications](/sdk/uniapp/group/group-applications/get-group-application-list-as-recipient).
