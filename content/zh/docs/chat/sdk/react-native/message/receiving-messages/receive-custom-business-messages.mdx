当服务端通过管理端接口直接下发非聊天的自定义业务通知（如系统广播、订单状态推送、活动提醒等）时，SDK 会触发 `OnRecvCustomBusinessMessage` 事件。

该事件的回调参数为纯业务数据（通常为 JSON 字符串），而非标准聊天消息对象 `MessageItem`。若需接收会话内部的聊天型自定义消息，请参考[接收消息](/sdk/react-native/message/receiving-messages/receive-messages)中监听新消息事件的说明。

```ts
const handleCustomBusinessMessage = (businessData: string) => {
  try {
    const payload = JSON.parse(businessData);
    // 处理特定业务通知，如更新系统通知栏或刷新全局业务状态
  } catch (error) {
    console.error('解析自定义业务数据失败:', error);
  }
};

// 设置监听
OpenIMSDK.on(
  OpenIMEvent.OnRecvCustomBusinessMessage,
  handleCustomBusinessMessage,
);

// 取消监听
OpenIMSDK.off(
  OpenIMEvent.OnRecvCustomBusinessMessage,
  handleCustomBusinessMessage,
);
```

业务侧应先校验接收到的数据格式与签名，再根据内部协议分发处理。在组件销毁、退出登录或切换账号时，请务必取消监听以避免内存泄漏。
