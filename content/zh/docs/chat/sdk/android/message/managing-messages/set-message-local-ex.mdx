---
title: '设置消息本地扩展'
description: '使用 setMessageLocalEx 保存仅当前设备使用的消息扩展数据。'
sourcePath: '/sdk/android/message/managing-messages/set-message-local-ex'
---

`setMessageLocalEx()` 为当前设备中的指定消息保存扩展字符串。`localEx` 适合记录下载路径、播放状态等本地信息，不会同步到服务器、其他设备或其他用户。

`conversationID` 和 `clientMsgID` 共同定位消息，`localExJson` 是由应用定义格式的字符串；如使用 JSON，应在写入前完成序列化并在读取时校验结构。

```java
OpenIMClient.getInstance().messageManager.setMessageLocalEx(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 更新当前设备中该消息的 localEx 展示。
        }

        @Override
        public void onError(int code, String error) {
            // 保留原值并提示保存失败。
        }
    },
    conversationID,
    clientMsgID,
    localExJson
);
```

成功回调表示本地扩展已保存。该操作不修改消息正文，也不会触发共享消息事件。
