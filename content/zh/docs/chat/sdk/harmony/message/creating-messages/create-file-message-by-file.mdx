---
title: '使用本地文件创建消息'
description: '根据应用可访问的本地文件路径创建待发送消息。'
sourcePath: '/sdk/harmony/message/creating-messages/create-file-message-by-file'
---

```ts
import sdk, { CreateFileMessageReq, CreateFileMessageResp } from '@openimsdk/imsdk';

const request: CreateFileMessageReq = {
  fileSourcePath: filePath,
  fileName: '项目计划.pdf',
};
const response: CreateFileMessageResp = await sdk.createFileMessage(request);
const message = response.message;
```

路径必须可由原生 SDK 读取。`fileName` 是接收端展示和保存时使用的名称，应保留合理扩展名，但不能替代真实文件类型校验。Promise 成功只创建消息对象；后续由 SDK 上传文件并发送。
