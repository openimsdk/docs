一个会话可以同时归属于多个不同的会话分组。调用 `getConversationGroupIDsByConversationID()` 可反向查询指定会话当前所属的全部会话分组 ID 列表。

```ts
const { data: conversationGroupIDs } =
  await openimsdk.getConversationGroupIDsByConversationID(conversationID);
```

参数 `conversationID` 为目标会话 ID（非群组 ID）。

## 返回结果

接口调用成功后，返回的 `data` 为 `string[]` 数组，每个元素对应一个 `conversationGroupID`。该接口不返回分组详情；如需获取分组的具体资料，请参考[查询会话分组列表](/sdk/wasm/conversation/managing-conversation-groups/get-conversation-groups)。

该查询为纯只读操作，不会触发任何事件。关于分组关系的实时增量变更监听，请参考[会话分组概览](/sdk/wasm/conversation/managing-conversation-groups/overview-conversation-groups)。
