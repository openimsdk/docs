Call `getSpecifiedGroupMembersInfo()` to retrieve member profiles for specified users in a group.

```ts
const members = await OpenIMSDK.getSpecifiedGroupMembersInfo({
  groupID: 'group-001',
  userIDList: ['user-001', 'user-002'],
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- |
| `groupID` | `string` | Yes | ID of the target group. |
| `userIDList` | `string[]` | Yes | User IDs of the members to retrieve. |

## Return value

When the call completes, it returns matching `GroupMemberItem[]` entries. See [Group overview](/sdk/react-native/group/overview-group) for field descriptions.
