批量检测指定用户与当前登录账号之间是否存在有效的好友关系，常用于用户个人资料页判断是否显示“加为好友”或“发消息”按钮。

```java
OpenIMClient.getInstance().friendshipManager.checkFriend(
    new OnBase<List<FriendshipInfo>>() {
        @Override
        public void onSuccess(List<FriendshipInfo> relations) {
            // 使用 relations 更新好友关系显示
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    Arrays.asList("user_a", "user_b")
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<List<FriendshipInfo>>` | 是 | 异步请求回调。 |
| `userIDs` | `List<String>` | 是 | 待检测的用户 ID 列表。 |

## 返回结果

成功回调返回 `List<FriendshipInfo>` 关系结果列表。客户端应以 `userID` 为主键定位对应用户并刷新关系状态：

| 字段 | 说明 |
| --- | --- |
| `userID` | 目标用户 ID。 |
| `result` | 关系状态值：`1` 表示该用户是好友且不在黑名单中；`0` 表示非好友。 |

若需要进一步获取好友的昵称、头像或自定义备注等资料，请参考[查询指定好友资料](/sdk/android/user/friends/get-friends-info)。
