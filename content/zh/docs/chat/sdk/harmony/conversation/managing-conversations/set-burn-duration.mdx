---
title: '设置阅后即焚时长'
description: '设置指定会话在阅后即焚模式下的消息保留时长。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/set-burn-duration'
---

阅后即焚属于商业版能力。`burnDuration` 单位为秒，只描述阅后即焚的保留时长。

```ts
import sdk, { SetConversationReq } from '@openimsdk/imsdk';

const request: SetConversationReq = {
  conversationID: conversationID,
  burnDuration: 30,
};
await sdk.setConversation(request);
```

启用模式还需设置 `isPrivateChat`。不要与服务端消息删除周期混用。
