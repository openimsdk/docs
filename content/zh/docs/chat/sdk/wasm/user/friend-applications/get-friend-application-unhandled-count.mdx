---
title: '获取未处理好友申请数'
description: '查询指定时间点之后的未处理好友申请数。'
sourcePath: '/sdk/wasm/user/friend-applications/get-friend-application-unhandled-count'
---

```ts
const { data: count } =
  await openimsdk.getFriendApplicationUnhandledCount({ time });
```

`time` 是统计起点的 Unix 毫秒时间戳，通常取上次查看申请列表的时间；传 `0` 表示统计全部未处理申请。Promise 成功后，`data` 是该时间点之后的未处理好友申请数量。该结果只表示查询时的数量，不会修改申请，也不会触发申请事件。
