description: '使用 iOS SDK 从绝对路径创建图片消息。'

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createImageMessageFromFullPath:imageURL.path];
```

路径必须是当前 App 可读取的图片绝对路径。返回对象仍需通过普通发送 API 上传并发送。
