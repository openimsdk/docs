---
title: '搜索会话'
description: '按展示名称搜索本地已有会话。'
sourcePath: '/sdk/harmony/conversation/retrieving-conversations/search-conversations'
---

```ts
import sdk, { SearchConversationReq, SearchConversationResp } from '@openimsdk/imsdk';

const request: SearchConversationReq = {
  searchParam: keyword.trim(),
};
const response: SearchConversationResp = await sdk.searchConversation(request);
renderConversationResults(response.conversationList);
```

搜索范围仅覆盖已同步到本地的会话，不会向服务端发起远程检索。搜索界面可结合会话事件监听，根据 `conversationID` 更新当前匹配项，完整监听配置请参考[获取会话列表](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list)。
