description: '使用 Android SDK 取消尚未接通的通话邀请。'

---

邀请尚未接通时，发起方可调用 `signalingCancel()` 取消通话邀请：

```java
OpenIMClient.getInstance().signalingManager.signalingCancel(
    new OnBase<String>() {
        @Override
        public void onSuccess(String result) {
            stopWaitingForAnswer(activeInfo.getInvitation().getRoomID());
        }

        @Override
        public void onError(int code, String error) {
            showCancelError(code, error);
        }
    },
    activeInfo
);
```

必须传入发起时保存的完整 `SignalingInfo`，不能只构造一个 `roomID`。成功回调表示取消信令请求完成；应用还应结束本地等待接听状态，并释放尚未使用的媒体资源。远端通过 `onInvitationCancelled` 更新。
