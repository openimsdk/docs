群名称、简介和头像可以由同一个资料编辑表单提交。只传本次实际变化的字段，不要把公告、入群验证或成员权限字段混入普通资料保存操作。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 要更新的群组 ID。 |
| `groupName` | `string` | 否 | 新群名称。 |
| `introduction` | `string` | 否 | 新群简介。 |
| `faceURL` | `string` | 否 | 新群头像地址。 |

除 `groupID` 外，至少传入一个实际需要修改的资料字段。

```uts
import { setGroupInfo } from '@/uni_modules/unix-openim-sdk'

await setGroupInfo({
  groupID,
  groupName: groupName.trim(),
  introduction: introduction.trim(),
  faceURL,
})
```

Promise 成功表示设置请求已完成。客户端可先将本地对应群组的基础资料更新为目标值，收到群资料变更事件后，按 `groupID` 确认最新状态；需要校准状态时可通过[查询指定群组资料](/sdk/uniapp/group/retrieving-groups/get-specified-groups-info)重新获取。完整群组事件监听见[群组概览](/sdk/uniapp/group/overview-group)。
