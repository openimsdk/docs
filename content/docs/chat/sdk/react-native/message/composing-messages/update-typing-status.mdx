Send custom typing indicator text to the counterparty in a one-to-one conversation:

```ts
await OpenIMSDK.typingStatusUpdate({
  recvID: receiverUserID,
  msgTip: 'typing…',
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `recvID` | `string` | Yes | Recipient user ID in the target one-to-one conversation. |
| `msgTip` | `string` | Yes | Custom typing indicator message string. |

## Return value

A resolved Promise confirms that the custom typing status indicator was dispatched to the recipient.

To synchronize typing activity automatically based on input focus events, see [Change input states](/sdk/react-native/message/composing-messages/change-input-states).
