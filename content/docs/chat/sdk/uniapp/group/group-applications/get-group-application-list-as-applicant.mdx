Invoke `getGroupApplicationListAsApplicant()` to retrieve a paginated record of outgoing group join applications submitted by the authenticated user. This API provides offset-based pagination; it does not filter by `groupID` or review outcome.

## Parameters

The parameters object can be omitted. When paginating, supply the following fields:

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `offset` | `number` | No | Pagination offset index; pass `0` for the first page. |
| `count` | `number` | No | Number of application records to fetch. |

## Code example

```uts
import {
  getGroupApplicationListAsApplicant,
} from '@/uni_modules/unix-openim-sdk'

const result = await getGroupApplicationListAsApplicant({
  offset: 0,
  count: 20,
})
const applications = result != null ? result.applications : []
```

## Return value

The Promise resolves with an `OpenIMGroupApplicationListResult | null` object containing `OpenIMGroupApplicationItem[]` elements in `applications`. For property definitions, see [Get received group applications](/sdk/uniapp/group/group-applications/get-group-application-list-as-recipient).

## State changes after the call

This is a read-only query that retrieves local snapshot records. When application status changes occur during active paging, merge records using the composite key `groupID:userID` or reload the query. For full event listener patterns, see [Get received group applications](/sdk/uniapp/group/group-applications/get-group-application-list-as-recipient).
