更新群组的基础资料，包括群名称、群头像和群简介。在传入的 `GroupInfo` 中指定 `groupID` 及需要更新的属性，未设置的属性将保持不变。

```java
GroupInfo update = new GroupInfo();
update.setGroupID("group_123");
update.setGroupName("移动端项目组");
update.setIntroduction("Android 与 iOS 协作群");
update.setFaceURL("https://example.com/group_avatar.png");

OpenIMClient.getInstance().groupManager.setGroupInfo(
    update,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 群资料更新成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理更新失败
        }
    }
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupInfo` | `GroupInfo` | 是 | 包含待更新字段的群资料对象，必须设置目标 `groupID` 以及需要更新的属性（如 `groupName`、`introduction`、`faceURL` 等）。 |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |

## 返回结果

成功回调中的 `data` 返回确认信息。

群资料修改成功后，群内所有在线成员随后将收到 `onGroupInfoChanged` 事件通知，返回更新后的 `GroupInfo`。客户端应以 `groupID` 为标识合并群组缓存并刷新界面；完整监听见[群组概览](/sdk/android/group/overview-group)。

关于群公告和自定义扩展属性的修改，请参阅[发布或更新群公告](/sdk/android/group/set-group-announcement)与[设置群组扩展字段](/sdk/android/group/set-group-extension)。
