将指定会话从当前登录账号的会话列表中暂时隐藏。该操作适合临时收起会话入口，不会删除历史消息，也不会影响好友关系或退出群组。

```java
OpenIMClient.getInstance().conversationManager.hideConversation(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成，会话已隐藏。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    conversationID
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `conversationID` | `String` | 是 | 目标会话的唯一标识。 |

## 返回结果

成功回调表示服务端已记录会话隐藏状态。

该操作仅从当前会话列表视图中隐藏该会话。当该会话收到新消息或重新全量同步后，SDK 会自动恢复该会话的可见性。接口调用成功后，客户端应根据 `conversationID` 从当前会话列表中剔除该项并刷新视图；后续会话状态变更请参考[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
