使用 `deleteAllMsgFromLocalAndSvr()` 清理当前登录账号在本地和服务端保存的全部消息。

```ts
await OpenIMSDK.deleteAllMsgFromLocalAndSvr();
```

这是不可撤销的账号级操作，执行前应向用户明确说明影响范围并二次确认。调用完成后，本地和服务端的清理请求已完成；其他会话成员已保存的消息副本不受影响。
