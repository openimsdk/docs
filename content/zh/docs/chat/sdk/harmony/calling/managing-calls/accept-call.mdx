---
title: '接受通话'
description: '接受当前通话邀请并取得房间凭据。'
sourcePath: '/sdk/harmony/calling/managing-calls/accept-call'
---

```ts
import sdk, { Platform, SignalingAcceptReq, SignalingAcceptResp } from '@openimsdk/imsdk';

const request: SignalingAcceptReq = {
  invitation: invitation,
  offlinePush: offlinePush,
  participant: participant,
  opUserPlatformID: Platform.HarmonyOS,
  userID: invitation.inviterUserID,
};
const response: SignalingAcceptResp = await sdk.signalingAccept(request);
await mediaEngineJoin(response.roomID, response.token, response.liveURL);
```

`invitation` 应使用收到或查询到的完整对象，不要只保留房间 ID 后重新构造。`participant` 表示当前接听者，`userID` 填写需要接收接受信令的邀请人。Promise 成功不代表媒体房间已经连接，也不代表其他参与端已经更新界面。
