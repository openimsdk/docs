---
title: '创建转发消息'
description: '使用 WASM SDK 创建单条转发消息。'
sourcePath: '/sdk/wasm/message/creating-messages/create-forward-message'
---

单条逐条转发会根据一条已发送成功的历史消息创建全新的待发送对象。需传入原始的完整 `MessageItem` 对象：

```ts
const { data: message } = await openimsdk.createForwardMessage(sourceMessage);
```

处于“发送中”或“发送失败”状态的消息不能用于转发。业务层在展示转发操作入口时，可先校验消息状态是否为已发送成功。

接口调用成功后，返回的 `data` 为分配了全新 `clientMsgID` 的待发送 `MessageItem` 对象，原消息保持不变。随后需调用 [发送消息](/sdk/wasm/message/sending-messages/send-message) 将其发送到目标单聊或群聊会话中。
