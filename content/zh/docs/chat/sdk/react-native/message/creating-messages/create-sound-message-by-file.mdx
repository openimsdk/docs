根据设备上的本地音频文件创建音频消息。

```ts
const message = await OpenIMSDK.createSoundMessageFromFullPath({
  soundPath,
  duration: 18,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `soundPath` | `string` | 是 | 设备本地音频文件的完整路径。 |
| `duration` | `number` | 是 | 音频播放时长，单位为秒。 |

## 返回结果

调用完成后返回已创建的 `MessageItem` 消息对象，其中 `soundElem` 保存音频元信息。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送消息](/sdk/react-native/message/sending-messages/send-message)将消息投递到单聊或群聊会话中，SDK 会在发送过程中自动处理本地音频文件的上传。
