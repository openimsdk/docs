Modify attributes of an existing conversation group. Supply only the fields being updated:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationGroupID` | `String` | Yes | Target conversation group ID. |
| `name` | `String?` | No | New group name. |
| `order` | `int?` | No | New sorting sequence value. |
| `ex` | `String?` | No | New custom business extension string. |
| `hidden` | `bool?` | No | Whether to hide this group from list views. |

## Code example

```dart
await OpenIM.iMManager.conversationGroupManager.updateConversationGroup(
  req: UpdateConversationGroupReq(
    conversationGroupID: conversationGroupID,
    name: 'Important Work',
    hidden: false,
  ),
);
```

## Return value

A successful `Future` indicates that the update request has been processed by the server. The client uses `conversationGroupID` as the merge key to update properties on the local group model.

## State changes after the call

Multi-device synchronization and arriving changes trigger `onConversationGroupChanged` notifications. For complete listener integration, see [Conversation groups overview](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups).
