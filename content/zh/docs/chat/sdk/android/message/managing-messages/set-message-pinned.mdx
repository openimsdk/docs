---
title: '置顶或取消置顶消息'
description: '设置会话消息的置顶状态，并处理置顶消息变化事件。'

---

最后一个参数为 `true` 时置顶消息，为 `false` 时取消置顶：

```java
messageManager.setConversationPinnedMsg(
    callback,
    conversationID,
    clientMsgID,
    true
);
```

成功回调表示设置请求完成，不代表置顶变化事件已经到达。

`OnAdvanceMsgListener.onChangedPinnedMsg` 是本页归属事件。回调中的 `ChangedPinnedMsg` 包含 `conversationID` 和当前置顶消息集合；按会话替换集合，并按每条置顶消息的 `clientMsgID` 去重：

```java
@Override
public void onChangedPinnedMsg(ChangedPinnedMsg event) {
    replacePinnedMessages(event.getConversationID(), event.getMsgs());
}
```

该回调应纳入应用唯一的 `OnAdvanceMsgListener`，集中设置入口见[事件概览](/sdk/android/events/overview-events)。成功回调、事件到达和[查询会话置顶消息](/sdk/android/message/managing-messages/get-pinned-messages)取得的快照是三个独立阶段。
