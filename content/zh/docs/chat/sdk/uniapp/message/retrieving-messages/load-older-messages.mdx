公共入口 `getAdvancedHistoryMessageList()` 读取历史：

```uts
import { getAdvancedHistoryMessageList } from '@/uni_modules/unix-openim-sdk'

const page = await getAdvancedHistoryMessageList({
  conversationID,
  startClientMsgID: '',
  count: 50,
})
```

第一页用空 `startClientMsgID`，后续使用当前最早边界消息的 ID。读取结果中的结束标记与消息列表，按 `clientMsgID` 去重。

商业版 `getHistoryMessageList()` <span className="enterprise-field-badge">商业版</span> 额外支持 `isReverse`、`viewType` 和 `lastMinSeq`。不要把它等同于已删除的单独 reverse-history 页面；方向通过参数表达。
