---
title: '创建 @ 消息'
description: '使用 iOS SDK 创建提及指定群成员的文本消息。'
sourcePath: '/sdk/ios/message/creating-messages/create-text-at-message'
---

```objc
OIMAtInfo *info = [OIMAtInfo new];
info.atUserID = member.userID;
info.groupNickname = member.nickname;
OIMMessageInfo *message =
    [OIMMessageInfo createTextAtMessage:text
                              atUsersID:@[member.userID]
                            atUsersInfo:@[info]
                                message:nil];
```

`atUsersID` 使用稳定用户 ID，`atUsersInfo` 提供展示资料，`message` 可传被引用原消息。单条消息的提及人数受底层限制；创建后只能发送到群聊。
