## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `messageList` | `MessageItem[]` | 是 | 要合并的已发送消息列表。 |
| `title` | `string` | 是 | 合并消息卡片标题。 |
| `summaryList` | `string[]` | 是 | 卡片摘要列表。 |

```ts
const { data: message } = await openimsdk.createMergerMessage({
  messageList: selectedMessages,
  title: '项目讨论记录',
  summaryList: selectedMessages.slice(0, 4).map(buildSummary),
});
```

接口调用成功后返回待发送的合并消息 `MessageItem` 对象，原始消息记录保持不变。后续需调用 [发送消息](/sdk/wasm/message/sending-messages/send-message) 投递该消息。在构造 `summaryList` 摘要列表时，建议截取前几条核心文本进行简要预览。
