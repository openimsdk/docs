Use `createMergerMessage()` to create a merged forwarded message containing multiple messages.

```ts
const message = await OpenIMSDK.createMergerMessage({
  messageList: selectedMessages,
  title: 'Project discussion',
  summaryList: ['Alex: The release plan is confirmed', 'Lee: I will follow up on testing'],
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `messageList` | `MessageItem[]` | Yes | Messages to merge. |
| `title` | `string` | Yes | Title of the merged message. |
| `summaryList` | `string[]` | Yes | Summary lines shown for the merged message. |

The call returns a `MessageItem` ready to send. Summary content should follow the display and privacy rules of the current conversation.
