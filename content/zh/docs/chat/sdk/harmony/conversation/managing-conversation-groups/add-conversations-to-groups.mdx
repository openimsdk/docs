该操作只增加会话与分组的关联，不创建会话，也不修改消息发送目标。

## 参数说明

| 参数                   | 类型       | 是否必填 | 说明                      |
| ---------------------- | ---------- | -------- | ------------------------- |
| `conversationIDs`      | `string[]` | 是       | 要添加的 OpenIM 会话 ID。 |
| `conversationGroupIDs` | `string[]` | 是       | 目标会话分组 ID。         |

```ts
import sdk, { AddConversationsToGroupsReq } from '@openimsdk/imsdk';

const request: AddConversationsToGroupsReq = {
  conversationIDs: [conversationID],
  conversationGroupIDs: [conversationGroupID],
};
await sdk.addConversationsToGroups(request);
```

Promise 成功表示关联请求已经完成，不表示分组成员事件已经到达。收到事件通知后，按 `conversationGroupID` 和 `conversationID` 合并增量，完整监听代码请参考[会话分组概览](/sdk/harmony/conversation/managing-conversation-groups/overview-conversation-groups)；需要最终确认时可重新查询受影响的分组。
