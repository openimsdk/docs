会话分组属于商业版能力。批量调整会话分组的展示顺序，传入包含 `conversationGroupOrders` 数组的对象，每项均须提供分组 ID 和对应的顺序值。

```uts
import { setConversationGroupOrder } from '@/uni_modules/unix-openim-sdk'

await setConversationGroupOrder({
  conversationGroupOrders: [
    { conversationGroupID: firstGroupID, order: 100 },
    { conversationGroupID: secondGroupID, order: 200 },
  ],
})
```

`order` 的排序方向由产品统一约定。Promise 成功表示排序请求已经完成，不返回完整分组数据。客户端可按各分组的 `conversationGroupID` 更新本地展示顺序；收到分组变更事件后，可参考[会话分组概览](/sdk/uniapp/conversation/managing-conversation-groups/overview-conversation-groups)重新查询列表校准最终顺序。
