Hide all conversation entries from the active conversation list for the current account. This batch operation hides conversations on the current device without deleting any historical chat messages.

```ts
await OpenIMSDK.hideAllConversations();
```

## Return value

A resolved Promise confirms that the request to hide all conversations was processed.

Upon successful resolution, clear the locally rendered conversation list and refresh the interface by invoking [Retrieve conversation list](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list) and [Get total unread count](/sdk/react-native/conversation/managing-conversations/get-total-unread-count). When new messages arrive or new interactions occur, affected conversations reappear through `OnNewConversation` or `OnConversationChanged` events, where the client merges entries keyed by `conversationID`.
