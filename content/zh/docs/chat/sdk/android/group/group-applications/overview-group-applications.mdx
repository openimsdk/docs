群申请记录使用 `GroupApplicationInfo` 表示。收到的申请面向群管理者，发出的申请面向当前用户；`handleResult`、`reqMsg`、`handledMsg` 和处理时间用于展示申请状态。

Android SDK 提供收到与发出申请的分页查询，以及同意、拒绝操作；不提供 Flutter 菜单中的“待处理申请数量”接口。申请新增、同意、拒绝和删除事件由[群组概览](/sdk/android/group/overview-group)的统一 listener 负责合并。
