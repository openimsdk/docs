---

`signalingGetRoomByGroupID()` 的参数是群组 ID，不是 `roomID`，即使通话使用了自定义 `roomID`。

```java
OpenIMClient.getInstance().signalingManager.signalingGetRoomByGroupID(
    new OnBase<RoomCallingInfo>() {
        @Override
        public void onSuccess(RoomCallingInfo room) {
            if (room.getRoomID() != null && !room.getRoomID().isEmpty()) {
                renderParticipants(room.getParticipant());
            }
        }

        @Override
        public void onError(int code, String error) {
            showNoActiveGroupCall();
        }
    },
    groupID
);
```

成功回调返回 `RoomCallingInfo` 快照，其中包含房间 ID、原始邀请、参与者、群组 ID、Token 和连接地址。

如果当前群组没有进行中的通话，接口可能返回错误或空房间。此时应清除本地保存的通话状态和房间凭据，不要继续尝试加入旧房间。
