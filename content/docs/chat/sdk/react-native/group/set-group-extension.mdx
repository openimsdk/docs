Attach custom application metadata to a group's `ex` property:

```ts
await OpenIMSDK.setGroupInfo({
  groupID,
  ex: JSON.stringify({
    projectID: 'project-42',
  }),
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group ID to update. |
| `ex` | `string` | Yes | Custom business extension string. Serialize JSON strings if saving structured objects. |

## Return value

A resolved Promise confirms that the group extension was persisted on the server.

The update triggers the `OnGroupInfoChanged` event. Use `groupID` as the key to locate the group in your state store and update its `ex` field. For event listener setup, see [Group overview](/sdk/react-native/group/overview-group).
