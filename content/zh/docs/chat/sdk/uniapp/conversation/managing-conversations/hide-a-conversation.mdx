---
title: '隐藏会话'
description: '从当前账号的会话列表隐藏指定会话入口。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/hide-a-conversation'
---

从当前登录用户的会话列表中隐藏指定会话入口。该操作不删除好友关系、不退出或解散群组，也不影响其他用户的会话状态。

```uts
import { hideConversation } from '@/uni_modules/unix-openim-sdk'

await hideConversation(conversationID)
```

该方法适合临时从聊天列表移除会话。收到新消息或重新同步后，隐藏的会话仍可能再次出现。

Promise 成功表示隐藏请求已完成，客户端可立即从当前列表移除对应 `conversationID` 的条目。收到会话变更事件后，继续按 `conversationID` 进行状态合并；若需核对完整列表，可重新执行分页拉取。完整会话事件监听见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。
