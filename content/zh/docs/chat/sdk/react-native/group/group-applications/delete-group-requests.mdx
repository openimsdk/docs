调用 `deleteGroupRequests()` 批量删除指定的入群申请记录。

```ts
await OpenIMSDK.deleteGroupRequests([
  {
    fromUserID: application.userID,
    groupID: application.groupID,
  },
]);
```

## 参数说明

数组中的每一项包含以下字段：

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `fromUserID` | `string` | 是 | 申请人的用户 ID，对应申请记录的 `userID`。 |
| `groupID` | `string` | 是 | 申请对应的群组 ID。 |

删除申请记录不会处理待处理申请。如需同意或拒绝申请，分别使用[接受入群申请](/sdk/react-native/group/group-applications/accept-group-application)和[拒绝入群申请](/sdk/react-native/group/group-applications/refuse-group-application)。

调用完成后表示删除请求已完成。申请记录删除时会触发 `OnGroupApplicationDeleted`，完整监听方式见[获取收到的入群申请](/sdk/react-native/group/group-applications/get-group-application-list-as-recipient)。
