Retrieve the group owner and all administrators directly, without paginating through the entire group membership:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID. |

## Code example

```dart
final ownerAndAdmins =
    await OpenIM.iMManager.groupManager.getGroupOwnerAndAdmin(
  groupID: groupID,
);
```

## Return value

A successful `Future` returns a list of group member records containing the owner and administrators (`List<GroupMembersInfo>`).

This query returns an immediate data snapshot and does not emit event notifications. When ownership transfers or administrator promotions occur, merge records idempotently using `groupID:userID`. See [Retrieving group members overview](/sdk/flutter/group/retrieving-group-members/overview-retrieving-group-members).
