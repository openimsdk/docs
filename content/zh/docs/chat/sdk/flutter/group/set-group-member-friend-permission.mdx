配置普通群成员之间是否允许通过群内会话或成员列表直接添加好友：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `applyMemberFriend` | `int` | 是 | 是否允许群成员互相加为好友。 |

```dart
await OpenIM.iMManager.groupManager.setGroupInfo(
  GroupInfo(
    groupID: groupID,
    applyMemberFriend: AllowType.notAllow,
  ),
);
```

`AllowType` 枚举说明：

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `AllowType.allow` | `0` | 允许群成员通过群聊互相添加好友。 |
| `AllowType.notAllow` | `1` | 禁止群成员通过群聊互相添加好友。 |

此字段仅限制添加好友权限，不负责控制群成员资料的可见性。如需控制群成员资料查看权限，请参考[设置成员资料查看权限](/sdk/flutter/group/set-group-member-profile-access)。

## 返回结果

Future 成功表示权限设置已提交。

SDK 会通过群资料变更通知广播最新设置。客户端以 `groupID` 为合并标识更新本地群资料中的 `applyMemberFriend` 字段，完整事件监听请参考[群组概览](/sdk/flutter/group/overview-group)；如需主动校准最新状态，可调用[查询指定群组资料](/sdk/flutter/group/retrieving-groups/get-specified-groups-info)。
