Configure verification rules for join requests and member invitations in a specified group. The caller's permissions are enforced by OpenIMServer:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID. |
| `needVerification` | `GroupVerification` | Yes | Join verification policy enumeration. |

## Code example

```dart
await OpenIM.iMManager.groupManager.setGroupInfo(
  GroupInfo(
    groupID: groupID,
    needVerification: GroupVerification.allNeedVerification,
  ),
);
```

`GroupVerification` enum options:

| Enum Option | Value | Behavior |
| --- | --- | --- |
| `GroupVerification.applyNeedVerificationInviteDirectly` | `0` | Join requests require approval; invitations from existing members enter directly. |
| `GroupVerification.allNeedVerification` | `1` | Both join requests and invitations require approval, unless initiated by an owner or administrator. |
| `GroupVerification.directly` | `2` | Direct access; no approval required for requests or invitations. |

## Return value

A successful `Future` indicates that the verification policy has been updated on the server.

## State changes after the call

The server broadcasts group profile update notifications. The client updates `needVerification` on the local group record using `groupID` as the key. For complete listener integration, see [Groups overview](/sdk/flutter/group/overview-group). To recalibrate group state, call [Get specified groups info](/sdk/flutter/group/retrieving-groups/get-specified-groups-info).
