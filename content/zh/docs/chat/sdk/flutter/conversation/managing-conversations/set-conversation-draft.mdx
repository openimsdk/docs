description: '保存或清空当前会话未发送的文字草稿。'

用户离开聊天页、切换会话或输入框内容变化时，可保存当前会话未发送的草稿文本。输入过程中建议先维护本地编辑器状态并对保存操作进行防抖；离开页面前再立即提交最新文本。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 目标会话 ID。 |
| `draftText` | `String` | 是 | 草稿文本内容；清空草稿时传入空字符串 `''`。 |

```dart
await OpenIM.iMManager.conversationManager.setConversationDraft(
  conversationID: conversationID,
  draftText: editorValue,
);
```

清空草稿时传空字符串：

```dart
await OpenIM.iMManager.conversationManager.setConversationDraft(
  conversationID: conversationID,
  draftText: '',
);
```

## 返回结果

Future 成功表示草稿已保存至本地会话数据。

多端同步或事件到达时通过会话变更事件通知。客户端以 `conversationID` 为合并标识更新对应会话的 `draftText` 和 `draftTextTime`，完整事件监听请参考[获取会话列表](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list)。退出登录或切换账号时应同时清理界面编辑器的内存状态。
