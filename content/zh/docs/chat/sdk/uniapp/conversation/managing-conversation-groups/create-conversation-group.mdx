会话分组属于商业版能力。创建普通分组时需要提供名称、顺序值和分组类型；需要同时加入一个会话时，再传 `conversationID`。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `name` | `string` | 是 | 分组名称。 |
| `order` | `number` | 是 | 分组顺序值，排序方向由产品统一约定。 |
| `conversationGroupType` | `OpenIMConversationGroupType` | 是 | 普通分组使用 `OpenIMConversationGroupTypeNormal`，筛选分组使用 `OpenIMConversationGroupTypeFilter`。 |
| `conversationID` | `string` 或 `null` | 否 | 创建后立即加入分组的会话 ID。 |
| `ex` | `string` 或 `null` | 否 | 应用约定的分组扩展字符串。 |

```uts
import {
  OpenIMConversationGroupTypeNormal,
  createConversationGroup,
} from '@/uni_modules/unix-openim-sdk'

const result = await createConversationGroup({
  name: '工作',
  order: 100,
  conversationGroupType: OpenIMConversationGroupTypeNormal,
  conversationID,
})
const group = result?.conversationGroup
```

Promise 成功后返回 `OpenIMCreateConversationGroupResult | null`，新分组位于 `conversationGroup`。客户端应以 `conversationGroupID` 为合并标识更新或插入本地分组状态；收到分组变更事件或连接恢复后，可参考[会话分组概览](/sdk/uniapp/conversation/managing-conversation-groups/overview-conversation-groups)重新查询列表校准最新状态。
