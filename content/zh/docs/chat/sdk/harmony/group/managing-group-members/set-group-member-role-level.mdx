description: '将普通群成员设置为管理员，或取消其管理员身份。'

只有具备相应权限的群主可以调整管理员身份。

```ts
import sdk, { GroupMemberRoleLevel, SetGroupMemberInfoReq } from '@openimsdk/imsdk';

const request: SetGroupMemberInfoReq = {
  groupID: groupID,
  userID: targetUserID,
  roleLevel: GroupMemberRoleLevel.GroupAdmin,
};
await sdk.setGroupMemberInfo(request);
```

## 参数说明

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `GroupMemberRoleLevel.GroupOrdinaryUsers` | `20` | 普通群成员。 |
| `GroupMemberRoleLevel.GroupAdmin` | `60` | 群管理员。 |
| `GroupMemberRoleLevel.GroupOwner` | `100` | 群主，只用于识别当前角色。 |

传入 `GroupAdmin` 可设置管理员，传入 `GroupOrdinaryUsers` 可取消管理员身份。不能通过写入 `GroupOwner` 完成群主变更，请使用[转让群主](/sdk/harmony/group/managing-group-members/transfer-group-owner)。Promise 成功后，SDK 会触发群成员资料变更事件；客户端收到通知后按 `groupID:userID` 更新对应成员的角色，完整监听配置请参考[分页查询群成员](/sdk/harmony/group/retrieving-group-members/get-group-member-list)。
