向目标用户发送添加好友申请，并附带验证说明信息：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `userID` | `String` | 是 | 申请添加的目标用户 ID。 |
| `reason` | `String` | 否 | 申请说明附言。 |

```dart
await OpenIM.iMManager.friendshipManager.addFriend(
  userID: 'user_b',
  reason: '你好，我是 Alex',
);
```

## 返回结果

Future 成功表示服务端已成功受理好友申请。

调用成功仅代表申请已送出，不代表对方已通过申请。待对方处理后，双方若达成好友关系，相关端会收到好友添加事件通知。当前用户已发出的申请进度请参考[获取发出的好友申请](/sdk/flutter/user/friend-applications/get-friend-application-list-as-applicant)。
