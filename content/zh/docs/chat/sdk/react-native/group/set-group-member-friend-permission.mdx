设置是否允许群成员通过群组关系向其他成员发送好友申请。该设置只控制从群成员关系发起好友申请的入口，与[设置成员资料查看权限](/sdk/react-native/group/set-group-member-profile-access)相互独立。

```ts
await OpenIMSDK.setGroupInfo({
  groupID,
  applyMemberFriend: AllowType.NotAllowed,
});
```

## 参数说明

`groupID` 为目标群组 ID，`applyMemberFriend` 使用 `AllowType`：

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `AllowType.Allowed` | `0` | 允许通过群成员关系发起好友申请。 |
| `AllowType.NotAllowed` | `1` | 不允许通过群成员关系发起好友申请。 |

## 返回结果

调用完成后，群内添加好友权限设置已生效。

群资料变化会通过 `OnGroupInfoChanged` 事件通知群内成员。客户端应以 `groupID` 为合并标识更新对应群组的 `applyMemberFriend` 字段。完整事件监听说明见[群组概览](/sdk/react-native/group/overview-group)。
