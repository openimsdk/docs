---

`signalingGetRoomByGroupID()` 返回可选 `roomID` 和 invitation。

```uts
import { signalingGetRoomByGroupID } from '@/uni_modules/unix-openim-sdk'

const result = await signalingGetRoomByGroupID({ groupID })
```

空值表示没有可加入房间。查询结果可能在返回后过期，真正加入前继续处理信令事件并获取有效 Token。
