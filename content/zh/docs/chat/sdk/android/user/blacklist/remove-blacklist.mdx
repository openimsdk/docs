---
title: '取消拉黑用户'
description: '使用 removeBlacklist() 将用户移出当前账号黑名单。'
sourcePath: '/sdk/android/user/blacklist/remove-blacklist'
---

```java
OpenIMClient.getInstance().friendshipManager.removeBlacklist(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markBlacklistRemovalSubmitted(targetUserID);
        }

        @Override
        public void onError(int code, String error) {
            recordBlacklistRemovalFailure(code, error);
        }
    },
    targetUserID
);
```

成功 callback 表示移除请求完成，不表示事件已经到达。黑名单快照应在 `onBlacklistDeleted` 到达后按 `userID` 删除；如果事件丢失，可重新调用[获取黑名单列表](/sdk/android/user/blacklist/get-blacklist)校准。

`onBlacklistDeleted` 由本页归属，应按 `userID` 删除本地记录：

```java
@Override
public void onBlacklistDeleted(BlacklistInfo user) {
    blacklistStore.remove(user.getUserID());
}
```
