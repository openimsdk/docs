基于相对于 SDK 初始化数据目录的相对文件路径创建图片消息对象。在调用[发送消息](/sdk/android/message/sending-messages/send-message)时，SDK 会自动完成原图压缩与文件上传。

```java
String imagePath = "images/pic_001.jpg"; // 相对于 SDK 数据目录的相对路径

Message message = OpenIMClient.getInstance().messageManager.createImageMessage(imagePath);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `imagePath` | `String` | 是 | 图片相对于 SDK 初始化数据目录的相对文件路径。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.PICTURE`。

本接口只在本地创建消息模型对象，不会发起网络上传。构建完成后，请调用[发送消息](/sdk/android/message/sending-messages/send-message)进行投递。若使用本地绝对路径创建，请参阅[使用本地路径创建图片消息](/sdk/android/message/creating-messages/create-image-message-by-file)。
