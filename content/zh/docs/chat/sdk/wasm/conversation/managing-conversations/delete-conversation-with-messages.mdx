---
title: '删除会话及消息'
description: '使用 WASM SDK 删除指定会话及其全部消息。'

---

产品语义为“删除此聊天”时，使用 `deleteConversationAndDeleteAllMsg()` 同时删除会话记录和当前账号下的会话消息。

```ts
await openimsdk.deleteConversationAndDeleteAllMsg(conversationID);
```

Promise 成功后可立即清理当前消息列表和会话列表项。成功不等于 `SdkEvent.OnConversationChanged` 已经到达；后续收到事件时，使用 `conversationID` 更新对应会话。如果没有收到事件，可重新查询并以最新结果为准。该操作不会删除好友关系、退出群组或影响其他用户的数据。
