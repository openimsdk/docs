用户打开会话阅读最新消息后，将该会话的未读消息标记为已读。

```ts
await OpenIMSDK.markConversationMessageAsRead(conversationID);
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 要标记已读的会话 ID。 |

## 返回结果

调用完成后，当前账号在该会话中的未读消息数已清零。

会话未读数及总未读数更新会通过 `OnConversationChanged` 和 `OnTotalUnreadMessageCountChanged` 事件通知；客户端应使用 `conversationID` 定位目标会话并将其 `unreadCount` 重置为 `0`。在群聊场景中，该操作仅重置当前账号的会话未读计数；若需向群内其他成员同步单条消息的已读回执，请参考[上报群消息已读](/sdk/react-native/message/managing-read-status/send-group-read-receipts)。完整会话监听说明见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。
