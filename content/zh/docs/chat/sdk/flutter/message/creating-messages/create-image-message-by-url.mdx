使用业务侧已上传至对象存储（OSS/COS 等）的图片 URL 和元数据，构建待发送的图片消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `sourcePicture` | `PictureInfo` | 是 | 原图信息，包含 URL、文件字节大小及宽高尺寸。 |
| `bigPicture` | `PictureInfo` | 是 | 大图信息，包含 URL、文件字节大小及宽高尺寸。 |
| `snapshotPicture` | `PictureInfo` | 是 | 缩略图信息，包含 URL、文件字节大小及宽高尺寸。 |

```dart
final message = await OpenIM.iMManager.messageManager.createImageMessageByURL(
  sourcePicture: source,
  bigPicture: big,
  snapshotPicture: snapshot,
);
```

各 `PictureInfo` 中的 URL、文件尺寸与宽高必须来自真实的媒体上传结果，以确保接收端能够正确排版与预览。

## 返回结果

Future 成功返回待发送的图片消息对象（`Message`），其图片属性保存在 `pictureElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送，也不会触发新消息事件通知。由于图片已在业务侧完成上传，构建完成后必须将返回的 `Message` 实例传给[发送不经 OSS 的消息](/sdk/flutter/message/sending-messages/send-message-not-oss)进行投递，避免重复上传。若需由 SDK 代为上传本地图片，请参考[创建图片消息](/sdk/flutter/message/creating-messages/create-image-message)。
