---
title: '拒绝好友申请'
description: '拒绝指定用户发来的好友申请。'
sourcePath: '/sdk/harmony/user/friend-applications/refuse-friend-application'
---

```ts
import sdk, { ApprovalStatus, HandleFriendApplicationReq } from '@openimsdk/imsdk';

const request: HandleFriendApplicationReq = {
  userID: applicantUserID,
  handleMsg: rejectReason,
  status: ApprovalStatus.Rejected,
};
await sdk.handleFriendApplication(request);
```

Promise 成功后等待申请拒绝事件到达更新状态，客户端按 `fromUserID:toUserID` 维护申请项，完整事件监听请参考 [获取收到的好友申请](/sdk/harmony/user/friend-applications/get-friend-application-list-as-recipient)。拒绝不会建立好友关系，也不等于删除申请记录。
