---
title: '接受入群申请'
description: '同意 Flutter 入群申请。'
sourcePath: '/sdk/flutter/group/group-applications/accept-group-application'
---

传入有效的 `groupID`、申请人 `userID` 和可选 `handleMsg`。Future 成功表示服务端完成处理请求，不应直接伪造成员记录。

```dart
await OpenIM.iMManager.groupManager.acceptGroupApplication(
  groupID: groupID,
  userID: applicantUserID,
  handleMsg: '欢迎加入',
);
```
