群主或管理员拒绝指定的加群申请：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupID` | `NSString *` | 目标群组 ID。 |
| `fromUserId` | `NSString *` | 申请人的用户 ID。 |
| `handleMsg` | `NSString *` | 拒绝理由或附言。 |

```objc
[[OIMManager manager] refuseGroupApplication:@"group_1001"
                                  fromUserId:@"user_003"
                                   handleMsg:@"暂不符合入群条件"
                                   onSuccess:^(NSString * _Nullable data) {
                                       NSLog(@"refuseGroupApplication success");
                                   }
                                   onFailure:^(NSInteger code, NSString *message) {
                                       NSLog(@"refuseGroupApplication failed: %ld %@", (long)code, message);
                                   }];
```

状态以 `groupID:userID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回操作结果。

服务端完成拒绝操作后，各端会通过 `onGroupApplicationRejected:` 事件分发状态变更（监听注册参见[入群申请概览](/sdk/ios/group/group-applications/overview-group-applications)），客户端应以 `groupID:userID` 为合并标识更新申请记录状态为已拒绝。
