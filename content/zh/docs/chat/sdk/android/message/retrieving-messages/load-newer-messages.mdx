title: '加载更新消息'
description: '使用 getAdvancedHistoryMessageListReverse 加载起点之后的消息。'

该方法用于从消息定位点向后读取，适合搜索定位或上下文分页。

```java
messageManager.getAdvancedHistoryMessageListReverse(callback, conversationID, startMessage, 20, ViewType.NORMAL);
```
