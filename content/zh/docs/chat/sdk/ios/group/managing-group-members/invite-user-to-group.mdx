title: '邀请用户加入群组'

群主和管理员可以邀请用户加入群组。客户端通常根据当前成员角色展示邀请入口，服务端会对操作者权限进行最终校验：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupID` | `NSString *` | 目标群组 ID。 |
| `reason` | `NSString *` | 邀请附言或入群说明。 |
| `usersID` | `NSArray<NSString *> *` | 被邀请的用户 ID 列表。 |

```objc
[[OIMManager manager] inviteUserToGroup:@"group_1001"
                                 reason:@"邀请加入项目讨论组"
                                usersID:@[@"user_001", @"user_002"]
                              onSuccess:^(NSArray<OIMGroupInviteResult *> *results) {
                                  for (OIMGroupInviteResult *item in results) {
                                      NSLog(@"user: %@, result: %ld", item.userID, (long)item.result);
                                  }
                              }
                              onFailure:^(NSInteger code, NSString *message) {
                                  NSLog(@"inviteUserToGroup failed: %ld %@", (long)code, message);
                              }];
```

状态以 `groupID:userID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回包含每个受邀用户处理状态的 `NSArray<OIMGroupInviteResult *> *` 数组。

调用成功表示服务端已接收并处理邀请请求。若群组开启了入群审核或用户设置了验证，用户可能需要确认后才能入群；当成员真正加入群组时，SDK 会通过[群组概览](/sdk/ios/group/overview-group)中说明的 `onGroupMemberAdded:` 事件广播通知，客户端应按 `groupID:userID` 合并更新本地群成员列表。群成员事件监听及详细查询请参见[群成员查询概览](/sdk/ios/group/retrieving-group-members/overview-retrieving-group-members)。
