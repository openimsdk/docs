---
title: '定期删除服务端消息'
description: '启用、关闭并配置指定会话的服务端消息定期删除策略。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/set-message-destruct'
---

该策略由开关和周期共同控制。

```ts
import sdk, { SetConversationReq } from '@openimsdk/imsdk';

const request: SetConversationReq = {
  conversationID: conversationID,
  isMsgDestruct: true,
  msgDestructTime: 3600,
};
await sdk.setConversation(request);
```

`msgDestructTime` 单位为秒。关闭时设置 `isMsgDestruct: false`。

达到周期后只删除服务端保存的消息，不主动删除当前设备或其他客户端已经同步到本地的消息。卸载重装、清除本地数据或换到尚未同步的新设备后，已被服务端删除的消息无法再次拉取。

Promise 成功后，SDK 会触发会话变更事件；客户端收到通知后根据 `conversationID` 更新对应会话的 `isMsgDestruct` 与 `msgDestructTime` 属性，完整监听配置请参考[获取会话列表](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list)。
