title: '发布或更新群公告'
description: '使用 Flutter SDK 设置群组公告。'
sourcePath: '/sdk/flutter/group/set-group-announcement'
---

```dart
await OpenIM.iMManager.groupManager.setGroupInfo(
  GroupInfo(
    groupID: groupID,
    notification: announcement.trim(),
  ),
);
```

`notification` 是群公告，与群简介 `introduction` 不同。传入空字符串可清空公告；修改权限最终由 OpenIMServer 校验。

Future 成功、`onGroupInfoChanged` 到达和重新查询是三个阶段。
