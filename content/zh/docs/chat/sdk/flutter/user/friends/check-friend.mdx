批量检查当前登录用户与指定用户列表之间的好友关系状态：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `userIDList` | `List<String>` | 是 | 待检查好友关系的目标用户 ID 列表。 |

```dart
final checks = await OpenIM.iMManager.friendshipManager.checkFriend(
  userIDList: ['user_a', 'user_b'],
);
```

## 返回结果

Future 成功返回好友关系信息列表（`List<FriendshipInfo>`）。

每个 `FriendshipInfo` 包含目标 `userID` 及 `result` 状态：当 `result == 1` 时表示对方为双向有效好友；其他数值表示非好友状态。

该查询为轻量级关系判断，不会返回好友备注、个性签名或扩展字段，也不会触发事件通知。若需查阅好友的完整资料卡信息，请参考[查询指定好友资料](/sdk/flutter/user/friends/get-friends-info)。
