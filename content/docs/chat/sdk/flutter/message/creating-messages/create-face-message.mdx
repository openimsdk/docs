Construct an emoji or sticker message object using built-in or custom sticker pack definitions:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `index` | `int` | Yes | Numeric index of the emoji or sticker defined by your application protocol. |
| `data` | `String` | Yes | Additional emoji payload, such as a remote URL, animated sticker resource identifier, or custom JSON string. |

## Code example

```dart
final message = await OpenIM.iMManager.messageManager
    .createFaceMessage(index: 3, data: emojiURL);
```

The emoji index scheme and payload structure are agreed upon at the application layer. We recommend implementing fallback rendering for missing or unrecognized emoji packs on the recipient client.

## Return value

Returns a `Future` resolving to an emoji `Message` object ready for transmission. Its payload is stored in `faceElem`.

## State changes after the call

Creating a message only constructs the local message data structure in memory; it does not perform network transmission and does not trigger new-message event callbacks. Once constructed, pass the returned `Message` instance to [Send a message](/sdk/flutter/message/sending-messages/send-message) to deliver it to a direct or group conversation.
