Update essential group attributes—including name, description, and avatar image. Pass only the properties to be modified:

```ts
await OpenIMSDK.setGroupInfo({
  groupID,
  groupName: groupName.trim(),
  introduction: introduction.trim(),
  faceURL,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group ID to update. |
| `groupName` | `string` | No | New group name. |
| `introduction` | `string` | No | New group description text. |
| `faceURL` | `string` | No | New group avatar image URL. |

Alongside `groupID`, provide at least one field to modify. Omitted fields remain unchanged on the server.

## Return value

A resolved Promise confirms that the group profile fields were updated on the server.

The update triggers the `OnGroupInfoChanged` event for all group members. Reconcile the local group record keyed by `groupID`. For complete event listeners, see [Group overview](/sdk/react-native/group/overview-group).
