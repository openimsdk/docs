```dart
final platformIDs =
    await OpenIM.iMManager.conversationManager.getInputStates(
  conversationID,
  otherUserID,
);

setTyping(otherUserID, platformIDs?.isNotEmpty == true);
```

The Future returns a nullable snapshot of platform IDs. The query itself does not trigger a listener. In a group conversation, do not poll every member frequently. Query relevant members only when opening the screen, restoring a connection, or reconciling state. Maintain online increments through the listener owned by [Report typing status](/sdk/flutter/message/composing-messages/update-typing-status).
