使用 `getGroupMemberOwnerAndAdmin()` 获取需要展示或校验管理身份的成员记录。

```java
OpenIMClient.getInstance().groupManager.getGroupMemberOwnerAndAdmin(
    new OnBase<List<GroupMembersInfo>>() {
        @Override public void onSuccess(List<GroupMembersInfo> members) { /* members 是查询到的成员资料。 */ }
        @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
    }, groupID);
```

`roleLevel` 的群主、管理员和普通成员常量见 `GroupRole`。
