---
title: '设置成员资料查看权限'
description: '控制群成员能否通过群组查看其他成员资料。'
sourcePath: '/sdk/harmony/group/set-group-member-profile-access'
---

`GroupLookMemberInfo` 明确区分允许和禁止。不要把枚举值当作普通布尔值使用。

```ts
import sdk, { GroupLookMemberInfo, SetGroupInfoReq } from '@openimsdk/imsdk';

const request: SetGroupInfoReq = {
  groupID: groupID,
  lookMemberInfo: GroupLookMemberInfo.AllowGroupLookMemberInfo,
};
await sdk.setGroupInfo(request);
```

如需禁止查看，传 `ProhibitGroupLookMemberInfo`。该设置与能否通过群组添加好友相互独立。Promise 成功后，通过群资料事件或重新查询更新界面。
