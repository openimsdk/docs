---
title: '删除本地消息'
description: '仅删除当前设备上的一条消息。'
sourcePath: '/sdk/harmony/message/managing-messages/delete-local-message'
---

```ts
import sdk, { DeleteMessageFromLocalReq } from '@openimsdk/imsdk';

const request: DeleteMessageFromLocalReq = {
  conversationID: conversationID,
  clientMsgID: message.clientMsgID,
};
await sdk.deleteMessageFromLocal(request);
removeMessage(conversationID, message.clientMsgID);
```

两个 ID 都应来自当前会话和消息对象。Promise 成功只表示当前设备数据库中的消息已删除；服务端仍可能保留记录，重建本地数据后可能重新同步。该操作不会通知其他设备或会话成员，也不等同于撤回。
