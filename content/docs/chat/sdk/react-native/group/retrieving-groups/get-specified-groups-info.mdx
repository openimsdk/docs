Batch query detailed profile information for specified groups by their IDs:

```ts
const groups = await OpenIMSDK.getSpecifiedGroupsInfo([
  'group-001',
  'group-002',
]);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupIDs` | `string[]` | Yes | Array of group IDs to query. |

## Return value

A resolved Promise returns `GroupItem[]` matching the requested group IDs. The order of elements in the returned array is not guaranteed to match the input sequence; correlate and merge records into local state using `groupID`. For field definitions, see [Group overview](/sdk/react-native/group/overview-group).
