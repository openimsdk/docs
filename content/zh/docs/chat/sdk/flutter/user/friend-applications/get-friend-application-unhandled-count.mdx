查询指定时间戳之后未处理的好友申请数量，常用于联系人角标或红点提示：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `time` | `int` | 是 | 起始时间戳（秒），通常传入上次查看申请列表的时间；传 `0` 统计全部未处理申请。 |

```dart
final count = await OpenIM.iMManager.friendshipManager
    .getFriendApplicationUnhandledCount(
  GetFriendApplicationUnhandledCountReq(time: lastViewedAt),
);
```

## 返回结果

Future 成功返回未处理好友申请数量（`int`）。

查询操作建立当前未处理申请数量的静态快照，不改变申请状态，也不会触发事件通知。查看或处理申请请参考[获取收到的好友申请](/sdk/flutter/user/friend-applications/get-friend-application-list-as-recipient)。
