使用业务侧已上传至对象存储的音频 URL 及元数据，构建待发送的语音/音频消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `soundElem` | `SoundElem` | 是 | 已上传音频的元数据模型，应包含真实的下载 URL、UUID、文件字节大小与秒级播放时长。 |

```dart
final message = await OpenIM.iMManager.messageManager
    .createSoundMessageByURL(soundElem: soundElem);
```

`SoundElem` 中填写的 URL、音频时长和文件大小必须来自真实上传结果，以确保接收端播放器能正确计算时长与缓冲。

## 返回结果

Future 成功返回待发送的音频消息对象（`Message`），其音频数据保存在 `soundElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送，也不会触发新消息事件通知。由于音频资源已由业务侧提前上传，构建完成后必须将返回的 `Message` 实例传给[发送不经 OSS 的消息](/sdk/flutter/message/sending-messages/send-message-not-oss)进行投递，避免重复上传。若需由 SDK 上传本地音频，请参考[创建音频消息](/sdk/flutter/message/creating-messages/create-sound-message)。
