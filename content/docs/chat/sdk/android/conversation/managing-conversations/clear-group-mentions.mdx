When group members mention the authenticated user or invoke `@everyone`, the conversation's `groupAtType` flags the corresponding mention status. After the user opens the group chat and views the relevant messages, reset the mention flag to dismiss high-priority badges or highlight indicators in the conversation list.

## Code example

```java
OpenIMClient.getInstance().conversationManager.resetConversationGroupAtType(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // Group mention reset completed.
        }

        @Override
        public void onError(int code, String error) {
            // code and error describe the failure.
        }
    },
    conversationID
);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | Yes | Callback delivering the asynchronous operation result. |
| `conversationID` | `String` | Yes | Target group conversation identifier. |

## Return value

The successful callback indicates that the server recorded the reset operation and restored `groupAtType` to its default state.

## State changes after the call

After resetting the mention flag, the SDK triggers the `OnConversationListener.onConversationChanged` event. Locate the conversation by `conversationID`, clear mention banners (such as "@mention" or "@everyone") from the conversation item, and refresh the UI. For complete listener registration details, see [Get the conversation list](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list).
