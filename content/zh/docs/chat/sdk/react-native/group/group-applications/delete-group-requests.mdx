批量删除指定的入群申请历史记录。该操作仅清除申请列表中的历史记录项，不代表同意或拒绝申请。

```ts
await OpenIMSDK.deleteGroupRequests([
  {
    fromUserID: application.userID,
    groupID: application.groupID,
  },
]);
```

## 参数说明

数组中的每一项包含以下字段：

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `fromUserID` | `string` | 是 | 申请人的用户 ID，对应申请记录的 `userID`。 |
| `groupID` | `string` | 是 | 申请对应的群组 ID。 |

删除申请记录不会改变申请本身的审批状态。如需审批申请，可分别参考[接受入群申请](/sdk/react-native/group/group-applications/accept-group-application)和[拒绝入群申请](/sdk/react-native/group/group-applications/refuse-group-application)。

## 返回结果

调用完成后，删除入群申请记录请求已处理完成。

记录删除后会触发 `OnGroupApplicationDeleted` 事件；客户端应以申请对应的 `groupID` 和申请人 `userID`（即 `fromUserID`）为复合标识，从本地申请列表中移除对应记录。完整监听方式见[获取收到的入群申请](/sdk/react-native/group/group-applications/get-group-application-list-as-recipient)。
