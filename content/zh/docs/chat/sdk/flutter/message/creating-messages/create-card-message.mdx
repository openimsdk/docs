```dart
final message = await OpenIM.iMManager.messageManager.createCardMessage(
  userID: userID,
  nickname: nickname,
  faceURL: faceURL,
);
```

卡片中的昵称、头像等资料会固定为创建消息时的内容，不会随用户资料自动更新。Future 只创建待发送对象。
