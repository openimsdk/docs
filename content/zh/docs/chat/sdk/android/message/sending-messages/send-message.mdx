---
title: '发送消息'
description: '使用 sendMessage 将 Message 发送到单聊或群聊。'
sourcePath: '/sdk/android/message/sending-messages/send-message'
---

单聊填写 `recvUid`，群聊填写 `recvGid`，另一个目标参数传 `null`。`OnMsgSendCallback` 同时承载成功、失败和媒体进度。

```java
messageManager.sendMessage(new OnMsgSendCallback() {
    @Override public void onSuccess(Message sentMessage) { mergeSentMessage(sentMessage); }
    @Override public void onError(int code, String error) { showSendError(error); }
}, message, peerUserID, null, offlinePushInfo);
```
