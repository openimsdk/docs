Only group owners have permission to assign or revoke administrator roles.

## Code example

```ts
import sdk, { GroupMemberRoleLevel, SetGroupMemberInfoReq } from '@openimsdk/imsdk';

const request: SetGroupMemberInfoReq = {
  groupID: groupID,
  userID: targetUserID,
  roleLevel: GroupMemberRoleLevel.GroupAdmin,
};
await sdk.setGroupMemberInfo(request);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group identifier. |
| `userID` | `string` | Yes | Target member user ID. |
| `roleLevel` | `GroupMemberRoleLevel` | Yes | Target role level. See role level values below. |

### Role level values

| Enum value | Value | Description |
| --- | --- | --- |
| `GroupMemberRoleLevel.GroupOrdinaryUsers` | `20` | Regular group member. Pass to demote an administrator. |
| `GroupMemberRoleLevel.GroupAdmin` | `60` | Group administrator. Pass to promote a member. |
| `GroupMemberRoleLevel.GroupOwner` | `100` | Group owner (used for role identification only). |

## Return value

Returns a Promise that resolves to `void` when the role update succeeds on the server.

## State changes after the call

Pass `GroupAdmin` to grant administrator status or `GroupOrdinaryUsers` to revoke it. You cannot change group ownership by passing `GroupOwner`; use [Transfer group ownership](/sdk/harmony/group/managing-group-members/transfer-group-owner) instead. Once the Promise resolves, the SDK triggers a group member info changed event; clients update the member record matching `groupID:userID`. For complete event listeners, see [Retrieve group member list](/sdk/harmony/group/retrieving-group-members/get-group-member-list).
