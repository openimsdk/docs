会话分组属于商业版能力。`getConversationGroupInfoWithConversations()` 同时返回一个分组和当前页会话详情。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationGroupID` | `string` | 是 | 要查询的会话分组 ID。 |
| `pagination.pageNumber` | `number` | 是 | 页码，从 `1` 开始。 |
| `pagination.showNumber` | `number` | 是 | 每页读取的会话数量。 |

```uts
import { getConversationGroupInfoWithConversations } from '@/uni_modules/unix-openim-sdk'

const result = await getConversationGroupInfoWithConversations({
  conversationGroupID,
  pagination: {
    pageNumber: 1,
    showNumber: 20,
  },
})

if (result != null) {
  renderConversationGroup(
    result.conversationGroup,
    result.conversations,
    result.ConversationTotal ?? 0,
  )
}
```

## 返回结果

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `conversationGroup` | `OpenIMConversationGroupItem` 或 `null` | 当前会话分组资料。 |
| `ConversationTotal` | `number` 或 `null` | 分组内会话总数；字段名首字母为大写。 |
| `conversations` | `OpenIMConversationItem[]` | 当前页会话详情。 |

分页结束条件应结合 `ConversationTotal` 和已经加载的会话数量判断。查询不会触发分组事件；分页期间收到分组变化信号时，应重置分页并重新查询。
