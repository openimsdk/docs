批量调整当前账号下会话分组的排序值。

```ts
await OpenIMSDK.setConversationGroupOrder([
  { conversationGroupID: firstGroupID, order: 100 },
  { conversationGroupID: secondGroupID, order: 200 },
]);
```

## 参数说明

方法接收包含排序项的数组，每个元素包含以下字段：

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationGroupID` | `string` | 是 | 要调整顺序的会话分组 ID。 |
| `order` | `number` | 是 | 新的排序值，业务侧应统一排序升降序规则。 |

## 返回结果

调用完成后，排序更新请求已处理完成。

分组信息更新后会触发 `OnConversationGroupChanged` 事件；客户端在合并状态时，应根据 `conversationGroupID` 更新对应分组的排序字段并重新对分组列表进行排序展示。完整监听方式见[会话分组概览](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups)。
