批量检查一组指定用户是否在目标群组内，无需拉取完整的成员资料对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `userIDList` | `List<String>` | 是 | 待检查的用户 ID 列表。 |

```dart
final presentUserIDs = await OpenIM.iMManager.groupManager.getUsersInGroup(
  groupID,
  userIDList,
);
```

## 返回结果

Future 成功返回在目标群组中实际存在的用户 ID 列表（`List<String>`）。

该接口为轻量级在群状态校验，不返回群昵称、角色级别或禁言等资料信息。如需查阅具体成员资料，请参考[查询指定群成员资料](/sdk/flutter/group/retrieving-group-members/get-group-members-info)。

查询操作建立静态快照，不改变群成员状态，也不会触发事件通知。
