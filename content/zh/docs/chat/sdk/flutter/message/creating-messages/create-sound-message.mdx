从本地音频文件路径构建待发送的语音/音频消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `soundPath` | `String` | 是 | 设备本地可访问的音频文件路径。 |
| `duration` | `int` | 是 | 音频播放时长（秒）。 |

```dart
final message = await OpenIM.iMManager.messageManager.createSoundMessage(
  soundPath: soundPath,
  duration: durationSeconds,
);
```

传入的路径必须是当前设备平台上真实存在且具备读取权限的文件路径，时长单位为秒。

## 返回结果

Future 成功返回待发送的音频消息对象（`Message`），音频属性保存在 `soundElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送或文件上传，也不会触发新消息事件通知。构建完成后，需将返回的 `Message` 实例传给[发送消息](/sdk/flutter/message/sending-messages/send-message)，由 SDK 执行媒体上传与消息投递。若使用全绝对路径创建，请参考[使用本地路径创建音频消息](/sdk/flutter/message/creating-messages/create-sound-message-from-full-path)；若音频已上传至对象存储，请参考[使用 URL 创建音频消息](/sdk/flutter/message/creating-messages/create-sound-message-by-url)。
