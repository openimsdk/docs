Set `filter` to `0` for all members, `1` for regular members, `2` for the owner, or `3` for administrators. Use `offset` and `count` for pagination.

```java
OpenIMClient.getInstance().groupManager.getGroupMemberList(
    new OnBase<List<GroupMembersInfo>>() {
        @Override public void onSuccess(List<GroupMembersInfo> members) { /* members contains the current page. */ }
        @Override public void onError(int code, String error) { /* code and error describe the failure. */ }
    }, groupID, 0, offset, 50);
```
