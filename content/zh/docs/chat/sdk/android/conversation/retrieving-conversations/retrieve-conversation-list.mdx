会话列表属于当前登录用户。建议采用分页方式拉取会话列表，以避免数据量过大造成内存和渲染压力。每条 `ConversationInfo` 包含会话标识、未读数、最后一条消息、置顶和草稿等状态。

```java
OpenIMClient.getInstance().conversationManager.getConversationListSplit(
    new OnBase<List<ConversationInfo>>() {
        @Override
        public void onSuccess(List<ConversationInfo> conversations) {
            // conversations 是当前页会话列表。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    0,
    50
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<List<ConversationInfo>>` | 是 | 异步请求回调。 |
| `offset` | `long` | 是 | 从 `0` 开始的分页偏移量；初始加载或下拉刷新时重置为 `0`。 |
| `count` | `long` | 是 | 本页期望拉取的会话数量。 |

## 返回结果

成功回调返回当前页的 `List<ConversationInfo>`。客户端在合并数据时应以 `conversationID` 为唯一主键进行去重与更新；当返回数量小于 `count` 时，通常表示已到达列表末尾。加载下一页时，按已拉取的会话总数累加 `offset`。

## 保持列表同步

会话列表发生新增或属性变更时，通过在应用层注册的 `OnConversationListener` 接收实时事件推送：

```java
OnConversationListener conversationListener = new OnConversationListener() {
    @Override
    public void onNewConversation(List<ConversationInfo> conversations) {
        // conversations 为新增的会话列表。
    }

    @Override
    public void onConversationChanged(List<ConversationInfo> conversations) {
        // conversations 为发生更新的会话列表。
    }
};

OpenIMClient.getInstance().conversationManager.setOnConversationListener(
    conversationListener
);
```

两个事件均携带 `List<ConversationInfo>` 列表。客户端收到后需遍历列表，根据 `conversationID` 找到对应的本地会话对象进行字段合并或插入新项，并刷新界面排序。退出登录或切换账号时，可传入 `null` 清理旧监听器。
