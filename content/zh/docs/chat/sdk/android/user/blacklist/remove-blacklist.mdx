---
title: '取消拉黑用户'
description: '将指定用户从当前账号的黑名单中移除。'
sourcePath: '/sdk/android/user/blacklist/remove-blacklist'
---

将指定用户从当前登录账号的黑名单中移出。取消拉黑后，对方恢复向当前账号发送单聊消息的权限。

```java
OpenIMClient.getInstance().friendshipManager.removeBlacklist(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 取消拉黑成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    targetUserID
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `targetUserID` | `String` | 是 | 目标用户的用户 ID。 |

## 返回结果

成功回调表示服务端已成功将该用户移出黑名单。

操作生效后，SDK 会触发 `OnFriendshipListener.onBlacklistDeleted` 事件；客户端应以 `userID` 为主键唯一定位对应项并从本地黑名单数据源中剔除，完整监听配置请参考[获取黑名单列表](/sdk/android/user/blacklist/get-blacklist)。

```java
@Override
public void onBlacklistDeleted(BlacklistInfo user) {
    // 收到黑名单移除通知，按 user.getUserID() 从本地列表删除
}
```
