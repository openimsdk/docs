The OpenIM Android SDK identifies users through unique `userID` values. User APIs read and update the current user's profile, retrieve public user information, and subscribe to real-time online presence states.

Friend relationships, friend applications, and blocklists belong to relationship management; for their associated data types, APIs, and state updates, see [Relationship overview](/sdk/android/user/overview-relationships).

## User data models

The Android SDK uses distinct data models tailored to different application contexts:

| Class | Application scenario | Primary operations |
| --- | --- | --- |
| `LocalUser` | The authenticated user's profile, settings screens, avatar, nickname, and account preferences. | [Get current user profile](/sdk/android/user/user-profile/get-self-local-user-info), [Update the current user profile](/sdk/android/user/user-profile/set-self-info) |
| `PublicUserInfo` | Querying application users and presenting public profile cards. | [Get user profiles](/sdk/android/user/user-profile/get-users-info) |
| `UsersOnlineStatus` | Online presence, connection status, and active platform lists. | [Subscribe to user status](/sdk/android/user/online-status/subscribe-users-online-status), [Refresh subscribed user status](/sdk/android/user/online-status/get-subscribe-online-users-status), [Unsubscribe from user status](/sdk/android/user/online-status/unsubscribe-users-online-status) |

`LocalUser` represents the authenticated user, whereas `PublicUserInfo` models queryable public contact profiles. Group member profiles, in-group nicknames, and member moderation belong to group capabilities.

## State updates

The Android SDK's `UserInfoManager` retains a single listener instance. Register `OnUserListener` centrally within an application event manager, and merge local cached user state using `userID` as the unique key before dispatching updates to UI observers:

- Current user profile changes: see [Update the current user profile](/sdk/android/user/user-profile/set-self-info).
- Online presence changes: see [Subscribe to user status](/sdk/android/user/online-status/subscribe-users-online-status).
- Friend relationships, requests, and blocklist updates: see [Relationship overview](/sdk/android/user/overview-relationships).
