Use `deleteConversationAndDeleteAllMsg()` for a product action such as “delete this chat”.

```java
OpenIMClient.getInstance().conversationManager.deleteConversationAndDeleteAllMsg(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            messageStore.clearConversation(conversationID);
            conversationStore.remove(conversationID);
        }

        @Override
        public void onError(int code, String error) {
            recordConversationDeleteFailure(code, error);
        }
    },
    conversationID
);
```

After success, clear the current message list and conversation row. This does not delete a friend relationship or leave or dismiss a group. A conversation can be regenerated by a new message or synchronization while the chat target still exists; reconcile through `onConversationChanged` or a fresh query.
