---
title: '接受入群申请'
description: '同意 iOS 入群申请。'
sourcePath: '/sdk/ios/group/group-applications/accept-group-application'
---

```objc
[[OIMManager manager] acceptGroupApplication:application.groupID
  fromUserId:application.userID handleMsg:@"同意加入"
  onSuccess:^(NSString * _Nullable data) { [self showHandled]; }
  onFailure:^(NSInteger code, NSString *message) { [self showErrorCode:code message:message]; }];
```

成功 callback 表示处理请求完成，不应直接伪造成员记录。申请与成员事件分别处理。
