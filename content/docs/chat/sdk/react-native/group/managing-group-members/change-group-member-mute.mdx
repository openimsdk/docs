Silence an individual group member for a set duration, or pass `0` to unmute:

```ts
await OpenIMSDK.changeGroupMemberMute({
  groupID: 'group-001',
  userID: 'user-002',
  mutedSeconds: 3600,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group ID. |
| `userID` | `string` | Yes | Member user ID to mute or unmute. |
| `mutedSeconds` | `number` | Yes | Mute duration in seconds; pass `0` to lift the mute immediately. |

## Return value

A resolved Promise confirms that the member muting status was updated on the server.

The update triggers `OnGroupMemberInfoChanged` carrying the member's latest attributes, including `muteEndTime`. Reconcile member status using the composite key `groupID:userID`. For complete event listeners, see [Get group member list by page](/sdk/react-native/group/retrieving-group-members/get-group-member-list).
