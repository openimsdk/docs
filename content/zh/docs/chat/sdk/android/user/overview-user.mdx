OpenIM Android SDK 使用 `userID` 标识用户。用户相关 API 用于读取和更新当前账号资料、查询公开用户资料，以及订阅用户在线状态。

好友、好友申请和黑名单属于用户之间的关系链能力，相关类型、API 和状态更新见[关系链概览](/sdk/android/user/overview-relationships)。

## 用户类型

Android SDK 会根据使用场景返回不同的用户对象：

| 类型 | 适用场景 | 主要 API |
| --- | --- | --- |
| `LocalUser` | 当前登录用户的本地资料、设置页、头像、昵称和账号级设置 | `getSelfLocalUserInfo()`、`setSelfInfo()` |
| `PublicUserInfo` | 查询应用用户和展示公开资料卡 | `getUsersInfo()` |
| `UsersOnlineStatus` | 用户在线状态和在线平台列表 | `subscribeUsersOnlineStatus()`、`getSubscribeOnlineUsersStatus()`、`unsubscribeOnlineUsersStatus()` |

`LocalUser` 表示当前登录用户，`PublicUserInfo` 表示可查询的公开用户资料。群成员资料、群内昵称和成员管理属于群组能力。

## 状态更新

Android SDK 只保留一个 `OnUserListener`。应用应在统一事件中心设置 listener，再把用户资料和在线状态变化分发给对应页面；本概览页不重复设置。具体事件数据和处理方式见下方归属页面：

- 当前用户资料变化：见[更新当前用户资料](/sdk/android/user/user-profile/set-self-info)。
- 在线状态变化：见[订阅用户在线状态](/sdk/android/user/online-status/subscribe-users-online-status)。
- 好友、好友申请和黑名单变化：见[关系链概览](/sdk/android/user/overview-relationships)。
