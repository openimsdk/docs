`createSoundMessageByURL()` 接收完整 `OpenIMSoundElem`。

```uts
import { createSoundMessageByURL } from '@/uni_modules/unix-openim-sdk'

const message = await createSoundMessageByURL(soundElem)
```

URL、UUID、大小、时长和类型应与上传结果一致。资源需对接收方可访问；不要把本地沙盒路径当成远端 URL。
