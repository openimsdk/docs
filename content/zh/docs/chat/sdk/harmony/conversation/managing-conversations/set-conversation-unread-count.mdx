---
title: '设置本地会话未读数'
description: '把一个或多个本地会话的未读数设置为指定值。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/set-conversation-unread-count'
---

该方法用于修正 SDK 本地会话未读数，不会制造服务端未读消息，也不能替代正常的已读上报。

```ts
import sdk, { ResetConversationUnreadReq } from '@openimsdk/imsdk';

const request: ResetConversationUnreadReq = {
  conversationIDs: [conversationID],
  num: 0,
};
await sdk.resetConversationUnread(request);
```

`num` 应为非负整数。同一值会应用到 `conversationIDs` 中的全部会话。Promise 成功后等待会话和总未读事件；需要严格确认时重新查询会话。
