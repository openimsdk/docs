Check whether the current server deployment and environment support speech-to-text capabilities. This method takes no parameters and is ideal for verifying feature availability before displaying a speech transcription entry point in the UI:

## Code example

```dart
try {
  await OpenIM.iMManager.messageManager.speechToTextCapabilities();
  setTranscriptionAvailable(true);
} catch (error) {
  setTranscriptionAvailable(false);
}
```

## Return value

Returns a `Future<void>`. Success indicates that the server has speech recognition enabled.

If the server does not support or has not enabled speech transcription, the call throws an error. This method does not return configuration details such as audio sample rate or duration limits. To perform speech-to-text transcription, see [Transcribe audio](/sdk/flutter/message/composing-messages/transcribe-audio).

## State changes after the call

This capability check queries server feature availability and does not alter message state or trigger event notifications.
