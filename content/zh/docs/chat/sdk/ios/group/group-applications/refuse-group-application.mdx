---
title: '拒绝入群申请'
description: '拒绝 iOS 入群申请。'
sourcePath: '/sdk/ios/group/group-applications/refuse-group-application'
---

```objc
[[OIMManager manager] refuseGroupApplication:application.groupID
  fromUserId:application.userID handleMsg:@"暂不接受"
  onSuccess:^(NSString * _Nullable data) { [self showHandled]; }
  onFailure:^(NSInteger code, NSString *message) { [self showErrorCode:code message:message]; }];
```

成功 callback 表示拒绝请求完成；`onGroupApplicationRejected:` 随后可能到达，按 `groupID:userID` 合并。
