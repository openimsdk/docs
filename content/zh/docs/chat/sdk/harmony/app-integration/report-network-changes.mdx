title: '上报网络状态变化'
description: '在宿主应用检测到网络变化后通知 OpenIMClientSDK 检查连接。'

---

宿主应用通过 NetworkKit 观察到网络类型、可用性或连接状态变化后，可以调用 `networkStatusChanged()` 通知 SDK 检查长连接。

```ts
import sdk from '@openimsdk/imsdk';

async function reportNetworkChanged(): Promise<void> {
  await sdk.networkStatusChanged();
}
```

监听网络状态需要由宿主模块声明 `ohos.permission.GET_NETWORK_INFO`。SDK HAR 本身不会注册 NetworkKit 观察器。

对连续抖动事件做合并或防抖，不要在一次系统回调中并行调用多次。Promise 成功只表示 SDK 已收到通知；实际重连结果通过连接事件确认。恢复连接后仍应等待同步事件完成，再读取需要校准的数据。
