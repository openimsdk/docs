调用 `removeBlack()` 将指定用户移出当前账号的黑名单。

```ts
await OpenIMSDK.removeBlack(blackUserID);
```

`blackUserID` 是要移出黑名单的用户 ID。移出后会触发 `OnBlackDeleted` 事件，监听方式见[获取黑名单](/sdk/react-native/user/blacklist/get-black-list)。
