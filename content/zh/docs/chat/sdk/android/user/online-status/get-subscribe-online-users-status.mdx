获取当前客户端已订阅用户的在线状态快照，用于恢复页面展示或主动校验在线信息。

```java
OpenIMClient.getInstance().userInfoManager.getSubscribeOnlineUsersStatus(
    new OnBase<List<UsersOnlineStatus>>() {
        @Override
        public void onSuccess(List<UsersOnlineStatus> states) {
            // 使用 states 显示在线状态
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    }
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<List<UsersOnlineStatus>>` | 是 | 异步请求回调。 |

## 返回结果

成功回调返回当前已订阅用户的状态列表 `List<UsersOnlineStatus>`。客户端应以 `userID` 为标识读取与维护在线状态缓存：

| 字段 | 说明 |
| --- | --- |
| `userID` | 目标用户的全局唯一 ID。 |
| `status` | 在线状态值（`1` 为在线，`0` 为离线）。 |
| `platformIDs` | 当前登录在线的平台列表（例如 Android、iOS、Web 等平台编号）。 |

如需订阅新用户或停止接收变更通知，请参阅[订阅用户在线状态](/sdk/android/user/online-status/subscribe-users-online-status)与[取消订阅用户状态](/sdk/android/user/online-status/unsubscribe-users-online-status)。
