---
title: '标记或取消标记会话'
description: '设置当前用户对指定会话的标记状态。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/mark-conversation'
---

标记会话属于商业版能力。`isMarked` 只影响当前用户看到的会话标记状态。标记后，会话会进入会话分组中的内置“标记一组”；取消标记后，会话会从该分组移除，不需要再调用会话分组成员 API 手动维护。

```uts
import { setConversation } from '@/uni_modules/unix-openim-sdk'

await setConversation({
  conversationID,
  isMarked: true,
})
```

传入 `false` 取消标记。标记状态与置顶状态相互独立，也不会修改群组资料或消息内容。会话分组的数据模型与查询方式见[会话分组概览](/sdk/uniapp/conversation/managing-conversation-groups/overview-conversation-groups)。

Promise 成功只表示设置请求已经完成，不表示会话变化事件已经到达。收到 `onConversationChanged()` 后，按 `conversationID` 更新对应会话的 `isMarked`；需要校准状态时重新查询会话。完整监听见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。
