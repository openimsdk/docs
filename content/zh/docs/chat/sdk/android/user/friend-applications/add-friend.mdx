---
title: '发送好友申请'
description: '使用 addFriend() 向指定用户发送好友申请。'
sourcePath: '/sdk/android/user/friend-applications/add-friend'
---

```java
OpenIMClient.getInstance().friendshipManager.addFriend(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markFriendApplicationSubmitted();
        }

        @Override
        public void onError(int code, String error) {
            recordFriendApplicationFailure(code, error);
        }
    },
    "user_b",
    "你好，我是 Alex"
);
```

第二个参数是申请接收方的 `userID`，第三个参数是申请附言。成功 callback 表示服务端已收到申请，不表示对方已经同意。目标用户 ID 不能为空；按昵称、手机号等字段搜索目标用户应先由业务后端完成。

好友申请状态变化通过 `OnFriendshipListener` 合并，见[获取收到的好友申请](/sdk/android/user/friend-applications/get-recv-friend-application-list)。
