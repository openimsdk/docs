description: '使用 UniApp SDK 清理当前账号本地与服务端的全部消息。'

---

该操作清理当前登录账号在本地和服务端保存的全部消息，影响所有会话，不适合作为单条消息或单个会话的清理入口。方法没有业务参数。

```uts
import { deleteAllMsgFromLocalAndSvr } from '@/uni_modules/unix-openim-sdk'

await deleteAllMsgFromLocalAndSvr()
resetAllMessageState()
```

这是不可撤销的账号级操作，执行前必须二次确认。Promise 成功表示本次清理请求已经完成；应用还要清空当前账号在内存中的消息列表、搜索结果、分页游标和相关缓存。

该操作不会删除其他会话成员持有的消息副本，也不表示当前账号的其他设备已经完成界面刷新。随后根据会话事件更新会话摘要；状态仍不确定时，重新查询会话和消息并以最新结果为准。
