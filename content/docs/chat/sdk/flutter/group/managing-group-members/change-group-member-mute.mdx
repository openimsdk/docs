A group owner or administrator can mute an individual group member for a specified duration, or unmute them immediately by passing 0 seconds:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID. |
| `userID` | `String` | Yes | Target member user ID to mute or unmute. |
| `seconds` | `int` | Yes | Mute duration in seconds from the current time. Pass `0` to unmute immediately. |

## Code example

```dart
await OpenIM.iMManager.groupManager.changeGroupMemberMute(
  groupID: groupID,
  userID: targetUserID,
  seconds: 3600,
);
```

## Return value

A successful `Future` indicates that the mute duration has been applied on the server. The member's status is keyed by `groupID:userID`.

## State changes after the call

Connected clients in the group receive member profile update events containing the updated `muteEndTime` Unix epoch timestamp in seconds. For complete member listener setup and incremental merging logic, see [Retrieving group members overview](/sdk/flutter/group/retrieving-group-members/overview-retrieving-group-members).
