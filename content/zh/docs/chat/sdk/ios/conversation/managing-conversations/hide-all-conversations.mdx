---
title: '隐藏全部会话'
description: '使用 iOS SDK 隐藏当前账号的全部会话入口。'
sourcePath: '/sdk/ios/conversation/managing-conversations/hide-all-conversations'
---

该方法作用于当前账号的全部会话：

```objc
[[OIMManager manager] hideAllConversationsWithOnSuccess:^(NSString *data) {
    [self clearConversationList];
}
                                              onFailure:nil];
```

成功表示隐藏请求完成，可以据此清理当前账号的会话列表页面状态和分页引用。该操作不删除消息或聊天关系。
