```objc
[[OIMManager manager] insertGroupMessageToLocalStorage:message
    groupID:groupID
    sendID:currentUserID
    onSuccess:^(OIMMessageInfo *stored) {
        if (stored != nil) [self upsertMessage:stored];
    }
    onFailure:nil];
```

The method declaration allows `groupID` and `sendID` to be `nil`; pass the actual group ID and sender ID when calling it. The success callback may also receive `nil`, so check the result before using it. This method modifies the current device only. It does not send the message to group members or trigger the new-message delegate.
