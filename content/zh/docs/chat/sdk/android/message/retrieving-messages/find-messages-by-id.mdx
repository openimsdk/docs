构造 `SearchParams` 列表查询消息。

```java
messageManager.findMessageList(new OnBase<SearchResult>() {
    @Override public void onSuccess(SearchResult result) { showFoundMessages(result); }
    @Override public void onError(int code, String error) { showQueryError(error); }
}, searchParams);
```
