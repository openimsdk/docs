配置普通群成员是否允许查看其他成员的个人资料卡片与详细信息：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `lookMemberInfo` | `int` | 是 | 是否允许查看群成员资料。 |

```dart
await OpenIM.iMManager.groupManager.setGroupInfo(
  GroupInfo(
    groupID: groupID,
    lookMemberInfo: AllowType.notAllow,
  ),
);
```

`AllowType` 枚举说明：

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `AllowType.allow` | `0` | 允许群成员查看其他成员资料。 |
| `AllowType.notAllow` | `1` | 禁止群成员查看其他成员资料。 |

该设置与[设置群内添加好友权限](/sdk/flutter/group/set-group-member-friend-permission)相互独立。

## 返回结果

Future 成功表示权限策略已更新。

SDK 会通过群资料变更通知广播最新设置。客户端以 `groupID` 为合并标识更新本地群资料中的 `lookMemberInfo` 字段，完整事件监听请参考[群组概览](/sdk/flutter/group/overview-group)；如需主动校准最新状态，可调用[查询指定群组资料](/sdk/flutter/group/retrieving-groups/get-specified-groups-info)。
