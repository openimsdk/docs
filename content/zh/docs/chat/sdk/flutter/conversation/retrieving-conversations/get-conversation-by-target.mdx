从通讯录、用户资料页或群组资料页发起聊天时，可按聊天目标与会话类型获取会话对象。即使该会话尚未产生任何聊天消息，SDK 也会自动初始化并返回对应的会话资料，避免在业务层自行伪造数据结构：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `sourceID` | `String` | 是 | 聊天目标 ID。单聊传入对方 `userID`，群聊传入目标 `groupID`。 |
| `sessionType` | `int` | 是 | 会话类型。单聊传入 `ConversationType.single`，群聊传入 `ConversationType.superGroup`。 |

```dart
final conversation =
    await OpenIM.iMManager.conversationManager.getOneConversation(
  sourceID: targetUserID,
  sessionType: ConversationType.single,
);

openChatPage(conversation: conversation);
```

## 返回结果

Future 成功返回对应的 `ConversationInfo` 会话对象。

该查询建立静态快照，不会触发事件通知。后续会话属性变化由[获取会话列表](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list)统一监听合并。
