推荐指定用户，构建待发送的名片消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `userID` | `String` | 是 | 名片推荐的目标用户 ID。 |
| `nickname` | `String` | 是 | 目标用户的昵称。 |
| `faceURL` | `String?` | 否 | 目标用户的头像 URL 地址。 |

```dart
final message = await OpenIM.iMManager.messageManager.createCardMessage(
  userID: userID,
  nickname: nickname,
  faceURL: faceURL,
);
```

名片中的昵称与头像会作为历史快照写入消息内容中，不会随该用户后续资料的更新而自动变动。

## 返回结果

Future 成功返回待发送的名片消息对象（`Message`），其内容保存在 `cardElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送，也不会触发新消息事件通知。构建完成后，需将返回的 `Message` 实例传给[发送消息](/sdk/flutter/message/sending-messages/send-message)投递至单聊或群聊会话。
