`isPinned` changes only the sort state in the current user's conversation list. It does not affect other group members or the other user in a one-to-one chat.

```ts
await openimsdk.setConversation({
  conversationID,
  isPinned: true,
});
```

Pass `true` to pin the conversation and `false` to unpin it. A successful Promise means that the setting request has completed. Merge the latest conversation from `OnConversationChanged` by `conversationID`; see [Get the conversation list](/sdk/wasm/conversation/retrieving-conversations/retrieve-conversation-list) for the complete listener.
