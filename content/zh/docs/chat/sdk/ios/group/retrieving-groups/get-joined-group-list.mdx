一次性查询当前登录用户加入的全部群组列表快照：

```objc
[[OIMManager manager] getJoinedGroupListWithOnSuccess:^(NSArray<OIMGroupInfo *> *groups) {
    [self replaceGroups:groups];
} onFailure:^(NSInteger code, NSString *message) {
    [self showErrorCode:code message:message];
}];
```

该方法不接收业务参数。若当前账号加入的群组数量较多，推荐优先使用[分页获取已加入群组](/sdk/ios/group/retrieving-groups/get-joined-group-list-page)。

## 返回结果

成功回调 `onSuccess` 返回当前用户已加入的全部群组列表 `NSArray<OIMGroupInfo *> *`。查询操作不触发群组事件；群组增减事件的监听见[群组概览](/sdk/ios/group/overview-group)。
