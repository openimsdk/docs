批量查询指定用户在当前登录用户好友列表中的详细关系资料：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `userIDList` | `List<String>` | 是 | 待查询好友资料的目标用户 ID 列表。 |
| `filterBlack` | `bool` | 否 | 是否过滤已加入黑名单的用户。传入 `true` 表示过滤黑名单用户；传入 `false` 表示包含黑名单用户。 |

```dart
final friends = await OpenIM.iMManager.friendshipManager.getFriendsInfo(
  userIDList: ['user_a', 'user_b'],
  filterBlack: true,
);
```

## 返回结果

Future 成功返回匹配的好友信息列表（`List<FriendInfo>`）。

每个 `FriendInfo` 包含好友的完整资料字段，如 `userID`、`nickname`、`faceURL`、好友备注名 `remark` 以及扩展字段 `ex` 等。客户端应核验可空的 `userID`，并以 `userID` 为合并标识更新本地联系人缓存。若返回列表中未包含某个目标 ID，通常表示该用户并非好友或已被黑名单过滤规则排除。

该查询为只读操作，不会触发好友 listener。若仅需判断双方的好友关系状态而无需完整资料卡，请参考[检查好友关系](/sdk/flutter/user/friends/check-friend)；若需查询非好友用户的公开基础资料，请参考[获取指定用户资料](/sdk/flutter/user/retrieving-users/retrieve-users)。
