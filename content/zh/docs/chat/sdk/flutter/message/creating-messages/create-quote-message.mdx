```dart
final message = await OpenIM.iMManager.messageManager.createQuoteMessage(
  text: '同意这个方案',
  quoteMsg: originalMessage,
);
```

原消息应来自列表、历史查询或事件，不要手工拼接。Future 不修改原消息。
