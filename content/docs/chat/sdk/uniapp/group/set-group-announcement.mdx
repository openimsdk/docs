```uts
import { setGroupInfo } from '@/uni_modules/unix-openim-sdk'

await setGroupInfo({ groupID, notification: 'Release on Friday at 17:00' })
```

Send only `notification`, then confirm its update time and author from group information. Announcements are visible to members and must not contain secrets.
