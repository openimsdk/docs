---
title: '置顶或取消置顶会话'
description: '使用 pinConversation() 设置指定会话的置顶状态。'
sourcePath: '/sdk/android/conversation/managing-conversations/pin-conversation'
---

```java
OpenIMClient.getInstance().conversationManager.pinConversation(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    conversationID,
    true
);
```

最后一个参数为 `true` 时置顶，传 `false` 时取消置顶。

会话列表发生变化时，可通过 `onConversationChanged` 接收更新，监听器设置方式见[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
