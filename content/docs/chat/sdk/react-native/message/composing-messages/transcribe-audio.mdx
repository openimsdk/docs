Transcribe a local audio recording into text:

Pass the absolute local filesystem path accessible to the SDK. Do not pass remote HTTP URLs, Base64 strings, or uploaded storage keys.

```ts
const { text } = await OpenIMSDK.speechToText(filename);
```

## Parameters

Supply `filename` as the full local filesystem path of the audio file.

## Return value

A resolved Promise returns an object containing `{ text }`, representing the transcribed text string. Before transcribing, consider verifying format and duration constraints with [Check speech-to-text capabilities](/sdk/react-native/message/composing-messages/check-speech-to-text). To store the transcribed result onto a local voice message, see [Save local transcript](/sdk/react-native/message/composing-messages/save-local-transcript).
