Construct a voice or audio message object from an absolute filesystem path recorded on the local device. When sending via [Send a message](/sdk/android/message/sending-messages/send-message), the SDK automatically uploads the file and tracks progress.

## Code example

```java
String absolutePath = "/storage/emulated/0/Recordings/voice_sample.m4a";
long durationSeconds = 8L; // Duration: 8 seconds

Message message = OpenIMClient.getInstance().messageManager.createSoundMessageFromFullPath(
    absolutePath,
    durationSeconds
);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `soundPath` | `String` | Yes | Absolute filesystem path of the audio file on the local device. Ensure read permissions are granted. |
| `duration` | `long` | Yes | Audio playback duration in seconds. |

## Return value

Returns the created `Message` object with `contentType` set to `MessageType.VOICE`.

## State changes after the call

1. **Local initialization**: Initializes the local `Message` structure without starting network uploads.
2. **Transmission**: Call [Send a message](/sdk/android/message/sending-messages/send-message) to upload and deliver the audio message.
