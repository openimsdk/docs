Retrieve a snapshot of all groups joined by the current login account:

```ts
const groups = await OpenIMSDK.getJoinedGroupList();
```

## Return value

A resolved Promise returns `GroupItem[]` representing all groups joined by the account. Maintain and merge group state in your local cache using `groupID` as the unique key. If an account belongs to a large number of groups, prefer [Get joined group list by page](/sdk/react-native/group/retrieving-groups/get-joined-group-list-page) to fetch and reconcile data incrementally. For field definitions, see [Group overview](/sdk/react-native/group/overview-group).
