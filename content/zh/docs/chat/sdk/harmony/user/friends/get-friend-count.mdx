---
title: '获取好友数量'
description: '查询当前账号好友关系的总数量。'
sourcePath: '/sdk/harmony/user/friends/get-friend-count'
---

获取好友总数量时不接收业务参数，适合在界面中展示联系人统计或辅助判断是否需要继续分页。

```ts
import sdk, { GetFriendListCountResp } from '@openimsdk/imsdk';

const response: GetFriendListCountResp = await sdk.getFriendListCount();
showFriendCount(response.count);
```

`count` 是查询时的好友数量。查询不会触发好友事件；好友增删后可参考[分页获取好友列表](/sdk/harmony/user/friends/get-friend-list-page)监听事件更新本地值，无法确认时重新查询。
