获取当前登录用户的完整个人资料：

## 参数说明

该方法无需传入任何参数。

```dart
final user = await OpenIM.iMManager.userManager.getSelfUserInfo();
```

## 返回结果

Future 成功返回当前登录用户的个人资料对象（`UserInfo`）。

`UserInfo` 包含当前账号的基础信息：
- `userID`：当前用户唯一 ID。
- `nickname`：用户昵称。
- `faceURL`：用户头像地址。
- `gender`：性别枚举值。
- `ex`：业务扩展字段。
- `globalRecvMsgOpt`：全局离线消息接收选项。

该查询为本地只读操作，不会触发用户资料变更相关的事件监听。获取到的数据可用于初始化应用个人中心、设置页或本地当前用户状态缓存。当退出登录或切换账号时，应及时清空旧账号的内存资料。

修改个人资料请参考[更新当前用户资料](/sdk/flutter/user/retrieving-and-updating-user-information/update-self-profile)。全局资料变更事件监听与注册请参考[事件概览](/sdk/flutter/events/overview-events)。
