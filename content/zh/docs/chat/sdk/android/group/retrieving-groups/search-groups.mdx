按关键字在本地搜索群组。支持按群组全局 ID 和群名称进行匹配，可配置是否启用对应维度的检索开关。

```java
List<String> keywordList = Collections.singletonList("开发");
boolean isSearchGroupID = true;
boolean isSearchGroupName = true;

OpenIMClient.getInstance().groupManager.searchGroups(
    new OnBase<List<GroupInfo>>() {
        @Override
        public void onSuccess(List<GroupInfo> groups) {
            // groups 为匹配到的群组列表
        }

        @Override
        public void onError(int code, String error) {
            // 处理搜索失败
        }
    },
    keywordList,
    isSearchGroupID,
    isSearchGroupName
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<List<GroupInfo>>` | 是 | 异步请求回调。 |
| `keywordList` | `List<String>` | 是 | 搜索关键字列表。两项搜索开关均关闭或关键字为空时不应发起请求。 |
| `isSearchGroupID` | `boolean` | 是 | 是否匹配群组 ID：`true` 为包含，`false` 为不包含。 |
| `isSearchGroupName` | `boolean` | 是 | 是否匹配群名称：`true` 为包含，`false` 为不包含。 |

## 返回结果

成功回调返回匹配到的群组资料列表 `List<GroupInfo>`。

搜索结果仅代表查询发起时的匹配快照。搜索结果中的群组不代表当前用户一定已加入该群；如需判断成员关系，可调用[检查是否已加入群组](/sdk/android/group/retrieving-groups/is-join-group)。
