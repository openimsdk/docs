Before an invitation is answered, the initiator can cancel the pending call invitation:

## Code example

```java
OpenIMClient.getInstance().signalingManager.signalingCancel(
    new OnBase<String>() {
        @Override
        public void onSuccess(String result) {
            // Cancel request completed.
        }

        @Override
        public void onError(int code, String error) {
            // code and error describe the failure.
        }
    },
    activeInfo
);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | Yes | Callback delivering the asynchronous operation result. |
| `signalingInfo` | `SignalingInfo` | Yes | Complete signaling payload stored when the call was initiated, preserving the original `roomID`, inviter, and invitees. |

## Return value

The successful callback indicates that the server accepted the cancellation request. Dismiss the outgoing calling screen and release local media resources on the caller device.

## State changes after the call

Invitees and other associated devices receive notification events indicating that the invitation was cancelled. Update the active call state using `roomID`. For complete listener registration details, see [Handle call events](/sdk/android/calling/managing-calls/handle-call-events).
