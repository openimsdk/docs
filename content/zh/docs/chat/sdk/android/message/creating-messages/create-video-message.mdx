## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `videoPath` | `String` | 是 | 相对于 SDK 初始化数据目录的视频路径。 |
| `mimeType` | `String` | 是 | 视频类型，例如 `mp4`。 |
| `durationSeconds` | `long` | 是 | 视频时长，单位为秒。 |
| `snapshotPath` | `String` | 是 | 相对于 SDK 初始化数据目录的封面图路径。 |

```java
Message message = OpenIMClient.getInstance().messageManager.createVideoMessage(
    videoPath,
    mimeType,
    durationSeconds,
    snapshotPath
);
```

视频和封面图文件都必须可读。返回的 `Message` 只是在本地创建的待发送对象；使用[发送消息](/sdk/android/message/sending-messages/send-message)时，SDK 才会上传媒体并投递消息。
