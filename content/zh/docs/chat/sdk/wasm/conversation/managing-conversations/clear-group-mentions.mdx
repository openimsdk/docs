---
title: '重置群聊 @ 状态'
description: '在用户处理群聊中的 @ 消息后重置会话的群聊 @ 状态。'
sourcePath: '/sdk/wasm/conversation/managing-conversations/clear-group-mentions'
---

用户处理群聊中的 @ 消息后，把该会话的 `groupAtType` 重置为普通状态：

```ts
import { GroupMentionType } from '@openim/wasm-client-sdk';

await openimsdk.setConversation({
  conversationID,
  groupAtType: GroupMentionType.Normal,
});
```

`groupAtType` 是 SDK 根据群消息生成的提醒状态。本操作只负责将其重置为普通状态，不应用于伪造 `MentionedMe`、`MentionedAll` 等未发生的状态。重置群聊 @ 状态与标记消息已读是两个不同操作。

Promise 成功后，仍通过 `OnConversationChanged` 更新对应会话；完整监听示例见[获取会话列表](/sdk/wasm/conversation/retrieving-conversations/retrieve-conversation-list)。
