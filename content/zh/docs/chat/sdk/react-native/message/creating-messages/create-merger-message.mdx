创建包含多条历史记录的合并转发消息。

```ts
const message = await OpenIMSDK.createMergerMessage({
  messageList: selectedMessages,
  title: '项目讨论记录',
  summaryList: ['小王：发布计划已确认', '小李：我会跟进测试'],
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `messageList` | `MessageItem[]` | 是 | 要打包合并的消息列表。 |
| `title` | `string` | 是 | 合并消息在列表和卡片中展示的标题。 |
| `summaryList` | `string[]` | 是 | 合并卡片上展示的摘要文本列表。 |

## 返回结果

调用完成后返回已创建的 `MessageItem` 消息对象，其中 `mergeElem` 保存合并消息的完整列表、标题与摘要。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送消息](/sdk/react-native/message/sending-messages/send-message)将消息投递到单聊或群聊会话中。摘要内容应符合当前会话的展示与隐私规则。
