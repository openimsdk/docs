Use `createGroup()` to create a group. Set the group profile in `GroupInfo`, and pass the initial regular members, administrators, and owner as separate parameters. The success callback returns the complete `GroupInfo` created by the server. Store the server-assigned `groupID`.

```java
GroupInfo info = new GroupInfo();
info.setGroupName("Project discussion");
info.setIntroduction("For project members only");

OpenIMClient.getInstance().groupManager.createGroup(
    memberUserIDs, adminUserIDs, info, ownerUserID,
    new OnBase<GroupInfo>() {
        @Override public void onSuccess(GroupInfo group) { openGroup(group.getGroupID()); }
        @Override public void onError(int code, String error) { showCreateError(error); }
    }
);
```

Select the owner and administrators according to your application's permission rules. Do not infer the owner from a local user list.
