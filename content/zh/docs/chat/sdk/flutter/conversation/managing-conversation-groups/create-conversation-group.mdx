创建当前登录用户的会话分组，以便将相关会话按自定义业务维度聚合管理。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupName` | `String` | 是 | 分组名称。 |
| `order` | `int?` | 否 | 分组排序顺序值，排序规则由业务层统一约定。 |
| `ex` | `String?` | 否 | 业务自定义扩展字符串。 |
| `conversationID` | `String?` | 否 | 创建分组时直接关联的第一个会话 ID。 |
| `conversationGroupType` | `ConversationGroupType?` | 否 | 分组类型，默认为 `ConversationGroupType.custom`。 |

```dart
final group = await OpenIM.iMManager.conversationGroupManager
    .createConversationGroup(
  req: CreateConversationGroupReq(
    groupName: '工作',
    order: 100,
    conversationID: conversationID,
    conversationGroupType: ConversationGroupType.custom,
  ),
);
```

## 返回结果

Future 成功返回新创建的 `ConversationGroupInfo` 对象。客户端以 `conversationGroupID` 为合并标识更新本地分组列表。

多端同步或事件到达时通过 `onConversationGroupAdded` 通知，完整事件监听请参考[会话分组概览](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups)。
