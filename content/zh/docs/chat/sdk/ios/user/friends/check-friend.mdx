---
title: '检查好友关系'
description: '使用 iOS SDK 检查指定用户的好友关系。'
sourcePath: '/sdk/ios/user/friends/check-friend'
---

```objc
[[OIMManager manager] checkFriend:@[@"user_a", @"user_b"]
                        onSuccess:^(NSArray<OIMSimpleResultInfo *> *results) {
                            [relationshipStore mergeResults:results];
                        }
                        onFailure:nil];
```

参数是待检查的用户 ID 数组。成功 callback 中每项 `OIMSimpleResultInfo` 以 `userID` 标识目标，`result == 1` 表示目标是好友且不在黑名单中。本方法未定义其他 `result` 值的业务含义。

该方法只返回调用时的好友关系，不触发好友 delegate。需要好友备注、头像或扩展字段时使用[查询指定好友资料](/sdk/ios/user/friends/get-specified-friends-info)。
