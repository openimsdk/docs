---
title: '创建回复消息'
description: '引用一条已有消息并创建带回复文本的待发送消息。'
sourcePath: '/sdk/harmony/message/creating-messages/create-quote-message'
---

```ts
import sdk, { CreateQuoteMessageReq, CreateQuoteMessageResp } from '@openimsdk/imsdk';

const request: CreateQuoteMessageReq = {
  text: '收到，我今天处理。',
  quoteMessage: originalMessage,
};
const response: CreateQuoteMessageResp = await sdk.createQuoteMessage(request);
const message = response.message;
```

`originalMessage` 应来自当前会话的查询结果或消息事件，不要自行构造不完整对象。发送前确认原消息仍属于目标会话，并为原消息已删除或无法读取提供降级展示。
