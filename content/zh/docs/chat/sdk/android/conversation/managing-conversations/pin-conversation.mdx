---
title: '置顶或取消置顶会话'
description: '使用 pinConversation() 设置 Android 指定会话的置顶状态。'
sourcePath: '/sdk/android/conversation/managing-conversations/pin-conversation'
---

```java
OpenIMClient.getInstance().conversationManager.pinConversation(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markPinRequestSubmitted(conversationID, true);
        }

        @Override
        public void onError(int code, String error) {
            recordConversationPinFailure(code, error);
        }
    },
    conversationID,
    true
);
```

最后一个参数为 `true` 时置顶，传 `false` 时取消置顶。该状态只影响当前账号的会话列表。

成功 callback 不等于 `onConversationChanged` 已经到达。后续按 `conversationID` 合并最新会话，完整 listener 见[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
