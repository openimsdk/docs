---
title: '创建合并消息'
description: '使用 createMergerMessage 将多条消息合并为一条摘要消息。'
sourcePath: '/sdk/android/message/creating-messages/create-merger-message'
---

传入消息列表、标题和摘要列表；摘要顺序应与展示协议保持一致。

```java
Message message = OpenIMClient.getInstance().messageManager.createMergerMessage(
    messages, title, summaries);
```
