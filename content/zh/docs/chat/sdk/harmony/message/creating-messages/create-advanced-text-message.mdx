---

高级文本通过 `MessageEntity` 标记正文中的范围，适合链接、话题或业务实体。实体的偏移量和长度必须与 `text` 使用同一种字符计数规则。

```ts
import sdk, {
  CreateAdvancedTextMessageReq,
  CreateAdvancedTextMessageResp,
  MessageEntity,
} from '@openimsdk/imsdk';

const entity: MessageEntity = {
  type: 'url',
  offset: 3,
  length: 4,
  url: 'https://example.com/releases',
  ex: '',
};
const request: CreateAdvancedTextMessageReq = {
  text: '查看发布说明',
  messageEntities: [entity],
};
const response: CreateAdvancedTextMessageResp = await sdk.createAdvancedTextMessage(request);
const message = response.message;
```

接收端应检查每个范围没有越界，并对 URL 和扩展数据做安全校验。Promise 成功只创建消息对象，不会发送或打开链接。
