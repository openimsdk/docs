使用 `deleteMessageFromLocalStorage()` 删除当前设备中指定会话的一条消息。

```ts
await OpenIMSDK.deleteMessageFromLocalStorage({
  conversationID,
  clientMsgID,
});
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 消息所属的会话 ID。 |
| `clientMsgID` | `string` | 是 | 要删除的消息 ID。 |

调用完成后，当前设备上的目标消息已删除。
