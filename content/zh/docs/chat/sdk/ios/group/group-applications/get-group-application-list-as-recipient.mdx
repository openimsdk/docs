群主或管理员分页查询收到的加群申请记录：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupIDs` | `NSArray<NSString *> *` | 待查询的目标群组 ID 列表。 |
| `handleResults` | `NSArray<NSNumber *> *` | 处理状态过滤列表，包装 `OIMApplicationStatus` 枚举。 |
| `offset` | `NSInteger` | 分页拉取的偏移量（从 0 开始）。 |
| `count` | `NSInteger` | 每页返回的最大条数。 |

### 处理状态枚举

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `OIMApplicationStatusNormal` | `0` | 待审核（未处理）。 |
| `OIMApplicationStatusAgree` | `1` | 已同意。 |
| `OIMApplicationStatusReject` | `-1` | 已拒绝。 |

```objc
GetGroupApplicationListAsRecipientReq *req =
    [[GetGroupApplicationListAsRecipientReq alloc] initWithGroupIDs:@[@"group_1001"]
                                                      handleResults:@[@(OIMApplicationStatusNormal)]
                                                             offset:0
                                                              count:20];

[[OIMManager manager] getGroupApplicationListAsRecipientWithReq:req
                                                      onSuccess:^(NSArray<OIMGroupApplicationInfo *> *items) {
                                                          [self replaceItems:items];
                                                      }
                                                      onFailure:^(NSInteger code, NSString *message) {
                                                          NSLog(@"getGroupApplicationListAsRecipient failed: %ld %@", (long)code, message);
                                                      }];
```

状态以 `groupID:userID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回包含入群申请对象的数组 `NSArray<OIMGroupApplicationInfo *> *`。

只有作为目标群组的群主或管理员时，才能成功拉取对应的入群申请。继续加载后续页面时按已请求条数递增 `offset`。

该查询仅返回调用时刻的数据快照，不触发申请 delegate 回调。申请状态的后续增量变动处理请参见[入群申请概览](/sdk/ios/group/group-applications/overview-group-applications)。
