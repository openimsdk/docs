按分组类型获取当前登录账号的会话分组列表。

```ts
const groups = await OpenIMSDK.getConversationGroups(
  ConversationGroupType.ConversationGroupTypeNormal,
);
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `groupType` | `ConversationGroupType` | 是 | 要查询的会话分组类型。 |

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `ConversationGroupTypeNormal` | `0` | 普通自定义分组。 |
| `ConversationGroupTypeAll` | `1` | 全部会话分组类型。 |

## 返回结果

调用完成后返回匹配的 `ConversationGroup[]`。字段说明见[会话分组概览](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups)。

每个分组对象包含 `conversationGroupID`、`name`、`order` 和归属该分组的 `conversationIDs`。如果需要同时拉取分组下的会话详细资料，可使用[查询分组内会话](/sdk/react-native/conversation/managing-conversation-groups/get-conversation-group-info-with-conversations)。
