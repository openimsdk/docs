调用获取 @所有人 标签接口可获取 SDK 内部预置的用于标识“全体成员”的特殊常量字符串。

```objc
NSString *tag = [OIMMessageInfo getAtAllTag];
```

## 返回结果

- 返回 SDK 约定的 @全体成员 占位标记字符串（`NSString *`）。该字符串不是真实的用户 ID，仅用于在解析或构建群消息时区分是否提及了全体成员。相关消息创建见[创建 @所有人 消息](/sdk/ios/message/creating-messages/create-text-at-all-message)。
