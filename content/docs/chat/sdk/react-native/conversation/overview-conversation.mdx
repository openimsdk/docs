In the OpenIM React Native SDK, a conversation represents the state of a chat session maintained by the currently authenticated account. Both direct one-to-one chats and group chats map to a `ConversationItem`, which encapsulates list display metadata, unread counters, drafts, and message reception preferences.

Conversations and chat targets use distinct identifiers: `conversationID` identifies the conversation record for the current account and acts as the unique primary key for client-side state merging; direct chat targets use the peer's `userID`, and group chat targets use the `groupID`. Group profiles, members, and permissions remain managed through group-specific APIs.

## Conversation identifiers

| Identifier | Description |
| --- | --- |
| `conversationID` | Unique primary key for the conversation record of the current account; used for settings, message history, and unread reconciliation. |
| `userID` | Target user ID in direct 1-on-1 chats. |
| `groupID` | Target group ID in group chats. |
| `sourceID` | Target identifier when querying by type: supply `userID` for direct chats, or `groupID` for group chats. |

To compute the `conversationID` from a chat target without a network round-trip, invoke [Get conversation ID](/sdk/react-native/conversation/retrieving-conversations/get-conversation-id) with `sourceID` and `sessionType`.

## Conversation properties

A `ConversationItem` contains display fields alongside account-level conversation settings:

| Category | Fields | Description |
| --- | --- | --- |
| Identity & type | `conversationID`, `conversationType` | Locates the conversation and distinguishes between direct and group chats. |
| List display | `showName`, `faceURL`, `latestMsg`, `latestMsgSendTime` | Displays conversation title, avatar, and preview of the latest message. |
| Unread & mentions | `unreadCount`, `groupAtType` | Reflects unread badge counts and `@` mention notifications. |
| Organization | `isPinned`, `draftText`, `isMarked` <span className="enterprise-field-badge">Commercial</span>, `remark` <span className="enterprise-field-badge">Commercial</span> | Controls pin-to-top, marking, message drafts, and custom remarks for the current user. |
| Message policy | `recvMsgOpt`, `isPrivateChat` <span className="enterprise-field-badge">Commercial</span>, `burnDuration` <span className="enterprise-field-badge">Commercial</span>, `isMsgDestruct` <span className="enterprise-field-badge">Commercial</span>, `msgDestructTime` <span className="enterprise-field-badge">Commercial</span> | Configures notification options, burn-after-reading, and automated message retention policies. |
| State & extensions | `isNotInGroup`, `attachedInfo`, `ex` | Indicates group membership status, SDK internal metadata, and custom business extensions. |

## Hiding, deleting, and clearing

Hiding, deleting, and clearing have distinct scopes:

| Action | Effect |
| --- | --- |
| [Hide a conversation](/sdk/react-native/conversation/managing-conversations/hide-a-conversation) | Hides a single conversation from the current account's list; it reappears when a new message arrives. |
| [Hide all conversations](/sdk/react-native/conversation/managing-conversations/hide-all-conversations) | Hides all conversation entries from the local list for the current account. |
| [Delete conversation with messages](/sdk/react-native/conversation/managing-conversations/delete-conversation-with-messages) | Removes the conversation entry and permanently deletes local and server messages for this account. |
| [Clear conversation messages](/sdk/react-native/conversation/managing-conversations/clear-conversation-messages) | Preserves the conversation entry while wiping all message records for this account. |
