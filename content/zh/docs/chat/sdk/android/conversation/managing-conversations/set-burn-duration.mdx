设置指定会话在阅后即焚模式下的消息阅读倒计时时长（单位为秒）。开启阅后即焚后，消息在被对方阅读后将触发倒计时并自动销毁。

```java
OpenIMClient.getInstance().conversationManager.setConversationBurnDuration(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    conversationID,
    30
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `conversationID` | `String` | 是 | 目标会话的唯一标识。 |
| `burnDuration` | `int` | 是 | 阅后即焚倒计时时长，单位为秒，例如 `30`。注意不要与服务端消息定期删除周期混淆。 |

## 返回结果

成功回调表示服务端已成功保存阅后即焚时长配置。若要真正启用或停用阅后即焚模式，需配合调用[开启或关闭阅后即焚](/sdk/android/conversation/managing-conversations/set-private-chat)。

配置生效后，SDK 会触发 `OnConversationListener.onConversationChanged` 事件；客户端收到通知后应根据 `conversationID` 更新对应会话的 `burnDuration` 属性，完整监听配置请参考[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
