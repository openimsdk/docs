---
title: '创建转发消息'
description: '使用 iOS SDK 创建单条转发消息。'
sourcePath: '/sdk/ios/message/creating-messages/create-forward-message'
---

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createForwardMessage:sourceMessage];
```

原消息必须是已经发送成功的完整 `OIMMessageInfo`。返回对象具有新的 `clientMsgID`，不会修改原消息；后续再发送到目标单聊或群聊。
