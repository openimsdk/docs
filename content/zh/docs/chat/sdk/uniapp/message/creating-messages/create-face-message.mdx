`createFaceMessage()` 接收 `index` 与 `data`。

```uts
import { createFaceMessage } from '@/uni_modules/unix-openim-sdk'

const message = await createFaceMessage({ index: 1, data: 'smile' })
```

发送与接收端必须共享表情包版本和索引约定。未知索引应显示降级占位，不让解析错误阻断消息列表。
