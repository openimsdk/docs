调用 `getJoinedGroupList()` 获取当前账号已加入的全部群组。

```ts
const groups = await OpenIMSDK.getJoinedGroupList();
```

## 返回结果

调用完成后返回 `GroupItem[]`。群组数量较多时，可使用[分页获取已加入群组](/sdk/react-native/group/retrieving-groups/get-joined-group-list-page)分批读取。
