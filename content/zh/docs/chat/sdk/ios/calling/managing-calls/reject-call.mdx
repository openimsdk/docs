title: '拒绝通话'
description: '使用 iOS SDK 拒绝通话邀请。'
sourcePath: '/sdk/ios/calling/managing-calls/reject-call'
---

用户拒绝来电时，将收到的原始 `OIMSignalingInfo` 传给拒绝接口：

```objc
[[OIMManager manager] signalingReject:signalingInfo
                            onSuccess:^{ [self closeIncomingCall]; }
                            onFailure:^(NSInteger code, NSString * _Nullable message) {
    [self showCallError:code message:message ?: @"拒绝邀请失败"];
}];
```

成功 callback 只表示 OpenIMServer 已完成拒绝请求。发起端随后通过 `onInviteeRejected:` 更新，完整处理见[通话事件](/sdk/ios/calling/managing-calls/handle-call-events)。
