查询当前语音识别服务支持的音频格式、采样率、录音时长和文件大小等参数限制。实际执行语音转文字请参考[识别音频文字](/sdk/react-native/message/composing-messages/transcribe-audio)。

```ts
const capabilities = await OpenIMSDK.speechToTextCapabilities();
```

## 返回结果

调用后返回 `SpeechToTextCapabilities` 对象：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `format` | `string[]` | 支持的音频格式列表。 |
| `sampleRateHz` | `number` | 要求的音频采样率，单位为赫兹。 |
| `maxRecordTimeMs` | `number` | 支持的最大录音时长，单位为毫秒。 |
| `maxFileSize` | `number` | 支持的最大音频文件大小，单位为字节。 |
| `provider` | `string` | 当前语音识别服务提供方标识。 |
