---

指定关键词列表、用户 ID 与群昵称两个搜索开关，以及分页条件。

```java
OpenIMClient.getInstance().groupManager.searchGroupMembers(
    new OnBase<List<GroupMembersInfo>>() {
        @Override public void onSuccess(List<GroupMembersInfo> members) { showMemberSearch(members); }
        @Override public void onError(int code, String error) { showSearchError(error); }
    }, groupID, Collections.singletonList(keyword), true, true, 0, 20);
```

搜索仅限目标群组；空关键词或两个搜索开关均关闭时不应发起请求。
