```dart
final user = await OpenIM.iMManager.userManager.getSelfUserInfo();
setCurrentUser(user);
```

Future 返回当前账号 `UserInfo`，可初始化头像、昵称和设置页。查询不触发资料 callback；退出或切换账号时清理旧快照。
