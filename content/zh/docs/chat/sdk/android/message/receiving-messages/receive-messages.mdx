设置 `setAdvancedMsgListener()` 后，`onRecvNewMessage` 接收实时消息，`onRecvOfflineNewMessage` 接收离线批次，`onRecvOnlineOnlyMessage` 仅接收在线消息。

```java
messageManager.setAdvancedMsgListener(new OnAdvanceMsgListener() {
    @Override public void onRecvNewMessage(Message message) { messageStore.merge(message); }
    @Override public void onRecvOfflineNewMessage(List<Message> messages) { messageStore.mergeAll(messages); }
});
```
