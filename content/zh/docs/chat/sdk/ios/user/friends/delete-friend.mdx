---
title: '删除好友'
description: '删除 iOS 好友关系。'
sourcePath: '/sdk/ios/user/friends/delete-friend'
---

```objc
[[OIMManager manager] deleteFriend:@"user_b"
                         onSuccess:nil
                         onFailure:nil];
```

成功 callback 表示请求完成。`onFriendDeleted:` 随后按 `userID` 移除记录，完整 delegate 见[分页获取好友列表](/sdk/ios/user/friends/get-friend-list-page)。
