---
title: '清理本地与服务端消息'
description: '使用 WASM SDK 清理当前账号本地与服务端的全部消息。'
sourcePath: '/sdk/wasm/message/managing-messages/clear-all-messages'
---

该操作清理当前登录账号在本地和服务端保存的全部消息，影响所有会话，不适合作为单条消息或单个会话的清理入口。方法没有业务参数。

```ts
await openimsdk.deleteAllMsgFromLocalAndSvr();
resetAllMessages();
```

这是不可撤销的账号级操作，执行前必须二次确认。Promise 成功表示服务端已完成本次请求，并且当前账号在本地及服务端保存的消息已清理；随后还要清空当前账号在内存中的消息列表、搜索结果和分页状态。

该操作不会删除其他会话成员已经保存的消息副本，也不代表当前账号的其他设备已经完成界面刷新。后续根据会话事件更新会话摘要；状态仍不确定时，重新查询会话和消息并以最新结果为准。
