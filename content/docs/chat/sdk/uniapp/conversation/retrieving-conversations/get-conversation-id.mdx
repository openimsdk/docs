```uts
import { getConversationIDBySessionType } from '@/uni_modules/unix-openim-sdk'

const conversationID = await getConversationIDBySessionType({ sourceID, sessionType })
```

The returned ID is the canonical local key for the given direct or group target. Use exported session-type constants instead of numeric literals, and do not construct conversation IDs manually.
