清空当前登录账号在本地及云端服务端保存的全部历史消息。此操作不可逆，执行后当前账号的所有历史聊天记录将无法找回。该操作仅影响当前操作账号，不删除其他聊天对象的记录副本，也不会破坏好友或群组关系。

```java
OpenIMClient.getInstance().messageManager.deleteAllMsgFromLocalAndSvr(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 本地及云端消息清空成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理清理失败
        }
    }
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |

## 返回结果

成功回调中的 `data` 返回确认信息。

清理完成后，所有会话的消息记录将被清空，会话最后一条消息展示也会相应更新。若仅需清理本设备的本地离线缓存而不影响云端漫游记录，请使用[清理全部本地消息](/sdk/android/message/managing-messages/clear-all-local-messages)。
