Clear the entry badge count after the user actually navigates to and views the group applications screen, rather than automatically on application launch or background preloading.

## Code example

```ts
import sdk from '@openimsdk/imsdk';

await sdk.clearGroupApplicationBadgeCount();
```

## Parameters

This method does not take any parameters.

## Return value

Returns a Promise that resolves to `void` when the badge count has been cleared on the server.

## State changes after the call

Clearing the badge count does not delete, approve, or reject any application records, nor does it change the number of unhandled applications. Promise resolution confirms the clear request has completed. Client badge displays should be calibrated by subsequent badge events or by calling [Get group application badge count](/sdk/harmony/group/group-applications/get-group-application-badge-count).
