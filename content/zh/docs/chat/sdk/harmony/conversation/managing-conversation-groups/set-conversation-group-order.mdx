---
title: '调整会话分组顺序'
description: '批量设置会话分组的显示顺序。'
sourcePath: '/sdk/harmony/conversation/managing-conversation-groups/set-conversation-group-order'
---

每个排序项必须同时提供分组 ID 和新的顺序值。

```ts
import sdk, { SetConversationGroupOrderReq } from '@openimsdk/imsdk';

const request: SetConversationGroupOrderReq = {
  conversationGroupOrders: [
    { conversationGroupID: firstGroupID, order: 100 },
    { conversationGroupID: secondGroupID, order: 200 },
  ],
};
await sdk.setConversationGroupOrder(request);
```

`order` 的排序方向由产品统一约定。Promise 成功表示排序请求已被服务端接受，不返回可直接刷新界面的分组对象；可以先按提交值更新本地顺序，再通过事件或重新查询确认最终顺序。
