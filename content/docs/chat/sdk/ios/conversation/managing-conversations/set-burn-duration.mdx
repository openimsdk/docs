```objc
[[OIMManager manager] setConversationBurnDuration:conversationID
                                          duration:30
                                         onSuccess:nil
                                         onFailure:nil];
```

`duration` is measured in seconds. This setting controls burn after reading in a private chat and is distinct from periodic deletion of server-side messages. After success, merge the latest state through `onConversationChanged:`.
