---
title: '获取发出的好友申请'
description: '分页查询当前用户发出的好友申请。'
sourcePath: '/sdk/uniapp/user/friend-applications/get-friend-application-list-as-applicant'
---

调用 `getFriendApplicationListAsApplicant()` 建立当前用户发出的好友申请列表。`offset` 和 `count` 都可以省略；需要稳定分页时，建议显式传入。

```uts
import { getFriendApplicationListAsApplicant } from '@/uni_modules/unix-openim-sdk'

const result = await getFriendApplicationListAsApplicant({
  offset: 0,
  count: 20,
})
const applications = result?.applications ?? []
```

Promise 成功后返回 `OpenIMFriendApplicationListResult | null`，当前页申请位于 `applications`。每一项都是 `OpenIMFriendApplicationItem`，字段含义和状态值见[获取收到的好友申请](/sdk/uniapp/user/friend-applications/get-friend-application-list-as-recipient)。当前 UTS 合同不支持按处理结果过滤，界面需要分类时应在取得当前页后按 `handleResult` 筛选。

查询不会触发申请事件。分页期间收到状态变化时，使用 `fromUserID:toUserID` 找到对应记录；完整事件处理见[获取收到的好友申请](/sdk/uniapp/user/friend-applications/get-friend-application-list-as-recipient)。
