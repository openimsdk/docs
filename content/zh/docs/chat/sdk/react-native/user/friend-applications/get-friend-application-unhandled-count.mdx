查询指定时间点之后未处理的好友申请数量，适用于展示待办数量或红点角标。

```ts
const count = await OpenIMSDK.getFriendApplicationUnhandledCount({
  time,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `time` | `number` | 是 | 查询起始时间的 Unix 毫秒时间戳；传 `0` 表示统计全部未处理申请。 |

## 返回结果

调用完成后返回 `number`，表示指定时间点之后仍待处理的好友申请数量。该方法仅查询当前计数快照，不会修改会话未读数，也不会触发申请事件。
