Because hiding all conversations significantly impacts user navigation, request explicit user confirmation before calling this method:

## Code example

```ts
import sdk from '@openimsdk/imsdk';

await sdk.hideAllConversations();
```

## Return value

Returns a Promise that resolves to `void` when all conversation entries are hidden.

## State changes after the call

Hiding all conversations does not delete friends, groups, or remote chat history. Conversations automatically re-emerge whenever new incoming or outgoing messages occur. After the Promise resolves, clear the locally rendered conversation list, then re-query [Retrieve conversation list](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list) and [Get total unread message count](/sdk/harmony/conversation/managing-conversations/get-total-unread-count) to calibrate views.
