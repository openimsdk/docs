```objc
[[OIMManager manager] checkFriend:@[@"user_a", @"user_b"]
                        onSuccess:^(NSArray<OIMSimpleResultInfo *> *results) {
                            [relationshipStore mergeResults:results];
                        }
                        onFailure:nil];
```

Pass an array of user IDs to check. Each `OIMSimpleResultInfo` in the success callback identifies its target by `userID`. A `result` value of `1` means that the target is a friend and is not blocked. This method does not define business meanings for other `result` values.

This method only retrieves a relationship snapshot and does not trigger a friendship delegate. To retrieve friend remarks, avatars, or extension fields, use [`getSpecifiedFriendsInfo:filterBlack:onSuccess:onFailure:`](/sdk/ios/user/friends/get-specified-friends-info).
