---
title: '设置群组扩展字段'
description: '设置指定群组的业务扩展字符串。'
sourcePath: '/sdk/harmony/group/set-group-extension'
---

`ex` 是完整字符串，SDK 不会自动合并其中的 JSON 字段。多个业务模块共用时，应划分稳定命名空间，并在写入前保留其他模块的数据。

```ts
import sdk, { SetGroupInfoReq } from '@openimsdk/imsdk';

const request: SetGroupInfoReq = {
  groupID: groupID,
  ex: JSON.stringify({ projectID: 'project-42' }),
};
await sdk.setGroupInfo(request);
```

实际项目已有扩展数据时，应按业务约定解析旧值、合并本次字段，再序列化整个新值。Promise 成功后，SDK 会触发群资料变更事件；客户端收到通知后根据 `groupID` 更新群组的 `ex` 扩展字段，完整监听代码请参考[群组概览](/sdk/harmony/group/overview-group)。
