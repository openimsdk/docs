---
title: '清理本地与服务端消息'
description: '清理当前账号本地与服务端保存的全部消息。'
sourcePath: '/sdk/harmony/message/managing-messages/clear-all-messages'
---

该操作影响当前账号的所有会话，不适合作为单条消息或单个会话入口。

```ts
import sdk from '@openimsdk/imsdk';

await sdk.deleteAllMsgFromLocalAndServer();
resetAllMessageState();
```

这是不可撤销的账号级操作。Promise 成功后，应同步清空当前账号内存中的消息列表、搜索结果、分页游标和相关缓存。它不会删除其他会话成员持有的副本，也不表示当前账号的其他设备已经完成界面刷新。仅清理本地数据请参考[清理全部本地消息](/sdk/harmony/message/managing-messages/clear-all-local-messages)；单个会话清理请参考[清空会话消息](/sdk/harmony/conversation/managing-conversations/clear-conversation-messages)。
