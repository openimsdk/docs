title: '获取已加入群组'
description: '查询当前账号已加入的全部群组。'

---

群组数量较少时，可以一次读取当前账号已加入的完整列表。

```ts
import sdk, { GetJoinedGroupsResp } from '@openimsdk/imsdk';

const response: GetJoinedGroupsResp = await sdk.getJoinedGroups();
const groups = response.groups;
```

返回的 `IMGroup[]` 不是应用内的公开群目录。群组数量较多时应使用[分页获取已加入群组](/sdk/harmony/group/retrieving-groups/get-joined-group-list-page)，避免一次加载全部记录。查询不会触发事件，后续加入、退出和资料变化仍需通过群组事件更新。
