---
title: '发布或更新群公告'
description: '设置群组公告内容。'
sourcePath: '/sdk/wasm/group/set-group-announcement'
---

`notification` 是群公告，与用于介绍群组的 `introduction` 不同。

```ts
await openimsdk.setGroupInfo({
  groupID,
  notification: announcement.trim(),
});
```

传入空字符串可清空公告。公告的修改权限由 OpenIMServer 校验；客户端可以根据当前成员角色隐藏入口，但不能只依赖前端判断。

Promise 成功、`OnGroupInfoChanged` 到达和重新查询是三个不同阶段。如何用事件更新对应群资料，见[群组概览](/sdk/wasm/group/overview-group)。
