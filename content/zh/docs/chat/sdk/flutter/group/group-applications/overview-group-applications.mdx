入群申请管理涵盖用户主动发起的入群申请、管理员收到的申请审核、未处理申请计数以及接受与拒绝操作。

- [获取发出的入群申请](/sdk/flutter/group/group-applications/get-group-application-list-as-applicant)
- [获取未处理入群申请数](/sdk/flutter/group/group-applications/get-group-application-unhandled-count)
- [接受入群申请](/sdk/flutter/group/group-applications/accept-group-application)
- [拒绝入群申请](/sdk/flutter/group/group-applications/refuse-group-application)

## 状态更新

入群申请的状态变更通过应用唯一的 `OnGroupListener` 回调分发：
- `onGroupApplicationAdded`：收到新的入群申请。
- `onGroupApplicationAccepted`：入群申请已被接受。
- `onGroupApplicationRejected`：入群申请已被拒绝。
- `onGroupApplicationDeleted`：入群申请记录已移除。

客户端统一以 `groupID:userID` 为合并标识更新申请状态。在分页拉取申请列表期间若收到事件变更，建议在本轮加载完成后重新刷新首屏数据进行校准，完整群组事件监听请参考[群组概览](/sdk/flutter/group/overview-group)。
