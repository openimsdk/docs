description: '使用 WASM SDK 上报群消息已读回执。'
sourcePath: '/sdk/wasm/message/managing-read-status/send-group-read-receipts'
---

```ts
await openimsdk.sendGroupMessageReadReceipt({
  conversationID,
  clientMsgIDList: visibleUnreadMessageIDs,
});
```

传入的消息 ID 列表必须全部归属于指定的群聊会话。接口调用成功表示服务端已接收已读上报。需要注意：会话级别的本地未读角标清零由 [标记会话已读](/sdk/wasm/conversation/managing-conversations/mark-conversation-read) 负责，两者属于独立操作。

群内其他成员（尤其是消息发送者）可通过 `SdkEvent.OnRecvGroupReadReceipt` 事件获知群消息已读状态的更新。本页集中提供该事件的监听示例：收到事件后，使用 `conversationID` 和 `clientMsgID` 定位目标消息，并同步更新其已读人数 `hasReadCount` 与未读人数 `unreadCount`：

```ts
import { SdkEvent } from '@openim/wasm-client-sdk';

const handleGroupReadReceipt = ({ data }) => {
  mergeGroupReadReceipt(data);
};

openimsdk.on(SdkEvent.OnRecvGroupReadReceipt, handleGroupReadReceipt);

function removeGroupReadReceiptListener() {
  openimsdk.off(SdkEvent.OnRecvGroupReadReceipt, handleGroupReadReceipt);
}
```

在组件销毁、退出登录或切换账号时，请调用 `removeGroupReadReceiptListener()` 解绑监听。业务层若需获取具体的已读成员列表，请参考[查询群消息已读成员](/sdk/wasm/message/managing-read-status/get-group-message-readers)。
