title: '加载历史消息'
description: '使用 getAdvancedHistoryMessageList 分页加载会话历史消息。'
sourcePath: '/sdk/android/message/retrieving-messages/load-older-messages'
---

首次查询传 `startMsg` 为 `null`，后续将上一页边界消息作为起点。普通历史消息使用 `ViewType.History`，按返回的 `clientMsgID` 去重。

```java
messageManager.getAdvancedHistoryMessageList(callback, conversationID, startMessage, 20, ViewType.History);
```
