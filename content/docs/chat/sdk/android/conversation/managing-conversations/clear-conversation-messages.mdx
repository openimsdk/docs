Purge all historical messages from a conversation while preserving the conversation entry itself in the chat list. Use this operation when the user wants to wipe message history without removing the chat contact or group item.

## Code example

```java
OpenIMClient.getInstance().messageManager.clearConversationAndDeleteAllMsg(
    conversationID,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // Messages cleared successfully.
        }

        @Override
        public void onError(int code, String error) {
            // code and error describe the failure.
        }
    }
);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `String` | Yes | Target conversation identifier. |
| `base` | `OnBase<String>` | Yes | Callback delivering the asynchronous operation result. |

## Return value

The successful callback indicates that all messages for the specified conversation were deleted locally and remotely. The conversation entry remains in the chat list, but its latest message preview (`latestMsg`) is cleared.

## State changes after the call

Purging messages triggers the `OnConversationListener.onConversationChanged` event. Locate the conversation by `conversationID`, reset message history in active chat views, and clear the latest message preview in the list. For complete listener registration details, see [Get the conversation list](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list). To delete the conversation entry alongside its messages, see [Delete a conversation and its messages](/sdk/android/conversation/managing-conversations/delete-conversation-with-messages).
