---
title: '创建自定义消息'
description: '使用 iOS SDK 创建结构化业务自定义消息。'
sourcePath: '/sdk/ios/message/creating-messages/create-custom-message'
---

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createCustomMessage:json
                              extension:@"com.example.order"
                            description:@"订单卡片"];
```

三个参数分别是序列化业务数据、协议标识和降级文案。接收端应校验版本和字段；权限、支付或审批等权威状态必须由业务服务维护。该 selector 只创建待发送对象。
