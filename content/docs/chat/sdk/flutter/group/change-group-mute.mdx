Enable or disable group-wide mute for an entire group. The caller's administrative permissions are enforced by OpenIMServer:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID. |
| `mute` | `bool` | Yes | Pass `true` to mute all non-administrative members, or `false` to disable mute. |

## Code example

```dart
await OpenIM.iMManager.groupManager.changeGroupMute(
  groupID: groupID,
  mute: true,
);
```

## Return value

A successful `Future` indicates that the mute request has been processed and saved by the server.

## State changes after the call

Upon receiving the group profile change event, the client updates the group entity using `groupID` as the merge key. For listener integration, see [Groups overview](/sdk/flutter/group/overview-group). To proactively verify the latest group state, invoke [Get specified groups info](/sdk/flutter/group/retrieving-groups/get-specified-groups-info).
