---
title: '查询用户入群状态'
description: '使用 getUsersInGroup 从候选用户中筛出当前在群内的用户 ID。'
sourcePath: '/sdk/android/group/retrieving-group-members/get-users-in-group'
---

`getUsersInGroup()` 返回传入用户中已在指定群内的 ID 列表，不返回成员资料。

```java
OpenIMClient.getInstance().groupManager.getUsersInGroup(new OnBase<List<String>>() {
    @Override public void onSuccess(List<String> joinedUserIDs) { /* joinedUserIDs 是在群成员 ID。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
}, groupID, candidateUserIDs);
```

需要昵称、角色或禁言状态时，再调用[查询指定群成员资料](/sdk/android/group/retrieving-group-members/get-specified-group-members-info)。
