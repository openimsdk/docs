---
title: '创建文本消息'
description: '使用 WASM SDK 创建文本消息。'
sourcePath: '/sdk/wasm/message/creating-messages/create-text-message'
---

调用 `createTextMessage()` 可创建标准纯文本消息的待发送对象。注意：消息创建接口仅在本地生成包含 `clientMsgID` 的待发送 `MessageItem`，不会将消息直接投递到服务端，亦不会触发新消息事件。建议在调用前对输入文本进行前后空格过滤与长度校验。

```ts
const text = input.trim();
if (!text) return;

const { data: message } = await openimsdk.createTextMessage(text);
```

接口调用成功后返回待发送的 `MessageItem`。下一步可调用 [发送消息](/sdk/wasm/message/sending-messages/send-message) 将该对象投递至指定单聊或群聊。发送成功后，业务层可根据 `clientMsgID` 找到并更新本地消息列表中的发送状态。
