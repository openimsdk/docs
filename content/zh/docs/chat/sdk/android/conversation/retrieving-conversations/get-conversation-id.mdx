在本地根据聊天目标与会话类型快速计算对应的 `conversationID`，无需发起网络查询。

```java
String conversationID = OpenIMClient.getInstance().conversationManager
    .getConversationIDBySessionType(
        sourceId,
        ConversationType.SINGLE_CHAT
    );
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `sourceId` | `String` | 是 | 聊天目标标识。单聊时传入对方的 `userID`；群聊时传入群组的 `groupID`。 |
| `sessionType` | `int` | 是 | 会话类型。单聊为 `ConversationType.SINGLE_CHAT`，群聊为 `ConversationType.GROUP_CHAT` 或 `ConversationType.SUPER_GROUP_CHAT`。 |

## 返回结果

同步返回生成的 `conversationID` 字符串。该方法为纯本地计算，不发起网络请求。如果需要进一步获取会话的未读数、草稿或最新消息等详细资料，可继续调用[查询指定会话](/sdk/android/conversation/retrieving-conversations/get-conversation-by-target)。
