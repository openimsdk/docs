当前群主可以将群主身份转让给群内的其他成员，目标用户必须是当前群组的有效成员：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `userID` | `String` | 是 | 接任新群主的目标成员用户 ID。 |

```dart
await OpenIM.iMManager.groupManager.transferGroupOwner(
  groupID: groupID,
  userID: targetUserID,
);
```

## 返回结果

Future 成功表示服务端已完成群主身份转让：原群主自动降为普通成员，目标成员晋升为群主。

转让成功后，相关客户端会收到成员资料变更通知（如 `onGroupMemberInfoChanged`）。一次转让涉及原群主与新群主两条记录变更，客户端应使用复合标识 `groupID:userID` 分别合并。完整的事件监听逻辑请参考[群成员查询概览](/sdk/flutter/group/retrieving-group-members/overview-retrieving-group-members)；界面若需刷新管理团队列表，也可主动调用[获取群主和管理员](/sdk/flutter/group/retrieving-group-members/get-group-owner-and-admin)重新拉取。

群主若需离开群组，必须先转让群主身份，再调用[退出群组](/sdk/flutter/group/quit-group)；若需要彻底结束该群，请参考[解散群组](/sdk/flutter/group/dismiss-group)。
