Publish or update the announcement for a specified group. Group announcements are stored separately from group descriptions (`introduction`). Permissions are enforced by OpenIMServer:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID. |
| `notification` | `String` | Yes | New group announcement content. Pass an empty string `''` to clear the announcement. |

## Code example

```dart
await OpenIM.iMManager.groupManager.setGroupInfo(
  GroupInfo(
    groupID: groupID,
    notification: announcement.trim(),
  ),
);
```

## Return value

A successful `Future` indicates that the announcement has been updated on the server.

## State changes after the call

The server broadcasts group profile update notifications to all group members. The client updates `notification` on the local group record using `groupID` as the key. For complete listener integration, see [Groups overview](/sdk/flutter/group/overview-group). To recalibrate group state, call [Get specified groups info](/sdk/flutter/group/retrieving-groups/get-specified-groups-info).
