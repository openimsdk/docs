title: '恢复待处理的通话邀请'
description: '查询应用启动或回到前台时仍然有效的待处理邀请。'

---

查询当前账号是否仍有待处理的音视频通话邀请。在应用冷启动、从后台切回前台或收到来电通知事件后，可通过此操作获取类型明确且结构完整的邀请数据。

```uts
import {
  signalingGetInvitationInfoStartApp,
} from '@/uni_modules/unix-openim-sdk'

const result = await signalingGetInvitationInfoStartApp({
  userID: currentUserID,
})

if (result?.invitation?.roomID != null) {
  restoreIncomingCall(result.invitation!)
}
```

参数对象可以省略；提供 `userID` 时应填写当前登录用户 ID，不要查询其他用户的邀请。

Promise 成功后返回 `OpenIMSignalingGetInvitationInfoStartAppResult | null`。非空结果中的 `invitation` 为 `OpenIMSignalingInvitationInfo | null`；若未返回有效邀请，应按 `roomID` 清理旧来电界面，避免复用过期的房间凭据。

该查询只读取当前状态，不会主动接受或拒绝邀请，也不会补发通话事件。恢复界面后仍需监听取消、超时、其他设备接听和挂断，见[处理通话事件](/sdk/uniapp/calling/managing-calls/handle-call-events)。
