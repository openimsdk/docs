title: '设置全局消息接收方式'
description: '通过 setSelfInfo() 设置当前账号的全局消息接收与通知策略。'
sourcePath: '/sdk/android/user/user-profile/set-global-message-reception'
---

使用独立的 `UserInfoReq` 写入 `globalRecvMsgOpt`，避免在更新昵称或头像时意外覆盖账号级消息策略。

```java
UserInfoReq request = new UserInfoReq();
request.setGlobalRecvMsgOpt(2);

OpenIMClient.getInstance().userInfoManager.setSelfInfo(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markGlobalReceiveOptionSubmitted();
        }

        @Override
        public void onError(int code, String error) {
            recordGlobalReceiveOptionFailure(code, error);
        }
    },
    request
);
```

| 数值 | 含义                     |
| ---- | ------------------------ |
| `0`  | 正常接收消息并允许通知。 |
| `1`  | 屏蔽消息。               |
| `2`  | 接收消息但不提示。       |

如果产品只提供“全局免打扰”开关，通常在 `0` 和 `2` 之间切换；`1` 会停止接收消息，应单独展示。单个会话的接收方式由会话 API 管理，不受本设置替代。

成功 callback 表示请求完成。最终账号快照通过 `onSelfInfoUpdated` 或 `getSelfLocalUserInfo()` 校准，事件处理见[更新当前用户资料](/sdk/android/user/user-profile/set-self-info)。
