开启或关闭指定会话的阅后即焚私聊模式：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 目标会话 ID。 |
| `req` | `ConversationReq` | 是 | 会话修改请求对象，`isPrivateChat` 设为 `true` 开启阅后即焚，设为 `false` 关闭。 |

```dart
await OpenIM.iMManager.conversationManager.setConversation(
  conversationID,
  ConversationReq(isPrivateChat: true),
);
```

## 返回结果

Future 成功表示阅后即焚开关已设置。具体的销毁倒计时时长由 `burnDuration` 决定，请参考[设置阅后即焚时长](/sdk/flutter/conversation/managing-conversations/set-burn-duration)；此功能与服务端的定时消息销毁相互独立。

多端同步或事件到达时通过会话变更事件通知。客户端以 `conversationID` 为合并标识更新对应会话的 `isPrivateChat` 状态，完整事件监听请参考[获取会话列表](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list)。
