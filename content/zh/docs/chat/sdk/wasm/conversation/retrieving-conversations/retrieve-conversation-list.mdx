会话列表属于当前登录用户。每条 `ConversationItem` 都包含会话标识、未读数、最后一条消息、置顶和草稿等状态。应使用分页接口读取会话，避免一次加载完整列表。

## 分页获取会话

使用 `getConversationListSplit()` 分页获取会话。`offset` 是起始位置，`count` 是本页数量；第一页必须从 `offset: 0` 开始：

### 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `offset` | `number` | 是 | 起始偏移量，第一页传 `0`。 |
| `count` | `number` | 是 | 本次读取的会话数量。 |

```ts
const pageSize = 50;

async function loadConversationPage(offset = 0) {
  const { data } = await openimsdk.getConversationListSplit(
    { offset, count: pageSize }
  );

  mergeConversations(data);
  return data;
}
```

Promise 成功后，`data` 是当前页的 `ConversationItem[]`。

### 会话字段

`ConversationItem` 同时包含聊天目标、列表展示和当前账号的会话设置：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `conversationID` | `string` | 会话的稳定 ID，用于在列表和事件中找到同一会话。 |
| `conversationType` | `SessionType` | 会话类型，例如单聊或群聊。 |
| `userID` | `string` | 单聊对方的用户 ID；群聊中通常为空。 |
| `groupID` | `string` | 群聊对应的群组 ID；单聊中通常为空。 |
| `showName` | `string` | 当前会话记录中的展示名称。 |
| `faceURL` | `string` | 当前会话记录中的展示头像。 |
| `latestMsg` | `string` | 最后一条消息的序列化内容；为空时表示没有可展示的末条消息。 |
| `latestMsgSendTime` | `number` | 最后一条消息的发送时间，Unix 毫秒时间戳，用于列表排序。 |
| `unreadCount` | `number` | 当前账号在该会话中的未读消息数。 |
| `recvMsgOpt` | `MessageReceiveOption` | 该会话的消息接收与提醒方式。 |
| `groupAtType` | `GroupMentionType` | 群聊中的 @ 提醒状态；单聊不使用。 |
| `draftText` | `string` | 当前设备保存的会话草稿。 |
| `draftTextTime` | `number` | 草稿更新时间，Unix 毫秒时间戳。 |
| `isPinned` | `boolean` | 会话是否置顶。 |
| `isMarked` <span className="enterprise-field-badge">商业版</span> | `boolean`（可选） | 会话是否已标记，可与会话分组中的“标记”分组配合使用。 |
| `isPrivateChat` | `boolean` | 是否启用私聊阅后即焚。 |
| `burnDuration` | `number` | 私聊阅后即焚时长，单位为秒。 |
| `isMsgDestruct` | `boolean` | 是否启用定期删除服务端消息。 |
| `msgDestructTime` | `number` | 服务端消息的定期删除周期，单位为秒。 |
| `isNotInGroup` | `boolean` | 当前账号是否已经不在该群组中。 |
| `updateUnreadCountTime` | `number`（可选） | 会话未读数最后一次更新的时间，Unix 毫秒时间戳。 |
| `maxSeq` | `number`（可选） | 当前会话已同步消息的最大序列号。 |
| `minSeq` | `number`（可选） | 当前会话已同步消息的最小序列号。 |
| `remark` <span className="enterprise-field-badge">商业版</span> | `string`（可选） | 会话备注。 |
| `attachedInfo` | `string` | SDK 附加信息；只按已确认的业务约定解析。 |
| `ex` | `string`（可选） | 会话扩展字符串。 |

列表标题和头像可以直接使用 `showName`、`faceURL`。好友资料或群资料更新后，应通过对应的资料查询或事件获取最新内容。不要根据展示名称生成会话 ID。

继续加载时按已经请求的条目数量推进 `offset`；合并结果按 `conversationID` 去重，避免同一会话因查询结果和事件重复进入列表。

当本次返回数量小于 `count` 时，表示已经到达列表末尾。用户主动刷新、重新登录或重连后，应清空旧分页状态并从 `offset: 0` 重新读取当前完整的会话列表；列表加载完成后，再把后续会话事件带来的变化合并到列表中。

## 保持列表同步

`getConversationListSplit()` 成功后，将返回的 `ConversationItem[]` 加入当前分页列表；查询本身不会触发会话事件。列表打开期间监听 `SdkEvent.OnNewConversation` 和 `SdkEvent.OnConversationChanged`，两个事件的 `data` 都是 `ConversationItem[]`。收到事件时，使用 `conversationID` 添加新会话或更新已有会话：

```ts
import { SdkEvent } from '@openim/wasm-client-sdk';

const handleNewConversation = ({ data }) => {
  mergeConversations(data);
};

const handleConversationChanged = ({ data }) => {
  mergeConversations(data);
};

openimsdk.on(SdkEvent.OnNewConversation, handleNewConversation);
openimsdk.on(SdkEvent.OnConversationChanged, handleConversationChanged);

function removeConversationListListeners() {
  openimsdk.off(SdkEvent.OnNewConversation, handleNewConversation);
  openimsdk.off(SdkEvent.OnConversationChanged, handleConversationChanged);
}
```

组件卸载、退出登录或切换账号时调用 `removeConversationListListeners()`。总未读数由[维护总未读数](/sdk/wasm/conversation/managing-conversations/get-total-unread-count)负责，输入状态由[上报输入状态](/sdk/wasm/message/composing-messages/update-typing-status)负责。

不要用已加入群组列表替代会话列表。用户可能已经加入群组但尚未产生对应会话，也可能退出群组后仍保留历史会话记录。
