`getSelfUserInfo()` 查询当前登录账号的用户资料，不接收业务参数。

```uts
import { getSelfUserInfo } from '@/uni_modules/unix-openim-sdk'

const currentUser = await getSelfUserInfo()
if (currentUser != null) {
  setCurrentUser(currentUser)
}
```

## 返回结果

Promise 成功后返回 `OpenIMUserInfo | null`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `userID` | `string` | 当前登录用户的 OpenIMSDK 用户 ID。 |
| `nickname` | `string` | 账号级昵称。 |
| `faceURL` | `string` | 账号级头像地址。 |
| `ex` | `string` | 由业务约定的账号级扩展字符串。 |
| `createTime` | `number \| null` | 用户记录创建时间；存在值时为 Unix 毫秒时间戳。 |
| `attachedInfo` | `string \| null` | SDK 附加信息，只按已确认的业务约定解析。 |
| `globalRecvMsgOpt` | `number \| null` | 当前账号的全局消息接收方式，取值含义见[设置全局消息接收方式](/sdk/uniapp/user/profile/set-global-message-reception)。 |

当前 UTS 类型的查询结果不包含 `addFriendPermission`。虽然可以通过 `setSelfInfo()` 设置加好友权限，但界面不能假设本查询会返回该字段；需要展示当前策略时，应由业务层保存已确认的设置，或以服务端后续提供的可查询合同为准。

该查询只返回调用时的数据，不会触发资料事件。当前用户资料发生变化时，SDK 通过 `onSelfInfoUpdated()` 通知；完整监听和清理代码见[更新当前用户资料](/sdk/uniapp/user/profile/set-self-info)。切换账号时，应清理上一账号的资料缓存后再加载新账号。
