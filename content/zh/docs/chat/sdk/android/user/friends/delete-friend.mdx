---
title: '删除好友'
description: '使用 deleteFriend() 删除当前用户的一条好友关系。'
sourcePath: '/sdk/android/user/friends/delete-friend'
---

```java
OpenIMClient.getInstance().friendshipManager.deleteFriend(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markFriendDeletionSubmitted(friendUserID);
        }

        @Override
        public void onError(int code, String error) {
            recordFriendDeletionFailure(code, error);
        }
    },
    friendUserID
);
```

成功 callback 表示删除请求完成。`onFriendDeleted` 到达后再按 `userID` 从好友状态中移除记录，事件处理见[分页获取好友列表](/sdk/android/user/friends/get-friend-list-page)。
