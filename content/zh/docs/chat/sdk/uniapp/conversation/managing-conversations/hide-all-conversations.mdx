---
title: '隐藏全部会话'
description: '从当前客户端的会话列表隐藏全部会话。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/hide-all-conversations'
---

`hideAllConversations()` 会重置当前客户端上全部会话的列表状态、未读数、最后一条消息摘要和草稿，使这些会话不再出现在分页会话列表中。该操作作用于当前客户端的全部会话，而不是当前打开的单个会话。

```uts
import { hideAllConversations } from '@/uni_modules/unix-openim-sdk'

await hideAllConversations()
```

Promise 成功表示本地会话状态已经完成重置。该操作不会删除本地消息记录或服务端消息，也不会删除好友关系、群组或其他客户端上的会话。后续收到新消息或重新建立有效会话状态时，相应会话仍可再次出现。

操作完成后，应重新查询[会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)和[消息总未读数](/sdk/uniapp/conversation/managing-conversations/get-total-unread-count)，用最新结果替换界面状态。
