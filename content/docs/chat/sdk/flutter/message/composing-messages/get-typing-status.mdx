Query whether a specific member in a conversation is currently in a "typing" state:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `String` | Yes | Target conversation ID. |
| `userID` | `String` | Yes | Target user ID to query. |

## Code example

```dart
final platformIDs =
    await OpenIM.iMManager.conversationManager.getInputStates(
  conversationID,
  otherUserID,
);

setTyping(otherUserID, platformIDs?.isNotEmpty == true);
```

## Return value

Returns a `Future` resolving to a nullable platform ID list (`List<int>?`). A non-empty list contains the platform IDs on which the user is actively typing. Returns `null` or an empty list if the user is not currently typing.

## State changes after the call

This query returns a point-in-time snapshot and does not trigger event callbacks. In group chats, avoid polling all members frequently. You can query the counterparty when opening the chat screen or recovering from network reconnection; for continuous real-time typing indicators, see the event listener in [Update typing status](/sdk/flutter/message/composing-messages/update-typing-status).
