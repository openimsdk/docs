Mutes or unmutes a specific group member for a specified duration.

## Code example

```ts
import sdk, { ChangeGroupMemberMuteReq } from '@openimsdk/imsdk';

const request: ChangeGroupMemberMuteReq = {
  groupID: groupID,
  userID: targetUserID,
  mutedSeconds: 3600,
};
await sdk.changeGroupMemberMute(request);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group identifier. |
| `userID` | `string` | Yes | Target member user ID. |
| `mutedSeconds` | `number` | Yes | Mute duration in seconds. Pass `0` to unmute. |

## Return value

Returns a Promise that resolves to `void` when the mute status has been updated on the server.

## State changes after the call

`mutedSeconds` is expressed in seconds; passing `0` lifts the mute. Group owners can mute administrators and regular members; administrators can only mute regular members. Permissions are validated by OpenIMServer. After the call succeeds, the SDK triggers a group member info changed event; clients update the member's `muteEndTime` matching `groupID:userID`. For complete event listeners, see [Retrieve group member list](/sdk/harmony/group/retrieving-group-members/get-group-member-list).
