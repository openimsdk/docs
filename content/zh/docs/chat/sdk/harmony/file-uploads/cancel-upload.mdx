---
title: '取消文件上传'
description: '使用取消 ID 终止尚未完成的文件上传。'
sourcePath: '/sdk/harmony/file-uploads/cancel-upload'
---

取消 ID 应在开始上传前生成，并与业务上传任务一起保存；并发任务必须使用不同的值。

```ts
import sdk, { CancelUploadReq } from '@openimsdk/imsdk';

const request: CancelUploadReq = { cancelID: cancelID };
await sdk.cancelUpload(request);
```

Promise 成功表示取消请求已经完成。任务已结束、取消 ID 不存在或服务端已接收完整文件时，实际结果取决于当前上传阶段；界面应以原上传 Promise 的最终结果为准，并避免用户取消后继续写入业务数据。取消不会删除已经保存的远端资源，也不会撤销已发送消息。
