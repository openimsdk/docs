```objc
[[OIMManager manager] isJoinedGroup:groupID
    onSuccess:^(BOOL joined) { [self updateJoinedState:joined]; }
    onFailure:^(NSInteger code, NSString *message) { [self showErrorCode:code message:message]; }];
```

The `joined` value in the success callback is the current membership snapshot. The query does not trigger a delegate. For ongoing changes, see [Groups overview](/sdk/ios/group/overview-group).
