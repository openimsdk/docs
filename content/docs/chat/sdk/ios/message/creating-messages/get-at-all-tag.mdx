Invoke `getAtAllTag` on `OIMMessageInfo` to obtain the SDK's internal constant string used to identify an all-members mention:

## Code example

```objc
NSString *tag = [OIMMessageInfo getAtAllTag];
```

## Return value

Returns the constant placeholder string used by the SDK to represent all group members. This string is not a valid user ID and is used to detect whether an incoming group message targets everyone. For constructing all-member messages, refer to [Create an @all message](/sdk/ios/message/creating-messages/create-text-at-all-message).
