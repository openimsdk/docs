Search by conversation, keywords, senders, message types, time range, and pagination parameters. Pass `null` for `conversationID` to search across all local conversations.

```java
messageManager.searchLocalMessages(callback, conversationID, keywords, 1,
    senderIDs, messageTypes, 0, 0, 0, 20);
```
