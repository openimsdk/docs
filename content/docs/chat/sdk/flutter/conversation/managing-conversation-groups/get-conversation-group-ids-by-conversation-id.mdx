A single conversation can belong to multiple conversation groups simultaneously. Call this method to query all conversation groups currently associated with a given conversation:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `String` | Yes | Target conversation ID. |

## Code example

```dart
final groups = await OpenIM.iMManager.conversationGroupManager
    .getConversationGroupByConversationID(
  conversationID: conversationID,
);
```

## Return value

A successful `Future` returns the full list of groups containing this conversation (`List<ConversationGroupInfo>`). The client uses `conversationGroupID` as the merge key to map relations between conversations and their parent groups.

This query returns an immediate data snapshot and does not emit event notifications. For subsequent membership changes, see [Conversation groups overview](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups).
