```objc
[[OIMManager manager] addFriend:@"user_b"
                     reqMessage:@"Hi, I'm Alex"
                      onSuccess:nil
                      onFailure:nil];
```

The first argument is the recipient's user ID, and `reqMessage` is the optional request message. Pass an empty string when no message is needed. A successful callback means only that the server has accepted the request; it does not mean that the users are already friends.

For incremental friend-request updates, see [Retrieve received friend requests](/sdk/ios/user/friend-applications/get-friend-application-list-as-recipient).
