---
title: '接受入群申请'
description: '使用 acceptGroupApplication 同意指定用户的入群申请。'
sourcePath: '/sdk/android/group/group-applications/accept-group-application'
---

调用时同时传入申请的 `groupID`、申请人 `userID` 和处理说明。当前用户需要具有审批权限。

```java
OpenIMClient.getInstance().groupManager.acceptGroupApplication(new OnBase<String>() {
    @Override public void onSuccess(String data) { /* 请求已完成。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
}, groupID, applicantUserID, "欢迎加入");
```

同意后，通过[群组概览](/sdk/android/group/overview-group)中的相关事件接收申请状态和成员变化通知。
