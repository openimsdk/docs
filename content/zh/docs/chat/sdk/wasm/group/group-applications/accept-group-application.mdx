## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 申请对应的群组 ID。 |
| `fromUserID` | `string` | 是 | 申请人用户 ID，对应申请记录的 `userID`。 |
| `handleMsg` | `string` | 是 | 处理说明；没有说明时传空字符串。 |

```ts
await openimsdk.acceptGroupApplication({
  groupID: application.groupID,
  fromUserID: application.userID,
  handleMsg: '同意加入',
});
```

Promise 成功表示服务端完成本次同意请求。不要仅根据 Promise 成功在本地构造最终成员记录；收到 `OnGroupApplicationAccepted` 后更新对应申请，成员真正加入时再处理成员事件。
