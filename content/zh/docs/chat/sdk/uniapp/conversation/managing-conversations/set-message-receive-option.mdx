`recvMsgOpt` 只作用于指定会话，适合实现会话级免打扰。当前 UTS 合同将该字段公开为 `number`，没有导出具名常量；业务代码应集中封装取值。

| 数值 | 含义 |
| --- | --- |
| `0` | 正常接收消息，并允许通知。 |
| `1` | 不接收该会话消息。 |
| `2` | 接收消息，但不通知。 |

```uts
import { setConversation } from '@/uni_modules/unix-openim-sdk'

const receiveWithoutNotification = 2

await setConversation({
  conversationID,
  recvMsgOpt: receiveWithoutNotification,
})
```

会话级设置与账号级默认策略相互独立，账号级设置见[设置全局消息接收方式](/sdk/uniapp/user/profile/set-global-message-reception)。Promise 成功、`onConversationChanged()` 到达和重新查询是三个不同阶段；事件更新方式见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。
