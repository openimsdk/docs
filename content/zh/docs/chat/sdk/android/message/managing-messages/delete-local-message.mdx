---
title: '删除本地消息'
description: '使用 deleteMessageFromLocalStorage 仅删除当前设备的消息副本。'
sourcePath: '/sdk/android/message/managing-messages/delete-local-message'
---

`deleteMessageFromLocalStorage()` 只删除当前设备中由 `conversationID` 和 `clientMsgID` 指定的消息，不影响服务端、其他设备或其他用户的记录。

```java
OpenIMClient.getInstance().messageManager.deleteMessageFromLocalStorage(
    conversationID,
    clientMsgID,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 按 clientMsgID 从当前会话列表移除消息。
        }

        @Override
        public void onError(int code, String error) {
            // 保留消息并提示删除失败。
        }
    }
);
```

成功回调表示本地记录已经删除。此操作不会触发共享消息事件；重新同步或重新安装后，仍可能再次读取到服务端保留的消息。
