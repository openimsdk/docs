将单条已有的历史消息构造成一条待转发的消息对象。SDK 会基于原消息正文克隆并重置为待发送状态，适用于单条消息的转发分享。

```java
Message message = OpenIMClient.getInstance().messageManager.createForwardMessage(sourceMessage);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `message` | `Message` | 是 | 待转发的原始历史消息对象。 |

## 返回结果

返回克隆构建的新待发送 `Message` 对象。

本方法只在本地构造消息对象，不会自动发起网络发送。构建完成后，请调用[发送消息](/sdk/android/message/sending-messages/send-message)将该消息发送至新的目标单聊或群聊。若需将多条消息合并转发，请参阅[创建合并消息](/sdk/android/message/creating-messages/create-merger-message)。
