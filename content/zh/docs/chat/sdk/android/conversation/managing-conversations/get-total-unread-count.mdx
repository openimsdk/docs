`getTotalUnreadMsgCount()` 返回当前账号所有会话的总未读数。

```java
OpenIMClient.getInstance().conversationManager.getTotalUnreadMsgCount(
    new OnBase<String>() {
        @Override
        public void onSuccess(String value) {
            int totalUnread = Integer.parseInt(value);
            // totalUnread 是当前账号的未读消息总数。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    }
);
```

回调值是 `String`，解析后即可用于显示总未读数。

总未读数发生变化时，可以通过 `OnConversationListener.onTotalUnreadMessageCountChanged(int count)` 接收更新；监听器设置方式见[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
