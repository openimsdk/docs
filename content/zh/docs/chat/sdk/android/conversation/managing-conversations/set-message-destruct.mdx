---

`isMsgDestruct` 与 `msgDestructTime` 共同构成服务端消息定期删除设置，可以在一次 `ConversationReq` 中提交。

```java
ConversationReq request = new ConversationReq();
request.setMsgDestruct(true);
request.setMsgDestructTime(3600);

OpenIMClient.getInstance().conversationManager.setConversation(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markMessageDestructSubmitted(conversationID);
        }

        @Override
        public void onError(int code, String error) {
            recordMessageDestructFailure(code, error);
        }
    },
    conversationID,
    request
);
```

`msgDestructTime` 的单位为秒。关闭时只传 `request.setMsgDestruct(false)`；该能力用于定期删除服务端消息，不是阅后即焚。

成功 callback 表示设置请求完成。最新开关和周期通过 `onConversationChanged` 按 `conversationID` 合并，完整 listener 见[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
