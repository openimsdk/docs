使用 `createMarkdownMessage()` 创建 Markdown 消息。

```ts
const message = await OpenIMSDK.createMarkdownMessage(
  '## 发布完成\n\n- Android\n- iOS',
);
```

参数是完整的 Markdown 文本。调用后返回待发送的 `MessageItem`；接收端展示不可信 Markdown 文本时，应使用支持安全策略的 Markdown 渲染器。
