`changeGroupMute()` 控制群组整体禁言，操作权限由 OpenIMServer 校验。`muteBypassUserIDs` 用于指定全员禁言期间仍可发言的成员。

## 参数说明

| 参数                                                                       | 类型       | 是否必填 | 说明                                              |
| -------------------------------------------------------------------------- | ---------- | -------- | ------------------------------------------------- |
| `groupID`                                                                  | `string`   | 是       | 目标群组 ID。                                     |
| `mute`                                                                     | `boolean`  | 是       | `true` 开启全员禁言，`false` 关闭。               |
| `muteBypassUserIDs` | `string[]` | 是       | 禁言期间允许发言的用户 ID；不设置例外时传空数组。 |

```ts
import sdk, { ChangeGroupMuteReq } from '@openimsdk/imsdk';

const request: ChangeGroupMuteReq = {
  groupID: groupID,
  mute: true,
  muteBypassUserIDs: ['user_002'],
};
await sdk.changeGroupMute(request);
```

Promise 成功表示设置请求已经完成，不表示群资料事件已经到达。收到事件后按 `groupID` 更新资料；需要校准时重新查询指定群组。
