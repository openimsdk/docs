Retrieve detailed profiles for one or more groups by their unique group IDs.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupIDList` | `List<String>` | Yes | The list of target group IDs to query. |

## Code example

```dart
final groups = await OpenIM.iMManager.groupManager.getGroupsInfo(
  groupIDList: groupIDs,
);
```

## Return value

Returns a `Future` resolving to a `List<GroupInfo>` containing the profiles of all matched groups.

Even when querying a single group, provide its ID inside a single-element list and verify whether the returned list contains any elements to confirm the group exists.

## State changes after the call

This query retrieves a point-in-time snapshot and does not trigger event callbacks. Public group discovery and complex directory search belong to business server logic. For subsequent profile updates and state merging keyed by `groupID`, see [Group overview](/sdk/flutter/group/overview-group).
