拒绝对方发来的添加好友申请，并附带拒绝理由：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `userID` | `String` | 是 | 提出好友申请的对方用户 ID。 |
| `handleMsg` | `String` | 否 | 拒绝申请时的理由附言。 |

```dart
await OpenIM.iMManager.friendshipManager.refuseFriendApplication(
  userID: applicantUserID,
  handleMsg: '暂不添加',
);
```

## 返回结果

Future 成功表示服务端已完成拒绝好友申请的处理。

操作成功后，申请状态按申请方 `userID` 更新为已拒绝。后续相关端会收到好友申请变更通知。完整的申请状态监听与合并规则请参考[获取收到的好友申请](/sdk/flutter/user/friend-applications/get-friend-application-list-as-recipient)。
