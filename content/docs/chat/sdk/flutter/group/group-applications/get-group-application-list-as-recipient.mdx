Retrieve pending and processed incoming group join applications received by the current user as an owner or administrator:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupIDs` | `List<String>?` | No | Optional list of group IDs to filter requests by. Omitting queries requests across all managed groups. |
| `handleResults` | `List<int>?` | No | Filter by resolution status: `0` for pending, `1` for approved, `-1` for rejected. |
| `offset` | `int` | Yes | Zero-based pagination offset index. |
| `count` | `int` | Yes | Maximum number of records to retrieve per page. |

## Code example

```dart
final applications = await OpenIM.iMManager.groupManager
    .getGroupApplicationListAsRecipient(
  GetGroupApplicationListAsRecipientReq(
    groupIDs: [groupID],
    handleResults: [0],
    offset: 0,
    count: 20,
  ),
);
```

## Return value

A successful `Future` returns a list of matching group join applications (`List<GroupApplicationInfo>`).

This query returns an immediate data snapshot and does not emit event notifications. When new applications arrive or decisions sync across sessions, refer to [Group applications overview](/sdk/flutter/group/group-applications/overview-group-applications).
