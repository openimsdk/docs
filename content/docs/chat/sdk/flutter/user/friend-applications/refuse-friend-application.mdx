```dart
await OpenIM.iMManager.friendshipManager.refuseFriendApplication(
  userID: applicantUserID,
  handleMsg: 'Not right now',
);
```

`userID` identifies the applicant, and `handleMsg` is an optional response note. A successful `Future` means that the rejection request completed. Merge application changes through the shared listener described in [Retrieve received friend applications](/sdk/flutter/user/friend-applications/get-friend-application-list-as-recipient).
