---
title: '禁言或解除禁言群成员'
description: '使用 changeGroupMemberMute 设置指定成员的禁言时长。'
sourcePath: '/sdk/android/group/managing-group-members/change-group-member-mute'
---

`seconds` 为禁言时长，单位为秒；传 `0` 解除成员禁言。该操作与全员禁言相互独立。

```java
OpenIMClient.getInstance().groupManager.changeGroupMemberMute(new OnBase<String>() {
    @Override public void onSuccess(String data) { markMemberMuteSubmitted(groupID, userID); }
    @Override public void onError(int code, String error) { showMemberMuteError(error); }
}, groupID, userID, 3600L);
```

在 `onGroupMemberInfoChanged` 中读取 `muteEndTime` 更新成员状态；不要用本机时间和请求时长长期推算最终禁言状态。
