---
title: '接受好友申请'
description: '同意指定用户发来的好友申请。'
sourcePath: '/sdk/harmony/user/friend-applications/accept-friend-application'
---

```ts
import sdk, { ApprovalStatus, HandleFriendApplicationReq } from '@openimsdk/imsdk';

const request: HandleFriendApplicationReq = {
  userID: applicantUserID,
  handleMsg: '',
  status: ApprovalStatus.Approved,
};
await sdk.handleFriendApplication(request);
```

`userID` 填申请人的用户 ID。Promise 成功不表示事件已到达：客户端按 `fromUserID:toUserID` 监听申请事件更新状态，完整事件监听请参考 [获取收到的好友申请](/sdk/harmony/user/friend-applications/get-friend-application-list-as-recipient)；好友列表更新请参考 [分页获取好友列表](/sdk/harmony/user/friends/get-friend-list-page)。
