---
title: '清理全部本地消息'
description: '使用 WASM SDK 清理当前账号的全部本地消息。'
sourcePath: '/sdk/wasm/message/managing-messages/clear-all-local-messages'
---

该操作清理当前登录账号在当前设备上的全部本地消息，适合“清除本机聊天记录”等明确场景。它没有业务参数，影响范围不是当前打开的单个会话。

```ts
await openimsdk.deleteAllMsgFromLocal();
resetAllMessages();
```

这是不可撤销的账号级本地操作。Promise 成功只表示当前设备的本地数据库已清理；随后还要清空当前账号在内存中的消息列表、搜索结果和分页状态。服务端仍保留历史，重新登录、重建本地数据或再次同步后，消息可能重新出现。该操作不会通知其他设备或会话成员，也不触发独立的消息删除事件。
