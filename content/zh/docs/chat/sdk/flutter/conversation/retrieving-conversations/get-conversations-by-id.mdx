在已知一组会话 ID 的场景下，可批量获取这些会话的详细资料：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationIDList` | `List<String>` | 是 | 待查询的目标会话 ID 列表。 |

```dart
final conversations = await OpenIM.iMManager.conversationManager
    .getMultipleConversation(conversationIDList: conversationIDs);

final byID = {
  for (final item in conversations) item.conversationID: item,
};
```

## 返回结果

Future 成功返回匹配到的 `List<ConversationInfo>` 会话列表。若某些 ID 未命中本地记录，将不会出现在返回列表中，应用层不应依赖返回结果与入参索引的一一对应关系。

查询操作建立静态快照，不会触发事件通知。后续会话更新请参考[获取会话列表](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list)。
