---
title: '将用户移出黑名单'
description: '将指定用户移出当前账号的黑名单。'
sourcePath: '/sdk/harmony/user/blacklist/remove-black'
---

```ts
import sdk, { DeleteBlackReq } from '@openimsdk/imsdk';

const request: DeleteBlackReq = {
  userID: targetUserID,
};
await sdk.deleteBlack(request);
```

移出黑名单不会自动恢复好友关系。Promise 成功后等待 `EventOnBlackDeleted`，或重新查询黑名单校准。
