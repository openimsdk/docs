根据群组 ID 查询当前群聊通话的房间信息。

```ts
const room = await OpenIMSDK.signalingGetRoomByGroupID(groupID);
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 目标群组 ID。 |

## 返回结果

调用完成后返回 `CallingRoomData`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `roomID` | `string` | 通话房间 ID。 |
| `invitation` | `RtcInvite`（可选） | 房间对应的通话邀请信息。 |
| `participant` | `ParticipantInfo[]`（可选） | 当前房间的参与者资料。 |

`participant` 中的 `userInfo` 是用户资料；群聊场景还可能包含 `groupMemberInfo` 和 `groupInfo`。查询只返回当前房间的快照，不会触发信令事件；后续通话状态变化以[处理通话事件](/sdk/react-native/calling/managing-calls/handle-call-events)为准，客户端使用 `roomID` 和参与者 `userID` 关联与合并状态。
