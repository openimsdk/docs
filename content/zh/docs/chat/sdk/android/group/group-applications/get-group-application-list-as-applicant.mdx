分页获取当前登录用户主动向各个群组发出的入群申请历史。通过请求对象指定分页偏移量和条数，可在界面上呈现申请的审批状态（如待审核、已同意或已拒绝）。

```java
GetGroupApplicationListAsApplicantReq request = new GetGroupApplicationListAsApplicantReq(0, 20);

OpenIMClient.getInstance().groupManager.getSendGroupApplicationList(
    new OnBase<List<GroupApplicationInfo>>() {
        @Override
        public void onSuccess(List<GroupApplicationInfo> items) {
            // items 为当前页申请记录
        }

        @Override
        public void onError(int code, String error) {
            // 处理获取失败
        }
    },
    request
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<List<GroupApplicationInfo>>` | 是 | 异步请求回调。 |
| `request` | `GetGroupApplicationListAsApplicantReq` | 是 | 分页请求参数对象。常用字段包括 `offset`（分页偏移量，从 0 开始）与 `count`（每页拉取数量）。 |

## 返回结果

成功回调返回申请信息列表 `List<GroupApplicationInfo>`。单条申请的核心字段包含：

| 字段 | 说明 |
| --- | --- |
| `groupID` | 申请加入的目标群组 ID。 |
| `groupName` | 申请加入的目标群组名称。 |
| `reqMsg` | 申请时提交的附言说明。 |
| `handleResult` | 审批处理结果：`0` 未处理，`1` 已同意，`-1` 已拒绝。 |
| `handledMsg` | 管理员填写的审批反馈附言。 |
| `reqTime` | 发起申请的毫秒级时间戳。 |

客户端应以 `groupID` 为主要维度进行状态呈现与缓存合并。当申请被管理员审核通过后，当前用户端将触发 `onJoinedGroupAdded` 事件接收群资料并更新群列表；完整监听见[群组概览](/sdk/android/group/overview-group)。
