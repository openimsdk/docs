分页查询当前登录用户已加入的群组列表，适用于群组较多的通讯录或群组选择页面。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `offset` | `number` | 是 | 起始偏移量，第一页传 `0`。 |
| `count` | `number` | 是 | 本次读取数量。 |

```uts
import { getJoinedGroupListPage } from '@/uni_modules/unix-openim-sdk'

const result = await getJoinedGroupListPage({
  offset: 0,
  count: 50,
})
const groups = result != null ? result.groups : []
```

## 返回结果

Promise 成功后返回 `OpenIMGroupListResult | null`；非空结果的 `groups` 是当前页 `OpenIMGroupItem[]`。客户端应按各群组的 `groupID` 进行去重和状态合并。该结果不包含总数或下一页游标；当返回数量小于 `count` 时，可以视为已经到达当前列表末尾。

继续加载时，按已请求的条目数增加 `offset`，不要使用收到群组事件后可能已经变化的界面列表长度。群资料字段见[群组概览](/sdk/uniapp/group/overview-group)。

分页期间收到群组新增或删除事件时，应参考[群组概览](/sdk/uniapp/group/overview-group)重置分页并从第一页重新加载，避免偏移量错位导致数据重复或遗漏。
