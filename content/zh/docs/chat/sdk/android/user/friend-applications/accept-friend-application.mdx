---
title: '接受好友申请'
description: '使用 acceptFriendApplication() 接受好友申请。'
sourcePath: '/sdk/android/user/friend-applications/accept-friend-application'
---

```java
OpenIMClient.getInstance().friendshipManager.acceptFriendApplication(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 接受好友申请成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    applicantUserID,
    "已通过"
);
```

`applicantUserID` 是申请方用户 ID，最后一个参数是处理附言。成功 callback 表示接受好友申请请求完成。申请状态通过 `onFriendApplicationAccepted` 通知，新好友关系通过 `onFriendAdded` 通知。
