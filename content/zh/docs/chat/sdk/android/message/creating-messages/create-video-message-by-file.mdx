基于本地设备文件系统的绝对路径创建视频消息对象。需分别传入本地视频文件的绝对路径和生成的封面缩略图绝对路径。在调用[发送消息](/sdk/android/message/sending-messages/send-message)时，SDK 会自动完成文件上传。

```java
String absoluteVideoPath = "/storage/emulated/0/DCIM/Camera/VID_20261012.mp4";
String mimeType = "video/mp4";
long durationSeconds = 15L;
String absoluteSnapshotPath = "/storage/emulated/0/DCIM/Camera/VID_thumb.jpg";

Message message = OpenIMClient.getInstance().messageManager.createVideoMessageFromFullPath(
    absoluteVideoPath,
    mimeType,
    durationSeconds,
    absoluteSnapshotPath
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `videoPath` | `String` | 是 | 本地视频文件的绝对文件路径。必须保证当前应用具备读取权限。 |
| `mimeType` | `String` | 是 | 视频 MIME 类型（例如 `video/mp4`）。 |
| `duration` | `long` | 是 | 视频播放时长（单位：秒）。 |
| `snapshotPath` | `String` | 是 | 本地视频封面缩略图的绝对文件路径。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.VIDEO`。

构建完成后，调用[发送消息](/sdk/android/message/sending-messages/send-message)向目标会话投递。
