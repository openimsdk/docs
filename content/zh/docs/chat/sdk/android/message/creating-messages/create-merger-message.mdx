将多条历史消息打包为一条合并转发消息。在会话列表中以合并卡片形式展示，点击可打开多条消息的展开记录列表。

```java
List<Message> messages = Arrays.asList(msg1, msg2, msg3);
String title = "工作组的聊天记录";
List<String> summaries = Arrays.asList("张三: 我们已发布新版本", "李四: 收到，开始验证");

Message message = OpenIMClient.getInstance().messageManager.createMergerMessage(
    messages,
    title,
    summaries
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `messages` | `List<Message>` | 是 | 需要合并打包的原始消息列表，按时间先后顺序传入。 |
| `title` | `String` | 是 | 合并转发卡片的标题（如“群聊的聊天记录”）。 |
| `summaries` | `List<String>` | 是 | 卡片上展示的摘要文本列表（通常展示前几条消息的“发送者: 内容”）。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.MERGER`。

构建完成后，调用[发送消息](/sdk/android/message/sending-messages/send-message)将该合并消息投递至目标会话。
