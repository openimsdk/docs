已经持有一组 `conversationID` 时，使用 `getMultipleConversation()` 读取最新会话快照。

```java
OpenIMClient.getInstance().conversationManager.getMultipleConversation(
    new OnBase<List<ConversationInfo>>() {
        @Override
        public void onSuccess(List<ConversationInfo> conversations) {
            for (ConversationInfo item : conversations) {
                conversationStore.put(item.getConversationID(), item);
            }
        }

        @Override
        public void onError(int code, String error) {
            recordConversationQueryFailure(code, error);
        }
    },
    conversationIDs
);
```

调用前去除空值和重复 ID。成功 callback 返回 `List<ConversationInfo>`；某个 ID 没有结果时按缺失记录处理，不要依赖响应与请求列表的位置完全一一对应。

查询本身不触发会话 listener。会话列表的持续同步见[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
