`localEx` 只保存在当前设备，适合折叠、选中、本地来源标记或应用自定义的语音转写结果，不会同步给其他用户或设备。

```uts
import { setMessageLocalEx } from '@/uni_modules/unix-openim-sdk'

const clientMsgID = message.clientMsgID
if (clientMsgID == null) return

const nextLocalEx = JSON.stringify({
  selected: true,
  transcript: '识别后的文字',
})

await setMessageLocalEx({
  conversationID,
  clientMsgID,
  localEx: nextLocalEx,
})
```

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 目标消息所属的会话 ID。 |
| `clientMsgID` | `string` | 是 | 目标消息的客户端消息 ID。 |
| `localEx` | `string` | 是 | 要保存的完整扩展字符串。 |

该方法不会自动合并旧 JSON。多个功能共用 `localEx` 时，先读取并校验原值，在业务层合并各自字段后再整体写回，避免覆盖其他功能的数据。Promise 成功表示本地数据库已更新；不会触发共享消息事件。
