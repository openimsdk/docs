Set `roleLevel` with a `GroupRole` constant: `OWNER`, `ADMIN`, or `MEMBER`. Use the separate ownership-transfer API when changing the group owner; do not infer an ownership-transfer flow from this API.

```java
SetGroupMemberInfo update = new SetGroupMemberInfo();
update.setGroupID(groupID);
update.setUserID(userID);
update.setRoleLevel(GroupRole.ADMIN);

OpenIMClient.getInstance().groupManager.setGroupMemberInfo(update, new OnBase<String>() {
    @Override public void onSuccess(String data) { markRoleSubmitted(groupID, userID); }
    @Override public void onError(int code, String error) { showRoleError(error); }
});
```

The server validates the role change and its permissions. Use the member profile change event as the source of truth.
