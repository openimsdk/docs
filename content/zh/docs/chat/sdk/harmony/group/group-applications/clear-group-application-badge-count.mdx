---
title: '清除入群申请角标'
description: '将当前账号的入群申请入口角标清零。'
sourcePath: '/sdk/harmony/group/group-applications/clear-group-application-badge-count'
---

在用户确实打开并查看入群申请入口后再清除角标，不要在应用启动或仅预加载列表时自动调用。

```ts
import sdk from '@openimsdk/imsdk';

await sdk.clearGroupApplicationBadgeCount();
```

清除角标不会删除、接受或拒绝任何申请，也不会改变未处理申请数量。Promise 成功表示清除请求已经完成；界面状态还应以随后到达的角标事件或重新查询结果为准。
