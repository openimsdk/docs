title: '清理全部本地消息'
description: '使用 Flutter SDK 清理当前账号的全部本地消息。'
sourcePath: '/sdk/flutter/message/managing-messages/clear-all-local-messages'
---

```dart
await OpenIM.iMManager.messageManager.deleteAllMsgFromLocal();
clearLocalMessageState();
```

这是账号级破坏性操作。Future 成功只表示当前设备本地消息已清理；服务端仍保留历史，重建数据后可能再次同步。不要只重置当前会话。
