---
title: '更新当前用户资料'
description: '使用 setSelfInfo() 更新当前用户的昵称、头像或扩展资料。'
sourcePath: '/sdk/android/user/user-profile/set-self-info'
---

使用 `UserInfoReq` 只设置实际需要修改的字段。

```java
UserInfoReq request = new UserInfoReq();
request.setNickname(displayName.trim());
request.setFaceURL(avatarURL);
request.setEx(extra);

OpenIMClient.getInstance().userInfoManager.setSelfInfo(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 更新当前用户资料成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    request
);
```

`UserInfoReq` 支持 `nickname`、`faceURL`、`ex` 和 `addFriendPermission` 等字段。`ex` 用于保存当前用户的扩展信息。

成功 callback 表示更新请求完成。当前账号资料变化时，可通过 `onSelfInfoUpdated(UserInfo info)` 接收通知。

## 更新字段

| 字段                  | 说明               |
| --------------------- | ------------------ |
| `nickname`            | 要更新的昵称。     |
| `faceURL`             | 要更新的头像地址。 |
| `ex`                  | 用户扩展字符串。   |
| `addFriendPermission` | 添加好友权限值。   |

一次请求只写入需要变更的字段。设置全局消息接收方式时，参见[设置全局消息接收方式](/sdk/android/user/user-profile/set-global-message-reception)。

当前用户资料变化时，可通过 `OnUserListener` 接收 `onSelfInfoUpdated`：

```java
@Override
public void onSelfInfoUpdated(UserInfo info) {
    // 处理当前用户资料变化
}
```
