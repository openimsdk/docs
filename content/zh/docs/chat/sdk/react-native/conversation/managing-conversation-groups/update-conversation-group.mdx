修改已有会话分组的名称、扩展信息或隐藏状态。调用时仅需传入需要更新的字段。

```ts
const group = await OpenIMSDK.updateConversationGroup({
  conversationGroupID,
  name: '重点工作',
  hidden: false,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationGroupID` | `string` | 是 | 要更新的会话分组 ID。 |
| `name` | `string` | 否 | 新的分组名称。 |
| `ex` | `string` | 否 | 新的分组扩展字符串。 |
| `hidden` | `boolean` | 否 | 是否隐藏分组。 |

## 返回结果

调用完成后返回更新后的 `ConversationGroupResp`。

分组更新成功后会触发 `OnConversationGroupChanged` 事件；客户端应使用 `conversationGroupID` 作为标识，在本地会话分组列表中合并最新分组属性。完整监听方式见[会话分组概览](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups)。
