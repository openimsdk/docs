Add one or more conversations to specified conversation groups. This operation creates organizational links; it does not instantiate new conversations or alter chat destinations.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationGroupIDs` | `List<String>` | Yes | List of target conversation group IDs. |
| `conversationIDs` | `List<String>` | Yes | List of conversation IDs to add to the groups. |

## Code example

```dart
await OpenIM.iMManager.conversationGroupManager.addConversationsToGroups(
  conversationGroupIDs: [conversationGroupID],
  conversationIDs: [conversationID],
);
```

## Return value

A successful `Future` indicates that the association request was processed by the server. The client updates the local conversation list within each group using `conversationGroupID` and `conversationID` as composite keys.

## State changes after the call

Multi-device synchronization and arriving changes trigger `onConversationGroupMemberAdded` notifications. For complete listener integration, see [Conversation groups overview](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups).
