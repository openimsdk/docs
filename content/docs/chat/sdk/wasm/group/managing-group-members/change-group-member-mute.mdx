## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | ID of the target group. |
| `userID` | `string` | Yes | User ID of the target member. |
| `mutedSeconds` | `number` | Yes | Mute duration in seconds. Pass `0` to unmute the member. |

```ts
await openimsdk.changeGroupMemberMute({
  groupID,
  userID: targetUserID,
  mutedSeconds: 3600,
});
```

The group owner can mute administrators and regular members, while an administrator can mute only regular members. OpenIMServer performs the final authorization check.

When the Promise resolves, the server has completed the request. Use `muteEndTime` in the member profile as the authoritative final state instead of calculating it solely from the submitted duration. For handling `OnGroupMemberInfoChanged`, see [List group members](/sdk/wasm/group/retrieving-group-members/get-group-member-list).
