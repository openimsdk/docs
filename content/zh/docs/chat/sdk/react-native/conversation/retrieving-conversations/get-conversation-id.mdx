根据聊天目标 ID 和会话类型获取或生成确定性的会话 ID。

```ts
const conversationID = await OpenIMSDK.getConversationIDBySessionType({
  sourceID: targetUserID,
  sessionType: SessionType.Single,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `sourceID` | `string` | 是 | 单聊传对方用户 ID，群聊传群组 ID。 |
| `sessionType` | `SessionType` | 是 | 会话类型。单聊使用 `SessionType.Single`，群聊使用 `SessionType.Group`。 |

## 返回结果

调用完成后返回 `string` 类型的 `conversationID`。该 ID 是客户端在定位会话、监听会话变更以及执行各类会话操作时的唯一合并标识。
