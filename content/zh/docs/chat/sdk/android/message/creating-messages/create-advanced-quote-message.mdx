构建同时包含富文本高亮实体与历史消息引用的高级回复消息。回复正文中可携带超链接、提及等结构化标签，并附带被引用消息的上下文信息。

```java
RichMessage mention = new RichMessage();
mention.setType("mention");
mention.setOffset(0);
mention.setLength(6);
mention.setInfo("{\"userID\":\"user_a\"}");

Message message = OpenIMClient.getInstance().messageManager.createAdvancedQuoteMessage(
    "OpenIM 方案赞同",
    originalMessage,
    Collections.singletonList(mention)
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `text` | `String` | 是 | 当前发送的回复文本正文。 |
| `message` | `Message` | 是 | 被引用的完整历史消息对象。 |
| `richMessages` | `List<RichMessage>` | 是 | 正文中的富文本实体定义列表，详细格式见[创建富文本消息](/sdk/android/message/creating-messages/create-advanced-text-message)。 |

## 返回结果

返回创建完成的待发送 `Message` 对象。

本方法只在本地构造消息对象，不会自动发起网络发送。构建完成后，请调用[发送消息](/sdk/android/message/sending-messages/send-message)进行投递。
