调用 `addFriend()` 向指定用户发送好友申请。

```ts
await OpenIMSDK.addFriend({
  toUserID,
  reqMsg,
});
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `toUserID` | `string` | 是 | 要申请添加的用户 ID。 |
| `reqMsg` | `string` | 是 | 申请附言；没有内容时传空字符串。 |

发送成功只表示好友申请已提交，不表示对方已经同意。申请状态变化时，可在[获取收到的好友申请](/sdk/react-native/user/friend-applications/get-friend-application-list-as-recipient)页面监听相关事件。
