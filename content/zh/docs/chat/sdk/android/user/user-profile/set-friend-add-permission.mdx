`addFriendPermission` 用于设置其他用户添加当前账号时是否需要审核。该能力属于商业版。

使用 `UserInfoReq.setAddFriendPermission()` 设置权限值，再调用 `setSelfInfo()`：

```java
UserInfoReq request = new UserInfoReq();
request.setAddFriendPermission(AddFriendPermission.Allow.getValue());

OpenIMClient.getInstance().userInfoManager.setSelfInfo(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 设置好友添加权限成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    request
);
```

## 权限值

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `AddFriendPermission.Allow` | `0` | 允许其他用户添加，但需要当前用户审核好友申请。 |
| `AddFriendPermission.AllowNoReview` | `1` | 允许其他用户添加，并直接建立好友关系，无需审核。 |
| `AddFriendPermission.Deny` | `2` | 不允许其他用户添加当前账号。 |

成功 callback 表示设置请求完成。该设置只影响之后的添加行为，不会删除已有好友关系或处理已经存在的好友申请。
