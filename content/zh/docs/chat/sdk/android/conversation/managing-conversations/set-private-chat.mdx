开启或关闭指定单聊会话的阅后即焚（私聊）模式。开启后，在该会话中发送的消息在对端阅读后将启动倒计时并自动销毁。

```java
OpenIMClient.getInstance().conversationManager.setOneConversationPrivateChat(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    conversationID,
    true
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `conversationID` | `String` | 是 | 目标会话的唯一标识。 |
| `isPrivate` | `boolean` | 是 | 传入 `true` 表示开启阅后即焚；传入 `false` 表示关闭。 |

## 返回结果

成功回调表示服务端已更新该会话的阅后即焚开关。阅读后的销毁倒计时时长可通过[设置阅后即焚时长](/sdk/android/conversation/managing-conversations/set-burn-duration)单独配置。

配置生效后，SDK 会触发 `OnConversationListener.onConversationChanged` 事件；客户端收到通知后应根据 `conversationID` 更新对应会话的 `isPrivateChat` 字段并刷新聊天界面提示，完整监听配置请参考[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
