使用 `createFileMessageFromFullPath()` 根据设备上的文件创建消息。

```ts
const message = await OpenIMSDK.createFileMessageFromFullPath({
  filePath,
  fileName: '产品说明.pdf',
});
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `filePath` | `string` | 是 | 文件的完整路径。 |
| `fileName` | `string` | 是 | 对外展示的文件名。 |

调用后返回待发送的 `MessageItem`。使用[发送消息](/sdk/react-native/message/sending-messages/send-message)时，SDK 会处理本地文件上传。
