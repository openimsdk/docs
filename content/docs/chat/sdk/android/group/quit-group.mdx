`quitGroup()` only removes the current signed-in user. It does not dismiss the group or remove other members.

```java
OpenIMClient.getInstance().groupManager.quitGroup(new OnBase<String>() {
    @Override public void onSuccess(String data) { removeJoinedGroup(groupID); }
    @Override public void onError(int code, String error) { showQuitError(error); }
}, groupID);
```

Even after the request succeeds, handle `onJoinedGroupDeleted` and clear application caches for the group's member list, conversation entry, and related data.
