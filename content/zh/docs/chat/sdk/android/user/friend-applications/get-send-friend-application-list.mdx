分页查询当前登录账号主动向其他用户发出的好友申请记录及其审批状态。

```java
GetFriendApplicationListAsApplicantReq request =
    new GetFriendApplicationListAsApplicantReq(0, 20);

OpenIMClient.getInstance().friendshipManager.getSendFriendApplicationList(
    new OnBase<List<FriendApplicationInfo>>() {
        @Override
        public void onSuccess(List<FriendApplicationInfo> applications) {
            // 使用 applications 更新发出的好友申请列表
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    request
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<List<FriendApplicationInfo>>` | 是 | 异步请求回调。 |
| `request` | `GetFriendApplicationListAsApplicantReq` | 是 | 发出的好友申请分页查询对象，构造方法传入 `offset` 和 `count`。 |

### 分页请求对象属性

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `offset` | `int` | 分页起始偏移量，首批传 `0`。 |
| `count` | `int` | 本页期望返回的申请数量。 |

## 返回结果

成功回调返回当前分页的 `List<FriendApplicationInfo>`。发出的申请记录中，当前用户为 `fromUserID`，接收方为 `toUserID`。客户端应以目标用户 `userID`（`toUserID`）为主键进行去重与状态展示。各项字段与处理状态枚举值与[获取收到的好友申请](/sdk/android/user/friend-applications/get-recv-friend-application-list)保持一致。
