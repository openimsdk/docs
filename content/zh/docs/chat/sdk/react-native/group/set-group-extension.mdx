设置指定群组的自定义扩展信息字段。

```ts
await OpenIMSDK.setGroupInfo({
  groupID,
  ex: JSON.stringify({
    projectID: 'project-42',
  }),
});
```

## 参数说明

`groupID` 为目标群组 ID，`ex` 是字符串类型，可按业务需要传递 JSON 字符串或其他格式的自定义扩展信息。

## 返回结果

调用完成后，群组扩展字段设置已生效。

群资料变化会通过 `OnGroupInfoChanged` 事件通知群内成员。客户端应以 `groupID` 为合并标识更新对应群组的 `ex` 扩展字段。完整事件监听说明见[群组概览](/sdk/react-native/group/overview-group)。
