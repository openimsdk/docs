创建带有消息实体的富文本消息。

```ts
const message = await OpenIMSDK.createAdvancedTextMessage({
  text: '请查看 https://openim.io',
  messageEntityList: [
    {
      type: 'url',
      offset: 4,
      length: 17,
      url: 'https://openim.io',
    },
  ],
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `text` | `string` | 是 | 富文本的原始文本内容。 |
| `messageEntityList` | `MessageEntity[]` | 否 | 文本中的实体列表。 |

每项 `MessageEntity` 包含 `type`、`offset`、`length`，并可按需传入 `url` 和 `info`。

## 返回结果

调用完成后返回已创建的 `MessageItem` 消息对象。

该方法仅在本地构建消息对象，不会直接将消息发送到服务端，也不会触发事件通知。生成消息后，需调用[发送消息](/sdk/react-native/message/sending-messages/send-message)将其发送到指定单聊或群聊会话中。
