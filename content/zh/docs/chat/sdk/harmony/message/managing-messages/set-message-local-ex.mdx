description: '更新当前设备上的消息本地扩展字段。'

`localEx` 只保存在当前设备，适合折叠、选中、本地来源标记或应用自定义的语音转写结果。

```ts
import sdk, { SetMessageLocalExReq } from '@openimsdk/imsdk';

const request: SetMessageLocalExReq = {
  conversationID: conversationID,
  clientMsgID: message.clientMsgID,
  localEx: JSON.stringify({ selected: true, transcript: '识别后的文字' }),
};
await sdk.setMessageLocalEx(request);
```

该方法不会自动合并旧 JSON。多个功能共用时，先读取并校验原值，在业务层合并后再整体写回。Promise 成功只表示本地数据库已更新，不会触发共享消息事件。
