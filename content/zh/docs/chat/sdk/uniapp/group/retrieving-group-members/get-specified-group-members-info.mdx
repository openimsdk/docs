`getSpecifiedGroupMembersInfo()` 适合在已经持有用户 ID 时读取对应的群内昵称、角色和禁言状态。

```uts
import {
  getSpecifiedGroupMembersInfo,
} from '@/uni_modules/unix-openim-sdk'

const result = await getSpecifiedGroupMembersInfo({
  groupID: groupID,
  userIDList: userIDList,
})
const members = result != null ? result.members : []
```

`groupID` 和 `userIDList` 均为必填参数。Promise 成功后返回 `OpenIMGroupMemberListResult | null`；非空结果的 `members` 是匹配的 `OpenIMGroupMemberItem[]`。

结果数组不保证与输入 ID 按位置一一对应。同一用户在不同群组中的昵称、角色和禁言状态可能不同，应使用 `groupID:userID` 对应和缓存成员资料。字段含义见[分页查询群成员](/sdk/uniapp/group/retrieving-group-members/get-group-member-list)。

查询不会触发成员事件；页面保持打开时，继续处理成员新增、移除和资料变化事件。
