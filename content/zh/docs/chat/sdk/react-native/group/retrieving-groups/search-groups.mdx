按群组 ID 或群名称关键词搜索本地已缓存或已加入的群组列表。

```ts
const groups = await OpenIMSDK.searchGroups({
  keywordList: ['项目'],
  isSearchGroupID: false,
  isSearchGroupName: true,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `keywordList` | `string[]` | 是 | 搜索关键词列表。 |
| `isSearchGroupID` | `boolean` | 是 | 是否匹配群组 ID。 |
| `isSearchGroupName` | `boolean` | 是 | 是否匹配群组名称。 |

## 返回结果

调用完成后返回匹配的 `GroupItem[]`。客户端在展示或合并搜索结果时，应使用 `groupID` 作为唯一标识。各字段详细说明见[群组概览](/sdk/react-native/group/overview-group)。
