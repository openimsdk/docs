为指定会话设置自定义业务扩展信息。扩展字段通常为序列化后的 JSON 字符串，可用于保存特定业务状态、会话标签或自定义显示属性。

```java
OpenIMClient.getInstance().conversationManager.setConversationEx(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    conversationID,
    extensionJSON
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `conversationID` | `String` | 是 | 目标会话的唯一标识。 |
| `ex` | `String` | 是 | 自定义扩展字符串，通常传入格式规范的 JSON 文本。 |

## 返回结果

成功回调表示服务端已成功持久化扩展字段。该配置会同步至当前用户的其他端。

配置生效后，SDK 会触发 `OnConversationListener.onConversationChanged` 事件；客户端收到通知后应根据 `conversationID` 更新对应会话的 `ex` 字段，完整监听配置请参考[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
