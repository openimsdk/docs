```objc
[[OIMManager manager] refuseGroupApplication:application.groupID
  fromUserId:application.userID handleMsg:@"Not approved at this time"
  onSuccess:^(NSString * _Nullable data) { [self showHandled]; }
  onFailure:^(NSInteger code, NSString *message) { [self showErrorCode:code message:message]; }];
```

A successful callback means that the rejection request has completed. `onGroupApplicationRejected:` may arrive afterward; merge it by `groupID:userID`.
