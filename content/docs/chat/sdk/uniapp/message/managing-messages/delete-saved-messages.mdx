```uts
import { deleteMessages, off, onMsgDeleted } from '@/uni_modules/unix-openim-sdk'

const deletedSubscription = onMsgDeleted((message) => removeMessageByID(message.clientMsgID))
await deleteMessages(deleteParams)
off(deletedSubscription)
```

`deleteMessages()` is <span className="enterprise-field-badge">Commercial</span> and uses `OpenIMDeleteMessagesParams`; `onMsgDeleted` is public. Merge request/event idempotently and follow the deployed service's cross-device semantics.
