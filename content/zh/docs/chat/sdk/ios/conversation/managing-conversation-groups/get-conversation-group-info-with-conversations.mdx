分页查询指定会话分组的详细信息及其包含的会话列表：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `conversationGroupID` | `NSString *` | 目标会话分组 ID。 |
| `pagination.pageNumber` | `NSInteger` | 分页页码，从 `1` 开始。 |
| `pagination.showNumber` | `NSInteger` | 每页拉取的数据条数。 |

```objc
#import <OpenIMSDK/CallbackProxy.h>
@import OpenIMCore;

NSDictionary *request = @{
    @"conversationGroupID": @"group_work_101",
    @"pagination": @{ @"pageNumber": @1, @"showNumber": @20 },
};

NSData *requestData = [NSJSONSerialization dataWithJSONObject:request options:0 error:nil];
NSString *requestJSON = [[NSString alloc] initWithData:requestData
                                              encoding:NSUTF8StringEncoding];

CallbackProxy *callback = [[CallbackProxy alloc]
    initWithOnSuccess:^(NSString * _Nullable data) {
        if (data == nil) {
            return;
        }
        [self handleGroupConversationsPageJSON:data];
    }
    onFailure:^(NSInteger code, NSString * _Nullable message) {
        NSLog(@"GetConversationGroupInfoWithConversations failed: %ld %@", (long)code, message);
    }];

Open_im_sdkGetConversationGroupInfoWithConversations(callback, requestJSON);
```

状态中分组以 `conversationGroupID` 为合并标识，分组成员以 `conversationID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 的 `data` 参数返回包含 `group`（分组详情）、`conversationElems`（当前页会话列表对象）与 `isEnd`（是否到达末尾布尔值）的 JSON 字符串。分页加载是否结束以 `isEnd` 为判断依据。

该接口只返回调用时的分页数据快照，不触发分组 listener 回调。分组成员发生增删时的事件同步处理请参见[会话分组概览](/sdk/ios/conversation/managing-conversation-groups/overview-conversation-groups)。
