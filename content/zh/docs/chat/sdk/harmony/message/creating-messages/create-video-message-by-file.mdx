sourcePath: '/sdk/harmony/message/creating-messages/create-video-message-by-file'

```ts
import sdk, { CreateVideoMessageReq, CreateVideoMessageResp } from '@openimsdk/imsdk';

const request: CreateVideoMessageReq = {
  videoSourcePath: videoPath,
  videoType: 'video/mp4',
  duration: 18,
  snapshotSourcePath: coverPath,
};
const response: CreateVideoMessageResp = await sdk.createVideoMessage(request);
const message = response.message;
```

视频与封面图都必须是原生 SDK 可读取的路径。`duration` 使用秒，`videoType` 填写真实 MIME 类型。Promise 成功只创建消息对象；后续由 SDK 上传两份资源并发送。
