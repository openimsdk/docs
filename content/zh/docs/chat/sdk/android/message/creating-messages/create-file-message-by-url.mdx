使用已上传至业务自有云存储或第三方 CDN 的文件远端 URL 创建文件消息对象。无需 SDK 再次上传文件，适用于企业已有网盘或文件系统集成场景。

```java
FileElem fileElem = new FileElem();
fileElem.setSourceUrl("https://example.com/files/report.pdf");
fileElem.setFileName("项目汇报.pdf");
fileElem.setFileSize(2048000L);

Message message = OpenIMClient.getInstance().messageManager.createFileMessageByURL(fileElem);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `fileElem` | `FileElem` | 是 | 文件模型对象，需设置文件远端下载地址 `sourceUrl`、文件名 `fileName` 以及文件大小 `fileSize`。 |

## 返回结果

返回包含已上传文件属性的待发送 `Message` 对象，其 `contentType` 为 `MessageType.FILE`。

构建完成后，调用[发送不经 OSS 的消息](/sdk/android/message/sending-messages/send-message-not-oss)直接投递。
