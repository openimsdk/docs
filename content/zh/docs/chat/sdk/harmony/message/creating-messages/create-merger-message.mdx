---
title: '创建合并转发消息'
description: '将多条已有消息整理为一条合并转发消息。'
sourcePath: '/sdk/harmony/message/creating-messages/create-merger-message'
---

```ts
import sdk, { CreateMergerMessageReq, CreateMergerMessageResp } from '@openimsdk/imsdk';

const request: CreateMergerMessageReq = {
  messages: selectedMessages,
  title: '项目讨论记录',
  summaries: ['Alex：请确认发布时间', 'Morgan：计划周五上线'],
};
const response: CreateMergerMessageResp = await sdk.createMergerMessage(request);
const message = response.message;
```

`messages` 的顺序即完整记录的展示顺序；`summaries` 由业务层生成，不会由 SDK 自动概括。创建成功只得到待发送的 `IMMessage`，还需要调用 `sendMessage()` 发送到目标会话。
