---
title: '清空会话消息'
description: '保留会话入口并清空当前账号保存的会话消息。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/clear-conversation-messages'
---

`clearConversationAndDeleteAllMsg()` 保留会话入口，清除当前账号保存的消息以及相关消息摘要状态。操作完成后，SDK 无法从本地数据中恢复这些消息。

```uts
import { clearConversationAndDeleteAllMsg } from '@/uni_modules/unix-openim-sdk'

await clearConversationAndDeleteAllMsg(conversationID)
```

Promise 成功后，可以清空当前消息列表。随后收到 `onConversationChanged()` 时，按 `conversationID` 更新最后一条消息、摘要和未读状态；如果事件可能遗漏，应重新查询会话并以最新结果为准。完整监听见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。

如需同时删除会话入口，使用[删除会话及消息](/sdk/uniapp/conversation/managing-conversations/delete-conversation-with-messages)。
