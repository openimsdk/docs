```ts
const previous = JSON.parse(member.ex || '{}');

await openimsdk.setGroupMemberInfo({
  groupID,
  userID: targetUserID,
  ex: JSON.stringify({
    ...previous,
    title: 'maintainer',
  }),
});
```

`ex` 是完整字符串，SDK 不会自动合并 JSON。写入前应保留其他业务模块的命名空间。

Promise 成功后，收到 `OnGroupMemberInfoChanged` 时使用 `groupID:userID` 更新对应成员；完整监听见[分页查询群成员](/sdk/wasm/group/retrieving-group-members/get-group-member-list)。
