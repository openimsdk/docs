`setAppBadge:onSuccess:onFailure:` 用于向 SDK 上报应用当前展示的消息总未读数。

```objc
[[OIMManager manager] setAppBadge:totalUnreadCount
                        onSuccess:^(NSString * _Nullable data) {
                            // SDK 已接受本次角标值。
                        }
                        onFailure:^(NSInteger code, NSString * _Nullable msg) {
                            // 根据业务需要处理错误。
                        }];
```

`totalUnreadCount` 应为非负整数。通常在消息总未读数变化、登录同步完成或清空未读消息后更新；不要把单个会话的未读数作为应用总角标。

成功回调只表示 SDK 已接受本次角标值，不会改变会话的本地未读数。若应用需要在系统桌面图标上展示角标，还应按 iOS 的通知与角标机制更新系统界面。消息总未读数的查询和持续维护见[获取消息总未读数](/sdk/ios/conversation/managing-conversations/get-total-unread-count)。
