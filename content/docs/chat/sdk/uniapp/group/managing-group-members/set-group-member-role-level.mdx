Invoke `setGroupMemberInfo()` to promote a regular member to administrator or demote an administrator to regular status. Only the group owner has permission to perform role adjustments.

## Parameters

The `roleLevel` property accepts values of type `OpenIMGroupMemberRole`:

| Enum constant | Numeric value | Description |
| --- | --- | --- |
| `OpenIMGroupMemberRoleNormal` | `20` | Regular member (used to demote an administrator). |
| `OpenIMGroupMemberRoleAdmin` | `60` | Administrator (used to promote a member). |
| `OpenIMGroupMemberRoleOwner` | `100` | Group owner (used for role identification only; cannot be passed to this API). |

Do not attempt to transfer group ownership by passing `OpenIMGroupMemberRoleOwner`; invoke [Transfer group ownership](/sdk/uniapp/group/managing-group-members/transfer-group-owner) instead.

## Code example

```uts
import {
  OpenIMGroupMemberRoleAdmin,
  setGroupMemberInfo,
} from '@/uni_modules/unix-openim-sdk'

await setGroupMemberInfo({
  groupID: groupID,
  userID: targetUserID,
  roleLevel: OpenIMGroupMemberRoleAdmin,
})
```

## Return value

The Promise resolves with `void` once OpenIMServer updates the member role.

## State changes after the call

A resolved Promise confirms that the role update completed. Connected clients receive `onGroupMemberInfoChanged`, at which point the UI updates the member's `roleLevel` matching `groupID:userID`. For complete member event handling, see [Get group member list](/sdk/uniapp/group/retrieving-group-members/get-group-member-list).
