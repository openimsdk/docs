`speechToText()` <span className="enterprise-field-badge">商业版</span> 使用文件名和音频数据。

```uts
import { speechToText } from '@/uni_modules/unix-openim-sdk'

const result = await speechToText({ filename: 'voice.m4a', data: audioBase64 })
```

先检查能力，限制音频大小和格式。`data` 的编码以商业服务协议为准；不要记录完整音频或 Base64。转写结果需要用户确认，不用于高风险自动决策。
