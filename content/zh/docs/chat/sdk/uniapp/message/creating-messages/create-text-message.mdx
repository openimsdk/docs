创建文本消息接口接收文本字符串。调用前应在业务层处理空白字符、文本长度和合规校验规则。

```uts
import { createTextMessage } from '@/uni_modules/unix-openim-sdk'

const text = input.trim()
if (text.length == 0) return

const message = await createTextMessage(text)
if (message == null) return
```

Promise 成功后返回 `OpenIMMessageItem | null`。创建操作只在本地构造待发送对象，不会写入服务端，也不会触发新消息事件。

后续可调用[发送消息](/sdk/uniapp/message/sending-messages/send-message)发送该消息，客户端使用返回消息的 `clientMsgID` 关联并更新本地消息状态。
