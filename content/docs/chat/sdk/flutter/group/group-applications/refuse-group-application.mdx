Pass a valid `groupID`, the applicant's `userID`, and an optional `handleMsg`. Handle a successful `Future` and arrival of `onGroupApplicationRejected` separately.

```dart
await OpenIM.iMManager.groupManager.refuseGroupApplication(
  groupID: groupID,
  userID: applicantUserID,
  handleMsg: 'The group is not accepting new members right now',
);
```
