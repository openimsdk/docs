Retrieve the full profile of the currently logged-in user:

## Parameters

This method accepts no parameters.

## Code example

```dart
final user = await OpenIM.iMManager.userManager.getSelfUserInfo();
```

## Return value

A successful `Future` returns a `UserInfo` object representing the current user's profile.

`UserInfo` contains core account properties:
- `userID`: Unique current user identifier.
- `nickname`: User's display nickname.
- `faceURL`: Avatar URL.
- `gender`: Gender enumeration value.
- `ex`: Custom business extension string.
- `globalRecvMsgOpt`: Global message reception and notification setting.

This query is a read-only operation and does not trigger profile change events. Use the returned object to initialize user profile pages, settings screens, or current-user application state. Clear in-memory profile state when logging out or switching accounts.

To modify personal information, see [Update self profile](/sdk/flutter/user/retrieving-and-updating-user-information/update-self-profile). For profile event listening, see [Events overview](/sdk/flutter/events/overview-events).
