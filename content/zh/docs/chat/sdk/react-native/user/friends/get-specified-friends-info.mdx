按用户 ID 批量查询指定好友的好友资料。

```ts
const friends = await OpenIMSDK.getSpecifiedFriendsInfo({
  userIDList: ['user_a', 'user_b'],
  filterBlack: true,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `userIDList` | `string[]` | 是 | 要查询的用户 ID 列表。 |
| `filterBlack` | `boolean` | 否 | 是否过滤已加入黑名单的用户；默认为 `false`。 |

## 返回结果

调用完成后返回匹配的 `FriendUserItem[]` 好友记录列表，返回顺序不保证与传入 ID 列表一一对应。字段详细说明见[分页获取好友列表](/sdk/react-native/user/friends/get-friend-list-page)。

查询非好友的公开用户资料时，使用[获取用户资料](/sdk/react-native/user/profile/get-users-info)。
