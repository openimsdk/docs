---
title: '设置入群验证方式'
description: '设置申请或邀请用户加入群组时的审核策略。'
sourcePath: '/sdk/uniapp/group/set-group-join-verification'
---

当前 UTS 合同使用 `0 | 1 | 2` 表示入群验证方式，没有导出具名常量。建议在业务层集中封装这些值。

| 数值 | 含义 |
| --- | --- |
| `0` | 用户申请需要审核；群成员邀请可以直接入群。 |
| `1` | 申请和普通成员邀请都需要审核；群主或管理员邀请除外。 |
| `2` | 申请或邀请均可直接入群。 |

```uts
import { setGroupInfo } from '@/uni_modules/unix-openim-sdk'

const allNeedVerification: 0 | 1 | 2 = 1

await setGroupInfo({
  groupID,
  needVerification: allNeedVerification,
})
```

客户端应根据策略展示申请提示，但最终是否允许加入仍由 OpenIMServer 判断。Promise 成功后，收到 `onGroupInfoChanged()` 时再更新对应群资料；完整监听见[群组概览](/sdk/uniapp/group/overview-group)。
