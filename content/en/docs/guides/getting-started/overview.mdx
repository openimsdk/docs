## Overview

**OpenIMSDK** is an **open-source in-app instant messaging solution** designed for developers. It enables developers to integrate chat, groups, friends, notifications, and audio/video calling capabilities into their own applications without building complex communication systems from scratch.

Unlike standalone chat applications such as WeChat or Slack, OpenIMSDK focuses on providing **embeddable communication capabilities**. Deploying organizations can manage data, interaction logic, and deployment methods independently, and extend the system to match specific business scenarios.

OpenIMSDK also serves as an open-source alternative to instant messaging cloud platforms such as Twilio and Sendbird. It supports self-hosted private deployments and localized infrastructure environments, serving as a drop-in replacement for architectures reliant on third-party IM cloud services.

## Key capabilities

OpenIMSDK covers the core modules of real-time in-app communication:

- **Unified APIs:** Provides consistent API design and complete SDK documentation to streamline chat integration across platforms.
- **Open-source scope:** Provides full source code for self-hosting and secondary development, allowing deploying organizations to adapt the platform to specific business constraints.
- **Intelligent interaction extensions:** Supports integration with LLMs, multi-agent workflows, and other intelligent interaction scenarios.
- **Secondary development:** Enables customization of chat logic, interaction behavior, and UI components according to business requirements.
- **Private deployment:** Deploys onto self-hosted servers, private clouds, or localized infrastructure, giving deploying teams full governance over data, networking, and compliance policies.
- **Server architecture:** Built with a Go microservice architecture that supports high concurrency, high availability, clustering, and horizontal scaling.
- **Message deliverability testing:** Validates the reliability of message sending, receiving, and push delivery pipelines by simulating real user behavior.

## Ecosystem components

- **OpenIMServer:** The core IM backend responsible for real-time message communication between users. It can be deployed on private servers or private clouds.
- **ChatServer:** The business extension server providing user registration, administration portals, and other application-layer services. If you already operate an existing business system, you can integrate it as needed.
- **REST API:** Enables trusted business backends to call OpenIMServer with administrator privileges to manage users, groups, messages, and other resources.
- **Webhooks:** Triggers proactive HTTP/HTTPS requests from OpenIMServer to business backends before or after specified events occur, allowing backends to intervene in subsequent workflows or synchronize data.
- **OpenIMClientSDK:** Covers iOS, Android, Web, Flutter, uni-app, Mini Programs, React Native, and Electron, providing core integration for chat, groups, relationship chains, and push notifications.

## Deployment options

- **Self-hosted private deployment:** Run OpenIMServer on local servers, private clouds, or localized environments, and deploy ChatServer according to business needs. This documentation provides guides for Docker Compose, source builds, and clustered deployments.

## Use cases

- In-app chat and social applications
- AI assistants, intelligent customer support bots, and virtual agents
- Enterprise collaboration and video conferencing platforms
- Unified communication hubs for e-commerce and customer service
- Real-time interaction systems for healthcare and education
- Dedicated secure communication systems for government and enterprise

OpenIMSDK serves as a self-hosted communication infrastructure foundation.
