通过本地沙盒中的音频文件绝对路径及播放时长，可调用创建音频消息方法生成待发送的语音消息对象。SDK 会在发送流程中自动上传音频文件至对象存储服务。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createSoundMessageFromFullPath:audioURL.path
                                          duration:durationSeconds];
```

## 参数说明

- `soundPath`：本地沙盒内可访问的音频文件绝对路径（`NSString *`）。
- `duration`：音频文件的播放时长（单位：秒）。

## 返回结果

- 返回初始化的语音消息对象（`OIMMessageInfo *`），其内容类型为语音。
- 该方法仅在本地内存中构建待发送消息对象。后续需调用[发送消息](/sdk/ios/message/sending-messages/send-message)接口完成文件上传与消息投递。若音频已由业务自行上传至存储服务，见[使用 URL 创建音频消息](/sdk/ios/message/creating-messages/create-sound-message-by-url)。
