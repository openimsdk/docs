Group owners and administrators can clear every historical message sent by a designated member in a group chat. This is commonly used to remove spam, moderate rule violations, or ban abusive accounts across a group conversation.

## Code example

```java
String conversationID = "g_group_123";
String targetUserID = "user_spammer";

OpenIMClient.getInstance().messageManager.deleteUserAllMessagesInConv(
    conversationID,
    targetUserID,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // Deletion request processed successfully
        }

        @Override
        public void onError(int code, String error) {
            // Failed to delete user messages (e.g. insufficient permissions)
        }
    }
);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `String` | Yes | Globally unique ID of the target group conversation. Group conversations only. |
| `targetUserID` | `String` | Yes | User ID of the member whose messages should be cleared. |
| `base` | `OnBase<String>` | Yes | Callback handler for the asynchronous request. |

## Return value

Upon success, `data` in `onSuccess` returns a confirmation message.

## State changes after the call

1. **Callback confirmation**: The `onSuccess` callback indicates that the server has executed the purge across the specified group conversation.
2. **Asynchronous event delivery**: All online group members receive an event via `OnAdvanceMsgListener.onDeleteUserAllMsgsInConv`:
   ```java
   @Override
   public void onDeleteUserAllMsgsInConv(DeleteUserAllMsgsListenerMsg event) {
       // Filter by event.getConversationID() and event.getUserID()
       // Remove all messages sent by this user from the local timeline
   }
   ```
   Group members filter messages by `conversationID` and `sendID == targetUserID`, removing all matching bubbles from their active UI timeline.
3. **Re-query calibration**: If UI state diverges after reconnecting, reload the message history using [Load older messages](/sdk/android/message/retrieving-messages/load-older-messages).

For complete listener registration and lifecycle management, see [Receive messages](/sdk/android/message/receiving-messages/receive-messages).
