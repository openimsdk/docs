title: '设置会话扩展字段'
description: '设置当前用户指定会话的业务扩展字符串。'
sourcePath: '/sdk/wasm/conversation/managing-conversations/set-conversation-extension'
---

属性 `ex` 用于存储业务自定义的会话级扩展数据：

```ts
const previous = JSON.parse(conversation.ex || '{}');

await openimsdk.setConversation({
  conversationID,
  ex: JSON.stringify({
    ...previous,
    category: 'work',
  }),
});
```

`ex` 为原生字符串字段，SDK 不会自动进行 JSON 合并。若多个业务模块共用该扩展字段，建议按业务维度划分命名空间，并在更新前读取现有内容进行增量合并。

接口调用成功后，SDK 会触发 `SdkEvent.OnConversationChanged` 事件通知会话变更。业务层可根据 `conversationID` 更新对应会话的 `ex` 数据。完整的事件监听配置请参考[获取会话列表](/sdk/wasm/conversation/retrieving-conversations/retrieve-conversation-list)。
