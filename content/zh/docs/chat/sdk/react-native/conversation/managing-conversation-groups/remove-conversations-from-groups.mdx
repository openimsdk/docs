将一个或多个会话从指定的会话分组中批量移除。该操作仅解除会话与分组的归属关联，不会删除会话本身或会话历史消息。

```ts
await OpenIMSDK.removeConversationsFromGroups({
  conversationIDs: [conversationID],
  conversationGroupIDs: [conversationGroupID],
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationIDs` | `string[]` | 是 | 要移除的会话 ID 列表。 |
| `conversationGroupIDs` | `string[]` | 是 | 目标会话分组 ID 列表。 |

## 返回结果

调用完成后，分组与会话的关联移除请求已处理完成。

分组关联变化会通过 `OnConversationGroupMemberDeleted` 事件通知；客户端在合并状态时，应分别以 `conversationGroupID` 定位目标会话分组、以 `conversationID` 从该分组的成员列表中移除对应会话。完整监听方式见[会话分组概览](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups)。
