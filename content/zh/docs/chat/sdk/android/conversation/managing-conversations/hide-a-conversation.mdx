title: '隐藏会话'
description: '使用 hideConversation() 从 Android 当前账号的会话列表隐藏入口。'

---

`hideConversation()` 只隐藏当前登录用户的会话入口，不会删除单聊关系、退出群组或影响其他用户。

```java
OpenIMClient.getInstance().conversationManager.hideConversation(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            conversationStore.remove(conversationID);
        }

        @Override
        public void onError(int code, String error) {
            recordConversationHideFailure(code, error);
        }
    },
    conversationID
);
```

该方法适合临时从聊天列表移除入口。收到新消息或重新同步后，隐藏的会话可能再次出现。

成功 callback 表示隐藏请求已完成，调用端可以从当前列表移除该 `conversationID`。后续收到 `onConversationChanged` 时仍应按 `conversationID` 幂等合并；完整 listener 见[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
