A group owner or administrator calls this method to decline a pending join request:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID. |
| `userID` | `String` | Yes | User ID of the applicant. |
| `handleMsg` | `String?` | No | Optional remark explaining the reason for declining. |

## Code example

```dart
await OpenIM.iMManager.groupManager.refuseGroupApplication(
  groupID: groupID,
  userID: applicantUserID,
  handleMsg: 'Applications are closed currently',
);
```

## Return value

A successful `Future` indicates that the rejection decision has been recorded on the server.

## State changes after the call

Multi-device synchronization and arriving changes trigger the `onGroupApplicationRejected` callback. The client updates application status using `groupID:userID` as the key. For complete listener integration, see [Group applications overview](/sdk/flutter/group/group-applications/overview-group-applications).
