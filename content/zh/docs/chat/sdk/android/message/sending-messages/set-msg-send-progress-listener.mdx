title: '监听消息发送进度'
description: '通过 OnMsgSendCallback 的进度回调更新媒体发送进度。'

---

Android 没有独立的全局发送进度 listener；进度随每次 `sendMessage()` 或 `sendMessageNotOss()` 传入的 `OnMsgSendCallback` 返回。

```java
messageManager.sendMessage(new OnMsgSendCallback() {
    @Override public void onProgress(long progress) { updateProgress(progress); }
    @Override public void onSuccess(Message sentMessage) { finishProgress(); }
    @Override public void onError(int code, String error) { failProgress(error); }
}, message, peerUserID, null, offlinePushInfo);
```
