根据多个 `conversationID` 批量拉取会话信息，适用于通知中心跳转、快捷会话同步或自定义分组会话渲染。

```java
OpenIMClient.getInstance().conversationManager.getMultipleConversation(
    new OnBase<List<ConversationInfo>>() {
        @Override
        public void onSuccess(List<ConversationInfo> conversations) {
            // conversations 是按 conversationIDs 查询到的当前会话资料。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    conversationIDs
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<List<ConversationInfo>>` | 是 | 异步请求回调。 |
| `conversationIDs` | `List<String>` | 是 | 待查询的 `conversationID` 列表，建议调用前去重并过滤空值。 |

## 返回结果

成功回调返回包含命中会话的 `List<ConversationInfo>`。客户端应以各对象的 `conversationID` 作为主键对本地会话缓存进行合并更新。若传入的某些会话 ID 不存在，返回列表中将不包含对应项。
