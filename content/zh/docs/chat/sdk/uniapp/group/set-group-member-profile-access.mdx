`lookMemberInfo` 的类型为 `OpenIMGroupAllowType`。注意此处的数值定义：

## 参数说明

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `OpenIMGroupAllowTypeAllowed` | `0` | 允许成员查看其他成员资料。 |
| `OpenIMGroupAllowTypeNotAllowed` | `1` | 不允许成员查看其他成员资料。 |

```uts
import {
  OpenIMGroupAllowTypeNotAllowed,
  setGroupInfo,
} from '@/uni_modules/unix-openim-sdk'

await setGroupInfo({
  groupID,
  lookMemberInfo: OpenIMGroupAllowTypeNotAllowed,
})
```

该设置与是否允许群内互相添加好友相互独立。Promise 成功表示设置请求已完成，客户端可先将本地对应群组的查看资料权限更新为目标值，收到群资料变更事件后，按 `groupID` 确认最新状态。完整群组事件监听见[群组概览](/sdk/uniapp/group/overview-group)。
