将一条群聊消息直接写入本地数据库。此方法仅在当前客户端本地保存消息记录，不会向服务端或群聊其他成员发送网络消息，常用于在本地插入系统通知、入群引导或业务占位提示。

```ts
const localMessage = await OpenIMSDK.insertGroupMessageToLocalStorage({
  message,
  groupID,
  sendID,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `message` | `MessageItem` | 是 | 要写入本地数据库的完整消息对象，通常由消息创建接口生成。 |
| `groupID` | `string` | 是 | 目标群组 ID。 |
| `sendID` | `string` | 是 | 消息发送方的用户 ID，可指定为当前登录用户或系统虚拟账号。 |

## 返回结果

调用成功后返回已写入本地数据库的 `MessageItem`。消息以 `clientMsgID` 为客户端唯一合并标识保存至本地群聊历史。如果需要向群聊其他成员正常发送网络消息，请调用[发送消息](/sdk/react-native/message/sending-messages/send-message)。
