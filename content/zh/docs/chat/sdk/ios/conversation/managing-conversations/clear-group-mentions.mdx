用户处理完群聊中的 @ 提醒消息后，将该群会话的 `@` 提醒状态重置为普通状态：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `conversationID` | `NSString *` | 目标群聊会话 ID。 |

```objc
[[OIMManager manager] resetConversationGroupAtType:@"group_2001"
                                         onSuccess:^(NSString * _Nullable data) {
                                             NSLog(@"resetConversationGroupAtType success");
                                         }
                                         onFailure:^(NSInteger code, NSString *message) {
                                             NSLog(@"resetConversationGroupAtType failed: %ld %@", (long)code, message);
                                         }];
```

状态以 `conversationID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回操作结果。

操作成功后，会话的 `groupAtType` 状态将被重置为普通状态（`OIMGroupAtTypeNormal`），消除会话项上的强提醒角标或红点。会话属性更新会通过 `onConversationChanged:` 事件广播，客户端按 `conversationID` 更新对应会话的展示状态。

群聊 @ 提醒状态与消息已读状态彼此独立。标记会话已读请参考[标记会话已读](/sdk/ios/conversation/managing-conversations/mark-conversation-read)；会话列表监听配置参见[获取会话列表](/sdk/ios/conversation/retrieving-conversations/retrieve-conversation-list)。
