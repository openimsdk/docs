title: '创建群组'

创建群组时提供初始群资料、普通成员列表和管理员列表。当前接口不通过参数另行指定群主；创建完成后，以返回群资料中的 `ownerUserID` 为准。

## 参数说明

| 参数                | 类型                     | 是否必填 | 说明                                              |
| ------------------- | ------------------------ | -------- | ------------------------------------------------- |
| `groupName`         | `string`                 | 是       | 群名称。                                          |
| `adminUserIDs`      | `string[]`               | 是       | 初始管理员用户 ID；没有管理员时传空数组。         |
| `memberUserIDs`     | `string[]`               | 是       | 初始普通成员用户 ID；没有普通成员时传空数组。     |
| `groupID`           | `string`                 | 否       | 由业务预先指定的群组 ID；通常省略并由服务端生成。 |
| `notification`      | `string`                 | 否       | 初始群公告。                                      |
| `introduction`      | `string`                 | 否       | 初始群简介。                                      |
| `faceURL`           | `string`                 | 否       | 群头像地址。                                      |
| `needVerification`  | `GroupNeedVerification`  | 否       | 入群验证策略。                                    |
| `lookMemberInfo`    | `GroupLookMemberInfo`    | 否       | 成员资料查看权限。                                |
| `applyMemberFriend` | `GroupApplyMemberFriend` | 否       | 群内添加好友权限。                                |
| `ex`                | `string`                 | 否       | 群组扩展字符串。                                  |

成员列表应先去重，并确保管理员和普通成员列表没有交集。

```ts
import sdk, { CreateGroupReq, CreateGroupResp } from '@openimsdk/imsdk';

const request: CreateGroupReq = {
  groupName: '项目讨论组',
  faceURL: 'https://example.com/group.png',
  adminUserIDs: ['user_002'],
  memberUserIDs: ['user_003', 'user_004'],
};
const response: CreateGroupResp = await sdk.createGroup(request);
openGroupPage(response.groupInfo.groupID);
```

Promise 成功后返回新建的 `IMGroup`。可以立即用于群资料页；收到加入群组事件后，再按 `groupID` 合并已加入群组列表。完整监听见[群组概览](/sdk/harmony/group/overview-group)。
