批量删除好友申请记录。

```ts
await OpenIMSDK.deleteFriendRequests([
  { fromUserID, toUserID },
]);
```

## 参数说明

数组中的每一项包含以下字段：

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `fromUserID` | `string` | 是 | 申请发起人的用户 ID。 |
| `toUserID` | `string` | 是 | 申请接收人的用户 ID。 |

## 返回结果

调用完成后，指定的好友申请记录已被删除。

删除记录不等于拒绝申请，也不会影响已建立的好友关系。记录删除会触发 `OnFriendApplicationDeleted` 事件通知。客户端应以申请记录中的 `fromUserID` 与 `toUserID` 复合维度从好友申请列表中移除对应项。完整事件监听说明见[获取收到的好友申请](/sdk/react-native/user/friend-applications/get-friend-application-list-as-recipient)。
