---
title: '设置群成员禁言'
description: '设置或解除指定群成员的禁言状态。'
sourcePath: '/sdk/harmony/group/managing-group-members/change-group-member-mute'
---

```ts
import sdk, { ChangeGroupMemberMuteReq } from '@openimsdk/imsdk';

const request: ChangeGroupMemberMuteReq = {
  groupID: groupID,
  userID: targetUserID,
  mutedSeconds: 3600,
};
await sdk.changeGroupMemberMute(request);
```

`mutedSeconds` 的单位为秒，传 `0` 解除禁言。群主可以禁言管理员和普通成员；管理员只能禁言普通成员，最终权限由 OpenIMServer 校验。接口调用成功后，SDK 会触发群成员资料变更事件；客户端收到通知后根据 `groupID:userID` 更新该成员的 `muteEndTime` 禁言截止时间，完整监听配置请参考[分页查询群成员](/sdk/harmony/group/retrieving-group-members/get-group-member-list)。
