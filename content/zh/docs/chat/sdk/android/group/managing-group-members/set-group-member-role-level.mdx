设置指定群成员的群内角色等级。群主可以通过此接口将普通成员设为管理员，或撤销管理员身份。若需要转让群主，请使用[转让群主](/sdk/android/group/managing-group-members/transfer-group-owner)。

```java
SetGroupMemberInfo update = new SetGroupMemberInfo();
update.setGroupID("group_123");
update.setUserID("user_b");
update.setRoleLevel(GroupRole.ADMIN);

OpenIMClient.getInstance().groupManager.setGroupMemberInfo(
    update,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 角色修改成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理修改失败
        }
    }
);
```

## 角色枚举说明

`roleLevel` 取值可使用 `GroupRole` 中定义的常量：

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `GroupRole.MEMBER` | `20` | 普通群成员。 |
| `GroupRole.ADMIN` | `60` | 群管理员，具备成员管理、禁言等权限。 |

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupMemberInfo` | `SetGroupMemberInfo` | 是 | 群成员资料修改对象，必须设置 `groupID`、成员 `userID` 以及新的角色常量 `roleLevel`。 |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |

## 返回结果

成功回调中的 `data` 返回确认信息。

角色变更成功后，群内成员端随后将收到 `onGroupMemberInfoChanged` 事件通知，返回更新后的 `GroupMembersInfo`。客户端应以 `groupID:userID` 为标识更新成员权限与展示角标；完整监听见[群组概览](/sdk/android/group/overview-group)。
