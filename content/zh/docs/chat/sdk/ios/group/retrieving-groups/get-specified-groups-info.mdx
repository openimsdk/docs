已知群组 `groupID` 时，可以按需批量查询对应的群详细资料快照：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupsID` | `NSArray<NSString *> *` | 待查询的群组 ID 列表。 |

```objc
[[OIMManager manager] getSpecifiedGroupsInfo:@[@"group_1001", @"group_1002"]
                                   onSuccess:^(NSArray<OIMGroupInfo *> *groups) {
                                       [groupStore mergeGroups:groups];
                                   }
                                   onFailure:^(NSInteger code, NSString *message) {
                                       NSLog(@"getSpecifiedGroupsInfo failed: %ld %@", (long)code, message);
                                   }];
```

状态以 `groupID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回匹配的群组资料数组 `NSArray<OIMGroupInfo *> *`。查询单个群组时传入单元素数组并读取首项；若返回空数组则表示未查到匹配的群组。

该查询仅返回调用时刻的群资料快照，不会触发群组 delegate 回调。公开群发现或跨业务目录检索建议由业务服务端提供；群资料后续的增量更新由[群组概览](/sdk/ios/group/overview-group)中说明的群组监听器接收，并通过 `groupID` 合并更新本地群状态。
