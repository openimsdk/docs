当用户离开聊天界面、切换会话或编辑内容发生变更时，可调用 `setConversationDraft()` 保存对应会话的未发送草稿。参数需传入目标会话 `conversationID` 和草稿文本 `draftText`。

在输入过程中，建议在界面本地维护输入框状态并做防抖处理；在用户离开页面、切出聊天窗口或切换会话时再提交一次最新草稿，避免频繁写入 SDK。

```ts
await openimsdk.setConversationDraft(
  {
    conversationID,
    draftText: editorValue,
  }
);
```

清空草稿时传入空字符串：

```ts
await openimsdk.setConversationDraft({
  conversationID,
  draftText: '',
});
```

## 调用后的状态变化

接口调用成功后，草稿内容即已成功保存。随后 SDK 会触发 `SdkEvent.OnConversationChanged` 事件（`data` 为变更后的 `ConversationItem[]` 列表），业务层可根据 `conversationID` 匹配并更新本地会话的 `draftText` 与 `draftTextTime`。

完整的会话事件注册、更新与销毁流程请参考[获取会话列表](/sdk/wasm/conversation/retrieving-conversations/retrieve-conversation-list)。在用户退出登录或切换账号时，建议同时清理前端输入组件的内存草稿状态，防止残留数据影响新账号。
