```ts
const { data: members } =
  await openimsdk.getSpecifiedGroupMembersInfo({
    groupID,
    userIDList,
  });
```

Both `groupID` and `userIDList` are required.

When the Promise resolves, `data` is the matching `GroupMemberItem[]`. For field descriptions, see [List group members](/sdk/wasm/group/retrieving-group-members/get-group-member-list). The returned array is not guaranteed to match the input IDs by position. Because a user's nickname, role, and mute status may differ between groups, cache each record by `groupID:userID`.

This query does not trigger member events. For subsequent incremental updates, see [List group members](/sdk/wasm/group/retrieving-group-members/get-group-member-list).
