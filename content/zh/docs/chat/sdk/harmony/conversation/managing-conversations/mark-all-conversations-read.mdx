---
title: '将全部会话标为已读'
description: '清零当前账号全部本地未读会话的未读数。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/mark-all-conversations-read'
---

```ts
import sdk from '@openimsdk/imsdk';

await sdk.markAllConversationMessageAsRead();
```

Promise 成功表示 SDK 已完成本次找到的全部未读会话处理。它不等同于相关会话事件已经到达，也不保证其他客户端的界面已同步完成。界面仍应在收到会话变更事件后，使用 `conversationID` 更新对应会话的未读数，并通过总未读数事件更新全局角标；完整监听代码请参考[获取会话列表](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list)和[获取消息总未读数](/sdk/harmony/conversation/managing-conversations/get-total-unread-count)。必要时可重新查询会话列表和总未读数进行校准。
