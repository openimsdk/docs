Construct a forward message referencing an existing message:

```ts
const message = await OpenIMSDK.createForwardMessage(sourceMessage);
```

## Parameters

Supply `sourceMessage` as the complete `MessageItem` object of the message being forwarded.

## Return value

A resolved Promise returns a newly created `MessageItem` ready to be dispatched.

This method builds the message structure strictly in client memory; it does not dispatch messages to the server or trigger lifecycle events. After initialization, invoke [Send message](/sdk/react-native/message/sending-messages/send-message) to deliver it to a target conversation. To bundle multiple messages into a single combined forwarded card, see [Create merger message](/sdk/react-native/message/creating-messages/create-merger-message).
