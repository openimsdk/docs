---
title: '解散群组'
description: '由群主解散指定群组。'
sourcePath: '/sdk/uniapp/group/dismiss-group'
---

只有群主可以调用 `dismissGroup()`。解散会影响群内所有成员，不同于删除、隐藏或清空当前账号的会话。

```uts
import { dismissGroup } from '@/uni_modules/unix-openim-sdk'

await dismissGroup(groupID)
```

`groupID` 是要解散的群组 ID。Promise 成功表示 SDK 已完成解散请求；相关客户端收到 `onGroupDismissed()` 后，应按 `groupID` 将群组标记为已解散，并关闭继续管理成员或发送消息的入口。完整监听见[群组概览](/sdk/uniapp/group/overview-group)。

会话是否保留属于会话领域。群组事件处理器不应直接删除会话或历史消息。
