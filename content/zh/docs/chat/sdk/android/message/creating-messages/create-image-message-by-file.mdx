基于本地文件系统的绝对路径（例如从相册选取或相机拍摄生成的本地文件路径）创建图片消息对象。调用[发送消息](/sdk/android/message/sending-messages/send-message)时，SDK 会自动读取本地文件并执行上传。

```java
String absolutePath = "/storage/emulated/0/Pictures/chat_image.png";

Message message = OpenIMClient.getInstance().messageManager.createImageMessageFromFullPath(absolutePath);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `imagePath` | `String` | 是 | 本地设备中图片文件的绝对文件路径。必须保证应用具备读取权限。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.PICTURE`。

本接口仅在本地生成待发送的消息实例。构建完成后，请调用[发送消息](/sdk/android/message/sending-messages/send-message)投递至单聊或群聊。
