清空指定会话中的全部历史消息。该操作仅清除消息记录，保留会话本身及其设置。

```ts
await OpenIMSDK.clearConversationAndDeleteAllMsg(conversationID);
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 要清空消息的会话 ID。 |

## 返回结果

调用完成后，清空会话消息请求已处理完成。

Promise 成功表示历史消息已清空。会话的最新消息、未读数与摘要状态发生变化时，会触发 `OnConversationChanged` 事件；客户端应使用 `conversationID` 定位目标会话，并清空本地渲染的该会话消息。完整监听方式见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。
