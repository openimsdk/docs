---
title: '拒绝入群申请'
description: '拒绝指定用户加入群组。'
sourcePath: '/sdk/harmony/group/group-applications/refuse-group-application'
---

```ts
import sdk, { ApprovalStatus, HandleGroupApplicationReq } from '@openimsdk/imsdk';

const request: HandleGroupApplicationReq = {
  groupID: application.groupID,
  fromUserID: application.userID,
  handledMsg: '暂不接受该申请',
  status: ApprovalStatus.Rejected,
};
await sdk.handleGroupApplication(request);
```

Promise 成功表示拒绝请求已经完成。收到申请拒绝事件后，再使用 `groupID:userID` 更新对应记录；完整监听见[获取收到的入群申请](/sdk/harmony/group/group-applications/get-group-application-list-as-recipient)。
