---
title: '创建文件消息'
description: '使用相对于 SDK 初始化数据目录的路径创建文件消息。'
sourcePath: '/sdk/android/message/creating-messages/create-file-message'
---

```java
Message message = OpenIMClient.getInstance().messageManager
    .createFileMessage(filePath, fileName);
```

文件应位于 SDK 初始化时配置的数据目录内，`filePath` 传入相对于该目录的路径，`fileName` 用于接收端展示。本方法只创建待发送对象。
