---
title: '获取已加入群组数量'
description: '查询当前账号已加入的群组总数。'
sourcePath: '/sdk/harmony/group/retrieving-groups/get-joined-group-count'
---

```ts
import sdk, { GetJoinedGroupCountResp } from '@openimsdk/imsdk';

const response: GetJoinedGroupCountResp = await sdk.getJoinedGroupCount();
setJoinedGroupCount(response.count);
```

`count` 是查询时当前账号已加入的群组数量。该查询本身不会触发事件；收到群组加入或退出事件时可先进行增量更新，完整监听配置请参考[群组概览](/sdk/harmony/group/overview-group)，并在连接恢复后重新调用本接口校准。
