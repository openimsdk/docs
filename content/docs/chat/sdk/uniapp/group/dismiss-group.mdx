```uts
import { dismissGroup } from '@/uni_modules/unix-openim-sdk'

await dismissGroup(groupID)
```

This owner-only destructive action ends the group according to server policy. Confirm explicitly and process `onGroupDismissed`; do not equate local navigation with successful dismissal.
