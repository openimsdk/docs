---
title: '清空会话消息'
description: '保留会话入口并清空当前账号保存的会话消息。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/clear-conversation-messages'
---

```ts
import sdk, { ClearConversationAndDeleteAllMsgReq } from '@openimsdk/imsdk';

const request: ClearConversationAndDeleteAllMsgReq = {
  conversationID: conversationID,
};
await sdk.clearConversationAndDeleteAllMsg(request);
```

Promise 成功后清空当前会话的消息列表。会话入口仍保留，SDK 会触发会话变更事件更新该会话的最后一条消息、摘要及未读数；客户端收到通知后根据 `conversationID` 更新对应会话，完整监听配置请参考[获取会话列表](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list)。如需同时移除会话入口，请参考[删除会话及消息](/sdk/harmony/conversation/managing-conversations/delete-conversation-with-messages)。
