更新群组的基础展示信息（群名称、群简介和群头像）。群公告、入群验证与权限设置属于独立能力，不建议在修改群基础资料时混合提交：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `groupName` | `String?` | 否 | 新的群名称。 |
| `introduction` | `String?` | 否 | 新的群简介。 |
| `faceURL` | `String?` | 否 | 新的群头像 URL。 |

```dart
await OpenIM.iMManager.groupManager.setGroupInfo(
  GroupInfo(
    groupID: groupID,
    groupName: groupName.trim(),
    introduction: introduction.trim(),
    faceURL: faceURL,
  ),
);
```

## 返回结果

Future 成功表示服务端已接受并更新群资料。

SDK 会通过群资料变更通知同步最新资料。客户端以 `groupID` 为合并标识更新本地群资料缓存，完整事件监听请参考[群组概览](/sdk/flutter/group/overview-group)；需要主动拉取最新数据校验时，可调用[查询指定群组资料](/sdk/flutter/group/retrieving-groups/get-specified-groups-info)。
