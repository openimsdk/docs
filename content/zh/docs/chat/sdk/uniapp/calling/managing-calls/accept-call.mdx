收到邀请后，先校验当前 session、请求麦克风/摄像头权限，再调用 `signalingAccept()`。

```uts
import { signalingAccept } from '@/uni_modules/unix-openim-sdk'

const result = await signalingAccept({ invitation })
```

返回的 `token`、`roomID`、`liveURL` 均可选且敏感，只保存在内存中。权限失败时不得发送 accept；应按产品策略拒绝或提示用户。

Promise 成功与对方接受事件、媒体真正连接是不同阶段。
