使用 `createMergerMessage()` 创建包含多条消息的合并转发消息。

```ts
const message = await OpenIMSDK.createMergerMessage({
  messageList: selectedMessages,
  title: '项目讨论记录',
  summaryList: ['小王：发布计划已确认', '小李：我会跟进测试'],
});
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `messageList` | `MessageItem[]` | 是 | 要合并的消息列表。 |
| `title` | `string` | 是 | 合并消息的标题。 |
| `summaryList` | `string[]` | 是 | 合并消息展示的摘要列表。 |

调用后返回待发送的 `MessageItem`。摘要内容应符合当前会话的展示与隐私规则。
