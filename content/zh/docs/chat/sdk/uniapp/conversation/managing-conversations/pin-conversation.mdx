---
title: '置顶或取消置顶会话'
description: '设置指定会话在当前用户会话列表中的置顶状态。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/pin-conversation'
---

`isPinned` 只改变当前用户会话列表中的排序状态，不影响其他群成员或单聊对方。

```uts
import { setConversation } from '@/uni_modules/unix-openim-sdk'

await setConversation({
  conversationID,
  isPinned: true,
})
```

传入 `true` 置顶，传入 `false` 取消置顶。Promise 成功表示本次设置请求已成功返回，不表示会话变化事件已经到达。收到 `onConversationChanged()` 后，按 `conversationID` 更新对应会话；需要校准状态时重新查询会话。完整监听见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。
