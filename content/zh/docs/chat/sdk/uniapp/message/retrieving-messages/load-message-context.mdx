`fetchSurroundingMessages()` <span className="enterprise-field-badge">商业版</span> 围绕完整锚点消息读取前后文。

```uts
import { fetchSurroundingMessages } from '@/uni_modules/unix-openim-sdk'

const result = await fetchSurroundingMessages({
  startMessage: targetMessage,
  viewType: 0,
  before: 20,
  after: 20,
})
```

`viewType` 使用产品/合同定义值。结果与实时事件可能重复，按 `clientMsgID` 去重并保持时间顺序。不要用只包含 ID 的伪消息作为锚点。
