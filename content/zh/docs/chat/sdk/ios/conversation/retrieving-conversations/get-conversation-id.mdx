title: '生成会话 ID'
description: '使用 iOS SDK 按聊天目标计算会话 ID。'

---

只需要会话 ID 时调用同步方法，不要在应用层自行拼接：

```objc
NSString *conversationID = [[OIMManager manager]
    getConversationIDBySessionType:OIMConversationTypeC2C
                          sourceID:targetUserID];
```

单聊的 `sourceID` 是对方用户 ID，群聊是群组 ID并使用 `OIMConversationTypeGroup`。返回值为空时不要继续执行会话操作。该方法不返回 `OIMConversationInfo`，也不触发 delegate。
