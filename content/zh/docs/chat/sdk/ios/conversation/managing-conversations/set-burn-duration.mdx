配置单聊私聊会话中消息的阅后即焚倒计时时长：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `conversationID` | `NSString *` | 目标会话 ID。 |
| `duration` | `NSInteger` | 阅后即焚时长（单位：秒）。 |

```objc
[[OIMManager manager] setConversationBurnDuration:@"c2c_user1002"
                                         duration:30
                                        onSuccess:^(NSString * _Nullable data) {
                                            NSLog(@"setConversationBurnDuration success");
                                        }
                                        onFailure:^(NSInteger code, NSString *message) {
                                            NSLog(@"setConversationBurnDuration failed: %ld %@", (long)code, message);
                                        }];
```

状态以 `conversationID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回操作结果。

操作成功后，会话属性更新会通过 `onConversationChanged:` 事件广播，客户端按 `conversationID` 更新对应会话的 `burnDuration` 属性。

该设置仅控制私聊阅后即焚的消息销毁倒计时，开启与关闭模式请参考[开启或关闭阅后即焚](/sdk/ios/conversation/managing-conversations/set-private-chat)；如需配置服务端全量历史消息定期清理，请参考[设置服务端消息删除周期](/sdk/ios/conversation/managing-conversations/set-message-destruct-time)。会话列表监听配置参见[获取会话列表](/sdk/ios/conversation/retrieving-conversations/retrieve-conversation-list)。
