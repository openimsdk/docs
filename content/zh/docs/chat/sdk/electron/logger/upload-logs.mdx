Electron FFI 提供 `uploadLogs()`，用于把原生侧已落盘的诊断日志上传到当前 OpenIMServer 配置的日志收集链路。浏览器侧的日志配置见 [WASM 日志](/sdk/wasm/logger)；WASM 包不提供对等的 `uploadLogs()`。

`uploadLogs()` 上传原生侧已经生成的日志。`ex` 可用于附加本次上传的说明或诊断标记。

## 上传日志

### 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `line` | `number` | 是 | 本次上传读取的日志行数或行范围配置，按 Electron FFI SDK 约定填写。 |
| `cancelID` | `string` | 否 | 取消标识；未传时由 SDK 使用默认值。 |
| `ex` | `string` | 否 | 附加到本次上传的扩展说明；没有时可不传或传空字符串。 |

```ts
await openimsdk.uploadLogs({
  line: 2000,
  ex: 'desktop-diag-session',
});
```

## 调用结果

`uploadLogs()` 的 Promise 成功表示本次上传请求已完成。它不会修改会话、消息或用户资料，也不会触发业务领域事件。上传失败时可结合 `errCode`、`errMsg` 与 OpenIMServer 侧日志定位原因。
