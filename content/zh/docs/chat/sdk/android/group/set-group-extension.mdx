---
title: '设置群组扩展字段'
description: '通过 GroupInfo.ex 保存应用定义的群组扩展数据。'
sourcePath: '/sdk/android/group/set-group-extension'
---

`GroupInfo.ex` 是完整字符串，SDK 不会合并 JSON；提交新值会替换原有内容。

```java
GroupInfo update = new GroupInfo();
update.setGroupID(groupID);
update.setEx("{\"projectCode\":\"mobile\",\"archived\":false}");

OpenIMClient.getInstance().groupManager.setGroupInfo(update, new OnBase<String>() {
    @Override public void onSuccess(String data) { /* 请求已完成。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
});
```

成功回调表示扩展字段更新请求已完成，不表示其他客户端界面已经更新。`onGroupInfoChanged` 返回更新后的 `GroupInfo`；按 `groupID` 替换群资料中的 `ex`。完整 listener 注册见[群组概览](/sdk/android/group/overview-group)。
