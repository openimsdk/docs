Control how the system processes incoming friend requests sent to the current account:

```ts
await OpenIMSDK.setSelfInfo({
  addFriendPermission: AddFriendPermission.AddFriendAllowed,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `addFriendPermission` | `AddFriendPermission` | Yes | Friend verification policy option. |

`AddFriendPermission` option values:

| Enum value | Value | Description |
| --- | --- | --- |
| `AddFriendPermission.AddFriendAllowed` | `0` | Anyone can send a request; manual approval is required. |
| `AddFriendPermission.AddFriendAllowedNoReview` | `1` | Automatic acceptance without review; friendship is created immediately. |
| `AddFriendPermission.AddFriendDenied` | `2` | Disallow friend requests from other users entirely. |

## Return value

A resolved Promise confirms that the friend permission setting was persisted on the server.

This setting applies to subsequent incoming friend requests; it does not alter existing friendships or auto-approve pending applications. Updates trigger the `OnSelfInfoUpdated` event. Reconcile local state by `userID` and update `addFriendPermission`. For event listeners, see [Update current user profile](/sdk/react-native/user/profile/set-self-info).
