Pass a valid `groupID`, the applicant's `userID`, and an optional `handleMsg`. A successful `Future` means that the server completed the handling request. Do not fabricate a member record locally.

```dart
await OpenIM.iMManager.groupManager.acceptGroupApplication(
  groupID: groupID,
  userID: applicantUserID,
  handleMsg: 'Welcome to the group',
);
```
