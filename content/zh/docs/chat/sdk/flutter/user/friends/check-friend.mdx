---

```dart
final checks = await OpenIM.iMManager.friendshipManager.checkFriend(
  userIDList: ['user_a', 'user_b'],
);
```

Future 返回 `List<FriendshipInfo>`。每项的 `userID` 标识目标，`result == 1` 表示目标是好友且不在黑名单中。本方法未定义其他 `result` 值的业务含义。

该方法只返回调用时的好友关系，不触发好友 listener。需要备注、头像或关系扩展字段时使用[查询指定好友资料](/sdk/flutter/user/friends/get-friends-info)。
