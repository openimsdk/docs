调用 `deleteFriend()` 删除当前用户与指定用户的好友关系。

```ts
await OpenIMSDK.deleteFriend(friendUserID);
```

`friendUserID` 是要删除的好友用户 ID。删除好友后会触发 `OnFriendDeleted` 事件，事件携带被删除好友的信息；好友列表的监听方式见[分页获取好友列表](/sdk/react-native/user/friends/get-friend-list-page)。
