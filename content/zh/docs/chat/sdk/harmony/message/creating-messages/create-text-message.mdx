---
title: '创建文本消息'
description: '根据文本内容创建一条待发送消息。'
sourcePath: '/sdk/harmony/message/creating-messages/create-text-message'
---

调用前应在业务层处理空白、长度和内容规则。

```ts
import sdk, { CreateTextMessageReq, CreateTextMessageResp } from '@openimsdk/imsdk';

const text = input.trim();
if (text.length > 0) {
  const request: CreateTextMessageReq = { text: text };
  const response: CreateTextMessageResp = await sdk.createTextMessage(request);
  const message = response.message;
}
```

Promise 成功只返回待发送的 `IMMessage`，不会写入 OpenIMServer，也不会触发新消息事件。下一步将该对象交给[发送消息](/sdk/harmony/message/sending-messages/send-message)。
