群组查询只返回调用时的群资料，不会触发群组 listener。公开群发现、跨业务目录和复杂权限过滤应由业务后端提供；SDK 查询面向已知群组和当前账号已加入的群组。

```dart
final groups = await OpenIM.iMManager.groupManager.getGroupsInfo(
  groupIDList: groupIDs,
);
```

Future 成功返回匹配的 `List<GroupInfo>`。读取单个群组时仍传列表，并检查结果是否为空；之后的变化统一按[群组概览](/sdk/flutter/group/overview-group)的规则合并。
