在搜索结果定位、引用回复跳转或通知点击打开等场景下，可调用 `findMessageList()` 按照会话 ID 与客户端消息 ID（`clientMsgID`）批量检索本地已缓存的完整消息对象。

## 参数说明

`findMessageList()` 接收查询条件数组，每一项结构如下：

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `items[].conversationID` | `string` | 是 | 目标消息所属的会话 ID。 |
| `items[].clientMsgIDList` | `string[]` | 是 | 要在该会话中查找的消息 ID。 |

```ts
const { data: result } = await openimsdk.findMessageList([
  {
    conversationID,
    clientMsgIDList: [clientMsgID],
  },
]);

const items = result.findResultItems ?? result.searchResultItems ?? [];
const targetMessage = items[0]?.messageList?.[0];
```

接口调用成功后，返回的 `data` 为 `SearchMessageResult` 对象，业务层主要读取其中的 `findResultItems` 数组。完整的字段定义请参考[搜索消息](/sdk/wasm/message/searching-messages/search-messages)。

该接口支持同时传入多个会话的检索条件。在处理返回结果时，请按各分组结果项中的 `conversationID` 与消息对象的 `clientMsgID` 映射匹配。若本地尚未同步该消息或消息已被删除，结果列表可能为空。该查询为本地只读操作，不会触发任何事件。
