查询指定用户在目标会话中的当前输入状态。

```ts
const platformIDs = await OpenIMSDK.getInputStates({
  conversationID,
  userID,
});

const isTyping = platformIDs.length > 0;
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 目标会话 ID。 |
| `userID` | `string` | 是 | 要查询输入状态的目标用户 ID。 |

## 返回结果

调用后返回处于输入状态的平台 ID 数组 `number[]`；若返回空数组，表示该用户当前未在任何设备处于输入状态。客户端可据此显示或隐藏正在输入提示。实时监听输入状态请参考[更新输入状态](/sdk/react-native/message/composing-messages/change-input-states)中的 `OnInputStatusChanged` 事件说明。
