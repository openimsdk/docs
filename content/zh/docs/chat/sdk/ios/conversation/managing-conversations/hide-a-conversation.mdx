临时隐藏指定会话在聊天列表中的入口，不删除好友关系、不退出群组亦不清空历史聊天记录：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `conversationID` | `NSString *` | 待隐藏的目标会话 ID。 |

```objc
[[OIMManager manager] hideConversation:@"c2c_user1002"
                             onSuccess:^(NSString * _Nullable data) {
                                 NSLog(@"hideConversation success");
                             }
                             onFailure:^(NSInteger code, NSString *message) {
                                 NSLog(@"hideConversation failed: %ld %@", (long)code, message);
                             }];
```

状态以 `conversationID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回操作结果。

操作成功后，客户端可立即从本地展示列表中移除对应 `conversationID` 的会话行。后续如果收到该会话的新消息或执行增量同步，隐藏的会话会自动重新出现在会话列表中。

会话监听配置参见[获取会话列表](/sdk/ios/conversation/retrieving-conversations/retrieve-conversation-list)。若需一次性隐藏当前账号的所有会话入口，请参考[隐藏全部会话](/sdk/ios/conversation/managing-conversations/hide-all-conversations)。
