设置指定会话的消息接收和免打扰模式，例如正常提醒、仅接收消息不弹通知或屏蔽消息。

```java
OpenIMClient.getInstance().conversationManager.setConversationRecvMessageOpt(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    conversationID,
    2
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `conversationID` | `String` | 是 | 目标会话的唯一标识。 |
| `opt` | `int` | 是 | 消息接收模式枚举值。 |

### 消息接收模式

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `ReceiveMessageOpt.Normal` | `0` | 正常接收消息并触发本地通知与离线推送。 |
| `ReceiveMessageOpt.NotReceive` | `1` | 完全不接收该会话的消息，也不发送通知。 |
| `ReceiveMessageOpt.NotNotify` | `2` | 正常接收消息并在会话列表显示，但不触发通知与离线推送（免打扰）。 |

## 返回结果

成功回调表示服务端已记录当前会话的接收策略。该设置会在该用户的各端保持同步。

配置生效后，SDK 会触发 `OnConversationListener.onConversationChanged` 事件；客户端收到通知后应根据 `conversationID` 更新对应会话的 `recvMsgOpt` 属性并刷新免打扰图标，完整监听配置请参考[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。若需配置账号级别的全局免打扰，请参考[设置全局消息接收方式](/sdk/android/user/user-profile/set-global-message-reception)。
