---
title: '获取发出的入群申请'
description: '使用 getSendGroupApplicationList 分页读取当前用户发出的入群申请。'
sourcePath: '/sdk/android/group/group-applications/get-group-application-list-as-applicant'
---

使用 `GetGroupApplicationListAsApplicantReq` 设置分页和筛选条件，再调用 `getSendGroupApplicationList()`。

```java
GetGroupApplicationListAsApplicantReq request = new GetGroupApplicationListAsApplicantReq(0, 20);
OpenIMClient.getInstance().groupManager.getSendGroupApplicationList(
    new OnBase<List<GroupApplicationInfo>>() {
        @Override public void onSuccess(List<GroupApplicationInfo> items) { /* items 是当前页申请记录。 */ }
        @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
    }, request);
```

申请被同意后，通过 `onJoinedGroupAdded` 接收加入群组通知。
