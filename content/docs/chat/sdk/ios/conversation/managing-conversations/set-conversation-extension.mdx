```objc
NSString *ex = @"{\"category\":\"work\"}";
[[OIMManager manager] setConversationEx:conversationID
                                     ex:ex
                              onSuccess:nil
                              onFailure:nil];
```

`ex` is replaced as a complete string. The SDK does not merge JSON on behalf of the application. Before updating it, parse the previous value and preserve fields owned by other parts of your application. After success, merge the latest conversation through `onConversationChanged:`.
