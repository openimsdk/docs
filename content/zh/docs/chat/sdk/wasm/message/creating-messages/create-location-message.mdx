## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `description` | `string` | 是 | 位置名称或地址描述。 |
| `longitude` | `number` | 是 | 经度。 |
| `latitude` | `number` | 是 | 纬度。 |

```ts
const { data: message } = await openimsdk.createLocationMessage({
  description: '上海市浦东新区',
  longitude: 121.4737,
  latitude: 31.2304,
});
```

经纬度数值由业务层调用定位 API 或通过地图选择器获取。发送端与接收端应约定统一的坐标体系（如 WGS84 或 GCJ02），避免因地图坐标系差异导致位置偏移。接口调用成功后返回待发送的 `MessageItem` 对象，后续需通过 [发送消息](/sdk/wasm/message/sending-messages/send-message) 发送。
