设置或清除指定会话的标记状态。标记状态属于当前登录账号，会话标记后可用于分类展示或归入标记分组。

```ts
await OpenIMSDK.setConversation({
  conversationID,
  isMarked: true,
});
```

将 `isMarked` 设置为 `false` 可取消标记。会话分组的查询和管理方式见[会话分组概览](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups)。

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 要设置的会话 ID。 |
| `isMarked` | `boolean` | 否 | `true` 标记会话，`false` 取消标记。 |

## 返回结果

调用完成后，会话的标记状态已更新。

更新成功后会触发 `OnConversationChanged` 事件；客户端应使用 `conversationID` 定位目标会话，并合并最新的 `isMarked` 状态。完整监听方式见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。
