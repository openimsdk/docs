Cancel active presence subscriptions for designated users:

```ts
await OpenIMSDK.unsubscribeUsersStatus(userIDs);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `userIDList` | `string[]` | Yes | Array of user IDs to unsubscribe from. |

## Return value

A resolved Promise confirms that the subscription was removed on the server.

Unsubscribe when paging away, clearing search results, unmounting components, or logging out. Once unsubscribed, presence events for these users cease arriving.
