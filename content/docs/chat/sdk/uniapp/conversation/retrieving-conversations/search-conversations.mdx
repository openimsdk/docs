```uts
import { searchConversation } from '@/uni_modules/unix-openim-sdk'

const result = await searchConversation('project')
renderConversations(result?.conversations ?? [])
```

This searches local conversation metadata. Reject an empty keyword in the UI, deduplicate by `conversationID`, and do not treat local results as an authoritative server-wide search.
