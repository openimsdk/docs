Decline a friend application sent by another user with an optional refusal remark:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `userID` | `String` | Yes | User ID of the applicant who submitted the friend request. |
| `handleMsg` | `String` | No | Optional remark explaining the reason for declining. |

## Code example

```dart
await OpenIM.iMManager.friendshipManager.refuseFriendApplication(
  userID: applicantUserID,
  handleMsg: 'Declined for now',
);
```

## Return value

A successful `Future` indicates that the server has processed and recorded the application rejection.

## State changes after the call

Upon success, update the applicant's record to rejected using their `userID` as the key. Connected devices receive friend application update events. For complete application status listening and state merging logic, see [Get friend application list as recipient](/sdk/flutter/user/friend-applications/get-friend-application-list-as-recipient).
