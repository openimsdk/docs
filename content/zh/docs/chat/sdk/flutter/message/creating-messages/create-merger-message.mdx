将多条消息打包为合并转发卡片，构建待发送的合并消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `messageList` | `List<Message>` | 是 | 需合并转发的消息对象列表（应为已发送成功的有效消息）。 |
| `title` | `String` | 是 | 合并消息卡片的标题（例如“群聊的聊天记录”）。 |
| `summaryList` | `List<String>` | 是 | 卡片在会话列表中展示的前几条摘要文本列表。 |

```dart
final message = await OpenIM.iMManager.messageManager.createMergerMessage(
  messageList: selectedMessages,
  title: '聊天记录',
  summaryList: summaries,
);
```

待合并的消息应来自真实的会话记录，摘要列表建议按照消息时间顺序截取前 2~4 条文本。

## 返回结果

Future 成功返回待发送的合并消息对象（`Message`），其合并数据保存在 `mergeElem` 中。

SDK 会为合并消息生成全新的客户端消息标识 `clientMsgID`，原始消息不会受到任何改动。创建操作仅在本地组装消息数据，不会自动执行网络发送，也不会触发新消息事件通知。构建完成后，需将返回的 `Message` 实例传给[发送消息](/sdk/flutter/message/sending-messages/send-message)投递至单聊或群聊会话。
