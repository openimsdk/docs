接入 OpenIM HarmonyOS SDK 前，需要准备可访问的 OpenIMServer、与用户 ID 匹配的登录 Token、与当前版本匹配的 HAR，以及能够构建 HarmonyOS 原生模块的开发环境。

## 准备服务地址

| 字段      | 说明                                               |
| --------- | -------------------------------------------------- |
| `apiAddr` | OpenIMServer HTTP API 地址，例如 `https://api.example.com`。 |
| `wsAddr`  | OpenIMServer WebSocket 地址，例如 `wss://ws.example.com`。  |

应从目标手机、平板和 2in1 设备验证 DNS、TLS 证书、防火墙、反向代理和 WebSocket 升级，不能只在开发电脑上验证地址。

## 准备用户与 Token

业务服务为当前账号取得对应的 `userID` 与 Token，再将两者交给 App 登录。服务端接入方式见[准备使用 Platform API](/platform-api/prepare-to-use-api)和[获取用户 Token](/platform-api/auth/tokens/get-user-token)。

## 准备开发环境

- DevEco Studio `6.1.1`。
- HarmonyOS SDK `6.1.1(24)` 及配套 Hvigor、OHPM 工具。
- 与 `@openimsdk/imsdk@1.0.2` 对应的 `openimsdk-harmony-1.0.2.har`。
- 面向 `phone`、`tablet` 或 `2in1` 的应用模块。

不要同时加入另一版本的 OpenIM HAR 或手工复制其中的 SO 文件，否则可能出现重复原生模块、ABI 不一致或 ArkTS 声明与二进制不匹配。

## 准备权限和目录

SDK 需要 `ohos.permission.INTERNET`。如果宿主应用自行监听 NetworkKit 网络变化并调用 `networkStatusChanged()`，还需要声明 `ohos.permission.GET_NETWORK_INFO`。

初始化前为 SDK 准备应用私有目录：

- `dataDir` 与 `dbPath` 用于本地数据库和同步数据。
- `logFilePath` 用于 SDK 日志。
- 三个路径都必须稳定、可写，不能使用临时缓存目录或共享外部目录。

## 发布前检查

- HAR 同时包含目标设备需要的 ABI。
- 真机可以访问 API、WebSocket 和消息媒体资源域名。
- `userID` 与 Token 相互匹配，并且可以完成登录。
- 应用已经处理前后台切换、网络变化、Token 失效、账号切换和多端互斥登录。
- 退出登录与进程级 SDK 销毁是两个独立阶段，不会因页面或窗口关闭反复调用 `unInitSDK()`。

准备完成后继续阅读[工程与设备接入](/sdk/harmony/getting-started/environment-specific-implementation)。
