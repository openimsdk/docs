Validate or replace a friend remark.

## HTTP request
```http
POST {WEBHOOK_ADDRESS}/callbackBeforeSetFriendRemarkCommand
```

## Request body
| Property | Type | Description |
| --- | --- | --- |
| callbackCommand | string | `callbackBeforeSetFriendRemarkCommand`. |
| ownerUserID | string | Relationship owner |
| friendUserID | string | Friend user ID |
| remark | string | Proposed remark |

## Response
Return the common before-event response from [Webhooks overview](/platform-api/webhooks/overview). Use `nextCode: 1` to reject the operation.

## Processing rules
- Configuration key: `beforeSetFriendRemark`.
- OpenIM waits synchronously; timeout behavior follows `failedContinue`.
- The response may return `remark` to replace the pending value.
