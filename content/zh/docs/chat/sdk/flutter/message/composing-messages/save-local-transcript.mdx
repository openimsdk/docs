将音频识别出的文字结果保存至本地语音消息的 `soundElem.text` 中，以便在重新进入会话时直接展示转写文本：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 消息所属会话 ID。 |
| `clientMsgID` | `String` | 是 | 目标消息的客户端消息 ID。 |
| `message` | `Message` | 是 | 写入转写内容后的完整消息对象。 |

```dart
message.soundElem!.text = SoundText(text: transcript, translate: previousText?.translate);
await OpenIM.iMManager.messageManager.setMessageLocalContent(
  conversationID: conversationID,
  clientMsgID: message.clientMsgID!,
  message: message,
);
```

## 返回结果

Future 成功表示转写文本已成功写入当前设备的本地数据库，本地可通过客户端消息标识 `clientMsgID` 更新界面状态。

该操作仅修改当前设备的本地存储，不会上传到服务端，也不会触发消息事件通知或同步至对端设备。音频转文字的前置识别流程请参考[识别音频文字](/sdk/flutter/message/composing-messages/transcribe-audio)。
