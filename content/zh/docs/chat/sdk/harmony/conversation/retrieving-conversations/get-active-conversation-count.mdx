---
title: '获取活跃会话数量'
description: '查询当前账号本地活跃会话的数量。'
sourcePath: '/sdk/harmony/conversation/retrieving-conversations/get-active-conversation-count'
---

```ts
import sdk, { GetActiveConversationCountResp } from '@openimsdk/imsdk';

const response: GetActiveConversationCountResp = await sdk.getActiveConversationCount();
showActiveConversationCount(response.count);
```

`count` 是 SDK 当前本地状态中的活跃会话数量，不等同于已加入群组数、未读会话数或当前分页条目数。查询不会触发事件；列表变化后需要精确值时重新查询。
