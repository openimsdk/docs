---
title: '定期删除服务端消息'
description: '使用 iOS SDK 启用或关闭会话的服务端消息定期删除策略。'
sourcePath: '/sdk/ios/conversation/managing-conversations/set-message-destruct'
---

```objc
[[OIMManager manager] setConversationIsMsgDestruct:conversationID
                                     isMsgDestruct:YES
                                         onSuccess:nil
                                         onFailure:nil];
```

该开关控制是否定期删除会话的服务端消息，不是私聊阅后即焚。删除周期由独立方法设置；应用需要分别保存开关和周期请求的结果。成功后通过 `onConversationChanged:` 合并状态。
