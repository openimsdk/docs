---
title: '设置成员资料查看权限'
description: '通过 GroupInfo.lookMemberInfo 设置是否允许通过群组查看成员资料。'
sourcePath: '/sdk/android/group/set-group-member-profile-access'
---

`lookMemberInfo` 使用整数开关：`0` 关闭，`1` 打开。更新时只提交该权限字段和 `groupID`。

```java
GroupInfo update = new GroupInfo();
update.setGroupID(groupID);
update.setLookMemberInfo(1);

OpenIMClient.getInstance().groupManager.setGroupInfo(update, new OnBase<String>() {
    @Override public void onSuccess(String data) { /* 请求已完成。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
});
```

此开关约束通过群组入口获取成员资料的权限，不改变成员已经拥有的用户资料。
