在已知 `roomID` 的场景下，可以调用此方法重新获取进入音视频媒体房间所需的凭证：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `roomID` | `String` | 是 | 目标通话房间 ID。 |

```dart
final credentials = await OpenIM.iMManager.signalingManager
    .signalingGetTokenByRoomID(roomID: roomID);

if (credentials.token?.isNotEmpty == true &&
    credentials.roomID?.isNotEmpty == true) {
  await mediaEngine.join(
    roomID: credentials.roomID!,
    token: credentials.token!,
    liveURL: credentials.liveURL,
  );
}
```

## 返回结果

Future 成功返回 `SignalingCertificate` 对象，包含加入音视频通话房间所需的凭据信息。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `token` | `String?` | 接入媒体引擎所需的房间鉴权凭证。 |
| `roomID` | `String?` | 通话房间 ID。 |
| `liveURL` | `String?` | 媒体流服务器地址。 |
| `busyLineUserIDList` | `List<String>?` | 当前正处于忙线状态的用户 ID 列表。 |

只有当获取到非空的 `token` 和有效房间凭据后，才能调用媒体引擎连接音视频房间。凭证失效或断线重连时，可再次调用本接口重新获取。
