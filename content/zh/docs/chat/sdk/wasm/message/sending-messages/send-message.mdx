调用 `sendMessage()` 可发送由各类消息创建接口构建生成的 `MessageItem` 待发送对象。单聊场景仅需填写 `recvID`，群聊场景仅需填写 `groupID`，另一目标字段传空字符串即可。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `recvID` | `string` | 条件必填 | 单聊时填写接收方用户 ID；群聊时传空字符串。 |
| `groupID` | `string` | 条件必填 | 群聊时填写目标群组 ID；单聊时传空字符串。 |
| `message` | `MessageItem` | 是 | 待发送的消息对象。 |
| `offlinePushInfo` | `OfflinePush` | 否 | 离线推送配置。 |
| `isOnlineOnly` | `boolean` | 否 | 是否只向在线客户端投递；此类消息不进入本地历史。 |

```ts
const { data: sentMessage } = await openimsdk.sendMessage({
  recvID: receiverUserID,
  groupID: '',
  message,
});
```

接口调用成功后，返回的 `data` 为经服务端确认并补充服务端时间戳、序号与状态的 `MessageItem` 对象。前端界面可根据 `clientMsgID` 将本地乐观展示的“发送中”消息替换为已发送状态。完整的数据结构说明请参考[消息概览](/sdk/wasm/message/overview-message)。

接收端客户端将通过新消息事件接收该消息，详情请参考[接收消息](/sdk/wasm/message/receiving-messages/receive-messages)。

如果多媒体资源（如图片、视频、音频、文件）已由业务自身的上传服务上传并获得了公网 URL，建议结合 URL 创建接口使用 `sendMessageNotOss()` 发送，详见[发送已上传的媒体消息](/sdk/wasm/message/sending-messages/send-message-not-oss)。
