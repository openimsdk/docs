用户处理群聊中的提及消息后，调用 `resetConversationGroupAtType()` 重置会话的群组提醒状态。

```ts
await OpenIMSDK.resetConversationGroupAtType(conversationID);
```

## 参数说明

`conversationID` 为要重置提醒状态的群聊会话 ID。

该方法将会话的 `groupAtType` 恢复为普通状态，不用于主动设置“有人提及我”或“提及所有人”等状态。重置群组提醒和[标记会话已读](/sdk/react-native/conversation/managing-conversations/mark-conversation-read)是两个独立操作。

## 返回结果

调用完成后，会话的群组提醒状态已重置。会话列表中的变化通过 `OnConversationChanged` 事件返回，事件监听方式见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。
