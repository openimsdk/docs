在指定群组内搜索群成员。支持按群内昵称与用户 ID 进行关键字检索，适用于快速定位成员或群内提及选人等交互场景。

```java
String groupID = "group_123";
List<String> keywordList = Collections.singletonList("技术");
boolean isSearchUserID = true;
boolean isSearchMemberNickname = true;
int offset = 0;
int count = 20;

OpenIMClient.getInstance().groupManager.searchGroupMembers(
    new OnBase<List<GroupMembersInfo>>() {
        @Override
        public void onSuccess(List<GroupMembersInfo> members) {
            // members 为匹配到的群成员列表
        }

        @Override
        public void onError(int code, String error) {
            // 处理搜索失败
        }
    },
    groupID,
    keywordList,
    isSearchUserID,
    isSearchMemberNickname,
    offset,
    count
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<List<GroupMembersInfo>>` | 是 | 异步请求回调。 |
| `groupID` | `String` | 是 | 目标群组全局唯一 ID。 |
| `keywordList` | `List<String>` | 是 | 搜索关键字列表。空列表或无有效关键字时不应发起搜索。 |
| `isSearchUserID` | `boolean` | 是 | 是否匹配用户 ID：`true` 为匹配，`false` 为不匹配。 |
| `isSearchMemberNickname` | `boolean` | 是 | 是否匹配群内昵称：`true` 为匹配，`false` 为不匹配。 |
| `offset` | `int` | 是 | 分页起始偏移量，首页从 `0` 开始。 |
| `count` | `int` | 是 | 本次获取的最大记录条数。 |

## 返回结果

成功回调返回匹配到的群成员列表 `List<GroupMembersInfo>`。

搜索结果仅反映查询发起时的匹配快照。客户端应以 `groupID:userID` 为标识在搜索结果列表中展示匹配项。
