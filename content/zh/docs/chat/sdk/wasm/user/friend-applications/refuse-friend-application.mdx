---
title: '拒绝好友申请'
description: '拒绝指定用户的好友申请。'
sourcePath: '/sdk/wasm/user/friend-applications/refuse-friend-application'
---

拒绝收到的好友申请时，`toUserID` 应填写申请人的用户 ID。`handleMsg` 可以记录拒绝说明；没有内容时传空字符串。

```ts
await openimsdk.refuseFriendApplication({ toUserID: applicantUserID, handleMsg: '' });
```

Promise 成功表示服务端已完成本次拒绝请求，但不代表申请事件已经到达。收到 `OnFriendApplicationRejected` 后，按申请双方的用户 ID 更新对应记录；拒绝申请不会创建好友关系，也不等同于删除申请记录。完整监听方式见[获取收到的好友申请](/sdk/wasm/user/friend-applications/get-friend-application-list-as-recipient)。
