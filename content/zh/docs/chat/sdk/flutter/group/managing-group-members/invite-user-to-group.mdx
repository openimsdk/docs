`inviteUserToGroup()` 向一个群组邀请一组用户。客户端可以根据当前成员角色控制操作入口，但最终权限由 OpenIMServer 校验。

```dart
await OpenIM.iMManager.groupManager.inviteUserToGroup(
  groupID: groupID,
  reason: '加入项目讨论',
  userIDList: selectedUserIDs,
);
```

`groupID`、邀请原因 `reason` 和 `userIDList` 分别表示目标群组、邀请说明和目标用户列表。Future 成功表示服务端已处理邀请请求，不等同于所有目标用户都已在各端完成状态更新。

相关客户端可能随后收到成员新增或入群申请变化。不要把事件到达当作当前 Future 的完成回调；成员合并规则见[群成员查询](/sdk/flutter/group/retrieving-group-members/overview-retrieving-group-members)。
