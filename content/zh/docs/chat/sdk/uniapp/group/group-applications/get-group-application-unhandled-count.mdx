查询当前用户需要处理的未审批入群申请总数，常用于展示群管理菜单中的待办角标或红点。

## 参数说明

当前 UTS 方法签名要求传入 `offset` 和 `count`。这两个字段不是时间戳，也不应当用于实现“某个时间点之后”的统计；为保持跨端调用一致，可以从 `0` 开始传入一个合理的页大小。

```uts
import {
  getGroupApplicationUnhandledCount,
} from '@/uni_modules/unix-openim-sdk'

const count = await getGroupApplicationUnhandledCount({
  offset: 0,
  count: 20,
})
setPendingApplicationCount(count != null ? count : 0)
```

Promise 成功后返回 `number | null`。`null` 表示没有可用结果，不应直接当作 SDK 已确认的零条记录。

该查询不会修改申请状态，也不会清除申请入口角标。需要实时维护入口角标时，请参考[获取收到的入群申请](/sdk/uniapp/group/group-applications/get-group-application-list-as-recipient)中关于入群申请未处理数量变更事件的监听与处理。
