---
title: '开启或关闭阅后即焚'
description: '设置指定会话是否启用阅后即焚模式。'

---

阅后即焚与[定期删除服务端消息](/sdk/harmony/conversation/managing-conversations/set-message-destruct)属于不同策略。

```ts
import sdk, { SetConversationReq } from '@openimsdk/imsdk';

const request: SetConversationReq = {
  conversationID: conversationID,
  isPrivateChat: true,
};
await sdk.setConversation(request);
```

传入 `true` 开启阅后即焚，传入 `false` 关闭。消息保留时长请参考[设置阅后即焚时长](/sdk/harmony/conversation/managing-conversations/set-burn-duration)单独配置。接口调用成功后，SDK 会触发会话变更事件；客户端收到通知后根据 `conversationID` 更新对应会话的 `isPrivateChat` 属性，完整监听配置请参考[获取会话列表](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list)。
