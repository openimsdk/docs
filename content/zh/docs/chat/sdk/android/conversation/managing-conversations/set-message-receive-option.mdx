---
title: '设置会话消息接收方式'
description: '使用 setConversationRecvMessageOpt() 设置 Android 单个会话的消息接收与通知方式。'
sourcePath: '/sdk/android/conversation/managing-conversations/set-message-receive-option'
---

```java
OpenIMClient.getInstance().conversationManager.setConversationRecvMessageOpt(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markReceiveOptionSubmitted(conversationID);
        }

        @Override
        public void onError(int code, String error) {
            recordReceiveOptionFailure(code, error);
        }
    },
    conversationID,
    2
);
```

| 数值 | 含义                         |
| ---- | ---------------------------- |
| `0`  | 正常接收消息并允许通知。     |
| `1`  | 不接收该会话消息，也不通知。 |
| `2`  | 接收该会话消息，但不通知。   |

账号级默认策略见[设置全局消息接收方式](/sdk/android/user/user-profile/set-global-message-reception)。成功 callback 后通过 `onConversationChanged` 按 `conversationID` 合并最新会话。
