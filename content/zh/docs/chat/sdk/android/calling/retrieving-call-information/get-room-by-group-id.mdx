title: '查询群组通话房间'
description: '使用 Android SDK 按群组 ID 查询进行中的通话房间。'
sourcePath: '/sdk/android/calling/retrieving-call-information/get-room-by-group-id'
---

`signalingGetRoomByGroupID()` 的参数是群组 ID，不是 `roomID`，即使通话使用了自定义 `roomID`。

```java
OpenIMClient.getInstance().signalingManager.signalingGetRoomByGroupID(
    new OnBase<RoomCallingInfo>() {
        @Override
        public void onSuccess(RoomCallingInfo room) {
            // room 包含房间、完整邀请和当前参与者信息。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明查询失败原因。
        }
    },
    groupID
);
```

成功回调返回当前的 `RoomCallingInfo`，其中包含房间 ID、事件中收到的完整邀请数据、参与者、群组 ID、Token 和连接地址。

成功结果没有有效 `roomID` 时，表示未取得可用的房间信息。错误回调中的 `code` 和 `error` 只说明查询失败原因，不能据此判断群组没有进行中的通话。
