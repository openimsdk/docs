检查当前登录用户是否已经是目标群组的成员：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |

```dart
final joined = await OpenIM.iMManager.groupManager.isJoinedGroup(
  groupID: groupID,
);
```

## 返回结果

Future 成功返回布尔值（`bool`），`true` 表示当前用户已加入该群组，`false` 表示未加入。

该查询为轻量级状态判断，不会触发事件通知。入群流程与群组事件管理请参考[申请加入群组](/sdk/flutter/group/join-group)与[群组概览](/sdk/flutter/group/overview-group)。
