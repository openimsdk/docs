调用 `isJoinGroup()` 检查当前账号是否已加入指定群组。

```ts
const isJoined = await OpenIMSDK.isJoinGroup('group-001');
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 要检查的群组 ID。 |

## 返回结果

调用完成后返回 `boolean`：`true` 表示当前账号已加入群组，`false` 表示尚未加入。
