群主或管理员可以将指定用户列表移出群组：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `reason` | `String` | 是 | 移出群组的原因或操作说明。 |
| `userIDList` | `List<String>` | 是 | 需要移出群组的用户 ID 列表。 |

```dart
await OpenIM.iMManager.groupManager.kickGroupMember(
  groupID: groupID,
  reason: '成员调整',
  userIDList: selectedUserIDs,
);
```

## 返回结果

Future 成功表示服务端已完成成员移除操作。

操作生效后，群内相关客户端会收到群成员减少事件通知；客户端应使用复合标识 `groupID:userID` 从本地群成员列表中移除对应记录。完整的事件监听与状态清理请参考[群成员查询概览](/sdk/flutter/group/retrieving-group-members/overview-retrieving-group-members)。
