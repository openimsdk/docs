---
title: '移除群成员'
description: '从指定群组移除一个或多个成员。'
sourcePath: '/sdk/harmony/group/managing-group-members/kick-group-member'
---

不能使用该方法移除群主；如需更换群主，应先通过[转让群主](/sdk/harmony/group/managing-group-members/transfer-group-owner)转让群主身份。

```ts
import sdk, { KickGroupMemberReq } from '@openimsdk/imsdk';

const request: KickGroupMemberReq = {
  groupID: groupID,
  kickedUserIDs: [targetUserID],
  reason: '已离开项目',
};
await sdk.kickGroupMember(request);
```

调用前应对 `kickedUserIDs` 去重。Promise 成功表示服务端已接受移除请求；SDK 会触发群成员减少事件，客户端收到通知后按 `groupID:userID` 移除对应成员记录，完整监听配置请参考[分页查询群成员](/sdk/harmony/group/retrieving-group-members/get-group-member-list)。
