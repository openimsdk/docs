Use `resetConversationUnread()` to calibrate local conversation badge counters. This method does not fabricate server unread records and should not substitute for [Mark conversation as read](/sdk/harmony/conversation/managing-conversations/mark-conversation-read):

## Code example

```ts
import sdk, { ResetConversationUnreadReq } from '@openimsdk/imsdk';

const request: ResetConversationUnreadReq = {
  conversationIDs: [conversationID],
  num: 0,
};
await sdk.resetConversationUnread(request);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationIDs` | `string[]` | Yes | List of conversation IDs to update. |
| `num` | `number` | Yes | Target unread count value (non-negative integer). |

## Return value

Returns a Promise that resolves to `void` when the local counter is reset.

## State changes after the call

The specified `num` is applied to every conversation in `conversationIDs`. Resolving the Promise triggers both `EventOnConversationChanged` and `EventOnTotalUnreadMessageCountChanged`. Correlate conversation items by `conversationID` and update the badge totals, as detailed in [Retrieve conversation list](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list) and [Get total unread message count](/sdk/harmony/conversation/managing-conversations/get-total-unread-count).
