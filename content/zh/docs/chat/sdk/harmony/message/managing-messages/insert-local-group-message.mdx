---
title: '插入本地群聊消息'
description: '向当前设备的群聊记录插入一条本地消息。'
sourcePath: '/sdk/harmony/message/managing-messages/insert-local-group-message'
---

```ts
import sdk, { InsertGroupMessageToLocalReq, InsertGroupMessageToLocalResp } from '@openimsdk/imsdk';

const request: InsertGroupMessageToLocalReq = {
  msg: message,
  groupID: groupID,
  sendID: currentUserID,
};
const response: InsertGroupMessageToLocalResp = await sdk.insertGroupMessageToLocal(request);
insertMessage(response.msg);
```

`groupID` 和 `sendID` 必须与消息路由及界面展示一致。客户端使用 `clientMsgID`（必要时同时限定 `conversationID`）合并本地消息列表。Promise 成功只修改当前设备，不发送给群成员，也不触发共享新消息事件；单聊本地消息插入请参考 [插入本地单聊消息](/sdk/harmony/message/managing-messages/insert-local-single-message)。
