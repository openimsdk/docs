Retrieve an immediate presence snapshot for all users currently subscribed to by the signed-in client:

## Parameters

This method accepts no parameters. It automatically retrieves current presence data for all subscribed users.

## Code example

```dart
final states = await OpenIM.iMManager.userManager.getSubscribeUsersStatus();
```

## Return value

A successful `Future` returns a list of presence status records (`List<UserStatusInfo>`).

Each `UserStatusInfo` item includes the target user's `userID`, numeric online `status`, and platform breakdown in `detailPlatformStatus`. When reconnecting or resuming from the background, invoke this method to pull a fresh presence snapshot and merge records into the local state store using `userID` as the key.

OpenIM manages presence through persistent subscriptions; it does not offer ad-hoc one-off status queries for unsubscribed users. This query is a read-only snapshot retrieval and does not modify active subscriptions or trigger presence listener events.

To manage subscription targets, see [Subscribe to user status](/sdk/flutter/user/retrieving-and-updating-user-information/subscribe-user-status) and [Unsubscribe from user status](/sdk/flutter/user/retrieving-and-updating-user-information/unsubscribe-user-status).
