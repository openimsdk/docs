```uts
import { getAdvancedHistoryMessageList } from '@/uni_modules/unix-openim-sdk'

const page = await getAdvancedHistoryMessageList({ conversationID, startClientMsgID: '', count: 50 })
```

Use an empty cursor for the first page and the earliest boundary message ID for the next. Deduplicate by `clientMsgID` and honor the returned end marker.

Commercial `getHistoryMessageList()` additionally supports `isReverse`, `viewType`, and `lastMinSeq`; direction is a parameter, not a separate reverse-history API.
