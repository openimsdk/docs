Once a call is connected, any participant can hang up to terminate their session. Pass the active `SignalingInfo` object, ensuring `roomID` matches the ongoing media room.

## Code example

```java
OpenIMClient.getInstance().signalingManager.signalingHungUp(
    new OnBase<String>() {
        @Override
        public void onSuccess(String result) {
            // Hangup request completed.
        }

        @Override
        public void onError(int code, String error) {
            // code and error describe the failure.
        }
    },
    signalingInfo
);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | Yes | Callback delivering the asynchronous operation result. |
| `signalingInfo` | `SignalingInfo` | Yes | Active call signaling object, where `roomID` matches the ongoing call room. |

## Return value

The successful callback indicates that the server processed the hangup signal. The client that initiated the hangup should dismiss the calling screen, disconnect from the media room, and release camera and microphone hardware resources.

## State changes after the call

Other participants in the room receive hangup or participant disconnected events. Update active rosters or terminate the call screen using `roomID` (or `roomID:userID`). For event handling details, see [Handle call events](/sdk/android/calling/managing-calls/handle-call-events).
