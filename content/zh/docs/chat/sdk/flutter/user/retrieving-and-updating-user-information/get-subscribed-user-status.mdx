主动拉取当前已订阅全部用户的实时在线状态快照：

## 参数说明

该方法无需传入任何参数。调用后将自动获取当前客户端所有已建立订阅关系的目标用户的最新状态。

```dart
final states = await OpenIM.iMManager.userManager.getSubscribeUsersStatus();
```

## 返回结果

Future 成功返回已订阅用户的在线状态列表（`List<UserStatusInfo>`）。

每个 `UserStatusInfo` 包含目标用户的 `userID`、在线状态数值 `status` 以及各平台在线详情 `detailPlatformStatus` 等。在网络重连或从后台恢复活跃时，可调用此接口拉取全量快照，并以 `userID` 为合并标识更新本地在线状态缓存。

SDK 的在线状态基于长效订阅机制维护，不提供针对非订阅用户的临时单次状态查询接口。该查询为本地只读快照拉取，不会改变现有的订阅关系集合，也不会触发在线状态回调事件。

订阅与退订目标用户在线状态分别请参考[订阅用户在线状态](/sdk/flutter/user/retrieving-and-updating-user-information/subscribe-user-status)与[取消用户状态订阅](/sdk/flutter/user/retrieving-and-updating-user-information/unsubscribe-user-status)。
