在指定群组中按用户 ID 或群内昵称关键词搜索群成员列表：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `keywordList` | `List<String>` | 是 | 搜索关键词列表；传入前建议去除首尾空格。 |
| `isSearchUserID` | `bool` | 否 | 是否匹配群成员的用户 ID。 |
| `isSearchMemberNickname` | `bool` | 否 | 是否匹配群内昵称。 |
| `offset` | `int` | 否 | 分页偏移量，首屏从 `0` 开始。 |
| `count` | `int` | 否 | 每页拉取的最大结果数量。 |

```dart
final members = await OpenIM.iMManager.groupManager.searchGroupMembers(
  groupID: groupID,
  keywordList: [keyword.trim()],
  isSearchUserID: true,
  isSearchMemberNickname: true,
  offset: 0,
  count: 50,
);
```

## 返回结果

Future 成功返回当前分页匹配到的群成员列表（`List<GroupMembersInfo>`）。

当搜索关键词或匹配开关发生变化时，应将 `offset` 重置为 `0` 重新查询。搜索操作建立临时快照，不会触发群成员事件通知。后续群成员变动与增量合并规则请参考[群成员查询概览](/sdk/flutter/group/retrieving-group-members/overview-retrieving-group-members)。
