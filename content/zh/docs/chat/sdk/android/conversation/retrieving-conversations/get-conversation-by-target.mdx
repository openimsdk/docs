按聊天目标获取单个会话的快照信息，常见于从联系人名片、群资料页或搜索结果直接发起或打开聊天窗口的场景。若本地尚未建立该会话，SDK 会自动生成并返回基础会话对象。

```java
OpenIMClient.getInstance().conversationManager.getOneConversation(
    new OnBase<ConversationInfo>() {
        @Override
        public void onSuccess(ConversationInfo conversation) {
            // conversation 是目标会话资料。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    sourceId,
    ConversationType.SINGLE_CHAT
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<ConversationInfo>` | 是 | 异步请求回调。 |
| `sourceId` | `String` | 是 | 聊天目标标识。单聊时传入对方的 `userID`；群聊时传入群组的 `groupID`。 |
| `sessionType` | `int` | 是 | 会话类型。单聊为 `ConversationType.SINGLE_CHAT`，群聊为 `ConversationType.GROUP_CHAT` 或 `ConversationType.SUPER_GROUP_CHAT`。 |

## 返回结果

成功回调返回目标会话的 `ConversationInfo` 快照对象，包含未读数、草稿、置顶状态及最新一条消息等。客户端可获取其 `conversationID` 作为会话的全局合并标识。

若需要持续接收会话属性更新或新消息通知，请参考[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)在应用层注册 `OnConversationListener`。
