Use `setMessageLocalContent()` to save transcription text in a voice message on the current device. Pass the complete message object and preserve its existing fields.

```ts
const updatedMessage = {
  ...message,
  soundElem: {
    ...message.soundElem,
    text: {
      text: transcript,
      translate: message.soundElem?.text?.translate ?? {},
    },
  },
};

await OpenIMSDK.setMessageLocalContent({
  conversationID,
  message: updatedMessage,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `string` | Yes | Conversation containing the message. |
| `message` | `MessageItem` | Yes | Complete message object containing the transcription. |

After the call completes, the transcription is saved in the message content on the current device.
