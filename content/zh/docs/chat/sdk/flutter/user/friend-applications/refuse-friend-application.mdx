title: '拒绝好友申请'
description: '使用 Flutter SDK 拒绝好友申请。'
sourcePath: '/sdk/flutter/user/friend-applications/refuse-friend-application'
---

```dart
await OpenIM.iMManager.friendshipManager.refuseFriendApplication(
  userID: applicantUserID,
  handleMsg: '暂不添加',
);
```

`userID` 是申请方，`handleMsg` 是可选处理附言。Future 成功表示拒绝请求完成；申请变化通过统一 listener 合并，见[获取收到的好友申请](/sdk/flutter/user/friend-applications/get-friend-application-list-as-recipient)。
