Paginate and query outgoing group applications submitted by the current account, with optional filters for group IDs and review statuses:

```ts
const applications = await OpenIMSDK.getGroupApplicationListAsApplicant({
  groupIDs: ['group-001'],
  handleResults: [
    ApplicationHandleResult.Unprocessed,
    ApplicationHandleResult.Agree,
    ApplicationHandleResult.Reject,
  ],
  offset: 0,
  count: 20,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupIDs` | `string[]` | Yes | Array of group IDs to filter by; pass an empty array `[]` to query all groups. |
| `handleResults` | `number[]` | Yes | List of handle statuses to filter by; pass an empty array `[]` to match all. |
| `offset` | `number` | Yes | Pagination offset starting from `0`. |
| `count` | `number` | Yes | Maximum number of records to retrieve. |

Status values correspond to `ApplicationHandleResult`, detailed in [Get received group applications](/sdk/react-native/group/group-applications/get-group-application-list-as-recipient).

## Return value

Resolves to an array of `GroupApplicationItem[]` for the requested page. When the returned count is less than `count`, the end of the list has been reached. Reconcile records using the composite key `groupID:userID`. For property definitions and event listeners, see [Get received group applications](/sdk/react-native/group/group-applications/get-group-application-list-as-recipient).
