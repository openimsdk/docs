---

```dart
final group = await OpenIM.iMManager.groupManager.createGroup(
  groupInfo: GroupInfo(groupID: '', groupName: '项目讨论组', groupType: GroupType.work),
  memberUserIDs: ['user-003'],
  adminUserIDs: ['user-002'],
  ownerUserID: currentUserID,
);
```

普通成员、管理员和群主不能重复。Future 成功返回新建的 `GroupInfo`；群组列表增量通过 `onJoinedGroupAdded` 合并。
