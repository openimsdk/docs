title: '设置会话草稿'
description: '使用 setConversationDraft() 保存会话草稿。'

---

用户离开聊天页、切换会话或输入框内容变化时，可以使用 `setConversationDraft()` 保存草稿。输入过程中先维护编辑器状态并对保存调用做防抖；离开页面前再提交一次最新文本。

```java
OpenIMClient.getInstance().conversationManager.setConversationDraft(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markDraftSubmitted(conversationID);
        }

        @Override
        public void onError(int code, String error) {
            recordDraftSaveFailure(code, error);
        }
    },
    conversationID,
    editorValue
);
```

清空草稿时传空字符串。会话列表中的草稿变化可通过 `onConversationChanged` 接收。
