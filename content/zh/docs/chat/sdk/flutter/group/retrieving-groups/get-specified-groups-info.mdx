根据群组 ID 列表批量拉取群组的详细资料：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupIDList` | `List<String>` | 是 | 待查询的目标群组 ID 列表。 |

```dart
final groups = await OpenIM.iMManager.groupManager.getGroupsInfo(
  groupIDList: groupIDs,
);
```

## 返回结果

Future 成功返回匹配到的群组资料列表（`List<GroupInfo>`）。

即使仅查询单个群组，也需传入包含该群 ID 的列表，并根据返回列表是否为空判断群组是否存在。

查询操作建立静态数据快照，不会触发事件通知。公开群发现或复杂权限检索应由业务服务端提供；后续群资料变更与基于 `groupID` 的增量合并规则请参考[群组概览](/sdk/flutter/group/overview-group)。
