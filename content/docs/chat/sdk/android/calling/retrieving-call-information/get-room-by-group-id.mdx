Look up an ongoing call room by group ID. Supply the `groupID` parameter even if a custom `roomID` was assigned to the call.

## Code example

```java
OpenIMClient.getInstance().signalingManager.signalingGetRoomByGroupID(
    new OnBase<RoomCallingInfo>() {
        @Override
        public void onSuccess(RoomCallingInfo room) {
            // room contains room ID, original invitation, and current participant list.
        }

        @Override
        public void onError(int code, String error) {
            // code and error describe the failure.
        }
    },
    groupID
);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `base` | `OnBase<RoomCallingInfo>` | Yes | Callback delivering the asynchronous operation result. |
| `groupID` | `String` | Yes | Target group ID to query. |

## Return value

The successful callback returns a `RoomCallingInfo` snapshot of the active group call:

- `roomID`: Call room identifier.
- `invitation`: Original invitation payload configured at initiation.
- `participant`: Roster and status of members currently in the room.
- `groupID`: Target group ID.
- `token`: Media token required to join the session.
- `liveURL`: Media server endpoint URL.

If `roomID` in the returned object is empty, no ongoing audio/video call exists in this group. This query delivers a point-in-time snapshot; track subsequent call transitions via [Handle call events](/sdk/android/calling/managing-calls/handle-call-events).
