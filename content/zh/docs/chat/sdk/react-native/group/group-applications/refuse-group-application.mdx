调用 `refuseGroupApplication()` 拒绝指定用户的入群申请。

```ts
await OpenIMSDK.refuseGroupApplication({
  groupID: application.groupID,
  fromUserID: application.userID,
  handleMsg: '暂不接受该申请',
});
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 申请对应的群组 ID。 |
| `fromUserID` | `string` | 是 | 申请人的用户 ID，对应申请记录的 `userID`。 |
| `handleMsg` | `string` | 是 | 拒绝原因；没有说明时传空字符串。 |

调用完成后，入群申请已被拒绝。申请状态变化时会触发 `OnGroupApplicationRejected`，完整监听方式见[获取收到的入群申请](/sdk/react-native/group/group-applications/get-group-application-list-as-recipient)。
