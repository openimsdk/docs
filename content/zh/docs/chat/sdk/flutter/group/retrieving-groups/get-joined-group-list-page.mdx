分页查询当前登录用户已加入的群组列表，适合群组数量较多时的分批加载：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `offset` | `int` | 否 | 分页拉取的起始偏移量，首屏从 `0` 开始。 |
| `count` | `int` | 否 | 每页拉取的最大群组数量。 |

```dart
final groups = await OpenIM.iMManager.groupManager.getJoinedGroupListPage(
  offset: 0,
  count: 50,
);
```

## 返回结果

Future 成功返回当前分页已加入的群组列表（`List<GroupInfo>`）。

分页加载下一页时，应按已请求条目数递增 `offset`，不得使用因接收事件发生变动的本地列表长度作为偏移基准。如果在分页加载期间收到群组变动通知，建议重置偏移量从第一页重新读取。

查询操作建立静态数据快照，不会触发事件通知。群组增量同步与基于 `groupID` 的状态合并规则请参考[群组概览](/sdk/flutter/group/overview-group)。
