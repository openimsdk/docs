字段 `recvMsgOpt` 用于设置单个会话的消息接收策略，常用于实现会话级别的免打扰：

```ts
import sdk, { ConvRecvMsgOpt, SetConversationReq } from '@openimsdk/imsdk';

const request: SetConversationReq = {
  conversationID: conversationID,
  recvMsgOpt: ConvRecvMsgOpt.ReceiveNotNotifyMessage,
};
await sdk.setConversation(request);
```

## 参数说明

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `ConvRecvMsgOpt.ReceiveMessage` | `0` | 正常接收消息，并允许通知提醒。 |
| `ConvRecvMsgOpt.NotReceiveMessage` | `1` | 不接收该会话消息。 |
| `ConvRecvMsgOpt.ReceiveNotNotifyMessage` | `2` | 正常接收该会话消息，但不触发通知提醒（免打扰）。 |

账号全局默认的消息接收策略由 `globalRecvMsgOpt` 控制，详情请参考[设置全局消息接收方式](/sdk/harmony/user/profile/set-global-message-reception)。

接口调用成功后，SDK 会触发会话变更事件通知策略变更。客户端可根据 `conversationID` 更新对应会话的接收配置与免打扰状态，完整监听配置请参考[获取会话列表](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list)。
