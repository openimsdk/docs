Hide a single conversation entry from the active conversation list for the current account. This action hides the list item on the current device without deleting chat history; the conversation will reappear when a new message arrives or an interaction occurs.

```ts
await OpenIMSDK.hideConversation(conversationID);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `string` | Yes | Target conversation ID to hide. |

## Return value

A resolved Promise confirms that the request to hide the conversation was processed.

Upon Promise resolution, remove the conversation identified by `conversationID` from the local UI list view. Subsequent mutations or incoming messages will trigger the `OnConversationChanged` event, prompting the application to re-insert or update the conversation by `conversationID`. For full event handling, see [Retrieve conversation list](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list).
