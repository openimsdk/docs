调用 `unsubscribeUsersStatus()` 取消订阅指定用户的在线状态。

```ts
await OpenIMSDK.unsubscribeUsersStatus(userIDs);
```

页面翻页、搜索结果变化、退出登录或不再需要展示这些用户时，应取消对应订阅。
