---

将指定用户加入当前登录账号的黑名单。黑名单属于单向关系，拉黑后对方将无法向当前用户发送单聊消息。

```java
OpenIMClient.getInstance().friendshipManager.addBlacklist(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 拉黑用户成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    targetUserID,
    "{\"source\":\"profile-menu\"}"
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `targetUserID` | `String` | 是 | 目标用户的用户 ID。 |
| `ex` | `String` | 否 | 自定义业务扩展字符串，无需扩展时可传空字符串或使用无 `ex` 重载。 |

## 返回结果

成功回调表示服务端已成功将目标用户加入当前账号的黑名单。

操作生效后，SDK 会触发 `OnFriendshipListener.onBlacklistAdded` 事件；客户端应以 `userID` 为主键唯一定位该用户并同步本地黑名单列表，完整监听配置请参考[获取黑名单列表](/sdk/android/user/blacklist/get-blacklist)。若需移出黑名单，请参考[取消拉黑用户](/sdk/android/user/blacklist/remove-blacklist)。

```java
@Override
public void onBlacklistAdded(BlacklistInfo user) {
    // 收到新增黑名单通知，按 user.getUserID() 更新本地黑名单
}
```
