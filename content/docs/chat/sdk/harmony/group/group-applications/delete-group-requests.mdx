This operation removes application records identified by group and applicant, making it suitable for cleaning up processed or obsolete entries from display lists.

## Code example

```ts
import sdk, { DeleteGroupRequestsReq } from '@openimsdk/imsdk';

const request: DeleteGroupRequestsReq = {
  groupRequests: [{ groupID: application.groupID, fromUserID: application.userID }],
};
await sdk.deleteGroupRequests(request);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupRequests` | `GroupRequestItem[]` | Yes | List of group application records to delete, each containing `groupID` and `fromUserID`. |

## Return value

Returns a Promise that resolves to `void` when the records have been deleted.

## State changes after the call

Deleting application records does not reject the application. To submit a review decision, first use [Accept group application](/sdk/harmony/group/group-applications/accept-group-application) or [Refuse group application](/sdk/harmony/group/group-applications/refuse-group-application). Once the Promise resolves, clients can remove local records matching `groupID:userID`. For complete event listeners, see [Retrieve received group applications](/sdk/harmony/group/group-applications/get-group-application-list-as-recipient).
