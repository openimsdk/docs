按房间 ID 重新获取进入通话房间所需的入会凭据：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `roomID` | `NSString *` | 目标通话房间 ID（部分头文件参数名可能为 `groupID`，实际应传入房间 ID）。 |

```objc
[[OIMManager manager] signalingGetTokenByRoomID:roomID
                                      onSuccess:^(OIMInvitationResultInfo * _Nullable credentials) {
    if (credentials.roomID.length > 0) [self joinMediaRoom:credentials];
}
                                      onFailure:^(NSInteger code, NSString * _Nullable message) {
    [self showCallError:code message:message ?: @"获取房间凭据失败"];
}];
```

## 返回结果

成功回调 `onSuccess` 返回 `OIMInvitationResultInfo` 对象，包含该房间的 `roomID`、接入 Token（`token`）及流媒体地址（`liveURL`）。取得有效凭据后再连接音视频媒体引擎；当房间凭据过期或媒体重连时，可重新调用此接口刷新凭据。
