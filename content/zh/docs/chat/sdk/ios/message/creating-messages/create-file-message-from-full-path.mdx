通过本地沙盒中的文件绝对路径及显示文件名，可调用创建文件消息方法生成待发送的文件消息对象。SDK 会在发送流程中自动将文件上传至对象存储服务。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createFileMessageFromFullPath:fileURL.path
                                          fileName:fileURL.lastPathComponent];
```

## 参数说明

- `filePath`：本地沙盒内可访问的文件绝对路径（`NSString *`）。
- `fileName`：在会话聊天界面中展示的文件名称（`NSString *`）。

## 返回结果

- 返回初始化的文件消息对象（`OIMMessageInfo *`），其内容类型为文件。
- 该方法仅在本地构建消息对象，后续需调用[发送消息](/sdk/ios/message/sending-messages/send-message)接口完成文件上传与消息投递。若文件已由业务自行上传至存储服务，见[使用 URL 创建文件消息](/sdk/ios/message/creating-messages/create-file-message-by-url)。
