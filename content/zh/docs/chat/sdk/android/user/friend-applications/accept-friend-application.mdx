---
title: '接受好友申请'
description: '使用 acceptFriendApplication() 接受好友申请。'
sourcePath: '/sdk/android/user/friend-applications/accept-friend-application'
---

```java
OpenIMClient.getInstance().friendshipManager.acceptFriendApplication(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markApplicationAccepted(applicantUserID);
        }

        @Override
        public void onError(int code, String error) {
            recordApplicationAcceptFailure(code, error);
        }
    },
    applicantUserID,
    "已通过"
);
```

`applicantUserID` 是申请方用户 ID，最后一个参数是处理附言。成功 callback 表示接受请求完成；好友申请状态和新增好友关系可能通过不同 callback 到达，应分别合并。申请状态由 `onFriendApplicationAccepted` 更新，新好友关系由 `onFriendAdded` 更新。
