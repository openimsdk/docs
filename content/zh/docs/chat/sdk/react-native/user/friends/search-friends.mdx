按关键词搜索当前用户的好友。提交搜索前应去除关键词首尾空格；当前请求使用 `keywordList` 中的第一个非空关键词。

```ts
const friends = await OpenIMSDK.searchFriends({
  keywordList: [keyword.trim()],
  isSearchUserID: true,
  isSearchNickname: true,
  isSearchRemark: true,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `keywordList` | `string[]` | 是 | 搜索关键词数组，当前使用第一个非空关键词。 |
| `isSearchUserID` | `boolean` | 是 | 是否匹配用户 ID。 |
| `isSearchNickname` | `boolean` | 是 | 是否匹配好友昵称。 |
| `isSearchRemark` | `boolean` | 是 | 是否匹配好友备注。 |

## 返回结果

调用完成后返回 `SearchedFriendsInfo[]` 列表。每个元素包含好友信息字段以及 `relationship`：`0` 表示黑名单关系，`1` 表示好友关系。客户端应以 `userID` 作为结果记录的合并与展示标识。
