---
title: '挂断通话'
description: '结束已经建立的音频或视频通话。'
sourcePath: '/sdk/uniapp/calling/managing-calls/hang-up-call'
---

通话已经建立后，参与者调用 `signalingHungUp()`：

```uts
import { signalingHungUp } from '@/uni_modules/unix-openim-sdk'

await signalingHungUp({ invitation })
```

`invitation` 是本次通话的完整 `OpenIMSignalingInvitationInfo`，其中的 `roomID` 必须与当前媒体房间一致。

Promise 成功只表示挂断信令请求完成。应用仍需停止本地采集、离开媒体房间并释放摄像头和麦克风。取消、拒绝、超时和挂断应共用可重复执行的清理流程，并用 `roomID` 识别通话，避免同一事件导致重复释放资源。
