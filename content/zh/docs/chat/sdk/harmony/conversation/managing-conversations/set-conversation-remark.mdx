---
title: '设置会话备注'
description: '为当前用户的指定会话设置备注。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/set-conversation-remark'
---

备注只属于当前用户，不修改好友备注、用户昵称或群名称。

```ts
import sdk, { SetConversationReq } from '@openimsdk/imsdk';

const request: SetConversationReq = {
  conversationID: conversationID,
  remark: '项目讨论',
};
await sdk.setConversation(request);
```

传入空字符串可清空会话备注。接口调用成功后，SDK 会触发会话变更事件；客户端收到通知后根据 `conversationID` 更新对应会话的 `remark` 属性，完整监听配置请参考[获取会话列表](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list)。
