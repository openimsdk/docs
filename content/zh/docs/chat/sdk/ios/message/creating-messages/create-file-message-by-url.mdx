当业务层已自行将文档或附件上传至对象存储并持有下载链接时，可调用通过 URL 创建文件消息方法直接生成文件消息对象，避免 SDK 再次执行上传。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createFileMessageByURL:uploadedURL
                                  fileName:@"report.pdf"
                                      size:uploadedSize];
```

## 参数说明

- `fileURL`：已上传的远端文件下载访问 URL（`NSString *`）。
- `fileName`：接收端展示的文件名称（`NSString *`）。
- `size`：文件的实际大小（字节数）。

## 返回结果

- 返回包含远端 URL 的文件消息对象（`OIMMessageInfo *`）。所传的 URL、文件名和大小必须来自真实的上传结果。
- 由于媒体资源已由业务自行上传，后续需调用[发送不经 OSS 的消息](/sdk/ios/message/sending-messages/send-message-not-oss)直接完成消息发送。若需由 SDK 托管上传本地文件，见[使用本地路径创建文件消息](/sdk/ios/message/creating-messages/create-file-message-from-full-path)。
