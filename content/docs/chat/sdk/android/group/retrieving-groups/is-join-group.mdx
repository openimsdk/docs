`isJoinGroup()` only checks the membership relationship between the current signed-in user and the specified `groupID`.

```java
OpenIMClient.getInstance().groupManager.isJoinGroup(groupID, new OnBase<Boolean>() {
    @Override public void onSuccess(Boolean joined) { updateJoinAction(Boolean.TRUE.equals(joined)); }
    @Override public void onError(int code, String error) { showMembershipError(error); }
});
```

This result does not replace a group profile query and cannot determine whether another user is in the group.
