该方法统计指定时间之后仍需要当前用户处理的入群申请，适合显示待办数量或判断是否出现新的待处理申请。它不会读取或修改申请入口角标。

```ts
const { data: count } =
  await openimsdk.getGroupApplicationUnhandledCount({ time: 0 });
```

`time` 是统计起点的 Unix 毫秒时间戳；传 `0` 表示统计全部未处理申请。需要统计“上次查看之后”的申请时，保存上次成功打开申请列表的时间，并将其作为下一次查询起点。

Promise 成功后，`data` 是该时间点之后需要当前用户处理的申请数量。该值与申请入口的角标计数是两个独立概念；读取数量不会触发申请事件。
