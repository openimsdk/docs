Subscribe to single, batch, offline, and online-only delivery paths, then deduplicate by `(conversationID,clientMsgID)`.

```uts
import { off, onRecvNewMessage, onRecvNewMessages, onRecvOfflineNewMessage, onRecvOfflineNewMessages, onRecvOnlineOnlyMessage } from '@/uni_modules/unix-openim-sdk'

const subscriptions = [
  onRecvNewMessage(mergeMessage), onRecvOfflineNewMessage(mergeMessage),
  onRecvOnlineOnlyMessage(mergeOnlineOnlyMessage),
  onRecvNewMessages((result) => result.messages.forEach(mergeMessage)),
  onRecvOfflineNewMessages((result) => result.messages.forEach(mergeMessage)),
]
subscriptions.forEach((subscription) => off(subscription))
```

Online-only messages may not exist in history. A single application message store should own these global listeners; history queries remain necessary for snapshots and recovery.
