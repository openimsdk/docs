该查询适合成员搜索或构建群聊 @ 候选人。

## 参数说明

| 参数                   | 类型                | 是否必填 | 说明                         |
| ---------------------- | ------------------- | -------- | ---------------------------- |
| `groupID`              | `string`            | 是       | 目标群组 ID。                |
| `keyword`              | `string`            | 是       | 去除首尾空格后的非空关键词。 |
| `searchUserID`         | `boolean`           | 是       | 是否匹配用户 ID。            |
| `searchMemberNickname` | `boolean`           | 是       | 是否匹配群内昵称。           |
| `pagination`           | `RequestPagination` | 是       | 页码和每页数量。             |

```ts
import sdk, { SearchGroupMembersReq, SearchGroupMembersResp } from '@openimsdk/imsdk';

const request: SearchGroupMembersReq = {
  groupID: groupID,
  keyword: keyword.trim(),
  searchUserID: true,
  searchMemberNickname: true,
  pagination: { pageNumber: 1, showNumber: 30 },
};
const response: SearchGroupMembersResp = await sdk.searchGroupMembers(request);
const members = response.members;
```

搜索结果是独立结果集，不应替换完整成员列表。关键词或匹配字段变化时，重置页码并替换当前搜索结果。
