Attach custom business extension strings to a group. The `ex` field is a plain text string that overwrites existing data; if managing structured data like JSON, fetch existing values first, merge attributes in the application layer, and submit the complete serialized string:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID. |
| `ex` | `String` | Yes | New custom business extension string. |

## Code example

```dart
await OpenIM.iMManager.groupManager.setGroupInfo(
  GroupInfo(
    groupID: groupID,
    ex: mergedExtensionJSON,
  ),
);
```

## Return value

A successful `Future` indicates that the extension string has been updated on the server.

## State changes after the call

The server broadcasts group profile update notifications. The client updates `ex` on the local group record using `groupID` as the key. For complete listener integration, see [Groups overview](/sdk/flutter/group/overview-group). To recalibrate group state, call [Get specified groups info](/sdk/flutter/group/retrieving-groups/get-specified-groups-info).
