Retrieve outgoing group join applications submitted by the currently logged-in user using pagination:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupIDs` | `List<String>?` | No | Optional list of group IDs to filter results by. Queries all submitted requests when omitted. |
| `handleResults` | `List<int>?` | No | Filter by resolution status: `0` for pending, `1` for approved, `-1` for rejected. |
| `offset` | `int` | Yes | Zero-based pagination offset index. |
| `count` | `int` | Yes | Maximum number of records to retrieve per page. |

## Code example

```dart
final applications = await OpenIM.iMManager.groupManager
    .getGroupApplicationListAsApplicant(
  GetGroupApplicationListAsApplicantReq(
    groupIDs: [groupID],
    handleResults: [0],
    offset: 0,
    count: 20,
  ),
);
```

## Return value

A successful `Future` returns a list of group join applications sent by the current user (`List<GroupApplicationInfo>`).

This query returns an immediate data snapshot and does not emit event notifications. For tracking approval status transitions, see [Group applications overview](/sdk/flutter/group/group-applications/overview-group-applications).
