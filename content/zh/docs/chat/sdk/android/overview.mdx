OpenIM Android SDK 用于在原生 Android 应用中接入 OpenIM 即时通讯能力。SDK 基于 Java/Kotlin 提供客户端入口 `OpenIMClient`，并通过各领域 Manager 统一管理会话、消息、群组、好友及信令能力。
