`send: true` 表示查询当前用户发出的申请。

```ts
import sdk, { GetFriendApplicationReq, GetFriendApplicationResp } from '@openimsdk/imsdk';

const request: GetFriendApplicationReq = {
  send: true,
  handleResults: [],
  pagination: {
    pageNumber: 1,
    showNumber: 20,
  },
};
const response: GetFriendApplicationResp = await sdk.getFriendApplication(request);
showSentApplications(response.applications);
```

每项 `IMFriendApplication` 使用 `fromUserID:toUserID` 标识，包含申请附言、处理结果、处理说明和时间。查询不会触发事件；事件统一由[收到的好友申请](/sdk/harmony/user/friend-applications/get-friend-application-list-as-recipient)页面监听。
