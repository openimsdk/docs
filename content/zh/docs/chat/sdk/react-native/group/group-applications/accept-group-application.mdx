群主或管理员同意指定用户的入群申请。

```ts
await OpenIMSDK.acceptGroupApplication({
  groupID: application.groupID,
  fromUserID: application.userID,
  handleMsg: '同意加入',
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 申请对应的群组 ID。 |
| `fromUserID` | `string` | 是 | 申请人的用户 ID，对应申请记录的 `userID`。 |
| `handleMsg` | `string` | 是 | 处理说明；没有说明时传空字符串。 |

## 返回结果

调用完成后，入群申请审批已处理完成。

同意后，申请状态变化会通过 `OnGroupApplicationAccepted` 事件通知；新成员加入群组会触发 `OnGroupMemberAdded` 事件。客户端应以 `groupID:userID` 复合标识维护新成员记录，并以 `groupID` 关联所属群组。完整事件监听说明见[获取收到的入群申请](/sdk/react-native/group/group-applications/get-group-application-list-as-recipient)。
