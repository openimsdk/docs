---
title: '隐藏全部会话'
description: '从当前账号的会话列表隐藏全部会话入口。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/hide-all-conversations'
---

该操作影响范围较大，应要求用户确认。

```ts
import sdk from '@openimsdk/imsdk';

await sdk.hideAllConversations();
```

隐藏不会删除好友、群组或服务端历史消息；当收到新消息时，相关会话会自动重新生成并展示。调用成功后，客户端可清空当前本地展示的会话列表，并重新查询[获取会话列表](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list)与[获取消息总未读数](/sdk/harmony/conversation/managing-conversations/get-total-unread-count)进行校准。
