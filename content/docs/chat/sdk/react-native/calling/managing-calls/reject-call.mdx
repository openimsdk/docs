When an incoming call invitation arrives and the user declines to answer, invoke `signalingReject()` to refuse the invitation:

```ts
await OpenIMSDK.signalingReject({
  opUserID: currentUserID,
  invitation,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `opUserID` | `string` | Yes | User ID of the participant rejecting the invitation. |
| `invitation` | `RtcInvite` | Yes | Complete call invitation object received in the incoming invitation callback. |

## Return value

A resolved Promise confirms that the rejection signaling request has been processed by the server.

The caller and other devices receive notification via the `OnInviteeRejected` event. Reconcile the local room state using `roomID` and update participant states using `userID`. For complete event listeners, see [Handle call events](/sdk/react-native/calling/managing-calls/handle-call-events).
