通过本地沙盒中的视频文件绝对路径、封装格式、播放时长及封面缩略图路径，可调用创建视频消息方法生成待发送的视频消息对象。发送时 SDK 会自动执行视频与封面图的上传流程。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createVideoMessageFromFullPath:videoURL.path
                                         videoType:@"video/mp4"
                                          duration:durationSeconds
                                      snapshotPath:snapshotURL.path];
```

## 参数说明

- `videoPath`：本地沙盒内可访问的视频文件绝对路径（`NSString *`）。
- `videoType`：视频封装类型（`NSString *`），如 `video/mp4`。
- `duration`：视频播放时长（单位：秒）。
- `snapshotPath`：本地沙盒内可访问的视频第一帧封面图绝对路径（`NSString *`）。

## 返回结果

- 返回初始化的视频消息对象（`OIMMessageInfo *`），其内容类型为视频。
- 该方法仅在本地内存中构建待发送消息对象。后续需调用[发送消息](/sdk/ios/message/sending-messages/send-message)接口完成媒体上传与消息投递。若视频已由业务自行上传至存储服务，见[使用 URL 创建视频消息](/sdk/ios/message/creating-messages/create-video-message-by-url)。
