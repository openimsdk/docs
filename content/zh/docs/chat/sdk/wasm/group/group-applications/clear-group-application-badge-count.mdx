---
title: '清除入群申请角标'
description: '清除当前用户的入群申请角标。'
sourcePath: '/sdk/wasm/group/group-applications/clear-group-application-badge-count'
---

用户打开并确认申请列表后，可以清除角标：

```ts
await openimsdk.clearGroupApplicationBadgeCount();
```

该方法没有业务参数，只清除当前账号的入群申请入口角标。Promise 成功表示清除请求已完成，但不代表角标变化事件已经到达；该操作不会同意、拒绝或删除任何申请。

收到 `OnGroupApplicationBadgeCountChanged` 后，使用事件中的最新数量更新角标。完整监听方式见[获取收到的入群申请](/sdk/wasm/group/group-applications/get-group-application-list-as-recipient)。如果产品使用“未处理申请数”作为角标，应重新查询该数量，不要把两个计数混为一谈。
