---
title: '删除好友'
description: '使用 deleteFriend() 删除当前用户的一条好友关系。'
sourcePath: '/sdk/android/user/friends/delete-friend'
---

```java
OpenIMClient.getInstance().friendshipManager.deleteFriend(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 删除好友成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    friendUserID
);
```

成功 callback 表示删除好友请求完成。好友关系发生变化时，通过 `onFriendDeleted` 接收通知，详见[分页获取好友列表](/sdk/android/user/friends/get-friend-list-page)。
