Use `createLocationMessage()` to create a location message.

```ts
const message = await OpenIMSDK.createLocationMessage({
  description: 'Pudong New Area, Shanghai',
  longitude: 121.4737,
  latitude: 31.2304,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `description` | `string` | Yes | Location name or address description. |
| `longitude` | `number` | Yes | Longitude. |
| `latitude` | `number` | Yes | Latitude. |

The call returns a `MessageItem` ready to send.
