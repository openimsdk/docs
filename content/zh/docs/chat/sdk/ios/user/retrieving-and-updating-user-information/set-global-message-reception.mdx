title: '设置全局消息接收方式'
description: '使用 iOS SDK 设置当前账号的默认消息接收与通知方式。'
sourcePath: '/sdk/ios/user/retrieving-and-updating-user-information/set-global-message-reception'
---

```objc
[[OIMManager manager] setGlobalRecvMessageOpt:OIMReceiveMessageOptNotNotify
    onSuccess:nil
    onFailure:nil];
```

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `OIMReceiveMessageOptReceive` | `0` | 正常接收消息，并允许离线推送或通知。 |
| `OIMReceiveMessageOptNotReceive` | `1` | 不接收消息，也不触发离线推送或通知。 |
| `OIMReceiveMessageOptNotNotify` | `2` | 接收消息，但不触发离线推送或通知。 |

如果产品只提供“全局免打扰”开关，通常在 `Receive` 与 `NotNotify` 之间切换；`NotReceive` 会停止接收消息，应作为不同选项展示。成功 callback 表示设置请求完成；需要确认最终值时重新获取当前用户资料。
