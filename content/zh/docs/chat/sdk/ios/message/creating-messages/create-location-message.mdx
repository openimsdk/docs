调用创建位置消息方法可将地理位置经纬度及地名描述组装为位置分享消息对象。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createLocationMessage:@"上海市浦东新区"
                                 latitude:31.2304
                                longitude:121.4737];
```

## 参数说明

- `description`：位置名称或详细地址文本描述（`NSString *`）。
- `latitude`：纬度数值（`double`）。
- `longitude`：经度数值（`double`）。

## 返回结果

- 返回初始化的位置消息对象（`OIMMessageInfo *`），其内容类型为位置。
- 该方法仅构建内存消息对象，不负责调用系统定位或转换地理坐标系。发送端与接收端应统一坐标系规范（如 WGS-84 或 GCJ-02）。创建后需调用[发送消息](/sdk/ios/message/sending-messages/send-message)进行投递。
