调用 `deleteConversationGroup()` 可删除指定的会话分组及其包含的会话关联关系。该操作仅移除分组维度，不会删除分组内的实际会话条目或聊天消息记录。

```ts
await openimsdk.deleteConversationGroup(conversationGroupID);
```

该接口接收的参数为会话分组标识 `conversationGroupID`（请勿误传聊天群组的 `groupID`）。

## 返回结果

接口调用成功后，业务层即可直接从前端列表中移除对应的 `conversationGroupID`。

随后 SDK 会触发 `SdkEvent.OnConversationGroupDeleted` 事件。多端或其他模块可据此同步清理对应分组。完整的事件监听配置请参考[会话分组概览](/sdk/wasm/conversation/managing-conversation-groups/overview-conversation-groups)。
