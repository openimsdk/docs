拒绝指定用户发来的好友申请。

```ts
await OpenIMSDK.refuseFriendApplication({
  toUserID: applicantUserID,
  handleMsg: '',
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `toUserID` | `string` | 是 | 申请发起人的用户 ID。 |
| `handleMsg` | `string` | 是 | 处理申请时附带的说明；没有说明时传空字符串。 |

## 返回结果

调用完成后，好友申请审批已处理完成。

拒绝好友申请后，会触发 `OnFriendApplicationRejected` 事件通知双方客户端。客户端应在好友申请列表中更新该记录的状态。完整事件监听说明见[获取收到的好友申请](/sdk/react-native/user/friend-applications/get-friend-application-list-as-recipient)。
