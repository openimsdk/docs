`signalingGetRoomByGroupID()` 的参数是群组 ID，不是自定义 `roomID`：

```java
OpenIMClient.getInstance().signalingManager.signalingGetRoomByGroupID(
    new OnBase<RoomCallingInfo>() {
        @Override
        public void onSuccess(RoomCallingInfo room) {
            if (room.getRoomID() != null && !room.getRoomID().isEmpty()) {
                renderParticipants(room.getParticipant());
            }
        }

        @Override
        public void onError(int code, String error) {
            showNoActiveGroupCall();
        }
    },
    groupID
);
```

成功回调返回 `RoomCallingInfo` 快照，其中包含房间 ID、原始邀请、参与者、群组 ID、Token 和连接地址。参与者资料中的账号资料、群内资料和群资料属于不同数据源，不应相互覆盖。

没有进行中的群通话时，应把错误或空房间视为“当前没有可恢复的通话”，不要继续使用旧凭据。即使业务为群通话使用自定义房间 ID，本方法仍然传入 `groupID`。
