Accept an incoming friend request by supplying the applicant's user ID:

## Code example

```ts
import sdk, { ApprovalStatus, HandleFriendApplicationReq } from '@openimsdk/imsdk';

const request: HandleFriendApplicationReq = {
  userID: applicantUserID,
  handleMsg: '',
  status: ApprovalStatus.Approved,
};
await sdk.handleFriendApplication(request);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `userID` | `string` | Yes | Applicant's user identifier. |
| `handleMsg` | `string` | No | Optional acceptance note or greeting message. |
| `status` | `ApprovalStatus` | Yes | Use `ApprovalStatus.Approved` (`1`) to accept the request. |

## Return value

Returns a Promise that resolves to `void` when the approval is processed on the server.

## State changes after the call

Resolving the Promise confirms approval on the server. Update the application status in your request view via `EventOnFriendApplicationAccepted` correlated by `fromUserID:toUserID`, as described in [Retrieve received friend applications](/sdk/harmony/user/friend-applications/get-friend-application-list-as-recipient). The newly established friendship triggers `EventOnFriendAdded`; see [Paginate friend list](/sdk/harmony/user/friends/get-friend-list-page) for directory synchronization.
