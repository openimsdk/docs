---
title: '插入本地单聊消息'
description: '使用 insertSingleMessageToLocalStorage 插入仅当前设备可见的单聊消息。'
sourcePath: '/sdk/android/message/managing-messages/insert-local-single-message'
---

`insertSingleMessageToLocalStorage()` 把一条消息写入当前设备的指定单聊，可用于迁移记录或展示仅本地可见的业务提示。它不会向服务器发送消息。

`message` 是要插入的完整消息对象，`receiver` 是接收者用户 ID，`sender` 是发送者用户 ID。两者决定消息所属的单聊方向，不能互换。

```java
OpenIMClient.getInstance().messageManager.insertSingleMessageToLocalStorage(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 重新读取或更新当前设备上的单聊消息列表。
        }

        @Override
        public void onError(int code, String error) {
            // 提示本地写入失败。
        }
    },
    message,
    receiverUserID,
    senderUserID
);
```

成功回调表示本地写入完成。该操作不触发新消息事件，不能用于代替[发送消息](/sdk/android/message/sending-messages/send-message)。
