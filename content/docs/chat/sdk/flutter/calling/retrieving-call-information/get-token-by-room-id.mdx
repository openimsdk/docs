If you already know `roomID`, retrieve fresh credentials for joining the room:

```dart
final credentials = await OpenIM.iMManager.signalingManager
    .signalingGetTokenByRoomID(roomID: roomID);

if (credentials.token?.isNotEmpty == true &&
    credentials.roomID?.isNotEmpty == true) {
  await mediaEngine.join(
    roomID: credentials.roomID!,
    token: credentials.token!,
    liveURL: credentials.liveURL,
  );
}
```

Every `SignalingCertificate` field can be empty. Connect the media engine after obtaining valid `roomID`, `token`, and `liveURL` values. Call this method again when the credentials expire.
