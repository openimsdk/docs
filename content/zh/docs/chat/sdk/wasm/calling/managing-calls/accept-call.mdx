title: '接受通话'
description: '使用 WASM SDK 接受通话邀请并取得房间凭据。'

---

从 `OnReceiveNewInvitation` 取得原始 `SignalingInvitation` 后，使用 `signalingAccept()` 接受邀请：

```ts
const { data: roomCredentials } = await openimsdk.signalingAccept({
  opUserID: currentUserID,
  invitation,
});
```

`opUserID` 是执行接听操作的当前用户；`invitation` 必须保留收到的原始 `roomID`、邀请人、被邀请人和会话类型，不能重新构造。

Promise 成功后，`data` 是 `SignalingAcceptResult`，包含 `roomID`、`token` 和 `liveURL`。获取有效的 `token` 和 `roomID` 后再连接媒体房间；远端状态由[通话事件](/sdk/wasm/calling/managing-calls/handle-call-events)继续合并。
