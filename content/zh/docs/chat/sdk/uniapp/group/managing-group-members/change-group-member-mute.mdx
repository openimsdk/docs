---
title: '设置成员禁言'
description: '按秒设置指定群成员的禁言时长。'
sourcePath: '/sdk/uniapp/group/managing-group-members/change-group-member-mute'
---

`changeGroupMemberMute()` 使用 `mutedSeconds` 设置禁言时长。

```uts
import { changeGroupMemberMute } from '@/uni_modules/unix-openim-sdk'

await changeGroupMemberMute({ groupID, userID: 'user_b', mutedSeconds: 3600 })
```

解除禁言使用服务端约定的 0 秒。权限、最大时长和特殊角色限制由服务端校验；最终成员状态以事件或重新查询为准。
