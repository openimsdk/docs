---
title: '标记或取消标记会话'
description: '设置当前用户对指定会话的标记状态。'
sourcePath: '/sdk/wasm/conversation/managing-conversations/mark-conversation'
---

`isMarked` 只影响当前用户看到的会话标记状态。标记后，会话会进入会话分组中的内置“标记一组”；取消标记后，会话会从该筛选分组移除。这个分组由会话标记状态维护，不需要再调用会话分组成员 API 手动添加或移除。

```ts
await openimsdk.setConversation({
  conversationID,
  isMarked: true,
});
```

传入 `false` 取消标记。该字段不是置顶状态，也不会改变群组或消息内容。会话分组的数据模型、查询和后续变化事件见[会话分组概览](/sdk/wasm/conversation/managing-conversation-groups/overview-conversation-groups)。

Promise 成功表示请求完成。收到 `OnConversationChanged` 后，使用 `conversationID` 更新对应会话的 `isMarked`；完整监听示例见[获取会话列表](/sdk/wasm/conversation/retrieving-conversations/retrieve-conversation-list)。
