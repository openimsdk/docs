设置指定会话在聊天列表中的置顶状态：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `conversationID` | `NSString *` | 待置顶或取消置顶的会话 ID。 |
| `isPinned` | `BOOL` | 是否置顶。`YES` 为置顶，`NO` 为取消置顶。 |

```objc
[[OIMManager manager] pinConversation:@"c2c_user1002"
                             isPinned:YES
                            onSuccess:^(NSString * _Nullable data) {
                                NSLog(@"pinConversation success");
                            }
                            onFailure:^(NSInteger code, NSString *message) {
                                NSLog(@"pinConversation failed: %ld %@", (long)code, message);
                            }];
```

状态以 `conversationID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回操作结果。

操作成功后，会话属性变更会通过 `onConversationChanged:` 事件广播（监听参见[获取会话列表](/sdk/ios/conversation/retrieving-conversations/retrieve-conversation-list)），客户端应以 `conversationID` 为合并标识更新对应会话的 `isPinned` 属性并重排列表顺序。
