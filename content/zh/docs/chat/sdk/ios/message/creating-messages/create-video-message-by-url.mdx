当业务层已自行将视频文件及封面截图上传至对象存储并获得远端访问地址时，可调用通过 URL 创建视频消息方法生成视频消息对象，避免 SDK 再次执行重复上传。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createVideoMessageByURL:videoURL
                                  videoType:@"video/mp4"
                                   duration:durationSeconds
                                       size:videoSize
                                   snapshot:snapshotURL];
```

## 参数说明

- `videoURL`：已上传的远端视频文件访问 URL（`NSString *`）。
- `videoType`：视频 MIME 类型（`NSString *`），如 `video/mp4`。
- `duration`：视频播放时长（单位：秒）。
- `size`：视频文件的实际大小（字节数）。
- `snapshot`：已上传的远端封面缩略图访问 URL（`NSString *`）。

## 返回结果

- 返回包含远端 URL 的视频消息对象（`OIMMessageInfo *`）。所传的 URL、时长、大小及封面图必须来自真实的上传结果。
- 由于媒体资源已由业务自行上传，后续需调用[发送不经 OSS 的消息](/sdk/ios/message/sending-messages/send-message-not-oss)直接投递消息。若需由 SDK 托管上传本地视频，见[使用本地路径创建视频消息](/sdk/ios/message/creating-messages/create-video-message-from-full-path)。
