---
title: '删除本地消息'
description: '使用 UniApp SDK 仅删除当前设备上的一条消息。'
sourcePath: '/sdk/uniapp/message/managing-messages/delete-local-message'
---

仅希望从当前设备隐藏或清理一条消息时，传入消息所属的 `conversationID` 和消息自身的 `clientMsgID`：

```uts
import { deleteMessageFromLocalStorage } from '@/uni_modules/unix-openim-sdk'

const clientMsgID = message.clientMsgID
if (clientMsgID == null) return

await deleteMessageFromLocalStorage({
  conversationID,
  clientMsgID,
})

removeMessage(conversationID, clientMsgID)
```

两个 ID 都应来自当前会话和消息对象，不要使用列表位置、消息文本或服务端消息 ID 代替。调用前应确认 `clientMsgID` 非空。

Promise 成功只表示当前设备本地数据库中的消息已删除；应用随后应按 `conversationID:clientMsgID` 从界面状态中移除它。服务端仍可能保留记录，重建本地数据后消息可能重新同步。该操作不会通知其他设备或会话成员，也不等同于撤回；需要让会话成员看到撤回状态时使用[撤回消息](/sdk/uniapp/message/managing-messages/revoke-a-message)。
