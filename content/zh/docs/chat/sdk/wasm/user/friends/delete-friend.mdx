---
title: '删除好友'
description: '删除当前用户与指定用户的好友关系。'
sourcePath: '/sdk/wasm/user/friends/delete-friend'
---

```ts
await openimsdk.deleteFriend(friendUserID);
```

`friendUserID` 是要删除的好友用户 ID。

Promise 成功表示好友关系删除请求已完成。可以结束提交状态，但好友列表和资料卡仍应通过 `OnFriendDeleted` 或重新查询校准；事件按 `userID` 移除记录，完整监听见[分页获取好友列表](/sdk/wasm/user/friends/get-friend-list-page)。
