该操作清理当前登录账号在当前设备上的全部本地消息，适合明确的“清除本机聊天记录”场景。它没有业务参数，影响范围不是当前打开的单个会话。

```uts
import { deleteAllMsgFromLocal } from '@/uni_modules/unix-openim-sdk'

await deleteAllMsgFromLocal()
resetAllMessageState()
```

这是不可撤销的账号级本地操作，执行前应二次确认。Promise 成功后，还要清空当前账号在内存中的消息列表、搜索结果、分页游标和相关缓存。

该操作不会通知其他设备或会话成员，也不触发独立的消息删除事件。服务端仍可能保留历史；重新登录、重建本地数据或再次同步后，消息可能重新出现。只清理某个会话时，应使用会话级清理能力，不要调用本页方法。
