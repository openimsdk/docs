本页只说明 Android 工程的依赖和权限配置。SDK 初始化、连接监听和登录流程见[认证与管理登录会话](/sdk/android/getting-started/authenticate-and-manage-session)。

## 添加 SDK 依赖

在应用 module 的 `build.gradle` 中添加依赖：

```groovy
dependencies {
    implementation 'io.openim:android-sdk:<android-sdk-version>@aar'
    implementation 'io.openim:core-sdk:<core-sdk-version>@aar'
    implementation 'com.google.code.gson:gson:<gson-version>'
}
```

将占位符替换为同一 SDK 发行版本说明中列出的依赖版本。不要混用不同发行批次的 Android 包装层与 Core AAR；团队项目还应提交依赖锁定结果。

## 配置 Manifest

应用需要网络访问权限：

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
```
