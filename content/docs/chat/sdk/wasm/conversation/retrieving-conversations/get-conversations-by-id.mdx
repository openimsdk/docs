When you already have a set of `conversationID` values, use `getMultipleConversation()` to retrieve the current data for those conversations in one call.

```ts
const { data: conversations } =
  await openimsdk.getMultipleConversation(conversationIDs);

const byID = new Map(
  conversations.map((item) => [item.conversationID, item]),
);
```

The successful Promise returns `ConversationItem[]`. See [Get the conversation list](/sdk/wasm/conversation/retrieving-conversations/retrieve-conversation-list) for field descriptions.

Treat an ID with no corresponding result as a missing record. Do not assume that response items correspond positionally to request items. This query does not trigger a conversation event.
