查询指定时间点之后需要当前用户处理的入群申请数量，适用于展示待办角标或红点提示。

```ts
const count = await OpenIMSDK.getGroupApplicationUnhandledCount({
  time: 0,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `time` | `number` | 是 | 统计起点的 Unix 毫秒时间戳；传 `0` 表示统计全部待处理申请。 |

## 返回结果

调用完成后返回 `number`，表示指定时间点之后仍待当前用户处理的入群申请数量。该方法仅查询当前本地或服务端的计数快照，不会读取或修改会话未读数，也不会触发申请状态事件。
