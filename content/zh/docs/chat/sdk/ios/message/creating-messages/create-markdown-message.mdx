通过底层 OpenIMCore 提供的 Markdown 消息创建能力，可将 Markdown 格式的富文本文档组装为待发送的消息数据结构。

```objc
NSString *payloadJSON = @"{\"content\":\"**项目更新**\"}";
NSString *messageJSON = Open_im_sdkCreateMarkdownMessage(payloadJSON);
OIMMessageInfo *message = [OIMMessageInfo mj_objectWithKeyValues:messageJSON];
```

## 参数说明

- `payloadJSON`：包含 Markdown 正文内容的 JSON 字符串，字段格式为 `{"content": "Markdown 文本"}`。

## 返回结果

- 底层函数返回消息的完整 JSON 字符串，通过数据模型转换可映射为 `OIMMessageInfo` 对象，其正文内容保存在 `markdownTextElem.content` 中。
- 创建、模型映射与网络发送属于不同阶段。接收端渲染时应对不可信 Markdown 语法做安全性校验，并提供降级文本渲染。后续发送需调用[发送消息](/sdk/ios/message/sending-messages/send-message)。
