删除指定的会话分组及其会话关联关系。该操作仅解除分组归类，不会删除会话本身或会话中的聊天消息。

```ts
await OpenIMSDK.deleteConversationGroup(conversationGroupID);
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationGroupID` | `string` | 是 | 要删除的会话分组 ID。 |

## 返回结果

调用完成后，分组删除请求已处理完成。

分组删除成功后会通过 `OnConversationGroupDeleted` 事件通知；客户端应使用 `conversationGroupID` 作为标识，从本地列表中移除对应的会话分组记录。完整监听方式见[会话分组概览](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups)。
