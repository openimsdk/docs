取消对指定用户的在线状态订阅，释放状态监听配额：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `userIDs` | `List<String>` | 是 | 待取消订阅在线状态的目标用户 ID 列表。 |

```dart
await OpenIM.iMManager.userManager.unsubscribeUsersStatus(
  ['user_a', 'user_b'],
);
```

## 返回结果

Future 成功返回 `void`，表示取消订阅请求已成功提交至服务端。

该操作为状态变更接口。退订成功后，SDK 将不再接收这些用户的在线状态增量推送。客户端在 Future 成功返回后，可从本地在线状态缓存中移除对应 `userID` 的条目；若请求失败，建议保留本地订阅标记以供重试。

订阅目标用户状态请参考[订阅用户在线状态](/sdk/flutter/user/retrieving-and-updating-user-information/subscribe-user-status)。拉取已订阅用户的状态快照请参考[查询已订阅用户状态](/sdk/flutter/user/retrieving-and-updating-user-information/get-subscribed-user-status)。
