修改成员在当前群内展示的独立昵称（群名片）：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `userID` | `String` | 是 | 目标群成员的用户 ID。 |
| `nickname` | `String` | 是 | 成员在群内展示的新群昵称。 |

```dart
await OpenIM.iMManager.groupManager.setGroupMemberInfo(
  groupMembersInfo: SetGroupMemberInfo(
    groupID: groupID,
    userID: targetUserID,
    nickname: '项目负责人',
  ),
);
```

群内昵称仅在当前群聊中生效，不会修改用户的全局账号昵称。修改本人或他人群昵称的权限由服务端统一校验。若需更新用户全局昵称，请参考[更新当前用户资料](/sdk/flutter/user/retrieving-and-updating-user-information/update-self-profile)。

## 返回结果

Future 成功表示服务端已保存该群成员的昵称设置。

设置生效后，群内相关客户端会收到成员资料变更事件通知；客户端应使用复合标识 `groupID:userID` 更新本地成员的群昵称。完整的事件监听与增量合并逻辑请参考[群成员查询概览](/sdk/flutter/group/retrieving-group-members/overview-retrieving-group-members)。
