使用已上传至业务自有云存储或第三方 CDN 的视频远端 URL 创建视频消息对象。无需 SDK 再次上传视频与缩略图，适用于业务自行管理多媒体存储的场景。

```java
VideoElem videoElem = new VideoElem();
videoElem.setVideoUrl("https://example.com/videos/sample.mp4");
videoElem.setVideoSize(10485760L);
videoElem.setDuration(30L);
videoElem.setSnapshotUrl("https://example.com/videos/snapshot.jpg");
videoElem.setSnapshotSize(12400L);

Message message = OpenIMClient.getInstance().messageManager.createVideoMessageByURL(videoElem);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `videoElem` | `VideoElem` | 是 | 视频模型对象，需设置视频 URL `videoUrl`、文件大小 `videoSize`、播放时长 `duration` 以及封面缩略图地址 `snapshotUrl` 等。 |

## 返回结果

返回包含已上传视频元数据的待发送 `Message` 对象，其 `contentType` 为 `MessageType.VIDEO`。

由于视频与封面资源已由业务端预先上传，发送该消息时应调用[发送不经 OSS 的消息](/sdk/android/message/sending-messages/send-message-not-oss)直接投递。
