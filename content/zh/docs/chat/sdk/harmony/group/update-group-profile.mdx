群名称、简介和头像可以由同一个资料编辑表单提交。只传本次实际变化的字段，不要把公告、入群验证或成员权限字段混入普通资料保存操作。

## 参数说明

| 参数           | 类型     | 是否必填 | 说明              |
| -------------- | -------- | -------- | ----------------- |
| `groupID`      | `string` | 是       | 要更新的群组 ID。 |
| `groupName`    | `string` | 否       | 新群名称。        |
| `introduction` | `string` | 否       | 新群简介。        |
| `faceURL`      | `string` | 否       | 新群头像地址。    |

除 `groupID` 外，至少传入一个实际需要修改的资料字段。

```ts
import sdk, { SetGroupInfoReq } from '@openimsdk/imsdk';

const request: SetGroupInfoReq = {
  groupID: groupID,
  groupName: groupName.trim(),
  introduction: introduction.trim(),
  faceURL: faceURL,
};
await sdk.setGroupInfo(request);
```

Promise 成功表示更新请求已经完成，不表示群资料事件已经到达。收到事件后按 `groupID` 更新群资料；需要立即校准时，可[查询指定群组](/sdk/harmony/group/retrieving-groups/get-specified-groups-info)。
