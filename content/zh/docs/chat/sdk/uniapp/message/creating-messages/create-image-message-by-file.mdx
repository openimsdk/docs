title: '使用本地图片创建消息'
description: '根据 App 可访问的本地图片路径创建待发送消息。'

---

`createImageMessageFromFullPath()` 接收一条 App 原生侧能够读取的完整图片路径。它不接收浏览器 `File`，也不需要业务层预先填写图片尺寸和缩略图信息。

```uts
import {
  createImageMessageFromFullPath,
} from '@/uni_modules/unix-openim-sdk'

const message = await createImageMessageFromFullPath(imageFullPath)
if (message == null) return
```

`imageFullPath` 应是 POSIX 绝对路径，或者是基于 `uni.env.USER_DATA_PATH` 的 `unifile://` URI。平台临时路径、相册选择结果或沙盒外路径不能直接假定原生 SDK 可读；必要时先复制到应用数据目录，再传入稳定路径。

Promise 成功后返回 `OpenIMMessageItem | null`。非空结果只创建待发送对象；后续使用[发送消息](/sdk/uniapp/message/sending-messages/send-message)，由 SDK 完成图片上传和消息发送。
