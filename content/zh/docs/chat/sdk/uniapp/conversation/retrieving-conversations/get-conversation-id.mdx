只需要 `conversationID` 而不需要完整会话对象时，调用 `getConversationIDBySessionType()`。单聊传对方用户 ID，群聊传群组 ID；不要在应用层自行拼接 ID。

```uts
import {
  OpenIMSessionTypeSingle,
  getConversationIDBySessionType,
} from '@/uni_modules/unix-openim-sdk'

const conversationID = await getConversationIDBySessionType({
  sourceID: targetUserID,
  sessionType: OpenIMSessionTypeSingle,
})
```

参数中的 `sessionType` 与[查询指定会话](/sdk/uniapp/conversation/retrieving-conversations/get-conversation-by-target)一致。Promise 成功后返回字符串，可用于会话设置、消息历史、已读、隐藏和删除等操作。该查询不会触发会话事件。
