收到通话邀请后，可以调用接口接受通话邀请并加入房间。

```ts
const roomCredentials = await OpenIMSDK.signalingAccept({
  opUserID: currentUserID,
  invitation,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `opUserID` | `string` | 是 | 当前接受邀请的操作用户 ID。 |
| `invitation` | `RtcInvite` | 是 | 完整的通话邀请对象，建议直接使用邀请事件回调中的数据，不要自行拼接。 |

## 返回结果

调用完成后返回 `RtcInviteResults`，包含通话房间的 `roomID`、`token` 和 `liveURL`。

Promise 成功表示信令已成功接受并取得进入房间的凭据，但不代表音视频媒体通道已建立完成。其他端会通过 `OnInviteeAccepted` 事件感知状态变化；客户端应使用 `roomID` 标识通话房间，并结合参与者 `userID` 维护成员状态。完整事件监听说明见[处理通话事件](/sdk/react-native/calling/managing-calls/handle-call-events)。
