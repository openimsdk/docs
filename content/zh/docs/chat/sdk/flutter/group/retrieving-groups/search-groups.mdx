在当前用户已加入的群组中，按群组 ID 或群名称关键词进行本地检索：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `keywordList` | `List<String>` | 是 | 搜索关键词列表；传入前建议去除首尾空格。 |
| `isSearchGroupID` | `bool` | 否 | 是否匹配群组 ID。 |
| `isSearchGroupName` | `bool` | 否 | 是否匹配群名称。 |

```dart
final groups = await OpenIM.iMManager.groupManager.searchGroups(
  keywordList: [keyword.trim()],
  isSearchGroupID: true,
  isSearchGroupName: true,
);
```

## 返回结果

Future 成功返回匹配搜索条件的已加入群组列表（`List<GroupInfo>`）。

该接口仅在本地已同步的群组数据中检索，并非全局公开群目录的发现功能。搜索操作建立临时快照，不会触发事件通知。群组增量同步与基于 `groupID` 的状态合并规则请参考[群组概览](/sdk/flutter/group/overview-group)。
