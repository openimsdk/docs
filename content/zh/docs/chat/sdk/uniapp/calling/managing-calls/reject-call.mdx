---
title: '拒绝通话'
description: '拒绝当前尚未接听的通话邀请。'
sourcePath: '/sdk/uniapp/calling/managing-calls/reject-call'
---

用户拒绝来电时，把完整的 `OpenIMSignalingInvitationInfo` 传给 `signalingReject()`：

```uts
import { signalingReject } from '@/uni_modules/unix-openim-sdk'

await signalingReject({ invitation })
```

不要只用 `roomID` 或邀请人 ID 构造简化对象。Promise 成功表示本次拒绝请求已成功返回；应用可以关闭当前来电界面并释放尚未使用的本地媒体资源，但不能据此判断发起方已经收到拒绝事件。

发起方之后可能收到拒绝事件。当前 UTS 契约只公开字符串事件载荷，处理方式见[处理通话事件](/sdk/uniapp/calling/managing-calls/handle-call-events)。
