description: '查询好友申请列表中的未处理申请数量。'

---

UTS 插件的 `getFriendApplicationUnhandledCount()` 接收分页参数。首次查询从 `offset: 0` 开始，`count` 表示本次参与查询的申请数量。

```uts
import { getFriendApplicationUnhandledCount } from '@/uni_modules/unix-openim-sdk'

const pendingCount = await getFriendApplicationUnhandledCount({
  offset: 0,
  count: 100,
})
```

Promise 成功后返回 `number | null`。非空数值表示该次查询得到的未处理申请数量；该方法只读取当前状态，不会修改申请，也不会触发好友申请事件。

如果产品需要维护实时角标，应在首次查询后结合好友申请事件更新，并在重新登录或事件可能遗漏时重新查询最新数量。完整监听方式见[获取收到的好友申请](/sdk/uniapp/user/friend-applications/get-friend-application-list-as-recipient)。
