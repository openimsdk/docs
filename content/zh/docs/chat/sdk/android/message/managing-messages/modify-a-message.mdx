`modifyMessage` 用于修改会话中已经存在的消息。通常应以原消息为基础修改支持编辑的内容，并保留其他字段。

```java
messageManager.modifyMessage(callback, modifyRequest);
```

成功回调表示修改请求已经完成。

消息修改后，其他客户端通过 `OnAdvanceMsgListener.onMessageModified` 接收修改后的完整 `Message`：

```java
@Override
public void onMessageModified(Message message) {
    // message 是修改后的消息。
}
```

`MessageManager` 只能设置一个 `OnAdvanceMsgListener`；如果应用还需要处理其他消息事件，请在同一个 listener 中实现相应回调。设置方法见[事件概览](/sdk/android/events/overview-events)。
