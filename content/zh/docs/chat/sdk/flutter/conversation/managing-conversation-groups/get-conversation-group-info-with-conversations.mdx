使用 `getConversationGroupInfoWithConversations()` 同时读取一个会话分组及其当前页会话详情。

```dart
final page = await OpenIM.iMManager.conversationGroupManager
    .getConversationGroupInfoWithConversations(
  req: GetConversationGroupInfoWithConversationsReq(
    groupID: conversationGroupID,
    pagination: RequestPagination(pageNumber: 1, showNumber: 20),
  ),
);

renderConversationGroup(page.group, page.conversationElems ?? const []);
```

`groupID` 在这个 request 中表示 `conversationGroupID`。`pageNumber` 从 `1` 开始，`showNumber` 是每页数量。

## 返回结果

响应提供 nullable 的 `group`、当前页 `conversationElems` 和 `isEnd`。Flutter model 没有 WASM 响应中的 `conversationTotal`，分页终止应依据 `isEnd`。

该查询不会触发分组 listener；分页期间如果收到变化事件，可在本轮完成后重新查询确认当前结果。
