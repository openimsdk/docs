---
title: '从文件创建图片消息'
description: '使用相对路径或绝对路径创建图片消息。'
sourcePath: '/sdk/android/message/creating-messages/create-image-message-by-file'
---

缓存目录内使用 `createImageMessage()`，绝对路径使用 `createImageMessageFromFullPath()`。

```java
Message message = OpenIMClient.getInstance().messageManager.createImageMessageFromFullPath(filePath);
```
