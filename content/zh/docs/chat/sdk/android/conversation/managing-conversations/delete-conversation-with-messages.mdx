title: '删除会话及消息'
description: '使用 deleteConversationAndDeleteAllMsg() 删除 Android 指定会话及其全部消息。'

---

产品语义为“删除此聊天”时，调用 `deleteConversationAndDeleteAllMsg()`。

```java
OpenIMClient.getInstance().conversationManager.deleteConversationAndDeleteAllMsg(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            messageStore.clearConversation(conversationID);
            conversationStore.remove(conversationID);
        }

        @Override
        public void onError(int code, String error) {
            recordConversationDeleteFailure(code, error);
        }
    },
    conversationID
);
```

成功 callback 后清理当前消息列表和会话行。该操作不删除好友关系，也不退出或解散群组；聊天目标仍存在时，会话可能由新消息或同步重新生成。

后续通过 `onConversationChanged` 或重新查询校准会话列表，完整 listener 见[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
