---
title: '设置会话草稿'
description: '保存或清空指定会话的输入草稿。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/set-conversation-draft'
---

当用户离开聊天页、切换会话或输入内容改变时，保存会话草稿。输入过程中建议在组件内维护临时文本并在持久化时做防抖处理；离开页面前提交最新内容，避免高频按键频繁写入 SDK。

```uts
import { setConversationDraft } from '@/uni_modules/unix-openim-sdk'

await setConversationDraft({
  conversationID,
  draftText: editorValue,
})
```

清空草稿时把 `draftText` 设为空字符串。

Promise 成功表示草稿已成功保存到本地。客户端可先将本地草稿内容更新为目标值，收到会话变更事件后，按 `conversationID` 确认 `draftText` 和 `draftTextTime`；完整会话事件监听见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。退出登录或切换账号时应清理输入框内存状态，避免草稿跨账号污染。
