`lookMemberInfo` 的类型为 `OpenIMGroupAllowType`。这里的数值不能按常见布尔值理解。

| 常量 | 数值 | 含义 |
| --- | --- | --- |
| `OpenIMGroupAllowTypeAllowed` | `0` | 允许成员查看其他成员资料。 |
| `OpenIMGroupAllowTypeNotAllowed` | `1` | 不允许成员查看其他成员资料。 |

```uts
import {
  OpenIMGroupAllowTypeNotAllowed,
  setGroupInfo,
} from '@/uni_modules/unix-openim-sdk'

await setGroupInfo({
  groupID,
  lookMemberInfo: OpenIMGroupAllowTypeNotAllowed,
})
```

该设置与是否允许通过群组添加好友相互独立。Promise 成功后，收到 `onGroupInfoChanged()` 时再更新对应群资料；完整监听见[群组概览](/sdk/uniapp/group/overview-group)。
