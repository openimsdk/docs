关系链记录当前用户与其他用户之间的好友关系、好友申请和黑名单。资料、账号设置和在线状态属于用户能力，见[用户概览](/sdk/android/user/overview-user)。

## 关系链类型

Android SDK 会根据关系链场景返回不同的对象：

| 类型 | 适用场景 | 主要操作 |
| --- | --- | --- |
| `UserInfo` | 好友列表、指定好友资料和黑名单列表中的用户资料及关系信息 | [分页获取好友列表](/sdk/android/user/friends/get-friend-list-page)、[查询指定好友资料](/sdk/android/user/friends/get-friends-info)、[获取黑名单列表](/sdk/android/user/blacklist/get-blacklist) |
| `FriendInfo` | 好友资料、备注和关系扩展字段 | `UserInfo.friendInfo`、[搜索好友](/sdk/android/user/friends/search-friends) |
| `FriendshipInfo` | 当前用户与目标用户的好友关系结果 | [检查好友关系](/sdk/android/user/friends/check-friend) |
| `FriendApplicationInfo` | 收到或发出的好友申请及其处理状态 | [获取收到的好友申请](/sdk/android/user/friend-applications/get-recv-friend-application-list)、[获取发出的好友申请](/sdk/android/user/friend-applications/get-send-friend-application-list) |
| `BlacklistInfo` | 黑名单关系信息 | `UserInfo.blackInfo`、[获取黑名单列表](/sdk/android/user/blacklist/get-blacklist) |

`UserInfo` 可包含好友或黑名单关系信息；通过 `friendInfo` 属性获取 `FriendInfo`，通过 `blackInfo` 属性获取 `BlacklistInfo`。

## 状态更新

关系链状态变更统一通过 `OnFriendshipListener` 实时推送。好友记录、好友申请及黑名单条目的去重与增量合并均以 `userID` 为全局唯一标识。各类事件的监听实现请参考下方对应能力页面：

```java
OpenIMClient client = OpenIMClient.getInstance();

client.friendshipManager.setOnFriendshipListener(new OnFriendshipListener() {
    @Override
    public void onFriendApplicationAdded(FriendApplicationInfo application) {
        // 处理好友申请变化
    }

    @Override
    public void onFriendApplicationAccepted(FriendApplicationInfo application) {
        // 处理好友申请已接受
    }

    @Override
    public void onFriendApplicationRejected(FriendApplicationInfo application) {
        // 处理好友申请已拒绝
    }

    @Override
    public void onFriendApplicationDeleted(FriendApplicationInfo application) {
        // 处理好友申请删除
    }

    @Override
    public void onFriendAdded(FriendInfo friend) {
        // 处理好友关系变化
    }

    @Override
    public void onFriendInfoChanged(FriendInfo friend) {
        // 处理好友资料变化
    }

    @Override
    public void onFriendDeleted(FriendInfo friend) {
        // 处理好友关系删除
    }

    @Override
    public void onBlacklistAdded(BlacklistInfo user) {
        // 处理新增黑名单记录
    }

    @Override
    public void onBlacklistDeleted(BlacklistInfo user) {
        // 处理黑名单记录删除
    }
});
```

- 好友申请变化：见[获取收到的好友申请](/sdk/android/user/friend-applications/get-recv-friend-application-list)。
- 好友关系和好友资料变化：见[分页获取好友列表](/sdk/android/user/friends/get-friend-list-page)。
- 黑名单变化：见[获取黑名单列表](/sdk/android/user/blacklist/get-blacklist)。
