---
title: '隐藏会话'
description: '从当前账号的会话列表隐藏指定会话入口。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/hide-a-conversation'
---

`hideConversation()` 只隐藏当前登录用户的会话入口，不删除好友关系、不退出群组，也不影响其他用户。

```uts
import { hideConversation } from '@/uni_modules/unix-openim-sdk'

await hideConversation(conversationID)
```

该方法适合临时从聊天列表移除会话。收到新消息或重新同步后，隐藏的会话仍可能再次出现。

Promise 成功表示隐藏请求已经完成，应用可以立即从当前列表移除对应 `conversationID`，但不能把隐藏描述为删除聊天关系。随后收到 `onConversationChanged()` 时，继续按 `conversationID` 合并状态；需要确认列表时重新分页查询。完整监听见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。
