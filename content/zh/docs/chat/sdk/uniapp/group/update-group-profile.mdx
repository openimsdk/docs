`setGroupInfo()` 只更新提供的可选字段。

```uts
import { setGroupInfo } from '@/uni_modules/unix-openim-sdk'

await setGroupInfo({
  groupID,
  groupName: '新的群名',
  introduction: '项目协作群',
  faceURL: 'https://cdn.example.com/group.png',
})
```

群主和管理员权限由服务端校验。Promise 成功后通过 `onGroupInfoChanged` 或重新查询刷新，不直接覆盖未提交字段。

`displayIsRead` <span className="enterprise-field-badge">商业版</span> 是字段级扩展；公共服务端不支持时不要发送。
