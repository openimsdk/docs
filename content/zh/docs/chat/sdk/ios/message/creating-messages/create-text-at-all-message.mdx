在群聊发布重要公告或通知时，可调用创建 @所有人 消息方法生成提及群内全部成员的消息对象。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createTextAtAllMessage:@"@所有人 请查看公告"
                               displayText:@"@所有人"
                                   message:nil];
```

## 参数说明

- `text`：完整的消息正文文本（`NSString *`）。
- `displayText`：@所有人 标签在文本中展示的文字内容（`NSString *`），如 `@所有人`。
- `message`：被引用的原始消息对象（`OIMMessageInfo * _Nullable`），不需要引用时传 `nil`。

## 返回结果

- 返回初始化的 `OIMMessageInfo` 对象。
- 该方法仅用于群聊场景，仅创建内存对象。当前用户是否有权限在群内发布 @所有人 消息由服务端权限策略统一校验。后续发送见[发送消息](/sdk/ios/message/sending-messages/send-message)。
