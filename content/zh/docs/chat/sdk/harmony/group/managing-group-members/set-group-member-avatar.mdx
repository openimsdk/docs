description: '更新指定成员在一个群组中的头像。'

`faceURL` 是群成员资料中的头像地址，只作用于指定群组。

```ts
import sdk, { SetGroupMemberInfoReq } from '@openimsdk/imsdk';

const request: SetGroupMemberInfoReq = {
  groupID: groupID,
  userID: targetUserID,
  faceURL: avatarURL,
};
await sdk.setGroupMemberInfo(request);
```

群内头像与用户账号头像是不同数据。修改账号头像时，应使用[更新当前用户资料](/sdk/harmony/user/profile/set-self-info)。Promise 成功后，SDK 会触发群成员资料变更事件；客户端收到通知后按 `groupID:userID` 更新该成员资料，完整监听配置请参考[分页查询群成员](/sdk/harmony/group/retrieving-group-members/get-group-member-list)。
