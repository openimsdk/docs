---
title: '取消订阅用户状态'
description: '停止接收指定用户的在线状态变化。'
sourcePath: '/sdk/harmony/user/online-status/unsubscribe-users-status'
---

页面翻页、搜索结果变化或业务不再展示某些用户时，应及时取消对应订阅。

```ts
import sdk, { UnsubscribeUsersOnlineStatusReq } from '@openimsdk/imsdk';

const request: UnsubscribeUsersOnlineStatusReq = {
  userIDs: ['user_a', 'user_b'],
};
await sdk.unsubscribeUsersOnlineStatus(request);

for (let index = 0; index < request.userIDs.length; index += 1) {
  presenceByUserID.delete(request.userIDs[index]);
}
```

Promise 成功后按请求中的 `userID` 清理本地订阅集合，不需要等待状态事件。取消用户订阅与移除监听是两项独立操作，订阅流程与事件监听请参考 [订阅用户在线状态](/sdk/harmony/user/online-status/subscribe-users-status)。
