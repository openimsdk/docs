---
title: '取消通话邀请'
description: '由发起方取消尚未接通的通话邀请。'
sourcePath: '/sdk/uniapp/calling/managing-calls/cancel-call'
---

邀请尚未接通时，发起方可主动取消当前通话邀请：

```uts
import { signalingCancel } from '@/uni_modules/unix-openim-sdk'

await signalingCancel({ invitation })
```

`invitation` 应使用发起通话时保存的完整邀请，其中的 `roomID` 必须与当前等待接听的通话一致。

Promise 成功表示取消请求已经完成。客户端应按 `roomID` 结束本地呼叫等待状态，并释放为本次通话预先申请但未使用的媒体资源。Promise 成功不代表对方已同步接收取消信令，被邀请方后续接收取消事件的处理见[处理通话事件](/sdk/uniapp/calling/managing-calls/handle-call-events)。

取消只适用于尚未接通的邀请。通话已经建立后应使用[挂断通话](/sdk/uniapp/calling/managing-calls/hang-up-call)。
