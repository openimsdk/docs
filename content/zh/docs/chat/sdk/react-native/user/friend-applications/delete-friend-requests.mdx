调用 `deleteFriendRequests()` 批量删除好友申请记录。

## 参数说明

数组中的每一项使用以下字段：

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `fromUserID` | `string` | 是 | 申请发起人的用户 ID。 |
| `toUserID` | `string` | 是 | 申请接收人的用户 ID。 |

```ts
await OpenIMSDK.deleteFriendRequests([
  { fromUserID, toUserID },
]);
```

删除记录不等于拒绝申请，也不会删除已经建立的好友关系。申请记录变化时，可在[获取收到的好友申请](/sdk/react-native/user/friend-applications/get-friend-application-list-as-recipient)页面监听 `OnFriendApplicationDeleted`。
