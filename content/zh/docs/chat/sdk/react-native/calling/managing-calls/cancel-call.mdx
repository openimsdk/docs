发起方在通话尚未接通时，可以取消已发出的通话邀请。

```ts
await OpenIMSDK.signalingCancel({
  opUserID: currentUserID,
  invitation,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `opUserID` | `string` | 是 | 当前发起取消操作的用户 ID。 |
| `invitation` | `RtcInvite` | 是 | 发起通话时保存的完整通话邀请对象。 |

## 返回结果

调用完成后，取消邀请请求已处理完成。

被邀请成员会通过 `OnInvitationCancelled` 事件收到取消通知；客户端应使用 `roomID` 标识通话房间并清理呼叫中状态。完整事件监听说明见[处理通话事件](/sdk/react-native/calling/managing-calls/handle-call-events)。
