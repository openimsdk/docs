```dart
final message = await OpenIM.iMManager.messageManager
    .createSoundMessageByURL(soundElem: soundElem);
```

`SoundElem` should contain the actual URL, UUID, byte size, and duration in seconds. Send this object with `sendMessageNotOss()`.
