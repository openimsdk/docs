当需要手动拼装 @所有人 或自定义组合 @ 消息时，可调用创建 @所有人 标记方法生成用于承载“全体成员”属性的 `OIMAtInfo` 对象。

```objc
OIMAtInfo *atAll = [OIMMessageInfo createAtAllFlag:@"@所有人"];
```

## 参数说明

- `displayText`：在界面中展示的 @全体成员 占位文本（`NSString *`），如 `@所有人`。

## 返回结果

- 返回构建完成的 `OIMAtInfo` 对象。该标记并非真实的用户账号，仅用于作为 @ 消息中标识全体成员的参数对象。相关的高级提及消息创建见[创建 @ 消息](/sdk/ios/message/creating-messages/create-text-at-message)。
