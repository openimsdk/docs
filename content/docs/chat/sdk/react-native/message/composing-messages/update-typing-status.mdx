Use `typingStatusUpdate()` to send a typing hint to the other participant in a direct chat.

```ts
await OpenIMSDK.typingStatusUpdate({
  recvID: receiverUserID,
  msgTip: 'Typing...',
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `recvID` | `string` | Yes | User ID receiving the typing hint. |
| `msgTip` | `string` | Yes | Typing hint text to send. |

After the call completes, the typing hint has been sent. To update the current account's input state based on conversation focus, use [Update input states](/sdk/react-native/message/composing-messages/change-input-states).
