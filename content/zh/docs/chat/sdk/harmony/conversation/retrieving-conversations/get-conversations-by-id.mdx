---
title: '按 ID 批量获取会话'
description: '按一组 conversationID 查询对应的会话记录。'
sourcePath: '/sdk/harmony/conversation/retrieving-conversations/get-conversations-by-id'
---

```ts
import sdk, { GetMultipleConversationReq, GetMultipleConversationResp } from '@openimsdk/imsdk';

const request: GetMultipleConversationReq = {
  conversationIDList: conversationIDs,
};
const response: GetMultipleConversationResp = await sdk.getMultipleConversation(request);
mergeConversations(response.conversationList);
```

某个 ID 没有对应结果时按缺失记录处理。返回数组不保证与输入列表顺序一致，客户端应使用 `conversationID` 作为标识合并到本地状态中；后续会话变动请参考[获取会话列表](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list)进行事件监听。
