---
title: '将用户加入黑名单'
description: '将指定用户加入当前账号的黑名单。'
sourcePath: '/sdk/uniapp/user/blacklist/add-black'
---

`toUserID` 是要加入黑名单的用户 ID；`ex` 是可选的业务扩展字符串，不需要扩展信息时可以省略。

```uts
import { addBlack } from '@/uni_modules/unix-openim-sdk'

await addBlack({
  toUserID,
  ex: JSON.stringify({ source: 'profile' }),
})
```

Promise 成功表示本次加入黑名单请求已成功返回，不表示黑名单事件已经到达。收到 `onBlackAdded()` 后，按事件数据中的 `userID` 新增或更新黑名单记录；需要校准状态时重新查询黑名单。完整监听见[获取黑名单](/sdk/uniapp/user/blacklist/get-black-list)。重复加入、权限限制等情况应按 Promise 返回的错误处理。
