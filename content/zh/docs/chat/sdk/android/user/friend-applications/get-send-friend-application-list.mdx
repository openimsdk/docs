---
title: '获取发出的好友申请'
description: '使用 getSendFriendApplicationList() 分页查询当前用户发出的好友申请。'
sourcePath: '/sdk/android/user/friend-applications/get-send-friend-application-list'
---

```java
GetFriendApplicationListAsApplicantReq request =
    new GetFriendApplicationListAsApplicantReq(0, 20);

OpenIMClient.getInstance().friendshipManager.getSendFriendApplicationList(
    new OnBase<List<FriendApplicationInfo>>() {
        @Override
        public void onSuccess(List<FriendApplicationInfo> applications) {
            // 使用 applications 更新发出的好友申请列表
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    request
);
```

`offset` 从 `0` 开始，`count` 是页大小。成功 callback 返回当前页 `List<FriendApplicationInfo>`。

发出的申请中，当前用户通常是 `fromUserID`。列表字段和处理结果含义与[获取收到的好友申请](/sdk/android/user/friend-applications/get-recv-friend-application-list)相同。
