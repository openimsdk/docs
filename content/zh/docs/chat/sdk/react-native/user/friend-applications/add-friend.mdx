向指定用户发送好友申请。

```ts
await OpenIMSDK.addFriend({
  toUserID,
  reqMsg,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `toUserID` | `string` | 是 | 要申请添加的用户 ID。 |
| `reqMsg` | `string` | 是 | 申请附言；没有内容时传空字符串。 |

## 返回结果

调用完成后，好友申请已提交成功。

发送申请成功仅表示请求已提交至服务端，并不代表对方已接受。对方处理申请后，本端会收到 `OnFriendApplicationAccepted` 或 `OnFriendApplicationRejected` 事件通知；若对方接受，还会触发 `OnFriendAdded` 事件通知。客户端应以 `userID` 为合并标识添加新好友记录。完整事件监听说明见[获取收到的好友申请](/sdk/react-native/user/friend-applications/get-friend-application-list-as-recipient)。
