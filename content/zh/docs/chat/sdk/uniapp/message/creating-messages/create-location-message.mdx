`createLocationMessage()` 将业务层已经取得的位置说明和坐标写入消息。SDK 不负责定位、地理编码或地图展示。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `descriptionText` | `string` | 是 | 位置名称或可读地址。 |
| `longitude` | `number` | 是 | 经度，范围应为 `-180` 到 `180`。 |
| `latitude` | `number` | 是 | 纬度，范围应为 `-90` 到 `90`。 |

```uts
import { createLocationMessage } from '@/uni_modules/unix-openim-sdk'

const message = await createLocationMessage({
  descriptionText: '深圳湾公园',
  longitude: 113.9516,
  latitude: 22.4864,
})
if (message == null) return
```

坐标应来自定位结果或明确选点，并使用同一坐标系。SDK 不负责请求定位权限或校正坐标。

Promise 成功只返回待发送的 `OpenIMMessageItem | null`，不会请求定位权限或触发新消息事件。
