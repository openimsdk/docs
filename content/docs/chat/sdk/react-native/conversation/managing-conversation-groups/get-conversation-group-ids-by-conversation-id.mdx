A conversation can belong to multiple groups simultaneously. Pass a `conversationID` to query all conversation groups containing that conversation:

```ts
const groups = await OpenIMSDK.getConversationGroupByConversationID(conversationID);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `string` | Yes | Target conversation ID to query. |

## Return value

Resolves to an array of `ConversationGroup[]`, where each element represents a complete group structure including `conversationGroupID`, `name`, and `order`. This query returns a point-in-time snapshot and does not dispatch push events. For live updates, see [Conversation groups overview](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups).
