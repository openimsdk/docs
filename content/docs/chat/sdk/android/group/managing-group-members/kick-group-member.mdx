`kickGroupMember()` accepts a list of member IDs and a removal message. Prevent the current user from accidentally selecting themselves and respect the permission boundaries between owners and administrators.

```java
OpenIMClient.getInstance().groupManager.kickGroupMember(new OnBase<String>() {
    @Override public void onSuccess(String data) { markRemovalSubmitted(groupID); }
    @Override public void onError(int code, String error) { showRemovalError(error); }
}, groupID, memberUserIDs, "No longer participating in this project");
```

Remove targets from the member cache after receiving `onGroupMemberDeleted`.
