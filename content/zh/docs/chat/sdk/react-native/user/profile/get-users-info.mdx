按用户 ID 批量查询公开用户信息，适合用于展示好友候选人或陌生人资料卡等业务场景。

如果产品需要按昵称、手机号、组织、邮箱或其他业务字段检索用户，应先由业务服务端完成搜索和权限校验，再将返回的用户 ID 列表传入本接口查询公开资料。

```ts
const userIDList = Array.from(new Set(['user_a', 'user_b']));
const users = await OpenIMSDK.getUsersInfo(userIDList);
```

## 参数说明

`userIDList` 是要查询的用户 ID 数组。调用前建议去重，并控制单次请求数量。

## 返回结果

调用完成后返回查询到的 `PublicUserItem[]` 公开资料列表：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `userID` | `string` | OpenIM 用户 ID，客户端合并标识。 |
| `nickname` | `string` | 账号级公开昵称。 |
| `faceURL` | `string` | 账号级公开头像地址。 |
| `ex` | `string` | 账号级扩展字段，格式由业务约定。 |

返回数组不保证与输入 ID 列表按位置一一对应。

该接口只读取其他用户的公开信息。如需获取或管理当前登录账号的完整资料，请参考[获取当前用户资料](/sdk/react-native/user/profile/get-self-user-info)与[更新当前用户资料](/sdk/react-native/user/profile/set-self-info)。
