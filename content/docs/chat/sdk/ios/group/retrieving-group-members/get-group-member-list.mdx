```objc
[[OIMManager manager] getGroupMemberList:groupID filter:OIMGroupMemberFilterAll
  offset:0 count:50
  onSuccess:^(NSArray<OIMGroupMemberInfo *> *members) { [self replaceFirstPage:members]; }
  onFailure:^(NSInteger code, NSString *message) { [self showErrorCode:code message:message]; }];
```

When loading more, increment `offset` by the number of items requested. The iOS SDK does not provide a separate method for retrieving muted members. To identify them, retrieve members by page and inspect `muteEndTime`, which is measured in seconds.
