Delete a specified conversation group. This operation only dissolves the organizational grouping; it does not delete conversations or purge their message histories.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationGroupID` | `String` | Yes | Target conversation group ID (`conversationGroupID`, not a chat group `groupID`). |

## Code example

```dart
await OpenIM.iMManager.conversationGroupManager.deleteConversationGroup(
  conversationGroupID: conversationGroupID,
);
```

## Return value

A successful `Future` indicates that the deletion request was processed by the server. The client removes the group from its local state using `conversationGroupID` as the key.

## State changes after the call

Multi-device synchronization and arriving changes trigger `onConversationGroupDeleted` notifications. For complete listener integration, see [Conversation groups overview](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups).
