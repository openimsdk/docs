```dart
final messages = await OpenIM.iMManager.messageManager
    .getConversationPinnedMsg(conversationID: conversationID);
replacePinnedMessages(conversationID, messages);
```

Future 返回 `List<Message>`，不包含置顶时间或操作者。查询不触发 `onChangedPinnedMsg`；按非空 `clientMsgID` 去重。详细变化见[置顶或取消置顶消息](/sdk/flutter/message/managing-messages/set-message-pinned)。
