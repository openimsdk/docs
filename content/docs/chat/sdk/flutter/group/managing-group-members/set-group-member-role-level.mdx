A group owner can promote regular members to administrators or demote administrators back to regular members:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID. |
| `userID` | `String` | Yes | Target member user ID. |
| `roleLevel` | `int` | Yes | Role level integer from the role level enum table below. |

### Role level enumeration

| Enum Option | Value | Behavior |
| --- | --- | --- |
| `GroupRoleLevel.member` | `20` | Regular member (pass this value to demote an administrator). |
| `GroupRoleLevel.admin` | `60` | Group administrator (pass this value to promote a member). |
| `GroupRoleLevel.owner` | `100` | Group owner (read-only identifier; cannot be assigned via this API; use [Transfer group owner](/sdk/flutter/group/managing-group-members/transfer-group-owner) to change ownership). |

## Code example

```dart
await OpenIM.iMManager.groupManager.setGroupMemberInfo(
  groupMembersInfo: SetGroupMemberInfo(
    groupID: groupID,
    userID: targetUserID,
    roleLevel: GroupRoleLevel.admin,
  ),
);
```

## Return value

A successful `Future` indicates that the member role level was updated on the server.

## State changes after the call

Connected clients in the group receive member profile update events. The client updates the local member record and permissions using `groupID:userID` as the key. For complete listener integration, see [Retrieving group members overview](/sdk/flutter/group/retrieving-group-members/overview-retrieving-group-members).
