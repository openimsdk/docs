A group owner or administrator can remove specified members from a group:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID. |
| `reason` | `String` | Yes | Reason or administrative note for removing the members. |
| `userIDList` | `List<String>` | Yes | List of user IDs to remove from the group. |

## Code example

```dart
await OpenIM.iMManager.groupManager.kickGroupMember(
  groupID: groupID,
  reason: 'Member roster adjustments',
  userIDList: selectedUserIDs,
);
```

## Return value

A successful `Future` indicates that the member removal request has been processed by the server.

## State changes after the call

Connected clients in the group receive member removal notifications via `onGroupMemberDeleted`. Remove the corresponding records from local group member rosters using `groupID:userID` as the key. For complete listener integration, see [Retrieving group members overview](/sdk/flutter/group/retrieving-group-members/overview-retrieving-group-members).
