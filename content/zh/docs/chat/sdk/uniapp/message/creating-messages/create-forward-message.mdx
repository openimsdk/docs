---
title: '创建逐条转发消息'
description: '根据一条已有消息创建可发送到其他会话的转发消息。'
sourcePath: '/sdk/uniapp/message/creating-messages/create-forward-message'
---

`createForwardMessage()` 接收完整的 `OpenIMMessageItem`，并创建一条内容相同、可发送到其他会话的待发送消息。

```uts
import { createForwardMessage } from '@/uni_modules/unix-openim-sdk'

const message = await createForwardMessage(sourceMessage)
if (message == null) return
```

`sourceMessage` 应来自消息查询结果或消息事件，并且已经发送成功。转发前需要检查当前用户是否仍有权查看和传播消息内容；本地路径、已失效资源地址或只在当前设备有效的扩展信息不能假定在目标会话中仍可使用。

Promise 成功只返回新的待发送 `OpenIMMessageItem | null`，不会修改原消息，也不会自动选择或发送到目标会话。需要把多条消息汇总成一张记录卡片时，使用[创建合并转发消息](/sdk/uniapp/message/creating-messages/create-merger-message)。
