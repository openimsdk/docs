查询指定会话中某位成员当前是否处于“正在输入”状态：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 会话 ID。 |
| `userID` | `String` | 是 | 待查询输入状态的目标用户 ID。 |

```dart
final platformIDs =
    await OpenIM.iMManager.conversationManager.getInputStates(
  conversationID,
  otherUserID,
);

setTyping(otherUserID, platformIDs?.isNotEmpty == true);
```

## 返回结果

Future 成功返回平台 ID 列表（`List<int>?`），表示目标用户当前正在处于输入状态的平台 ID 集合；返回为空或 `null` 表示当前未处于输入中。

该接口只返回调用瞬时的状态快照，不会触发事件通知。群聊中请勿频繁轮询全体成员；进入会话页面或网络恢复后可查询对端状态，后续实时输入状态请参考[上报输入状态](/sdk/flutter/message/composing-messages/update-typing-status)中的事件监听。
