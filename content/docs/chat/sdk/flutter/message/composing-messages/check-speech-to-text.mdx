```dart
try {
  await OpenIM.iMManager.messageManager.speechToTextCapabilities();
  setTranscriptionAvailable(true);
} catch (error) {
  setTranscriptionAvailable(false);
}
```

This method returns `Future<void>`. Success means only that the transcription entry point can be shown; it does not return fields for formats, sample rates, durations, or sizes. Obtain exact limits from business configuration that matches the deployment rather than inventing a capability object.
