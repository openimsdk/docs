```objc
OIMMessageInfo *message =
    [OIMMessageInfo createTextAtAllMessage:@"@all Please review the announcement"
                               displayText:@"@all"
                                   message:nil];
```

Pass the complete quoted message through `message` when applicable. This selector only creates the object. Whether the sender may mention everyone is ultimately validated against the current group permissions and OpenIMServer.
