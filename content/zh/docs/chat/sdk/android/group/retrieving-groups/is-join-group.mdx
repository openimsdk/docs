检查当前登录用户是否已经是指定群组的成员。常用于从搜索结果、分享链接或扫码进入群聊前的前置权限判断。

```java
String groupID = "group_123";

OpenIMClient.getInstance().groupManager.isJoinGroup(
    groupID,
    new OnBase<Boolean>() {
        @Override
        public void onSuccess(Boolean joined) {
            // joined 为 true 表示当前用户已加入该群
        }

        @Override
        public void onError(int code, String error) {
            // 处理校验失败
        }
    }
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 待校验的目标群组全局唯一 ID。 |
| `base` | `OnBase<Boolean>` | 是 | 异步请求回调。 |

## 返回结果

成功回调返回布尔值 `Boolean`：
- `true`：表示当前用户已在群内，可直接打开群聊会话。
- `false`：表示当前用户未入群，界面可引导用户发起[申请加入群组](/sdk/android/group/join-group)。
