---
title: '删除本地消息'
description: '使用 iOS SDK 仅删除当前设备上的一条消息。'
sourcePath: '/sdk/ios/message/managing-messages/delete-local-message'
---

```objc
[[OIMManager manager] deleteMessageFromLocalStorage:conversationID
    clientMsgID:clientMsgID
    onSuccess:nil
    onFailure:nil];
```

成功只表示当前设备本地消息已删除。服务端仍保留记录，重建数据库后可能再次同步；该操作不通知其他设备或成员，也不是撤回。
