---
title: '查询 SDK 版本'
description: '读取当前 HarmonyOS HAR 内置的 OpenIMClientSDK 版本。'
sourcePath: '/sdk/harmony/getting-started/get-sdk-version'
---

`version()` 返回当前 HAR 实际加载的 OpenIMClientSDK 版本，适合在诊断页、启动日志或兼容性检查中确认运行基线。

```ts
import sdk, { VersionResp } from '@openimsdk/imsdk';

const response: VersionResp = await sdk.version();
console.info(`OpenIMClientSDK version: ${response.version}`);
```

Promise 成功后，`version` 字段是 SDK 版本字符串。该值用于排查制品是否符合预期，不应代替应用自己的版本号或作为服务端授权凭据。

如果多个模块都需要版本信息，应在应用级服务中查询一次并复用结果，避免在页面渲染期间反复调用。
