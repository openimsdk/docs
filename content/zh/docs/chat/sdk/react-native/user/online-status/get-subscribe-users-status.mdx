获取当前账号已订阅用户的在线状态列表。

```ts
const states = await OpenIMSDK.getSubscribeUsersStatus();
```

## 返回结果

调用完成后返回已订阅用户的 `UserOnlineState[]` 在线状态列表。客户端应以 `userID` 为合并标识更新本地用户的在线状态缓存。若目标用户尚未订阅，请先参考[订阅用户在线状态](/sdk/react-native/user/online-status/subscribe-users-status)。
