将指定用户加入当前账号的黑名单。

```ts
await OpenIMSDK.addBlack({
  toUserID,
  ex,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `toUserID` | `string` | 是 | 要加入黑名单的用户 ID。 |
| `ex` | `string` | 否 | 黑名单关系的扩展信息。 |

## 返回结果

调用完成后，目标用户已被加入黑名单。

加入黑名单后会触发 `OnBlackAdded` 事件通知。客户端应以 `userID` 为合并标识将该用户追加到本地黑名单列表中。完整事件监听说明见[获取黑名单](/sdk/react-native/user/blacklist/get-black-list)。
