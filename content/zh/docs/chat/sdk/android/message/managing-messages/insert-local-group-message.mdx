---
title: '插入本地群聊消息'
description: '使用 insertGroupMessageToLocalStorage 插入仅当前设备可见的群聊消息。'
sourcePath: '/sdk/android/message/managing-messages/insert-local-group-message'
---

传入群 ID 与发送者 ID，消息不会同步到其他设备。

```java
messageManager.insertGroupMessageToLocalStorage(callback, message, groupID, senderUserID);
```
