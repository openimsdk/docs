---
title: '标记或取消标记会话'
description: '设置当前用户对指定会话的标记状态。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/mark-conversation'
---

标记后会话进入会话分组中的内置“标记一组”，无需再调用分组成员 API。

```ts
import sdk, { SetConversationReq } from '@openimsdk/imsdk';

const request: SetConversationReq = {
  conversationID: conversationID,
  isMarked: true,
};
await sdk.setConversation(request);
```

传入 `true` 表示标记，传入 `false` 表示取消标记。标记与置顶相互独立。接口调用成功后，SDK 会触发会话变更事件；客户端收到通知后根据 `conversationID` 更新对应会话的 `isMarked` 属性，完整监听配置请参考[获取会话列表](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list)。
