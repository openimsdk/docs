从当前设备本地存储中删除指定会话的一条消息。

```ts
await OpenIMSDK.deleteMessageFromLocalStorage({
  conversationID,
  clientMsgID,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 消息所属的会话 ID。 |
| `clientMsgID` | `string` | 是 | 要删除的消息客户端 ID。 |

## 返回结果

调用完成后，目标消息已从当前设备本地数据库中删除。

此操作仅删除当前设备本地数据，不会同步至服务端或其他设备，也不会触发多端消息删除事件。客户端应以 `clientMsgID`（限定在所属 `conversationID` 会话内）从消息列表中移除该记录。若需在多端同步删除消息，请参考[批量删除消息](/sdk/react-native/message/managing-messages/delete-saved-messages)。
