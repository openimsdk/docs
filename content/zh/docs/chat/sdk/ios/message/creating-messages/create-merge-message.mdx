调用创建合并消息方法可将多条选中的历史消息打包为一条合并转发卡片消息。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createMergeMessage:selectedMessages
                                 title:@"聊天记录"
                           summaryList:summaries];
```

## 参数说明

- `messageList`：需要合并的历史消息对象列表（`NSArray<OIMMessageInfo *> *`）。
- `title`：合并消息卡片的外层展示标题（`NSString *`），如 `群聊的聊天记录`。
- `summaryList`：在合并卡片中预览展示的前几条摘要文本数组（`NSArray<NSString *> *`）。

## 返回结果

- 返回初始化的合并转发消息对象（`OIMMessageInfo *`），其内容类型为合并消息。
- 该方法不会修改被合并的原始消息。创建后需调用[发送消息](/sdk/ios/message/sending-messages/send-message)进行投递。
