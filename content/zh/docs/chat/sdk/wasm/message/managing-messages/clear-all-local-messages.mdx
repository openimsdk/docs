title: '清理全部本地消息'
description: '使用 WASM SDK 清理当前账号的全部本地消息。'
sourcePath: '/sdk/wasm/message/managing-messages/clear-all-local-messages'
---

调用 `deleteAllMsgFromLocal()` 可一次性清空当前登录账号在当前设备本地数据库中的全部历史消息，常用于“清理本机聊天缓存”等系统设置场景。该操作影响全局所有会话，无需传入业务参数。

```ts
await openimsdk.deleteAllMsgFromLocal();
resetAllMessages();
```

接口调用成功表示当前设备的本地离线消息缓存已清理完毕。业务层应同步重置前端维护的消息列表、搜索缓存与分页游标。需要注意：服务端仍保留云端消息记录，若后续重新登录或重新同步，消息仍可能被拉取；该操作仅作用于当前设备本地，不会向服务端同步删除，亦不会向其他端发送删除通知。
