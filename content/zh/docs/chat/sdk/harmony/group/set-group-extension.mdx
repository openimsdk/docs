`ex` 是完整字符串，SDK 不会自动合并其中的 JSON 字段。多个业务模块共用时，应划分稳定命名空间，并在写入前保留其他模块的数据。

```ts
import sdk, { SetGroupInfoReq } from '@openimsdk/imsdk';

const request: SetGroupInfoReq = {
  groupID: groupID,
  ex: JSON.stringify({ projectID: 'project-42' }),
};
await sdk.setGroupInfo(request);
```

实际项目已有扩展数据时，应按业务约定解析旧值、合并本次字段，再序列化整个新值。Promise 成功不表示群资料事件已经到达；事件同步方式见[群组概览](/sdk/harmony/group/overview-group)。
