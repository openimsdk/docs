Use `createImageMessageFromFullPath()` to create a message from an image stored on the device.

```ts
const message = await OpenIMSDK.createImageMessageFromFullPath(imagePath);
```

`imagePath` is the full path to the image on the device. The call returns a `MessageItem` ready to send. When you use [Send a message](/sdk/react-native/message/sending-messages/send-message), the SDK uploads the local resource.
