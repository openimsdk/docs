---
title: '清理全部消息'
description: '使用 iOS SDK 清理当前账号本地与服务端的全部消息。'
sourcePath: '/sdk/ios/message/managing-messages/clear-all-messages'
---

```objc
[[OIMManager manager] deleteAllMsgFromLocalAndSvrWithOnSuccess:^(NSString *data) {
    [self resetAllMessageSnapshots];
} onFailure:nil];
```

执行前必须二次确认。成功表示当前账号本地与服务端保存的消息已清理，不会删除其他会话成员保存的副本，也不能证明其他设备已刷新。会话摘要可通过 delegate 更新；必要时重新查询，以当前结果为准。
