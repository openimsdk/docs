---
title: '申请加入群组'
description: '使用 joinGroup 提交入群申请或加入请求。'

---

使用 `joinGroup()` 提交入群请求。`joinSource` 表示入群来源：`2` 表示邀请，`3` 表示搜索，`4` 表示二维码；带扩展数据时使用五参数重载。

```java
OpenIMClient.getInstance().groupManager.joinGroup(new OnBase<String>() {
    @Override public void onSuccess(String data) { markJoinSubmitted(groupID); }
    @Override public void onError(int code, String error) { showJoinError(error); }
}, groupID, "希望加入项目讨论", 3, "{\"from\":\"search\"}");
```

[入群验证方式](/sdk/android/group/set-group-join-verification)决定用户是直接加入还是先提交申请。需要审核时，成功回调只表示申请已提交；实际加入后通过 `onJoinedGroupAdded` 接收通知。
