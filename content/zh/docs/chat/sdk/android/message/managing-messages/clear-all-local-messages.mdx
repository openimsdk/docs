---
title: '清理全部本地消息'
description: '使用 deleteAllMsgFromLocal 清理当前设备的全部消息。'
sourcePath: '/sdk/android/message/managing-messages/clear-all-local-messages'
---

`deleteAllMsgFromLocal()` 只清理当前登录账号在本设备上的全部消息，不删除服务端记录，也不影响其他设备或其他用户。执行前应明确提示用户影响范围。

```java
OpenIMClient.getInstance().messageManager.deleteAllMsgFromLocal(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 清空当前账号在本设备上的消息列表和相关页面状态。
        }

        @Override
        public void onError(int code, String error) {
            // 保留现有页面数据，并提示清理失败。
        }
    }
);
```

成功回调表示本地清理已经完成。该操作不会触发其他客户端的消息事件；当前设备之后仍可能从服务端重新同步到可用的历史消息。
