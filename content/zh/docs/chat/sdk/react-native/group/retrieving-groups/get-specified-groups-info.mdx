根据群组 ID 数组批量查询指定群组的详细资料。该查询适合在已知群组 ID 时拉取最新群资料，不用于按名称搜索公开群。

```ts
const groups = await OpenIMSDK.getSpecifiedGroupsInfo([
  'group-001',
  'group-002',
]);
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `groupIDs` | `string[]` | 是 | 要查询的群组 ID 数组。 |

## 返回结果

调用完成后返回匹配的 `GroupItem[]`。返回的数组不保证与输入 ID 的顺序严格对应，客户端应使用 `groupID` 与现有群组数据建立映射与合并。各字段详细说明见[群组概览](/sdk/react-native/group/overview-group)。
