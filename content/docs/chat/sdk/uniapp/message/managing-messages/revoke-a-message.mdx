```uts
import { off, onNewRecvMessageRevoked, revokeMessage } from '@/uni_modules/unix-openim-sdk'

const revokedSubscription = onNewRecvMessageRevoked(mergeRevokedInfo)
await revokeMessage({ conversationID, clientMsgID })
off(revokedSubscription)
```

The server enforces sender, time, and permission rules. Keep a revoked placeholder instead of blindly removing the array entry; Promise and event order is not guaranteed.
