---
title: '拒绝好友申请'
description: '使用 refuseFriendApplication() 拒绝好友申请。'
sourcePath: '/sdk/android/user/friend-applications/refuse-friend-application'
---

```java
OpenIMClient.getInstance().friendshipManager.refuseFriendApplication(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 拒绝好友申请成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    applicantUserID,
    "暂不添加"
);
```

`applicantUserID` 是申请方用户 ID，最后一个参数是处理附言。成功 callback 表示拒绝好友申请请求完成；申请状态通过 `OnFriendshipListener` 通知，`handleResult == 2` 表示已拒绝。
