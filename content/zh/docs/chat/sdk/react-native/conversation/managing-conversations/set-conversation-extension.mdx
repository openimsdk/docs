设置或更新指定会话的自定义业务扩展字段 `ex`。

```ts
await OpenIMSDK.setConversation({
  conversationID,
  ex: JSON.stringify({
    category: 'work',
  }),
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 要设置的会话 ID。 |
| `ex` | `string` | 否 | 会话扩展字符串，可按业务需要传递 JSON 字符串或其他格式的扩展信息。 |

如果业务需要保留已有扩展内容，应先读取当前 `ex`，再按业务规则合并更新后写回。

## 返回结果

调用完成后，会话扩展字段已更新。

更新成功后会触发 `OnConversationChanged` 事件；客户端应使用 `conversationID` 定位目标会话，并合并最新的 `ex` 扩展内容。完整监听方式见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。
