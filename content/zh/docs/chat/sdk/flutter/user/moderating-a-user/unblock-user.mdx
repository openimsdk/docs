```dart
await OpenIM.iMManager.friendshipManager.removeBlacklist(
  userID: targetUserID,
);
```

Future 成功不等于事件已到达。`onBlackDeleted` 是本页归属事件，应纳入唯一 `OnFriendshipListener`，按非空 `userID` 从黑名单移除；完整快照使用已有的黑名单列表页面校准。
