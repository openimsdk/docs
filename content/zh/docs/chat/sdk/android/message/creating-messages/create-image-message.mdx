---
title: '创建图片消息'
description: '使用相对于 SDK 初始化数据目录的路径创建图片消息。'
sourcePath: '/sdk/android/message/creating-messages/create-image-message'
---

```java
Message message = OpenIMClient.getInstance().messageManager
    .createImageMessage(imagePath);
```

图片文件应位于 SDK 初始化时配置的数据目录内，`imagePath` 传入相对于该目录的路径。本方法只创建待发送对象，普通发送流程负责上传图片。
