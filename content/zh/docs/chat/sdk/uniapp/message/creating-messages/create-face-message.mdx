`createFaceMessage()` 用于发送双方约定的表情资源。`index` 是表情编号，`data` 是与该编号配套的业务数据字符串；SDK 不负责下载、校验或渲染表情资源。

```uts
import { createFaceMessage } from '@/uni_modules/unix-openim-sdk'

const message = await createFaceMessage({
  index: 1001,
  data: JSON.stringify({ packID: 'default', name: 'wave' }),
})
if (message == null) return
```

发送端和接收端应使用一致的表情编号与数据协议，并为未知编号或无法解析的数据提供降级展示。不要把未经校验的远端脚本或可执行内容写入 `data`。

Promise 成功只返回待发送的 `OpenIMMessageItem | null`，不会发送消息或触发表情资源下载。
