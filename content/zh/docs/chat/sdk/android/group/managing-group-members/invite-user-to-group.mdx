---
title: '邀请用户加入群组'
description: '使用 inviteUserToGroup 邀请一组用户加入指定群组。'
sourcePath: '/sdk/android/group/managing-group-members/invite-user-to-group'
---

传入群 ID、待邀请用户 ID 列表和邀请说明。服务端根据群设置和当前用户权限决定是否立即加入。

```java
OpenIMClient.getInstance().groupManager.inviteUserToGroup(new OnBase<String>() {
    @Override public void onSuccess(String data) { markInviteSubmitted(groupID); }
    @Override public void onError(int code, String error) { showInviteError(error); }
}, groupID, inviteeUserIDs, "邀请加入项目讨论");
```

成员实际加入后以 `onGroupMemberAdded` 合并，不能仅以提交成功显示为已加入。
