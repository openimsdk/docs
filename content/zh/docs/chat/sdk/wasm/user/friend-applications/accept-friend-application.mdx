title: '接受好友申请'
description: '同意指定用户的好友申请。'
sourcePath: '/sdk/wasm/user/friend-applications/accept-friend-application'
---

处理收到的好友申请时，`toUserID` 应填写申请人的用户 ID，而不是当前用户 ID。`handleMsg` 是本次处理附带的信息；没有内容时传空字符串。

```ts
await openimsdk.acceptFriendApplication({ toUserID: applicantUserID, handleMsg: '' });
```

Promise 成功表示服务端已完成本次同意请求。申请记录与好友关系是两份不同的数据：收到申请状态变化事件后更新对应申请，收到 `OnFriendAdded` 后再按 `userID` 写入好友列表。完整事件处理见[获取收到的好友申请](/sdk/wasm/user/friend-applications/get-friend-application-list-as-recipient)和[分页获取好友列表](/sdk/wasm/user/friends/get-friend-list-page)。
