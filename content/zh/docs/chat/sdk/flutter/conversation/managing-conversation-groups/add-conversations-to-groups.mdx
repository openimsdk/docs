使用 `addConversationsToGroups()` 将一个或多个会话加入一个或多个会话分组。该操作只增加关联，不会创建会话或改变消息发送目标。

```dart
await OpenIM.iMManager.conversationGroupManager.addConversationsToGroups(
  conversationGroupIDs: [conversationGroupID],
  conversationIDs: [conversationID],
);
```

`conversationGroupIDs` 和 `conversationIDs` 都必填，分别表示目标分组和要加入的会话。

## 返回结果

固定 Flutter 声明返回未具体化的 `Future`。成功表示关联请求已完成，不等同于 listener 已到达所有端。

之后新增的关联由 `onConversationGroupMemberAdded` 提供，完整处理见[会话分组概览](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups)。
