```dart
await OpenIM.iMManager.groupManager.setGroupInfo(
  GroupInfo(
    groupID: groupID,
    needVerification: GroupVerification.allNeedVerification,
  ),
);
```

| Constant | Value | Meaning |
| --- | --- | --- |
| `GroupVerification.applyNeedVerificationInviteDirectly` | `0` | User applications require approval; invitations from group members join directly. |
| `GroupVerification.allNeedVerification` | `1` | Applications and invitations from regular members require approval; invitations from the owner or administrators do not. |
| `GroupVerification.directly` | `2` | Applications and invitations both join directly. |

After the `Future` succeeds, reconcile the final state from `onGroupInfoChanged` or a new group-profile query.
