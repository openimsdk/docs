---
title: '删除好友'
description: '删除当前用户与指定用户的好友关系。'
sourcePath: '/sdk/wasm/user/friends/delete-friend'
---

```ts
await openimsdk.deleteFriend(friendUserID);
```

`friendUserID` 是要删除的好友用户 ID。

Promise 成功表示好友关系删除请求已完成，可以结束提交状态。好友列表和资料卡应在收到 `OnFriendDeleted` 后移除对应 `userID` 的记录；如果没有收到事件，可重新查询好友列表并以最新结果为准。完整监听示例见[分页获取好友列表](/sdk/wasm/user/friends/get-friend-list-page)。
