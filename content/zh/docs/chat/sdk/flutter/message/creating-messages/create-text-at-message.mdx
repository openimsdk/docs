构建群聊中提及（@）指定成员或全体成员的文本消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `text` | `String` | 是 | 包含 @ 展示文本的消息正文。 |
| `atUserIDList` | `List<String>` | 是 | 被提及的目标用户 ID 列表；若提醒全体成员可传入全体标识。 |
| `atUserInfoList` | `List<AtUserInfo>?` | 否 | 被提及成员的详细信息列表（包含用户 ID 与群昵称），用于辅助渲染。 |
| `quoteMessage` | `Message?` | 否 | 可选，被同时引用的原始消息对象；不引用则传 `null`。 |

```dart
final message = await OpenIM.iMManager.messageManager.createTextAtMessage(
  text: '@$userID 请确认',
  atUserIDList: [userID],
  atUserInfoList: [AtUserInfo(atUserID: userID, groupNickname: nickname)],
  quoteMessage: quotedMessage,
);
```

## 返回结果

Future 成功返回待发送的 @ 消息对象（`Message`），其内容存储在 `atTextElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送，也不会触发新消息事件通知。构建完成后，需将返回的 `Message` 对象传给[发送消息](/sdk/flutter/message/sending-messages/send-message)，并在发送方法中指定对应的群组 ID。
