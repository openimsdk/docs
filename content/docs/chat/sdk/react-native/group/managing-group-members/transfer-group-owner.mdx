Transfer group owner status to another existing member in the group:

```ts
await OpenIMSDK.transferGroupOwner({
  groupID: 'group-001',
  newOwnerUserID: 'user-002',
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group ID. |
| `newOwnerUserID` | `string` | Yes | User ID of the new group owner. This user must already be an active member of the group. |

## Return value

A resolved Promise confirms that the group ownership transfer has completed on the server.

Transferring ownership triggers `OnGroupMemberInfoChanged` notifications for both the former and new owners, as well as an `OnGroupInfoChanged` notification reflecting the group's new `ownerUserID`. Update local member records using the composite identifier `groupID:userID`, and update the group profile keyed by `groupID`. For complete event listeners, see [Get group member list by page](/sdk/react-native/group/retrieving-group-members/get-group-member-list).
