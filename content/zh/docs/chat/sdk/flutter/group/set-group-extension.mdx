title: '设置群组扩展字段'
description: '使用 Flutter SDK 设置群组的业务扩展字符串。'
sourcePath: '/sdk/flutter/group/set-group-extension'
---

```dart
await OpenIM.iMManager.groupManager.setGroupInfo(
  GroupInfo(
    groupID: groupID,
    ex: mergedExtensionJSON,
  ),
);
```

`ex` 是完整字符串，SDK 不会自动合并 JSON。写入前应读取旧值、保留其他业务命名空间，并让单一状态层负责串行更新。

Future 成功后，通过 `onGroupInfoChanged` 更新群资料，或重新查询确认最终结果。
