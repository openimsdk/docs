快速获取群组的群主与所有管理员成员列表：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupID` | `NSString *` | 目标群组 ID。 |

```objc
[[OIMManager manager] getGroupMemberOwnerAndAdmin:@"group_1001"
                                        onSuccess:^(NSArray<OIMGroupMemberInfo *> *members) {
                                            [self replaceOwnerAndAdmins:members];
                                        }
                                        onFailure:^(NSInteger code, NSString *message) {
                                            NSLog(@"getGroupMemberOwnerAndAdmin failed: %ld %@", (long)code, message);
                                        }];
```

状态以 `groupID:userID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回包含群主和所有管理员的 `NSArray<OIMGroupMemberInfo *> *` 数组。

该方法适用于在群信息页直接展示管理人员，无需拉取或遍历全量群成员。成员角色的后续变动通过 `onGroupMemberInfoChanged:` 事件分发，客户端应以 `groupID:userID` 为合并标识更新对应成员的角色状态。群成员监听设置与完整查询参见[群成员查询概览](/sdk/ios/group/retrieving-group-members/overview-retrieving-group-members)。
