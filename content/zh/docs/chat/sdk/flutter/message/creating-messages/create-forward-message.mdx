将已有的一条有效消息转发至其他单聊或群聊会话，构建待发送的转发消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `message` | `Message` | 是 | 需要转发的原始有效消息对象。 |

```dart
final message = await OpenIM.iMManager.messageManager
    .createForwardMessage(message: sourceMessage);
```

待转发的原始消息应当为已发送成功的真实消息记录。SDK 会为转发消息生成全新的客户端消息标识 `clientMsgID`，原始消息不会受到任何修改。

## 返回结果

Future 成功返回待发送的全新消息对象（`Message`）。

创建操作仅在本地组装消息数据，不会自动执行网络发送，不会修改原消息状态，也不会触发新消息事件通知。构建完成后，需将返回的 `Message` 实例传给[发送消息](/sdk/flutter/message/sending-messages/send-message)投递至目标会话。
