Configure whether regular group members are permitted to view the personal profile cards and details of fellow group members:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID. |
| `lookMemberInfo` | `int` | Yes | Whether viewing group member profile details is permitted. |

## Code example

```dart
await OpenIM.iMManager.groupManager.setGroupInfo(
  GroupInfo(
    groupID: groupID,
    lookMemberInfo: AllowType.notAllow,
  ),
);
```

`AllowType` enum options:

| Enum Option | Value | Behavior |
| --- | --- | --- |
| `AllowType.allow` | `0` | Members may view the profiles of other group members. |
| `AllowType.notAllow` | `1` | Members are restricted from viewing other members' profiles. |

This setting operates independently from [Set group member friend permission](/sdk/flutter/group/set-group-member-friend-permission).

## Return value

A successful `Future` indicates that the profile access policy has been updated on the server.

## State changes after the call

The server broadcasts group profile update notifications. The client updates `lookMemberInfo` on the local group record using `groupID` as the key. For complete listener integration, see [Groups overview](/sdk/flutter/group/overview-group). To recalibrate group state, call [Get specified groups info](/sdk/flutter/group/retrieving-groups/get-specified-groups-info).
