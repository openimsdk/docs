Control whether regular members have permission to view other members' profile details within the group:

```ts
await OpenIMSDK.setGroupInfo({
  groupID,
  lookMemberInfo: AllowType.NotAllowed,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group ID to update. |
| `lookMemberInfo` | `AllowType` | Yes | Member profile access permission setting. |

Access options:

| Enum value | Value | Description |
| --- | --- | --- |
| `AllowType.Allowed` | `0` | Allow members to view other members' profiles. |
| `AllowType.NotAllowed` | `1` | Disallow regular members from viewing other members' profiles. |

This setting controls profile viewing access and operates independently of [Set group member friend permission](/sdk/react-native/group/set-group-member-friend-permission).

## Return value

A resolved Promise confirms that the profile visibility setting was updated on the server.

The update triggers the `OnGroupInfoChanged` event. Use `groupID` to update the `lookMemberInfo` property of the group in local state. For full event listeners, see [Group overview](/sdk/react-native/group/overview-group).
