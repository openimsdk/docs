从本地文件系统的完整绝对路径构建待发送的图片消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `imagePath` | `String` | 是 | 设备文件系统中的完整绝对路径。 |

```dart
final message = await OpenIM.iMManager.messageManager
    .createImageMessageFromFullPath(imagePath: absolutePath);
```

传入的绝对路径必须在当前平台具备有效读取权限。

## 返回结果

Future 成功返回待发送的图片消息对象（`Message`），图片属性保存在 `pictureElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送或媒体上传，也不会触发新消息事件通知。构建完成后，需将返回的 `Message` 实例传给[发送消息](/sdk/flutter/message/sending-messages/send-message)，由 SDK 执行媒体上传与消息投递。若使用平台通用相对路径，请参考[创建图片消息](/sdk/flutter/message/creating-messages/create-image-message)；若图片已上传至对象存储，请参考[使用 URL 创建图片消息](/sdk/flutter/message/creating-messages/create-image-message-by-url)。
