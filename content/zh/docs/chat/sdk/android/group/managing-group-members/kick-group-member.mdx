`kickGroupMember()` 接收成员 ID 列表和移除说明。

```java
OpenIMClient.getInstance().groupManager.kickGroupMember(new OnBase<String>() {
    @Override public void onSuccess(String data) { /* 请求已完成。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
}, groupID, memberUserIDs, "已不再参与该项目");
```

成功回调表示移除请求已完成，不表示所有客户端界面已经更新。`onGroupMemberDeleted` 返回被移除成员的 `GroupMembersInfo`；按 `groupID:userID` 删除成员状态。完整 listener 注册见[群组概览](/sdk/android/group/overview-group)。
