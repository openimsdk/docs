按用户 ID 列表批量查询好友关系详情，包括好友备注、自定义扩展字段及基础资料。

```java
OpenIMClient.getInstance().friendshipManager.getFriendsInfo(
    new OnBase<List<UserInfo>>() {
        @Override
        public void onSuccess(List<UserInfo> friends) {
            for (UserInfo friend : friends) {
                // 使用 friends 更新好友资料
            }
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    Arrays.asList("user_a", "user_b"),
    true
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<List<UserInfo>>` | 是 | 异步请求回调。 |
| `userIDs` | `List<String>` | 是 | 目标好友用户 ID 列表，建议调用前去重并过滤空值。 |
| `filterBlack` | `boolean` | 是 | 传入 `true` 表示自动过滤黑名单用户；传入 `false` 则包含黑名单好友。 |

## 返回结果

成功回调返回包含命中好友的 `List<UserInfo>` 列表。客户端应以 `userID` 为主键合并本地好友资料，包含好友的公开基础信息、备注与扩展字段。

若目标用户非好友或因 `filterBlack == true` 被过滤，返回列表中将不包含该用户。如需在对方非好友时展示陌生人公开资料，请调用[获取指定用户资料](/sdk/android/user/user-profile/get-users-info)；若仅需判断双方好友关系，请参考[检查好友关系](/sdk/android/user/friends/check-friend)。
