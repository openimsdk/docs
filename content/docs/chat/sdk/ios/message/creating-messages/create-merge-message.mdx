```objc
OIMMessageInfo *message =
    [OIMMessageInfo createMergeMessage:selectedMessages
                                  title:@"Chat history"
                            summaryList:summaries];
```

The three arguments are an array of sent messages, the card title, and a positionally corresponding list of summaries. Generate each summary safely according to its message type. The returned object does not modify the source messages and is not sent automatically.
