`globalRecvMsgOpt` 是账号级默认策略，与昵称和头像相互独立。公开界面使用以下两个有效选项：

## 参数说明

| 枚举值                       | 数值 | 含义                                 |
| ---------------------------- | ---- | ------------------------------------ |
| `GlobalRecvMsgOpt.Normal`    | `0`  | 正常接收消息并允许通知。             |
| `GlobalRecvMsgOpt.NotNotify` | `2`  | 接收消息但不触发通知，即全天免打扰。 |

```ts
import sdk, { GlobalRecvMsgOpt, SetSelfInfoReq } from '@openimsdk/imsdk';

const request: SetSelfInfoReq = {
  userID: currentUserID,
  globalRecvMsgOpt: GlobalRecvMsgOpt.NotNotify,
};
await sdk.setSelfInfo(request);
```

关闭全局免打扰时改回 `GlobalRecvMsgOpt.Normal`。产品界面只应展示上表列出的两个有效选项。

单个会话的接收方式是更细粒度设置，请参考[设置会话消息接收方式](/sdk/harmony/conversation/managing-conversations/set-message-receive-option)。两者同时存在时，以 SDK 返回的最终会话状态展示，不要仅凭本地开关推断通知结果。Promise 成功后可等待当前用户资料事件，或参考[获取当前用户资料](/sdk/harmony/user/profile/get-self-user-info)重新查询确认。
