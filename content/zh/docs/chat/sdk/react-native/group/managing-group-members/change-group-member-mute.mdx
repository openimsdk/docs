设置指定成员的禁言时长；传入 `0` 可解除禁言。

```ts
await OpenIMSDK.changeGroupMemberMute({
  groupID: 'group-001',
  userID: 'user-002',
  mutedSeconds: 3600,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 目标群组 ID。 |
| `userID` | `string` | 是 | 要设置禁言的成员用户 ID。 |
| `mutedSeconds` | `number` | 是 | 禁言时长，单位为秒；传 `0` 解除禁言。 |

## 返回结果

调用完成后，成员禁言设置已生效。

成员状态变更会触发 `OnGroupMemberInfoChanged` 事件，事件载荷包含该成员的最新资料，可通过 `muteEndTime` 判断禁言截止时间。客户端应以 `groupID:userID` 复合标识定位并更新成员的禁言状态。完整事件监听说明见[分页查询群成员](/sdk/react-native/group/retrieving-group-members/get-group-member-list)。
