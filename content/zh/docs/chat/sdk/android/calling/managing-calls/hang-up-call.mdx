---
title: '挂断通话'
description: '使用 Android SDK 挂断已经建立的通话。'
sourcePath: '/sdk/android/calling/managing-calls/hang-up-call'
---

通话建立后，任一参与者都可以调用 `signalingHungUp()` 挂断。传入当前通话保存的完整 `SignalingInfo`，其中的 `roomID` 必须与当前媒体房间一致。

```java
OpenIMClient.getInstance().signalingManager.signalingHungUp(
    new OnBase<String>() {
        @Override
        public void onSuccess(String result) {
            // 信令操作已完成。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    signalingInfo
);
```

成功回调只表示挂断信令请求已完成，不代表本地资源已自动释放。应用应关闭通话界面、停止本地采集、断开媒体房间，并释放摄像头和麦克风。
