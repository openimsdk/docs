---
title: '清理全部本地消息'
description: '使用 WASM SDK 清理当前账号的全部本地消息。'
sourcePath: '/sdk/wasm/message/managing-messages/clear-all-local-messages'
---

```ts
await openimsdk.deleteAllMsgFromLocal();
resetAllMessageSnapshots();
```

这是账号级破坏性操作，应二次确认并清空全部内存消息快照。Promise 成功只表示本地数据库已清理；服务端仍保留历史，重建本地数据后消息可能再次同步。它不触发独立消息删除事件。
