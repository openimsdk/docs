构建带有引用上下文的文本回复消息。传入新的回复文本正文以及被引用的原 `Message` 对象，接收端展示该消息时会同时带出原消息的摘要或气泡。

```java
String replyText = "收到，我稍后处理。";

Message message = OpenIMClient.getInstance().messageManager.createQuoteMessage(
    replyText,
    quotedMessage
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `text` | `String` | 是 | 当前发送的回复文本正文。 |
| `quotedMessage` | `Message` | 是 | 被引用的完整历史消息对象。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.QUOTE`。

本接口仅在本地组装回复消息对象，不会自动发起网络发送。构建完成后，请调用[发送消息](/sdk/android/message/sending-messages/send-message)将消息投递至目标单聊或群聊。
