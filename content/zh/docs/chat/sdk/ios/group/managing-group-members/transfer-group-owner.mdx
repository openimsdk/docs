只有当前群主可以转让群主身份，目标用户必须是有效群成员：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupID` | `NSString *` | 目标群组 ID。 |
| `newOwner` | `NSString *` | 新群主的用户 ID。 |

```objc
[[OIMManager manager] transferGroupOwner:@"group_1001"
                                newOwner:@"user_002"
                               onSuccess:^(NSString * _Nullable data) {
                                   NSLog(@"transferGroupOwner success");
                               }
                               onFailure:^(NSInteger code, NSString *message) {
                                   NSLog(@"transferGroupOwner failed: %ld %@", (long)code, message);
                               }];
```

状态以 `groupID:userID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回操作结果。

服务端完成转让后：原群主降级为普通成员，新群主升级为群主角色。原群主和新群主的角色变更会通过 `onGroupMemberInfoChanged:` 事件分别通知各端，客户端以 `groupID:userID` 分别合并两名成员的最新角色。

如需即时刷新群管理层资料，可调用[获取群主和管理员](/sdk/ios/group/retrieving-group-members/get-group-member-owner-and-admin)；群成员完整监听与查询说明参见[群成员查询概览](/sdk/ios/group/retrieving-group-members/overview-retrieving-group-members)。

群主若需退出群组，必须先完成转让后再调用[退出群组](/sdk/ios/group/quit-group)；若该群已不再需要，群主也可以直接调用[解散群组](/sdk/ios/group/dismiss-group)。
