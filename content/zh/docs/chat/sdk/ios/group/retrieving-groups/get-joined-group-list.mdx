---
title: '获取已加入群组'
description: '查询当前用户加入的全部 iOS 群组。'
sourcePath: '/sdk/ios/group/retrieving-groups/get-joined-group-list'
---

```objc
[[OIMManager manager] getJoinedGroupListWithOnSuccess:
    ^(NSArray<OIMGroupInfo *> *groups) { [self replaceGroups:groups]; }
    onFailure:^(NSInteger code, NSString *message) { [self showErrorCode:code message:message]; }];
```

成功 callback 返回当前用户已加入的全部群组，不是公开群目录。大型列表应使用分页方法。
