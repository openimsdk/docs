向指定用户发起添加好友申请，并附带验证附言。

```java
OpenIMClient.getInstance().friendshipManager.addFriend(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 好友申请发送成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    "user_b",
    "你好，我是 Alex"
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `userID` | `String` | 是 | 申请接收方的用户 ID。 |
| `reqMsg` | `String` | 否 | 申请附言或验证说明信息。 |

## 返回结果

成功回调表示服务端已记录并转发该好友申请，不代表对方已同意。若对方已将当前账号设置为免审核直接添加，则会自动成为好友。

申请发出后，本端可查阅[获取发出的好友申请](/sdk/android/user/friend-applications/get-send-friend-application-list)确认状态；接收方将通过事件收到新申请通知，详见[获取收到的好友申请](/sdk/android/user/friend-applications/get-recv-friend-application-list)。好友申请的更新均以 `userID` 为标识进行跟踪。
