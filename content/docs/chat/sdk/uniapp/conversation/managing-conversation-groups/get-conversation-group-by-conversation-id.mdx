```uts
import { getConversationGroupByConversationID } from '@/uni_modules/unix-openim-sdk'

const result = await getConversationGroupByConversationID({ conversationID })
const groups = result?.conversationGroups ?? []
```

This <span className="enterprise-field-badge">Commercial</span> operation returns every group containing one conversation. A conversation can belong to several groups, so do not read only the first item. Deduplicate by `conversationGroupID`; an empty array means that the conversation currently belongs to no group, not that the query failed.
