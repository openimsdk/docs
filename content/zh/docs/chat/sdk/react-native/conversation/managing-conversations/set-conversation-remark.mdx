调用 `setConversation()` 设置当前账号的会话备注。

```ts
await OpenIMSDK.setConversation({
  conversationID,
  remark: '项目讨论',
});
```

## 参数说明

| 参数             | 类型     | 是否必填 | 说明                                   |
| ---------------- | -------- | -------- | -------------------------------------- |
| `conversationID` | `string` | 是       | 要设置的会话 ID。                      |
| `remark`         | `string` | 否       | 会话备注。传入空字符串可清除已有备注。 |

显示会话名称时，可根据产品规则优先使用 `remark`，没有备注时使用会话原有的 `showName`。会话备注不会更新用户资料或群组名称。

## 返回结果

调用完成后，会话的 `remark` 已更新。会话列表中的变化通过 `OnConversationChanged` 事件返回，事件监听方式见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。
