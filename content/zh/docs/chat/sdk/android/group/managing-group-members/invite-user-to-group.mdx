---
title: '邀请用户加入群组'
description: '使用 Android SDK 邀请一组用户加入指定群组。'
sourcePath: '/sdk/android/group/managing-group-members/invite-user-to-group'
---

传入群 ID、待邀请用户 ID 列表和邀请说明。调用成功表示邀请请求已提交，不保证所有用户都已经加入。

```java
OpenIMClient.getInstance().groupManager.inviteUserToGroup(new OnBase<String>() {
    @Override public void onSuccess(String data) { /* 请求已完成。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
}, groupID, inviteeUserIDs, "邀请加入项目讨论");
```

用户实际加入后，`onGroupMemberAdded` 返回新增的 `GroupMembersInfo`；按 `groupID:userID` 更新成员列表。完整 listener 注册见[群组概览](/sdk/android/group/overview-group)。
