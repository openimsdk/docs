使用业务侧已上传至对象存储的文件 URL 及元数据，构建待发送的文件消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `fileElem` | `FileElem` | 是 | 已上传文件的元数据模型，应包含真实的下载 URL、UUID、文件展示名称与字节大小。 |

```dart
final message = await OpenIM.iMManager.messageManager
    .createFileMessageByURL(fileElem: fileElem);
```

`FileElem` 中填写的 URL、文件名与大小必须来自真实的上传结果，以确保接收端能正确展示大小并下载文件。

## 返回结果

Future 成功返回待发送的文件消息对象（`Message`），其文件属性保存在 `fileElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送，也不会触发新消息事件通知。由于文件资源已由业务侧提前上传，构建完成后必须将返回的 `Message` 实例传给[发送不经 OSS 的消息](/sdk/flutter/message/sending-messages/send-message-not-oss)进行投递，避免重复上传。若需由 SDK 上传本地文件，请参考[创建文件消息](/sdk/flutter/message/creating-messages/create-file-message)。
