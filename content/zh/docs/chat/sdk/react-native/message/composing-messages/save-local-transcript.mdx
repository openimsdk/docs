将转写文字写入当前设备本地保存的语音消息中。传入更新后的完整消息对象，并保留原有消息字段。

```ts
const updatedMessage = {
  ...message,
  soundElem: {
    ...message.soundElem,
    text: {
      text: transcript,
      translate: message.soundElem?.text?.translate ?? {},
    },
  },
};

await OpenIMSDK.setMessageLocalContent({
  conversationID,
  message: updatedMessage,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 消息所属的会话 ID。 |
| `message` | `MessageItem` | 是 | 写入转写结果后的完整消息对象。 |

## 返回结果

调用完成后，转写文本已成功保存至当前设备的本地数据库。

此项修改仅保存在当前设备本地，不会向远端服务器同步，也不会触发多端消息更新事件。客户端应以 `clientMsgID`（限定在对应的 `conversationID` 中）更新当前视图中的语音消息展示。
