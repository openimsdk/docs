```uts
import { deleteConversation } from '@/uni_modules/unix-openim-sdk'

await deleteConversation(conversationID)
```

This removes the conversation entry without promising to delete its message history. Use the explicit conversation-and-message operation when that is the intended product action, and confirm destructive actions in the UI.
