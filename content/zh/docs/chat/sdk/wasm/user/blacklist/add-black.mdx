---
title: '将用户加入黑名单'
description: '将指定用户加入当前账号黑名单。'
sourcePath: '/sdk/wasm/user/blacklist/add-black'
---

当用户不希望继续接收指定账号的互动时，可以将该账号加入当前用户的黑名单。`toUserID` 是被加入黑名单的用户 ID；`ex` 是可选的业务扩展字符串，不需要扩展信息时可以省略。

```ts
await openimsdk.addBlack({
  toUserID,
  ex: JSON.stringify({ source: 'profile' }),
});
```

Promise 成功表示服务端已完成本次加入黑名单请求，但不代表黑名单事件已经到达。收到 `OnBlackAdded` 后，使用事件数据中的 `userID` 新增或更新黑名单记录；完整监听方式见[查询黑名单](/sdk/wasm/user/blacklist/get-black-list)。重复加入、权限限制等情况应按 Promise 的错误信息处理。
