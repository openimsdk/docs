开启或关闭群组整体禁言状态，调用者的操作权限由 OpenIMServer 校验：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `mute` | `bool` | 是 | `true` 开启全员禁言，`false` 关闭禁言。 |

```dart
await OpenIM.iMManager.groupManager.changeGroupMute(
  groupID: groupID,
  mute: true,
);
```

## 返回结果

Future 成功表示设置请求已由服务端处理完成。

收到群资料变更事件通知后，客户端以 `groupID` 为合并标识更新对应群资料，完整事件监听请参考[群组概览](/sdk/flutter/group/overview-group)；如需主动校准最新状态，可调用[查询指定群组资料](/sdk/flutter/group/retrieving-groups/get-specified-groups-info)。
