---
title: '获取入群申请角标数'
description: '查询当前账号的入群申请入口角标数量。'
sourcePath: '/sdk/harmony/group/group-applications/get-group-application-badge-count'
---

```ts
import sdk, { GetGroupApplicationBadgeCountResp } from '@openimsdk/imsdk';

const response: GetGroupApplicationBadgeCountResp = await sdk.getGroupApplicationBadgeCount();
setGroupApplicationBadge(response.count);
```

角标数由服务端维护，与“指定时间之后的未处理申请数”是两个独立概念。查询不会清除角标；角标后续变化通过申请角标事件同步，完整监听见[获取收到的入群申请](/sdk/harmony/group/group-applications/get-group-application-list-as-recipient)。
