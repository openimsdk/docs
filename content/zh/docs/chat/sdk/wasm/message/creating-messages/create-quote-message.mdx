---
title: '创建回复消息'
description: '创建一条包含原消息引用的回复消息。'
sourcePath: '/sdk/wasm/message/creating-messages/create-quote-message'
---

```ts
const { data: message } = await openimsdk.createQuoteMessage({
  text: '同意这个方案',
  message: JSON.stringify(originalMessage),
});
```

`text` 是新消息正文，`message` 是序列化后的原 `MessageItem`。不要手工拼接原消息字段。Promise 成功返回新的待发送对象，不会修改被引用消息。
