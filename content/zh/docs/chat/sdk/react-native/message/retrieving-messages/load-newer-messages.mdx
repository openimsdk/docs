从指定的锚点消息开始，向更新（较新）的时间方向分页读取历史消息。通常用于在用户跳转并定位到某条旧消息后，向下滑动聊天界面以继续加载该消息之后的对话记录。

```ts
const page = await OpenIMSDK.getAdvancedHistoryMessageListReverse({
  conversationID,
  startClientMsgID: anchorMessage.clientMsgID,
  count: 30,
  viewType: ViewType.History,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 要读取消息的会话 ID。 |
| `startClientMsgID` | `string` | 是 | 向更新方向读取时的起始锚点消息客户端 ID。 |
| `count` | `number` | 是 | 本次拉取的消息数量上限。 |
| `viewType` | `ViewType` | 是 | 场景类型，浏览普通聊天历史传入 `ViewType.History`。 |

## 返回结果

调用成功后返回 `AdvancedGetMessageResult` 对象：

- `messageList` (`MessageItem[]`)：本次拉取到的较新消息列表。
- `isEnd` (`boolean`)：标识是否已拉取到当前会话最新消息的尽头；为 `true` 表示后面没有更多更新的消息了。
- 更多返回字段详情请参考[加载历史消息](/sdk/react-native/message/retrieving-messages/load-older-messages)。
- 将获取到的消息合并到界面展示列表时，客户端应以 `clientMsgID` 为合并标识进行去重。
