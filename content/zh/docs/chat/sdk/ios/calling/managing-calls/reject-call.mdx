用户拒绝来电时，将收到的原始 `OIMSignalingInfo` 传给拒绝接口：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `signalingInfo` | `OIMSignalingInfo *` | 收到新邀请回调中提供的完整信令信息对象。 |

```objc
[[OIMManager manager] signalingReject:signalingInfo
                            onSuccess:^{ [self closeIncomingCall]; }
                            onFailure:^(NSInteger code, NSString * _Nullable message) {
    [self showCallError:code message:message ?: @"拒绝邀请失败"];
}];
```

通话状态以 `roomID` 为合并标识，参与者状态同时结合用户 ID。拒绝后应及时关闭当前来电展示界面并释放相关资源。

## 返回结果

成功回调 `onSuccess` 表示服务端已处理拒绝信令并通知对方。发起端与其他参与端随后会通过回调收到拒绝事件，完整处理流程见[处理通话事件](/sdk/ios/calling/managing-calls/handle-call-events)。
