---
title: '设置加好友权限'
description: '设置其他用户向当前账号发起好友关系时采用的处理策略。'
sourcePath: '/sdk/uniapp/user/profile/set-friend-add-permission'
---

`addFriendPermission` 控制其他用户添加当前账号时是否需要审核。该账号级策略属于商业版能力，与昵称、头像等普通资料相互独立。

| 数值 | 含义 |
| --- | --- |
| `0` | 允许其他用户发起好友申请，需要当前用户审核。 |
| `1` | 允许添加并直接建立好友关系，不需要当前用户审核。 |
| `2` | 不允许其他用户添加当前账号。 |

```uts
import { setSelfInfo } from '@/uni_modules/unix-openim-sdk'

const requireReview: 0 | 1 | 2 = 0

await setSelfInfo({
  addFriendPermission: requireReview,
})
```

当前 UTS 合同没有为这三个值导出具名常量，因此业务代码应集中封装数值与产品选项的映射，避免在多个页面散落无说明的数字。

该设置只影响后续添加行为，不会删除已有好友关系，也不会自动接受、拒绝或删除已经存在的好友申请。

Promise 成功表示设置请求已经完成，不等同于 `onSelfInfoUpdated()` 已到达。当前 `getSelfUserInfo()` 返回类型也没有公开 `addFriendPermission` 字段，因此不能通过该查询确认当前策略；需要展示时，应由业务层保存已确认的设置，或以服务端后续提供的查询合同为准。
