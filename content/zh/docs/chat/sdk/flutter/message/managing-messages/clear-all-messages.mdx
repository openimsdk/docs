同时清理当前登录账号在本地数据库与服务端的全部历史消息。该方法无需传入参数，适合在彻底清空账号聊天历史时使用：

```dart
await OpenIM.iMManager.messageManager.deleteAllMsgFromLocalAndSvr();
clearLocalMessageState();
```

## 返回结果

Future 成功表示服务端与当前设备本地均已完成全部消息的清理操作。

此操作属于不可撤销的账号级操作：它仅清除当前用户在本地与云端漫游中的历史记录，不会影响其他会话成员各自设备上保存的消息副本。Future 成功后，本地应清空当前所有消息缓存并刷新界面；会话摘要与未读计数随后可通过会话监听器更新，必要时可重新拉取会话列表校准状态。若仅需清理当前设备存储而保留云端漫游，请参考[清理全部本地消息](/sdk/flutter/message/managing-messages/clear-all-local-messages)；若只需删除单条消息，请参考[删除消息](/sdk/flutter/message/managing-messages/delete-saved-message)。
