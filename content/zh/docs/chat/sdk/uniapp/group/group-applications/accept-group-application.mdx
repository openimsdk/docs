群主或管理员可以使用 `acceptGroupApplication()` 同意一条待处理的入群申请。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 申请对应的群组 ID。 |
| `fromUserID` | `string` | 是 | 申请人的用户 ID，对应申请记录的 `userID`。 |
| `handleMsg` | `string` | 是 | 处理说明；没有说明时传空字符串。 |

```uts
import { acceptGroupApplication } from '@/uni_modules/unix-openim-sdk'

await acceptGroupApplication({
  groupID: application.groupID,
  fromUserID: application.userID,
  handleMsg: '同意加入',
})
```

Promise 成功表示 SDK 已完成本次同意请求。不要仅根据 Promise 成功在本地构造最终成员资料；收到 `onGroupApplicationAccepted()` 后更新申请记录，成员真正加入时再处理群成员事件。申请事件监听见[获取收到的入群申请](/sdk/uniapp/group/group-applications/get-group-application-list-as-recipient)。
