Only the current group owner can transfer ownership. The target user must be an active member of the specified group.

## Code example

```ts
import sdk, { TransferGroupOwnerReq } from '@openimsdk/imsdk';

const request: TransferGroupOwnerReq = {
  groupID: groupID,
  ownerUserID: targetUserID,
};
await sdk.transferGroupOwner(request);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group identifier. |
| `ownerUserID` | `string` | Yes | User ID of the new group owner. |

## Return value

Returns a Promise that resolves to `void` when ownership has transferred on the server.

## State changes after the call

Once the Promise resolves, roles for both the former owner and the new owner are updated. The SDK triggers group info and group member info changed events; clients update the group owner matching `groupID` and update member roles matching `groupID:userID`. For complete event listeners, see [Retrieve group member list](/sdk/harmony/group/retrieving-group-members/get-group-member-list). If the former owner intends to leave the group, transfer ownership first before calling [Leave group](/sdk/harmony/group/quit-group).
