---
title: '设置入群验证方式'
description: '通过 GroupInfo.needVerification 配置申请和邀请的入群验证规则。'
sourcePath: '/sdk/android/group/set-group-join-verification'
---

入群验证写入 `GroupInfo.needVerification`，再调用 `setGroupInfo()`。可使用 `GroupVerification` 常量：`APPLY_NEED_VERIFICATION_INVITE_DIRECTLY`、`ALL_NEED_VERIFICATION` 和 `DIRECTLY`。

```java
GroupInfo update = new GroupInfo();
update.setGroupID(groupID);
update.setNeedVerification(GroupVerification.ALL_NEED_VERIFICATION);

OpenIMClient.getInstance().groupManager.setGroupInfo(update, new OnBase<String>() {
    @Override public void onSuccess(String data) { /* 请求已完成。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
});
```

该设置影响后续入群请求，不替代对已存在申请的同意或拒绝处理。
