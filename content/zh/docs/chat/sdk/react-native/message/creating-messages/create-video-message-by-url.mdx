根据已上传视频及其封面图的 URL 资源信息创建视频消息。

```ts
const message = await OpenIMSDK.createVideoMessageByURL({
  videoPath: '',
  duration: 36,
  videoType: 'video/mp4',
  videoUUID: 'video-001',
  videoUrl: 'https://www.example.com/video.mp4',
  videoSize: 820000,
  snapshotPath: '',
  snapshotUUID: 'cover-001',
  snapshotSize: 42000,
  snapshotUrl: 'https://www.example.com/snapshot.png',
  snapshotWidth: 1280,
  snapshotHeight: 720,
  snapShotType: 'image/jpeg',
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `videoPath` | `string` | 是 | 本地视频路径；仅有远端资源时传空字符串。 |
| `duration` | `number` | 是 | 视频时长，单位为秒。 |
| `videoType` | `string` | 是 | 视频格式类型（MIME 类型）。 |
| `videoUUID`、`videoUrl`、`videoSize` | `string`、`string`、`number` | 是 | 视频资源标识、远端网络地址和字节大小。 |
| `snapshotPath` | `string` | 是 | 本地封面图路径；仅有远端资源时传空字符串。 |
| `snapshotUUID`、`snapshotUrl`、`snapshotSize` | `string`、`string`、`number` | 是 | 封面图资源标识、远端网络地址和字节大小。 |
| `snapshotWidth`、`snapshotHeight` | `number` | 是 | 封面图宽高尺寸，单位为像素。 |
| `snapShotType` | `string` | 否 | 封面图格式类型。 |

## 返回结果

调用完成后返回已创建的 `MessageItem` 消息对象，其中 `videoElem` 保存远端视频与封面图数据。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送已上传的媒体消息](/sdk/react-native/message/sending-messages/send-message-not-oss)直接投递该消息，无需重复上传视频和封面图。
