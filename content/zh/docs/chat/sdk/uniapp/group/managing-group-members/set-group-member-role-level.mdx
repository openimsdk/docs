---
title: '设置管理员'
description: '将普通群成员设置为管理员，或取消其管理员身份。'
sourcePath: '/sdk/uniapp/group/managing-group-members/set-group-member-role-level'
---

只有具备相应权限的群主可以调整管理员身份。`setGroupMemberInfo()` 的 `roleLevel` 类型为 `OpenIMGroupMemberRole`：

| 常量 | 数值 | 含义 | 是否用于本操作 |
| --- | --- | --- | --- |
| `OpenIMGroupMemberRoleNormal` | `20` | 普通成员。 | 是，用于取消管理员身份。 |
| `OpenIMGroupMemberRoleAdmin` | `60` | 管理员。 | 是，用于设置管理员。 |
| `OpenIMGroupMemberRoleOwner` | `100` | 群主。 | 否，只用于识别角色。 |

```uts
import {
  OpenIMGroupMemberRoleAdmin,
  setGroupMemberInfo,
} from '@/uni_modules/unix-openim-sdk'

await setGroupMemberInfo({
  groupID: groupID,
  userID: targetUserID,
  roleLevel: OpenIMGroupMemberRoleAdmin,
})
```

不能通过写入 `OpenIMGroupMemberRoleOwner` 转让群主，应使用[转让群主](/sdk/uniapp/group/managing-group-members/transfer-group-owner)。Promise 成功后，收到 `onGroupMemberInfoChanged()` 时再按 `groupID:userID` 更新成员角色。
