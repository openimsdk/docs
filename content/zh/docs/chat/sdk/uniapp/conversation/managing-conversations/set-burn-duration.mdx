---
title: '设置阅后即焚时长'
description: '设置指定会话在阅后即焚模式下的消息保留时长。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/set-burn-duration'
---

阅后即焚属于商业版能力。`burnDuration` 的单位为秒，只描述阅后即焚模式中的消息保留时长。

```uts
import { setConversation } from '@/uni_modules/unix-openim-sdk'

await setConversation({
  conversationID,
  burnDuration: 30,
})
```

启用或关闭模式需要另外设置 `isPrivateChat`，见[开启或关闭阅后即焚](/sdk/uniapp/conversation/managing-conversations/set-private-chat)。不要把 `burnDuration` 与服务端消息的周期删除配置混用。

Promise 成功表示设置请求已经完成。收到 `onConversationChanged()` 后，按 `conversationID` 更新对应会话的 `burnDuration`；完整监听见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。
