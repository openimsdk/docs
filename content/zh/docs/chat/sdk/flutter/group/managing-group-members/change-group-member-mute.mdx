群主或管理员可以设置单个成员在群组内的禁言时长，也可以通过传入 0 秒提前解除禁言：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `userID` | `String` | 是 | 被禁言或解除禁言的目标群成员用户 ID。 |
| `seconds` | `int` | 是 | 禁言时长（秒）。从当前调用时刻起算，传 `0` 表示解除禁言。 |

```dart
await OpenIM.iMManager.groupManager.changeGroupMemberMute(
  groupID: groupID,
  userID: targetUserID,
  seconds: 3600,
);
```

## 返回结果

Future 成功表示服务端已完成禁言时长设置，群成员状态按复合标识 `groupID:userID` 确定。

设置生效后，群内相关客户端会收到成员资料变更通知，事件载荷中的 `muteEndTime` 为秒级时间戳。完整的成员监听与增量合并逻辑请参考[群成员查询概览](/sdk/flutter/group/retrieving-group-members/overview-retrieving-group-members)。
