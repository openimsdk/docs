`getSpeechToTextCapabilities()` <span className="enterprise-field-badge">商业版</span> 返回能力信息。

```uts
import { getSpeechToTextCapabilities } from '@/uni_modules/unix-openim-sdk'

const capabilities = await getSpeechToTextCapabilities()
```

在展示转写入口前查询并缓存当前 session 的结果。能力可能随服务端、语言或账号变化；重新登录后刷新。没有能力时隐藏入口，不发送必然失败的请求。
