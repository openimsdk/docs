## Monitoring architecture

| Component | Purpose | Deployment method |
| --- | --- | --- |
| Prometheus | Collects and stores OpenIMServer time-series metrics | Enabled manually via profile |
| Alertmanager | Deduplicates, groups, and routes operational alerts | Enabled manually via profile |
| Grafana | Visualizes metrics through customizable dashboards | Enabled manually via profile |
| node-exporter | Collects host-level system metrics (CPU, RAM, disk, network) | Enabled manually via profile |

## Start the monitoring stack

### Start containers with Docker Compose

OpenIMServer uses Prometheus, Alertmanager, Grafana, and node-exporter for infrastructure and application observability. Standard `docker compose up -d` invocations **do not** start these services by default. Explicitly enable the `m` (monitoring) profile:

```bash
docker compose --profile m up -d
```

> **Windows deployments:** This Compose profile relies on host networking suitable for Linux. When running under Windows Docker Desktop, adjust the network mode and port forwarding in `docker-compose.yml`, and replace `127.0.0.1` scrape targets in `prometheus.yml` with your host machine's LAN IP address.

### Import OpenIMServer dashboards into Grafana

#### Sign in to Grafana

1. Log in to the OpenIM Admin Console, then select **Data Monitoring** in the left sidebar.
2. Sign in to Grafana using the default credentials (`admin` / `admin`).
3. Alternatively, navigate directly to `http://your_ip:13000` in your browser (replace `your_ip` with your server host IP).

![Grafana login page](/assets/guides/gettingStarted/assets/login1.png)

#### Add Prometheus as a data source

1. In the Grafana left navigation menu, open **Connections > Add new connection**.
2. Search for **Prometheus** and select it.
3. In the Prometheus server URL field, enter `http://your_ip:19090` (where `19090` is the Prometheus default port).
4. Click **Save & test** to confirm connectivity.

![Add Prometheus data source](/assets/guides/gettingStarted/assets/database.png)

![Configure Prometheus data source](/assets/guides/gettingStarted/assets/database2.png)

#### Import the OpenIMServer dashboard

1. Navigate to **Dashboards**, click **New**, and select **Import**.

![Create Grafana dashboard](/assets/guides/gettingStarted/assets/dashboard.png)

2. Import the OpenIMServer dashboard using either method:
   - Copy the raw JSON from [Demo.json](https://github.com/openimsdk/open-im-server/tree/main/config/grafana-template/Demo.json) and paste it into **Import via dashboard JSON model**.
   - Click **Upload dashboard JSON file** and select `open-im-server/config/grafana-template/Demo.json`.
3. Click **Load**.

![Load OpenIMServer dashboard](/assets/guides/gettingStarted/assets/dashboard2.png)

4. Select the Prometheus data source created in the previous step, then click **Import**.

![OpenIMServer metrics dashboard](/assets/guides/gettingStarted/assets/dashboard3.png)

OpenIMServer core performance metrics and service statuses are now visualized.

### Import node-exporter host metrics

1. Open **Dashboards**, click **New**, and select **Import**.

![Import node-exporter dashboard](/assets/guides/gettingStarted/assets/dashboard4.png)

2. Enter dashboard ID `1860` into **Grafana.com dashboard URL or ID**, then click **Load**.
3. Select your Prometheus data source and click **Import**.

![Load dashboard 1860](/assets/guides/gettingStarted/assets/dashboard5.png)

Once imported, host-level metrics including CPU utilization, memory pressure, disk I/O, and network throughput are displayed:

![node-exporter metrics](/assets/guides/gettingStarted/assets/dashboard6.png)
