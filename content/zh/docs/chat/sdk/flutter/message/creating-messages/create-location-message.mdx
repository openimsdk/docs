指定经纬度坐标与地名描述，构建待发送的地理位置消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `latitude` | `double` | 是 | 地理纬度。 |
| `longitude` | `double` | 是 | 地理经度。 |
| `description` | `String` | 是 | 位置描述或地标建筑名称（如“台北 101”）。 |

```dart
final message = await OpenIM.iMManager.messageManager.createLocationMessage(
  latitude: 25.033,
  longitude: 121.5654,
  description: '台北 101',
);
```

调用前应由业务层获取设备定位权限并校验经纬度有效性。

## 返回结果

Future 成功返回待发送的位置消息对象（`Message`），其位置数据存储在 `locationElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送，也不会触发新消息事件通知。构建完成后，需将返回的 `Message` 实例传给[发送消息](/sdk/flutter/message/sending-messages/send-message)投递至单聊或群聊会话。
