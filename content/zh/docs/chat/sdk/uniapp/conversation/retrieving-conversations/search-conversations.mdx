`searchConversation()` 在 SDK 本地会话数据中按 `showName` 搜索，适合实现会话列表内筛选。搜索词不能为空；该方法不会向服务端查询尚未同步到本地的会话。

```uts
import { searchConversation } from '@/uni_modules/unix-openim-sdk'

const result = await searchConversation(searchKeyword.trim())
const matchedConversations = result?.conversations ?? []
renderConversationResults(matchedConversations)
```

Promise 成功后返回 `OpenIMConversationListResult | null`，匹配会话位于 `conversations`。结果只反映调用时保存在本地的数据，查询本身不会触发事件。搜索界面需要实时更新时，监听[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)中的会话事件，并用 `conversationID` 更新或移除对应结果。
