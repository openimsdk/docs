`lookMemberInfo` 使用 `0 | 1` 表示权限，没有导出具名常量。这里的数值不能按常见布尔值理解。

| 数值 | 含义 |
| --- | --- |
| `0` | 允许成员查看其他成员资料。 |
| `1` | 不允许成员查看其他成员资料。 |

```uts
import { setGroupInfo } from '@/uni_modules/unix-openim-sdk'

const disallowMemberProfileAccess: 0 | 1 = 1

await setGroupInfo({
  groupID,
  lookMemberInfo: disallowMemberProfileAccess,
})
```

该设置与是否允许通过群组添加好友相互独立。Promise 成功后，收到 `onGroupInfoChanged()` 时再更新对应群资料；完整监听见[群组概览](/sdk/uniapp/group/overview-group)。
