创建群聊中的 @ 提醒消息。`text` 正文中的 @ 文本应与 `atUserIDList` 中的用户 ID 保持一致。

```ts
const message = await OpenIMSDK.createTextAtMessage({
  text: '@user-001 请确认发布内容。',
  atUserIDList: ['user-001'],
  atUsersInfo: [
    {
      atUserID: 'user-001',
      groupNickname: '小李',
    },
  ],
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `text` | `string` | 是 | 消息正文文本。 |
| `atUserIDList` | `string[]` | 是 | 被提及的用户 ID 列表。 |
| `atUsersInfo` | `AtUsersInfoItem[]` | 否 | 被提及用户在群内的展示信息，包含 `atUserID` 和 `groupNickname`。 |
| `message` | `MessageItem` | 否 | 引用或附带的原消息对象。 |

## 返回结果

调用完成后返回已创建的 `MessageItem` 消息对象，其中 `atTextElem` 保存被 @ 成员与展示名数据。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送消息](/sdk/react-native/message/sending-messages/send-message)将消息投递到群聊会话中。
