---
title: '更新群成员头像'
description: '更新指定成员在一个群组中的头像。'
sourcePath: '/sdk/harmony/group/managing-group-members/set-group-member-avatar'
---

`faceURL` 是群成员资料中的头像地址，只作用于指定群组。

```ts
import sdk, { SetGroupMemberInfoReq } from '@openimsdk/imsdk';

const request: SetGroupMemberInfoReq = {
  groupID: groupID,
  userID: targetUserID,
  faceURL: avatarURL,
};
await sdk.setGroupMemberInfo(request);
```

群内头像与用户账号头像是不同数据。修改账号头像时，应使用[更新当前用户资料](/sdk/harmony/user/profile/set-self-info)。Promise 成功后，通过成员资料变化事件更新对应记录。
