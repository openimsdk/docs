`getGroupMembersInfo()` 接收一个 `groupID` 和目标用户 ID 列表，返回这些用户在群内的 `GroupMembersInfo`。

```java
OpenIMClient.getInstance().groupManager.getGroupMembersInfo(
    new OnBase<List<GroupMembersInfo>>() {
        @Override public void onSuccess(List<GroupMembersInfo> members) { mergeMembers(members); }
        @Override public void onError(int code, String error) { showMemberQueryError(error); }
    }, groupID, userIDs);
```

返回空列表可能表示目标未在群内或无读取权限，应按业务需求处理。
