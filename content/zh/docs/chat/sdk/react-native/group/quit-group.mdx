退出当前账号已加入的群组。

```ts
await OpenIMSDK.quitGroup(groupID);
```

## 参数说明

`groupID` 为要退出的群组 ID。群主不能直接退出群组；若群主需要退出，必须先[转让群主](/sdk/react-native/group/managing-group-members/transfer-group-owner)。

## 返回结果

调用完成后，当前账号已成功退出目标群组。

退出群组后，当前用户客户端会触发 `OnJoinedGroupDeleted` 事件，事件载荷为对应的群组资料；群内其他成员会收到 `OnGroupMemberDeleted` 事件。客户端应以 `groupID` 为合并标识从已加入群组列表中移除该群，并清理本地相关群会话。完整事件监听说明见[群组概览](/sdk/react-native/group/overview-group)。
