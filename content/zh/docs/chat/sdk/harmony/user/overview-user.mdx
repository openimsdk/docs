OpenIMClientSDK 使用 `userID` 标识用户。用户领域负责当前账号资料、其他用户的公开资料、账号级消息接收方式、加好友权限和在线状态；好友、好友申请与黑名单属于“关系链”，群内昵称和角色属于群组。

## 资料来源

| 类型                 | 用途                                     |
| -------------------- | ---------------------------------------- |
| `IMUser`             | 当前用户和公开用户的账号级资料。         |
| `IMFriend`           | 好友关系资料，包含备注、置顶和关系扩展。 |
| `IMBlack`            | 当前账号维护的黑名单关系。               |
| `IMGroupMember`      | 群内昵称、头像、角色和禁言状态。         |
| `UserOnlinePlatform` | 指定用户当前在线的平台列表。             |

同一用户可能同时出现在多种数据来源中。联系人列表优先展示好友备注，群成员列表使用群内昵称，会话标题使用会话的 `showName`；不要用公开昵称覆盖其他领域的专属展示字段。
