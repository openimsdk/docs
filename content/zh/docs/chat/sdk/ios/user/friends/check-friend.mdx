---
title: '检查好友关系'
description: '使用 iOS SDK 检查指定用户的好友关系。'
sourcePath: '/sdk/ios/user/friends/check-friend'
---

```objc
[[OIMManager manager] checkFriend:@[@"user_a", @"user_b"]
                        onSuccess:^(NSArray<OIMSimpleResultInfo *> *results) {
                            [relationshipStore mergeResults:results];
                        }
                        onFailure:nil];
```

参数是待检查的用户 ID 数组。成功 callback 中每项 `OIMSimpleResultInfo` 以 `userID` 标识目标，`result == 1` 表示目标是好友且不在黑名单中；不要扩展为固定 SDK 未声明的其他状态。

该方法只查询关系快照，不触发好友 delegate。需要好友备注、头像或扩展字段时使用 [`getSpecifiedFriendsInfo:filterBlack:onSuccess:onFailure:`](/sdk/ios/user/friends/get-specified-friends-info)。
