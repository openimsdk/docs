分页拉取当前登录用户作为接收方收到的待审批或已处理好友申请列表：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `offset` | `int` | 否 | 分页起始偏移量，首屏从 `0` 开始。 |
| `count` | `int` | 否 | 每页拉取的好友申请记录数量。 |
| `handleResults` | `List<int>?` | 否 | 按处理结果状态筛选：`0` 待处理，`1` 已同意，`-1` 已拒绝。 |

```dart
final items = await OpenIM.iMManager.friendshipManager
    .getFriendApplicationListAsRecipient(
  req: GetFriendApplicationListAsRecipientReq(offset: 0, count: 20),
);
```

## 返回结果

Future 成功返回当前页收到的好友申请记录列表（`List<FriendApplicationInfo>`）。

查询操作建立静态快照，不会触发申请事件通知。申请处理请参考[接受好友申请](/sdk/flutter/user/friend-applications/accept-friend-application)与[拒绝好友申请](/sdk/flutter/user/friend-applications/refuse-friend-application)。

## 同步好友申请变化

好友申请相关事件在此集中监听并处理状态合并。申请记录使用 `fromUserID:toUserID` 复合标识定位：

```dart
void handleFriendApplicationChanged(FriendApplicationInfo item) {
  mergeFriendApplication(item);
}

void handleFriendApplicationDeleted(FriendApplicationInfo item) {
  removeFriendApplication(item.fromUserID, item.toUserID);
}
```

在应用唯一的 `OnFriendshipListener` 中，将 `onFriendApplicationAdded`、`onFriendApplicationAccepted` 和 `onFriendApplicationRejected` 交给 `handleFriendApplicationChanged`，将 `onFriendApplicationDeleted` 交给 `handleFriendApplicationDeleted`。完整组合入口见[事件概览](/sdk/flutter/events/overview-events)。

按 `toUserID == currentUserID` 区分收到和发出的申请。Flutter SDK 没有公开删除申请记录的方法，不应使用拒绝申请或删除好友关系模拟删除。
