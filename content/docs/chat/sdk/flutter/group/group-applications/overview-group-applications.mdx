## State synchronization

Group application state changes are dispatched via callbacks in the application-wide `OnGroupListener`:
- `onGroupApplicationAdded`: A new group join application was submitted.
- `onGroupApplicationAccepted`: A join application was approved.
- `onGroupApplicationRejected`: A join application was declined.
- `onGroupApplicationDeleted`: A join application record was removed.

The client updates application states using the composite key `groupID:userID`. If application change events arrive while paginating through records, refresh the first page after the current query completes. For complete group event listener registration, see [Groups overview](/sdk/flutter/group/overview-group).
