批量查询指定成员在群组内的详细资料快照：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupID` | `NSString *` | 目标群组 ID。 |
| `usersID` | `NSArray<NSString *> *` | 待查询的目标成员用户 ID 列表。 |

```objc
[[OIMManager manager] getSpecifiedGroupMembersInfo:@"group_1001"
                                           usersID:@[@"user_001", @"user_002"]
                                         onSuccess:^(NSArray<OIMGroupMemberInfo *> *members) {
                                             [self mergeMembers:members];
                                         }
                                         onFailure:^(NSInteger code, NSString *message) {
                                             NSLog(@"getSpecifiedGroupMembersInfo failed: %ld %@", (long)code, message);
                                         }];
```

状态以 `groupID:userID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回匹配的群成员资料数组 `NSArray<OIMGroupMemberInfo *> *`。若传入的用户不在群内，则不会出现在返回数组中。

该查询仅返回调用时刻的群成员快照，不触发成员 delegate 回调。群成员名片、角色与禁言状态的增量更新由[群成员查询概览](/sdk/ios/group/retrieving-group-members/overview-retrieving-group-members)中说明的事件处理，客户端统一使用 `groupID:userID` 合并状态。
