`setAppBadge()` 用于向 SDK 上报应用当前展示的消息总未读数。它不会直接操作 HarmonyOS 桌面图标，宿主应用仍需根据产品设计和系统能力更新界面角标。

```ts
import sdk, { SetAppBadgeReq } from '@openimsdk/imsdk';

const request: SetAppBadgeReq = {
  appUnreadCount: totalUnreadCount,
};
await sdk.setAppBadge(request);
```

`appUnreadCount` 应为非负整数。通常在消息总未读数变化、登录同步完成或清空未读消息后更新；不要把单个会话的未读数作为应用总角标。

Promise 成功只表示 SDK 已接受本次角标值，不代表 HarmonyOS 桌面角标已经显示，也不会改变会话的本地未读数。消息总未读数的查询和事件处理见[获取消息总未读数](/sdk/harmony/conversation/managing-conversations/get-total-unread-count)。
