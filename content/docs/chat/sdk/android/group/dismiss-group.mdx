`dismissGroup()` dismisses the specified group and is normally available only to its owner. Ask for explicit confirmation before calling it so that leaving a group is not accidentally implemented as dismissing it.

```java
OpenIMClient.getInstance().groupManager.dismissGroup(new OnBase<String>() {
    @Override public void onSuccess(String data) { markDismissSubmitted(groupID); }
    @Override public void onError(int code, String error) { showDismissError(error); }
}, groupID);
```

Merge the final state from `onGroupDismissed`. After receiving the event, remove cached group profile, member, and conversation-related data.
