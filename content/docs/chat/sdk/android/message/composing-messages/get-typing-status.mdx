When opening a conversation, restoring a connection, or reconciling state, query the platform IDs on which a specified user is currently typing.

```java
OpenIMClient.getInstance().conversationManager.getInputState(
    new OnBase<List<Integer>>() {
        @Override
        public void onSuccess(List<Integer> platformIDs) {
            boolean typing = platformIDs != null && !platformIDs.isEmpty();
            updateTypingState(conversationID, userID, typing);
        }

        @Override
        public void onError(int code, String error) {
            recordTypingStatusQueryFailure(code, error);
        }
    },
    conversationID,
    userID
);
```

The callback returns a snapshot array of platform IDs. An empty array means that no platform was typing at query time. The query itself does not trigger a typing-status event. In a group chat, do not poll every member frequently. Query relevant members only when opening the screen, restoring a connection, or reconciling state, and maintain incremental updates through the listener owned by [Report typing status](/sdk/android/message/composing-messages/update-typing-status).
