`createMergerMessage()` 将多条已有消息封装成一条合并转发消息。接收端通常先展示标题和摘要，再由用户打开完整记录。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `messageList` | `OpenIMMessageItem[]` | 是 | 要合并的已发送消息列表，顺序即展示顺序。 |
| `title` | `string` | 是 | 合并消息卡片标题。 |
| `abstractList` | `string[]` | 是 | 卡片摘要列表，由业务层根据消息内容生成。 |

```uts
import { createMergerMessage } from '@/uni_modules/unix-openim-sdk'

const message = await createMergerMessage({
  messageList: selectedMessages,
  title: '项目讨论记录',
  abstractList: [
    'Alex：请确认发布时间',
    'Morgan：计划周五上线',
  ],
})
if (message == null) return
```

`messageList` 应包含已经发送成功的完整消息对象。`abstractList` 不会由 SDK 自动生成，应由业务按目标会话的展示要求提供摘要；无法概括时可以使用统一降级文本。

Promise 成功只返回新的待发送 `OpenIMMessageItem | null`，不会修改原消息。若希望每条消息在目标会话中分别显示，逐条使用[创建逐条转发消息](/sdk/uniapp/message/creating-messages/create-forward-message)。
