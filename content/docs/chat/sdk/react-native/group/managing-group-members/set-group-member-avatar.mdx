Update the avatar of a designated member within a specific group:

```ts
await OpenIMSDK.setGroupMemberInfo({
  groupID: 'group-001',
  userID: 'user-002',
  faceURL: 'https://example.com/avatar.png',
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group ID. |
| `userID` | `string` | Yes | User ID of the member whose avatar is being updated. |
| `faceURL` | `string` | Yes | Member avatar URL within this specific group. |

Group-specific avatars apply solely within the target group. To update an account-level global avatar, see [Update self profile](/sdk/react-native/user/profile/set-self-info).

## Return value

A resolved Promise confirms that the member avatar was successfully updated on the server.

Member profile changes emit the `OnGroupMemberInfoChanged` event containing updated profile information. Match and update the corresponding member record using the composite key `groupID:userID`. For complete event listeners, see [Get group member list by page](/sdk/react-native/group/retrieving-group-members/get-group-member-list).
