`joinGroup()` 使用群组 ID、申请说明和加入途径发起入群请求。是否需要管理员审核由群组的 `needVerification` 配置决定，`joinSource` 只记录用户从哪个入口发起操作。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 目标群组 ID。 |
| `reqMsg` | `string` | 是 | 申请说明；没有说明时传空字符串。 |
| `joinSource` | `number` | 是 | 入群途径，取值见下表。 |
| `ex` | `string` | 否 | 业务扩展字符串。 |

| `joinSource` | 含义 |
| --- | --- |
| `2` | 通过邀请加入。 |
| `3` | 通过搜索加入。 |
| `4` | 通过二维码加入。 |

```uts
import { joinGroup } from '@/uni_modules/unix-openim-sdk'

await joinGroup({
  groupID: groupID,
  reqMsg: '申请加入项目讨论组',
  joinSource: 3,
})
```

Promise 成功表示 SDK 已完成本次请求。需要审核时，这不代表当前用户已经加入群组；应等待申请处理，并在收到 `onJoinedGroupAdded()` 后按 `groupID` 更新已加入群组列表。完整监听见[群组概览](/sdk/uniapp/group/overview-group)。

无需审核时也建议以加入事件或重新查询的结果确认最终成员状态，不要仅根据按钮操作修改本地权限。
