创建新的群组，并在创建时指定群名称、群类型以及初始群主、管理员与普通成员列表：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupInfo` | `GroupInfo` | 是 | 群基本资料，包含群名称 `groupName`、群类型 `groupType`（如 `GroupType.work` 工作群）等。`groupID` 可传空字符串由服务端自动生成。 |
| `memberUserIDs` | `List<String>?` | 否 | 初始普通成员用户 ID 列表。 |
| `adminUserIDs` | `List<String>?` | 否 | 初始管理员用户 ID 列表。 |
| `ownerUserID` | `String?` | 否 | 初始群主用户 ID；不指定时默认为当前创建者。 |

普通成员、管理员与群主的用户 ID 列表应保持互斥，不可重复传入。

```dart
final group = await OpenIM.iMManager.groupManager.createGroup(
  groupInfo: GroupInfo(groupID: '', groupName: '项目讨论组', groupType: GroupType.work),
  memberUserIDs: ['user-003'],
  adminUserIDs: ['user-002'],
  ownerUserID: currentUserID,
);
```

## 返回结果

Future 成功返回新创建的 `GroupInfo` 对象。

创建者本地及受邀成员端通过群组监听收到加入群通知，客户端以 `groupID` 为合并标识将该群加入本地已加入群组列表，完整事件监听请参考[群组概览](/sdk/flutter/group/overview-group)。
