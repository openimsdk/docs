根据本地图片文件路径创建图片消息。

```ts
const message = await OpenIMSDK.createImageMessageFromFullPath(imagePath);
```

## 参数说明

`imagePath` 是图片在设备本地存储中的完整路径。

## 返回结果

调用完成后返回已创建的 `MessageItem` 消息对象，其中 `pictureElem` 保存图片信息。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送消息](/sdk/react-native/message/sending-messages/send-message)将消息投递到单聊或群聊会话中，SDK 会在发送过程中自动处理本地图片上传并生成缩略图。
