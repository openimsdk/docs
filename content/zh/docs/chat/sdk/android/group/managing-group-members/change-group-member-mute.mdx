title: '设置群成员禁言'
description: '使用 Android SDK 设置指定成员的禁言时长。'
sourcePath: '/sdk/android/group/managing-group-members/change-group-member-mute'
---

`seconds` 为禁言时长，单位为秒；传 `0` 解除成员禁言。该操作与[全员禁言](/sdk/android/group/change-group-mute)相互独立。

```java
OpenIMClient.getInstance().groupManager.changeGroupMemberMute(new OnBase<String>() {
    @Override public void onSuccess(String data) { /* 请求已完成。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
}, groupID, userID, 3600L);
```

成功回调表示设置请求已完成，不表示其他客户端界面已经更新。`onGroupMemberInfoChanged` 返回更新后的 `GroupMembersInfo`；按 `groupID:userID` 更新成员状态。完整 listener 注册见[群组概览](/sdk/android/group/overview-group)。
