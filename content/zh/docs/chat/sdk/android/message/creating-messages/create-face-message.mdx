---
title: '创建表情消息'
description: '使用 createFaceMessage 创建自定义表情消息。'
sourcePath: '/sdk/android/message/creating-messages/create-face-message'
---

`index` 是业务定义的表情编号，`data` 保存表情 URL、资源版本等自定义信息。发送方和接收方必须使用相同协议解析这些值。

```java
Message message = OpenIMClient.getInstance().messageManager.createFaceMessage(index, dataJson);
```

返回的 `Message` 只是在本地创建的待发送对象。接收端遇到未知表情编号或资源版本时，可以显示占位图或文本；创建完成后使用[发送消息](/sdk/android/message/sending-messages/send-message)。
