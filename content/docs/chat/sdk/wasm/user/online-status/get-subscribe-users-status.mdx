```ts
const { data: states } = await openimsdk.getSubscribeUsersStatus();
```

After the Promise succeeds, `data` contains the current `UserOnlineState[]` for subscribed users. See [Subscribe to online status](/sdk/wasm/user/online-status/subscribe-users-status) for field descriptions.

This query does not trigger a status event. If the target user has not been subscribed to, call `subscribeUsersStatus()` first.
