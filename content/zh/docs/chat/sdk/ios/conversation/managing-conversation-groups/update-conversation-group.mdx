修改已有会话分组的名称、扩展字段或隐藏状态：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `conversationGroupID` | `NSString *` | 必填，目标会话分组 ID。 |
| `name` | `NSString *` | 可选，新的分组名称。 |
| `ex` | `NSString *` | 可选，新的业务扩展字符串。 |
| `hidden` | `NSNumber *` | 可选，是否隐藏该分组（包装 `BOOL`）。 |

```objc
#import <OpenIMSDK/CallbackProxy.h>
@import OpenIMCore;

NSDictionary *request = @{
    @"conversationGroupID": @"group_work_101",
    @"name": @"重点工作",
    @"hidden": @NO,
};

NSData *requestData = [NSJSONSerialization dataWithJSONObject:request options:0 error:nil];
NSString *requestJSON = [[NSString alloc] initWithData:requestData
                                              encoding:NSUTF8StringEncoding];

CallbackProxy *callback = [[CallbackProxy alloc]
    initWithOnSuccess:^(NSString * _Nullable data) {
        if (data == nil) {
            return;
        }
        [self upsertConversationGroupJSON:data];
    }
    onFailure:^(NSInteger code, NSString * _Nullable message) {
        NSLog(@"UpdateConversationGroup failed: %ld %@", (long)code, message);
    }];

Open_im_sdkUpdateConversationGroup(callback, requestJSON);
```

状态以 `conversationGroupID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 的 `data` 参数返回更新后的分组 JSON 字符串，客户端应以 `conversationGroupID` 为合并标识更新本地分组存储。

其他端同步或后续变更会通过 `onConversationGroupChanged:` 事件广播，完整事件处理请参见[会话分组概览](/sdk/ios/conversation/managing-conversation-groups/overview-conversation-groups)。
