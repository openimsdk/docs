准备 `PictureInfo` 的原图、大图和缩略图信息后创建消息。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `sourceURL` | `String` | 是 | 已上传原图的远端 URL。 |
| `sourcePicture` | `PictureInfo` | 是 | 原图的 URL、宽高、大小和类型信息。 |
| `bigPicture` | `PictureInfo` | 是 | 大图信息；未单独生成时按业务约定填写可用图片信息。 |
| `snapshotPicture` | `PictureInfo` | 是 | 缩略图信息，用于列表和预览展示。 |

```java
Message message = OpenIMClient.getInstance().messageManager.createImageMessageByURL(
    sourceURL, sourcePicture, bigPicture, snapshotPicture);
```

返回的 `Message` 只包含已上传图片的描述信息，不会再次上传文件。确认各 URL 可由接收端访问后，使用[发送已上传的媒体消息](/sdk/android/message/sending-messages/send-message-not-oss)。
