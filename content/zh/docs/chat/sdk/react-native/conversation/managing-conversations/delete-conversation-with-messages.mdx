删除指定的会话记录，并同步清理该会话在当前账号下的全部历史消息。

```ts
await OpenIMSDK.deleteConversationAndDeleteAllMsg(conversationID);
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 要删除的会话 ID。 |

## 返回结果

调用完成后，删除会话及消息请求已处理完成。

Promise 成功表示该会话及对应消息已从当前设备与服务端清除。会话列表发生变动时会触发 `OnConversationChanged` 事件；客户端应以 `conversationID` 作为标识，从本地会话列表中移除该会话项，并同步清空聊天详情页的消息缓存。完整监听方式见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。
