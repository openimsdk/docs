---
title: '创建 Markdown 消息'
description: '使用 WASM SDK 创建 Markdown 消息。'
sourcePath: '/sdk/wasm/message/creating-messages/create-markdown-message'
---

Markdown 消息适合发送需要基础排版的文本内容。参数是完整的 Markdown 源文本；发送前应按照产品规则校验空白、长度和允许的语法。

```ts
const { data: message } = await openimsdk.createMarkdownMessage(
  '**发布完成**\n\n- Web\n- WASM',
);
```

SDK 只保存和传递内容，不负责保证渲染安全。接收端必须使用安全配置的渲染器，过滤不可信 HTML、链接和脚本协议，并为不支持 Markdown 的客户端提供纯文本展示方式。

Promise 成功后，`data` 是待发送的 `MessageItem`，不会自动发送或触发新消息事件。下一步使用[发送消息](/sdk/wasm/message/sending-messages/send-message)投递该对象。
