分页查询一条指定群消息的已读或未读成员列表。常用于在群聊消息气泡旁展示已读人数及点击查看具体成员名单。

```ts
const members = await OpenIMSDK.getGroupMessageReaderList({
  conversationID,
  clientMsgID,
  filter: GroupMessageReaderFilter.Read,
  offset: 0,
  count: 50,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 群聊会话 ID。 |
| `clientMsgID` | `string` | 是 | 要查询已读情况的消息客户端 ID。 |
| `filter` | `GroupMessageReaderFilter` | 是 | 成员筛选条件。`Read` 为查询已读成员，`Unread` 为查询未读成员。 |
| `offset` | `number` | 是 | 分页偏移量，首次查询传入 `0`。 |
| `count` | `number` | 是 | 本次查询拉取的成员数量上限。 |

## 返回结果

调用成功后返回当前页的群成员列表 `GroupMemberItem[]`。列表中各成员以 `groupID:userID` 为唯一标识。详细成员属性字段请参考[群组概览](/sdk/react-native/group/overview-group)；若需加载更多已读成员，可根据上一页返回的条数递增 `offset` 继续查询。
