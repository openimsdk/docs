Dismiss and disband a specified group. The caller must be the group owner. Once disbanded, all members are evicted:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID. The caller must be the owner of this group. |

## Code example

```dart
await OpenIM.iMManager.groupManager.dismissGroup(groupID: groupID);
```

## Return value

A successful `Future` indicates that the dismissal request was processed by the server. The client should remove the group from its joined group list.

## State changes after the call

Multi-device synchronization and group-wide broadcasts trigger the `onGroupDismissed` callback. The client uses `groupID` as the key to purge local group and conversation states. For complete listener integration, see [Groups overview](/sdk/flutter/group/overview-group). Dismissing a group disbands the entity entirely on the server; it is distinct from hiding or deleting local conversations.
