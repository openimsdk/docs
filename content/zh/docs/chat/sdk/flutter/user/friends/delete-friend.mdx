将指定用户从当前登录用户的好友列表中解除关系：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `userID` | `String` | 是 | 待删除好友的用户 ID。 |

```dart
await OpenIM.iMManager.friendshipManager.deleteFriend(
  userID: 'user_123',
);
```

## 返回结果

Future 成功返回 `void`，表示删除好友请求已成功提交至服务端并在本地同步删除好友关系。

该操作为状态变更接口。删除成功后，当前客户端及该账号其他在线端会收到 `onFriendDeleted` 事件通知。客户端应以 `userID` 为合并标识，从本地缓存或好友列表中移除该好友项。完整的好友事件监听与列表维护请参考[分页获取好友列表](/sdk/flutter/user/friends/get-friend-list-page)。
