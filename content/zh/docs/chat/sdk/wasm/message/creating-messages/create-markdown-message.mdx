---
title: '创建 Markdown 消息'
description: '使用 WASM SDK 创建 Markdown 消息。'
sourcePath: '/sdk/wasm/message/creating-messages/create-markdown-message'
---

Markdown 消息适用于需要富文本排版（如加粗、列表、代码块）的文本内容。传入参数为完整的 Markdown 原始字符串；在提交前建议结合业务需求对内容长度与排版语法进行基本校验。

```ts
const { data: message } = await openimsdk.createMarkdownMessage(
  '**发布完成**\n\n- Web\n- WASM',
);
```

SDK 负责内容的传输与持久化。在前端渲染接收到的 Markdown 消息时，请配置可靠的安全过滤机制（如防 XSS 攻击），过滤不受信的 HTML 标签及危险链接协议。

接口调用成功后，返回的 `data` 为待发送的 `MessageItem` 对象。后续需调用 [发送消息](/sdk/wasm/message/sending-messages/send-message) 将其真正发送出去。
