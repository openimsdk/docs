---
title: '查询会话置顶消息'
description: '使用 WASM SDK 获取会话中当前置顶的消息。'
sourcePath: '/sdk/wasm/message/managing-messages/get-pinned-messages'
---

```ts
const { data: messages } =
  await openimsdk.getConversationPinnedMsg(conversationID);
replacePinnedMessages(conversationID, messages);
```

接口调用成功后，返回的 `data` 为当前会话中处于置顶状态的 `MessageItem[]` 列表。关于消息项的具体属性说明请参考[消息概览](/sdk/wasm/message/overview-message)。

该接口为只读查询，不会触发置顶事件。在维护置顶栏时，建议使用 `clientMsgID` 唯一标识每条置顶消息，并结合消息撤回或修改事件保持同步展示。关于置顶与取消置顶的操作及实时事件监听，请参考[置顶或取消置顶消息](/sdk/wasm/message/managing-messages/set-message-pinned)。
