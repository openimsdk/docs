---
title: '保存本地转写结果'
description: '使用 WASM SDK 把转写结果保存到当前设备的语音消息。'
sourcePath: '/sdk/wasm/message/composing-messages/save-local-transcript'
---

语音转写成功后，若需将转写文本持久化保存在当前设备本地的语音消息中，可将识别文本写入消息对象的 `soundElem.text`，并通过 `setMessageLocalContent()` 更新本地存储：

```ts
const updated = {
  ...message,
  soundElem: { ...message.soundElem, text: { text: transcript, translate: message.soundElem.text?.translate ?? {} } },
};
await openimsdk.setMessageLocalContent({ conversationID, message: updated });
```

调用该接口时需传入包含更新内容后的完整消息对象。接口调用成功表示已保存至当前设备的本地数据库中，该更新仅作用于本机，不会上传至服务端、不触发消息事件，也不同步给其他用户或设备。
