配置群组的加群与邀请入群验证策略，调用者的修改权限由 OpenIMServer 校验：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `needVerification` | `GroupVerification` | 是 | 入群验证策略枚举值。 |

```dart
await OpenIM.iMManager.groupManager.setGroupInfo(
  GroupInfo(
    groupID: groupID,
    needVerification: GroupVerification.allNeedVerification,
  ),
);
```

`GroupVerification` 枚举说明：

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `GroupVerification.applyNeedVerificationInviteDirectly` | `0` | 用户申请需要审核；群成员邀请可直接入群。 |
| `GroupVerification.allNeedVerification` | `1` | 申请和普通成员邀请都需要审核；群主或管理员邀请除外。 |
| `GroupVerification.directly` | `2` | 申请或邀请均可直接入群（免审批）。 |

## 返回结果

Future 成功表示验证策略已更新完成。

SDK 会通过群资料变更通知同步最新策略。客户端以 `groupID` 为合并标识更新本地群资料中的 `needVerification` 字段，完整事件监听请参考[群组概览](/sdk/flutter/group/overview-group)；如需主动校准最新状态，可调用[查询指定群组资料](/sdk/flutter/group/retrieving-groups/get-specified-groups-info)。
