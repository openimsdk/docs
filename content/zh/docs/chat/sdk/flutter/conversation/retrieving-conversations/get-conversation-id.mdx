在只需要会话 ID 进行业务关联或预查询的场景下，可调用此方法获取稳定的 `conversationID`，避免在应用层自行拼接字符串：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `sourceID` | `String` | 是 | 聊天目标 ID。单聊为对方 `userID`，群聊为目标 `groupID`。 |
| `sessionType` | `int` | 是 | 会话类型。单聊传入 `ConversationType.single`，群聊传入 `ConversationType.superGroup`。 |

```dart
final conversationID = await OpenIM.iMManager.conversationManager
    .getConversationIDBySessionType(
  sourceID: targetUserID,
  sessionType: ConversationType.single,
);
```

## 返回结果

Future 成功返回计算得出的标准 `conversationID` 字符串。此接口只执行 ID 计算，不返回完整 `ConversationInfo` 会话实体，也不会触发任何会话事件回调。
