```dart
final sent = await OpenIM.iMManager.messageManager.sendMessage(
  message: message,
  userID: receiverUserID,
  offlinePushInfo: offlinePushInfo,
);
```

单聊只传 `userID`，群聊只传 `groupID`；`isOnlineOnly` 消息不进入普通历史。Future 成功返回服务端确认后的 `Message`，先确认 `clientMsgID` 非空，再替换本地待发送项。
