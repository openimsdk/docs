When holding an array of conversation IDs, retrieve their latest conversation items in a batch with `getMultipleConversation()`:

```ts
const conversations = await OpenIMSDK.getMultipleConversation(conversationIDList);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationIDList` | `string[]` | Yes | Array of conversation IDs to retrieve. |

## Return value

Resolves to an array of `ConversationItem[]`. The returned array length may be smaller than the input list if certain conversation records do not exist in the local SQLite database. Reconcile the returned conversation records into your application state keyed by `conversationID`. For detailed property definitions, see [Retrieve conversation list](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list).
