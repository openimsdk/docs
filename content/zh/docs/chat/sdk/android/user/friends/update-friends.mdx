修改指定好友的关系属性，包括设置好友备注名、置顶好友以及更新业务扩展字段。

```java
UpdateFriendsReq request = new UpdateFriendsReq();
request.setFriendUserIDs(new String[] { friendUserID });
request.setRemark(remark.trim());

OpenIMClient.getInstance().friendshipManager.updateFriendsReq(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 更新好友资料成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    request
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `request` | `UpdateFriendsReq` | 是 | 好友资料更新请求体。 |

### 请求体属性

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `friendUserIDs` | `String[]` | 待更新的目标好友用户 ID 数组。注意批量更新时会将相同字段值覆盖应用到数组中所有好友。 |
| `remark` | `String` | 当前登录用户为目标好友设置的备注名。 |
| `isPinned` | `boolean` | 是否在通讯录中置顶该好友。 |
| `ex` | `String` | 好友关系扩展字段。 |

## 返回结果

成功回调表示服务端已成功持久化好友资料变更。

修改生效后，SDK 会通过 `OnFriendshipListener` 派发事件：
- `onFriendInfoChanged(FriendInfo friend)`：通知好友资料发生变更，客户端应以 `userID` 为主键更新本地好友数据中的对应属性。

完整监听配置请参考[分页获取好友列表](/sdk/android/user/friends/get-friend-list-page)。
