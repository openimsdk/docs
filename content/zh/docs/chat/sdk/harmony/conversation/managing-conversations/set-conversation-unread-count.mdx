---
title: '设置本地会话未读数'
description: '把一个或多个本地会话的未读数设置为指定值。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/set-conversation-unread-count'
---

该方法用于修正 SDK 本地会话未读数，不会制造服务端未读消息，也不能替代正常的[标记会话已读](/sdk/harmony/conversation/managing-conversations/mark-conversation-read)。

```ts
import sdk, { ResetConversationUnreadReq } from '@openimsdk/imsdk';

const request: ResetConversationUnreadReq = {
  conversationIDs: [conversationID],
  num: 0,
};
await sdk.resetConversationUnread(request);
```

`num` 应为非负整数。同一数值会应用到 `conversationIDs` 中的全部会话。Promise 成功后，SDK 会触发会话变更事件与总未读数变化事件；客户端收到通知后根据 `conversationID` 更新对应会话的未读数，完整监听配置请参考[获取会话列表](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list)与[获取消息总未读数](/sdk/harmony/conversation/managing-conversations/get-total-unread-count)。
