```objc
[[OIMManager manager] deleteFriend:@"user_b"
                         onSuccess:nil
                         onFailure:nil];
```

A successful callback means that the request has completed. `onFriendDeleted:` subsequently removes the record by `userID`. For the complete delegate implementation, see [Retrieve the friend list by page](/sdk/ios/user/friends/get-friend-list-page).
