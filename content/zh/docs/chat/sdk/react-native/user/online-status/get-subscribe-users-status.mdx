调用 `getSubscribeUsersStatus()` 获取当前账号已订阅用户的在线状态。

```ts
const states = await OpenIMSDK.getSubscribeUsersStatus();
```

返回已订阅用户的 `UserOnlineState[]`。目标用户尚未订阅时，请先调用[订阅用户在线状态](/sdk/react-native/user/online-status/subscribe-users-status)。
