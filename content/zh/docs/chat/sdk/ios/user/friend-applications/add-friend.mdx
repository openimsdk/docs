向指定用户发送好友申请：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `userID` | `NSString *` | 申请接收方用户的 ID。 |
| `reqMessage` | `NSString *` | 申请验证附言；若无附言传空字符串。 |

```objc
[[OIMManager manager] addFriend:@"user_b"
                     reqMessage:@"你好，我是 Alex"
                      onSuccess:^(NSString *data) {
    [applicationStore markSentToUserID:@"user_b"];
}
                      onFailure:^(NSInteger code, NSString *message) {
    NSLog(@"addFriend failed: %ld %@", (long)code, message);
}];
```

状态以 `userID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 仅表示服务端已接收该好友申请，不表示对方已同意或双方已成为好友。发出的申请记录可通过[获取发出的好友申请](/sdk/ios/user/friend-applications/get-friend-application-list-as-applicant)查询；对方处理后的申请事件通知见[获取收到的好友申请](/sdk/ios/user/friend-applications/get-friend-application-list-as-recipient)。
