---
title: '设置消息本地扩展'
description: '更新 iOS 当前设备的消息本地扩展字段。'
sourcePath: '/sdk/ios/message/managing-messages/set-message-local-ex'
---

```objc
[[OIMManager manager] setMessageLocalEx:conversationID
                            clientMsgID:message.clientMsgID
                                localEx:@"{\"downloaded\":true}"
                              onSuccess:nil
                              onFailure:nil];
```

`localEx` 是完整字符串，只更新当前设备本地数据库，不会同步给其他设备或触发新消息 delegate。需要保留旧字段时先在业务层解析并合并。
