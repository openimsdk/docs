The `lookMemberInfo` property configures member profile visibility using `OpenIMGroupAllowType`. Note the numeric definitions for this enum:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group identifier. |
| `lookMemberInfo` | `OpenIMGroupAllowType` | Yes | Member profile access permission constant. |

| Enum constant | Numeric value | Description |
| --- | --- | --- |
| `OpenIMGroupAllowTypeAllowed` | `0` | Members are permitted to view fellow member profiles. |
| `OpenIMGroupAllowTypeNotAllowed` | `1` | Members are not permitted to view fellow member profiles. |

## Code example

```uts
import {
  OpenIMGroupAllowTypeNotAllowed,
  setGroupInfo,
} from '@/uni_modules/unix-openim-sdk'

await setGroupInfo({
  groupID,
  lookMemberInfo: OpenIMGroupAllowTypeNotAllowed,
})
```

## Return value

The Promise resolves with `void` once OpenIMServer updates the permission.

## State changes after the call

A resolved Promise confirms that the setting was saved. Update the local group's `lookMemberInfo` field optimistically, and confirm final state when `onGroupInfoChanged` arrives matching `groupID`. This setting is independent of whether members can add each other as friends. For complete group event listener registration, see [Group overview](/sdk/uniapp/group/overview-group).
