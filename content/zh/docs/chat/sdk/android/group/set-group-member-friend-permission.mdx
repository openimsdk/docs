---
title: '设置群内添加好友权限'
description: '通过 GroupInfo.applyMemberFriend 设置是否允许从群成员发起好友申请。'
sourcePath: '/sdk/android/group/set-group-member-friend-permission'
---

`applyMemberFriend` 使用整数开关：`0` 关闭，`1` 打开。该规则只影响从该群成员关系入口发起的好友申请。

```java
GroupInfo update = new GroupInfo();
update.setGroupID(groupID);
update.setApplyMemberFriend(0);

OpenIMClient.getInstance().groupManager.setGroupInfo(update, new OnBase<String>() {
    @Override public void onSuccess(String data) { /* 请求已完成。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
});
```

成功回调表示权限更新请求已完成，不表示其他客户端界面已经更新。`onGroupInfoChanged` 返回更新后的 `GroupInfo`；按 `groupID` 更新该权限字段。完整 listener 注册见[群组概览](/sdk/android/group/overview-group)。
