用户查看或处理群聊中的提及消息后，重置该群聊会话的 @ 提醒状态。

```ts
await OpenIMSDK.resetConversationGroupAtType(conversationID);
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 要重置提醒状态的群聊会话 ID。 |

该操作将会话的 `groupAtType` 恢复为无提醒状态，不用于主动设置提及状态。重置群组提醒与[标记会话已读](/sdk/react-native/conversation/managing-conversations/mark-conversation-read)是两个独立操作。

## 返回结果

调用完成后，该会话的群组提醒状态已重置。

状态更新后会触发 `OnConversationChanged` 事件；客户端应使用 `conversationID` 定位目标会话，将 `groupAtType` 更新为常规无提醒状态。完整监听方式见[获取会话列表](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list)。
