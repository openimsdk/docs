检查当前登录账号是否已加入指定的群组：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupID` | `NSString *` | 待检查的目标群组 ID。 |

```objc
[[OIMManager manager] isJoinedGroup:@"group_1001"
                          onSuccess:^(BOOL joined) {
                              [self updateJoinedState:joined];
                          }
                          onFailure:^(NSInteger code, NSString *message) {
                              NSLog(@"isJoinedGroup failed: %ld %@", (long)code, message);
                          }];
```

状态以 `groupID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回布尔值 `joined`。`YES` 表示当前用户已加入该群组，`NO` 表示尚未加入或已离开。

该接口只返回调用时的轻量成员从属快照，不会触发群组 delegate 回调。群加入和退出的具体操作请参考[申请加入群组](/sdk/ios/group/join-group)与[退出群组](/sdk/ios/group/quit-group)；群成员关系的增量事件处理请参见[群组概览](/sdk/ios/group/overview-group)。
