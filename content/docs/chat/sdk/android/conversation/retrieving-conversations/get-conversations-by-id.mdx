Use `getMultipleConversation()` to retrieve multiple conversations by `conversationIDs`. `conversationIDs` is the list of conversation IDs to query.

```java
OpenIMClient.getInstance().conversationManager.getMultipleConversation(
    new OnBase<List<ConversationInfo>>() {
        @Override
        public void onSuccess(List<ConversationInfo> conversations) {
            // conversations contains snapshots for the requested conversationIDs.
        }

        @Override
        public void onError(int code, String error) {
            // code and error describe the failure.
        }
    },
    conversationIDs
);
```

The callback returns `List<ConversationInfo>`.
