从通讯录、用户资料或群资料进入聊天页时，使用 `getOneConversation()`。单聊传对方用户 ID，群聊传群组 ID；即使还没有消息，也不要自行构造 `ConversationInfo`。

```java
OpenIMClient.getInstance().conversationManager.getOneConversation(
    new OnBase<ConversationInfo>() {
        @Override
        public void onSuccess(ConversationInfo conversation) {
            openChatPage(conversation);
        }

        @Override
        public void onError(int code, String error) {
            recordConversationOpenFailure(code, error);
        }
    },
    targetUserID,
    ConversationType.SINGLE_CHAT
);
```

参数 `sourceId` 在单聊中是对方 `userID`，在群聊中是 `groupID`。群聊根据群类型使用 `ConversationType.GROUP_CHAT` 或 `ConversationType.SUPER_GROUP_CHAT`。

成功 callback 返回 `ConversationInfo`。查询本身不触发会话 listener；后续变化由[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)统一按 `conversationID` 合并。
