```dart
final platformIDs =
    await OpenIM.iMManager.conversationManager.getInputStates(
  conversationID,
  otherUserID,
);

setTyping(otherUserID, platformIDs?.isNotEmpty == true);
```

Future 返回可空的平台 ID 数组快照，查询本身不触发 listener。群聊中不要频繁轮询全部成员；只在进入页面、连接恢复或补偿状态时查询重点成员，在线增量由[上报输入状态](/sdk/flutter/message/composing-messages/update-typing-status)归属的 listener 维护。
