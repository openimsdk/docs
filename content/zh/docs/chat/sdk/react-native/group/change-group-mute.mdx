调用 `changeGroupMute()` 开启或关闭群组全员禁言。

```ts
await OpenIMSDK.changeGroupMute({
  groupID,
  isMute: true,
  muteBypassUserIDs: [serviceAccountUserID],
});
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 目标群组 ID。 |
| `isMute` | `boolean` | 是 | `true` 开启群组禁言，`false` 关闭群组禁言。 |
| `muteBypassUserIDs` <span className="enterprise-field-badge">商业版</span> | `string[]` | 否 | 群组禁言期间仍允许发言的用户 ID。 |

不要把全部成员传入 `muteBypassUserIDs`。群主和管理员是否可以发言由服务端权限控制。

## 返回结果

调用完成后，群组全员禁言设置已更新。群资料变化会通过 `OnGroupInfoChanged` 返回，事件监听方式见[群组概览](/sdk/react-native/group/overview-group)。
