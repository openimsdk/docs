发布或更新群组公告。群公告与群简介（`introduction`）属于不同字段，修改群公告的操作权限由 OpenIMServer 校验：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `notification` | `String` | 是 | 新的群公告内容；若需要清空公告，传入空字符串 `''`。 |

```dart
await OpenIM.iMManager.groupManager.setGroupInfo(
  GroupInfo(
    groupID: groupID,
    notification: announcement.trim(),
  ),
);
```

## 返回结果

Future 成功表示群公告已成功更新至服务端。

SDK 会通过群资料变更通知向全群广播。客户端以 `groupID` 为合并标识更新本地群资料中的 `notification` 字段，完整事件监听请参考[群组概览](/sdk/flutter/group/overview-group)；如需主动校准最新状态，可调用[查询指定群组资料](/sdk/flutter/group/retrieving-groups/get-specified-groups-info)。
