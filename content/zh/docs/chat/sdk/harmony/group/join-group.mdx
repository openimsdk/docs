是否需要管理员审核由群组的 `needVerification` 决定，`joinSource` 只记录用户从哪个入口发起操作。

## 参数说明

| 参数         | 类型              | 是否必填 | 说明                                   |
| ------------ | ----------------- | -------- | -------------------------------------- |
| `groupID`    | `string`          | 是       | 目标群组 ID。                          |
| `reqMsg`     | `string`          | 是       | 申请说明；没有说明时传空字符串。       |
| `joinSource` | `GroupJoinSource` | 是       | 入群途径，例如搜索或二维码。           |
| `ex`         | `string`          | 是       | 业务扩展字符串；没有扩展时传空字符串。 |

```ts
import sdk, { GroupJoinSource, JoinGroupReq } from '@openimsdk/imsdk';

const request: JoinGroupReq = {
  groupID: groupID,
  reqMsg: '申请加入项目讨论组',
  joinSource: GroupJoinSource.Search,
  ex: '',
};
await sdk.joinGroup(request);
```

Promise 成功表示本次申请已提交至服务端。需要审核时，可通过[获取发出的入群申请](/sdk/harmony/group/group-applications/get-group-application-list-as-applicant)查看审批进度；若群组无需审核直接加入，SDK 会触发加入群组事件，客户端按 `groupID` 将群组加入列表，完整监听代码请参考[群组概览](/sdk/harmony/group/overview-group)。
