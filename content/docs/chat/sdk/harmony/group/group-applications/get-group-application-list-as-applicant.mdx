Pass `send: true` to paginate group applications sent by the signed-in user:

## Code example

```ts
import sdk, { GetGroupApplicationReq, GetGroupApplicationResp } from '@openimsdk/imsdk';

const request: GetGroupApplicationReq = {
  send: true,
  groupIDs: [],
  handleResults: [],
  pagination: { pageNumber: 1, showNumber: 20 },
};
const response: GetGroupApplicationResp = await sdk.getGroupApplication(request);
const applications = response.applications;
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `send` | `boolean` | Yes | Set to `true` to query outgoing applications sent by the current user. |
| `groupIDs` | `string[]` | Yes | Filter by group IDs. Pass `[]` for all groups. |
| `handleResults` | `HandleResult[]` | Yes | Filter by review status. Pass `[]` for all states. |
| `pagination.pageNumber` | `number` | Yes | Page index, starting from `1`. |
| `pagination.showNumber` | `number` | Yes | Number of records to retrieve per page. |

## Return value

Returns a Promise that resolves to a `GetGroupApplicationResp` object containing `applications: IMGroupApplication[]`.

## State changes after the call

Pass empty arrays for `groupIDs` and `handleResults` to query across all groups and review statuses without restrictions. For application fields, composite key `groupID:userID`, and real-time event listener patterns, see [Retrieve received group applications](/sdk/harmony/group/group-applications/get-group-application-list-as-recipient). If application state events arrive while scrolling, reset the pagination offset and re-query from page 1.
