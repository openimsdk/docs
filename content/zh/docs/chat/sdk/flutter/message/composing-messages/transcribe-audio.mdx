`filename` 必须是当前设备上 SDK 可读取的本地路径，不是 URL、Base64 或上传文件名：

```dart
final result = await OpenIM.iMManager.messageManager.speechToText(
  filename: soundElem.soundPath!,
);
final transcript = result.text ?? '';
```

只有远端 URL 时先下载到受控本地路径。Future 返回 `SpeechToTextResp`，不会修改原消息或触发 listener。调用前先[检查语音识别能力](/sdk/flutter/message/composing-messages/check-speech-to-text)。
