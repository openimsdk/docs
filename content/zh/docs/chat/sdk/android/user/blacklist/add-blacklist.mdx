description: '使用 addBlacklist() 将用户加入当前账号黑名单。'

---

```java
OpenIMClient.getInstance().friendshipManager.addBlacklist(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markBlacklistRequestSubmitted(targetUserID);
        }

        @Override
        public void onError(int code, String error) {
            recordBlacklistAddFailure(code, error);
        }
    },
    targetUserID,
    "{\"source\":\"profile-menu\"}"
);
```

第二个参数是目标 `userID`，第三个参数是可选扩展字符串。无需扩展信息时可使用不带 `ex` 的重载。成功 callback 表示拉黑请求完成，不表示事件已经到达。

黑名单是单向关系：被拉黑用户不能向当前用户发送消息，但当前用户是否允许继续向对方发送消息由业务层决定。`ex` 是完整字符串，更新前应合并业务自己的扩展字段。

`onBlacklistAdded` 由本页归属，应组合进应用唯一的 `OnFriendshipListener`：

```java
@Override
public void onBlacklistAdded(BlacklistInfo user) {
    blacklistStore.put(user.getUserID(), user);
}
```
