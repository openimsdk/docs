---
title: '更新群成员头像'
description: '使用 SetGroupMemberInfo.faceURL 更新成员在群内展示的头像。'
sourcePath: '/sdk/android/group/managing-group-members/set-group-member-avatar'
---

群成员头像是群内资料字段，不修改用户全局头像。传入已可访问的头像 URL。

```java
SetGroupMemberInfo update = new SetGroupMemberInfo();
update.setGroupID(groupID);
update.setUserID(userID);
update.setFaceURL(avatarURL);

OpenIMClient.getInstance().groupManager.setGroupMemberInfo(update, new OnBase<String>() {
    @Override public void onSuccess(String data) { /* 请求已完成。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
});
```

修改成功后，通过 `onGroupMemberInfoChanged` 接收成员资料变化通知。
