---
title: '设置会话扩展字段'
description: '设置当前用户指定会话的业务扩展字符串。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/set-conversation-extension'
---

`ex` 是完整字符串，SDK 不会自动合并 JSON。多个模块共用时，应在业务层合并稳定命名空间。

```ts
import sdk, { SetConversationReq } from '@openimsdk/imsdk';

const request: SetConversationReq = {
  conversationID: conversationID,
  ex: JSON.stringify(conversationExtra),
};
await sdk.setConversation(request);
```

Promise 成功后等待会话变化事件，或重新查询校准。不要把 Token 或敏感资料写入扩展字段。
