根据已上传图片的 URL 资源信息创建图片消息。原图、大图和缩略图可共用同一资源信息，也可按业务需要分别传入不同尺寸或质量的资源。

```ts
const picture = {
  uuid: 'image-001',
  type: 'image/jpeg',
  size: 120000,
  width: 1280,
  height: 720,
  url: 'https://www.example.com/picture.png',
};

const message = await OpenIMSDK.createImageMessageByURL({
  sourcePicture: picture,
  bigPicture: picture,
  snapshotPicture: picture,
  sourcePath: '',
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `sourcePicture` | `PicBaseInfo` | 是 | 原图资源信息。 |
| `bigPicture` | `PicBaseInfo` | 是 | 大图资源信息。 |
| `snapshotPicture` | `PicBaseInfo` | 是 | 缩略图资源信息。 |
| `sourcePath` | `string` | 是 | 图片本地路径；仅有远端资源时传空字符串。 |

每个 `PicBaseInfo` 包含 `uuid`、`type`、`size`、`width`、`height` 和 `url`，分别表示资源标识、类型、字节大小、像素尺寸和远端网络地址。

## 返回结果

调用完成后返回已创建的 `MessageItem` 消息对象，其中 `pictureElem` 保存远端图片数据。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送已上传的媒体消息](/sdk/react-native/message/sending-messages/send-message-not-oss)直接投递该消息，无需重复上传图片资源。
