解除指定用户与当前登录用户的好友关系：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `friendUserID` | `NSString *` | 待删除的好友用户 ID。 |

```objc
[[OIMManager manager] deleteFriend:@"user_b"
                         onSuccess:^(NSString *data) {
    [friendStore removeUserID:@"user_b"];
}
                         onFailure:^(NSInteger code, NSString *message) {
    NSLog(@"deleteFriend failed: %ld %@", (long)code, message);
}];
```

状态以 `userID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 表示服务端已处理删除好友请求。好友删除事件随后会通过好友监听下发至各端并按 `userID` 移除本地记录，完整事件处理见[分页获取好友列表](/sdk/ios/user/friends/get-friend-list-page)。
