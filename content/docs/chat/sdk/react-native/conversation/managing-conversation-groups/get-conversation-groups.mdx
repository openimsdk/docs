Retrieve conversation groups created by the authenticated account filtered by type:

```ts
const groups = await OpenIMSDK.getConversationGroups(
  ConversationGroupType.ConversationGroupTypeNormal,
);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupType` | `ConversationGroupType` | Yes | Conversation group type filter. |

Group type enum values:

| Enum value | Value | Description |
| --- | --- | --- |
| `ConversationGroupTypeNormal` | `0` | Standard custom conversation groups. |
| `ConversationGroupTypeAll` | `1` | All conversation group categories. |

## Return value

Resolves to an array of `ConversationGroup[]`. For field definitions, see [Conversation groups overview](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups).

Each group item contains `conversationGroupID`, `name`, `order`, and the list of associated `conversationIDs`. To retrieve group metadata populated with full conversation items in a single call, use [Get conversation group info with conversations](/sdk/react-native/conversation/managing-conversation-groups/get-conversation-group-info-with-conversations).
