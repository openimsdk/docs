从搜索结果或引用消息跳入聊天上下文时，把已经取得的 `Message` 作为锚点。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 锚点消息所在的会话 ID。 |
| `startMsg` | `Message` | 是 | 已经取得的锚点消息。 |
| `type` | `ViewType` | 是 | 上下文查看类型；引用消息使用 `ViewType.History`，搜索结果使用 `ViewType.Search`。 |
| `before` | `int` | 是 | 锚点之前最多读取的消息数量。 |
| `after` | `int` | 是 | 锚点之后最多读取的消息数量。 |

```java
messageManager.fetchSurroundingMessages(
    new OnBase<Messages>() {
        @Override
        public void onSuccess(Messages messages) {
            List<Message> surrounding = messages.getData();
            renderMessages(surrounding);
        }

        @Override
        public void onError(int code, String error) {
            // 处理失败
        }
    },
    conversationID,
    targetMessage,
    ViewType.Search,
    20,
    20
);
```

成功回调中的 `messages.getData()` 是锚点前后取得的消息列表，消息字段见[消息概览](/sdk/android/message/overview-message)。

`before` 和 `after` 分别限制锚点前后的数量。返回结果可能少于请求总数，例如锚点靠近历史边界或部分消息已经删除。按 `conversationID:clientMsgID` 合并，不要依赖固定数组位置。需要先定位消息时见[按 ID 查找消息](/sdk/android/message/retrieving-messages/find-messages-by-id)。
