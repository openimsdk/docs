邀请尚未接通时，发起方可主动取消通话邀请：

```java
OpenIMClient.getInstance().signalingManager.signalingCancel(
    new OnBase<String>() {
        @Override
        public void onSuccess(String result) {
            // 信令操作已完成。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    activeInfo
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `signalingInfo` | `SignalingInfo` | 是 | 发起呼叫时保存的完整信令对象，必须包含原始 `roomID`、邀请人和被邀请人等字段。 |

## 返回结果

成功回调表示服务端已受理取消邀请请求。主叫端应同步关闭呼叫等待界面并释放相关媒体资源。

被叫端及其他参与设备将通过事件收到取消通知，客户端可根据 `roomID` 更新当前呼叫状态，具体监听实现请参考[处理通话事件](/sdk/android/calling/managing-calls/handle-call-events)。
