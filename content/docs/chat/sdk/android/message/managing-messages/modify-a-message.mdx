Use `modifyMessage` to change an existing message in a conversation. Preserve the original conversation ID, `clientMsgID`, routing fields, sender, and other message data in the request, and update only the supported content.

```java
messageManager.modifyMessage(callback, modifyRequest);
```

The success callback means that the modification request completed; it does not mean that every client interface has updated. Other clients receive the complete modified `Message` through `OnAdvanceMsgListener.onMessageModified`.

This page is the complete owner of `onMessageModified`. Resolve the `conversationID` from the message routing fields, then replace the original message by `conversationID:clientMsgID`. Do not match by array position or displayed text:

```java
@Override
public void onMessageModified(Message message) {
    String conversationID = resolveConversationID(message);
    if (conversationID == null) {
        return;
    }
    replaceMessage(conversationID, message.getClientMsgID(), message);
}
```

Add this callback to the application's single `OnAdvanceMsgListener`; see [Events](/sdk/android/events/overview-events) for centralized setup. Callback completion, event delivery, and a new history query are three independent stages.
