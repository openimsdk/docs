The Android SDK does not provide a separate announcement method. Create a `GroupInfo` containing the `groupID` and `notification`, then call `setGroupInfo()`.

```java
GroupInfo update = new GroupInfo();
update.setGroupID(groupID);
update.setNotification("Release review starts at 20:00 tonight.");

OpenIMClient.getInstance().groupManager.setGroupInfo(update, new OnBase<String>() {
    @Override public void onSuccess(String data) { refreshAnnouncement(groupID); }
    @Override public void onError(int code, String error) { showAnnouncementError(error); }
});
```

The returned `GroupInfo` exposes the update time and author through `notificationUpdateTime` and `notificationUserID`. The server validates whether the current user has permission to publish the announcement.
