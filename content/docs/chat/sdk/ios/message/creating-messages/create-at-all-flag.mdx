```objc
OIMAtInfo *atAll = [OIMMessageInfo createAtAllFlag:@"@all"];
```

The argument is the display text for all members. The returned `OIMAtInfo` can be used to assemble an @ message. This marker is not a real group member and does not mean that the sender has passed the permission check.
