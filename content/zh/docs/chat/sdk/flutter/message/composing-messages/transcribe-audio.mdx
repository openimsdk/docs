将本地音频文件上传到语音识别服务并返回识别出的文本内容：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `filename` | `String` | 是 | 当前设备上待识别音频文件的本地可读取绝对路径。 |

```dart
final result = await OpenIM.iMManager.messageManager.speechToText(
  filename: soundElem.soundPath!,
);
final transcript = result.text ?? '';
```

## 返回结果

Future 成功返回语音识别结果对象（`SpeechToTextResp`），可通过其 `text` 字段获取识别后的文本字符串。

该方法仅执行语音识别，不会自动修改消息对象或触发事件通知。若语音消息仅包含远端 URL，需先下载到本地沙盒路径再执行识别。调用前建议通过[检查语音识别能力](/sdk/flutter/message/composing-messages/check-speech-to-text)探测支持情况；识别出的文字若需保存在本地消息中，请参考[保存本地转写结果](/sdk/flutter/message/composing-messages/save-local-transcript)。
