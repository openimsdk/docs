---
title: '删除入群申请'
description: '批量删除 iOS 入群申请记录。'
sourcePath: '/sdk/ios/group/group-applications/delete-group-requests'
---

```objc
DeleteGroupRequest *request =
  [[DeleteGroupRequest alloc] initWithGroupID:application.groupID
                                   fromUserID:application.userID];
[[OIMManager manager] deleteGroupRequests:@[request]
  onSuccess:^(NSString * _Nullable data) { [self reloadApplications]; }
  onFailure:^(NSInteger code, NSString *message) { [self showErrorCode:code message:message]; }];
```

删除记录不等于拒绝申请，也不改变成员关系。其他端通过 `onGroupApplicationDeleted:` 移除相同记录。
