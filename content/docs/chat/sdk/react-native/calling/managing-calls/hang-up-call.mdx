After a call is connected or while it is in progress, invoke `signalingHungUp()` to hang up and exit the call room:

```ts
await OpenIMSDK.signalingHungUp({
  opUserID: currentUserID,
  invitation,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `opUserID` | `string` | Yes | User ID of the participant terminating the call. |
| `invitation` | `RtcInvite` | Yes | Complete call invitation object for the active call. Its `roomID` must match the current room. |

## Return value

A resolved Promise confirms that the hang-up signaling request has been processed by the server.

Other participants receive notification via the `OnHangUp` event. The client should identify the call room using `roomID` and release local media engine resources and screen state. For full event handling, see [Handle call events](/sdk/react-native/calling/managing-calls/handle-call-events).
