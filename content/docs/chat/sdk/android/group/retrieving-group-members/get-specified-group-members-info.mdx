`getGroupMembersInfo()` accepts one `groupID` and a list of target user IDs. It returns the users' `GroupMembersInfo` profiles within that group.

```java
OpenIMClient.getInstance().groupManager.getGroupMembersInfo(
    new OnBase<List<GroupMembersInfo>>() {
        @Override public void onSuccess(List<GroupMembersInfo> members) { mergeMembers(members); }
        @Override public void onError(int code, String error) { showMemberQueryError(error); }
    }, groupID, userIDs);
```

An empty list can mean that the targets are not in the group or that the current user cannot read their profiles. Handle the result according to your product requirements.
