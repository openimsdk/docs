解除当前登录用户与指定用户之间建立的双向好友关系。

```java
OpenIMClient.getInstance().friendshipManager.deleteFriend(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 删除好友成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    friendUserID
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `friendUserID` | `String` | 是 | 待解除好友关系的目标用户 ID。 |

## 返回结果

成功回调表示服务端已完成好友关系的解除。

解除成功后，SDK 会通过 `OnFriendshipListener` 派发事件：
- `onFriendDeleted(FriendInfo friend)`：通知好友关系已解除，客户端收到事件后应以 `userID` 为主键从本地好友列表缓存中移除对应项。

完整监听配置请参考[分页获取好友列表](/sdk/android/user/friends/get-friend-list-page)。删除好友不会自动清除会话和历史消息，如需同步清理请参考[删除会话及消息](/sdk/android/conversation/managing-conversations/delete-conversation-with-messages)。
