群消息成员级已读属于商业版能力。指定群聊会话、消息、筛选方向和分页范围：

```uts
import {
  OpenIMGroupMessageReaderFilterRead,
  getGroupMessageReaderList,
} from '@/uni_modules/unix-openim-sdk'

const clientMsgID = message.clientMsgID
if (clientMsgID == null) return

const result = await getGroupMessageReaderList({
  conversationID,
  clientMsgID,
  filter: OpenIMGroupMessageReaderFilterRead,
  offset: 0,
  count: 50,
})

const readers = result?.readers ?? []
```

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `string` | 是 | 群聊会话 ID。 |
| `clientMsgID` | `string` | 是 | 要查询阅读成员的客户端消息 ID。 |
| `filter` | `OpenIMGroupMessageReaderFilter` | 是 | 使用 `OpenIMGroupMessageReaderFilterRead` 查询已读成员，使用 `OpenIMGroupMessageReaderFilterUnread` 查询未读成员。 |
| `offset` | `number` | 是 | 分页偏移量，第一页传 `0`。 |
| `count` | `number` | 是 | 本次请求的成员数量。 |

Promise 成功后返回 `OpenIMGetGroupMessageReaderListResult | null`；非空结果的当前页成员位于 `readers`。按 `groupID:userID` 去重；本次返回数量小于 `count` 时，可视为到达列表末尾。查询只建立调用时的成员列表，不触发回执事件。
