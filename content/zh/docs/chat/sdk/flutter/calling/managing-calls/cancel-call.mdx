title: '取消通话邀请'
description: '使用 Flutter SDK 取消尚未接通的通话邀请。'
sourcePath: '/sdk/flutter/calling/managing-calls/cancel-call'
---

邀请尚未接通时，发起方取消邀请：

```dart
await OpenIM.iMManager.signalingManager
    .signalingCancel(info: activeInfo);
```

使用发起时保存的完整 `SignalingInfo`。Future 成功表示取消信令请求完成；应用还应停止等待状态并释放媒体资源。
