---
title: '开启或关闭阅后即焚'
description: '使用 iOS SDK 设置会话的阅后即焚模式。'
sourcePath: '/sdk/ios/conversation/managing-conversations/set-private-chat'
---

```objc
[[OIMManager manager] setConversationPrivateChat:conversationID
                                        isPrivate:YES
                                        onSuccess:nil
                                        onFailure:nil];
```

`YES` 表示启用阅后即焚，`NO` 表示关闭。阅后即焚时长由独立方法设置，不要把两个请求的成功或事件阶段混为一体。该能力与定期删除服务端消息不同。
