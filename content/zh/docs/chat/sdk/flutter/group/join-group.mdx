用户申请加入公开群或指定群组：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `reason` | `String?` | 否 | 申请入群的附言或验证理由。 |
| `joinSource` | `int` | 是 | 入群来源类型：`2` 通过群成员邀请，`3` 通过搜索群 ID 或名称，`4` 通过扫描群二维码。 |

```dart
await OpenIM.iMManager.groupManager.joinGroup(
  groupID: groupID,
  reason: '申请加入项目讨论组',
  joinSource: 3,
);
```

## 返回结果

Future 成功表示请求已提交。若群组设置为免验证直接入群，当前用户立即成为群成员；若群组开启了验证审批，则需等待群主或管理员审核。

正式加入群组后，SDK 会触发加入群通知。客户端以 `groupID` 为合并标识将该群加入本地已加入群组列表，完整事件监听请参考[群组概览](/sdk/flutter/group/overview-group)。入群申请管理请参考[入群申请概览](/sdk/flutter/group/group-applications/overview-group-applications)。
