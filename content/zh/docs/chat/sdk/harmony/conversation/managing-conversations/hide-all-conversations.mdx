---
title: '隐藏全部会话'
description: '从当前账号的会话列表隐藏全部会话入口。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/hide-all-conversations'
---

该操作影响范围较大，应要求用户确认。

```ts
import sdk from '@openimsdk/imsdk';

await sdk.hideAllConversations();
```

隐藏不会删除好友、群组或服务端消息。后续新消息或有效同步可能重新生成会话。完成后重新查询会话列表和总未读数。
