搜索结果、回复引用或通知跳转应同时保存会话 ID 和客户端消息 ID。

```ts
import sdk, { FindMessageListReq, FindMessageListResp } from '@openimsdk/imsdk';

const request: FindMessageListReq = {
  conversationsArgs: [
    {
      conversationID: conversationID,
      clientMsgIDList: [clientMsgID],
    },
  ],
};
const response: FindMessageListResp = await sdk.findMessageList(request);
const results = response.findResultItems;
```

一次调用可以查询多个会话。不要假设结果项与输入数组的位置一致，应按结果项的 `conversationID` 和消息的 `clientMsgID` 对应。`totalCount` 是找到的消息数量；消息尚未同步、已经删除或 ID 不存在时可能返回空结果。
