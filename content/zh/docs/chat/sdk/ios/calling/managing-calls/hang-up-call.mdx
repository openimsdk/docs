通话建立后，任一参与者均可使用当前通话保存的 `OIMSignalingInfo` 调用挂断接口结束通话：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `signalingInfo` | `OIMSignalingInfo *` | 当前进行中的通话信令信息对象。 |

```objc
[[OIMManager manager] signalingHungUp:signalingInfo
                            onSuccess:^{ [self releaseCallResources]; }
                            onFailure:^(NSInteger code, NSString * _Nullable message) {
    [self showCallError:code message:message ?: @"挂断通话失败"];
}];
```

通话状态以 `roomID` 为合并标识，参与者状态同时结合用户 ID。

## 返回结果

成功回调 `onSuccess` 表示挂断信令已成功提交至服务端。其他参与方将通过回调收到挂断通知（详见[处理通话事件](/sdk/ios/calling/managing-calls/handle-call-events)）。应用收到成功回调或挂断事件后，需及时停止音视频采集、离开媒体房间并释放摄像头、麦克风和 `AVAudioSession` 等硬件资源，清理流程建议按 `roomID` 幂等执行。
