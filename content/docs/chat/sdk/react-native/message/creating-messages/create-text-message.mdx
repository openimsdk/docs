Use `createTextMessage()` to create a text message ready to send.

```ts
const message = await OpenIMSDK.createTextMessage('Hello, welcome to the discussion.');
```

The argument is the message text. The call returns a `MessageItem`; pass it as `message` to [Send a message](/sdk/react-native/message/sending-messages/send-message).
