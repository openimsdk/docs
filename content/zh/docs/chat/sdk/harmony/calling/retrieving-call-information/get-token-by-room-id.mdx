description: '按房间 ID 重新获取加入媒体房间所需的凭据。'

---

```ts
import sdk, { SignalingGetTokenByRoomIDReq, SignalingGetTokenByRoomIDResp } from '@openimsdk/imsdk';

const request: SignalingGetTokenByRoomIDReq = {
  roomID: roomID,
  userID: currentUserID,
  participant: participant,
};
const response: SignalingGetTokenByRoomIDResp = await sdk.signalingGetTokenByRoomID(request);
await mediaEngineJoin(roomID, response.token, response.liveURL);
```

`participant` 是当前入会用户资料。响应不重复返回房间 ID，连接媒体引擎时继续使用请求值。只有取得非空的 `token` 和可用的 `liveURL` 后才能进入媒体房间；请求失败时应保留当前通话状态并按业务流程重试或退出。
