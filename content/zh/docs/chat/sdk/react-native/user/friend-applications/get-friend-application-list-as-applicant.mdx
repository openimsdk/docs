调用 `getFriendApplicationListAsApplicant()` 分页查询当前用户发出的好友申请。

```ts
const applications = await OpenIMSDK.getFriendApplicationListAsApplicant({
  offset: 0,
  count: 20,
});
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `offset` | `number` | 是 | 分页偏移量，首页传 `0`。 |
| `count` | `number` | 是 | 本次请求的申请数量。 |

返回当前页的 `FriendApplicationItem[]`。申请记录字段见[获取收到的好友申请](/sdk/react-native/user/friend-applications/get-friend-application-list-as-recipient)。
