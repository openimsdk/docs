Android 消息以 `Message` 表示，使用 `clientMsgID` 去重，使用 `sessionType`、`recvID` 和 `groupID` 区分单聊与群聊。消息内容由对应的 element 字段承载，发送、接收、撤回和删除是不同的状态变化。

```java
OpenIMClient.getInstance().messageManager.setAdvancedMsgListener(new OnAdvanceMsgListener() {
    @Override public void onRecvNewMessage(Message message) { messageStore.merge(message); }
});
```

查询建立快照，`OnAdvanceMsgListener` 合并增量；`MessageManager` 的 listener 设置会替换当前 listener。
