---
title: '搜索消息'
description: '使用 searchLocalMessages 搜索当前账号已同步到本地的消息。'
sourcePath: '/sdk/android/message/searching-messages/search-messages'
---

可按会话、关键词、发送者、消息类型、时间范围和分页参数搜索。`conversationID` 传 `null` 表示全局搜索。

```java
messageManager.searchLocalMessages(callback, conversationID, keywords, 1,
    senderIDs, messageTypes, 0, 0, 0, 20);
```
