---
title: '转让群主'
description: '将群主身份转让给另一名有效群成员。'
sourcePath: '/sdk/harmony/group/managing-group-members/transfer-group-owner'
---

只有当前群主可以转让，目标用户必须是该群组中的有效成员。

```ts
import sdk, { TransferGroupOwnerReq } from '@openimsdk/imsdk';

const request: TransferGroupOwnerReq = {
  groupID: groupID,
  ownerUserID: targetUserID,
};
await sdk.transferGroupOwner(request);
```

Promise 成功后，原群主和新群主的角色都可能变化，应逐条处理成员资料变化事件。群主需要退出群组时，必须先完成转让，再调用[退出群组](/sdk/harmony/group/quit-group)。
