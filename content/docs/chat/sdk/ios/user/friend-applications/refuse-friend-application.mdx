```objc
[[OIMManager manager] refuseFriendApplication:applicantUserID
                                     handleMsg:@"Not adding contacts at this time"
                                     onSuccess:nil
                                     onFailure:nil];
```

The first argument is the applicant's user ID, and `handleMsg` is the response message. A successful callback means that the reject request has completed. The request update may arrive afterward. For the complete synchronization rules, see [Retrieve received friend requests](/sdk/ios/user/friend-applications/get-friend-application-list-as-recipient).
