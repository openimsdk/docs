```java
Message message = OpenIMClient.getInstance().messageManager.createVideoMessageFromFullPath(
    absoluteVideoPath,
    mimeType,
    durationSeconds,
    absoluteSnapshotPath

```

视频和缩略图的绝对路径必须可读，视频时长单位为秒。本方法只创建待发送对象。
