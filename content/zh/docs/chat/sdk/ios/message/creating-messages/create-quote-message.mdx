---
title: '创建回复消息'
description: '使用 iOS SDK 创建引用消息。'
sourcePath: '/sdk/ios/message/creating-messages/create-quote-message'
---

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createQuoteMessage:@"同意这个方案"
                                message:originalMessage];
```

第一个参数是新正文，第二个参数是列表、历史查询或事件返回的完整原消息。创建不会修改原消息，也不会自动发送。
