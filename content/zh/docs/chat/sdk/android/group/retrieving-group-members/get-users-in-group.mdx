title: '检查用户是否在群内'
description: '使用 getUsersInGroup 从候选用户中筛出当前在群内的用户 ID。'
sourcePath: '/sdk/android/group/retrieving-group-members/get-users-in-group'
---

`getUsersInGroup()` 返回传入用户中已在指定群内的 ID 列表，不返回成员资料。

```java
OpenIMClient.getInstance().groupManager.getUsersInGroup(new OnBase<List<String>>() {
    @Override public void onSuccess(List<String> joinedUserIDs) { updateMembership(joinedUserIDs); }
    @Override public void onError(int code, String error) { showMembershipError(error); }
}, groupID, candidateUserIDs);
```

需要昵称、角色或禁言状态时，再调用“获取群成员资料”。
