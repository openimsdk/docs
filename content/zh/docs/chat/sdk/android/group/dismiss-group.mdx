---
title: '解散群组'
description: '使用 dismissGroup 解散当前用户有权限管理的群组。'
sourcePath: '/sdk/android/group/dismiss-group'
---

`dismissGroup()` 解散指定群组，仅群主可执行。

```java
OpenIMClient.getInstance().groupManager.dismissGroup(new OnBase<String>() {
    @Override public void onSuccess(String data) { markDismissSubmitted(groupID); }
    @Override public void onError(int code, String error) { showDismissError(error); }
}, groupID);
```

通过 `onGroupDismissed` 接收群组解散通知。
