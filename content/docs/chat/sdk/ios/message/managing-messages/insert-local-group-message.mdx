```objc
[[OIMManager manager] insertGroupMessageToLocalStorage:message
    groupID:groupID
    sendID:currentUserID
    onSuccess:^(OIMMessageInfo *stored) {
        if (stored != nil) [self upsertMessage:stored];
    }
    onFailure:nil];
```

The pinned declaration allows `groupID`, `sendID`, and the success result to be `nil`, but application code must validate the target and sender before calling. This method modifies the current device only. It does not send the message to group members or trigger the new-message delegate.
