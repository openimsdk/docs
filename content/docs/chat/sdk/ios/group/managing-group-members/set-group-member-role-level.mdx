Pass `OIMGroupMemberRoleAdmin` to make the user an administrator or `OIMGroupMemberRoleMember` to remove administrator status. Do not set Owner directly as a substitute for transferring ownership. Handle the success callback and `onGroupMemberInfoChanged:` separately.

```objc
[[OIMManager manager] setGroupMemberRoleLevel:groupID
  userID:targetUserID
  roleLevel:OIMGroupMemberRoleAdmin
  onSuccess:^(NSString * _Nullable data) { [self showSaved]; }
  onFailure:^(NSInteger code, NSString *message) {
    [self showErrorCode:code message:message];
  }];
```
