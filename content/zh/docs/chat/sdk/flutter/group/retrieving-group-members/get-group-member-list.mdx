支持按角色筛选并分页查询目标群组内的成员列表。调用者通常需要已加入该群组：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `filter` | `int` | 否 | 角色筛选：`0` 全部成员，`1` 群主，`2` 管理员，`3` 普通成员。默认为 `0`。 |
| `offset` | `int` | 否 | 分页偏移量，第一页从 `0` 开始。 |
| `count` | `int` | 否 | 每页拉取的最大成员数量。 |

```dart
final members = await OpenIM.iMManager.groupManager.getGroupMemberList(
  groupID: groupID,
  filter: 0,
  offset: 0,
  count: 50,
);
```

## 返回结果

Future 成功返回当前分页的群成员列表（`List<GroupMembersInfo>`）。

分页拉取下一页时，应按已请求条目数递增 `offset`，不得使用接收增量事件后发生变化的本地数组长度作为偏移基准。若需直接读取群主与管理员团队，请使用[获取群主和管理员](/sdk/flutter/group/retrieving-group-members/get-group-owner-and-admin)。

查询操作建立静态数据快照，不会触发事件通知。后续群成员变动与增量合并规则请参考[群成员查询概览](/sdk/flutter/group/retrieving-group-members/overview-retrieving-group-members)。
