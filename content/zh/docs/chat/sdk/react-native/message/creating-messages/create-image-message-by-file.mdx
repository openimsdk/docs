使用 `createImageMessageFromFullPath()` 根据本地图片完整路径创建消息。

```ts
const message = await OpenIMSDK.createImageMessageFromFullPath(imagePath);
```

`imagePath` 是图片在设备上的完整路径。调用后返回待发送的 `MessageItem`；使用[发送消息](/sdk/react-native/message/sending-messages/send-message)发送时，SDK 会处理本地资源上传。
