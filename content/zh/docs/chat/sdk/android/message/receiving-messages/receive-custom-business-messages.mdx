监听独立于普通聊天会话的自定义业务消息。该监听器接收到的数据为纯文本或 JSON 字符串载荷，适用于音视频通话信令、自定义透传指令等场景，不需要作为普通聊天气泡渲染进消息列表。

```java
OpenIMClient.getInstance().messageManager.setCustomBusinessListener(
    new OnCustomBusinessListener() {
        @Override
        public void onRecvCustomBusinessMessage(String payload) {
            // payload 为业务端自定义的 JSON 字符串或指令数据
        }
    }
);
```

## 回调说明

- `payload`（`String`）：接收到的自定义业务数据字符串。业务层可按预先约定的 JSON 结构进行反序列化并分发业务逻辑。

## 使用建议

建议在 SDK 初始化完成后由全局信令管理层统一注册监听。该消息不影响会话的未读数，也不会触发会话列表最后一条消息的变更。若需要构建并发送自定义业务消息，请参阅[创建自定义消息](/sdk/android/message/creating-messages/create-custom-message)。
