---
title: '创建音频消息'
description: '使用相对于 SDK 初始化数据目录的路径创建音频消息。'
sourcePath: '/sdk/android/message/creating-messages/create-sound-message'
---

```java
Message message = OpenIMClient.getInstance().messageManager
    .createSoundMessage(soundPath, durationSeconds);
```

音频文件应位于 SDK 初始化时配置的数据目录内，`soundPath` 传入相对于该目录的路径，时长单位为秒。本方法只创建待发送对象。
