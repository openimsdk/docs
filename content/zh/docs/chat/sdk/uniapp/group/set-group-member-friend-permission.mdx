`applyMemberFriend` 的类型为 `OpenIMGroupAllowType`。

## 参数说明

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `OpenIMGroupAllowTypeAllowed` | `0` | 允许通过群成员关系发起好友申请。 |
| `OpenIMGroupAllowTypeNotAllowed` | `1` | 不允许通过群成员关系发起好友申请。 |

```uts
import {
  OpenIMGroupAllowTypeNotAllowed,
  setGroupInfo,
} from '@/uni_modules/unix-openim-sdk'

await setGroupInfo({
  groupID,
  applyMemberFriend: OpenIMGroupAllowTypeNotAllowed,
})
```

该字段只控制群内互相添加好友的权限，不等同于禁止查看成员资料，也不会影响既有的好友关系。Promise 成功表示设置请求已完成，客户端可先将本地对应群组的该权限更新为目标值，收到群资料变更事件后，按 `groupID` 确认最新状态。完整群组事件监听见[群组概览](/sdk/uniapp/group/overview-group)。
