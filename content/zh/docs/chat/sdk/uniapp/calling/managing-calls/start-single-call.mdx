`signalingInvite()` <span className="enterprise-field-badge">商业版</span> 使用 invitation 和可选离线推送信息。

```uts
import { signalingInvite } from '@/uni_modules/unix-openim-sdk'

const result = await signalingInvite({
  invitation: {
    inviterUserID: selfUserID,
    inviteeUserIDList: [peerUserID],
    mediaType: 'video',
    timeout: 30,
    sessionType: 1,
  },
  offlinePushInfo: { title: '视频通话', desc: '收到新的通话邀请' },
})
```

返回值可能含 `roomID`、`token`、`liveURL` 和忙线用户列表，全部按可选字段处理。邀请成功后若页面展示失败，应主动取消。不要在日志中打印 token 或 liveURL。
