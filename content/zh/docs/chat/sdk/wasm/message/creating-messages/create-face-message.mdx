title: '创建表情消息'
description: '使用 WASM SDK 创建表情消息。'
sourcePath: '/sdk/wasm/message/creating-messages/create-face-message'
---

表情消息适合发送应用内约定的表情包条目。SDK 不负责下载表情资源或解释业务协议，发送端与接收端需要共同约定索引和扩展数据的含义。

```ts
const { data: message } = await openimsdk.createFaceMessage({
  index: 12,
  data: JSON.stringify({ pack: 'default' }),
});
```

`index` 是双方约定的表情索引，`data` 是完整扩展字符串，可以承载表情包标识、版本等必要信息。接收端遇到未知表情包或索引时，应提供占位图或文本提示。

Promise 成功后，`data` 是待发送的 `MessageItem`；创建操作不会上传表情资源或发送消息。下一步使用[发送消息](/sdk/wasm/message/sending-messages/send-message)中的 `sendMessage()` 投递该对象。
