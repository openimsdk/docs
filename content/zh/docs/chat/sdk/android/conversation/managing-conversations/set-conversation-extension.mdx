`ex` 是用于保存会话扩展信息的字符串，可以传入 JSON 字符串或其他业务约定格式的字符串。

```java
OpenIMClient.getInstance().conversationManager.setConversationEx(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markConversationExtensionSubmitted(conversationID);
        }

        @Override
        public void onError(int code, String error) {
            recordConversationExtensionFailure(code, error);
        }
    },
    conversationID,
    extensionJSON
);
```

成功回调表示设置请求已完成。会话列表中的扩展字段变化可通过 `onConversationChanged` 接收，监听器设置方式见[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。
