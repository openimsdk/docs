---
title: '设置群组全员禁言'
description: '开启或关闭 iOS 群组整体禁言。'
sourcePath: '/sdk/ios/group/change-group-mute'
---

```objc
[[OIMManager manager] changeGroupMute:groupID
    isMute:YES
    onSuccess:^(NSString * _Nullable data) { [self showGroupMuted]; }
    onFailure:^(NSInteger code, NSString *message) {
        [self showErrorCode:code message:message];
    }];
```

`isMute` 为 `YES` 时开启，为 `NO` 时关闭。固定 iOS SDK 没有 WASM 的例外用户参数。

成功 callback 表示服务端完成设置；`onGroupInfoChanged:` 随后可能返回更新后的 `OIMGroupInfo`，完整 delegate 见[群组概览](/sdk/ios/group/overview-group)。
