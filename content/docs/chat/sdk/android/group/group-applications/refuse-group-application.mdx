The reject operation also takes the application's `groupID`, the applicant's `userID`, and a handling message.

```java
OpenIMClient.getInstance().groupManager.refuseGroupApplication(new OnBase<String>() {
    @Override public void onSuccess(String data) { markApplicationRejected(groupID, applicantUserID); }
    @Override public void onError(int code, String error) { showHandleError(error); }
}, groupID, applicantUserID, "The group is currently full");
```

After the rejection succeeds, receive the notification through `onGroupApplicationRejected` or call the query API again to retrieve the latest application list.
