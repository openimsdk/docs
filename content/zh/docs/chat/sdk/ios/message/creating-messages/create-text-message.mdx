---
title: '创建文本消息'
description: '使用 iOS SDK 创建文本消息。'
sourcePath: '/sdk/ios/message/creating-messages/create-text-message'
---

`OIMMessageInfo` 的消息工厂只同步创建待发送对象，不会发送消息或触发接收 delegate。

```objc
OIMMessageInfo *message = [OIMMessageInfo createTextMessage:text];
```

参数是文本正文。调用前应在业务层处理空白、长度和内容规则。创建后将对象交给[发送消息](/sdk/ios/message/sending-messages/send-message)。
