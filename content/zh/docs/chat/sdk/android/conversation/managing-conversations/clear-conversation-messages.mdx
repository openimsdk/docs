产品语义为“清空聊天记录”时，调用 `messageManager.clearConversationAndDeleteAllMsg()`。

```java
OpenIMClient.getInstance().messageManager.clearConversationAndDeleteAllMsg(
    conversationID,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            messageStore.clearConversation(conversationID);
        }

        @Override
        public void onError(int code, String error) {
            recordConversationClearFailure(code, error);
        }
    }
);
```

成功 callback 后保留会话入口，但清除当前账号下的消息和摘要状态。立即清理当前消息列表，再通过 `onConversationChanged` 或重新查询校准最后一条消息、摘要和未读状态。
