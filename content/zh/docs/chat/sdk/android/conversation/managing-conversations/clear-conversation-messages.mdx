清空指定会话内的所有历史消息，但仍保留该会话在列表中的入口节点。常用于用户清理聊天记录但仍需保留联系人或群聊会话的场景。

```java
OpenIMClient.getInstance().messageManager.clearConversationAndDeleteAllMsg(
    conversationID,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成，消息已清空。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    }
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 目标会话的唯一标识。 |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |

## 返回结果

成功回调表示指定会话的消息已清空完成。会话条目仍然保留在列表中，但其最后一条消息内容（`latestMsg`）将被清空重置。

清理完成后，SDK 会触发 `OnConversationListener.onConversationChanged` 事件；客户端应以 `conversationID` 唯一定位目标会话，并刷新会话项和消息列表，完整监听配置请参考[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。若需连同会话列表项彻底删除，请参考[删除会话及消息](/sdk/android/conversation/managing-conversations/delete-conversation-with-messages)。
