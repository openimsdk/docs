用户处理完群聊中的 @ 消息后，将 `groupAtType` 重置为普通状态：

```dart
await OpenIM.iMManager.conversationManager.setConversation(
  conversationID,
  ConversationReq(groupAtType: GroupAtType.atNormal),
);
```

本操作只负责将状态重置为普通状态，不应用于主动写入 `atMe`、`atAll` 等状态。群聊 @ 状态与消息已读状态不同。

Future 成功后，通过 `onConversationChanged` 合并该会话；完整 listener 见[获取会话列表](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list)。
