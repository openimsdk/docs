调用 `setGroupInfo()` 设置或更新群公告。

```ts
await OpenIMSDK.setGroupInfo({
  groupID,
  notification: announcement,
});
```

`groupID` 为目标群组 ID，`notification` 为公告内容。传入空字符串可以清空群公告；群公告与群简介 `introduction` 是两个独立字段。

## 返回结果

调用完成后，群公告已更新。群资料变化会通过 `OnGroupInfoChanged` 返回，事件监听方式见[群组概览](/sdk/react-native/group/overview-group)。
