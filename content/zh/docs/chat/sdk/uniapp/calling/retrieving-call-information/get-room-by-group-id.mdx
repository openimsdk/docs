---
title: '查询群组通话房间'
description: '按群组 ID 查询当前正在进行的通话房间。'
sourcePath: '/sdk/uniapp/calling/retrieving-call-information/get-room-by-group-id'
---

`signalingGetRoomByGroupID()` 按 `groupID` 查询当前群通话，不接收自定义 `roomID`：

```uts
import {
  signalingGetRoomByGroupID,
} from '@/uni_modules/unix-openim-sdk'

const result = await signalingGetRoomByGroupID({ groupID })

if (result?.roomID != null) {
  restoreGroupCall(result.roomID!, result.invitation)
} else {
  clearStaleGroupCall(groupID)
}
```

Promise 成功后返回 `OpenIMSignalingGetRoomByGroupIDResult | null`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `roomID` | `string` 或 `null` | 当前群通话的房间 ID。 |
| `invitation` | `OpenIMSignalingInvitationInfo` 或 `null` | 当前房间对应的邀请数据。 |

结果为空或没有有效 `roomID` 时，表示本次查询没有取得可恢复房间，应清理本地旧状态。Promise 被拒绝表示查询失败；除非当前部署明确约定了“房间不存在”的错误码，否则不要把任意网络或鉴权错误解释为没有通话。
