OpenIMClientSDK uses `userID` as the unique user identifier. The user domain manages personal profiles, public profiles of other users, global notification settings, friend application permissions, and online presence. Friendships, friend applications, and blocklists belong to the relationship domain, whereas group-specific nicknames and role levels belong to the group domain.

## Data models

| Model | Purpose |
| --- | --- |
| `IMUser` | Account-level and public profile information for self and other users. |
| `IMFriend` | Friend relationship record, including private remarks and relationship extensions. |
| `IMBlack` | Blocklist entry maintained by the current account. |
| `IMGroupMember` | Group-specific nickname, avatar, role level, and mute status. |
| `UserOnlinePlatform` | Platform presence details for online users. |

A single user can appear simultaneously across multiple data sources. Contact lists should prioritize friend remarks, group rosters should display group member nicknames, and conversation headers should use `showName`. Never overwrite context-specific display labels with public nicknames.
