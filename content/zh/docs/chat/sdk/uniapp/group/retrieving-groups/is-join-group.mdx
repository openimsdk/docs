title: '检查是否已加入群组'
description: '检查当前用户是否已加入指定群组。'

---

在进入群聊相关功能前，可快速检查当前登录用户是否已加入指定群组，以便控制界面操作入口与权限展示。

```uts
import { isJoinGroup } from '@/uni_modules/unix-openim-sdk'

const joined = await isJoinGroup(groupID)
if (joined == true) {
  showGroupMemberActions()
}
```

`groupID` 是目标群组 ID。Promise 成功后返回 `boolean | null`：`true` 表示查询时当前用户已加入，`false` 表示未加入；`null` 不应当作已加入处理。

该方法只查询当前时刻的状态，不会触发群组事件。需要持续维护成员状态时，应结合[群组概览](/sdk/uniapp/group/overview-group)中的加入、退出和解散事件，按 `groupID` 同步状态，并在网络重连或关键操作后重新查询校准。
