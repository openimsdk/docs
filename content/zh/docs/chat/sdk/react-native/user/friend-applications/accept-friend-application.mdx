接受指定用户发来的好友申请。

```ts
await OpenIMSDK.acceptFriendApplication({
  toUserID: applicantUserID,
  handleMsg: '',
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `toUserID` | `string` | 是 | 申请发起人的用户 ID。 |
| `handleMsg` | `string` | 是 | 处理申请时附带的说明；没有说明时传空字符串。 |

## 返回结果

调用完成后，好友申请审批已处理完成。

接受好友申请后双方建立正式好友关系，会触发 `OnFriendApplicationAccepted` 事件，并触发 `OnFriendAdded` 事件通知双方客户端。客户端应以 `userID` 为合并标识将新好友添加到本地好友列表中，并更新对应申请记录的状态。完整事件监听说明见[分页获取好友列表](/sdk/react-native/user/friends/get-friend-list-page)。
