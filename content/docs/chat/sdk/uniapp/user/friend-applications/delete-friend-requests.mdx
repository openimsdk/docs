`deleteFriendRequests()` is <span className="enterprise-field-badge">Commercial</span>.

```uts
import { deleteFriendRequests } from '@/uni_modules/unix-openim-sdk'

await deleteFriendRequests({
  friendRequests: [{ fromUserID: 'user_a', toUserID: 'user_b' }],
})
```

Each `OpenIMSimpleFriendRequest` identifies an exact request. Deleting request history does not remove an established friendship. Confirm targets in the UI and reload both the list and unhandled count; after a batch failure, do not assume which records were removed.
