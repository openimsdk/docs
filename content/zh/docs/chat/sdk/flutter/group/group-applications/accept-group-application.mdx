群主或管理员调用此方法审核通过指定用户的入群申请：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `userID` | `String` | 是 | 申请人用户 ID。 |
| `handleMsg` | `String?` | 否 | 审核处理附言。 |

```dart
await OpenIM.iMManager.groupManager.acceptGroupApplication(
  groupID: groupID,
  userID: applicantUserID,
  handleMsg: '欢迎加入',
);
```

## 返回结果

Future 成功表示入群申请已批准，该用户正式成为群成员。

多端同步或事件到达时通过 `onGroupApplicationAccepted` 通知，新成员加入由 `onGroupMemberAdded` 通知。客户端以 `groupID:userID` 为合并标识更新申请状态与群成员列表，完整事件监听请参考[入群申请概览](/sdk/flutter/group/group-applications/overview-group-applications)。
