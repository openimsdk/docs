传入一组用户 ID，批量检查并筛选出其中已加入指定群组的用户列表。

```ts
const userIDs = await OpenIMSDK.getUsersInGroup({
  groupID: 'group-001',
  userIDList: ['user-001', 'user-002', 'user-003'],
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 目标群组 ID。 |
| `userIDList` | `string[]` | 是 | 要检查的用户 ID 数组。 |

## 返回结果

调用完成后返回 `string[]`，包含已加入该群组的用户 ID 列表。未包含在返回结果中的用户表示未加入该群或已退出。若需要进一步拉取成员详细资料，可使用[查询指定群成员资料](/sdk/react-native/group/retrieving-group-members/get-specified-group-members-info)。
