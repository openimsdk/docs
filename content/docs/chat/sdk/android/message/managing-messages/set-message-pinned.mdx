Pass `true` as the final argument to pin the message or `false` to unpin it:

```java
messageManager.setConversationPinnedMsg(
    callback,
    conversationID,
    clientMsgID,
    true
);
```

The success callback means that the request completed; it does not mean that the pinned-message event has arrived.

This page owns `OnAdvanceMsgListener.onChangedPinnedMsg`. `ChangedPinnedMsg` contains the `conversationID` and current pinned-message collection. Replace the collection for that conversation, then deduplicate its messages by `clientMsgID`:

```java
@Override
public void onChangedPinnedMsg(ChangedPinnedMsg event) {
    replacePinnedMessages(event.getConversationID(), event.getMsgs());
}
```

Add this callback to the application's single `OnAdvanceMsgListener`; see [Events](/sdk/android/events/overview-events) for centralized setup. Callback completion, event delivery, and the snapshot from [View pinned messages](/sdk/android/message/managing-messages/get-pinned-messages) are three independent stages.
