`searchLocalMessages()` 在 SDK 本地数据中搜索。

```uts
import { searchLocalMessages } from '@/uni_modules/unix-openim-sdk'

const result = await searchLocalMessages({
  conversationID,
  keywordList: ['发布'],
  keywordListMatchType: 0,
  senderUserIDList: [],
  messageTypeList: [],
  searchTimePosition: 0,
  searchTimePeriod: 0,
  pageIndex: 1,
  count: 50,
})
```

匹配类型、时间单位和页码使用合同/服务端约定。搜索只覆盖已同步到本地且可索引的内容；不要承诺服务器全量历史。结果按会话与消息 ID 去重。
