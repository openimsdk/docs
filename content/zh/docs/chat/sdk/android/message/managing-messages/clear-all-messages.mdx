---
title: '清理全部消息'
description: '使用 deleteAllMsgFromLocalAndSvr 清理本地和服务端消息。'
sourcePath: '/sdk/android/message/managing-messages/clear-all-messages'
---

`deleteAllMsgFromLocalAndSvr()` 清理当前账号的本地消息，并请求删除该账号在服务端保存的消息。这是高影响操作，产品界面应明确说明范围并要求二次确认。

```java
OpenIMClient.getInstance().messageManager.deleteAllMsgFromLocalAndSvr(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 清空当前账号的消息列表和相关页面状态。
        }

        @Override
        public void onError(int code, String error) {
            // 不要只清理界面；保留现有数据并提示失败。
        }
    }
);
```

成功回调表示清理请求已经完成。它不会删除其他用户各自保存的消息副本，也不会自动删除好友、群组或会话关系。不要把清理界面当作请求成功；需要重新展示数据时，再查询对应会话的消息。
