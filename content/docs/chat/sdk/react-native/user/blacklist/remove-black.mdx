Unblock a user by removing them from the current account's blacklist:

```ts
await OpenIMSDK.removeBlack(blackUserID);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `blackUserID` | `string` | Yes | Target user ID to unblock and remove from the blacklist. |

## Return value

A resolved Promise confirms that the user was removed from the blacklist on the server.

Unblocking triggers the `OnBlackDeleted` event. Remove the entry keyed by `userID` from your local blacklist cache. For event listener details, see [Get blacklist](/sdk/react-native/user/blacklist/get-black-list).
