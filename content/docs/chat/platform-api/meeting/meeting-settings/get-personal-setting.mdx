Get a user's personal audio and video preferences for a meeting.

## HTTP request
```bash
POST {API_ADDRESS}/rtc-meeting/get_personal_setting
```

## Request body
| Parameter | Required | Type | Description |
| --- | --- | --- | --- |
| meetingID | Yes | string | Meeting ID. |
| userID | Yes | string | Participant user ID. |

## Response
`data.setting` contains a [`PersonalMeetingSetting`](/platform-api/meeting/overview#personalmeetingsetting) with `cameraOnEntry` and `microphoneOnEntry`.

## Permissions and limits
- Available only in OpenIM Enterprise.
- Validate that the caller may read the participant's meeting preferences.
