Combine multiple historical messages into a single merged forward card:

```ts
const message = await OpenIMSDK.createMergerMessage({
  messageList: selectedMessages,
  title: 'Project Discussion Records',
  summaryList: [
    'Alex: Release schedule confirmed',
    'Taylor: I will follow up on QA testing',
  ],
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `messageList` | `MessageItem[]` | Yes | Array of messages to bundle and merge. |
| `title` | `string` | Yes | Title displayed on the merged card and preview header. |
| `summaryList` | `string[]` | Yes | Array of preview summary strings displayed on the message card. |

## Return value

A resolved Promise returns the initialized `MessageItem` object with merged records, title, and summaries stored in `mergeElem`.

This method builds the message structure strictly in client memory; it does not dispatch messages to the server or trigger lifecycle events. After initialization, invoke [Send message](/sdk/react-native/message/sending-messages/send-message) to deliver it to a conversation. Ensure summary snippets respect conversation privacy constraints.
