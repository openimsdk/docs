向 OpenIM SDK 上报客户端当前展示的消息总未读数，用于同步远端推送服务的角标计数状态。

```ts
await OpenIMSDK.setAppBadge(totalUnreadCount);
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `totalUnreadCount` | `number` | 是 | 应用当前的总未读消息数，必须为非负整数。 |

## 返回结果

调用成功代表 SDK 已接受并更新本次角标数值。

- 本方法仅向 SDK 及推送服务同步总未读数，不会直接改变各会话本身的未读状态。
- 若需要在移动操作系统桌面图标（iOS/Android 启动器）上显示数字角标，应用层还需结合 React Native 的原生角标模块（如 `@react-native-community/push-notification-ios` 或各厂商推送 SDK）同步更新系统原生桌面角标。
- 消息总未读数的实时查询与事件监听请参考[获取消息总未读数](/sdk/react-native/conversation/managing-conversations/get-total-unread-count)。
