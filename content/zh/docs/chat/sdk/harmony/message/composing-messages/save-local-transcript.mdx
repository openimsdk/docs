---
title: '更新本地消息内容'
description: '替换当前设备数据库中的完整消息内容。'
sourcePath: '/sdk/harmony/message/composing-messages/save-local-transcript'
---

该操作只修改当前设备的本地消息。接口接收完整 `IMMessage`，不是只更新某一个内容字段。

```ts
import sdk, { IMMessage, SetMessageLocalContentReq } from '@openimsdk/imsdk';

const localMessage: IMMessage = cloneMessage(message);
if (localMessage.textElem !== undefined) {
  localMessage.textElem.content = '仅在当前设备显示的文本';
}

const request: SetMessageLocalContentReq = {
  conversationID: conversationID,
  message: localMessage,
};
await sdk.setMessageLocalContent(request);
```

`cloneMessage()` 代表应用中返回独立 `IMMessage` 的类型安全复制函数。更新对象必须保留原始标识和其他必要字段，不能只构造 `clientMsgID` 与新内容。Promise 成功后不会上传到 OpenIMServer、同步给其他设备或触发共享消息事件。若只保存转写文本等应用数据，通常更适合合并写入 `localEx`。
