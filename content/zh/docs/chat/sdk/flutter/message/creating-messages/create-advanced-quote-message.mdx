引用已有消息并附带富文本内容（如超链接、特定高亮格式），构建待发送的高级引用回复消息：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `text` | `String` | 是 | 回复正文文本。 |
| `quoteMsg` | `Message` | 是 | 被引用的原始完整消息对象。 |
| `list` | `List<RichMessageInfo>?` | 否 | 富文本实体配置列表，包含链接、高亮等偏移量与长度配置。 |

```dart
final message = await OpenIM.iMManager.messageManager
    .createAdvancedQuoteMessage(
  text: text,
  quoteMsg: originalMessage,
  list: entities,
);
```

每个富文本实体的偏移量与长度必须基于最终正文字符串计算，被引用的原始消息应来自真实消息记录。

## 返回结果

Future 成功返回待发送的高级引用消息对象（`Message`），其引用内容保存在 `quoteElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送，不会修改被引用的原始消息，也不会触发新消息事件通知。构建完成后，需将返回的 `Message` 实例传给[发送消息](/sdk/flutter/message/sending-messages/send-message)投递至单聊或群聊会话。
