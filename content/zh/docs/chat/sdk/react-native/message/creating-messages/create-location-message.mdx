创建带有经纬度和地址描述的位置消息。

```ts
const message = await OpenIMSDK.createLocationMessage({
  description: '上海市浦东新区',
  longitude: 121.4737,
  latitude: 31.2304,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `description` | `string` | 是 | 位置名称或地址描述。 |
| `longitude` | `number` | 是 | 经度数值。 |
| `latitude` | `number` | 是 | 纬度数值。 |

## 返回结果

调用完成后返回已创建的 `MessageItem` 消息对象，其中 `locationElem` 保存位置信息。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送消息](/sdk/react-native/message/sending-messages/send-message)将消息投递到单聊或群聊会话中。
