清理当前登录账号在当前设备本地数据库中的所有消息记录。该方法无需传入参数，适合在释放本地存储空间或重置本地数据时使用：

```dart
await OpenIM.iMManager.messageManager.deleteAllMsgFromLocal();
clearLocalMessageState();
```

## 返回结果

Future 成功表示当前设备本地数据库中的所有历史消息已全部清除。

此操作属于设备本地的破坏性操作，仅清理当前端数据库，不会删除服务端保存的消息记录，也不会触发跨端消息删除事件通知。后续若重新拉取历史漫游或在其他端登录，服务端历史仍可正常同步。若需同时从本地和服务端彻底删除所有聊天记录，请参考[清理全部消息](/sdk/flutter/message/managing-messages/clear-all-messages)；若只需删除单条本地消息，请参考[删除本地消息](/sdk/flutter/message/managing-messages/delete-local-message)。
