调用 `getJoinedGroupListPage()` 分页获取当前账号已加入的群组。

```ts
const groups = await OpenIMSDK.getJoinedGroupListPage({
  offset: 0,
  count: 50,
});
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `offset` | `number` | 是 | 分页偏移量，第一页传 `0`。 |
| `count` | `number` | 是 | 本次读取的群组数量。 |

继续读取下一页时，将 `offset` 设置为已读取的群组数量。

## 返回结果

调用完成后返回当前页的 `GroupItem[]`。字段说明见[群组概览](/sdk/react-native/group/overview-group)。
