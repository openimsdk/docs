Call `setGroupInfo()` to set the group's `ex` extension field.

```ts
await OpenIMSDK.setGroupInfo({
  groupID,
  ex: JSON.stringify({
    projectID: 'project-42',
  }),
});
```

`groupID` is the target group ID. `ex` is a string and can contain JSON or another string format for business-specific data.

## Return value

When the call completes, the group extension field is updated. Group profile changes trigger `OnGroupInfoChanged`; see [Group overview](/sdk/react-native/group/overview-group) for event handling.
