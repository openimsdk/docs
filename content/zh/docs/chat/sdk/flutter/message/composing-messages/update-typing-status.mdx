description: '使用 Flutter SDK 上报当前用户的输入状态。'

---

```dart
await OpenIM.iMManager.conversationManager.changeInputStates(
  conversationID: conversationID,
  focus: true,
);
```

开始输入传 `true`，发送消息、失焦、切换会话或停止输入时传 `false`。输入状态不会保存草稿或写入消息列表。对开始输入做节流和去重；Future 成功不表示远端界面已更新。已废弃并抛出 `UnimplementedError` 的 `typingStatusUpdate()` 不要使用。

`onInputStatusChanged` 是本页归属事件，应纳入唯一的 `OnConversationListener`，按 `conversationID:userID` 覆盖 `platformIDs` 快照。设置入口见[事件概览](/sdk/flutter/events/overview-events)。
