Associate one or more conversations into one or more conversation groups in a batch operation:

```ts
await OpenIMSDK.addConversationsToGroups({
  conversationIDs: [conversationID],
  conversationGroupIDs: [conversationGroupID],
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationIDs` | `string[]` | Yes | List of conversation IDs to add. |
| `conversationGroupIDs` | `string[]` | Yes | List of destination conversation group IDs. |

## Return value

A resolved Promise confirms that the conversations were successfully assigned to the specified groups.

Membership updates trigger the `OnConversationGroupMemberAdded` event. In local state reconciliation, identify the target group by `conversationGroupID` and append member conversation records by `conversationID`. For event registration, see [Conversation groups overview](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups).
