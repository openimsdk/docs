title: '从文件创建文件消息'
description: '使用相对路径或绝对路径创建文件消息。'
sourcePath: '/sdk/android/message/creating-messages/create-file-message-by-file'
---

文件名与路径分别传入；相对路径相对于 SDK 初始化时配置的缓存目录。

```java
Message message = OpenIMClient.getInstance().messageManager
    .createFileMessageFromFullPath(filePath, fileName);
```
