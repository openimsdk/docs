---
title: '接受通话'
description: '使用 WASM SDK 接受通话邀请并取得房间凭据。'
sourcePath: '/sdk/wasm/calling/managing-calls/accept-call'
---

从 `OnReceiveNewInvitation` 取得完整的 `SignalingInvitation` 后，使用 `signalingAccept()` 接受邀请：

```ts
const { data: roomCredentials } = await openimsdk.signalingAccept({
  opUserID: currentUserID,
  invitation,
});
```

`opUserID` 是执行接听操作的当前用户；`invitation` 应直接使用事件中收到的完整邀请数据，其中包含 `roomID`、邀请人、被邀请人和会话类型，不要只选择部分字段重新构造。

Promise 成功后，`data` 是 `SignalingAcceptResult`，包含 `roomID`、`token` 和 `liveURL`。获取有效的 `token` 和 `roomID` 后再连接媒体房间；后续远端状态变化通过[通话事件](/sdk/wasm/calling/managing-calls/handle-call-events)更新。
