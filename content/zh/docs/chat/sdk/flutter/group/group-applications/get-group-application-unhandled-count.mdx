查询当前登录用户作为群主或管理员收到的未处理入群申请数量，常用于红点提示与角标计数：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `time` | `int` | 是 | 起始时间戳（秒），传入 `0` 表示统计全部未处理的入群申请数量。 |

```dart
final count = await OpenIM.iMManager.groupManager
    .getGroupApplicationUnhandledCount(
  GetGroupApplicationUnhandledCountReq(time: 0),
);
```

## 返回结果

Future 成功返回未处理入群申请数量（`int`）。

查询操作建立当前未处理数量的静态快照，不改变申请状态，也不会触发事件通知。新申请到达或处理状态变更请参考[入群申请概览](/sdk/flutter/group/group-applications/overview-group-applications)。
