## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `text` | `string` | 是 | 消息正文；建议使用稳定的 `@userID` 标记。 |
| `atUserIDList` | `string[]` | 是 | 被提及用户 ID；@ 全体时先调用 `getAtAllTag()` 获取专用标记。 |
| `atUsersInfo` | `AtUserInfo[]` | 否 | 用户 ID 与群内展示名信息。 |
| `message` | `MessageItem` | 否 | 被引用的原消息。 |

```ts
const { data: message } = await openimsdk.createTextAtMessage({
  text: '@user_a 请确认',
  atUserIDList: ['user_a'],
  atUsersInfo: [{ atUserID: 'user_a', groupNickname: 'Alex' }],
});
```

接口调用成功后返回待发送的 `MessageItem` 对象。该类型消息仅支持投递至群聊会话；创建方法仅在本地构建对象，不会改变会话的 @ 状态，亦不会触发新消息推送事件。

## 提及全体成员

在实现“@所有人”功能时，请勿在前端代码中硬编码字符串，应先调用 `getAtAllTag()` 接口获取服务端约定的全体成员标记，再将其写入正文与 `atUserIDList`：

```ts
const { data: atAllTag } = await openimsdk.getAtAllTag();
const { data: message } = await openimsdk.createTextAtMessage({
  text: `${atAllTag} 请查看群公告`,
  atUserIDList: [atAllTag],
});
```

`getAtAllTag()` 返回当前 SDK 约定的全体标记字符串；该调用为轻量本地方法，不发起网络请求，亦不触发任何事件。
