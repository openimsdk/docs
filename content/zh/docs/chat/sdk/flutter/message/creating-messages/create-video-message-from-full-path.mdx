从本地文件系统的完整绝对路径构建待发送的视频消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `videoPath` | `String` | 是 | 视频文件在设备文件系统中的完整绝对路径。 |
| `videoType` | `String` | 是 | 视频文件的 MIME 类型（例如 `video/mp4`）。 |
| `duration` | `int` | 是 | 视频播放时长（秒）。 |
| `snapshotPath` | `String` | 是 | 视频封面图在设备文件系统中的完整绝对路径。 |

```dart
final message = await OpenIM.iMManager.messageManager
    .createVideoMessageFromFullPath(
  videoPath: videoPath,
  videoType: 'video/mp4',
  duration: durationSeconds,
  snapshotPath: snapshotPath,
);
```

传入的视频与封面绝对路径必须具备有效的文件读取权限。

## 返回结果

Future 成功返回待发送的视频消息对象（`Message`），视频与封面图属性保存在 `videoElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送或媒体上传，也不会触发新消息事件通知。构建完成后，需将返回的 `Message` 实例传给[发送消息](/sdk/flutter/message/sending-messages/send-message)，由 SDK 执行媒体上传与消息投递。若使用平台通用相对路径，请参考[创建视频消息](/sdk/flutter/message/creating-messages/create-video-message)；若视频已上传至对象存储，请参考[使用 URL 创建视频消息](/sdk/flutter/message/creating-messages/create-video-message-by-url)。
