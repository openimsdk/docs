---
title: '创建群组'
description: '使用 createGroup 创建群资料并指定初始成员、管理员和群主。'
sourcePath: '/sdk/android/group/create-group'
---

使用 `createGroup()` 创建群组。`GroupInfo` 填写群资料；初始普通成员、管理员和群主分别通过独立参数传入。成功回调返回创建后的完整 `GroupInfo`，其中包含新群组的 `groupID`。

```java
GroupInfo info = new GroupInfo();
info.setGroupName("项目讨论");
info.setIntroduction("仅限项目成员");

OpenIMClient.getInstance().groupManager.createGroup(
    memberUserIDs, adminUserIDs, info, ownerUserID,
    new OnBase<GroupInfo>() {
        @Override public void onSuccess(GroupInfo group) { /* group 包含新群组信息。 */ }
        @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
    }
);
```
