When an invitee receives a call invitation and decides not to answer, call this method to decline the invitation:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `info` | `SignalingInfo` | Yes | The complete signaling object received in the invitation callback. Pass the original object rather than reconstructing one from `roomID`. |

## Code example

```dart
await OpenIM.iMManager.signalingManager
    .signalingReject(info: receivedInfo);
```

## Return value

A successful `Future` indicates that the rejection signaling request has been received by the server.

## State changes after the call

The client should dismiss the incoming call dialog and release any unallocated media resources associated with `roomID`. The initiator updates its outgoing call UI upon receiving the rejection event (see [Handle call events](/sdk/flutter/calling/managing-calls/handle-call-events) for complete event handling).
