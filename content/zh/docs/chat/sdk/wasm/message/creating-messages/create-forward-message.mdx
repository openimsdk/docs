---
title: '创建转发消息'
description: '使用 WASM SDK 创建单条转发消息。'
sourcePath: '/sdk/wasm/message/creating-messages/create-forward-message'
---

单条转发会根据一条已经发送成功的原消息创建新的待发送对象。传入完整的原 `MessageItem`，不要只传消息文本或自行拼接消息元素：

```ts
const { data: message } = await openimsdk.createForwardMessage(sourceMessage);
```

发送中或发送失败的消息不能转发。业务侧还应根据权限、内容有效期和本地文件可用性决定是否显示转发入口。

Promise 成功后，`data` 是具有新 `clientMsgID` 的待发送 `MessageItem`，原消息不会被修改。下一步使用[发送消息](/sdk/wasm/message/sending-messages/send-message)将新对象发送到目标单聊或群聊；创建操作本身不会触发新消息事件。
