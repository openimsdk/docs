When entering a conversation, restoring a connection, or confirming the current typing state, query the platforms on which a specified member is still typing:

```ts
const { data: platformIDs } = await openimsdk.getInputStates({
  conversationID,
  userID: memberUserID,
});

setTyping(memberUserID, platformIDs.length > 0);
```

The Promise returns the platform IDs on which the member is still typing when the call runs. The query itself does not trigger a typing-status event. In a group chat, do not poll every member. Maintain the set of typing users through the event described on [Report typing status](/sdk/wasm/message/composing-messages/update-typing-status).
