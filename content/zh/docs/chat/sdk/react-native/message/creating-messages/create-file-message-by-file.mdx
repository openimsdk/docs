根据设备上的本地文件创建文件消息。

```ts
const message = await OpenIMSDK.createFileMessageFromFullPath({
  filePath,
  fileName: '产品说明.pdf',
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `filePath` | `string` | 是 | 设备本地文件的完整路径。 |
| `fileName` | `string` | 是 | 消息对外展示的文件名。 |

## 返回结果

调用完成后返回已创建的 `MessageItem` 消息对象，其中 `fileElem` 保存文件元信息。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送消息](/sdk/react-native/message/sending-messages/send-message)将消息投递到单聊或群聊会话中，SDK 会在发送过程中自动处理本地文件上传。
