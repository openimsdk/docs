Decline an applicant's group join request as a group owner or administrator:

```ts
await OpenIMSDK.refuseGroupApplication({
  groupID: application.groupID,
  fromUserID: application.userID,
  handleMsg: 'Application declined',
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group ID of the application. |
| `fromUserID` | `string` | Yes | Applicant user ID (corresponds to `application.userID`). |
| `handleMsg` | `string` | Yes | Reason for refusal. Pass empty string `""` if not provided. |

## Return value

A resolved Promise confirms that the refusal was recorded on the server.

Refusing an application triggers the `OnGroupApplicationRejected` event. Update the review status of the application entry in the group application list. For full event listeners, see [Get received group applications](/sdk/react-native/group/group-applications/get-group-application-list-as-recipient).
