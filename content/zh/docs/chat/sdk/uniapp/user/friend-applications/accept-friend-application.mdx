title: '接受好友申请'
description: '同意指定用户发来的好友申请。'

同意指定用户发来的好友申请。处理收到的申请时，`toUserID` 填写申请人的用户 ID，而不是当前用户 ID。`handleMsg` 是处理时附带的信息；没有内容时传空字符串。

```uts
import { acceptFriendApplication } from '@/uni_modules/unix-openim-sdk'

await acceptFriendApplication({
  toUserID: applicantUserID,
  handleMsg: '',
})
```

Promise 成功表示本次同意请求已成功返回，不表示相关事件已经到达。申请记录与好友关系是两份不同的数据：收到好友申请被同意事件后更新对应申请，收到好友添加事件后再按 `userID` 写入好友列表；需要校准状态时分别重新查询申请和好友列表。完整处理方式请参考[获取收到的好友申请](/sdk/uniapp/user/friend-applications/get-friend-application-list-as-recipient)和[分页获取好友列表](/sdk/uniapp/user/friends/get-friend-list-page)。
