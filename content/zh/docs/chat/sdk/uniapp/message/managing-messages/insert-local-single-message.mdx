---
title: '插入本地单聊消息'
description: '使用 UniApp SDK 向当前设备的单聊记录插入一条本地消息。'
sourcePath: '/sdk/uniapp/message/managing-messages/insert-local-single-message'
---

本地插入适合只在当前设备展示的提示或迁移数据。先创建完整消息对象，再指定单聊双方：

```uts
import {
  createTextMessage,
  insertSingleMessageToLocalStorage,
} from '@/uni_modules/unix-openim-sdk'

const message = await createTextMessage('本地提示')
if (message == null) return

await insertSingleMessageToLocalStorage({
  message,
  recvID: targetUserID,
  sendID: currentUserID,
})
```

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `message` | `OpenIMMessageItem` | 是 | 要写入本地数据库的完整消息对象。 |
| `recvID` | `string` | 是 | 单聊接收方用户 ID。 |
| `sendID` | `string` | 是 | 消息发送方用户 ID。 |

`sendID` 和 `recvID` 必须与目标单聊一致。Promise 成功只表示当前设备本地数据库已写入，不会发送消息、离线推送或触发新消息事件。需要多端同步或让对方收到消息时，应使用[发送消息](/sdk/uniapp/message/sending-messages/send-message)。
