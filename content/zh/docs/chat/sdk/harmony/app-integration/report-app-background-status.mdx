title: '上报应用前后台状态'
description: '在 HarmonyOS 应用生命周期变化时通知 OpenIMClientSDK。'

---

宿主应用进入后台或回到前台时，调用 `setAppBackgroundStatus()` 上报当前状态，使 SDK 按实际生命周期调整连接与后台行为。

```ts
import sdk, { SetAppBackgroundStatusReq } from '@openimsdk/imsdk';

const backgroundRequest: SetAppBackgroundStatusReq = {
  isBackground: true,
};
await sdk.setAppBackgroundStatus(backgroundRequest);

const foregroundRequest: SetAppBackgroundStatusReq = {
  isBackground: false,
};
await sdk.setAppBackgroundStatus(foregroundRequest);
```

将调用接入应用级前后台生命周期，不要由每个页面重复上报。Promise 成功只表示状态已交给 SDK，不会创建登录会话，也不能代替 Token 更新或网络恢复处理。

2in1 多窗口应用应依据整个进程或主应用的可见状态制定策略，关闭一个窗口不应把仍在使用的 SDK 错误上报为完全退出。
