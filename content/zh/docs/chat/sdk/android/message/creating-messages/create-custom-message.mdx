构建承载特定业务逻辑的自定义消息对象。通过传递结构化 JSON 字符串、扩展信息以及展示描述，支持红包、投票、订单通知等自定义业务组件的会话交互。

```java
String dataJson = "{\"action\":\"red_packet\",\"packetID\":\"rp_888\",\"amount\":100}";
String extensionJson = "{\"theme\":\"festive\"}";
String description = "[收到一个红包]";

Message message = OpenIMClient.getInstance().messageManager.createCustomMessage(
    dataJson,
    extensionJson,
    description
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `data` | `String` | 是 | 自定义消息主体内容，通常为结构化 JSON 字符串。 |
| `extension` | `String` | 否 | 业务补充扩展信息，无内容时可传空字符串。 |
| `description` | `String` | 是 | 会话列表最后一条消息展示的简短摘要或通知栏提示文案。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.CUSTOM`。

发送端与接收端应提前约定自定义数据的协议结构并处理未知版本的降级展示。构建完成后，请调用[发送消息](/sdk/android/message/sending-messages/send-message)发送。
