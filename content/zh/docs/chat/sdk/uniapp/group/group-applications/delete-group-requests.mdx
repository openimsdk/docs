---
title: '删除入群申请'
description: '批量删除指定的入群申请记录。'
sourcePath: '/sdk/uniapp/group/group-applications/delete-group-requests'
---

`deleteGroupRequests()` 按“群组 + 申请人”批量删除入群申请记录。该操作适合清理已经处理或不再需要展示的记录。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupRequests` | `OpenIMSimpleGroupRequest[]` | 是 | 要删除的申请列表。 |
| `groupRequests[].groupID` | `string` | 是 | 申请加入的群组 ID。 |
| `groupRequests[].fromUserID` | `string` | 是 | 申请人的用户 ID，对应申请记录中的 `userID`。 |

```uts
import { deleteGroupRequests } from '@/uni_modules/unix-openim-sdk'

await deleteGroupRequests({
  groupRequests: [
    {
      groupID: application.groupID,
      fromUserID: application.userID,
    },
  ],
})
```

删除申请记录不等于拒绝申请。需要给出审核结果时，应先使用 `acceptGroupApplication()` 或 `refuseGroupApplication()`；删除后再拒绝可能已经找不到对应记录。

Promise 成功表示删除请求已经完成。`onGroupApplicationDeleted()` 随后可能到达，申请列表应按 `groupID:userID` 移除记录。该事件的完整监听见[获取收到的入群申请](/sdk/uniapp/group/group-applications/get-group-application-list-as-recipient)。
