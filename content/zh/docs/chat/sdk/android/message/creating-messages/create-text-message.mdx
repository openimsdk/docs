构建一条标准的纯文本消息对象。本接口仅在本地初始化 `Message` 实例并填充 `textElem` 字段，不会发起网络请求向服务端发送消息。

```java
String text = "你好，这是一条文本消息。";

Message message = OpenIMClient.getInstance().messageManager.createTextMessage(text);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `text` | `String` | 是 | 消息正文文本内容。传入前建议在客户端校验文本长度。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.TEXT`。

获取到 `Message` 对象后，可先在本地聊天界面中将其追加到列表展示并标记为发送中状态，随后调用[发送消息](/sdk/android/message/sending-messages/send-message)向单聊或群聊投递。
