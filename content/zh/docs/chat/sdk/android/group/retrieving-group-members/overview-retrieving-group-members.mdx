成员查询使用 `groupID` 限定范围，结果为 `GroupMembersInfo` 或用户 ID 列表。成员列表提供角色过滤和 offset 分页；指定成员资料、在群检查、群主管理员和关键词搜索各有独立接口。

成员增删和资料变化由[群组概览](/sdk/android/group/overview-group)归属的 `OnGroupListener` 统一合并。查询只建立快照，不能替代事件处理。
