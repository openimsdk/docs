---
title: '设置会话备注'
description: '为当前用户的指定会话设置备注。'
sourcePath: '/sdk/wasm/conversation/managing-conversations/set-conversation-remark'
---

字段 `remark` 用于设置当前用户专用的会话别名或备注。该修改仅对当前登录用户生效，不会修改对方的实际用户昵称、好友备注或群组名称：

```ts
await openimsdk.setConversation({
  conversationID,
  remark: '项目讨论',
});
```

传入空字符串可清除备注。在前端展示会话标题时，推荐优先展示 `remark`，当其为空时再回退展示 `showName`。

接口调用成功后，SDK 会触发 `SdkEvent.OnConversationChanged` 事件通知会话变更。前端可根据 `conversationID` 更新对应会话的备注显示。完整的事件监听配置请参考[获取会话列表](/sdk/wasm/conversation/retrieving-conversations/retrieve-conversation-list)。
