## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `message` | `MessageItem` | 是 | 要写入本地数据库的完整消息对象。 |
| `groupID` | `string` | 是 | 目标群组 ID。 |
| `sendID` | `string` | 是 | 消息发送方的用户 ID。 |

```ts
await openimsdk.insertGroupMessageToLocalStorage({
  message,
  groupID,
  sendID: currentUserID,
});
```

接口调用成功仅表示该消息已存入当前设备的本地数据库，并不会通过网络发送给群内其他成员，亦不会触发新消息推送事件。该接口通常用于插入仅在本机展示的群聊引导提示或临时系统通知。若需真正向群成员发送消息，请使用[发送消息](/sdk/wasm/message/sending-messages/send-message)。
