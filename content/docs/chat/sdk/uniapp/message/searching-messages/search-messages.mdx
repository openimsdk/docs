```uts
import { searchLocalMessages } from '@/uni_modules/unix-openim-sdk'

const result = await searchLocalMessages({
  conversationID, keywordList: ['release'], keywordListMatchType: 0,
  senderUserIDList: [], messageTypeList: [], searchTimePosition: 0,
  searchTimePeriod: 0, pageIndex: 1, count: 50,
})
```

Use contract-defined matching and time semantics. Search covers locally synchronized/indexable data, not guaranteed full server history. Deduplicate by conversation and message ID.
