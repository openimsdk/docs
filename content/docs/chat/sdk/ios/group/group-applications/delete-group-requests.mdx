Invoke `deleteGroupRequests:onSuccess:onFailure:` to delete group join application records in batches:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `requests` | `NSArray<DeleteGroupRequest *> *` | Yes | List of application deletion items. |

### DeleteGroupRequest properties

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `NSString *` | Yes | Target group ID. |
| `fromUserID` | `NSString *` | Yes | Applicant user ID. |

## Code example

```objc
DeleteGroupRequest *request =
    [[DeleteGroupRequest alloc] initWithGroupID:@"group_1001"
                                     fromUserID:@"user_003"];

[[OIMManager manager] deleteGroupRequests:@[request]
                                onSuccess:^(NSString * _Nullable data) {
                                    [self reloadApplications];
                                }
                                onFailure:^(NSInteger code, NSString *message) {
                                    NSLog(@"deleteGroupRequests failed: %ld %@", (long)code, message);
                                }];
```

## Return value

The `onSuccess` callback returns confirmation when the application records are successfully deleted.

## State changes after the call

1. **History pruning**: Deleting application records removes historical review items without approving or rejecting membership requests, and without modifying group member relationships.
2. **Event notification**: Multi-device synchronization broadcasts the deletion via the `onGroupApplicationDeleted:` listener callback. The client removes matching records using `groupID:userID`.
3. **Re-query calibration**: For listener integration, refer to [Group applications overview](/sdk/ios/group/group-applications/overview-group-applications).
