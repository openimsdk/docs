基于相对于 SDK 初始化数据目录的相对文件路径创建语音/音频消息对象。在调用[发送消息](/sdk/android/message/sending-messages/send-message)时，SDK 会自动上传音频文件。

```java
String soundPath = "sounds/voice_001.m4a";
long durationSeconds = 12L; // 录音时长 12 秒

Message message = OpenIMClient.getInstance().messageManager.createSoundMessage(
    soundPath,
    durationSeconds
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `soundPath` | `String` | 是 | 音频文件相对于 SDK 初始化数据目录的相对文件路径。 |
| `duration` | `long` | 是 | 音频播放时长（单位：秒）。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.VOICE`。

构建完成后，请调用[发送消息](/sdk/android/message/sending-messages/send-message)投递至目标单聊或群聊。若使用本地绝对路径创建，请参阅[使用本地路径创建音频消息](/sdk/android/message/creating-messages/create-sound-message-by-file)。
