---
title: '发布或更新群公告'
description: '通过 GroupInfo.notification 发布或更新群公告。'
sourcePath: '/sdk/android/group/set-group-announcement'
---

Android SDK 没有独立的公告方法。构造包含 `groupID` 与 `notification` 的 `GroupInfo`，再调用 `setGroupInfo()`。

```java
GroupInfo update = new GroupInfo();
update.setGroupID(groupID);
update.setNotification("今晚 20:00 进行版本发布确认。");

OpenIMClient.getInstance().groupManager.setGroupInfo(update, new OnBase<String>() {
    @Override public void onSuccess(String data) { refreshAnnouncement(groupID); }
    @Override public void onError(int code, String error) { showAnnouncementError(error); }
});
```

公告的更新时间和更新人由返回的 `GroupInfo` 中 `notificationUpdateTime`、`notificationUserID` 表示。权限由服务端校验。
