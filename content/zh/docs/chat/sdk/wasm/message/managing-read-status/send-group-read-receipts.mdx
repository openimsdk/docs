```ts
await openimsdk.sendGroupMessageReadReceipt({
  conversationID,
  clientMsgIDList: visibleUnreadMessageIDs,
});
```

同一批消息必须属于目标群会话。Promise 成功只表示服务端接受上报，不等于其他客户端界面已更新。会话未读数仍由 `markConversationMessageAsRead()` 独立维护。

其他客户端通过 `SdkEvent.OnRecvGroupReadReceipt` 接收群聊成员级已读变化。该事件的完整监听示例集中在本页；收到事件后，使用 `conversationID + clientMsgID` 找到对应消息，并更新其 `hasReadCount`、`unreadCount` 和成员信息。

```ts
import { SdkEvent } from '@openim/wasm-client-sdk';

const handleGroupReadReceipt = ({ data }) => {
  mergeGroupReadReceipt(data);
};

openimsdk.on(SdkEvent.OnRecvGroupReadReceipt, handleGroupReadReceipt);

function removeGroupReadReceiptListener() {
  openimsdk.off(SdkEvent.OnRecvGroupReadReceipt, handleGroupReadReceipt);
}
```

组件卸载、退出登录或切换账号时调用 `removeGroupReadReceiptListener()`。上报 Promise、群回执事件，以及[查询群消息已读成员](/sdk/wasm/message/managing-read-status/get-group-message-readers)返回的查询时成员列表是三个独立阶段。
