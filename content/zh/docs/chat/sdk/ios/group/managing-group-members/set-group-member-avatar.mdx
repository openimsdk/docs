更新群成员在当前群组内的独立展示头像：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupID` | `NSString *` | 目标群组 ID。 |
| `userID` | `NSString *` | 目标群成员的用户 ID。 |
| `faceURL` | `NSString *` | 成员在群内展示的新头像 URL。 |

```objc
NSDictionary *updates = @{
    @"groupID": @"group_1001",
    @"userID": @"user_003",
    @"faceURL": @"https://example.com/avatar/group_user_003.png"
};

[[OIMManager manager] setGroupMemberInfo:updates
                               onSuccess:^(NSString * _Nullable data) {
                                   NSLog(@"setGroupMemberInfo avatar success");
                               }
                               onFailure:^(NSInteger code, NSString *message) {
                                   NSLog(@"setGroupMemberInfo avatar failed: %ld %@", (long)code, message);
                               }];
```

状态以 `groupID:userID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 返回操作结果。

服务端完成头像更新后，群内各端会通过 `onGroupMemberInfoChanged:` 事件分发成员信息更新（监听注册参见[群组概览](/sdk/ios/group/overview-group)），客户端应以 `groupID:userID` 为合并标识更新对应成员在当前群的头像。注意群内专属头像仅在该群中展示，不同于用户账号级别的全局个人头像。群成员详细信息拉取可查阅[群成员查询概览](/sdk/ios/group/retrieving-group-members/overview-retrieving-group-members)。
