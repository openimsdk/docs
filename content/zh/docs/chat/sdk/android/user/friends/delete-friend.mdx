---
title: '删除好友'
description: '使用 deleteFriend() 删除当前用户的一条好友关系。'
sourcePath: '/sdk/android/user/friends/delete-friend'
---

```java
OpenIMClient.getInstance().friendshipManager.deleteFriend(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 删除好友成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    friendUserID
);
```

成功回调表示删除请求已经完成，不代表好友列表事件已经到达。`onFriendDeleted(FriendInfo info)` 提供被删除的好友关系资料；收到事件后按 `info.getUserID()` 从好友列表移除对应用户。完整 listener 见[分页获取好友列表](/sdk/android/user/friends/get-friend-list-page)，需要确认完整列表时再重新分页查询。
