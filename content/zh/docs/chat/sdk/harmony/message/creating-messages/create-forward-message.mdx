---
title: '创建逐条转发消息'
description: '根据一条已有消息创建可发送到其他会话的转发消息。'
sourcePath: '/sdk/harmony/message/creating-messages/create-forward-message'
---

```ts
import sdk, { CreateForwardMessageReq, CreateForwardMessageResp } from '@openimsdk/imsdk';

const request: CreateForwardMessageReq = { message: sourceMessage };
const response: CreateForwardMessageResp = await sdk.createForwardMessage(request);
const message = response.message;
```

源消息应来自查询结果或消息事件，并且已经发送成功。转发前检查用户仍有权传播内容；本地路径、失效资源地址和仅当前设备有效的数据不能假定在目标会话可用。创建操作只在本地构造消息对象，不会修改原消息或自动选择目标会话；后续调用 [发送消息](/sdk/harmony/message/sending-messages/send-message) 发送到目标单聊或群聊。
