构建用于分享联系人资料的个人名片消息。通过 `CardElem` 封装目标用户的 `userID`、昵称与头像信息。

```java
CardElem cardElem = new CardElem();
cardElem.setUserID("user_target");
cardElem.setNickname("李四");
cardElem.setFaceURL("https://example.com/avatar.png");

Message message = OpenIMClient.getInstance().messageManager.createCardMessage(cardElem);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `cardElem` | `CardElem` | 是 | 名片数据模型对象，至少设置被分享者的用户 ID `userID`、昵称 `nickname` 以及头像地址 `faceURL`。 |

## 返回结果

返回创建完成的 `Message` 对象，其 `contentType` 为 `MessageType.CARD`。

本接口仅在本地初始化消息对象，不会发起网络请求校验用户资料或发送消息。构建完成后，调用[发送消息](/sdk/android/message/sending-messages/send-message)投递至目标会话。
