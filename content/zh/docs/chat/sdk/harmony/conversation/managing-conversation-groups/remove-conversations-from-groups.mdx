---

该操作只删除会话与分组的关联，不删除会话，也不清空消息。

## 参数说明

| 参数                   | 类型       | 是否必填 | 说明                      |
| ---------------------- | ---------- | -------- | ------------------------- |
| `conversationIDs`      | `string[]` | 是       | 要移除的 OpenIM 会话 ID。 |
| `conversationGroupIDs` | `string[]` | 是       | 目标会话分组 ID。         |

```ts
import sdk, { RemoveConversationsFromGroupsReq } from '@openimsdk/imsdk';

const request: RemoveConversationsFromGroupsReq = {
  conversationIDs: [conversationID],
  conversationGroupIDs: [conversationGroupID],
};
await sdk.removeConversationsFromGroups(request);
```

Promise 成功表示关联移除请求已经完成，不表示分组成员事件已经到达。收到事件通知后，按 `conversationGroupID` 和 `conversationID` 合并增量，完整监听代码请参考[会话分组概览](/sdk/harmony/conversation/managing-conversation-groups/overview-conversation-groups)；需要最终确认时可重新查询受影响的分组。
