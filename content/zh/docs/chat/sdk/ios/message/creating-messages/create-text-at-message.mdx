在群聊会话中，当需要提及一名或多名特定群成员时，可调用创建 @ 消息方法生成包含提及信息的文本消息对象。

```objc
OIMAtInfo *info = [OIMAtInfo new];
info.atUserID = member.userID;
info.groupNickname = member.nickname;

OIMMessageInfo *message =
    [OIMMessageInfo createTextAtMessage:text
                              atUsersID:@[member.userID]
                            atUsersInfo:@[info]
                                message:nil];
```

## 参数说明

- `text`：包含 @ 文本的正文内容（`NSString *`）。
- `atUsersID`：被 @ 成员的用户 ID 列表（`NSArray<NSString *>`）。
- `atUsersInfo`：被 @ 成员的展示信息列表（`NSArray<OIMAtInfo *>`），包含用户的昵称等。
- `message`：被引用的原始消息对象（`OIMMessageInfo * _Nullable`），若不需要同时引用消息可传 `nil`。

## 返回结果

- 返回初始化的 `OIMMessageInfo` 对象，其内容类型为 @ 文本。
- 该方法仅在本地构建消息对象，通常只用于群聊会话。后续投递需调用[发送消息](/sdk/ios/message/sending-messages/send-message)。
