Invoke `quitGroup()` to leave an active group as a regular member or administrator. The group owner cannot leave the group directly; they must transfer ownership to another member using [Transfer group ownership](/sdk/uniapp/group/managing-group-members/transfer-group-owner) before exiting.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | The ID of the group to leave. |

## Code example

```uts
import { quitGroup } from '@/uni_modules/unix-openim-sdk'

await quitGroup(groupID)
```

## Return value

The Promise resolves with `void` once OpenIMServer processes the departure request.

## State changes after the call

A resolved Promise confirms that the exit request completed. The client removes the group from its joined group list using `groupID`, confirming removal when `onJoinedGroupDeleted` arrives. For complete group event listener registration, see [Group overview](/sdk/uniapp/group/overview-group).

Leaving a group does not automatically delete or hide local conversation records. The conversation entry may remain in the history list; do not infer active group membership from conversation existence alone.
