`isMsgDestruct` and `msgDestructTime` together configure scheduled server message deletion and can be sent in one `ConversationReq`.

```java
ConversationReq request = new ConversationReq();
request.setMsgDestruct(true);
request.setMsgDestructTime(3600);

OpenIMClient.getInstance().conversationManager.setConversation(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            markMessageDestructSubmitted(conversationID);
        }

        @Override
        public void onError(int code, String error) {
            recordMessageDestructFailure(code, error);
        }
    },
    conversationID,
    request
);
```

`msgDestructTime` is measured in seconds. Set `request.setMsgDestruct(false)` to disable the policy. This capability is distinct from burn after reading. Conversation list changes can be received through `onConversationChanged`; see [Get the conversation list](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list) for listener setup.
