将群主身份转让给群内的另一名有效成员，只有当前群主可以执行此操作。

```uts
import { transferGroupOwner } from '@/uni_modules/unix-openim-sdk'

await transferGroupOwner({
  groupID: groupID,
  newOwnerUserID: targetUserID,
})
```

`groupID` 是目标群组 ID，`newOwnerUserID` 是新群主的用户 ID。

Promise 成功表示 SDK 已完成转让请求。原群主和新群主的角色都会发生变化，因此应根据群成员信息变更事件，使用 `groupID:userID` 分别更新两位成员的角色记录。需要重新确认管理角色时，可以调用[分页查询群成员](/sdk/uniapp/group/retrieving-group-members/get-group-member-list)，将 `filter` 设为 `OpenIMGroupMemberFilterAdminAndOwner` 查询群主和管理员。

群主需要退出群组时，必须先完成转让，再调用[退出群组](/sdk/uniapp/group/quit-group)。如果群组不再需要，也可以选择解散群组，但解散会影响所有成员。
