拒绝指定用户发起的好友申请：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `userID` | `NSString *` | 发起好友申请的用户 ID。 |
| `handleMsg` | `NSString *` | 拒绝处理附言，如“暂不方便添加”；无需附言时传空字符串。 |

```objc
[[OIMManager manager] refuseFriendApplication:applicantUserID
                                     handleMsg:@"暂不添加"
                                     onSuccess:^(NSString *data) {
    [applicationStore markRejectedForUserID:applicantUserID];
}
                                     onFailure:^(NSInteger code, NSString *message) {
    NSLog(@"refuseFriendApplication failed: %ld %@", (long)code, message);
}];
```

状态以 `userID` 为合并标识。

## 返回结果

成功回调 `onSuccess` 表示服务端已处理拒绝操作。申请方及当前账号的其他登录端随后将通过好友申请监听收到申请状态变更事件，完整事件处理见[获取收到的好友申请](/sdk/ios/user/friend-applications/get-friend-application-list-as-recipient)。
