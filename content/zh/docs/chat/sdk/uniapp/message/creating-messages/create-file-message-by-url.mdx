`createFileMessageByURL()` 适用于文件已经由业务上传服务取得远端 URL 的场景。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `filePath` | `string` | 否 | 原始本地路径；只有远端资源时可以传空字符串。 |
| `uuid` | `string` | 否 | 文件资源唯一标识，优先使用上传结果返回的值。 |
| `sourceUrl` | `string` | 否 | 已上传文件的可访问地址；创建 URL 型文件消息时应提供。 |
| `fileName` | `string` | 否 | 接收端展示和保存时使用的文件名。 |
| `fileSize` | `number` | 否 | 文件大小，单位为字节。 |

```uts
import { createFileMessageByURL } from '@/uni_modules/unix-openim-sdk'

const message = await createFileMessageByURL({
  filePath: '',
  uuid: uploaded.uuid,
  sourceUrl: uploaded.url,
  fileName: '项目计划.pdf',
  fileSize: uploaded.size,
})
if (message == null) return
```

接口类型允许字段为空，但可下载的 URL 型文件消息需要有效的 `sourceUrl`，并应提供真实的文件名和文件大小。下载端仍需校验地址、文件类型和大小，不应仅依赖扩展名。

Promise 成功只创建待发送对象。后续使用[发送已上传的媒体消息](/sdk/uniapp/message/sending-messages/send-message-not-oss)，避免再次上传文件。
