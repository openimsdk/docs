```uts
import { hideConversation } from '@/uni_modules/unix-openim-sdk'

await hideConversation(conversationID)
```

Hiding removes the conversation from the visible list without deleting its message history. A later incoming message or product action can make it visible again; reload the list rather than deleting cached history.
