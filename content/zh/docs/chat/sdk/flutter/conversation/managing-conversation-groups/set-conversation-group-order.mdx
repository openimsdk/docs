批量设置会话分组的展示顺序。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `orders` | `List<ConversationGroupOrder>` | 是 | 分组排序项列表。每一项包含 `groupID`（即目标 `conversationGroupID`，非群组 ID）和对应的新排序值 `order`。 |

```dart
await OpenIM.iMManager.conversationGroupManager.setConversationGroupOrder(
  orders: [
    ConversationGroupOrder(groupID: firstGroupID, order: 100),
    ConversationGroupOrder(groupID: secondGroupID, order: 200),
  ],
);
```

## 返回结果

Future 成功表示排序设置请求已提交处理。客户端以 `conversationGroupID` 为合并标识更新本地分组顺序。

多端同步或事件到达时通过 `onConversationGroupChanged` 通知，完整事件监听请参考[会话分组概览](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups)。
