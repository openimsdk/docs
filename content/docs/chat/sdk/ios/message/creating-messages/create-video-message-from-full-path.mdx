```objc
OIMMessageInfo *message =
    [OIMMessageInfo createVideoMessageFromFullPath:videoURL.path
                                         videoType:@"video/mp4"
                                          duration:durationSeconds
                                      snapshotPath:snapshotURL.path];
```

Both the video and snapshot paths must be readable, and the duration is measured in seconds. Send the returned object through the regular sending API so the SDK can upload and send it.
