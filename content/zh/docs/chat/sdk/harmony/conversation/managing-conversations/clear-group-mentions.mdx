---
title: '重置群聊 @ 状态'
description: '在用户处理群聊中的 @ 消息后重置会话提醒状态。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/clear-group-mentions'
---

```ts
import sdk, { ConvGroupAtType, SetConversationReq } from '@openimsdk/imsdk';

const request: SetConversationReq = {
  conversationID: conversationID,
  groupAtType: ConvGroupAtType.AtNormal,
};
await sdk.setConversation(request);
```

本操作只把真实 @ 提醒重置为普通状态，不应用来伪造“@我”或“@所有人”。接口调用成功后，SDK 会触发会话变更事件；客户端收到通知后根据 `conversationID` 更新对应会话的 `groupAtType` 状态，完整监听配置请参考[获取会话列表](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list)。重置 @ 状态与标记已读属于不同操作，若需清除未读数请参考[标记会话已读](/sdk/harmony/conversation/managing-conversations/mark-conversation-read)。
