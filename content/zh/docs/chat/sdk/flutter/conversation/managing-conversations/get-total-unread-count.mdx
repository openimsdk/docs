`getTotalUnreadMsgCount()` 返回当前账号所有会话在调用时的总未读数，不要把当前已加载分页中的 `unreadCount` 简单相加。

```dart
final value = await OpenIM.iMManager.conversationManager
    .getTotalUnreadMsgCount();
final totalUnread = int.tryParse(value.toString()) ?? 0;
updateApplicationBadge(totalUnread);
```

查询本身不会触发回调。后续总数变化由应用唯一的 `OnConversationListener.onTotalUnreadMessageCountChanged` 更新；组合 listener 与设置入口见[事件概览](/sdk/flutter/events/overview-events)。

需要把该数值同步给 SDK 的推送角标状态时，参见[设置应用角标数量](/sdk/flutter/message/set-app-badge)。
