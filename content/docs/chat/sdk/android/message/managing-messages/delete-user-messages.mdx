```java
messageManager.deleteUserAllMessagesInConv(
    conversationID,
    targetUserID,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // The deletion request has completed
        }

        @Override
        public void onError(int code, String error) {
            // Handle the failure
        }
    }
);
```

This API is available only for group chats and deletes every message sent by the specified user in the target group conversation. It is a high-impact group moderation action and should not appear in an ordinary single-message menu. OpenIMServer validates the operator's permission. A successful callback does not mean that the event has already arrived.

This page owns `OnAdvanceMsgListener.onDeleteUserAllMsgsInConv`. When the event arrives, use its `conversationID` and `userID` to remove messages from that sender in the cached conversation, or reload conversation history to reconcile the state.

```java
@Override
public void onDeleteUserAllMsgsInConv(DeleteUserAllMsgsListenerMsg event) {
    removeMessagesBySender(event.getConversationID(), event.getUserID());
}
```

Callback completion, event arrival, and a new history query are three independent stages.
