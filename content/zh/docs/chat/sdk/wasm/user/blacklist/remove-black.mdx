---
title: '将用户移出黑名单'
description: '将指定用户移出当前账号黑名单。'
sourcePath: '/sdk/wasm/user/blacklist/remove-black'
---

解除黑名单限制时传入需要移出的用户 ID。该操作只改变当前账号维护的黑名单关系，不应在请求成功前直接认定双方关系已经恢复到其他业务状态。

```ts
await openimsdk.removeBlack(toUserID);
```

Promise 成功表示服务端已完成本次移出请求，但不代表黑名单事件已经到达。收到 `OnBlackDeleted` 后，使用事件数据中的 `userID` 从黑名单列表和相关缓存中移除记录；完整监听方式见[查询黑名单](/sdk/wasm/user/blacklist/get-black-list)。需要立即确认时，重新查询黑名单并以最新结果为准。
