Check whether the current logged-in user is already a member of the specified group.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID to check. |

## Code example

```dart
final joined = await OpenIM.iMManager.groupManager.isJoinedGroup(
  groupID: groupID,
);
```

## Return value

Returns a `Future` resolving to a `bool`. Returns `true` if the current user has joined the group, or `false` otherwise.

## State changes after the call

This query performs a lightweight membership check and does not trigger event callbacks. For group joining workflows and event handling, see [Join a group](/sdk/flutter/group/join-group) and [Group overview](/sdk/flutter/group/overview-group).
