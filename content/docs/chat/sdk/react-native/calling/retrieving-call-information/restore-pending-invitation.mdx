When the application cold starts or resumes from the background in response to a VoIP notification, retrieve any pending call invitations that remain unhandled:

```ts
const { invitation, offlinePushInfo } =
  await OpenIMSDK.getSignalingInvitationInfoStartApp();
```

## Return value

Resolves to an object containing pending invitation data:

| Field | Type | Description |
| --- | --- | --- |
| `invitation` | `RtcInvite` or `null` | The pending call invitation, or `null` if no active invitation exists. |
| `offlinePushInfo` | `OfflinePush` | The offline push configuration bundled with the invitation. |

When `invitation` is not `null`, use the invitation data to render the incoming call screen and identify the room via `roomID`. Subsequent cancellation, timeout, acceptance, or hang-up updates are delivered through events documented in [Handle call events](/sdk/react-native/calling/managing-calls/handle-call-events).
