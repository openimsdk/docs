使用 `createQuoteMessage()` 创建回复消息，并传入完整的原消息对象。

```ts
const message = await OpenIMSDK.createQuoteMessage({
  text: '同意这个方案。',
  message: originalMessage,
});
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `text` | `string` | 是 | 回复的文本内容。 |
| `message` | `MessageItem` | 是 | 被回复的原消息。 |

调用后返回新的待发送 `MessageItem`。接收端展示回复消息时，应注意处理原消息已删除或无法展示的情况。
