---

通话建立后，参与者挂断通话：

```dart
await OpenIM.iMManager.signalingManager
    .signalingHungUp(info: activeInfo);
```

Future 成功只表示挂断信令请求完成。应用还需停止本地采集、断开媒体房间并释放摄像头和麦克风。清理流程应按 `roomID` 幂等执行。
