从联系人、用户资料或群资料进入聊天页时，可直接按真实目标查询会话。单聊将对方 `userID` 作为 `sourceID`，群聊将 `groupID` 作为 `sourceID`。请使用 SDK 提供的查询方法，避免自行拼接 `conversationID` 或构造会话对象。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `sourceID` | `string` | 是 | 单聊为对方用户 ID，群聊为群组 ID。 |
| `sessionType` | `OpenIMSessionType` | 是 | 单聊使用 `OpenIMSessionTypeSingle`，群聊使用 `OpenIMSessionTypeWriteGroup`。 |

```uts
import {
  OpenIMSessionTypeSingle,
  getOneConversation,
} from '@/uni_modules/unix-openim-sdk'

const conversation = await getOneConversation({
  sourceID: targetUserID,
  sessionType: OpenIMSessionTypeSingle,
})

if (conversation != null) {
  openChatPage(conversation)
}
```

Promise 成功后返回 `OpenIMConversationItem | null`，字段含义见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。该查询只返回调用时的数据，不会触发会话事件；客户端应按 `conversationID` 合并后续状态变化，完整事件监听见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。
