语音识别属于商业版能力。显示转写入口或开始录音前，先读取当前服务支持的音频格式和限制：

```uts
import { getSpeechToTextCapabilities } from '@/uni_modules/unix-openim-sdk'

const capabilities = await getSpeechToTextCapabilities()

if (capabilities == null) {
  disableSpeechToText()
}
```

Promise 成功后返回 `OpenIMSpeechToTextCapabilitiesResult | null`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `format` | `string[] \| null` | 当前服务支持的音频格式。 |
| `sampleRateHz` | `number[] \| null` | 当前服务支持的采样率列表，单位为赫兹。 |
| `maxRecordTimeMs` | `number \| null` | 最大录音时长，单位为毫秒。 |
| `maxFileSize` | `number \| null` | 最大音频文件大小，单位为字节。 |
| `provider` | `string \| null` | 当前语音识别服务提供方。 |

字段在公开类型中均允许缺失。只对服务明确返回的限制做前置校验；返回 `null`、请求失败或关键能力缺失时，应隐藏或停用转写入口，不要自行猜测支持范围。该查询不会录音、识别音频或触发消息事件。
