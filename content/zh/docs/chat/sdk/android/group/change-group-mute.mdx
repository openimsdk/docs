---
title: '设置群组全员禁言'
description: '使用 Android SDK 开启或关闭群组全员禁言。'
sourcePath: '/sdk/android/group/change-group-mute'
---

使用 `changeGroupMute()` 切换全员禁言。`true` 开启，`false` 关闭；成员级禁言见[禁言或解除禁言群成员](/sdk/android/group/managing-group-members/change-group-member-mute)。

```java
OpenIMClient.getInstance().groupManager.changeGroupMute(new OnBase<String>() {
    @Override public void onSuccess(String data) { /* 请求已完成。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
}, groupID, true);
```

成功回调表示设置请求已完成，不表示所有客户端界面已经更新。`onGroupInfoChanged` 返回更新后的 `GroupInfo`；按 `groupID` 更新群资料。完整 listener 注册见[群组概览](/sdk/android/group/overview-group)。
