```objc
OIMMessageInfo *message =
    [OIMMessageInfo createFileMessageFromFullPath:fileURL.path
                                          fileName:fileURL.lastPathComponent];
```

The path must be an absolute path readable by the current application. The file name is displayed to recipients. Send the returned object through the regular sending API so the SDK can upload and send it.
