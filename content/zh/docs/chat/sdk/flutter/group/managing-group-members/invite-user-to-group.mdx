群成员或管理员可以邀请指定用户列表加入群组。客户端可在界面层按群权限控制入口，最终由服务端完成权限校验与入群逻辑处理：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `reason` | `String` | 是 | 邀请说明或申请备注。 |
| `userIDList` | `List<String>` | 是 | 被邀请加入群组的用户 ID 列表。 |

```dart
await OpenIM.iMManager.groupManager.inviteUserToGroup(
  groupID: groupID,
  reason: '加入项目讨论',
  userIDList: selectedUserIDs,
);
```

## 返回结果

Future 成功表示服务端已受理邀请请求。根据群组的验证模式配置，用户可能直接入群或生成待确认记录。

当用户直接加入成功时，群内客户端将收到成员新增事件通知；客户端应使用复合标识 `groupID:userID` 合并新成员到本地状态。完整的事件监听与增量合并逻辑请参考[群成员查询概览](/sdk/flutter/group/retrieving-group-members/overview-retrieving-group-members)。
