调用创建文本消息方法可构建一条纯文本类型的待发送消息对象。该方法为同步工厂方法，仅在内存中生成 `OIMMessageInfo` 实例，不会直接存入本地数据库或触发发送。

```objc
OIMMessageInfo *message = [OIMMessageInfo createTextMessage:text];
```

## 参数说明

- `text`：待发送的文本正文内容（`NSString *`）。调用前建议在业务层处理空白字符校验与最大字数限制。

## 返回结果

- 返回初始化完成的 `OIMMessageInfo` 对象，其内容类型为纯文本。
- 创建消息对象后，需通过[发送消息](/sdk/ios/message/sending-messages/send-message)接口将其投递至单聊或群聊会话中。
