---
title: '设置阅后即焚时长'
description: '设置指定会话在阅后即焚模式下的消息保留时长。'
sourcePath: '/sdk/harmony/conversation/managing-conversations/set-burn-duration'
---

`burnDuration` 单位为秒，只描述阅后即焚的保留时长。

```ts
import sdk, { SetConversationReq } from '@openimsdk/imsdk';

const request: SetConversationReq = {
  conversationID: conversationID,
  burnDuration: 30,
};
await sdk.setConversation(request);
```

启用阅后即焚还需通过[开启或关闭阅后即焚](/sdk/harmony/conversation/managing-conversations/set-private-chat)设置 `isPrivateChat`，注意不要与服务端自动删除的[定期删除服务端消息](/sdk/harmony/conversation/managing-conversations/set-message-destruct)混淆。接口调用成功后，SDK 会触发会话变更事件；客户端收到通知后根据 `conversationID` 更新对应会话的 `burnDuration` 属性，完整监听配置请参考[获取会话列表](/sdk/harmony/conversation/retrieving-conversations/retrieve-conversation-list)。
