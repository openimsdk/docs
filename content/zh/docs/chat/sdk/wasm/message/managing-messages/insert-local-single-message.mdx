## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `message` | `MessageItem` | 是 | 要写入本地数据库的完整消息对象。 |
| `recvID` | `string` | 是 | 单聊接收方的用户 ID。 |
| `sendID` | `string` | 是 | 消息发送方的用户 ID。 |

```ts
const { data: message } = await openimsdk.createTextMessage('本地提示');
await openimsdk.insertSingleMessageToLocalStorage({
  message,
  recvID: targetUserID,
  sendID: currentUserID,
});
```

接口调用成功仅表示该消息已存入当前设备的本地数据库，并不会通过网络发送给对方，亦不会触发 `OnRecvNewMessages` 事件。该方法常用于插入本地专属的系统通知或安全提示。示例中的 `createTextMessage()` 仅用于构建待插入的消息载体，详情请参考[创建文本消息](/sdk/wasm/message/creating-messages/create-text-message)。
