Verify whether the authenticated user is already a member of a specified group. This is typically used to determine UI routing before entering a group from search results, shared links, or QR code scans.

## Code example

```java
String groupID = "group_123";

OpenIMClient.getInstance().groupManager.isJoinGroup(
    groupID,
    new OnBase<Boolean>() {
        @Override
        public void onSuccess(Boolean joined) {
            // joined is true if the authenticated user is a member of the group
        }

        @Override
        public void onError(int code, String error) {
            // Handle check failure
        }
    }
);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID to verify. |
| `base` | `OnBase<Boolean>` | Yes | Callback delivering the asynchronous operation result. |

## Return value

The successful callback returns a `Boolean`:

- `true`: The current user is an active group member; navigate directly to the group chat screen.
- `false`: The current user is not a group member; prompt the user to [Apply to join a group](/sdk/android/group/join-group).
