---
title: '接受入群申请'
description: '使用 acceptGroupApplication 同意指定用户的入群申请。'
sourcePath: '/sdk/android/group/group-applications/accept-group-application'
---

调用时同时传入申请的 `groupID`、申请人 `userID` 和处理说明。服务端负责校验当前用户是否有审批权限。

```java
OpenIMClient.getInstance().groupManager.acceptGroupApplication(new OnBase<String>() {
    @Override public void onSuccess(String data) { markApplicationHandled(groupID, applicantUserID); }
    @Override public void onError(int code, String error) { showHandleError(error); }
}, groupID, applicantUserID, "欢迎加入");
```

同意后通过群申请事件与 `onGroupMemberAdded` 更新申请列表和成员列表。
