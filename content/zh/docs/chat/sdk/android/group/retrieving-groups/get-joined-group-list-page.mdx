title: '分页获取已加入群组'
description: '使用 getJoinedGroupListPage 分页读取当前账号已加入的群组。'
sourcePath: '/sdk/android/group/retrieving-groups/get-joined-group-list-page'
---

`offset` 从 `0` 开始，后续页按上一页返回的条目数推进；返回为空时停止加载。

```java
OpenIMClient.getInstance().groupManager.getJoinedGroupListPage(new OnBase<List<GroupInfo>>() {
    @Override public void onSuccess(List<GroupInfo> groups) { /* groups 是当前页群组。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
}, offset, 20);
```

加入或退出群组时，通过 `onJoinedGroupAdded` 和 `onJoinedGroupDeleted` 接收通知。
