title: '查询会话所属分组'
description: '查询指定会话当前关联的全部会话分组。'

---

会话分组属于商业版能力。同一个会话可以关联多个分组。UTS 插件使用 `getConversationGroupByConversationID()` 返回完整分组对象，而不是只返回分组 ID。

```uts
import { getConversationGroupByConversationID } from '@/uni_modules/unix-openim-sdk'

const result = await getConversationGroupByConversationID({
  conversationID,
})
const groups = result?.conversationGroups ?? []
```

Promise 成功后返回 `OpenIMGetConversationGroupByConversationIDResult | null`，分组数组位于 `conversationGroups`。`conversationID` 是 OpenIM 会话 ID，不是聊天群组 ID。需要分组 ID 时，从每个 `conversationGroupID` 非空的结果中读取。

该查询不会触发事件；关联发生变化时，按[会话分组概览](/sdk/uniapp/conversation/managing-conversation-groups/overview-conversation-groups)中的方式重新查询，并用最新结果更新界面。
