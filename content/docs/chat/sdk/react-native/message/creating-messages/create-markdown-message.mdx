Construct a message containing formatted Markdown content:

```ts
const message = await OpenIMSDK.createMarkdownMessage(
  '## Release Completed\n\n- Android\n- iOS',
);
```

## Parameters

Supply the full Markdown text string as the sole argument.

## Return value

A resolved Promise returns the initialized `MessageItem` object with Markdown content stored in `markdownTextElem`.

This method builds the message structure strictly in client memory; it does not dispatch messages to the server or trigger lifecycle events. After initialization, invoke [Send message](/sdk/react-native/message/sending-messages/send-message) to deliver it to a conversation. When rendering untrusted Markdown content in the UI, sanitize tags using secure renderer components.
