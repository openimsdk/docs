收到通话邀请后，如果不方便接听或需要拒绝，可以调用接口拒绝本次邀请。

```ts
await OpenIMSDK.signalingReject({
  opUserID: currentUserID,
  invitation,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `opUserID` | `string` | 是 | 当前拒绝邀请的操作用户 ID。 |
| `invitation` | `RtcInvite` | 是 | 收到通话邀请时的完整通话邀请对象。 |

## 返回结果

调用完成后，拒绝邀请请求已处理完成。

发起方及其他端会通过 `OnInviteeRejected` 事件收到拒绝通知；客户端应使用 `roomID` 标识通话房间，并结合参与者 `userID` 维护对应成员的状态。完整事件监听说明见[处理通话事件](/sdk/react-native/calling/managing-calls/handle-call-events)。
