用户在群聊中查看或处理完 @ 提醒消息后，可将会话的 `groupAtType` 重置为普通状态：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 目标群聊会话 ID。 |
| `req` | `ConversationReq` | 是 | 会话修改请求对象，在此将 `groupAtType` 设置为 `GroupAtType.atNormal`。 |

```dart
await OpenIM.iMManager.conversationManager.setConversation(
  conversationID,
  ConversationReq(groupAtType: GroupAtType.atNormal),
);
```

## 返回结果

Future 成功表示重置请求已完成。群聊 @ 状态仅用于未读强提醒，与消息本身的已读状态相互独立。

SDK 会通过会话变更事件通知该会话更新。客户端以 `conversationID` 为合并标识更新对应会话的 `groupAtType` 状态，完整事件监听请参考[获取会话列表](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list)。
