根据已有的一条消息创建转发消息。

```ts
const message = await OpenIMSDK.createForwardMessage(sourceMessage);
```

## 参数说明

`sourceMessage` 为被转发的原消息完整 `MessageItem` 对象。

## 返回结果

调用完成后返回新建的待发送 `MessageItem` 消息对象。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送消息](/sdk/react-native/message/sending-messages/send-message)将转发消息投递到目标单聊或群聊会话中。若需打包多条消息进行合并转发，请参考[创建合并消息](/sdk/react-native/message/creating-messages/create-merger-message)。
