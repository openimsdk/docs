```objc
[[OIMManager manager] setConversationMsgDestructTime:conversationID
                                     msgDestructTime:destructTime
                                         onSuccess:nil
                                         onFailure:nil];
```

`msgDestructTime` is the periodic deletion interval for server-side messages. Confirm its precise timing semantics against your server policy. Enable or disable the feature through the separate switch method. After success, read the latest snapshot from `OIMConversationInfo.msgDestructTime`.
