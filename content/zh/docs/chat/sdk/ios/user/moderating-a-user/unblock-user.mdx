```objc
[[OIMManager manager] removeFromBlackList:targetUserID
    onSuccess:nil
    onFailure:nil];
```

成功 callback 不等于事件已到达。`onBlackDeleted:` 是本页归属事件，按载荷的 `userID` 从黑名单移除；需要完整校准时重新查询黑名单列表。
