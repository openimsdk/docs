---
title: '删除会话及消息'
description: '删除指定会话记录及当前账号保存的全部会话消息。'
sourcePath: '/sdk/uniapp/conversation/managing-conversations/delete-conversation-with-messages'
---

同时删除指定会话记录及当前账号保存的该会话全部消息。操作完成后，SDK 无法从本地数据中恢复这些消息。

```uts
import { deleteConversationAndDeleteAllMsg } from '@/uni_modules/unix-openim-sdk'

await deleteConversationAndDeleteAllMsg(conversationID)
```

Promise 成功后，可从本地清理对应会话列表项和聊天记录。客户端以 `conversationID` 为标识进行本地状态移除；后续会话事件到达或需要校准时，可参考[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)重新拉取列表。

该操作不会删除好友关系、退出群组或影响其他用户的数据。只需要删除会话入口而保留消息时，使用[删除会话](/sdk/uniapp/conversation/managing-conversations/delete-conversation)。
