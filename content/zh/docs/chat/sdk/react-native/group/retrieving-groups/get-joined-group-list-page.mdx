分页拉取当前登录账号已加入的群组列表。

```ts
const groups = await OpenIMSDK.getJoinedGroupListPage({
  offset: 0,
  count: 50,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `offset` | `number` | 是 | 分页偏移量，第一页传 `0`。 |
| `count` | `number` | 是 | 本次读取的群组数量。 |

继续读取下一页时，将 `offset` 设置为已读取的群组数量。

## 返回结果

调用完成后返回当前页的 `GroupItem[]`。返回数量少于 `count` 时表示已拉取到最后一页；客户端在合并已加入群组列表时，应以 `groupID` 作为唯一合并标识。各字段详细说明见[群组概览](/sdk/react-native/group/overview-group)。
