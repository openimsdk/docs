获取当前登录账号的用户资料。

```ts
const currentUser = await OpenIMSDK.getSelfUserInfo();
```

## 返回结果

调用完成后返回当前账号的 `SelfUserInfo` 对象：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `userID` | `string` | 当前登录用户的 OpenIM 用户 ID，用于标识当前账号。 |
| `nickname` | `string` | 账号级昵称。 |
| `faceURL` | `string` | 账号级头像地址。 |
| `createTime` | `number` | 用户记录创建时间戳。 |
| `globalRecvMsgOpt` | `MessageReceiveOptType` | 当前账号的全局免打扰及消息接收选项。 |
| `ex` | `string` | 由业务约定的账号级自定义扩展字符串。 |

完成初始化并成功登录后调用该方法，可用于展示当前账号的头像、昵称和全局消息接收设置。切换账号时，应清理已保存的当前用户信息缓存。
