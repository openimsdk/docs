description: '设置申请或邀请用户加入群组时的审核策略。'

`GroupNeedVerification` 定义三种入群策略。

| 枚举值                                | 含义                                                 |
| ------------------------------------- | ---------------------------------------------------- |
| `ApplyNeedVerificationInviteDirectly` | 用户申请需要审核；成员邀请可直接入群。               |
| `AllNeedVerification`                 | 申请和普通成员邀请都需要审核；群主或管理员邀请除外。 |
| `DirectAccess`                        | 申请或邀请均可直接入群。                             |

```ts
import sdk, { GroupNeedVerification, SetGroupInfoReq } from '@openimsdk/imsdk';

const request: SetGroupInfoReq = {
  groupID: groupID,
  needVerification: GroupNeedVerification.AllNeedVerification,
};
await sdk.setGroupInfo(request);
```

客户端应根据策略展示申请提示，但最终是否允许加入仍由 OpenIMServer 判断。Promise 成功后，通过群资料事件或重新查询更新界面。
