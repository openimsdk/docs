---
title: '退出群组'
description: '退出当前用户已加入的群组。'
sourcePath: '/sdk/uniapp/group/quit-group'
---

普通成员和管理员可主动退出群组。群主不能直接退出群组，退出前应先通过[转让群主](/sdk/uniapp/group/managing-group-members/transfer-group-owner)将群主身份转让给其他成员。

```uts
import { quitGroup } from '@/uni_modules/unix-openim-sdk'

await quitGroup(groupID)
```

`groupID` 是要退出的群组 ID。Promise 成功表示退出群组请求已完成，客户端可按 `groupID` 从本地已加入群组列表中移除该群，随后收到群组退出事件时做最终确认。完整群组事件监听见[群组概览](/sdk/uniapp/group/overview-group)。

退出群组不会等同于删除或隐藏本地会话。历史会话可能继续保留，因此不能根据会话是否存在判断当前用户是否仍属于该群。
