title: '设置入群验证方式'
description: '设置申请或邀请用户加入群组时的审核策略。'

---

`needVerification` 的类型为 `OpenIMGroupVerificationType`。

| 常量 | 数值 | 含义 |
| --- | --- | --- |
| `OpenIMGroupVerificationTypeApplyNeedInviteNot` | `0` | 用户申请需要审核；群成员邀请可以直接入群。 |
| `OpenIMGroupVerificationTypeAllNeed` | `1` | 申请和普通成员邀请都需要审核；群主或管理员邀请除外。 |
| `OpenIMGroupVerificationTypeAllNot` | `2` | 申请或邀请均可直接入群。 |

```uts
import {
  OpenIMGroupVerificationTypeAllNeed,
  setGroupInfo,
} from '@/uni_modules/unix-openim-sdk'

await setGroupInfo({
  groupID,
  needVerification: OpenIMGroupVerificationTypeAllNeed,
})
```

客户端应根据策略展示申请提示，但最终是否允许加入仍由 OpenIMServer 判断。Promise 成功后，收到 `onGroupInfoChanged()` 时再更新对应群资料；完整监听见[群组概览](/sdk/uniapp/group/overview-group)。
