---
title: '拒绝通话'
description: '拒绝当前尚未接听的通话邀请。'
sourcePath: '/sdk/uniapp/calling/managing-calls/reject-call'
---

用户拒绝来电时，将完整的 `OpenIMSignalingInvitationInfo` 传入并执行拒绝操作：

```uts
import { signalingReject } from '@/uni_modules/unix-openim-sdk'

await signalingReject({ invitation })
```

不要只用 `roomID` 或邀请人 ID 构造简化对象。Promise 成功表示本次拒绝请求已成功返回，客户端应按 `roomID` 清理本地来电界面与待处理状态，并释放相关媒体资源。Promise 成功不代表发起方已经收到拒绝通知；发起方及其他端收到拒绝事件后的界面同步见[处理通话事件](/sdk/uniapp/calling/managing-calls/handle-call-events)。
