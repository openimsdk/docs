---
title: '查询指定好友资料'
description: '按用户 ID 批量查询指定好友的关系资料。'
sourcePath: '/sdk/harmony/user/friends/get-specified-friends-info'
---

该方法只返回已经建立好友关系的用户。陌生人的公开资料应使用用户资料 API。

```ts
import sdk, { GetSpecifiedFriendsReq, GetSpecifiedFriendsResp } from '@openimsdk/imsdk';

const request: GetSpecifiedFriendsReq = {
  friendUserIDs: ['user_a', 'user_b'],
  filterBlack: true,
};
const response: GetSpecifiedFriendsResp = await sdk.getSpecifiedFriends(request);
```

结果不保证按输入顺序返回，也可能少于请求数量。使用 `friendUserID` 建立映射；`filterBlack` 为 `true` 时过滤黑名单用户。
