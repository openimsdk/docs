更新指定成员在特定群组内的头像。

```ts
await OpenIMSDK.setGroupMemberInfo({
  groupID: 'group-001',
  userID: 'user-002',
  faceURL: 'https://example.com/avatar.png',
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `groupID` | `string` | 是 | 目标群组 ID。 |
| `userID` | `string` | 是 | 要更新头像的成员用户 ID。 |
| `faceURL` | `string` | 是 | 成员在该群组中的头像地址。 |

群内头像只作用于指定群组。需要修改账号头像时，使用[更新当前用户资料](/sdk/react-native/user/profile/set-self-info)。

## 返回结果

调用完成后，群内头像更新已生效。

成员资料变化会触发 `OnGroupMemberInfoChanged` 事件，事件载荷包含该成员的最新资料。客户端应以 `groupID:userID` 复合标识定位并更新对应成员的头像记录。完整事件监听说明见[分页查询群成员](/sdk/react-native/group/retrieving-group-members/get-group-member-list)。
