删除当前账号的指定会话记录，但保留该会话保存在本地的消息历史。

```uts
import { deleteConversation } from '@/uni_modules/unix-openim-sdk'

await deleteConversation(conversationID)
```

Promise 成功表示删除会话记录请求完成。客户端可按 `conversationID` 从当前会话列表中移除对应项。该操作不影响好友关系，也不会退出或解散群组；若该聊天目标产生新消息，系统将重新生成会话记录。完整会话列表与同步机制见[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)。
