Call `pinConversation()` to set whether a conversation is pinned.

```ts
await OpenIMSDK.pinConversation({
  conversationID,
  isPinned: true,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `string` | Yes | Conversation ID to update. |
| `isPinned` | `boolean` | Yes | Set `true` to pin or `false` to unpin. |

## Return result

After the call completes, the conversation's `isPinned` state is updated. Changes in the conversation list are delivered through `OnConversationChanged`; see [Retrieve the conversation list](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list).
