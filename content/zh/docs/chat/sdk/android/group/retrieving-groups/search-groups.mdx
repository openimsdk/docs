---

`searchGroups()` 接收关键词列表，并分别指定是否搜索群 ID、群名称。两个开关都关闭时没有有效搜索范围。

```java
OpenIMClient.getInstance().groupManager.searchGroups(new OnBase<List<GroupInfo>>() {
    @Override public void onSuccess(List<GroupInfo> groups) { /* groups 是查询结果。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
}, Collections.singletonList(keyword), true, true);
```

用户不一定是 `searchGroups()` 搜索到的群组的群成员，是否为群成员通过 [`isJoinGroup()`](/sdk/android/group/retrieving-groups/is-join-group) 确定。
