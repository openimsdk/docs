---
title: '发送好友申请'
description: '向指定用户发送好友申请。'
sourcePath: '/sdk/wasm/user/friend-applications/add-friend'
---

发送好友申请时，`toUserID` 是接收申请的用户 ID，`reqMsg` 是随申请提交的验证信息。提交前应避免向当前用户自己或已经建立好友关系的账号重复发送申请。

```ts
await openimsdk.addFriend({ toUserID, reqMsg });
```

`reqMsg` 没有内容时传空字符串。Promise 成功只表示服务端已接收申请，不表示对方已经同意，也不能据此把对方加入好友列表。申请状态通过好友申请事件更新；对方同意后，再根据 `OnFriendAdded` 更新好友关系。完整处理方式见[获取发出的好友申请](/sdk/wasm/user/friend-applications/get-friend-application-list-as-applicant)。
