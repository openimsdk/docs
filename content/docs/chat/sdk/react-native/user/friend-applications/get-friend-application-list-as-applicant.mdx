Paginate and query outgoing friend requests sent by the authenticated user:

```ts
const applications = await OpenIMSDK.getFriendApplicationListAsApplicant({
  offset: 0,
  count: 20,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `offset` | `number` | Yes | Pagination offset starting from `0`. |
| `count` | `number` | Yes | Maximum number of application records to fetch. |

## Return value

Resolves to an array of `FriendApplicationItem[]` representing outgoing friend applications for the current page. For detailed property descriptions and event listeners, see [Get received friend applications](/sdk/react-native/user/friend-applications/get-friend-application-list-as-recipient).
