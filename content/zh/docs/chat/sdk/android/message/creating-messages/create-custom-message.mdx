---
title: '创建自定义消息'
description: '使用 createCustomMessage 承载业务定义的 JSON 消息。'
sourcePath: '/sdk/android/message/creating-messages/create-custom-message'
---

`data`、`extension` 和 `description` 由业务定义，接收端应按自己的协议解析。

```java
Message message = OpenIMClient.getInstance().messageManager.createCustomMessage(
    dataJson, extensionJson, description);
```
