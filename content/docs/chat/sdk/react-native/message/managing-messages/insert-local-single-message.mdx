Use `insertSingleMessageToLocalStorage()` to write one message to the current device's direct-chat history.

```ts
await OpenIMSDK.insertSingleMessageToLocalStorage({
  message,
  recvID,
  sendID,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `message` | `MessageItem` | Yes | Complete message object to write. |
| `recvID` | `string` | Yes | Direct-chat recipient user ID. |
| `sendID` | `string` | Yes | Message sender user ID. |

After the call completes, the message is written to the current device's direct-chat history. To send it to the other participant, use [Send a message](/sdk/react-native/message/sending-messages/send-message).
