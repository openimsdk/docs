Once a call is connected, any participant can terminate the call:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `info` | `SignalingInfo` | Yes | Active signaling object whose `roomID` matches the ongoing media room. |

## Code example

```dart
await OpenIM.iMManager.signalingManager
    .signalingHungUp(info: activeInfo);
```

## Return value

A successful `Future` indicates that the hang-up signaling request has been received by the server.

## State changes after the call

The client should terminate the local call session associated with `roomID`, stop local audio/video capture, disconnect from the media server, and release camera and microphone hardware resources. Other participants exit the call upon receiving the hang-up event (see [Handle call events](/sdk/flutter/calling/managing-calls/handle-call-events) for complete event handling). Implement local teardown logic idempotently using `roomID`.
