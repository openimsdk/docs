---
title: '获取当前用户资料'
description: '查询当前登录用户的账号资料和账号级设置。'
sourcePath: '/sdk/harmony/user/profile/get-self-user-info'
---

`getSelfUserInfo()` 不接收业务参数，返回当前登录账号的 `IMUser`。

```ts
import sdk, { GetSelfUserInfoResp } from '@openimsdk/imsdk';

const response: GetSelfUserInfoResp = await sdk.getSelfUserInfo();
setCurrentUser(response.user);
```

| 字段                  | 说明                                   |
| --------------------- | -------------------------------------- |
| `userID`              | 当前登录用户 ID。                      |
| `nickname`、`faceURL` | 账号级昵称和头像。                     |
| `ex`                  | 业务约定的账号扩展字符串。             |
| `globalRecvMsgOpt`    | 全局消息接收方式。                     |
| `addFriendPermission` | 其他用户添加当前账号时的处理策略。     |
| `createTime`          | 用户记录创建时间，Unix 毫秒时间戳。    |
| `attached`            | SDK 附加信息，只按明确的业务约定解析。 |

查询只返回调用时的数据，不触发资料事件。资料变化事件的完整处理见[更新当前用户资料](/sdk/harmony/user/profile/set-self-info)。切换账号时应先清理上一账号的缓存。
