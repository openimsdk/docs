处理服务端下发的系统级或工作流层面的自定义业务信令通知：

```dart
OpenIM.iMManager.setCustomBusinessListener(
  OnCustomBusinessListener(
    onRecvCustomBusinessMessage: (String businessData) {
      handleCustomBusinessMessage(businessData);
    },
  ),
);
```

`onRecvCustomBusinessMessage` 回调携带的是服务端下发的原始业务字符串，并非标准的聊天 `Message` 对象。应用在接收后应校验数据格式、协议版本与业务字段，并按业务流水号或事件唯一 ID 进行幂等去重与分发。

若需要在普通单聊或群聊会话中发送图文混排的业务卡片，请参考[创建自定义消息](/sdk/flutter/message/creating-messages/create-custom-message)。全局 listener 的集中设置与解绑请参考[事件概览](/sdk/flutter/events/overview-events)。
