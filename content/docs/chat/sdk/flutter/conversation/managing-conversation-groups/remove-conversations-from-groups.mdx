Remove specified conversations from one or more conversation groups. This operation dissolves category links; it does not delete conversations or clear message history.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationGroupIDs` | `List<String>` | Yes | List of target conversation group IDs. |
| `conversationIDs` | `List<String>` | Yes | List of conversation IDs to remove from the groups. |

## Code example

```dart
await OpenIM.iMManager.conversationGroupManager.removeConversationsFromGroups(
  conversationGroupIDs: [conversationGroupID],
  conversationIDs: [conversationID],
);
```

## Return value

A successful `Future` indicates that the disassociation request was processed by the server. The client updates the local conversation list within each group using `conversationGroupID` and `conversationID` as composite keys.

## State changes after the call

Multi-device synchronization and arriving changes trigger `onConversationGroupMemberDeleted` notifications. For complete listener integration, see [Conversation groups overview](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups).
