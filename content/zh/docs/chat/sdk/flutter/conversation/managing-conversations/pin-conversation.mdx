将指定会话固定显示在会话列表顶部，或取消置顶。该置顶状态仅对当前登录用户生效：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 目标会话 ID。 |
| `req` | `ConversationReq` | 是 | 会话修改请求对象，`isPinned` 设置为 `true` 表示置顶，`false` 表示取消置顶。 |

```dart
await OpenIM.iMManager.conversationManager.setConversation(
  conversationID,
  ConversationReq(isPinned: true),
);
```

## 返回结果

Future 成功表示置顶状态已保存。客户端以 `conversationID` 为合并标识更新本地会话的 `isPinned` 状态并重新排序列表。

多端同步或事件到达时通过会话变更事件通知，完整事件监听请参考[获取会话列表](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list)。
