---
title: '发送好友申请'
description: '向指定用户发送好友申请。'
sourcePath: '/sdk/harmony/user/friend-applications/add-friend'
---

发送前避免向自己或已有好友关系的账号重复申请。`reqMsg` 是验证信息，`ex` 是双方业务已约定的扩展字符串。

```ts
import sdk, { AddFriendReq } from '@openimsdk/imsdk';

const request: AddFriendReq = {
  userID: targetUserID,
  reqMsg: verificationMessage,
  ex: '',
};
await sdk.addFriend(request);
```

Promise 成功表示服务端接受申请，不表示对方已经同意，也不能据此加入好友列表。申请状态和好友关系分别通过对应事件更新。
