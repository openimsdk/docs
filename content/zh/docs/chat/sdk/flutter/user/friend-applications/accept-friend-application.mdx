description: '使用 Flutter SDK 同意好友申请。'

---

```dart
await OpenIM.iMManager.friendshipManager.acceptFriendApplication(
  userID: applicantUserID,
  handleMsg: '已通过',
);
```

`userID` 是申请方，`handleMsg` 是可选处理附言。Future 成功表示处理请求完成；申请状态与新好友关系可能通过不同 listener 到达，应分别合并。
