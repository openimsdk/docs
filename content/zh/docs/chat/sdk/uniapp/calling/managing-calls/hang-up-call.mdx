---
title: '挂断通话'
description: '结束已经建立的音频或视频通话。'

---

通话建立后，参与者可主动挂断并结束通话：

```uts
import { signalingHungUp } from '@/uni_modules/unix-openim-sdk'

await signalingHungUp({ invitation })
```

`invitation` 是本次通话的完整 `OpenIMSignalingInvitationInfo`，其中的 `roomID` 必须与当前媒体房间一致。

Promise 成功只表示挂断信令请求完成。客户端仍需停止本地采集、离开媒体房间并释放摄像头和麦克风。各端应统一以 `roomID` 作为通话标识执行状态清理，避免重复释放资源。通话事件及远端挂断通知见[处理通话事件](/sdk/uniapp/calling/managing-calls/handle-call-events)。
