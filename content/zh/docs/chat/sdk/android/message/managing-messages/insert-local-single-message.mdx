---
title: '插入本地单聊消息'
description: '使用 insertSingleMessageToLocalStorage 插入仅当前设备可见的单聊消息。'
sourcePath: '/sdk/android/message/managing-messages/insert-local-single-message'
---

该方法不向服务器发送消息。`receiver` 是接收者用户 ID，`sender` 是发送者用户 ID。

```java
messageManager.insertSingleMessageToLocalStorage(callback, message, receiverUserID, senderUserID);
```
