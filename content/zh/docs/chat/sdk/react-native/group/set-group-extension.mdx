调用 `setGroupInfo()` 设置群组的 `ex` 扩展字段。

```ts
await OpenIMSDK.setGroupInfo({
  groupID,
  ex: JSON.stringify({
    projectID: 'project-42',
  }),
});
```

`groupID` 为目标群组 ID，`ex` 是字符串类型，可按业务需要传递 JSON 字符串或其他格式的扩展信息。

## 返回结果

调用完成后，群组扩展字段已更新。群资料变化会通过 `OnGroupInfoChanged` 返回，事件监听方式见[群组概览](/sdk/react-native/group/overview-group)。
