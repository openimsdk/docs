Batch retrieve friendship records for a list of target user IDs:

```ts
const friends = await OpenIMSDK.getSpecifiedFriendsInfo({
  userIDList: ['user_a', 'user_b'],
  filterBlack: true,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `userIDList` | `string[]` | Yes | List of friend user IDs to retrieve. |
| `filterBlack` | `boolean` | No | Whether to filter out blacklisted users; defaults to `false`. |

## Return value

Resolves to an array of matching `FriendUserItem[]`. The return order is not guaranteed to match the input list. For field definitions, see [Get friend list by page](/sdk/react-native/user/friends/get-friend-list-page).

To fetch public profile cards for users who are not friends, use [Get user profiles](/sdk/react-native/user/profile/get-users-info).
