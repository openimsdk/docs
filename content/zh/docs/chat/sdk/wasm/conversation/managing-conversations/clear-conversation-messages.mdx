description: '使用 WASM SDK 保留会话入口并清空其消息。'

当业务场景为“清空聊天记录”时，可调用 `clearConversationAndDeleteAllMsg()`。该操作会保留会话列表入口，仅清空当前登录账号在该会话下的全部历史消息，并重置最新消息摘要与未读数：

```ts
await openimsdk.clearConversationAndDeleteAllMsg(conversationID);
```

接口调用成功后，界面即可清空当前会话的消息展示列表。随后 SDK 会触发 `SdkEvent.OnConversationChanged` 事件以同步更新最后一条消息、消息摘要及未读数；如需手动校准，也可重新查询该会话。会话事件的详细监听方式请参考[获取会话列表](/sdk/wasm/conversation/retrieving-conversations/retrieve-conversation-list)。
