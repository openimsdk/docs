title: '撤回消息'
description: '撤回已发送消息，并处理其他客户端收到的撤回通知。'

撤回会使其他客户端把原消息显示为撤回状态。调用失败时，通过错误回调获取错误码和错误信息。

```java
messageManager.revokeMessageV2(callback, conversationID, clientMsgID);
```

成功回调表示撤回请求已经完成。其他客户端通过 `OnAdvanceMsgListener.onRecvMessageRevokedV2` 接收撤回通知。

`RevokedInfo` 包含 `clientMsgID`、撤回者和撤回时间：

```java
@Override
public void onRecvMessageRevokedV2(RevokedInfo info) {
    handleRevokedMessage(info);
}
```

接收端应把对应消息更新为撤回状态，而不是直接从列表删除。`MessageManager` 只能设置一个 `OnAdvanceMsgListener`；如果应用还需要处理其他消息事件，请在同一个 listener 中实现相应回调。设置方法见[事件概览](/sdk/android/events/overview-events)。
