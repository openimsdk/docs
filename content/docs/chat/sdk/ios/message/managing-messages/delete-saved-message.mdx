```objc
[[OIMManager manager] deleteMessage:conversationID
    clientMsgID:clientMsgID
    onSuccess:nil
    onFailure:nil];
```

Success means that the request to delete the message from the current device and the current account's server-side storage has completed. This method has no multi-device synchronization switch, does not delete copies retained by other participants, and does not display a revocation notice. Use the corresponding dedicated page when messages must be deleted in batches or synchronized across the current account's clients.
