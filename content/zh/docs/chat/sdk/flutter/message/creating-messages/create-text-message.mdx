构建待发送的纯文本消息对象：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `text` | `String` | 是 | 文本消息的正文内容；建议传入前先进行空白字符过滤与长度校验。 |

```dart
final message = await OpenIM.iMManager.messageManager
    .createTextMessage(text: text.trim());
```

## 返回结果

Future 成功返回待发送的消息对象（`Message`），其 `contentType` 为文本类型，正文内容保存在 `textElem` 中。

创建操作仅在本地组装消息数据，不会自动执行网络发送，也不会触发新消息事件通知。构建完成后，应将该对象传给[发送消息](/sdk/flutter/message/sending-messages/send-message)投递至单聊或群聊会话。
