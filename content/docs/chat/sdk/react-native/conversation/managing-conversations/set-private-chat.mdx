Toggle the burn-after-reading private chat mode for a direct one-to-one conversation. The countdown duration after reading is configured separately via [Set burn duration](/sdk/react-native/conversation/managing-conversations/set-burn-duration).

```ts
await OpenIMSDK.setConversationPrivateChat({
  conversationID,
  isPrivate: true,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `string` | Yes | Target conversation ID to configure. |
| `isPrivate` | `boolean` | Yes | Set `true` to enable burn-after-reading, or `false` to disable it. |

## Return value

A resolved Promise confirms that the private chat setting has been saved to the server.

The update triggers the `OnConversationChanged` event. Locate the conversation by `conversationID` in your local store and update `isPrivateChat`. For event details, see [Retrieve conversation list](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list).
