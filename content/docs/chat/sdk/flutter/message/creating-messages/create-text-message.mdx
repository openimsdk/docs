The message factory `Future` returns a `Message` waiting to be sent. It does not send the message or trigger the new-message listener.

```dart
final message = await OpenIM.iMManager.messageManager
    .createTextMessage(text: text.trim());
```

Validate whitespace, length, and content rules first. Then pass the object to [Send a message](/sdk/flutter/message/sending-messages/send-message).
