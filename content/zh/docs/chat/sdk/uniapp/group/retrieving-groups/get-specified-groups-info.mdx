`getSpecifiedGroupsInfo()` 适合在已经持有群组 ID 时读取最新群资料。它不是公开群目录，也不负责按名称发现陌生群组。

```uts
import { getSpecifiedGroupsInfo } from '@/uni_modules/unix-openim-sdk'

const result = await getSpecifiedGroupsInfo(groupIDs)
const groups = result != null ? result.groups : []
```

`groupIDs` 是待查询的群组 ID 数组。查询单个群组时仍需传入数组，并检查 `groups` 中是否存在对应结果。

Promise 成功后返回 `OpenIMGroupListResult | null`；非空结果的 `groups` 是匹配的 `OpenIMGroupItem[]`。数组不保证与输入 ID 按位置一一对应，应使用 `groupID` 建立对应关系。群资料主要字段见[群组概览](/sdk/uniapp/group/overview-group)。

查询只返回调用时的群资料，不会触发群组事件。页面保持打开时，应继续处理群资料变化事件，并在重连或关键操作后重新查询最新资料。
