控制群成员之间是否可以通过本群相互发起好友申请：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupInfoDictionary` | `NSDictionary *` | 包含 `groupID` 和好友添加权限配置的字典对象。 |

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `OIMAllowTypeAllowed` | `0` | 允许群成员互相添加好友。 |
| `OIMAllowTypeNotAllowed` | `1` | 禁止群成员互相添加好友。 |

```objc
NSDictionary *changes = @{
    @"groupID": groupID,
    @"applyMemberFriend": @(OIMAllowTypeNotAllowed)
};

[[OIMManager manager] setGroupInfoDictionary:changes
    onSuccess:^(NSString * _Nullable data) {
        [self showPermissionUpdated];
    }
    onFailure:^(NSInteger code, NSString *message) {
        [self showErrorCode:code message:message];
    }];
```

状态以 `groupID` 为合并标识。该字段仅控制添加好友权限，若需限制成员查看他人资料，请使用[设置成员资料查看权限](/sdk/ios/group/set-group-member-profile-access)。

## 返回结果

成功回调 `onSuccess` 表示服务端已更新该配置。群内各端随后会通过群资料变更事件收到更新后的 `OIMGroupInfo`，完整事件处理见[群组概览](/sdk/ios/group/overview-group)。
