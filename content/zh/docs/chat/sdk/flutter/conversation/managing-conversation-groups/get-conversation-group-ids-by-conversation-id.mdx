同一个会话可以属于多个会话分组。使用 `getConversationGroupByConversationID()` 查询指定会话当前所属的分组。

```dart
final groups = await OpenIM.iMManager.conversationGroupManager
    .getConversationGroupByConversationID(
  conversationID: conversationID,
);
```

## 返回结果

Future 成功后返回完整的 `List<ConversationGroupInfo>`，不是分组 ID 字符串列表。这一点与 WASM 的 `getConversationGroupIDsByConversationID()` 不同。

该查询不会触发 listener。关联变化的增量处理见[会话分组概览](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups)。
