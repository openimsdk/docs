调用创建表情消息方法可构建应用内自定义大表情或贴纸消息对象。

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createFaceMessageWithIndex:1 data:@"smile"];
```

## 参数说明

- `index`：表情包内部的表情索引号（`NSInteger`）。
- `data`：表情相关的协议标识、拼音缩写或自定义 JSON 字符串（`NSString *`）。

## 返回结果

- 返回初始化的表情消息对象（`OIMMessageInfo *`），其内容类型为自定义表情。
- `index` 和 `data` 由业务层自定义表情协议约定，发送端与接收端应保持协议一致，并为未知表情提供兜底占位渲染。创建后需调用[发送消息](/sdk/ios/message/sending-messages/send-message)进行投递。
