删除当前用户与指定用户的好友关系。

```ts
await OpenIMSDK.deleteFriend(friendUserID);
```

## 参数说明

`friendUserID` 是要删除的好友用户 ID。

## 返回结果

调用完成后，好友关系已解除。

删除好友后，双方客户端均会触发 `OnFriendDeleted` 事件通知。客户端应以 `userID` 为合并标识从本地好友列表中移除对应记录。完整事件监听说明见[分页获取好友列表](/sdk/react-native/user/friends/get-friend-list-page)。
