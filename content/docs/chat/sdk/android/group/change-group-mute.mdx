Use `changeGroupMute()` to toggle mute-all mode. Pass `true` to enable it or `false` to disable it. To mute one member, see [Mute or unmute a group member](/sdk/android/group/managing-group-members/change-group-member-mute).

```java
OpenIMClient.getInstance().groupManager.changeGroupMute(new OnBase<String>() {
    @Override public void onSuccess(String data) { markGroupMuteSubmitted(groupID, true); }
    @Override public void onError(int code, String error) { showGroupMuteError(error); }
}, groupID, true);
```

The effective speaking permissions for the owner and administrators, as well as server-side permission checks, depend on the deployment policy.
