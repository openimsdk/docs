---
title: '将全部会话标为已读'
description: '使用 WASM SDK 清零当前所有未读会话的未读数。'
sourcePath: '/sdk/wasm/conversation/managing-conversations/mark-all-conversations-read'
---

当用户明确执行“全部已读”时，调用 `markAllConversationMessageAsRead()` 处理当前本地记录中的所有未读会话：

```ts
await openimsdk.markAllConversationMessageAsRead();
```

Promise 成功表示 SDK 已完成本次找到的全部未读会话处理。它不等同于相关会话事件已经到达，也不保证其他客户端的界面已同步完成。

界面仍应在收到 `OnConversationChanged` 后，使用 `conversationID` 更新对应会话，并通过 `OnTotalUnreadMessageCountChanged` 更新总未读数；完整监听分别见[获取会话列表](/sdk/wasm/conversation/retrieving-conversations/retrieve-conversation-list)和[获取会话总未读数](/sdk/wasm/conversation/managing-conversations/get-total-unread-count)。必要时重新查询会话列表和总未读数，并以最新结果为准。
