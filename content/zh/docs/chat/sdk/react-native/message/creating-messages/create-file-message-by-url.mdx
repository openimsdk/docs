根据已上传文件的 URL 资源信息创建文件消息。

```ts
const message = await OpenIMSDK.createFileMessageByURL({
  filePath: '',
  fileName: '产品说明.pdf',
  uuid: 'file-001',
  sourceUrl: 'https://www.example.com/产品说明.pdf',
  fileSize: 256000,
  fileType: 'application/pdf',
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `filePath` | `string` | 是 | 本地文件路径；仅有远端资源时传空字符串。 |
| `fileName` | `string` | 是 | 对外展示的文件名。 |
| `uuid` | `string` | 是 | 文件唯一资源标识。 |
| `sourceUrl` | `string` | 是 | 已上传文件的远端网络地址。 |
| `fileSize` | `number` | 是 | 文件大小，单位为字节。 |
| `fileType` | `string` | 否 | 文件类型（MIME 类型）。 |

## 返回结果

调用完成后返回已创建的 `MessageItem` 消息对象，其中 `fileElem` 保存远端文件信息。

该方法仅在本地构建待发送的消息结构，不会直接向服务端发送，也不会触发收发消息事件。生成消息对象后，需通过[发送已上传的媒体消息](/sdk/react-native/message/sending-messages/send-message-not-oss)直接投递该消息，无需重复上传文件。
