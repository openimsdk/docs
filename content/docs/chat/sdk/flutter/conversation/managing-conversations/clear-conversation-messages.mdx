Retain the conversation entry in the conversation list while purging all message history locally and on the server:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `String` | Yes | Target conversation ID. |

## Code example

```dart
await OpenIM.iMManager.conversationManager
    .clearConversationAndDeleteAllMsg(conversationID: conversationID);
```

## Return value

A successful `Future` indicates that the clear operation has completed. The client should immediately empty its active message view. The SDK emits conversation change events to reset `latestMsg`, `latestMsgSendTime`, and unread counters.

## State changes after the call

Update the conversation item locally using `conversationID` as the primary key. For event listener integration, see [Retrieve conversation list](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list). To remove the conversation entry alongside its messages, see [Delete conversation with messages](/sdk/flutter/conversation/managing-conversations/delete-conversation-with-messages).
