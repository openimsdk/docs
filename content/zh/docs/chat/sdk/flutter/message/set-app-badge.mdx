向 SDK 上报应用当前展示的消息总未读数，便于 SDK 维护推送角标计数：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `count` | `int` | 是 | 应用展示的消息总未读数（非负整数）。 |

```dart
await OpenIM.iMManager.messageManager.setAppBadge(totalUnreadCount);
```

通常在消息总未读数变化、用户登录同步完成或批量标记已读后调用此方法同步最新角标数值；请勿将单个会话的未读数直接作为全局角标传入。

## 返回结果

Future 成功表示 SDK 已同步接收该角标数值。

调用此方法不会修改本地数据库中的会话未读计数。若应用需要在移动端桌面图标上显示角标数字，还应配合系统原生角标能力或平台插件同步更新桌面图标状态。消息总未读数的拉取与监听维护请参考[获取消息总未读数](/sdk/flutter/conversation/managing-conversations/get-total-unread-count)。
