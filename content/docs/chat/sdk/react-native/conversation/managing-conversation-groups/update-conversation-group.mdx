Modify the name, custom extension, or visibility of an existing conversation group. Pass only the fields that need to be changed:

```ts
const group = await OpenIMSDK.updateConversationGroup({
  conversationGroupID,
  name: 'Priority Work',
  hidden: false,
});
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationGroupID` | `string` | Yes | Target conversation group ID to update. |
| `name` | `string` | No | New display name for the group. |
| `ex` | `string` | No | New custom business extension string. |
| `hidden` | `boolean` | No | Whether to hide the group in the UI. |

## Return value

Resolves to the updated `ConversationGroupResp` object.

Modifications trigger the `OnConversationGroupChanged` event. Locate the group using `conversationGroupID` to reconcile properties in your local group state. For event listener setup, see [Conversation groups overview](/sdk/react-native/conversation/managing-conversation-groups/overview-conversation-groups).
