调用 `setConversationGroupOrder()` 可批量调整会话分组的展示排序。入参数组中的每一项需包含目标分组 ID 和新的排序数值。

## 参数说明

该方法直接接收数组，数组中的每一项使用以下字段：

| 参数                          | 类型     | 是否必填 | 说明                                 |
| ----------------------------- | -------- | -------- | ------------------------------------ |
| `items[].conversationGroupID` | `string` | 是       | 要调整的会话分组 ID。                |
| `items[].order`               | `number` | 是       | 新的排序值，排序规则由业务层约定。   |

```ts
await openimsdk.setConversationGroupOrder([
  { conversationGroupID: firstGroupID, order: 100 },
  { conversationGroupID: secondGroupID, order: 200 },
]);
```

## 返回结果

接口调用成功表示排序调整请求已完成。该接口不返回更新后的完整分组列表，业务层可先按提交的顺序值在前端对分组进行重排。

此外，多端或其他模块可能会收到 `SdkEvent.OnConversationGroupChanged` 事件。完整的事件监听配置请参考[会话分组概览](/sdk/wasm/conversation/managing-conversation-groups/overview-conversation-groups)。
