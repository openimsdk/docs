```uts
import { sendMessage } from '@/uni_modules/unix-openim-sdk'

const sent = await sendMessage({ message, recvID: 'user_b', groupID: '', isOnlineOnly: false })
upsertMessage(sent.clientMsgID, sent)
```

Set `recvID` for direct chat or `groupID` for group chat and leave the other empty. The Promise resolves directly to `OpenIMMessageItem`. Preserve failed messages for retry under the same `clientMsgID` unless your product explicitly creates a new send.
