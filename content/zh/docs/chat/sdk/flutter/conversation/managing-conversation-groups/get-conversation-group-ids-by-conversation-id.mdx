同一个会话可以归属于多个会话分组。调用此方法可查询指定会话当前已加入的全部会话分组：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationID` | `String` | 是 | 目标会话 ID。 |

```dart
final groups = await OpenIM.iMManager.conversationGroupManager
    .getConversationGroupByConversationID(
  conversationID: conversationID,
);
```

## 返回结果

Future 成功返回该会话所属的完整 `List<ConversationGroupInfo>` 列表。客户端以 `conversationGroupID` 为合并标识维护会话与分组的归属关系。

查询操作建立静态快照，不会触发事件通知。后续关联变动请参考[会话分组概览](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups)。
