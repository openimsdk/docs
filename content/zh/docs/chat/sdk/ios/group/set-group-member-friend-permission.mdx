---
title: '设置群内添加好友权限'
description: '使用 iOS SDK 控制群成员能否通过群组发送好友申请。'
sourcePath: '/sdk/ios/group/set-group-member-friend-permission'
---

```objc
NSDictionary *changes = @{
    @"groupID": groupID,
    @"applyMemberFriend": @(OIMAllowTypeNotAllowed)
};

[[OIMManager manager] setGroupInfoDictionary:changes
    onSuccess:nil
    onFailure:nil];
```

`OIMAllowTypeAllowed` 的值为 `0`，表示允许；`OIMAllowTypeNotAllowed` 的值为 `1`，表示不允许。该字段不负责隐藏群成员资料。

成功 callback 后，通过 `onGroupInfoChanged:` 更新设置，或重新查询确认最终状态。
