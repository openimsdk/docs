---
title: '检查是否已加入群组'
description: '使用 isJoinGroup 查询当前登录用户是否已经加入指定群组。'
sourcePath: '/sdk/android/group/retrieving-groups/is-join-group'
---

`isJoinGroup()`检查当前登录用户是否加入目标群组，参数为 `groupID`。

```java
OpenIMClient.getInstance().groupManager.isJoinGroup(groupID, new OnBase<Boolean>() {
    @Override public void onSuccess(Boolean joined) { /* joined 表示当前用户是否已在群内。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
});
```
