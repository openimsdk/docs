---
title: '插入本地群聊消息'
description: '使用 insertGroupMessageToLocalStorage 插入仅当前设备可见的群聊消息。'
sourcePath: '/sdk/android/message/managing-messages/insert-local-group-message'
---

`insertGroupMessageToLocalStorage()` 把一条消息写入当前设备的指定群聊，可用于迁移记录或展示仅本地可见的业务提示。它不会发送消息，也不会同步到其他设备。

`message` 是要插入的完整消息对象，`groupID` 是目标群组，`senderUserID` 是消息展示使用的发送者用户 ID。

```java
OpenIMClient.getInstance().messageManager.insertGroupMessageToLocalStorage(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 重新读取或更新当前设备上的群聊消息列表。
        }

        @Override
        public void onError(int code, String error) {
            // 提示本地写入失败。
        }
    },
    message,
    groupID,
    senderUserID
);
```

成功回调表示本地写入完成。该操作不触发新消息事件，不能用于代替[发送消息](/sdk/android/message/sending-messages/send-message)。
