Reset the `@` mention indicator on a group conversation after the user opens or dismisses mention alerts:

```ts
await OpenIMSDK.resetConversationGroupAtType(conversationID);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationID` | `string` | Yes | Target group conversation ID whose mention state will be reset. |

This operation restores `groupAtType` to its default non-mention state. Clearing group mentions is independent of [Mark conversation as read](/sdk/react-native/conversation/managing-conversations/mark-conversation-read).

## Return value

A resolved Promise confirms that the group mention status has been reset.

The state update triggers the `OnConversationChanged` event. Use `conversationID` to locate the target conversation in your state store and update `groupAtType` to `GroupAtType.AtNormal`. For event registration, see [Retrieve conversation list](/sdk/react-native/conversation/retrieving-conversations/retrieve-conversation-list).
