`deleteFriendRequests()` deletes records in batches by applicant and recipient pairs.

## Parameters

The method accepts an array directly. Each array item uses the following fields:

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `items[].fromUserID` | `string` | Yes | User ID of the applicant. |
| `items[].toUserID` | `string` | Yes | User ID of the application recipient. |

```ts
await openimsdk.deleteFriendRequests([{ fromUserID, toUserID }]);
```

Deleting a record is not the same as rejecting an application, and it does not delete an existing friendship. A successful Promise means that the deletion request has completed. `OnFriendApplicationDeleted` may arrive afterward; remove the record by `fromUserID:toUserID`. See [Get received friend applications](/sdk/wasm/user/friend-applications/get-friend-application-list-as-recipient) for the complete listener.
