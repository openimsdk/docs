---
title: '发送好友申请'
description: '使用 Flutter SDK 发送好友申请。'
sourcePath: '/sdk/flutter/user/friend-applications/add-friend'
---

```dart
await OpenIM.iMManager.friendshipManager.addFriend(
  userID: 'user_b',
  reason: '你好，我是 Alex',
);
```

`userID` 是申请接收方，`reason` 是可选附言。Future 成功表示服务端已收到申请，不表示对方已经同意。申请变化见[获取收到的好友申请](/sdk/flutter/user/friend-applications/get-friend-application-list-as-recipient)。
