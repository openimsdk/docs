```ts
await openimsdk.deleteAllMsgFromLocal();
resetAllMessageSnapshots();
```

This is a destructive account-level operation. Require confirmation and clear all in-memory message snapshots. When the Promise resolves, only the local database has been cleared. The server still retains message history, so messages may be synchronized again after local data is rebuilt. The operation does not trigger a separate message-deletion event.
