---
title: '使用本地路径创建音频消息'
description: '使用 iOS SDK 从绝对路径创建音频消息。'
sourcePath: '/sdk/ios/message/creating-messages/create-sound-message-from-full-path'
---

```objc
OIMMessageInfo *message =
    [OIMMessageInfo createSoundMessageFromFullPath:audioURL.path
                                          duration:durationSeconds];
```

路径必须可读，`duration` 使用秒。返回对象仍需通过普通发送 API 上传并发送。
