分页查询当前用户发出的好友申请列表。

```ts
const applications = await OpenIMSDK.getFriendApplicationListAsApplicant({
  offset: 0,
  count: 20,
});
```

## 参数说明

| 参数 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `offset` | `number` | 是 | 分页偏移量，从 `0` 开始。 |
| `count` | `number` | 是 | 本次获取的申请记录数量。 |

## 返回结果

调用完成后返回当前页的 `FriendApplicationItem[]` 申请记录列表。详细字段说明与事件监听请参考[获取收到的好友申请](/sdk/react-native/user/friend-applications/get-friend-application-list-as-recipient)。
