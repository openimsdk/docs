When the calling room ID is already known, query its RTC media access credentials using `signalingGetTokenByRoomID()`:

```ts
const roomCredentials =
  await OpenIMSDK.signalingGetTokenByRoomID(roomID);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `roomID` | `string` | Yes | Target calling room ID. |

## Return value

Resolves to an `RtcInviteResults` object containing `roomID`, `token`, `liveURL`, and optional `busyLineUserIDList`. Pass these room credentials to your real-time audio/video media engine to connect to the media session. For detailed field descriptions, see [Start a one-to-one call](/sdk/react-native/calling/managing-calls/start-single-call).
