## Integrate with your existing system

Instant messaging (IM) has become a critical part of internet infrastructure and an essential feature in many applications. If you have developed an application and wish to integrate OpenIMSDK for chat functionality, this document provides a brief overview of the integration steps.

![OpenIMSDK and business system relationship](/assets/guides/introduction/assets/relation.png)

In the system diagram above:

- **Your APP Server** represents your existing application's server-side. The development language is unrestricted. User information (including profiles and password verification) is stored on this server.
- **Your APP Client** represents your existing application's client-side. All mainstream development frameworks are supported.

## Your APP Server Calls REST API to Interface with OpenIMServer

1. **New User Registration**: After a user registers successfully, call the [User Registration API](/platform-api/user/creating-users/create-a-user).
2. **User Info Update**: After a user updates their info (e.g., avatar, nickname, extension fields), call the [Update User Info API](/platform-api/user/managing-users/update-a-user).
3. **Get IM Token**: After password verification, call the [Get User IM Token API](/platform-api/auth/tokens/get-user-token) and return the IM Token to **Your APP Client**.
4. **Import Existing Users**: Before launch, call the [User Registration API](/platform-api/user/creating-users/create-a-user) to import existing user data.

## Your APP Client Integrates OpenIMClientSDK

1. **User Login**: After successful login, obtain the IM Token from **Your APP Server** and call the [OpenIMClientSDK Login API](/sdk/wasm/getting-started/authenticate-and-manage-session).
2. **Embed OpenIMClientSDK**: Embed OpenIMClientSDK into your application to integrate chat functionality.
3. **User Info Management**: Use your existing **Your APP Server** APIs for retrieving and updating user info.
