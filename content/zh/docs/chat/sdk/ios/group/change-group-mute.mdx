开启或关闭群组全员禁言（通常仅群主和管理员有权限操作）：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupID` | `NSString *` | 目标群组 ID。 |
| `isMute` | `BOOL` | `YES` 表示开启全员禁言，`NO` 表示关闭全员禁言。 |

```objc
[[OIMManager manager] changeGroupMute:groupID
                               isMute:YES
                            onSuccess:^(NSString * _Nullable data) {
                                [self showGroupMuted];
                            }
                            onFailure:^(NSInteger code, NSString *message) {
                                [self showErrorCode:code message:message];
                            }];
```

状态以 `groupID` 为合并标识。全员禁言会限制除群主和管理员以外的普通群成员发言；若需对单个成员设置禁言时长，请使用[设置群成员禁言](/sdk/ios/group/managing-group-members/change-group-member-mute)。

## 返回结果

成功回调 `onSuccess` 表示服务端已更新全员禁言状态。群资料变更事件随后会广播给群内所有成员并携带最新的 `OIMGroupInfo`，完整事件处理见[群组概览](/sdk/ios/group/overview-group)。
