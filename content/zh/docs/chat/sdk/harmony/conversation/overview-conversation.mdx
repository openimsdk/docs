会话是当前登录用户围绕一次单聊或群聊维护的客户端聊天状态。`IMConversation` 保存目标、展示信息、最后一条消息、未读数、草稿和当前账号的会话设置。

| 标识             | 用途                                                  |
| ---------------- | ----------------------------------------------------- |
| `conversationID` | 会话状态的稳定 ID，用于历史消息、已读和会话设置。     |
| `userID`         | 单聊对方的用户 ID。                                   |
| `groupID`        | 群聊对应的群组 ID。                                   |
| `sourceID`       | 按目标查询时使用的 ID：单聊为用户 ID，群聊为群组 ID。 |

单聊使用 `SessionType.Single`，群聊使用 `SessionType.WriteGroup`。不要在应用层自行拼接 `conversationID`。

会话列表通过分页查询建立，再通过新增与变化事件增量更新。收到状态变化时以 `conversationID` 合并；重新登录、同步恢复或事件可能遗漏时重新查询校准。

会话的置顶、标记、备注、草稿、接收方式、阅后即焚和服务端消息删除策略彼此独立，文档按具体操作分别说明，避免一次更新无意覆盖其他字段。
