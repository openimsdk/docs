使用 `createAdvancedTextMessage()` 创建带消息实体的富文本消息。

```ts
const message = await OpenIMSDK.createAdvancedTextMessage({
  text: '请查看 https://openim.io',
  messageEntityList: [
    {
      type: 'url',
      offset: 4,
      length: 17,
      url: 'https://openim.io',
    },
  ],
});
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `text` | `string` | 是 | 富文本的原始文本。 |
| `messageEntityList` | `MessageEntity[]` | 否 | 文本中的实体列表。 |

每项 `MessageEntity` 包含 `type`、`offset`、`length`，并可选传入 `url` 和 `info`。调用后返回待发送的 `MessageItem`，使用[发送消息](/sdk/react-native/message/sending-messages/send-message)发送。
