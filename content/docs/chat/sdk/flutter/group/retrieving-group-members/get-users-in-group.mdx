Batch verify whether a specified set of users are members of a target group without loading full member profile records:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID. |
| `userIDList` | `List<String>` | Yes | List of candidate user IDs to check. |

## Code example

```dart
final presentUserIDs = await OpenIM.iMManager.groupManager.getUsersInGroup(
  groupID,
  userIDList,
);
```

## Return value

A successful `Future` returns a list containing only the user IDs that actively belong to the target group (`List<String>`).

This method performs a lightweight membership presence check; it does not return in-group nicknames, roles, or mute durations. To inspect detailed member profiles, see [Get group members info](/sdk/flutter/group/retrieving-group-members/get-group-members-info).

This query returns an immediate data snapshot and does not emit event notifications.
