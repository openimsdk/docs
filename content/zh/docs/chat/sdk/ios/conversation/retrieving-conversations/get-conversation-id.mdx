只需要会话 ID 字符串时调用纯本地同步方法计算，无需在业务层自行拼接字符串：

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `sessionType` | `OIMConversationType` | 会话类型。单聊使用 `OIMConversationTypeC2C`，群聊使用 `OIMConversationTypeGroup`。 |
| `sourceID` | `NSString *` | 聊天目标标识。单聊为对方用户 ID，群聊为群组 ID。 |

```objc
NSString *conversationID = [[OIMManager manager]
    getConversationIDBySessionType:OIMConversationTypeC2C
                          sourceID:@"user_1002"];

if (conversationID.length > 0) {
    [self handleConversationID:conversationID];
}
```

状态以 `conversationID` 为合并标识。

## 返回结果

同步返回标准化的会话唯一标识字符串 `NSString *`。若传入参数无效则可能返回 `nil`。

该方法为轻量同步方法，不发起网络请求，不涉及数据库 I/O，亦不触发任何 delegate 回调。该接口只计算 ID 字符串，不返回包含未读数、置顶与草稿等属性的完整会话对象；若需获取完整会话模型，请调用[查询指定会话](/sdk/ios/conversation/retrieving-conversations/get-conversation-by-target)。
