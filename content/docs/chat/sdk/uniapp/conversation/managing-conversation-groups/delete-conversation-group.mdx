Deleting conversation groups is a Commercial Edition capability. This operation deletes the conversation group and its membership associations; it does not delete member conversations or chat messages.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationGroupID` | `string` | Yes | Identifier of the conversation group to delete. |

## Code example

```uts
import { deleteConversationGroup } from '@/uni_modules/unix-openim-sdk'

await deleteConversationGroup({
  conversationGroupID,
})
```

The `conversationGroupID` parameter refers to the conversation category ID, not an OpenIM chat `groupID`.

## Return value

The Promise resolves with `void` upon successful completion.

## State changes after the call

Promise resolution indicates that the deletion was committed. Remove the group and its tab views from local state using `conversationGroupID` as the key. For event listeners and state synchronization upon reconnecting, see [Conversation group overview](/sdk/uniapp/conversation/managing-conversation-groups/overview-conversation-groups).
