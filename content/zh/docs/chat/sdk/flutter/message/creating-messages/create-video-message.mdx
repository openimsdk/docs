```dart
final message = await OpenIM.iMManager.messageManager.createVideoMessage(
  videoPath: videoPath,
  videoType: 'video/mp4',
  duration: durationSeconds,
  snapshotPath: snapshotPath,
);
```

视频和封面图路径必须可读，时长单位为秒。Future 只创建待发送对象。
