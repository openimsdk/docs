使用 `getConversationGroups()` 按类型读取当前用户的完整会话分组列表。

```dart
final groups = await OpenIM.iMManager.conversationGroupManager
    .getConversationGroups(
  conversationGroupType: ConversationGroupType.custom,
);
```

`conversationGroupType` 默认是 `ConversationGroupType.all`。查询普通自定义分组时传入 `ConversationGroupType.custom`。

## 返回结果

Future 成功后返回排序后的 `List<ConversationGroupInfo>`。缓存时先检查 nullable 的 `conversationGroupID`，再按该 ID 合并。

该查询不会触发 listener，之后的变化处理见[会话分组概览](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups)。
