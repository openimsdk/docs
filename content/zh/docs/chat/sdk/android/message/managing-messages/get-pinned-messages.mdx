description: '使用 getConversationPinnedMsgs 查询会话中的置顶消息。'
sourcePath: '/sdk/android/message/managing-messages/get-pinned-messages'
---

成功回调返回指定会话当前的置顶消息列表。

```java
messageManager.getConversationPinnedMsgs(new OnBase<List<Message>>() {
    @Override public void onSuccess(List<Message> messages) { /* messages 是置顶消息。 */ }
    @Override public void onError(int code, String error) { /* code 和 error 说明失败原因。 */ }
}, conversationID);
```
