按会话展示名称（`showName`）在 SDK 本地已同步的会话数据中进行模糊搜索，适用于会话列表搜索与快速筛选。搜索关键字不能为空；该接口不会检索尚未同步到本地数据库的历史会话。

```uts
import { searchConversation } from '@/uni_modules/unix-openim-sdk'

const result = await searchConversation(searchKeyword.trim())
const matchedConversations = result?.conversations ?? []
renderConversationResults(matchedConversations)
```

Promise 成功后返回 `OpenIMConversationListResult | null`，匹配会话位于 `conversations`。查询结果只反映调用时刻保存在本地的数据，查询操作本身不会触发事件。若搜索界面需响应会话状态变更，应监听[获取会话列表](/sdk/uniapp/conversation/retrieving-conversations/retrieve-conversation-list)中的会话事件，并以 `conversationID` 为合并标识更新或移除搜索结果。
