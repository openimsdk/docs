为指定群成员设置业务自定义扩展字段（如群内自定义头衔、职位或专属标签等）：

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `groupID` | `String` | 是 | 目标群组 ID。 |
| `userID` | `String` | 是 | 目标群成员的用户 ID。 |
| `ex` | `String` | 是 | 自定义扩展字符串，通常建议使用 JSON 字符串格式。 |

```dart
await OpenIM.iMManager.groupManager.setGroupMemberInfo(
  groupMembersInfo: SetGroupMemberInfo(
    groupID: groupID,
    userID: targetUserID,
    ex: mergedExtensionJSON,
  ),
);
```

`ex` 字段为整段覆盖写入，SDK 不会自动进行增量合并。若群成员扩展字段包含多模块数据，建议先查询现有扩展字符串，合并对应字段后再写入。

## 返回结果

Future 成功表示服务端已保存该群成员的扩展字段。

设置生效后，群内相关客户端会收到成员资料变更事件通知；客户端应使用复合标识 `groupID:userID` 更新本地成员的扩展信息。完整的事件监听与增量合并逻辑请参考[群成员查询概览](/sdk/flutter/group/retrieving-group-members/overview-retrieving-group-members)。
