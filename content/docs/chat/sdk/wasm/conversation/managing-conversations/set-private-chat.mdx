`isPrivateChat` enables or disables burn-after-reading mode. It is separate from scheduled server-message deletion.

```ts
await openimsdk.setConversation({
  conversationID,
  isPrivateChat: true,
});
```

Pass `false` to disable the mode. Configure its duration separately through `burnDuration`; see [Set the burn duration](/sdk/wasm/conversation/managing-conversations/set-burn-duration).

A successful Promise means only that the setting request has completed. When `OnConversationChanged` arrives, use `conversationID` to update the state on the matching conversation. See [Get the conversation list](/sdk/wasm/conversation/retrieving-conversations/retrieve-conversation-list) for the complete listener.
