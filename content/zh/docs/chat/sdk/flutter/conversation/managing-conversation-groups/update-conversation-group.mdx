修改已有会话分组的属性。更新时仅需传入需要变更的属性字段。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `conversationGroupID` | `String` | 是 | 目标会话分组 ID。 |
| `name` | `String?` | 否 | 新的分组名称。 |
| `order` | `int?` | 否 | 新的分组排序顺序值。 |
| `ex` | `String?` | 否 | 新的业务自定义扩展字符串。 |
| `hidden` | `bool?` | 否 | 是否在列表中隐藏该分组。 |

```dart
await OpenIM.iMManager.conversationGroupManager.updateConversationGroup(
  req: UpdateConversationGroupReq(
    conversationGroupID: conversationGroupID,
    name: '重点工作',
    hidden: false,
  ),
);
```

## 返回结果

Future 成功表示更新请求已提交处理。客户端以 `conversationGroupID` 为合并标识更新本地分组属性。

多端同步或事件到达时通过 `onConversationGroupChanged` 通知，完整事件监听请参考[会话分组概览](/sdk/flutter/conversation/managing-conversation-groups/overview-conversation-groups)。
