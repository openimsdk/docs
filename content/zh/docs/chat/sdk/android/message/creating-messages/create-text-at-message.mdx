传入文本、被 @ 用户 ID、`AtUserInfo` 列表和可选引用消息。

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `text` | `String` | 是 | 完整消息正文，应与界面最终显示内容一致。 |
| `userIDs` | `List<String>` | 是 | 被提醒的群成员用户 ID；去重后传入。 |
| `atUserInfos` | `List<AtUserInfo>` | 是 | 被提醒成员的用户 ID 和展示名称，应与 `userIDs` 对应。 |
| `quoteMessage` | `Message` | 否 | 同时回复某条消息时传被引用的完整消息，否则传 `null`。 |

```java
Message message = OpenIMClient.getInstance().messageManager.createTextAtMessage(
    text, userIDs, atUserInfos, quoteMessage);
```

返回的 `Message` 只是在本地创建的待发送对象。@ 提醒通常用于群聊；发送前应确认目标用户仍是群成员，并使用[发送消息](/sdk/android/message/sending-messages/send-message)投递到对应群组。
