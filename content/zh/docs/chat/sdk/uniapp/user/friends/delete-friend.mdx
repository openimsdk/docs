---
title: '删除好友'
description: '删除当前用户与指定用户的好友关系。'
sourcePath: '/sdk/uniapp/user/friends/delete-friend'
---

删除当前用户与指定用户的好友关系。接口直接接收要删除的好友用户 ID。

```uts
import { deleteFriend } from '@/uni_modules/unix-openim-sdk'

await deleteFriend(friendUserID)
```

Promise 成功表示本次删除好友请求已成功返回，不表示好友事件已经到达各端。收到好友删除事件后，客户端按事件数据中的 `userID` 从好友列表和相关缓存中移除记录；完整事件监听与处理逻辑请参考[分页获取好友列表](/sdk/uniapp/user/friends/get-friend-list-page)。如果事件可能遗漏，应重新查询好友列表并以最新结果为准。
