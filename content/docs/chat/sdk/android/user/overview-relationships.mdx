Relationship capabilities track friend connections, incoming/outgoing friend applications, and blocklists for the authenticated account. User profile details, account settings, and presence tracking belong to user capabilities; see [User overview](/sdk/android/user/overview-user).

## Relationship models

The Android SDK uses distinct models across relationship operations:

| Class | Application scenario | Primary operations |
| --- | --- | --- |
| `UserInfo` | Comprehensive user profile and relationship details in friend lists, profile lookups, and blocklists | [Get the friend list](/sdk/android/user/friends/get-friend-list-page), [Get friend profiles](/sdk/android/user/friends/get-friends-info), [Get the blacklist](/sdk/android/user/blacklist/get-blacklist) |
| `FriendInfo` | Friend metadata, remarks, and custom relationship extension fields | Accessed via `UserInfo.friendInfo`, [Search friends](/sdk/android/user/friends/search-friends) |
| `FriendshipInfo` | Check bilateral friendship state between the current user and a target | [Check friendship status](/sdk/android/user/friends/check-friend) |
| `FriendApplicationInfo` | Incoming and outgoing friend applications along with their review states | [Get received friend applications](/sdk/android/user/friend-applications/get-recv-friend-application-list), [Get sent friend applications](/sdk/android/user/friend-applications/get-send-friend-application-list) |
| `BlacklistInfo` | Blocklist entry information | Accessed via `UserInfo.blackInfo`, [Get the blacklist](/sdk/android/user/blacklist/get-blacklist) |

`UserInfo` contains comprehensive relation snapshots; access `FriendInfo` through the `friendInfo` property and `BlacklistInfo` through the `blackInfo` property.

## State updates

Relationship events are broadcast in real time through `OnFriendshipListener`. Deduplicate and incrementally merge friend records, friend applications, and blocklist entries using `userID` as the unique primary key:

```java
OpenIMClient client = OpenIMClient.getInstance();

client.friendshipManager.setOnFriendshipListener(new OnFriendshipListener() {
    @Override
    public void onFriendApplicationAdded(FriendApplicationInfo application) {
        // Handle new friend application
    }

    @Override
    public void onFriendApplicationAccepted(FriendApplicationInfo application) {
        // Handle friend application accepted
    }

    @Override
    public void onFriendApplicationRejected(FriendApplicationInfo application) {
        // Handle friend application rejected
    }

    @Override
    public void onFriendApplicationDeleted(FriendApplicationInfo application) {
        // Handle friend application deleted
    }

    @Override
    public void onFriendAdded(FriendInfo friend) {
        // Handle new friend added
    }

    @Override
    public void onFriendInfoChanged(FriendInfo friend) {
        // Handle friend profile or remark changed
    }

    @Override
    public void onFriendDeleted(FriendInfo friend) {
        // Handle friend removed
    }

    @Override
    public void onBlacklistAdded(BlacklistInfo user) {
        // Handle user added to blocklist
    }

    @Override
    public void onBlacklistDeleted(BlacklistInfo user) {
        // Handle user removed from blocklist
    }
});
```
