---
title: '删除群聊中指定用户的全部消息'
description: '使用 iOS SDK 删除指定用户在群聊中的全部消息。'
sourcePath: '/sdk/ios/message/managing-messages/delete-user-messages'
---

```objc
[[OIMManager manager] deleteUserAllMessagesInConversation:conversationID
    userID:targetUserID
    onSuccess:nil
    onFailure:nil];
```

该 selector 只用于群聊，可删除指定用户在目标群会话中的全部消息。这是群组管理或内容治理操作，操作者权限由服务端校验。不要根据成功 callback 猜测具体消息 ID。

`onDeleteUserAllMsgsInConv:` 是本页归属事件，载荷只有 `conversationID` 和 `userID`；按两者清除缓存并重新查询历史。listener 生命周期见[接收消息](/sdk/ios/message/receiving-messages/receive-messages)。
