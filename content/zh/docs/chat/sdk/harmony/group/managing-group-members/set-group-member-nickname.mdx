---
title: '修改群内昵称'
description: '修改指定成员在一个群组中的昵称。'
sourcePath: '/sdk/harmony/group/managing-group-members/set-group-member-nickname'
---

群内昵称只作用于指定群组，不会修改用户的账号昵称。

```ts
import sdk, { SetGroupMemberInfoReq } from '@openimsdk/imsdk';

const request: SetGroupMemberInfoReq = {
  groupID: groupID,
  userID: targetUserID,
  nickname: '项目负责人',
};
await sdk.setGroupMemberInfo(request);
```

当前账号能否修改本人或其他成员的群内昵称，由 OpenIMServer 根据角色和策略校验。Promise 成功后，收到成员资料变化事件时再按 `groupID:userID` 更新记录。
