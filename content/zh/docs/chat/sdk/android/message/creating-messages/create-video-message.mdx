---
title: '创建视频消息'
description: '使用相对于 SDK 初始化数据目录的路径创建视频消息。'
sourcePath: '/sdk/android/message/creating-messages/create-video-message'
---

```java
Message message = OpenIMClient.getInstance().messageManager.createVideoMessage(
    videoPath,
    mimeType,
    durationSeconds,
    snapshotPath
);
```

视频和快照文件应位于 SDK 初始化时配置的数据目录内，两个路径均相对于该目录。视频时长单位为秒。本方法只创建待发送对象。
