Retrieve pending call invitations that arrived before or during application startup. This is commonly used to restore incoming call screens after cold-launching from an offline push notification.

## Code example

```java
OpenIMClient.getInstance().signalingManager.getSignalingInvitationInfoStartApp(
    new OnBase<SignalingInfo>() {
        @Override
        public void onSuccess(SignalingInfo info) {
            // Verify whether info contains a valid invitation and roomID before using.
        }

        @Override
        public void onError(int code, String error) {
            // code and error describe the failure.
        }
    }
);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `base` | `OnBase<SignalingInfo>` | Yes | Callback delivering the asynchronous operation result. |

## Return value

The successful callback returns the pending call invitation payload as `SignalingInfo`.

This method does not answer or modify the call automatically. Verify whether `info` has a non-null `invitation` and a valid `roomID`. If an active invitation exists, present the incoming call UI to let the user [Accept a call](/sdk/android/calling/managing-calls/accept-call) or [Reject a call](/sdk/android/calling/managing-calls/reject-call). For subsequent cancellation or timeout events, see [Handle call events](/sdk/android/calling/managing-calls/handle-call-events).
