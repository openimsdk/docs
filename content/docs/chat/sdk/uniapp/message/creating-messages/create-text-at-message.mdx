```uts
import { createTextAtMessage } from '@/uni_modules/unix-openim-sdk'

const message = await createTextAtMessage({
  text: '@Alice please review', atUserIDList: ['user_a'],
  atUsersInfo: [{ atUserID: 'user_a', groupNickname: 'Alice' }], quoteMessage: null,
})
```

Keep mention IDs and display metadata aligned. Commercial `getAtAllTag()` returns the deployed “mention everyone” tag. Send the created message with a target group ID.
