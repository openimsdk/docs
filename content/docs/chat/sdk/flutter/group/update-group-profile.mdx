Update basic presentation properties of a group (group name, introduction, and avatar). Group announcements, join verification, and permissions are managed separately; do not mix them into profile modifications:

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `String` | Yes | Target group ID. |
| `groupName` | `String?` | No | New group name. |
| `introduction` | `String?` | No | New group introduction. |
| `faceURL` | `String?` | No | New group avatar URL. |

## Code example

```dart
await OpenIM.iMManager.groupManager.setGroupInfo(
  GroupInfo(
    groupID: groupID,
    groupName: groupName.trim(),
    introduction: introduction.trim(),
    faceURL: faceURL,
  ),
);
```

## Return value

A successful `Future` indicates that the server accepted and applied the group profile updates.

## State changes after the call

The server broadcasts group profile update notifications. The client updates the local group cache using `groupID` as the key. For complete listener integration, see [Groups overview](/sdk/flutter/group/overview-group). To proactively verify fresh state, call [Get specified groups info](/sdk/flutter/group/retrieving-groups/get-specified-groups-info).
