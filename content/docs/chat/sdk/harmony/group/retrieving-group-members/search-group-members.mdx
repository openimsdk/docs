Use this method to search members or build candidate selection lists when [Creating @ mention messages](/sdk/harmony/message/creating-messages/create-text-at-message).

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `groupID` | `string` | Yes | Target group identifier. |
| `keyword` | `string` | Yes | Non-empty search keyword trimmed of whitespace. |
| `searchUserID` | `boolean` | Yes | Whether to match member user IDs. |
| `searchMemberNickname` | `boolean` | Yes | Whether to match in-group member nicknames. |
| `pagination` | `RequestPagination` | Yes | Pagination configuration containing page number and page size. |

## Code example

```ts
import sdk, { SearchGroupMembersReq, SearchGroupMembersResp } from '@openimsdk/imsdk';

const request: SearchGroupMembersReq = {
  groupID: groupID,
  keyword: keyword.trim(),
  searchUserID: true,
  searchMemberNickname: true,
  pagination: { pageNumber: 1, showNumber: 30 },
};
const response: SearchGroupMembersResp = await sdk.searchGroupMembers(request);
const members = response.members;
```

## Return value

Returns a Promise resolving to `SearchGroupMembersResp`:

| Property | Type | Description |
| --- | --- | --- |
| `members` | `GroupMemberItem[]` | Array of matching group member items. |

## State changes after the call

Search results represent an isolated query view and should not replace your application's primary member roster. When search terms or field flags change, reset the page index and swap out search results. For managing the primary member roster, see [Retrieve group member list](/sdk/harmony/group/retrieving-group-members/get-group-member-list).
