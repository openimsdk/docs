---
title: '设置加好友权限'
description: '设置其他用户向当前账号发起好友关系时采用的处理策略。'
sourcePath: '/sdk/uniapp/user/profile/set-friend-add-permission'
---

`addFriendPermission` 控制其他用户添加当前账号时是否需要审核。该账号级策略属于商业版能力，与昵称、头像等普通资料相互独立。

| 常量 | 数值 | 含义 |
| --- | --- | --- |
| `OpenIMAddFriendPermissionAllowed` | `0` | 允许其他用户发起好友申请，需要当前用户审核。 |
| `OpenIMAddFriendPermissionAllowedNoReview` | `1` | 允许添加并直接建立好友关系，不需要当前用户审核。 |
| `OpenIMAddFriendPermissionDenied` | `2` | 不允许其他用户添加当前账号。 |

```uts
import {
  OpenIMAddFriendPermissionAllowed,
  setSelfInfo,
} from '@/uni_modules/unix-openim-sdk'

await setSelfInfo({
  addFriendPermission: OpenIMAddFriendPermissionAllowed,
})
```

该设置只影响后续添加行为，不会删除已有好友关系，也不会自动接受、拒绝或删除已经存在的好友申请。

Promise 成功表示设置请求已经完成，不等同于 `onSelfInfoUpdated()` 已到达。需要确认当前策略时，重新调用[获取当前用户资料](/sdk/uniapp/user/profile/get-self-user-info)，并读取返回结果中的 `addFriendPermission`。
