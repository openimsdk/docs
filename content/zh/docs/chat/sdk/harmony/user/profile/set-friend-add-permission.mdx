---
title: '设置加好友权限'
description: '设置其他用户向当前账号发起好友关系时采用的处理策略。'
sourcePath: '/sdk/harmony/user/profile/set-friend-add-permission'
---

该账号级策略只影响后续添加行为，不会修改已有好友或已经存在的申请。

| 枚举值                                         | 含义                         |
| ---------------------------------------------- | ---------------------------- |
| `AddFriendPermission.AddFriendAllowed`         | 允许申请，需要当前用户审核。 |
| `AddFriendPermission.AddFriendAllowedNoReview` | 允许添加并直接建立好友关系。 |
| `AddFriendPermission.AddFriendDenied`          | 不允许其他用户添加当前账号。 |

```ts
import sdk, { AddFriendPermission, SetSelfInfoReq } from '@openimsdk/imsdk';

const request: SetSelfInfoReq = {
  userID: currentUserID,
  addFriendPermission: AddFriendPermission.AddFriendAllowed,
};
await sdk.setSelfInfo(request);
```

Promise 成功表示设置请求完成。需要展示最终策略时重新调用 `getSelfUserInfo()`，并读取返回用户的 `addFriendPermission`。
