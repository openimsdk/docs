Provide `groupID`, `userID`, and the new `groupNickname`. A successful callback means that the server completed the request. Reconcile the final profile through `onGroupMemberInfoChanged:` or a new query.

```objc
[[OIMManager manager] setGroupMemberNickname:groupID
  userID:targetUserID
  groupNickname:@"New group nickname"
  onSuccess:^(NSString * _Nullable data) { [self showSaved]; }
  onFailure:^(NSInteger code, NSString *message) {
    [self showErrorCode:code message:message];
  }];
```
