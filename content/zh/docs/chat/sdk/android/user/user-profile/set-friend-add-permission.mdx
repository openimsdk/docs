配置其他用户向当前登录账号发起好友申请时的验证策略（如需要验证、直接通过或拒绝添加）。该能力属于商业版。

在用户资料配置对象中设置好友添加权限数值后，调用[更新当前用户资料](/sdk/android/user/user-profile/set-self-info)生效：

```java
UserInfoReq request = new UserInfoReq();
request.setAddFriendPermission(AddFriendPermission.Allow.getValue());

OpenIMClient.getInstance().userInfoManager.setSelfInfo(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 设置好友添加权限成功
        }

        @Override
        public void onError(int code, String error) {
            // 处理错误
        }
    },
    request
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `request` | `UserInfoReq` | 是 | 用户资料配置对象，传入包含对应权限枚举值的请求体。 |

### 权限枚举说明

| 枚举值 | 数值 | 含义 |
| --- | --- | --- |
| `AddFriendPermission.Allow` | `0` | 允许其他用户添加，但需要当前用户审核好友申请。 |
| `AddFriendPermission.AllowNoReview` | `1` | 允许其他用户添加，并直接建立好友关系，无需审核。 |
| `AddFriendPermission.Deny` | `2` | 不允许其他用户添加当前账号。 |

## 返回结果

成功回调表示服务端已记录好友添加权限设置。

该设置仅影响后续其他用户向当前账号发起的好友申请，不会影响已有好友关系，也不会自动审批或删除当前已存在的好友申请列表。好友申请审批请参考[获取收到的好友申请](/sdk/android/user/friend-applications/get-recv-friend-application-list)。
