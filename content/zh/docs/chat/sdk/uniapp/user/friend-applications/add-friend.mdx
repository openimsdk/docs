---
title: '发送好友申请'
description: '向指定用户发送好友申请。'
sourcePath: '/sdk/uniapp/user/friend-applications/add-friend'
---

发送前应避免向当前用户自己或已经建立好友关系的账号重复申请。`toUserID` 是接收申请的用户 ID，`reqMsg` 是验证信息；没有验证内容时传空字符串。`ex` 可用于保存双方业务已经约定的扩展信息。

```uts
import { addFriend } from '@/uni_modules/unix-openim-sdk'

await addFriend({
  toUserID,
  reqMsg: verificationMessage,
})
```

Promise 成功只表示服务端已接收申请，不表示对方已经同意，也不能据此把对方加入好友列表。申请记录通过好友申请事件更新；对方同意后，再根据 `onFriendAdded()` 更新好友关系。申请事件的完整处理见[获取收到的好友申请](/sdk/uniapp/user/friend-applications/get-friend-application-list-as-recipient)，好友事件见[分页获取好友列表](/sdk/uniapp/user/friends/get-friend-list-page)。
