---
title: '检查群成员数据是否完整同步'
description: '检查指定群组的本地成员数据是否已完成全量同步。'
sourcePath: '/sdk/harmony/group/data-synchronization/check-group-member-data-sync'
---

```ts
import sdk, { CheckGroupMemberFullSyncReq, CheckGroupMemberFullSyncResp } from '@openimsdk/imsdk';

const request: CheckGroupMemberFullSyncReq = { groupID: groupID };
const response: CheckGroupMemberFullSyncResp = await sdk.checkGroupMemberFullSync(request);
if (!response.IsFullSync) {
  showMemberSyncingState();
}
```

`IsFullSync` 为 `true` 表示查询时该群的本地成员数据已完成全量同步。该方法不返回成员列表，也不会主动开始同步；需要成员列表或资料时仍应通过[分页查询群成员](/sdk/harmony/group/retrieving-group-members/get-group-member-list)进行读取，并处理成员事件增量。
