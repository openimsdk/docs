title: '查询指定好友资料'
description: '按用户 ID 批量查询指定好友的关系资料。'

---

`getSpecifiedFriendsInfo()` 只查询已经建立好友关系的用户。`userIDList` 是要查询的用户 ID 数组；`filterBlack` 决定是否从结果中过滤已被当前账号加入黑名单的用户。

```uts
import { getSpecifiedFriendsInfo } from '@/uni_modules/unix-openim-sdk'

const result = await getSpecifiedFriendsInfo({
  userIDList: ['user_a', 'user_b'],
  filterBlack: true,
})
const friends = result?.friends ?? []
```

Promise 成功后返回 `OpenIMFriendListResult | null`，好友数组位于 `friends`。返回项不保证与输入 ID 按位置一一对应，应使用 `userID` 将资料对应到请求用户；完整字段见[分页获取好友列表](/sdk/uniapp/user/friends/get-friend-list-page)。

查询陌生人的公开账号资料时，应使用[获取用户资料](/sdk/uniapp/user/profile/get-users-info)。该方法只返回调用时的数据，不会触发好友事件。
