---
title: '开启或关闭阅后即焚'
description: '使用 Flutter SDK 设置会话的阅后即焚模式。'
sourcePath: '/sdk/flutter/conversation/managing-conversations/set-private-chat'
---

```dart
await OpenIM.iMManager.conversationManager.setConversation(
  conversationID,
  ConversationReq(isPrivateChat: true),
);
```

传入 `false` 关闭阅后即焚。具体时长由 `burnDuration` 单独设置，见[设置阅后即焚时长](/sdk/flutter/conversation/managing-conversations/set-burn-duration)。该能力与定期删除服务端消息不同。

Future 成功只表示设置请求完成；最新状态通过 `onConversationChanged` 合并，完整 listener 见[获取会话列表](/sdk/flutter/conversation/retrieving-conversations/retrieve-conversation-list)。
