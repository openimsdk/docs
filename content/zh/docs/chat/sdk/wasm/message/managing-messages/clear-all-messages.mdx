---
title: '清理本地与服务端消息'
description: '使用 WASM SDK 清理当前账号本地与服务端的全部消息。'
sourcePath: '/sdk/wasm/message/managing-messages/clear-all-messages'
---

调用 `deleteAllMsgFromLocalAndSvr()` 可一次性清空当前登录账号在本地数据库以及服务端的全部历史消息。该操作影响当前账号下的所有会话，通常用于注销或全量清空等全局功能，请勿置于单个会话的常规操作菜单中。

```ts
await openimsdk.deleteAllMsgFromLocalAndSvr();
resetAllMessages();
```

该操作为全局清除操作。接口调用成功后，当前账号在本地及云端保存的消息记录均已清除。业务层随后应重置前端内存中的消息列表、搜索缓存与分页游标。

需要说明的是：该接口仅清理当前账号的消息副本，不会影响聊天对象或其他群成员各自保存的消息记录。后续界面可根据会话变更事件重新计算会话摘要与未读数。
