---
title: '删除群聊中指定用户的全部消息'
description: '使用 Android SDK 删除指定用户在群聊中的全部消息。'
sourcePath: '/sdk/android/message/managing-messages/delete-user-messages'
---

```java
messageManager.deleteUserAllMessagesInConv(
    conversationID,
    targetUserID,
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 删除请求已完成
        }

        @Override
        public void onError(int code, String error) {
            // 处理失败
        }
    }
);
```

该 API 只用于群聊，可删除指定用户在目标群会话中的全部消息。调用者没有操作权限时，通过 `onError` 返回错误。

其他客户端通过 `OnAdvanceMsgListener.onDeleteUserAllMsgsInConv` 接收删除通知。回调参数包含对应的 `conversationID` 和 `userID`：

```java
@Override
public void onDeleteUserAllMsgsInConv(DeleteUserAllMsgsListenerMsg event) {
    handleUserMessagesDeleted(event.getConversationID(), event.getUserID());
}
```
