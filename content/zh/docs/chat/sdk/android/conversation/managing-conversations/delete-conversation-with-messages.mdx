---

从当前用户的会话列表中彻底删除指定会话条目，并一并删除该会话下的所有历史消息。常用于用户在会话列表页执行“删除会话”操作。

```java
OpenIMClient.getInstance().conversationManager.deleteConversationAndDeleteAllMsg(
    new OnBase<String>() {
        @Override
        public void onSuccess(String data) {
            // 请求已完成，会话及其消息已删除。
        }

        @Override
        public void onError(int code, String error) {
            // code 和 error 说明失败原因。
        }
    },
    conversationID
);
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `base` | `OnBase<String>` | 是 | 异步请求回调。 |
| `conversationID` | `String` | 是 | 目标会话的唯一标识。 |

## 返回结果

成功回调表示服务端与本地已完成该会话及其关联消息的删除处理。

需要注意的是，该操作仅删除当前用户的会话记录与本地消息，不会解除好友关系，也不会自动退出或解散群组。若后续该会话收到新消息，SDK 将作为新会话再次拉起并触发事件。

删除成功后，SDK 会触发 `OnConversationListener.onConversationChanged` 事件；客户端应根据 `conversationID` 从列表数据源中移除对应会话项并刷新 UI，完整监听配置请参考[获取会话列表](/sdk/android/conversation/retrieving-conversations/retrieve-conversation-list)。若仅需清除消息而保留会话入口，请参考[清空会话消息](/sdk/android/conversation/managing-conversations/clear-conversation-messages)。
