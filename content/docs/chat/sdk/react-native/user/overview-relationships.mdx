Relationship capabilities manage social connections between the current user and other accounts—encompassing friendships, incoming and outgoing friend requests, and blacklists. User profiles, presence, and account settings are covered separately in [User overview](/sdk/react-native/user/overview-user).

## Relationship data structures

The SDK provides specialized models corresponding to each social state:

| Structure | Context | Applicable guides |
| --- | --- | --- |
| `PublicUserItem` | Search public profiles, display friend candidates, or render stranger cards | [Get user profiles](/sdk/react-native/user/profile/get-users-info) |
| `FriendUserItem` | Friend list, friend remark aliases, pin status, and relationship extensions | [Get friend list by page](/sdk/react-native/user/friends/get-friend-list-page), [Get specified friends info](/sdk/react-native/user/friends/get-specified-friends-info) |
| `FriendshipInfo` | Check whether a friendship exists between users | [Check friend relationship](/sdk/react-native/user/friends/check-friend) |
| `FriendApplicationItem` | Received or sent friend requests and their processing statuses | [Get received friend applications](/sdk/react-native/user/friend-applications/get-friend-application-list-as-recipient), [Get sent friend applications](/sdk/react-native/user/friend-applications/get-friend-application-list-as-applicant) |
| `BlackUserItem` | Blacklisted users maintained by the current account | [Get blacklist](/sdk/react-native/user/blacklist/get-black-list), [Add user to blacklist](/sdk/react-native/user/blacklist/add-black), [Remove user from blacklist](/sdk/react-native/user/blacklist/remove-black) |

| Task | Recommended guide |

| Send or process friend requests | [Send a friend request](/sdk/react-native/user/friend-applications/add-friend), [Get received friend applications](/sdk/react-native/user/friend-applications/get-friend-application-list-as-recipient), [Accept a friend request](/sdk/react-native/user/friend-applications/accept-friend-application), [Refuse a friend request](/sdk/react-native/user/friend-applications/refuse-friend-application) |

## Event listeners

Relationship mutations trigger asynchronous events:

- Friend application events are documented in [Get received friend applications](/sdk/react-native/user/friend-applications/get-friend-application-list-as-recipient).
- Friendship establishment, deletion, and profile changes are documented in [Get friend list by page](/sdk/react-native/user/friends/get-friend-list-page).
- Blacklist additions and removals are documented in [Get blacklist](/sdk/react-native/user/blacklist/get-black-list).
