Deleting a conversation group disassociates its assigned conversations, but does not delete the underlying conversations or chat messages.

## Code example

```ts
import sdk, { DeleteConversationGroupReq } from '@openimsdk/imsdk';

const request: DeleteConversationGroupReq = {
  conversationGroupID: conversationGroupID,
};
await sdk.deleteConversationGroup(request);
```

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `conversationGroupID` | `string` | Yes | The identifier of the conversation group to delete (not a chat group ID). |

## Return value

Returns a Promise that resolves to `void` upon deletion.

## State changes after the call

Once the Promise resolves, remove the group entry from local state using `conversationGroupID`. The server notifies connected clients via `EventOnConversationGroupDeleted`. See [Conversation groups overview](/sdk/harmony/conversation/managing-conversation-groups/overview-conversation-groups) for complete listener setups.
