一次性获取当前登录账号已加入的全部群组列表快照。

```ts
const groups = await OpenIMSDK.getJoinedGroupList();
```

## 返回结果

调用完成后返回 `GroupItem[]`。客户端在维护已加入群组集合时，应以 `groupID` 作为唯一合并标识。群组数量较多时，推荐使用[分页获取已加入群组](/sdk/react-native/group/retrieving-groups/get-joined-group-list-page)分批读取并按页合并。详细字段说明见[群组概览](/sdk/react-native/group/overview-group)。
